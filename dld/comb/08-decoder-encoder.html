1. Decoders

A decoder has n inputs and 2n outputs. Exactly one output is "on" for each input combination: output Di is the minterm i of the inputs. A 2-to-4 decoder is four AND gates plus two inverters.

Active-high output
The selected output is 1, all others 0 (AND gates).
Active-low output
The selected output is 0, all others 1 (NAND gates). Written Di' or drawn with a bubble.
Enable
Extra input. The decoder works only when the enable is at its active level. When it is disabled, no output is selected: active-high outputs all 0, active-low outputs all 1. Active-low enable EN' works when EN' = 0 (tie it to ground to leave it always on). With two enables, both must be active.

Truth table of a 2-to-4 decoder with enable (active-high, ma'am's table): E = 0 gives 0000. E = 1: I1I0 = 00 → D0 = 1, 01 → D1, 10 → D2, 11 → D3. D0 = E I1' I0', D1 = E I1' I0, D2 = E I1 I0', D3 = E I1 I0.

2. Any function on a decoder: the four combinations

A decoder produces all minterms, so any function is "OR of its minterms". One extra gate does the OR. ma'am's four combinations, for F = Σ(3,5,6,7) (that is also 2021–22 Q4b):

decoder outputsgatewhich minterms go into the gatewhy it works
active-highORthe 1-minterms: 3, 5, 6, 7F = D3 + D5 + D6 + D7 (SOP)
active-highNORthe 0-minterms: 0, 1, 2, 4NOR is 1 only when none of the zero-minterms is on
active-lowNANDthe 1-minterms: 3, 5, 6, 7NAND of D' is the OR of D (De Morgan)
active-lowANDthe 0-minterms: 0, 1, 2, 4AND of D' is 0 whenever a zero-minterm is selected, and 1 otherwise

Rule to remember: OR and NAND take the ones. NOR and AND take the zeros. The decoder polarity tells you which of the two is allowed: active-high with OR/NOR, active-low with NAND/AND. Several functions on the same decoder just means several gates (ma'am's multi-function examples):

2022–23 Q4(b) · 10 marks · older 2012–13 and 2015–16 · 2021–22 Q4(b) · 10 marks (active-low, AND)

Design a full adder circuit using a 3×8 decoder and two OR gates. (2021–22: F(x,y,z) = Σ(3,5,6,7) using an active-low 3×8 decoder and AND gates.)

Answer

Full adder: S = Σ(1,2,4,7) and Cout = Σ(3,5,6,7) of (x, y, z). Both are symmetric functions, so it does not matter which input is the MSB. Put x on I2, y on I1, z on I0 of an active-high decoder. S = D1 + D2 + D4 + D7 and C = D3 + D5 + D6 + D7. Two 4-input OR gates.

2021–22 Q4b: F = Σ(3,5,6,7), active-low outputs, AND gates: the zeros are 0, 1, 2, 4, so F = D0'·D1'·D2'·D4' with one AND gate (the second drawing above).

Multi-output examples from ma'am's notes. F1 = Σ(0,5,7), F2 = Σ(2,3,4), F3 = Σ(1,6,7) with an active-high decoder and three OR gates; and F1 = Σ(2,4,7), F2 = Σ(0,3), F3 = Σ(0,2,3,4,7) with an active-low decoder and three NAND gates ("NAND → active-low decoder").

What to write (function on a decoder, 10–12 marks)

  1. The minterm list of each function (convert Π to Σ if needed).
  2. A labelled decoder block: inputs with their order (MSB first), enables tied active, outputs D0..D7 with their polarity.
  3. Gate choice with the rule: "active-high with OR takes the 1s", etc.
  4. Wires from exactly the needed outputs to the gate; the output named F (or S, C).
  5. One check row, for example "x y z = 0 1 1 selects D3, so C = 1".

3. Bigger decoders from smaller ones

A decoder with an enable can be grown: decode the high bits with one decoder, and use each of its outputs as the enable of one small decoder that decodes the low bits.

2023–24 Q3(a) · 12 marks · older: 3×8 from two 2×4 (2011–12, 8 marks)

Design a 4-to-16 decoder using the minimum number of 2-to-4 decoders. (The 2-to-4 decoders have an enable, 1 = enabled; the 4-to-16 decoder itself has no enable.)

Answer

16 outputs need at least 16 / 4 = 4 small decoders. Something must also choose which of the four is on, and a 2-to-4 decoder is exactly that. Minimum = 5 decoders.

  1. The first decoder takes the two high bits I3 I2. Its outputs Y0..Y3 are the enables of the four second-level decoders, so exactly one of them is enabled.
  2. All four second-level decoders get I1 I0.
  3. Second-level decoder k gives outputs D(4k)..D(4k+3). All other decoders are disabled (outputs 0).

3×8 from two 2×4 (older question and ma'am's notes): I2 chooses the decoder. I1 I0 go to both. The decoder for D0–D3 has E = I2'. The decoder for D4–D7 has E = I2. One inverter.

What to write (decoder expansion, 8–12 marks)

  1. The count and the reason: "16/4 = 4 decoders for the outputs, plus 1 to select = 5".
  2. The diagram: first-level decoder fed with the high bits, its outputs into the enables of the others, the low bits shared.
  3. Every output labelled D0..D15 and the enable polarity stated.

4. A 4-variable function on a small decoder

A 2-to-4 decoder only handles two variables. Put two variables on the decoder and let the other two variables appear in extra gates. For each decoder output, ask: "when the decoder selects this minterm, what must F be as a function of the other two variables?" This is exactly the MUX-input table.

  1. Pick two variables for the decoder inputs (any two, A is the MSB). Different choices give different gate counts; try them, take the cheapest.
  2. For each decoder output Di, find the residual ri: F as a function of the two remaining variables (0, 1, a literal, or a small function).
  3. F = Σ Di · ri. Where ri = 1 the output Di goes straight in. Where ri = 0, Di is not used.
  4. With active-low outputs Di': each term is Di' + ri' (an OR gate), and F = NAND of all the terms. The terms with ri = 1 are just Di'.
  5. Tie the enable to its active level.
2017–18 Q3(a) · 12 marks

Implement f(w,x,y,z) = Σ(0,2,6,7,8,10,11,13,14) with a 2×4 decoder with inputs A, B, an active-low enable EN' and active-low outputs D0'..D3', using the minimum number of extra logic gates.

Answer

The cheapest choice found is A = y, B = z (y MSB). The residuals in (w, x) are:

I0 = x', I1 = wx, I2 = 1, I3 = w ⊕ x. So F = D0·x' + D1·wx + D2 + D3·(w ⊕ x). With active-low outputs: F = NAND( D0' + x , D1' + (wx)' , D2' , D3' + (w ⊕ x)' ). Gates: OR(D0', x), NAND(w,x) and OR(D1', ·), XNOR(w,x) and OR(D3', ·), and the final NAND: 6 extra gates. EN' = 0.

For comparison, w and x on the decoder gives the residuals z', y, z' + y, y ⊕ z, and the same construction needs 8 extra gates.

2018–19 Q3(a) · 14 marks

Design a logic circuit for f(w,x,y,z) = Σ(0,2,6,7,10,11,12,14) with a 2-to-4 line decoder with inputs A, B, enabled by active-low enables EN1' and EN2', using the minimum number of extra gates.

Answer

Assumption: the outputs are active-high (the question says only that the enables are active-low). Again y, z on the decoder (A = y, B = z), residuals in (w, x):

I0 = w ⊙ x (XNOR), I1 = 0, I2 = 1, I3 = w ⊕ x. F = D0·(w ⊙ x) + D2 + D3·(w ⊕ x). Gates: XNOR, XOR, two ANDs and an OR: 5 extra gates. EN1' = EN2' = 0 (both to ground). (With w, x on the decoder instead, the residuals are z', y, y, z' and the circuit needs 6 gates.)

2017–18 Q3(c) · 10 marks

Design a half subtractor using a 2-to-4 decoder (active-high outputs, active-low enable EN').

Answer

x − y: Difference D = x ⊕ y = Σ(1,2), Borrow B = x'y = Σ(1). Decoder inputs I1 = x, I0 = y, EN' = 0. D = D1 + D2 (one OR gate). B = D1 (no gate, a wire).

2020–21 Q1(a) · 15 marks

Add two 2-bit numbers X1X0 and Y1Y0 with a 2-to-4 decoder (inputs I0, I1, active-low outputs O3..O0, active-low enables EN1', EN2'). Use the minimum number of extra gates.

Answer

The sum S2 S1 S0 needs four inputs, but the decoder takes only two. Use the decoder as the half adder of the low bits, and finish the high bit with gates.

  1. Decoder inputs: I1 = X0, I0 = Y0. Outputs O1' (X0'Y0), O2' (X0Y0'), O3' (X0Y0). Enables grounded.
  2. S0 = X0 ⊕ Y0 = O1 + O2 = NAND(O1', O2'). The carry c1 = O3 (the complement is O3').
  3. Let g = XNOR(X1, Y1) = (X1 ⊕ Y1)'. Then S1 = (X1 ⊕ Y1) ⊕ c1 = XOR(g, O3').
  4. S2 = X1Y1 + (X1 ⊕ Y1)·c1 = AND(X1, Y1) + NOR(g, O3').

Extra gates: NAND, XNOR, XOR, NOR, AND, OR = 6 (verified for all 16 input pairs). Assumption: other designs exist; this one uses the decoder for the low-bit half adder and no inverters.

2024–25 Q7(c) · 12 marks

Design a 1-bit full subtractor using a 4-to-16 decoder with active-low outputs and two active-low enables EN1', EN2'.

Answer

x − y − b: Diff = Σ(1,2,4,7), Bout = Σ(1,2,3,7). Only three inputs are needed, so tie the MSB input I3 to 0 (assumption) and put x, y, b on I2, I1, I0. Minterm numbers are then 0–7. Enables to ground. Outputs are active-low, so use NAND gates on the ones:

Diff = NAND(D1', D2', D4', D7'), Bout = NAND(D1', D2', D3', D7').

(Alternative that uses the spare input: tie I3 to 1 and take D9, D10, D12, D15 and D9, D10, D11, D15. Both are correct if the enables are tied to ground.)

5. Decoder as a demultiplexer

A demultiplexer sends one input line D to one of 2n output lines chosen by n select bits. A decoder with an enable is exactly a demultiplexer: put the data on the enable input and the select bits on the decoder inputs.

6. Encoders

An encoder is the reverse of a decoder: 2n input lines, n output lines, giving the binary number of the active input. The plain octal-to-binary encoder (8 inputs, 3 outputs) is three OR gates:

Y2 = I4 + I5 + I6 + I7
Y1 = I2 + I3 + I6 + I7
Y0 = I1 + I3 + I5 + I7

Two problems: (1) if two inputs are on at once the output is a mixture (I3 and I5 together give 111); (2) I0 on and no input on both give 000. Fix: make it a priority encoder (one input wins) with a valid output V (1 when any input is on).

7. Priority encoders

If several inputs can be on at once, the highest-priority one is encoded. The output is the binary number of that input (not its rank). V = 1 if any input is on, so that "no input" is not confused with "input 0".

Method (do these steps in this order).

  1. Write the priority order, highest first.
  2. Compressed truth table. The first row is "all inputs 0": outputs are don't-care (X X X), V = 0. Then one row per input, lowest priority first. In the row for input p: p = 1, every input of higher priority = 0, every input of lower priority = X. Outputs = binary number of p, V = 1.
  3. Equations. An output bit is 1 for every row whose input number has that bit = 1. So each output is an OR of terms of the form "input i is 1 and every higher-priority input is 0", one term per input i whose number has that bit set. V = OR of all inputs.
  4. Simplify with a K-map or by absorption (x + x'y = x + y). Because the all-zero row is a don't-care, the terms shrink a lot.
  5. Draw: AND-OR gates, every input and the outputs Y2 Y1 Y0 and V labelled.

ma'am's 4-input example (I3 > I2 > I1 > I0): rows 0000 → XX, V = 0; 0001 → 00; 001X → 01; 01XX → 10; 1XXX → 11. Y1 = I3 + I2, Y0 = I3 + I2'I1, V = I3 + I2 + I1 + I0.

What to write (priority encoder, 9–15 marks)

  1. One sentence: "highest priority input wins; output is its binary number; V = 1 when any input is 1".
  2. The compressed truth table: first row all 0 with X X X and V = 0, then the rows with the 0s above and X below, outputs filled in.
  3. Output equations as OR of "input i AND the higher inputs' complements", then the simplified form.
  4. V = OR of every input.
  5. The circuit with inputs, Y2 Y1 Y0 and V labelled.
  6. If the inputs are named by letters (A..H), say the code you assume (A = 000 … H = 111).

Traps that cost marks
  • Decoder with active-low outputs: using OR/NOR. Active-low takes NAND (ones) or AND (zeros).
  • Forgetting to tie the enable to its active level (EN' = 0), or to say "disabled = all outputs inactive".
  • Reading the decoder inputs in the wrong order. The first-named variable is the MSB (Di is the minterm number i).
  • Giving the rank instead of the number: the output is the index of the winning input, not "1st priority".
  • Priority table: putting X on the higher-priority side. X goes on the lower-priority side.
  • No V output, so "no input active" and "input 0 active" look identical.
  • 4-to-16 from 2-to-4: using 4 decoders and forgetting the first-level decoder.
