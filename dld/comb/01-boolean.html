Boolean algebra: laws, proofs, duality, canonical forms

Boolean algebra is asked in every paper, usually as the opening 5–12 marks. 2024–25 Q1c (7, prove and simplify xy + x'z + yz); 2023–24 Q1a (8, are the dual and the complement of F the same), Q1b (8, canonical vs standard forms), Q2a (10, (x'+y)(x+z)(y+z) in minterms), Q3b (11, simplify by algebra), Q3c (12, "consensus" circuit, exactly two inputs 1); 2022–23 Q3c (7, dual of XOR = its complement), Q4a (10, xy + x'z as a product of maxterms by the distributive law); 2021–22 Q2a (10, (A+B)'(A'+B')'), Q2c (7, A + B'C as minterms); 2019–20 Q5a (18, 3-input majority with NAND only), Q5c (10, truth-table proofs), Q7b (7, dual of XOR); 2018–19 Q1d (5) and 2017–18 Q1d (8, simplify to POS and SOP). CT1 2026: Q1 (5, simplify xy + x'z + yz), Q3 (4, complement by duality), Q4 (4, same gates, different levels). Older papers add: prove x(x+y) = x, the consensus theorem, De Morgan for 3 variables, non-associativity of NOR, XOR is not distributive over AND, a⊕b⊕c⊕d as maxterms. Treat this chapter as certain marks: all of it is short, mechanical and checkable.

1. The rules you may quote

Ma'am's course: a set B = {0, 1}, two operations OR (+) and AND (·), and the complement ('). Precedence: ( ) then ' then · then +. A literal is one occurrence of a variable or its complement, so xy + xy'z has 5 literals.

Axioms (postulates)
1 Closure. 2 Identity: x + 0 = x, x·1 = x. 3 Commutative. 4 Distributive: x(y+z) = xy + xz and x + yz = (x+y)(x+z). 5 Complement: x + x' = 1, x·x' = 0. 6 Cardinality: B has at least two different elements.
Theorems
1 Idempotency: x + x = x, x·x = x. 2 x + 1 = 1, x·0 = 0. 3 Absorption: x + xy = x, x(x+y) = x. 4 Involution: (x')' = x. 5 Associative. 6 De Morgan: (x+y)' = x'y', (xy)' = x' + y'. 7 Consensus: xy + x'z + yz = xy + x'z, and its dual (x+y)(x'+z)(y+z) = (x+y)(x'+z).

Duality principle: if an identity is true, its dual is true. To take the dual: (1) swap + and ·, (2) swap 0 and 1. Literals stay as they are. Every theorem above comes in a pair because of this. Three proof techniques are accepted: algebra from the axioms, duality, truth table.

Proofs from the axioms, as ma'am writes them (learn these two lines of reasoning, they are asked as "prove"):

to provechain
x + x = xx + x = (x+x)·1 = (x+x)(x+x') = x + xx' = x + 0 = x
x + 1 = 1x + 1 = 1·(x+1) = (x+x')(x+1) = x + x'·1 = x + x' = 1
x + xy = xx·1 + xy = x(1+y) = x(y+1) = x·1 = x. The dual, x(x+y) = x, follows by duality (2011–12: "Prove x(x+y) = x", 5 marks)
De Morgan (x+y)' = x'y'Let X = x+y and Y = x'y'. X + Y = (x+y+x')(x+y+y') = 1·1 = 1 and XY = xx'y' + yx'y' = 0. X and Y satisfy both complement axioms, so Y is the complement of X.

De Morgan for three variables, by successive substitution (2013–14, 10 marks): (x+y+z)' = (x + (y+z))' = x'·(y+z)' = x'·y'z' = x'y'z'. Dual: (xyz)' = x' + y' + z'.

2. Duality and complement

These two are different things, and 2023–24 Q1a and CT1 Q3 test exactly that.

Dual of f
Swap + and ·, swap 0 and 1. Literals unchanged. Example: dual of x(y + z') is x + yz'.
Complement f'
The function that is 1 where f is 0. By De Morgan: complement every literal and swap + and ·.

Why the "dual method" works (the answer to ma'am's margin question "how does this work?"): the dual satisfies dual(f)(x₁…xₙ) = ( f(x₁'…xₙ') )'. So if you complement every literal of the dual, you undo the inner complement and are left with f'. That is the whole method:

  1. Write the dual of f (swap + and ·, swap 0 and 1).
  2. Complement every literal in it.
  3. The result is f'. (Optionally simplify.)
CT1 2026 Q3 · 4 marks

How can we complement a function using the duality-principle based method? Show an example.

Answer

Method: (1) take the dual of f; (2) complement each literal. Example f(x,y,z) = x(y'z' + yz).

Dual: x + (y' + z')(y + z). Complement each literal: f' = x' + (y + z)(y' + z') = x' + yz' + y'z (since yy' = zz' = 0).

Check with De Morgan: f' = x' + (y'z' + yz)' = x' + (y + z)(y' + z'). Same. Check one row: x=1, y=0, z=0 gives f = 1·(1 + 0) = 1, and f' = 0 + 0 + 0 = 0 ✓.

Two more of ma'am's examples: complement of (x'+y+z')(x+y')(x+z): dual x'yz' + xy' + xz, then complement literals: xy'z + x'y + x'z'. Complement of xy' + x'y: (x'+y)(x+y') = xy + x'y'.

What to write (complement by duality, 4 marks)

  1. One line naming the two steps: "complement = dual, then complement each literal".
  2. The dual, written out. Then the literal-complemented result.
  3. A one-line check (De Morgan, or one truth-table row). Examiners reward the check.

Is the dual equal to the complement? (2023–24 Q1a, 8 marks)

Because dual(f)(x) = (f(x'))' and f'(x) = (f(x))', the dual equals the complement exactly when f(x') = f(x) for every input, that is, when f does not change if all inputs are inverted. XOR and XNOR of two variables have this property. Most functions do not.

2023–24 Q1(a) · 8 marks

Analyze whether the dual and the complement of F = ABC + A(B+C) + A'B'C' are the same. Justify.

Answer

F = ABC + AB + AC + A'B'C' = Σ(0, 5, 6, 7).

Dual: Fd = (A+B+C)(A + BC)(A'+B'+C'). Complement: F' = Σ(1, 2, 3, 4).

The truth tables differ. Fd = Σ(3, 4, 5, 6) and F' = Σ(1, 2, 3, 4): they agree only on rows 3 and 4. So they are not the same. (Quick reason: F(0,0,1) = 0 but F(1,1,0) = 1, so F(x') ≠ F(x).) The highlighted rows show where they differ.

Dual of XOR is its complement (2019–20 Q7b, 2022–23 Q3c, 7 marks each)

2019–20 Q7(b) · 2022–23 Q3(c) · 7 marks

Show that the dual of the exclusive-OR is equal to its complement.

Answer

x ⊕ y = xy' + x'y. Its dual: swap + and ·: (x + y')(x' + y).

Expand: (x + y')(x' + y) = xx' + xy + y'x' + y'y = 0 + xy + x'y' + 0 = xy + x'y'.

And xy + x'y' is XNOR, the complement of XOR: (xy' + x'y)' = (x'+y)(x+y') = xy + x'y' (same expansion). So dual(XOR) = XOR' ∎

Truth-table version: the third and fourth columns are identical.

What to write (dual of XOR, 7 marks)

  1. x ⊕ y = xy' + x'y.
  2. Dual = (x + y')(x' + y).
  3. Multiply out with xx' = 0: = xy + x'y'.
  4. State "= (x ⊕ y)' = XNOR". Add the 4-row truth table if time allows.

3. XOR identities (ma'am L18, used in parity and adders)

  • x ⊕ y = xy' + x'y. XNOR: (x ⊕ y)' = xy + x'y'.
  • x ⊕ 0 = x, x ⊕ 1 = x', x ⊕ x = 0, x ⊕ x' = 1.
  • x ⊕ y' = x' ⊕ y = (x ⊕ y)'. Reason: complementing one input moves every row between "odd" and "even".
  • Commutative and associative, so XOR of n variables is well defined. The output is 1 exactly when an odd number of inputs are 1 (so XOR is called an odd function).
  • XOR is not distributive over AND: x ⊕ (yz) ≠ (x ⊕ y)(x ⊕ z). Counter-example x = 1, y = 1, z = 0: left side 1 ⊕ (1·0) = 1 ⊕ 0 = 1; right side (1 ⊕ 1)(1 ⊕ 0) = 0·1 = 0. They differ. (2015–16, 7 marks.)
  • Dual of XOR of an even number of variables = its complement. (For an odd number of variables, the dual of XOR is XOR itself.)
2015–16 · 10 marks (older)

Why is XOR called an odd function? Convert a ⊕ b ⊕ c ⊕ d to canonical maxterm form.

Answer

The output is 1 when an odd number of inputs are 1, so the minterms are the 8 inputs with one or three 1s: Σ(1, 2, 4, 7, 8, 11, 13, 14). The maxterms are the others: Π(0, 3, 5, 6, 9, 10, 12, 15) = (a+b+c+d)(a+b+c'+d')(a+b'+c+d')(a+b'+c'+d)(a'+b+c+d')(a'+b+c'+d)(a'+b'+c+d)(a'+b'+c'+d').

4. Simplifying with algebra

The procedure (numbered, use it every time):

  1. Remove brackets with the distributive law. Use both forms: x + yz = (x+y)(x+z) is the one students forget.
  2. Delete duplicates (x + x = x) and zero products (xx' = 0).
  3. Absorb: x + xy = x, x + x'y = x + y.
  4. Merge pairs: xy + xy' = x. If a pair is missing, add a redundant term by consensus or multiply by (z + z') so that merging becomes possible.
  5. Count literals before and after. Stop when no law applies.
2024–25 Q1(c) 7 marks · CT1 2026 Q1 5 marks · older 2013–14 "consensus theorem" 8 marks

Using laws and theorems prove and simplify xy + x'z + yz = xy + x'z. (i) apply laws; (ii) prove step by step that yz is redundant.

Answer

Multiply the redundant term by (x + x') = 1:

yz = yz(x + x') = xyz + x'yz.

So xy + x'z + yz = xy + x'z + xyz + x'yz = xy(1 + z) + x'z(1 + y) = xy + x'z. The term yz is redundant ∎

In words: when x = 1, yz is already covered by xy; when x = 0, it is already covered by x'z. Either way yz adds nothing. The dual: (x+y)(x'+z)(y+z) = (x+y)(x'+z).

What to write (prove and simplify, 5–7 marks)

  1. The statement of the theorem: "consensus: xy + x'z + yz = xy + x'z".
  2. The trick line: yz = yz(x + x') = xyz + x'yz.
  3. The absorption line: xy + xyz = xy and x'z + x'yz = x'z.
  4. The final answer boxed, and the words "yz is redundant".
2021–22 Q2(a) 10 marks · also 2013–14 · "minimum number of literals"

Simplify (A + B)'(A' + B')' to the minimum number of literals.

Answer

De Morgan on each bracket: (A + B)' = A'B' and (A' + B')' = AB. So the product is A'B'·AB = (AA')(BB') = 0·0 = 0. Zero literals. (Check with a truth table: A+B is the complement of A'B' and A'+B' is the complement of AB; A'B' and AB are never 1 together.)

2023–24 Q3(b) · 11 marks

Show by Boolean algebra that F = xyz' + wx'y' + (x'+z+w)(x'+z+w') + xyz + wx'y simplifies to xy + wx' + x' + z (as printed).

Answer
  1. (x'+z+w)(x'+z+w') = (x'+z) + ww' = x' + z. (Distributive law, x + yz = (x+y)(x+z) with the pair w, w'.)
  2. xyz' + xyz = xy(z' + z) = xy.
  3. wx'y' + wx'y = wx'(y' + y) = wx'.
  4. So F = xy + wx' + x' + z. This is the printed result ∎
  5. It can be reduced further: wx' + x' = x' (absorption), and then x' + xy = x' + y. So the minimum is F = x' + y + z. Mention this: the printed target is not minimal. The engine agrees: F is 0 only when x = 1, y = 0, z = 0 (any w).
2017–18 Q1(d) 8 marks · 2018–19 Q1(d) 5 marks

Simplify to POS and SOP. (2017–18) BCD' + ABC' + ACD. (2018–19) ACD' + CD + AB' + ABCD.

Answer

2017–18: BCD' + ABC' + ACD. SOP: add the redundant term AB. It is allowed because AB = ABC' + ABC and ABC = ABCD + ABCD', where ABCD ⊆ ACD and ABCD' ⊆ BCD' (everything in AB is already in the function). Then ABC' is absorbed by AB: SOP = AB + ACD + BCD' (7 literals, down from 9).

POS: take the complement of the SOP of the zeros: F' = A'C' + B'C' + B'D' + A'D, so F = (A + C)(B + C)(B + D)(A + D') (8 literals). This is quickest on a K-map (group the 0s). The two forms have the same truth table, Σ(6, 11, 12, 13, 14, 15).

2018–19: ACD' + CD + AB' + ABCD. ACD' + CD = C(AD' + D) = C(A + D) = AC + CD. ABCD is absorbed by AC. So SOP = CD + AB' + AC (6 literals). POS: distribute: F = A(B' + C) + CD = (A + CD)(B' + C + CD) = (A + C)(A + D)(B' + C), because B' + C + CD = B' + C. POS = (A + C)(A + D)(B' + C). Truth table Σ(3, 7, 8, 9, 10, 11, 14, 15).

Quick way to get SOP and POS in the exam: write the function as a truth table or K-map first (chapter 3). SOP = group the 1s. POS = group the 0s, read F' as a sum of products, then complement with De Morgan. The algebra above is the "show your working" version.

5. Minterms, maxterms, canonical and standard forms

Minterm mi
An AND term containing every variable once, true or complemented. It is 1 at exactly one input row. The subscript is the row number read in binary: m₃ = x'yz (011). x'y'z is m₁.
Maxterm Mi
An OR term containing every variable once. It is 0 at exactly one row, and the complement convention is opposite: M₃ = x + y' + z' (011 → 0 means plain, 1 means complemented). mi' = Mi.
Canonical form
Sum of minterms (SOM, Σ) or product of maxterms (POM, Π). Every term has all variables.
Standard form
SOP or POS where terms need not contain every variable. Always a two-level circuit.

Σ to Π: keep the same function, swap the symbol, list the row numbers that are missing. Example Σ(0,1,2,3,6) = Π(4,5,7), because f' = Σ(4,5,7) = m₄ + m₅ + m₇, and f = (m₄ + m₅ + m₇)' = M₄M₅M₇.

Expanding by algebra (her method)

  1. To minterms (SOM): make it a sum of products (multiply out). For each product that is missing a variable v, multiply it by (v + v') and expand. Collect, drop duplicates.
  2. To maxterms (POM): make it a product of sums (use x + yz = (x+y)(x+z)). For each sum missing a variable v, add vv' (= 0) to it and split: (S + vv') = (S + v)(S + v').
  3. Write the row number of every term in binary → decimal.
2023–24 Q2(a) · 10 marks

Express F = (x'+y)(x+z)(y+z) in minterms.

Answer

By the dual consensus theorem, (x'+y)(x+z)(y+z) = (x'+y)(x+z), so the factor (y+z) is redundant. Multiply out: (x'+y)(x+z) = x'x + x'z + xy + yz = x'z + xy + yz = x'z + xy (consensus again).

Expand each product with the missing variable: x'z = x'z(y + y') = x'yz + x'y'z = m₃ + m₁. xy = xy(z + z') = xyz + xyz' = m₇ + m₆.

F = Σ(1, 3, 6, 7) = x'y'z + x'yz + xyz' + xyz.

2021–22 Q2(c) 7 marks · 2022–23 Q4(a) 10 marks

(2021–22) Express F(A,B,C) = A + B'C as a sum of minterms using Boolean algebra. (2022–23) Convert F = xy + x'z to a product of maxterms using the distributive law.

Answer

2021–22. A = A(B + B')(C + C') = ABC + ABC' + AB'C + AB'C'. B'C = B'C(A + A') = AB'C + A'B'C. Collect, remove the repeated AB'C: F = Σ(1, 4, 5, 6, 7) = A'B'C + AB'C' + AB'C + ABC' + ABC.

2022–23. Distribute twice: xy + x'z = (xy + x')(xy + z) = (x + x')(y + x')(x + z)(y + z) = (x' + y)(x + z)(y + z). Add the missing variable to each sum:

x' + y = x' + y + zz' = (x' + y + z)(x' + y + z') → rows 100, 101 → M₄, M₅. x + z = x + z + yy' = (x + y + z)(x + y' + z) → M₀, M₂. y + z = y + z + xx' = (x + y + z)(x' + y + z) → M₀, M₄.

Collect: F = Π(0, 2, 4, 5) = (x+y+z)(x+y'+z)(x'+y+z)(x'+y+z'). Cross-check: the minterm list is Σ(1, 3, 6, 7), and 0,2,4,5 are exactly the missing rows ✓.

What to write (expansion by algebra, 7–10 marks)

  1. The function as SOP (or POS) first.
  2. For each term: the line "× (v + v')" or "+ vv'", then the expanded terms.
  3. The binary → decimal row number beside every final term.
  4. The final Σ(...) or Π(...), and one cross-check: Σ and Π lists together cover 0…2ⁿ−1 with no overlap.

6. How many Boolean functions are there?

n variables have 2n rows (minterms). A function is decided by choosing, for each row, output 0 or 1. So there are 2(2ⁿ) functions. Another way: every function is a sum of some subset of the 2ⁿ minterms, and a set of 2ⁿ things has 2(2ⁿ) subsets.

2416 (AND, OR, NAND, NOR, XOR, XNOR, constants 0 and 1, x, y, x', y', and four inhibit/implication functions such as x'y)

7. Circuits from a description: majority and "exactly two"

Method (4 steps from ma'am's slides): name inputs and outputs, write the truth table, simplify (K-map), draw and verify. Both of these questions are 12–18 marks, mostly for doing the four steps in order.

2019–20 Q5(a) · 18 marks

A majority circuit outputs 1 if the input variables have more 1s than 0s. Design a 3-input majority circuit: truth table, simplified Boolean equation, logic diagram. Use only NAND gates.

Answer

F = 1 when at least two of x, y, z are 1: F = Σ(3, 5, 6, 7).

K-map: three pairs (3,7) = yz, (5,7) = xz, (6,7) = xy, all essential. F = xy + yz + xz (6 literals).

NAND only: NAND-NAND form. F = ((xy)'(yz)'(xz)')'. Three 2-input NANDs feed one 3-input NAND. 4 gates, 9 gate inputs, 2 levels.

(The three product terms are the three consensus pairs. Algebra check: xy + yz + xz = xy + z(x + y) is the full-adder carry.)

2023–24 Q3(c) · 12 marks

Consensus circuit: the output is 1 if exactly two of the three inputs are 1. Give the truth table, simplified equation and circuit.

Answer

Despite the name, this has nothing to do with the consensus theorem. Exactly two 1s: F = Σ(3, 5, 6).

The three minterms 011, 101, 110 are pairwise non-adjacent on the K-map, so nothing combines. F = x'yz + xy'z + xyz' (9 literals). Circuit: three 3-input ANDs and one 3-input OR (inverters for x', y', z'). 4 gates + 3 NOT.

A cheaper alternative uses the majority function: "at least two" AND NOT "all three": F = (xy + yz + xz)·(xyz)'. (State which one you draw.)

8. Proof by truth table (2019–20 Q5c, 10 marks)

2019–20 Q5(c) · 10 marks

Demonstrate the validity of these identities by truth tables: (i) De Morgan for three variables, (x + y + z)' = x'y'z'. (ii) The distributive law x(y + z) = xy + xz.

Answer

(The printed question lost its primes; the intended identity is (x+y+z)' = x'y'z'.) List all 8 rows, compute both sides, show the two columns are identical.

The last two columns of each table are identical on every row, so both identities hold ∎

What to write (truth-table proof, 5 marks each)

  1. The identity, with the missing primes put back.
  2. A table with all 2ⁿ rows (8 for three variables). Show intermediate columns (y+z, x+y+z).
  3. Left-side column and right-side column next to each other.
  4. One sentence: "the two columns are identical for all 8 input combinations, hence proved".

9. Same gates, same inputs, different levels (CT1 2026 Q4, 4 marks)

CT1 2026 Q4 · 4 marks

If two implementations of the same Boolean expression need the same number of logic gates with the same number of gate inputs but differ in the number of logic levels, which would you prefer? Justify.

Answer

Prefer the one with fewer levels. The delay from input to output is the sum of the gate delays along the longest path, so fewer levels means a smaller propagation delay and a faster circuit. Cost (gates, gate inputs) is equal, so the faster one loses nothing. This is also why ma'am calls the two-level standard form "quite faster" than a multi-level form.

Example: ABCD with three 2-input AND gates (3 gates, 6 inputs in both circuits):

The tree reaches F after 2 gate delays; the chain after 3. If a multi-level form does have fewer gates or inputs (factoring, e.g. AB + C(D+E) against AB + CD + CE), then it is a cost-against-speed trade-off, and you should say so.

Traps that cost marks

  • Dual ≠ complement. The dual keeps the literals; the complement flips them. They coincide only when F is unchanged by inverting every input (2-input XOR).
  • Maxterm subscripts: M₃ = x + y' + z' (1 means complemented in a maxterm). Do not copy the minterm pattern.
  • Σ to Π lists the missing numbers, not the same numbers.
  • Forgetting the second distributive law x + yz = (x+y)(x+z) when converting to a product of sums.
  • Stopping at the printed target: 2023–24 Q3(b) goes on to x' + y + z. Show the printed form first, then say it can be reduced.
  • A truth-table proof must list every row. "It is obvious" gets no marks.
