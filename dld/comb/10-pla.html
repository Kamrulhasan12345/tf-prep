1. What a PLA is

A Programmable Logic Array has two programmable planes. The AND plane builds product terms from the inputs and their complements. The OR plane adds chosen product terms for each output. Each output then passes through an XOR gate with a fixed 0 or 1: XOR 0 keeps the output (T, true), XOR 1 inverts it (C, complemented).

  • Size is given as n inputs, k product terms, m outputs (n buffer-inverters, k AND gates, m OR gates, m XOR gates).
  • Before programming, every connection exists. Programming means blowing the fuses you do not need. In ma'am's diagram a dot marks a connection that is kept; in the fuse maps below a red × marks a kept connection.
  • The cost is the number of distinct product terms k (shared terms count once). The number of literals in a term does not matter.

2. The programming table (ma'am's format)

Product termInputs A B COutputs F1 (T/C) F2 (T/C)
numbered 1 … k1 = variable true, 0 = complemented, – = not in the term1 = this term feeds that OR gate, – = not used
  1. Simplify each function. For every output work out both F and F' (K-map the 1s and the 0s).
  2. Choose, for each output, T (use F) or C (use F'), so that the total number of distinct product terms is smallest. Look for terms that appear in several chosen expressions.
  3. List the distinct product terms, number them.
  4. Fill the input columns: 1, 0 or – for each term.
  5. Fill the output columns: 1 where the term is in that output's chosen expression (F or F').
  6. Write T or C in the output column heads. C means the OR output is inverted by the XOR (XOR 1).
  7. Draw the fuse map if asked: inputs and complements as vertical lines, each term a horizontal line, × at kept connections.

Why complementing helps: F' may have terms in common with another output, or fewer terms than F itself. The page's PLA widget tries every T/C choice and every shared term set and reports the true minimum.

3. The classic: Σ(0,1,2,4) and Σ(0,5,6,7)

2022–23 Q2(b) · 15 marks · also 2011–12 (with F3 = Σ(0,3,5,7), 4 terms, polarity C T T) · 2014–15 (3 inputs, 4 terms, 2 outputs)

Tabulate the PLA programming table for F1(A,B,C) = Σ(0,1,2,4) and F2(A,B,C) = Σ(0,5,6,7). Minimise the number of product terms.

Answer

Step 1: both forms. F1 = A'B' + A'C' + B'C' (3 terms), F1' = AB + AC + BC. F2 = A'B'C' + AB + AC, F2' = A'B + A'C + AB'C'.

Step 2: choose. F1' (AB + AC + BC) and F2 (A'B'C' + AB + AC) share AB and AC. Using F1 complemented and F2 true gives 4 distinct terms: AB, AC, BC, A'B'C'. (Both true would need 6.)

F1 = (AB + AC + BC)' (C, XOR 1) and F2 = AB + AC + A'B'C' (T). Minimum = 4 terms, confirmed by the engine.

What to write (PLA table, 10–15 marks)

  1. K-maps (or equations) of each F and each F'. Say which form you use and why ("AB and AC are shared").
  2. The list of distinct product terms with a count.
  3. The programming table: term number, input columns 1 / 0 / –, output columns 1 / –, and (T) or (C) written in the output head.
  4. One line: "C means the output XOR is 1: F1 = (AB + AC + BC)'".
  5. The fuse map or PLA diagram if the question says "show the fuse map".

2020–21 Q2(a) · 15 marks

A digital security lock using a PLA has a BCD input and opens after converting the input to Excess-3. Use the minimum product terms and show the fuse map.

Answer

Inputs A B C D (BCD, 0–9); outputs w x y z = digit + 3. Codes 1010–1111 never occur: don't-cares that may be used as 1 or 0. (The 4-variable search over all T/C choices takes about 90 seconds, so the table below was computed once with the engine and stored.)

Single-output minimal forms: w = A + BC + BD, x = B'C + B'D + BC'D', y = CD + C'D', z = D'. Taking x complemented (x' = BC + BD + B'C'D') shares BC and BD with w. Result: 7 distinct product terms.

Class Test 2 · 2-bit adder on a PLA

Answer

Four inputs, three outputs. Minimum is 9 product terms with S2 complemented (stored result, engine search).

5. Reading a PLA

If a question gives the fuse map and asks for the functions (2013–14 style), read each product-term row (1 true, 0 complemented, – absent), then OR the terms that the output column marks, then apply the T/C bit. Always check whether the output is T or C before writing F.

6. ROM and memory decoding

ROM
A 2n × m ROM has n address lines and m outputs. Inside is a full n-to-2n decoder (every minterm) and an OR array that is programmed once. The programming table is simply the truth table: address → stored word. Any function of n variables with m outputs fits.
ROM versus PLA (2014–15)
A ROM decodes all 2n minterms (fixed AND plane, programmable OR plane). A PLA has both planes programmable and builds only the product terms needed, so it is much smaller for functions with few terms.
2013–14 · 10 marks (older)

Several 32×4 ROMs with enables are available. Build a 128×4 ROM.

Answer

128 words = 4 × 32. Four 32×4 ROMs share the five low address bits A4..A0. The two high bits A6 A5 go to a 2-to-4 decoder whose outputs are the four enables. Only the enabled ROM answers; the 4-bit outputs are ORed (or are three-state and wired together).

2024–25 Q7(a) · 8 marks

If you use two-dimensional decoding for addressing a 1K-word memory, can you optimise the cost? Justify.

Answer

Yes. 1K words = 1024 = 210, so 10 address bits.

one-dimensionaltwo-dimensional
decodersone 10-to-1024 decodertwo 5-to-32 decoders (row and column)
AND gates in the decoders1024, each with 10 inputs (10,240 input pins)32 + 32 = 64, each with 5 inputs (320 input pins)
word selectdecoder output goes straight to the wordeach word cell has one 2-input AND (row line AND column line): 1024 × 2 = 2048 pins
total input pins (approx.)about 10,240about 2,370

The five high bits select one of 32 row lines, the five low bits select one of 32 column lines, and a word is chosen where its row and column lines cross (coincident selection). The cost falls to about a quarter, and the saving grows with memory size. Decoder delay is also lower because the gates are smaller. The price is one extra 2-input gate in every cell.

Traps that cost marks
  • Not trying F'. Taking every output true is rarely the minimum; the marks are for minimum terms.
  • Counting a shared term twice. A term used by two outputs is one row.
  • Forgetting the T / C label in the output head, or reading a C column as the function itself.
  • Using don't-cares only for the 1s: in the Excess-3 lock the unused codes may help either polarity.
  • PLA table input columns: 0 means complemented literal, – means the variable is absent. Do not write 0 for "absent".
  • Calling a PLA a ROM: a ROM has a full decoder; a PLA has a programmable AND plane.
