1. Half adder, full adder, full subtractor

A half adder adds two bits. A full adder adds three bits (x, y and a carry-in z). A full subtractor computes x − y − b, where b is the borrow from the previous stage.

circuitoutputs
Half adderS = x ⊕ y    C = xy
Full adderS = x ⊕ y ⊕ z = Σ(1,2,4,7)    C = xy + xz + yz = xy + z(x ⊕ y) = Σ(3,5,6,7)
Half subtractorD = x ⊕ y    B = x'y
Full subtractorD = x ⊕ y ⊕ b = Σ(1,2,4,7)    Bout = x'y + x'b + yb = Σ(1,2,3,7)

The full adder from two half adders (ma'am's way): HA1 adds x and y. HA2 adds HA1's sum and z. The two carries are ORed.

2. The 4-bit ripple-carry adder

Chain four full adders. The carry out of each one goes into the next. C0 is the input carry (0 for a plain addition), C4 is the final carry.

Each full adder has to wait for the carry of the one before it. The worst case is C0 changing and rippling all the way to S3 and C4. This waiting is why the adder is slow and why carry look-ahead (section 6) exists.

3. Subtractor and adder-subtractor (2's complement)

Subtraction reuses the adder because A − B = A + B' + 1. B' is the 1's complement (flip every bit). The +1 makes it the 2's complement of B, which is −B.

2024–25 Q1(a) · 15 marks · compulsory · older: 2013–14 "adder, then modify it into a subtractor", 15 marks

Design a 4-bit binary subtractor using full adders. (i) Construct it and draw the logic diagram. (ii) Explain how subtraction is performed using 2's complement.

Answer

(i) Circuit. Four full adders. Each Bi goes through a NOT gate. The input carry C0 is tied to 1. The outputs D3..D0 are the difference, and C4 tells you the sign.

(ii) Explanation.

  1. The 2's complement of B is B' + 1, and −B is represented by it. So A − B = A + (−B) = A + B' + 1.
  2. The NOT gates give B'. The carry-in 1 supplies the +1.
  3. End carry C4 = 1: A ≥ B, the result is positive and the 4-bit answer is correct (discard the carry). Example 7 − 3: 0111 + 1100 + 1 = 1 0100. C4 = 1, D = 0100 = 4.
  4. End carry C4 = 0: A < B, the answer is negative and the 4 bits are the 2's complement of the magnitude. Example 3 − 7: 0011 + 1000 + 1 = 0 1100. C4 = 0, so the result is −(2's complement of 1100) = −0100 = −4.

Adder-subtractor with a control M (ma'am's "controlled adder/subtractor"): put an XOR gate on every B input. M = 0: B ⊕ 0 = B and C0 = 0, so A + B. M = 1: B ⊕ 1 = B' and C0 = 1, so A + B' + 1 = A − B. One circuit does both. Try it:

4. Overflow detection

2024–25 Q3(c) · 11 marks · older: 2013–14 and 2024–25 "how do you check overflow, signed and unsigned", 5 marks

What is overflow in binary arithmetic? Explain how overflow is detected in signed addition and subtraction, with examples.

Answer

Definition. Overflow means the true result does not fit in the n bits available, so the stored answer is wrong.

Unsigned: overflow when the end carry Cn = 1 (for subtraction A − B, Cn = 0 means a borrow, the answer is negative).

Signed (2's complement): the end carry means nothing. Overflow can happen only when the two operands have the same sign and the result has the opposite sign. Two operands of different signs can never overflow.

5. BCD adder and BCD adder-subtractor

A BCD digit is 0–9 (4 bits). Adding two digits plus a carry gives at most 9 + 9 + 1 = 19. The binary adder gives a binary sum, which is only right when it is ≤ 9.

  1. Add the two digits with a 4-bit binary adder: you get S3S2S1S0 and a carry C4.
  2. If the binary result is 10 to 19, add 0110 (6) to correct it. Adding 6 skips the six unused codes 1010–1111.
  3. The correction condition is K = C4 + S3S2 + S3S1. The sums 10–15 are 1010, 1011, 1100, 1101, 1110, 1111, and all have S3 = 1 with S2 = 1 or S1 = 1. Sums 16–19 have C4 = 1.
  4. A second 4-bit adder adds 0 K K 0 (that is 0110 when K = 1, 0000 when K = 0). K is also the decimal carry out.

Method (assumption stated: ma'am did not teach BCD subtraction, so use the standard 9's complement method of Mano). A − B = A + (9's complement of B) + 1, done by the BCD adder above.

  1. A block "B or 9's complement of B" in front of the adder, controlled by S. For S = 0 it passes B. For S = 1 it gives 9 − B. For a valid BCD digit the 9's complement is: n3 = B3'B2'B1', n2 = B2 ⊕ B1, n1 = B1, n0 = B0' (checked for all ten digits).
  2. S is also the carry-in of the first adder (the +1).
  3. Then the BCD adder: correction K = C4 + S3S2 + S3S1, second adder adds 0KK0.
  4. Output carry K. For S = 1, K = 1 means the answer is positive (discard the carry). K = 0 means negative: the digit is the 9's complement of the magnitude; take its 10's complement and attach a minus sign.

6. Carry look-ahead adder (CLA)

Idea. In a ripple adder, Ci+1 depends on Ci, so the carries come one after another. In a CLA every carry is written directly in terms of the inputs (A, B and C0), so all carries are produced at the same time by two levels of AND-OR gates.

  1. For each bit define propagate Pi = Ai ⊕ Bi (the carry passes through) and generate Gi = AiBi (this stage makes a carry by itself). These are the first half adder of the FA.
  2. Sum: Si = Pi ⊕ Ci. Carry: Ci+1 = Gi + PiCi.
  3. Substitute again and again until only C0 is left (C0 is the input carry; ma'am's note has it as 0 for plain addition):

C1 = G0 + P0C0
C2 = G1 + P1G0 + P1P0C0
C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0
C4 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0

Look at the pattern: Ck has one term for each earlier G, each ANDed with all the P above it, plus the last term with C0.

Delay, one gate = one unit, XOR counted as one gate:

Ripple delay grows by 2 for every extra bit. CLA stays about 4 levels, at the cost of wide AND/OR gates (more hardware, more fan-in), which is why practical CLA blocks stop at 4 bits.

What to write (CLA, 12–15 marks)

  4. The block diagram: PG generators, look-ahead carry box, sum XORs.
  5. The delay comparison, if asked.

7. Binary multipliers

2021–22 Q4(c) · 15 marks · older: 2012–13 (20), 2013–14 1-bit (5)

Discuss and design a 2-bit by 2-bit binary multiplier.

Answer

Multiply B1B0 by A1A0 like decimal long multiplication. Each partial product bit is an AND.

            A1    A0
      x     B1    B0
      ----------------
          A1B0  A0B0
    A1B1  A0B1
    ----------------------
 P3   P2    P1    P0
  1. P0 = A0B0.
  2. P1 and the carry c1: add A1B0 and A0B1 with a half adder HA1. P1 = A1B0 ⊕ A0B1, c1 = A1B0·A0B1.
  3. P2 and P3: add A1B1 and c1 with a second half adder HA2. P2 = A1B1 ⊕ c1, P3 = A1B1·c1.

Hardware: 4 AND gates and 2 half adders. (Ma'am's own note says 3 half adders; the slide and the book use 2. Both work, 2 is enough.)

2018–19 Q2(c) · 10 marks · older 2016–17 (15)

Design a circuit with 4-bit binary adders which returns A × B, where A and B are 3-bit binary numbers.

Answer

The product is 6 bits (7 × 7 = 49 < 64). Form the partial-product rows with 9 AND gates, then add them with two 4-bit adders (the same idea as Mano's 4×3 multiplier).

  1. Row 0 = A·B0 = a2b0 a1b0 a0b0. Row 1 = A·B1 = a2b1 a1b1 a0b1 (weight ×2). Row 2 = A·B2 = a2b2 a1b2 a0b2 (weight ×4).
  2. P0 = a0b0 directly.
  3. Adder 1 adds (0, 0, a2b0, a1b0) and (0, a2b1, a1b1, a0b1). Its lowest sum bit is P1. Its upper bits and carry, C4 S3 S2 S1, go on.
  4. Adder 2 adds (C4, S3, S2, S1) and (0, a2b2, a1b2, a0b2). Its four sum bits are P2, P3, P4, P5. Its carry out is always 0 and is not used.

Hardware: 9 AND gates and two 4-bit adders (checked for all 64 input pairs).

8. Incrementer and decrementer

2021–22 Q4(a) · 10 marks · older 2011–12 · homework in ma'am's notes

Design a 4-bit incrementer circuit using only half adders. The incrementer adds 1 to a binary number.

Answer

Adding 1 means A + 0001. The carry-in of the LSB is 1 and every other bit adds 0, so a half adder per bit is enough (the second input of each HA is the carry from the HA before it). HA0 adds x0 and the constant 1.

y0 = x0', y1 = x1 ⊕ x0, y2 = x2 ⊕ x1x0, y3 = x3 ⊕ x2x1x0. The final carry is 1 only for 1111 + 1. (Decrementer, ma'am's note: x − 1 = x + 1111, which needs one half adder for the LSB (adding 1) and three full adders for the rest.)

9. 1's and 2's complement circuits from half adders

A half adder's sum output is an XOR, so HA(a, C).sum = a ⊕ C. With C = 0 it passes a; with C = 1 it flips a. That is a "controlled complementer", the XOR used in the adder-subtractor.

2023–24 Q4(a) · 6 marks · CT2 2026 Q2(a)+(b) · 4+4 marks

(2023–24) Using only half adders, design a circuit that outputs the 1's complement of a 4-bit input when control C = 1 and passes the input unchanged when C = 0. (CT2) The same for a 2-bit input with two half adders; then change it to give the 2's complement when C = 1 using up to four half adders and no other gates.

Answer

1's complement, 4 bits: four HAs. HAi takes (ai, C). The sum output is yi = ai ⊕ C. The carry outputs are not used.

2's complement, 2 bits (CT2 Q2b): 2's complement = 1's complement + 1 = (a ⊕ C) + C. Let xi = ai ⊕ C.

  1. HA1: (a0, C) gives x0.
  2. HA2: (x0, C) gives y0 = x0 ⊕ C = a0 (bit 0 of a 2's complement is always a0), and the carry c = x0·C.
  3. HA3: (a1, C) gives x1.
  4. HA4: (x1, c) gives y1 = x1 ⊕ c. Its carry is not used.

Check, C = 1: a = 01 gives y = 11 (−1 = 11). a = 10 gives y = 10. a = 00 gives y = 00. a = 11 gives y = 01. With C = 0 the output equals the input. For 4 bits the same method needs 8 half adders: four to form xi and four to add the carry C (checked for all 16 inputs).

10. Four-bit adder with controlled inputs (the 2018–19 trick)

2018–19 Q2(b) · 13 marks · also filed twice in the QBank

Using a 4-bit binary adder and XOR gates, design a circuit that takes 4-bit A and a 2-bit control, and returns A + 1 when the control is 00, A' when 01, A' + 1 when 10, and A when 11.

Answer

Assumption: the question mentions a second BCD input B, but no result uses it, so B is not needed (tie the adder's second input to 0000). The control bits are S1 S0.

Idea: feed the adder X = A or A' (XOR with a control k), Y = 0000, and carry-in c.

S1 S0wantedXk (XOR with A)carry-in c
00A + 1A01
01A'A'10

From the table: k = S1 ⊕ S0 (0, 1, 1, 0) and c = S0' (1, 0, 1, 0). Gates: one XOR for k, four XORs on A, one NOT for c.

Check with A = 0101: 00 gives 0110, 01 gives 1010, 10 gives 1011, 11 gives 0101. All four hold for every A from 0000 to 1111.

Traps that cost marks
  • Forgetting the carry-in 1 in the subtractor. Without it you get A + B' = A − B − 1.
  • Reading C4 wrongly: in subtraction C4 = 1 means no borrow (positive result).
  • BCD adder: the correction adds 0110 only when K = 1. Do not forget that C4 = 1 also triggers it (sums 16–19).
  • CLA: leaving C3 and C4 unexpanded, or dropping the P·P·…·C0 term.
  • Signed overflow: using the end carry alone. It is C3 ⊕ C4.
  • Half-adder complementers: the sum output is the XOR, not the carry output.
  • 2×2 multiplier: P3 is the carry of HA2, not an AND of the inputs.
