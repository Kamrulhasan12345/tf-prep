Multiplexers: implementing any function

A MUX question appeared in all 8 recent papers: 2024–25 Q5a+b (23 marks, 8×1 with two enables, then 32×1), 2023–24 Q1d (12, full adder from two 4×1), 2022–23 Q1c (13, 4×1 + gates), 2021–22 Q3b (12, read a given MUX), 2020–21 Q3a+b (30, enables and a story), 2019–20 Q8b (17, 4×1 + gates), 2018–19 Q4b+c (27, enables; full subtractor), 2017–18 Q4b+c (27, 8×1 from a POS; full adder). It is the most reliable 12–25 marks in Section A.

1. What a MUX is

A 2n×1 multiplexer has 2n data inputs I0…, n select lines and one output. The select lines, read as a binary number, choose which input is copied to the output. Sn−1 is the most significant select bit.

4×1: Y = S₁'S₀'·I₀ + S₁'S₀·I₁ + S₁S₀'·I₂ + S₁S₀·I₃

Each AND term is one minterm of the select lines, gated with one data input. So a MUX is "a decoder of the select lines, ANDed with the data, then ORed". That is why it can build any function: put variables on the selects, and the data inputs choose which minterms are 1.

Enable
An extra control input. Active-high enable EN: the MUX works when EN = 1. Active-low EN' (drawn with a bubble): works when EN' = 0. Disabled → output 0 (state this assumption in the exam). With two enables, both must be in their active level.
Quad 2×1 MUX
Four 2×1 MUXes sharing one select: chooses a whole 4-bit word A or B.

What to write (method A, about 12–15 marks)

  1. The truth table, or the implementation table: two rows (D', D) by eight columns (I₀..I₇), minterms written in, the 1-minterms circled.
  2. For each column, its input: 0, 1, D or D'.
  3. A labelled 8×1 MUX block: I₀…I₇ with their values, S₂ = A, S₁ = B, S₀ = C, an inverter for D', the enable tied active (EN' = 0), output F.
  4. One line: "S₂ is the MSB; the MUX is enabled permanently".

3. Method B: 4 variables on a 4×1 MUX (with external gates)

With only two select lines, each data input must be a function of the two remaining variables, built with gates. Split the truth table into four slices by the select variables, and simplify each slice on its own (a 2-variable K-map, or by eye).

2022–23 Q1(c) · 13 marks

Implement F(A, B, C, D) = Σ(1, 2, 4, 7, 8, 9, 10, 11, 13, 15) with a 4×1 multiplexer and external gates.

Answer

I₀ = C ⊕ D (XOR gate), I₁ = C ⊙ D (XNOR gate), I₂ = 1, I₃ = D, with S₁ = A and S₀ = B. Two external gates. This is also ma'am's Lec 16 example #3.

2019–20 Q8(b) · 17 marks

Implement F(A, B, C, D) = Σ(1, 2, 4, 10, 12, 13, 14, 15) with a 4×1 multiplexer and external gates. Connect A and B to the selection lines.

Answer

I₀ = C ⊕ D, I₁ = C'D' (one NOR gate), I₂ = CD' (AND with an inverter), I₃ = 1.

2018–19 Q4(b) · 15 marks

Using a 4×1 MUX design f(w,x,y,z) = Π(0,2,5,6,7,8,9,10). The MUX has selects S₁S₀, inputs I₀..I₃, EN₁' active low and EN₂ active high.

Answer

First turn the product of maxterms into minterms: f = Σ(1,3,4,11,12,13,14,15) (all numbers not in the Π list). With w, x on the selects:

I₀ = z, I₁ = y'z' (one NOR gate: y'z' = (y+z)'), I₂ = yz (one AND), I₃ = 1. Enables: EN₁' = 0 (ground), EN₂ = 1 (VCC). Two extra gates. (Picking x, y instead gives w'z ; z ; z'+w ; w, which needs more gates.)

4. Using the enables

Enables let one select-line decoder be shared: a disabled MUX outputs 0, so you can OR the outputs of several MUXes and only the enabled one counts. This is how you build a big MUX from small ones.

2024–25 Q5(a)+(b) · 13 + 10 marks · compulsory question

(a) A 4×4 smart grid is activated by g(a,b,c,d) = Σ(1,2,5,7,12,14). Design it with a switching circuit that has 3 selector bits S₂S₁S₀ selecting one of eight inputs, an active-low enable EN₀' and an active-high enable EN₁. Minimum extra gates. (b) Using that circuit, design a 32×1 multiplexer with selectors A,B,C,D,E (A = MSB), minimum extra gates.

Answer

(a) The "switching circuit" is an 8×1 MUX. Method A with S₂S₁S₀ = abc and d on the data lines:

I₀..I₇ = d, d', d, d, 0, 0, d', d'. One NOT gate. EN₀' = 0, EN₁ = 1.

(b) 32 inputs need four 8×1 MUXes. C, D, E go to S₂S₁S₀ of all four. A and B choose which MUX is enabled, using the two enables as a built-in 2-to-4 decoder:

MUXinputsenabled whenEN₀' (needs 0)EN₁ (needs 1)
M0I₀–I₇A=0, B=0AB'
M1I₈–I₁₅A=0, B=1AB
M2I₁₆–I₂₃A=1, B=0BA
M3I₂₄–I₃₁A=1, B=1B'A

Exactly one MUX is enabled for each AB; the others output 0. Output Y = M0 + M1 + M2 + M3 (one 4-input OR). Extra gates: one NOT (B') and one OR. (If the MUX outputs were three-state, the four outputs could be wired together and the OR dropped; say which you assume.)

The same idea, from ma'am's notes: an 8×1 from two 4×1 and a 2×1 (S₁S₀ to both 4×1, S₂ selects in the 2×1), and a 16×1 from two 8×1 and a 2×1 (S₂S₁S₀ shared, S₃ on the 2×1).

5. Arithmetic with two MUXes

2023–24 Q1(d) 12 marks · 2017–18 Q4(c) 12 marks · 2018–19 Q4(c) 12 marks

Design a full adder using NOT gates and two 4×1 multiplexers. (2018–19: a full subtractor the same way.)

Answer

Truth tables: S = Σ(1,2,4,7), C = Σ(3,5,6,7) for x, y, z (z = carry in). With x, y on the selects of both MUXes:

MUX 1 (Sum): I₀..I₃ = z, z', z', z. MUX 2 (Carry): 0, z, z, 1. One NOT gate for z'.

Full subtractor (x − y − bin): D is the same as S (z, z', z', z). Borrow B = x'y + x'b + yb = Σ(1,2,3,7): inputs z, 1, 0, z.

6. Reading a MUX circuit

2021–22 Q3(b) · 12 marks

A 4×1 MUX has I₀ = Z', I₁ = Z, I₂ = 0, I₃ = 1 and S₁ = X, S₀ = Y. Give F(X,Y,Z) as a product of maxterms.

Answer

F = X'Y'·Z' + X'Y·Z + XY'·0 + XY·1 = X'Y'Z' + X'YZ + XY = Σ(0, 3, 6, 7). The product of maxterms lists the others: F = Π(1, 2, 4, 5).

7. DEMUX and three-state gates

A demultiplexer sends one data line to one of 2n outputs chosen by the selects. A decoder with an enable is a DEMUX: put the data on the enable and the selects on the decoder inputs. The selected output follows the data, all others stay 0 (2017–18 and 2018–19 asked "show that a decoder can be used as a demultiplexer", 5–8 marks: draw the 2-to-4 decoder with E as the data input and its truth table with E in it).

A three-state buffer has a control C: C = 1 → output = input; C = 0 → output is disconnected (high impedance, Hi-Z). Because disconnected outputs do not fight, several three-state outputs can share one wire: a 2×1 MUX is two buffers with controls S and S'. A 4×1 MUX is four buffers whose controls come from a 2-to-4 decoder. Advantage (2024–25 Q6a, 6 marks): many sources on one bus without an OR gate, and the bus can be disconnected entirely.

Traps that cost marks
  • S₁ is the MSB. If the question defines a reversed order (2020–21 Q3a: "C₁C₀ = 11 selects Q₀"), follow the question and say so.
  • A Π list gives the 0s. Convert to Σ before filling the table.
  • Do not forget the enables: draw them and tie them to their active level.
  • Label every data input on the block. The marks are in the labels.
