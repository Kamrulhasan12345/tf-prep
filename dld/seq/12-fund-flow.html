Fundamental-mode circuits: primitive and reduced flow tables

Fundamental mode was asked in every one of the 8 papers, always as the biggest Section B question: 2024–25 none (pulse mode instead), 2023–24 Q8a (23 marks, inputs a b c, output U), 2022–23 Q8b (12, excitation function → flow table) and Q8a (race, see next chapter), 2021–22 Q8a (20, railroad crossing: primitive + reduced), 2020–21 Q8a (25, x₁/x₂ detector: whole design to the circuit), 2019–20 Q4b (25, electrical lock: whole design), 2018–19 Q8a (20, z = 1 on x₂ rising with x₁ = 0 …), 2017–18 Q8a (20, two outputs, sequences 00-01-11 and 00-10-11). The bank has 14 fundamental-mode items (gated latch, edge-triggered T, "what is fundamental mode", output of unstable states, excitation functions). Adnan sir's hints: "35 mark #1 question" and "TF #3: 25 → fundamental, 10 → state assignment, will definitely come". This chapter is the 25; the next chapter is the 10.

The whole method on one screen
  1. Rules of the game: level inputs, only one input changes at a time (so 00 → 11 is never allowed; columns are written in Gray order 00 01 11 10), and the circuit settles before the next change.
  2. Primitive flow table: one row per situation, exactly one stable (circled) entry per row. From a stable cell, change one input: if a row with the right output is already stable in that column, point to it; else start a new row. The two double-change cells are "–". Output of an unstable cell: "–" unless quick/slow is stated.
  3. Reduce it (even if the question does not say so): implication table → compatible pairs → maximal compatibles and incompatibles → bounds l ≤ k ≤ u → smallest closed cover → merge rows (stable entries keep their circle).
  4. Race-free assignment (next chapter): transition diagram, add spare rows for triangles. Then the transition table, K-maps for Y and Z (D latches: Y = next state), circuit.
  5. Check by walking the table: change one input = move sideways; if the entry is not circled, move down to that row, repeat until circled.

1. Words you must be able to define

Fundamental mode (4 marks, 2015–16)
An asynchronous circuit with level inputs, no clock, in which only one input changes at a time and the next change comes only after the circuit has reached a stable state.
Total state
The pair (input combination, internal state): a cell of the flow table.
Stable / unstable
A total state is stable if the next-state entry equals its own row (circled). Otherwise it is unstable: the secondary variables change and the circuit moves vertically to the row named, in the same column, until it reaches a circled entry.
Primitive flow table
One stable state per row; written straight from the words. "Analogous to a state table" (Adnan sir).
Output of an unstable cell (7 marks, 2011–12). Adnan sir's rule: turns ON quickly → 1; turns ON slowly → 0; turns OFF quickly → 0; turns OFF slowly → 1. If the question says nothing about quick or slow, write "–" (don't care) in every unstable cell where the output changes; where the output is the same before and after, write that value. Stable cells always carry the output of the state.

2. Reading a flow table: try it

This is the reduced table of 2018–19 Q8a (derived in section 5). Click an input value (change only one bit at a time) and watch the circuit go sideways to the new column, then down while the entry is not circled.

3. Building the primitive flow table from words

Primitive flow table (DFS with backtracking)

  1. Write the columns 00 01 11 10. Row 1 = the starting input, stable, with the starting output. Circle it.
  2. From a stable cell, change one input (move to a neighbouring column; never diagonal). Decide the output the new stable situation needs, and what the circuit must remember.
  3. If a row is already stable in that column with that output and the same future, write its number in this cell. Otherwise make a new row, circle its number in the new column, and write the new row's number in the cell you came from.
  4. Fill the unstable cell's output by the rule above.
  5. Explore every neighbour of every row (that is the DFS); when a row has been explored in all legal directions, go back. Cells for double changes (00 ↔ 11, 01 ↔ 10) stay "–". Cells the story forbids stay "–".
  6. Check: every row has one circled entry; every column has a stable entry for each output the question produces.

The question is about histories: the same input pair with different outputs, or with different futures, needs different rows. That is why every question says "the first change that follows", "after the sequence", "in this order".

4. Reducing: merge compatible rows

Reduction of a flow table

  1. Implication table (the same as for incompletely specified machines): for each pair of rows, cross it out if some column has two different specified outputs. Otherwise list the pairs of next states that must also be compatible (two different next states in one column). A pair is crossed out if an implied pair is crossed out. A stable entry (own row) counts as a next state, like any other.
  2. Pairs left = compatible pairs. Draw the merger graph; its maximal cliques are the maximal compatibles. The crossed pairs give the maximal incompatibles.
  3. Bounds: lower l = size of the largest incompatible set; upper u = number of maximal compatibles (and at most the number of rows). So l ≤ k ≤ u.
  4. Closed cover of the smallest size: every row in some chosen set (covering), and the next states of every set lie inside one chosen set (closed). Try size l first. Then the answer is "minimum".
  5. Reduced table: one row per chosen set. In each column take the next states of its members; the entry is the chosen set that contains them. Stable entries stay circled; outputs are the specified ones of the members.
Differs from the textbook / from state minimisation (Section 10): the machine is incompletely specified because of the "–" cells, so the same compatibles/closed-cover procedure applies. Prefer a cover whose sets do not overlap, and, if the next chapter's assignment fails, try another cover of the same size (below, the 2021–22 table has two).

5. 2018–19 Q8a, in full (20 marks)

2018–19 Q8(a) · 10 + 10 marks

Construct a primitive flow table for a fundamental mode circuit whose output Z is 0 when the two inputs x₁ and x₂ are equal. Z = 1 results when x₁ = 0 and x₂ changes from 0 to 1, and when x₁ = 1 and x₂ changes from 1 to 0. No other input change causes an output change. Determine the reduced flow table with the minimum number of rows.

Answer

Think in histories. At 01 the output depends on how we got there: from 00 (x₂ rose with x₁ = 0) Z = 1; from 11 (x₁ fell) Z stays 0. Likewise at 10: from 11 (x₂ fell with x₁ = 1) Z = 1; from 00 Z = 0. Rows:

  1. row 1 = 00, Z = 0 (start) · row 2 = 01, Z = 1 (came from 00) · row 3 = 11, Z = 0 · row 4 = 01, Z = 0 (came from 11) · row 5 = 10, Z = 1 (came from 11) · row 6 = 10, Z = 0 (came from 00).

Primitive flow table (stable entries circled, "–" = not allowed or output unspecified):

Implication table. Step through it:

Compatible pairs: 1-2, 1-6, 2-5, 2-6, 3-4, 3-5, 4-5, 4-6. Maximal compatibles {1,2,6} {3,4,5} {2,5} {4,6}; maximal incompatibles {1,3} {1,4} {1,5} {2,3} {2,4} {3,6} {5,6}; l = 2, u = 4. The only closed cover of size 2 is {1,2,6} {3,4,5}: a = {1,2,6}, b = {3,4,5}.

Reduced flow table:

Two rows: one state variable. Stable cells: a at 00, 01, 10; b at 01, 11, 10. A single secondary variable means no race is possible.

What to write (primitive + reduced flow table, 10 + 10 marks)

  1. One line on the assumptions: "fundamental mode: one input changes at a time, so 00–11 and 01–10 are never adjacent".
  2. The meaning of every row in a short list ("row 2 = 01, Z = 1, came from 00").
  3. The primitive flow table: circled stable entries, one per row, "–" where not allowed, outputs next to every entry.
  4. The implication table with the crossed pairs and the implied pairs written in the cells; the list of compatible pairs; maximal compatibles and incompatibles; l ≤ k ≤ u.
  5. The chosen closed cover and the reduced table with its names (a = (1,2,6) …).
  6. Only if asked: assignment, K-maps, circuit (section 7).

6. 2017–18 Q8a: two outputs (20 marks)

2017–18 Q8(a) · 10 + 10 marks

Fundamental mode circuit, inputs x₁x₂, outputs z₁z₂. At 00 the output is 00. Output 10 is produced after the input sequence 00-01-11 and stays 10 until the input returns to 00 (then 00). Output 01 is produced after 00-10-11 and stays until 00. Primitive flow table; minimum-row reduced flow table.

Answer

Rows: 1 = 00 (00); 2 = 01 after 00 (00); 3 = 11 after 00-01 (10); 4 = 01 after 3 (10, still 10 until 00); 5 = 10 after 3 (10); 6 = 10 after 00 (00); 7 = 11 after 00-10 (01); 8 = 01 after 7 (01); 9 = 10 after 7 (01). Going back to 00 from any of 3–9 sends to row 1; the output drops to 00 in an unstable cell, so it is "–" there (not stated whether quickly or slowly).

Maximal compatibles {3,4,5} {7,8,9} {1,2} {1,6} {2,5} {6,8}; maximal incompatibles: 17 of them, the largest of size 4; l = 4, u = 6. 7 closed covers of size 4 exist; a tidy one is {3,4,5} {7,8,9} {1,2} {6}. Minimum = 4 rows.

Read it: a = {1,2} idle, b = {3,4,5} output 10, c = {6} "x₁ first" (00), d = {7,8,9} output 01. The next chapter shows this 4-row table has triangles (no 2-variable race-free assignment without extra rows).

7. 2019–20 Q4b: electrical lock, the whole design (25 marks)

2019–20 Q4(b) · 25 marks

Fundamental mode electrical lock with switch inputs X₁, X₂. The open signal Z = 1 only after: (i) start with X₁ = X₂ = 0; (ii) while X₂ = 0, X₁ is turned on and then off; (iii) then, while X₁ stays off, X₂ is turned on, which opens the lock (Z = 1); (iv) any deviation leaves the lock closed (Z = 0). Give the primitive flow table, reduced flow table, race-free state assignment, K-maps and circuit diagram.

Answer

Sequence of inputs: 00 → 10 → 00 → 01. Anything else is a "deviation" that keeps Z = 0 until the inputs return to 00, where the lock starts again. Assumption: after opening, X₂ turned off (back to 00) closes the lock and restarts; X₁ turned on while open (11) is a deviation.

Rows: 1 = 00 fresh · 2 = 01 deviation · 3 = 11 deviation · 4 = 10 deviation · 5 = 10 (X₁ on, correct so far) · 6 = 00 (X₁ on then off, correct so far) · 7 = 01 open, Z = 1.

Compatibles: maximal {2,3,4} {1,2} {4,7} {5,6}; l = 4, u = 4, so k = 4: a = {1} fresh, b = {2,3,4} dead (deviated), c = {5,6} correct so far, d = {7} open.

Race-free assignment. Every pair of the four rows must be adjacent (a–b, a–c, a–d, b–c, b–d, c–d): a complete graph K₄, impossible with 2 variables. Use Adnan sir's recipe (next chapter, same as his TF #3): 3 variables, a = 000 in the middle, spare rows b′ (b–c), c′ (c–d), d′ (b–d). Then every unstable move changes one bit:

Z = y₃: only the open row d = 100 has Z = 1 (the spare row d′ = 101 is a via-row; its output was "–").

Verified by simulation in the build: random single-input-change walks of the specification and of these equations agree on the output after every change, and every unstable move changes one state bit.

What to write (full design, 25 marks)

  1. Assumptions and the input sequence the lock needs (00 → 10 → 00 → 01).
  2. Primitive flow table (7 rows) with row meanings.
  3. Implication table, compatible pairs, maximal compatibles/incompatibles, bounds, the cover, the reduced table.
  4. Transition diagram, the extra rows, the assignment (codes) and the race-free flow table.
  5. Transition table with the output column, K-maps for Y₃ Y₂ Y₁ and Z (variables x₁ x₂ y₃ y₂ y₁, unused codes = don't care).
  6. Equations and the circuit: AND-OR for each Y, feedback of y₃ y₂ y₁ (latch or delay element), Z gate.

8. 2020–21 Q8a: x₁ after x₂ (25 marks, whole design)

2020–21 Q8(a) · 25 marks

Two inputs x₁, x₂, one output z. z changes 0 → 1 only on the first x₁ change that follows an x₂ change. A 1 → 0 change occurs only when x₁ changes 1 → 0 while x₂ = 1. Primitive flow table, reduced flow table, race-free state assignment, K-maps and circuit.

Answer

What must be remembered. Whether the last input change was an x₂ change ("armed"), and whether z is already 1. Three situations in each column: U (z = 0, last change was x₁ or nothing yet), A (z = 0, armed: the last change was x₂), O (z = 1). An x₂ change always arms; an x₁ change from A makes z = 1; from U it keeps z = 0. In O, nothing changes z except x₁ falling while x₂ = 1 (11 → 01), which gives z = 0 and "unarmed" (the last change was x₁). Assumed start: 00, z = 0, unarmed.

Primitive flow table (rows are numbered in the order the search finds them: 1 = 00 U, 2 = 01 A, 3 = 00 A, 4 = 10 O, 5 = 00 O, 6 = 01 O, 7 = 11 O, 8 = 01 U, 9 = 11 U, 10 = 10 A, 11 = 11 A, 12 = 10 U):

12 rows. Maximal compatibles {4,5,6} {1,12} {2,3} {4,7} {8,9} {10,11}; l = u = 6. So the minimum is 6 rows, and 3 closed covers of size 6 exist. Use {5,6} {1,12} {2,3} {4,7} {8,9} {10,11} (this one needs only one spare row; for the other two covers no 3-variable assignment with up to three spare rows exists).

Six rows need 3 state variables, but the six rows do not fit on a 3-cube with every unstable move one step long. One extra via-row b′ (between b and c) fixes it, 7 rows, 3 variables:

Checked in the build: random single-input-change walks of the specification and of these equations give the same z after every change, and every unstable move changes one state bit.

9. 2021–22 Q8a: railroad crossing (20 marks)

2021–22 Q8(a) · 10 + 10 marks

At a junction of a single-track railroad and a road, lights are controlled by switches pressed or released by trains. When a train approaches from either direction and is within 1500 ft, the lights change from green to red and stay red until the train is 1500 ft past the junction. A train is shorter than 3000 ft. Primitive flow table and its reduction.

Answer

Model (state it). Switch x₁ is 1500 ft west, x₂ is 1500 ft east, 1 = pressed by a train. Output z = 1 means red. Because a train is shorter than 3000 ft (the switches are 3000 ft apart), its tail leaves the first switch before its nose reaches the second, so x₁ and x₂ are never pressed together: column 11 is unspecified. West-to-east train: 00 → 10 → 00 → 01 → 00, red from the first press until the last release. East-to-west: 00 → 01 → 00 → 10 → 00.

Rows: 1 = 00 green · 2 = 01 first switch (from east), red · 3 = 00 between (from east), red · 4 = 10 second switch (to west), red · 5 = 10 first switch (from west), red · 6 = 00 between, red · 7 = 01 second switch (to east), red.

Maximal compatibles {2,3} {2,5} {3,6} {4,7} {5,6} {1}; l = 4, u = 6. 2 covers of size 4. The one used here, {2,5} {3,6} {4,7} {1}, treats the two directions as the same rows (a = idle, b = first switch pressed, c = between switches, d = second switch pressed); it also allows a 2-variable race-free assignment (next chapter).

10. 2023–24 Q8a: inputs a, b, c, output U (23 marks)

2023–24 Q8(a) · 23 marks

Asynchronous fundamental-mode circuit with inputs a, b, c and output U. U = 1 only if all three inputs are 1 and they went to 1 in the order a, b, c. U returns to 0 when all inputs return to 0. Give the primitive flow table, the reduced flow table, the minimum number of states for a race-free assignment and a possible assignment.

Answer

Assumptions. Three inputs: 8 columns in Gray order 000 001 011 010 110 111 101 100 (only single-bit moves are neighbours). U is set when 111 is reached in the order a, b, c and held until abc = 000. If you read it as "U = 1 only at 111", change the output of the held rows; the table structure does not change.

Situations: alive (the 1s so far came in the order a, then b: columns 000, 100, 110), dead (any wrong order: stays dead until 000), open (U = 1, held). Primitive table (17 rows: 1 = 000 alive; 2–8 dead at 001 011 010 110 111 101 100; 9 = 100 alive; 10 = 110 alive; 11–17 open at 111 011 001 101 100 110 010):

The alive rows 1, 9, 10 are compatible, because the column itself says how far the sequence has got; all dead rows are compatible; all open rows are compatible. l = 3. Minimum 3 rows:

Race-free assignment: the unstable moves are a → b, a → c, b → a, c → a. The transition diagram is the path b – a – c, so 3 states, 2 variables: a = 00, b = 01, c = 10 (a is adjacent to both). No extra rows.

11. Older items from the bank

Bank #250 · 2011–12 · 6 + 6 marks

Gated latch with inputs G and D, output Q: Q follows D while G = 1; when G goes to 0 the value of D at that time is held. Fundamental mode. Derive the primitive flow table and the reduced flow table.

Answer

Columns G D = 00 01 11 10. With G = 1 the output equals D (stable states 11 with Q = 1 and 10 with Q = 0); with G = 0 it holds, so 00 and 01 each need a row for Q = 0 and for Q = 1. That is 6 rows: 1 = 00,Q0; 2 = 01,Q0; 3 = 11,Q1; 4 = 01,Q1; 5 = 00,Q1; 6 = 10,Q0.

Maximal compatibles {1,2,6} {3,4,5} {3,6}; l = 2. Minimum 2 rows: a = Q0 {1,2,6}, b = Q1 {3,4,5}.

Bank #249 · 2015–16 · 12 marks

Derive the primitive flow table of a negative-edge triggered T flip-flop (inputs T and clock C, output Q).

Answer

Columns T C = 00 01 11 10. Q toggles only when C falls while T = 1 (11 → 10). Rows (Q = 0): 1 = 00, 2 = 01, 3 = 11, 8 = 10; (Q = 1): 4 = 10, 5 = 00, 6 = 01, 7 = 11. Changing T, or C rising, or C falling with T = 0, keeps Q.

Four rows after reduction: {1,2,8} {4,5,6} {3} {7}.

12. The other direction: excitation function → flow table (2022–23 Q8b, 12 marks)

2022–23 Q8(b) · 12 marks (bank #251, #253)

An asynchronous circuit has the excitation function y = x₁x₂' + (x₁ + x₂')y and output z = y. (i) Draw the logic diagram. (ii) Derive the transition table and the output map. (iii) Obtain a two-state flow table.

Answer
  1. Logic diagram: AND of x₁ and x₂', AND of (x₁ + x₂') with y, OR of the two; the output y is fed back and is also z.
  2. Transition table (y is the present state, entries Y; a cell is stable if Y = y). Row y = 0: 00 → 0, 01 → 0, 11 → 0, 10 → 1. Row y = 1: 00 → 1, 01 → 0, 11 → 1, 10 → 1.
  3. Flow table: call y = 0 state a and y = 1 state b. z = y gives the outputs.

Read the table: y = 0 is state a, y = 1 is state b. Row a (y = 0) is stable at 00, 01, 11 and unstable (goes to b) at 10. Row b (y = 1) is stable at 00, 11, 10 and unstable (goes to a) at 01. Output z = y, so z = 0 in row a and z = 1 in row b.

Bank #252 · 2016–17 · 15 marks

Y₁ = x₁x₂ + x₁y₂' + x₂'y₁, Y₂ = x₂ + x₁y₁'y₂ + x₁'y₁, Z = x₂ + y₁. Draw the logic diagram and derive the transition table.

Answer

Evaluate Y₁Y₂/Z for every (x₁x₂, y₁y₂). Rows y₁y₂ = 00, 01, 11, 10; columns x₁x₂ = 00, 01, 11, 10. Circle (stable) the cells where Y₁Y₂ = y₁y₂.

Traps that cost marks

  • A diagonal move in the flow table (00 → 11 or 01 → 10). Those cells are "–".
  • Two circled entries in one row of the primitive table (that is a reduced table, not primitive). One stable state per row.
  • Reusing a row for the same column and output although the future is different (the "from 00" and "from 11" 01-states in 2018–19). Add a row.
  • Skipping the reduction because "the question did not ask": Adnan sir says state minimisation is needed even if not asked.
  • Writing an output in an unstable cell that contradicts the stable cell it ends in. Use "–" when the output changes and the question does not say quick/slow.
  • Merging rows whose outputs differ in some column, or whose implied pairs are crossed out. Check the implication table.
  • Reduced table: forgetting that a merged row's stable entries keep their circles, and that every unstable entry points to the row that contains the member's next states.
