Mealy and Moore, slowly

Asked in 6 of the last 8 papers: 2024–25 Q8a (10 marks: block diagrams + difference with an example), 2023–24 Q8c (6: Mealy → Moore), 2022–23 Q7c (10: differentiate with block diagrams), 2021–22 Q8c (5: Mealy → Moore), 2018–19 Q8c (7: Moore → Mealy), 2017–18 Q6c (5: define both). In the bank, "Mealy vs Moore block diagram and difference" appears in 5 sessions. It is small marks each time, but nearly certain, and every sequential design question (detectors, vending machines, locks) is drawn as one of the two.

The whole chapter on one screen

  1. Mealy: output = f(present state, input). Written on the arrow: x/z.
  2. Moore: output = f(present state only). Written inside the circle: A/0. Arrows carry only the input.
  3. Mealy reacts to the input at once (same clock period). Moore shows the result one clock later, after the state changes. It needs more states, but its output is stable and glitch-free.
  4. Mealy → Moore: look at the outputs on the arrows coming into each state. If they are all the same, keep the state and give it that output. If they differ, split the state into one copy per output (B0, B1). Each copy keeps the old row; each arrow goes to the copy that matches its output.
  5. Moore → Mealy: put on each arrow the output of the state it points to, delete the output column, then merge equivalent states.

1. The two models

Every clocked sequential circuit is a finite state machine: memory (flip-flops) holds the present state, combinational logic computes the next state, and some logic computes the output. The two models differ only in what the output logic is allowed to see.

Mealy model
Moore model

Mealy: S(t+1) = δ(S(t), x(t)), z(t) = λ(S(t), x(t))
Moore: S(t+1) = δ(S(t), x(t)), z(t) = λ(S(t))

That is his notation: δ is the next-state function and λ the output function. The only difference is the x(t) inside λ.

2. Same job, both ways: a 1101 detector

Output 1 when the last four inputs were 1101 (overlapping allowed). In the Mealy machine, states remember how much of 1101 has been matched: A = nothing, B = "1", C = "11", D = "110". The output 1 sits on the arrow D → B for input 1, at the moment the last 1 arrives. Press Play to feed it 1101101.

Converted to Moore, the "just saw 1101" moment has to become a state with output 1. B is entered with output 0 (from A) and with output 1 (from D), so B splits into B0 and B1. B1 is the "found it" state. Same input string:

Compare the two output strings. The Moore machine shows each 1 in the state after the arrow that the Mealy machine marked, and it needs one more state (5 instead of 4).

3. Timing: why Moore is "one clock late" and glitch-free

This is the part people get wrong, so look at the waveforms. During one clock period the machine sits in one state and sees one input value.

  • Mealy computes z from (state, x) during that period. If x changes mid-period, z can change mid-period. If x has a glitch, z has the same glitch.
  • Moore computes z from the state only. The state changes only at the clock edge, so z changes only at clock edges: stable, no glitches, but the effect of an input appears one period later.

What to write · "differentiate with block diagrams and an example" (5–10 marks)

  1. Both block diagrams (section 1). In Mealy, draw the extra wire from the input to the output logic and label it.
  2. The two output equations: z = λ(S, x) and z = λ(S).
  3. The table above, at least 4 rows.
  4. A tiny example of each, the 1101 detector: the Mealy diagram (4 states, 1/1 on D→B) and the Moore diagram (5 states, the extra state written B1/1). Say "the Moore machine needs one more state and outputs one clock later".

5. Which one does a word problem want?

Adnan sir's rule (from the pulse-mode lock): level output, "after …" → Moore. Pulse output, "until …" or "when …" → Mealy.

"The lock output is 1 after the sequence" is a level that stays while you remain in the unlocked state, so it is Moore (the output belongs to the state). "Produce a pulse when the amount reaches 15 Tk" happens on the transition, so it is Mealy. If the question says nothing, Mealy is shorter. Say which model you chose.

6. Mealy → Moore, step by step

The method (his "split by the output you enter with")

  1. Make a list: for each state, every (state, input) → this state arrow and the output on it.
  2. If all incoming outputs are equal, keep the state and give it that output. If they differ, split it into S0, S1, … (subscript = output).
  3. Write the Moore table. Each copy of S gets S's old next-state row. In every cell, a Mealy entry "T, z" becomes "Tz" (or just T if T was not split).
  4. Add the output column Z = the subscript.
  5. A state with no incoming arrow (only the start state can be like that) can take either output; say so. The start state's output is the "initial output", before any input.

His own example has three inputs and three output values. Every state is entered with all three outputs, so every state splits into three:

His notes say the copies a0, a1, a2 are "equivalent" because their rows match. They are not equivalent in the Moore machine: their outputs differ (0, 1, 2). Equal next-state rows with different outputs never merge. Do not write that they merge.
2023–24 Q8(c) · 6 marks

Transform the Mealy machine into a corresponding Moore machine.

PS | x=0 | x=1
A  | B,1 | C,0
B  | C,1 | D,0
C  | D,0 | E,1
D  | E,0 | A,1
E  | A,1 | B,1
Answer

Incoming outputs: A ← D(1), E(1): only 1 → A/1. B ← A(1), E(1) → B/1. C ← A(0), B(1) → split C0, C1. D ← B(0), C(0) → D/0. E ← C(1), D(0) → split E0, E1.

Moore machine, 7 states: A/1, B/1, C0/0, C1/1, D/0, E0/0, E1/1. A's output 1 is only its initial output; note that in one line.

2021–22 Q8(c) · 5 marks

Transform the Mealy machine into a Moore machine.

PS | x=0 | x=1
A  | C,0 | B,0
B  | A,1 | D,0
C  | B,1 | A,1
D  | D,1 | C,0
Answer

A/1 (entered only with 1), B splits B0/B1, C/0, D splits D0/D1: 6 states.

7. Moore → Mealy

His notes say "by simplification" and leave it as self-study. The method is short:

  1. Output on each arrow = the Moore output of the state the arrow goes to. In the table: cell "T" becomes "T, z(T)".
  2. Delete the Z column.
  3. Now states that were split only to carry different outputs may be equivalent. Run the partition method (next-but-one chapter) and merge them. That is the "simplification".
2018–19 Q8(c) · 7 marks

Obtain the Mealy equivalent state table for the Moore machine:

PS | x=0 | x=1 | Z
A  | A   | B   | 0
B  | C   | B   | 0
C  | C   | D   | 1
D  | A   | D   | 0
Answer

Each cell takes the output of its next state: A → 0, B → 0, C → 1, D → 0.

PSx=0x=1
AA, 0B, 0
BC, 1B, 0
CC, 1D, 0
DA, 0D, 0

Check for equivalent states: P₀ = (ABCD); P₁ = (AD)(BC) by output rows; P₂: for x = 1, A goes to B and D goes to D, which are in different blocks, so A and D split; likewise B and C. Final (A)(B)(C)(D): no merging, the Mealy machine also has 4 states.

Traps
  • Splitting by the outputs on the arrows leaving a state. Always use the arrows entering it.
  • Forgetting to redirect the arrows. "T, 1" must point to T1, not to T0.
  • In Moore diagrams, writing outputs on the arrows. The arrows carry only the input; the output goes in the circle as A/0.
  • Saying Moore is "faster". It is slower by one clock; it is more stable.
  • Reading a Moore output too early: in a timing question, z for period k is the output of the state during period k.
