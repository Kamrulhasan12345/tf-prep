The whole method on one screen
  1. Race = a move where two or more state variables must change. If the circuit ends in the same stable state whatever the order, it is non-critical; if an intermediate state is stable (or leads elsewhere), the order decides and it is critical. Never allow a critical race.
  2. Transition diagram: a vertex per row, an edge for every unstable move row r → row s. The two codes of every edge must differ in exactly one bit.
  3. 2 variables work if the graph is inside a square (a path or a 4-cycle). A triangle (3 mutually joined rows) never fits: add one spare row on one edge to turn it into a square.
  4. Dense graph (K₄): use 3 variables, spare rows on 3 edges (b′, c′, d′ in Adnan sir's TF #3), place them on the cube with the adjacency map: a = 000, b = 001, b′ = 011, c = 010, c′ = 110, d = 100, d′ = 101.
  5. Modified flow table: the spare row is a via-row (leads on to the target, everything else "–"). Then transition table → K-maps → circuit.

1. What a race is (2022–23 Q8a, 12 marks)

An asynchronous circuit has a combinational part and feedback. When an unstable total state moves to a row whose code differs in more than one bit, the secondary variables change at slightly different speeds: a race. Adnan sir's picture: moving 00 → 11 can go via 10 (path 1) or via 01 (path 2).

Non-critical race
Both intermediate states (10 and 01) are unstable in that column and lead on to 11. Whichever variable wins, the circuit ends in 11.
Critical race
One intermediate state is stable in that column. If that path wins, the circuit stops there and never reaches 11: the result depends on the speeds.
Cycle
A chain of unstable states that returns to a state it has already visited, so it never settles (it oscillates).

What to write (what is a race, 12 marks)

  1. Definition: more than one state variable must change for one input change; the circuit is a combinational part with feedback and the variables change at different speeds.
  2. Non-critical: all paths end in the same stable state. Critical: some path ends in a different stable state. Give one table of each (a 2-variable transition table is enough) and draw the paths 00 → 10 → 11 and 00 → 01 → 11 with the stable ones marked.
  3. The cure: assign states so that every unstable move changes one bit (single-step transitions), adding spare rows if needed.

2. Transition diagram and adjacency

Finding a race-free assignment

  1. From the (reduced) flow table list every unstable entry: row r has "s" in some column → edge r – s. Do it for all rows; each pair once. (Stable entries are not edges.)
  2. Number of state variables k = ⌈log₂ rows⌉ (2 for 3–4 rows, 3 for 5–8).
  3. Draw the graph. Put the vertices on the corners of a square (k = 2) or cube (k = 3). Every edge must join neighbouring corners (codes differing in one bit); diagonals are not allowed.
  4. If it does not fit, add a spare row on an edge r – s: r now goes to the spare row x, x goes on to s. Two edges instead of one, each of length one. Repeat until it fits. A graph with a triangle never fits a square or a cube corner pair directly, so a triangle always needs a spare row.
  5. Write the modified flow table with the extra rows and the codes.

4. Triangles: 2020–21 Q8b (10 marks) and Adnan sir's a, b, c example

2020–21 Q8(b) · 10 marks

Reduced flow table below; find a valid assignment without critical race and complete the modified flow table.

Answer

Edges: a-b, b-c, a-c: a triangle a – b – c. Three states fit 2 variables only if they form a path; the engine finds no 2-variable assignment. Break the triangle with a spare row on one edge. Choose a – c: c′ between them (a = 00, b = 01, c = 11, c′ = 10: the square 00-01-11-10).

Rewrite: c (stable at 01, 11) goes to a at 00 through c′: row c has c′ at 00; row c′ has a at 00 and nothing else (c′ is only a stepping stone). The check: a–b 00–01, b–c 01–11, c–c′ 11–10, c′–a 10–00: all single steps.

Which edge to cut? Any one of the three works (the search finds all three). The marks are for the diagram, the extra row, and a modified table in which every unstable entry is a single-bit move.

What to write (state assignment, 8–12 marks)

  1. The list of edges, or the transition diagram with the edge labels (the column in which the move happens).
  2. The statement "triangle / K₄ → cannot be placed on a square → add rows" (or "fits a square, no extra row").
  3. The codes, written next to every state; for 3 variables the adjacency map.
  4. The modified flow table in full: every original row, every spare row, every stable entry circled, every unstable entry a row name.
  5. One line of check: "every unstable move changes one bit".

7. From the race-free table to the circuit (Badhon's notes)

Adnan sir stops at the transition table; Badhon's notes finish the job. Take his Example 1 (the three-row table with output z, rows a, b, c).

Race-free table → circuit

  1. Transition table: replace row names by codes. Write the next-state code Yk and the output in each cell; spare rows and unspecified cells give don't-cares; unused codes are don't-cares.
  2. Latches: "If D latches are used, the transition table is the excitation table": D = Y. (With SR latches: S = Y·y', R = Y'·y.)
  3. K-maps over (x₁, x₂, y…) for each Y and for z. Minimise with don't-cares.
  4. Circuit: AND-OR network for each Y; the outputs y fed back; z from its own gates.

The trial assignment a = 00, b = 01, c = 10 in his notes is not race-free: b → c at 10 changes both bits (01 → 10). That is why the assignment comes first. With the spare row c′ (a = 00, b = 01, c = 11, c′ = 10):

Compare Badhon's trial-assignment result (Y₂ = x₁x₂y₁' + x₁x₂'y₁ + x₁y₂, Y₁ = x₁'x₂ + x₂y₁, Z = y₂y₁'). The equations differ because the codes differ; a race-free answer must use the race-free codes.

Traps that cost marks

  • Counting only the edges of the circled entries. Edges come from the unstable entries.
  • Using the trial assignment "a = 00, b = 01, c = 10" and never checking 01 → 10.
  • Adding a spare row but leaving the old unstable entry pointing straight at the far state (the via-row must be in the path).
  • Giving the spare row stable entries: it is a stepping stone only.
  • Forgetting that one cell of the 3-cube stays unused (7 rows) and is a don't-care in the K-maps.
  • Calling a race "critical" only because two bits change: it is critical only if some path ends in a different stable state.
