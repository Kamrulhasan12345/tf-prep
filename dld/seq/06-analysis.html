1. Analysis is design run backwards

In design you start from words and end at a circuit. In analysis you start from the circuit (or its equations) and end at the state diagram. Adnan sir's list, from the circuit upward:

  1. Equations. Read the flip-flop input equations and the output equation off the circuit (J1 = x y2, K1 = x', …, Z = …).
  2. Excitation table. For every present state and input, evaluate each equation. Result: the J, K (or S R, T, D) values.
  3. Transition table. Apply the flip-flop's behaviour (section 2) to get the next state. Result: PS → NS with the output.
  4. State table. Give the binary states names (A, B, C, D) and write the same table with the names.
  5. State diagram. Draw the circles and arrows from the state table.

The exam wording often lists "transition table, excitation table, state table". Order on paper does not matter, but you can only fill the transition table after the excitation values, so do the excitation table first and say so. Textbook names: Adnan's excitation table = the flip-flop-input columns in Mano's state table; his transition table = Mano's binary state table.

3. Adnan sir's worked analysis: the JK circuit

His example (L9): input x; J1 = x y2, K1 = x'; J2 = x, K2 = x' + y1'; output Z = x y1 y2. Below, the lab computes every table from the equations. The states are named by their code: S0 = 00, S1 = 01, S2 = 10, S3 = 11 (y2 y1). His names: A = 00, B = 01, C = 11, D = 10.

Reading the diagram: any state on x = 0 goes to 00 (his A). On x = 1 the machine walks A → D → B → C and then stays in C, where Z = 1. So Z becomes 1 on the fourth consecutive 1 and stays 1 while 1s continue: an overlapping 1111 detector. His notes never say this; say it in one line if the question asks "what does the circuit do".

4. 2019–20 Q2(b) and 2021–22 Q7(a): two flip-flops, two inputs, 16 rows

2019–20 Q2(b) · 25 marks · 2021–22 Q7(a) · 20 marks

A sequential circuit has two J-K flip-flops A and B, two inputs x1 and x2 and one output z. The flip-flop input equations and the output equation are:

JA = yAx1 + yBx2   KA = yAyB + x1x2   JB = yAx1   KB = yAyBx1 + yBx2   z = yAx1x2 + yBx1x2

(i) Draw the logic diagram. (ii) Derive the transition table, excitation table and state table. (iii) Draw the state diagram. (2021–22 asks the same, with a different wording and 20 marks.)

Answer

Two flip-flops and two inputs give 4 × 4 = 16 rows. The lab evaluates all of them with the engine (L.analyze with labels A, B). Input x1x2 is written as a 2-bit number with x1 first.

What the diagram shows. State 00 is absorbing: in that state JA = JB = 0 for every input, so neither flip-flop can be set and the machine stays in 00. z = 1 only when x1x2 = 11 and the state is not 00, so z is a Mealy output (the arrows carry it). From 11 the machine drops to 00 on any input except 00, which takes it to 01.

Logic diagram (i). Two J-K flip-flops sharing one clock. Gate drawings for the five equations are in the lab above (open "Gate drawing"). Feed yA = Q of A, yB = Q of B, and use the Q' outputs where an equation needs a complement.

5. 2023–24 Q7(b): a T flip-flop and a J-K flip-flop

2023–24 Q7(b) · 12 marks

Analyse the sequential circuit in the figure (a T flip-flop with output Q1 and a J-K flip-flop with output Q0; an AND gate, an OR gate, and an OR gate for the output y). Derive the transition table, excitation table and state table.

Answer

The reading used (the scan is dark in places; this is read from the original page 3 at 300 dpi).

  • T input of the first flip-flop = x. Its outputs Q1 and Q1'.
  • AND gate: inputs Q1 and Q0' (the wire from the AND's lower input runs down and joins the Q' output of the J-K flip-flop, the line along the bottom). Output goes to J. So J = Q1·Q0'.
  • OR gate: inputs Q1' and Q0' (same vertical wire). Output goes to K. So K = Q1' + Q0'.
  • Output OR gate: inputs Q1 (the wire along the top of the figure) and Q0. So y = Q1 + Q0.
  • Both flip-flops share clk. State variables Q1 Q0, Q1 the MSB.

Observations. y depends on the state only (y = 0 only in state 00), so write y inside the circles: it is a Moore-type output. State 11 with x = 0 holds itself (J = K = 0). With x = 1 the T flip-flop toggles Q1 every clock. Timing for the input 1 1 0 1 0 0 1, starting in 00:

What to write: an analysis question (12–25 marks)

  1. One line per equation: JA = …, KA = …, JB = …, KB = …, z = … (read from the circuit; state the reading if the figure is unclear).
  2. Excitation table: columns present state (yAyB), inputs, then JAKA JBKB and z. Every combination of PS and inputs gets a row.
  3. Transition table: present state against each input value, cell = next state, output. State the rule used ("J-K: 00 hold, 01 reset, 10 set, 11 toggle").
  4. State table: name the states (A = 00, B = 01, …) and rewrite the transition table with the names.
  5. State diagram: circle per state, arrow per (state, input) labelled input / output for a Mealy output, or output inside the circle for a Moore output.
  6. Logic diagram if asked: flip-flops on one clock, one gate network per input equation.
  7. If asked, one sentence on what the circuit does.

6. Older items: state equations, counter direction, a timing question

2014–15 · 15 marks · and 2016–17 · 4+7+4 marks

(2014–15) Two J-K flip-flops A and B, inputs x and y, output z. JA = Bx + B'y', KA = B'xy', JB = A'x, KB = A + xy'. Draw the logic diagram, tabulate the state table and derive the state equations for A and B. (2016–17) The 2019–20 equations again with A, B, x, y: logic diagram, state table, state diagram.

Answer

The 2016–17 item is the same as the one in section 4 with x1 = x, x2 = y, so use that solution. For 2014–15 the extra task is the state equations A⁺ and B⁺. Method: build the transition table (section 1), read the next A and next B as functions of A, B, x, y, and minimise with a K-map. (The OCR of the paper's output equation is unclear, so only the state equations are given.)

The shortcut that gives the same answer: A⁺ = JAA' + KA'A.

2015–16 · 7 marks · counter direction

A counter has two J-K flip-flops. The least significant flip-flop Q0 has J = K = 1 (VDD). The current values are Q0 = 0 and Q1 = 1. In which direction does the next clock pulse take the count, up or down? What would you change to count the other way?

Answer

The figure is partly lost in the scan: the only thing that matters is which output of Q0 drives J1 and K1. Rule: J1 = K1 = Q0 makes it an up counter, J1 = K1 = Q0' makes it a down counter. Flip-flop 1 toggles when the lower bit is 1 (up) or 0 (down). Both versions, started from Q1Q0 = 10:

With Q0 driving J1 K1 the next state from 10 is 11 (up). With Q0' it is 01 (down). To make it count the other way, move the connection from Q0 to Q0' (or the reverse). Use the lab's tables as your answer layout. State which connection your figure shows.

2011–17 bank · 6 marks · timing

A gated S-R latch is driven by D (S = D·CLK, R = D'·CLK). CLK = 1, D = 1, Q = 1, Q' = 0. D changes from 1 to 0 after the hold time, with CLK still 1. What are Q and Q'?

Answer

CLK = 1 means a latch is transparent: Q follows D for the whole time CLK is high. So when D falls to 0, S = 0 and R = 1, and the latch resets: Q = 0, Q' = 1. (An edge-triggered flip-flop would not change, because the clock edge is already past. Say which of the two the figure is. A latch with a gate input is level sensitive; the question's "after the hold time" hint is meant to test this.)

Traps that cost marks

  • Reading the input pair x1x2 as a number the wrong way round. Say "x1 is the first (left) bit".
  • Using the characteristic equation inconsistently: for J-K the next state is JQ' + K'Q, not J + KQ.
  • Leaving out rows. With 2 FFs and 2 inputs there are 16 rows, with all of them filled.
  • Forgetting the outputs in the state table and state diagram. Mealy output goes on the arrow (input/output), Moore output inside the circle.
  • Mixing up transition table and excitation table. Excitation table = FF inputs; transition table = next states.
  • Not stating the reading of an unclear figure.
  • Drawing the logic diagram with different clocks. Synchronous: one clock to every flip-flop.
