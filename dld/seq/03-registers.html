1. Registers and shift registers

A register of n flip-flops stores n bits. A shift register moves its bits one place at every clock pulse. His example: the byte 10100010 shifted right is 01010001 (the new bit enters on the left). Shifted left it is 01000100 (the new bit enters on the right).

NameData inData outHow
SISOserialserialbit in on the first FF, bit out of the last FF after n clocks
SIPOserialparallelread all Q outputs after n clocks (serial to parallel converter)
PISOparallelserialload all D inputs, then shift out one bit per clock (parallel to serial)
PIPOparallelparallelload all D inputs at one clock: a plain register

Basic right-shift register: n D flip-flops in a row, the Q of each feeds the D of the next, serial in at the first D, common clock and common clear. His remark: there is no way to hold the data by inhibiting the clock. The register shifts at every pulse. That is why we add a MUX per stage (section 2).

Run the bench: serial-in bits 1, 0, 1, 1 arrive on successive clocks and move to the right.

Parallel load register. Each D input is its own input line Ii: at every pulse the inputs are saved. To hold the data a 2×1 MUX sits in front of each D: L = 0 sends the flip-flop's own Q back to D (hold), L = 1 loads Ii. Both directions: a 2×1 MUX with select S (S = 0 right, S = 1 left) picks the left or the right neighbour. Everything together needs a 4×1 MUX per stage: this is the universal shift register.

2024–25 Q1(b) · 13 marks · compulsory Q1 · older: 12, 12, 15 marks (2012–13, 2015–16, 2016–17)

Design a 4-bit universal shift register using multiplexers and D flip-flops.

Answer
  1. Modes (state them first): S1 S0 = 00 hold, 01 shift right, 10 shift left, 11 parallel load. Add an asynchronous CLEAR if you like (74194).
  2. One stage = one 4×1 MUX + one D flip-flop. The MUX output is the D input. Stage i (bit i, Q3 is the MSB):
    • I0 = Qi (hold)
    • I1 = Qi+1 (shift right: the bit moves down from the left neighbour); for the MSB stage I1 = serial-in right, SIR
    • I2 = Qi−1 (shift left); for the LSB stage I2 = serial-in left, SIL
    • I3 = Pi (parallel input)
  3. All four MUXes share S1 and S0. All four flip-flops share CLK and CLEAR.
  4. Draw the figure above: four MUXes, four D flip-flops, the three wiring rows, serial outputs Q0 (right shift) and Q3 (left shift).
  5. Write the equation for one stage: Di = S1'S0'·Qi + S1'S0·Qi+1 + S1S0'·Qi−1 + S1S0·Pi.

Worked case: Q3 Q2 Q1 Q0 = 1011, S1 S0 = 01 (right), SIR = 0. After one clock: 0101. Same register, S1 S0 = 10 (left), SIL = 0: after one clock 0110.

3. The same register with a 2-to-4 decoder (2021–22 Q5(b))

2021–22 Q5(b) · 10 marks

Use a 2-to-4 decoder, NAND gates and edge-triggered D flip-flops to design a 4-bit shift register: S1S0 = 00 shift right, 01 shift left, 10 synchronous common clear, 11 synchronous parallel load.

Answer

The decoder outputs are d0 = S1'S0' (right), d1 = S1'S0 (left), d2 = S1S0' (clear), d3 = S1S0 (load). Each D input is an AND-OR of the modes that put something into it. Clear (d2) is not used by any gate, so D = 0 and the flip-flop clears at the next clock edge: synchronous clear for free.

D3 = d0·SIR + d1·Q2 + d3·P3
D2 = d0·Q3 + d1·Q1 + d3·P2
D1 = d0·Q2 + d1·Q0 + d3·P1
D0 = d0·Q1 + d1·SIL + d3·P0

One stage of the 2-to-4 decoder register. d2 (mode 10, clear) feeds no AND gate, so D = 0 and the flip-flop clears at the clock. The decoder (left) is shared by all four stages.

With NAND gates: each AND term is a 2-input NAND and the three NAND outputs go into one 3-input NAND (NAND-NAND = AND-OR). That is four NAND gates per bit, 16 NANDs and one decoder for the whole register. Compare with the 4×1 MUX version: same function with a shared decoder, but there is no hold mode here.

Check: S1 S0 = 10: d2 = 1, d0 = d1 = d3 = 0, so all D = 0 and every Q clears at the clock ✓.

4. Copy register A to B (2022–23 Q5(c))

2022–23 Q5(c) · marks not legible in the scan (about 12) · block diagram wanted

Design a sequential circuit to copy the content of shift register A to shift register B. Use a block diagram to represent the shift register in the diagram.

Answer
Block diagrams for copying A into B: parallel (needs a load control) and serial (needs the same clock and shift enable on both).

Assumption: the registers are n bits, A is a shift register (as the question says).

  1. Serial transfer (uses the shift registers as they are): connect the serial out of A to the serial in of B, apply the same clock and a shift enable to both. After n clock pulses every bit of A has moved into B, and B = A. A's own serial in can take its serial out (recirculate) so that A keeps its data. A control circuit (a mod-n counter, or the shift enable held high for n pulses) stops the transfer.
  2. Parallel transfer (faster): connect Ai to the parallel input of Bi and give B a load control L (a 2×1 MUX in front of each D, as in the load register). L = 1 for one clock pulse copies all bits at once.

Say which one you choose and why: serial needs fewer wires, n clocks; parallel needs n wires, one clock.

5. Serial transmission and error propagation (2024–25 Q4(a), 16 marks)

2024–25 Q4(a) · 16 marks

A 4-bit shift register is used for serial data transmission. (i) Analyse the timing relationship between input data, clock and output. (ii) Explain how errors may propagate in serial communication using shift registers.

Answer

(i) Timing. Take a 4-bit serial-in parallel-out register (D flip-flops, positive edge). Send the bits 1, 0, 1, 1 (first bit first). Each bit must be stable at D for a set-up time before the rising clock edge and a hold time after it. At each edge every Q takes the value of the stage on its left, and Q0 takes the bit at D.

  1. After edge 1 the first bit (1) is in Q0. After edge 2 it is in Q1, after edge 3 in Q2, after edge 4 in Q3.
  2. After 4 edges all four bits are present: Q3 Q2 Q1 Q0 = 1 1 0 1 (the first bit sent is in Q3). Read the parallel output now. One more edge shifts the first bit out (serial out at Q3).
  3. The latency from first bit in to last stage is 4 clock periods. The data rate is one bit per clock. The clock period must exceed tpd + tsetup of one stage, so the maximum rate is 1/(tpd + tsu).
  4. Input must change only between edges (just after an edge). Output changes a delay tpd after each edge.

(ii) Error propagation.

  1. One corrupted bit (noise flips a bit at D): it is shifted along with the others and ends up in one fixed position. The other bits are right, so the error is confined to one bit, but nothing in the register detects it. Example: the stream 1, 0, 0, 1 instead of 1, 0, 1, 1: Q3 Q2 Q1 Q0 = 1 0 0 1 instead of 1 1 0 1.
  2. Extra or missing clock pulse (a glitch on the clock, or a lost edge): the register shifts one place too many or too few. Every following bit lands one place off (framing error). The error propagates to the whole word and to every word after it until the receiver is re-synchronised.
  3. Feedback registers (serial adder, a register whose output returns to its input): a wrong bit is added into the carry, so it also changes the next bit. The error propagates along the number.
  4. Remedies: parity bit per word, start/stop bits or a frame marker for synchronisation, CRC, and a clean clock.

What to write (serial transmission timing)

  1. Draw CLK, serial D, Q0, Q1, Q2, Q3 one under the other, with the sampling edges marked.
  2. Write the bit sequence you assumed.
  3. Mark when all four bits are valid (after 4 edges) and where the first bit leaves.
  4. Two or three error cases, each with one sentence of effect.

6. Ring counter and the self-correcting fix (2024–25 Q3(a), 2017–18 Q7(c), 2022–23 Q6(b))

A ring counter is a shift register whose last output feeds the first input. One 1 circulates. For n flip-flops it has n states (mod-n). His 4-bit table (Q0 Q1 Q2 Q3): 1000 → 0100 → 0010 → 0001 → 1000. D flip-flops do the shifting. The first FF has PRESET and the others have CLEAR, so the counter starts at 1000.

Use "Load a bad state" and "Self-correction" on the bench above.

2024–25 Q3(a) · 12 marks

A ring counter is initialised incorrectly. (i) Analyse the resulting sequence of states. (ii) Propose a circuit modification to ensure automatic correction.

Answer

(i) Analysis (4-bit, Q0 Q1 Q2 Q3, D0 = Q3). The 16 states fall into separate loops, because the circuit only rotates the pattern it starts with and the number of 1s never changes:

  • (0000) stuck: never leaves all-zero
  • (0001 → 1000 → 0100 → 0010)
  • (0011 → 1001 → 1100 → 0110)
  • (0101 → 1010)
  • (0111 → 1011 → 1101 → 1110)
  • (1111) stuck: never leaves all-one

Only the loop with exactly one 1 is the intended ring. For example, an initial state 1010 gives 1010, 0101, 1010, 0101, ... forever: wrong frequency (it flips every clock), wrong pattern (two 1s), and it never corrects itself. Initial state 0000 or 1111 locks up completely.

(ii) Modification. Replace D0 = Q3 by D0 = (Q0 + Q1 + Q2)', a NOR of all outputs except the last. A 1 is fed in only when the first n−1 stages are all 0.

  • Any state with a 1 in Q0..Q2: D0 = 0, so the 1s are shifted down and out at Q3 one by one, until Q0..Q2 are all 0.
  • When Q0 Q1 Q2 = 000: D0 = 1, so a single 1 is injected (0001 gives 1000, 0000 gives 1000).
  • Result: from every one of the 16 states the counter enters the 1000 → 0100 → 0010 → 0001 loop within at most 3 clocks (computed). It is a self-correcting (self-starting) ring counter. Cost: one 3-input NOR gate.
2017–18 Q7(c) · 10 marks · 2022–23 Q6(b) · 5 marks · older: 4-stage switch-tail (5), 4-bit design (10)

Design a 5-bit ring counter using a shift register and draw the timing diagram. (2022–23: write a short note about a ring counter.)

Answer

Five D flip-flops, clocked together, Q0 → D1 → ... → Q4 → D0. Q0 is preset to 1 and Q1..Q4 are cleared at start. States (Q0..Q4): 10000, 01000, 00100, 00010, 00001, then 10000 again. Mod-5. Each output is high for one clock and low for four: the waveforms are the same shape delayed by one clock each.

Short note points (5 marks): circular shift register; one 1 circulates; n flip-flops, n states; each flip-flop output is already one decoded state (no decoder needed); initial state set by preset/clear; wasteful (2n − n unused states) and not self-starting unless modified (section 6); uses: sequence generators, timing control.

7. Johnson (twisted-ring) counter (2019–20 Q2(a), 2020–21 Q5(b), 2018–19 Q6(c))

A ring counter with the inverted last output fed back: D0 = Q3' (his words: "flip Q3, then shift by 1"). All flip-flops are cleared at the start (0000). The register fills with 1s and then with 0s. n flip-flops give 2n states. His 4-bit table (Q0..Q3): 0000, 1000, 1100, 1110, 1111, 0111, 0011, 0001, back to 0000. Each output is high for 4 clocks and low for 4, each shifted by one clock.

2018–19 Q6(c) · 7 marks · 2019–20 Q2(a) and 2020–21 Q5(b) · 10 marks · older (2014–15) · 10 marks

Design a 4-bit Johnson counter using a shift register and illustrate its operation using a timing diagram. (2019–20, 2020–21: distinguish ring and Johnson; design a 5-bit ring counter and a 5-bit Johnson counter with timing diagrams. 2014–15: also the disadvantage.)

Answer

4-bit Johnson. Four D flip-flops with common clock and clear; D0 = Q3', D1 = Q0, D2 = Q1, D3 = Q2. Clear to 0000.

5-bit Johnson (10 states, Q0..Q4): 00000, 10000, 11000, 11100, 11110, 11111, 01111, 00111, 00011, 00001, 00000.

Disadvantage (2014–15): if it starts in an unused state it can stay in a loop of unused states forever. For 4 bits the engine-style enumeration gives the loops: (0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001) ; (0010 → 1001 → 0100 → 1010 → 1101 → 0110 → 1011 → 0101). Only the first loop is the real 8-state sequence. Cure (found by exhaustive search over all choices of D0 on the unused states): D0 = Q3' + Q1·Q2' (Q0 is the first stage). It equals Q3' on the 8 valid states, so the sequence is unchanged, and every unused state enters the 8-state loop. Also: needs 2-input decoding gates to get one-hot outputs.

Advantages: only one flip-flop output changes per clock (no glitches in the decoded outputs), twice the states of a ring counter for the same number of flip-flops, and each decoded state needs just a 2-input AND.

What to write (ring and Johnson, with timing, 7–10 marks)

  1. Circuit: n D flip-flops in a row, the feedback wire (Qn−1 for ring, Qn−1' for Johnson), the common clock, preset on the first FF for ring or clear for Johnson.
  2. The count table, clock by clock, with the number of states (n or 2n).
  3. The timing diagram: CLK on top, then every Qi below it. Ring: one pulse per output, high for one clock. Johnson: high for n clocks, each output shifted by one clock.
  4. One line: "ring is mod-n, Johnson is mod-2n".

8. Serial adder and serial subtractor as small state machines

A serial adder adds two numbers one bit pair per clock, LSB first, with one flip-flop to remember the carry. It is a Mealy machine with two states. His definition: state A = carry 0 at the previous clock, state B = carry 1. Inputs x1 x2, output z = the sum bit. Convention: lower case y = present carry, capital Y = next carry.

2017–18 Q6(b) · 10 marks · older: trace 0101 + 0011 (6+6, 2011–12 and 2012–13), 2016–17 · 10

Design a serial adder that computes the sum of two 4-bit numbers A and B stored in shift registers; the result is stored in the register of A. (Older: draw the logic diagram and show the values after every clock pulse for 0101 + 0011.)

Answer
  1. A and B are 4-bit right-shift registers. Their serial outputs (the LSBs) go to the full adder inputs x1, x2.
  2. The full adder's sum output goes to the serial input of A (leftmost flip-flop). After 4 clocks the sum is in A.
  3. The carry out goes to the D input of a flip-flop; its Q is the carry in. The flip-flop is cleared at the start (no carry).
  4. All three (A, B, carry flip-flop) have the same clock. Four clocks are needed.

Traps that cost marks

  • Ring and Johnson tables use Q0 as the leftmost bit. A different order is fine if you label it. Do not mix orders between the table and the timing diagram.
  • A ring counter with D0 = Q3 does not fix a bad state. The fix is the NOR of Q0 .. Q(n−2).
  • Johnson feeds back Qn−1 complemented. Forgetting the bubble gives a ring counter.
  • Clear the carry or borrow flip-flop before a serial add. Otherwise the first sum bit is wrong.
  • Serial adder: LSB first, and the sum enters the left end of A so after 4 clocks the bits are in the right order.
  • Universal register: the MSB stage has no left neighbour (use SIR) and the LSB stage no right neighbour (use SIL). Label them.
  • In the decoder version the clear mode has no gate: say that "D = 0 when d2 = 1".
  • Draw the clock edge marks on a timing diagram, and give the assumed input sequence.
