1. The recipe: Adnan sir's 8 steps

Use this order and these names on the script. The textbook name is in brackets.

  1. State Diagram. Decide what each state remembers. Write that meaning next to the circle. Arrows are labelled x / z (input / output).
  2. State Table. One row per state; for each input value, the next state and the output.
  3. Number of FFs and state assignment. #FF = ⌈log₂ #states⌉. Give every state a binary code (A = 00, B = 01, …) [state assignment].
  4. Transition Table. The state table written with the binary codes: y2y1 → Y2Y1, z [binary state table].
  5. Excitation Requirement. The 4-row table for your flip-flop type (Q → Q⁺ → S R / J K / T / D) [flip-flop excitation table].
  6. Excitation Table. For every present state and input, the flip-flop inputs. Unused states and impossible inputs: x [flip-flop input columns of the state table].
  7. K-Map. One map per flip-flop input and per output, in the variables y2 y1 x. Result: equations.
  8. Circuit Diagram. Flip-flops, one clock, gates from the equations.
The Mealy / Moore rule in one line
Mealy: output on the arrow, depends on state and input; it reacts in the same clock period. Moore: output written in the circle, depends on the state only; it changes one clock later. A Mealy detector needs fewer states (the last arrow carries the 1); a Moore detector needs one extra state for the "detected" output. Unless the question says Moore, Adnan sir's examples are Mealy.

If the question gives the flip-flop (S-R, T, D, J-K) use that one. The excitation table for each is on the counter chapter; the trap list there applies here too. To check a finished design, analyse it backwards.

2. Sequence detectors: the idea

A state remembers how many bits of the pattern have been matched so far. For a 4-bit pattern X you need four states: no match (S0), first bit matched (S1), two matched (S2), three matched (S3). The 4th matching bit is the arrow that outputs 1.

Overlapping vs non-overlapping only changes where the output arrow goes.
  • Overlapping: after a detection the last bits can already be the start of the next pattern. The detection arrow goes to the state that matches the longest suffix (for 1101 it goes to "1 matched", because the last 1 of 1101 is also the start of 1101).
  • Non-overlapping: after a detection start from scratch: the arrow goes to S0.
For the other arrows (a wrong bit), both kinds use the same rule: go to the state for the longest tail of what has been read that is also the start of the pattern. Falling back to S0 every time is the classic mistake.

What to write: a sequence detector (20–25 marks)

  1. One line: "Mealy machine. Overlapping: after a detection the machine goes to … (state)". Name the states by what they remember (A = none, B = "1", C = "11", D = "110").
  2. State diagram with every arrow labelled x/z. Two arrows leave every state. The 1 appears on one arrow only.
  3. State table (PS; x = 0 and x = 1: NS, z).
  4. "#FF = ⌈log₂ 4⌉ = 2, assignment A = 00, B = 01, C = 10, D = 11."
  5. Transition table, then the excitation requirement for the given FF type (four rows).
  6. Excitation table: 8 rows (4 states × 2 inputs), columns S2R2 S1R1 and z. Use x where the requirement says so.
  7. K-maps for S2, R2, S1, R1, z in the variables y2 y1 x (3-variable maps, 8 cells). Circle, write the equations.
  8. Circuit diagram with flip-flops on one clock, gates, input x, output z.

4. 2019–20 Q1(b): non-overlapping, your roll number, T flip-flops

2019–20 Q1(b) · 25 marks

Design a sequence recognizer using T flip-flops that recognizes a 4-bit non-overlapping binary sequence X from an input stream of bits, where X = the 4-bit binary representation of your roll number (mod 16).

Answer

The question is a template: you must do it for your own X. Do the method below on paper for your X; the widget builds the diagram, tables and T equations for any 4-bit X so you can check.

The method for a general X = x1x2x3x4:

  1. States S0, S1, S2, S3: Sk means "the last k bits read are x1…xk".
  2. Forward arrows: from Sk on input xk+1 go to Sk+1, output 0 (k = 0, 1, 2). From S3 on input x4: output 1 and go to S0 (non-overlapping).
  3. Every other arrow (wrong bit): write the string "x1…xk + the bit just read", and go to the state for the longest tail of that string that equals the start of X (S0 if no tail does).
  4. Then the 8 steps: 4 states, 2 T flip-flops, A = S0 = 00 … S3 = 11. Excitation requirement for T: T = Q ⊕ Q⁺ (0 if the bit stays, 1 if it changes).

Worked X = 1011. Step 3 gives: S1 ("1") on 1 → "11": tail "1" → S1. S2 ("10") on 0 → "100": no tail → S0. S3 ("101") on 0 → "1010": tail "10" → S2. Press play: the input 1011011 has a second 1011 that overlaps the first, so a non-overlapping machine gives z = 0001000 (the second one is not counted).

Equations for X = 1011, non-overlapping (S0 = 00 … S3 = 11, flip-flops y2 y1): T2 = y2'y1x' + y2y1'x' + y2y1x, T1 = y1'x + y1x' + y2x, z = y2y1x. Check: for y2 = 0, T1 = y1 ⊕ x; the term y2x is what makes the detection arrow S3 —1→ S0 clear y1 (and y2y1x clears y2).

Try your own X: type 4 bits and press Build. The checkbox switches to overlapping to see the difference in the last arrow.

5. 2022–23 Q5(a): three or more consecutive 1s, D flip-flops

2022–23 Q5(a) · 12 marks (also 2011–12 · 15 marks)

Develop a sequential circuit that detects a sequence of three or more consecutive 1s in a string of bits coming through an input line. Use D flip-flops. Show the state diagram, the state table and simplified logic equations. You do not need to show the logic diagram.

Answer

States remember the run length of 1s: A = no 1 (or a 0 just came), B = one 1, C = two or more 1s. On a third (or later) 1 the output is 1 and the machine stays in C. Any 0 returns to A. Three states, so 2 flip-flops (code 11 unused: x).

Equations: D2 = y2x + y1x, D1 = y2'y1'x, z = y2x (A = 00, B = 01, C = 10; the unused code 11 is a don't-care).

Moore version (4 states)

With output in the state you need a fourth state D = "three or more 1s", output 1: A, B, C, D = 00, 01, 10, 11. Equations: D2 = y2x + y1x, D1 = y1'x + y2x, z = y2y1.

6. Serial parity (2018–19 Q6(b), 2020–21 Q6(b))

2018–19 Q6(b) · 8 marks · 2020–21 Q6(b) · 10 marks

Design a serial parity generation circuit. It receives a sequence of bits and determines whether the sequence contains an even or odd number of 1s. The output p is 0 for even parity and 1 for odd parity.

Answer

Two states remember "an even number of 1s so far" (EV) and "an odd number" (OD). A 1 flips the state, a 0 keeps it (a self-loop on each state). The output is the state itself, so this is a Moore machine with p written in the circle: EV/0 and OD/1. One flip-flop. Assumption (state it): the circuit is reset to EV before a sequence starts (asynchronous clear).

(The self-loops EV —0→ EV and OD —0→ OD sit at the edge of the drawing and may be cut off; the table above has them.)

Code EV = 0, OD = 1 (the code is the output). With three kinds of flip-flop (all from the engine):

The output is p = y (the flip-flop's Q). If the question wants the parity including the current bit with no one-clock delay, use the Mealy form p = x ⊕ y; the machine itself is the same.

7. 2023–24 Q5(b): divide-by-three counter of 1s

2023–24 Q5(b) · 12 marks

Divide-by-three counter counting 1s in an input stream: the output is 1 for every third 1 seen (not necessarily in succession); then it starts again. Use D flip-flops.

Answer

Count 1s modulo 3: S0 = 0 (or 3) ones seen, S1 = 1 one, S2 = 2 ones. A 0 changes nothing (loop). A 1 moves to the next state, and on the arrow S2 —1→ S0 the output is 1. Three states, 2 flip-flops, S0 = 00, S1 = 01, S2 = 10, code 11 unused (x).

Equations: D2 = y1x + y2x', D1 = y2'y1'x + y1x', z = y2x. The "not necessarily in succession" in the question is why the 0-arrows are self-loops, not resets.

8. 2023–24 Q6(a): traffic-light controller with WALK (23 marks)

2023–24 Q6(a) · 23 marks

A traffic light controller for an NS street crossing an EW street. Input: WALK button. Outputs NS and EW (0 red, 1 green). With no pedestrians: NS = 0, EW = 1 for 1 minute, then NS = 1, EW = 0 for 1 minute, and so on. When WALK is pushed, NS and EW both become 1 for a minute when the present minute expires, then they alternate again. (i) State diagram and state/output table. (ii) Transition and excitation tables using S-R flip-flops. (iii) Circuit diagram.

Answer

Assumptions (write them at the top). One clock period = 1 minute. WALK is sampled at each clock edge. The light pattern is a function of the state only (Moore). After the walk minute the normal alternation continues as if the walk minute had been inserted between two normal minutes.

States (the memory). A = EW green (NS 0, EW 1). B = NS green (1, 0). C = both green, entered from A, so the next minute is NS green. D = both green, entered from B, so the next minute is EW green. Two kinds of "both green" are needed so the alternation is not lost. 4 states, 2 flip-flops, A = 00, B = 01, C = 10, D = 11 (no unused code).

B1 0AD

D1 1AA

Moore diagram (the pair in the circle is NS EW). WALK pressed in C or D is ignored: the walk minute is already running.

Equations: S1 = y1'x, R1 = y1, S0 = y0'x' + y1y0', R0 = y0x' + y1y0, NS = y1 + y0, EW = y1 + y0'. Check: in A (00) with x = 1: S1 = 1, R1 = 0, so y1 becomes 1, S0 = 0 so y0 stays 0: 10 = C ✓.

The 3-state shortcut (if you prefer fewer states)

Use one "both green" state C (code 10, code 11 unused) and always return to A (EW green) afterwards. This gives S1 = y1'x, R1 = y1, S0 = y1'y0'x', R0 = y0, NS = y1 + y0, EW = y0'. Cheaper, but the alternation is not preserved after a walk that started from A, so state clearly that this is your interpretation.

9. 2020–21 Q6(a): the synchronous vending machine (JK, 20 marks)

2020–21 Q6(a) · 20 marks

Design the control unit of a synchronous vending machine. It accepts 5, 10 and 20 Tk notes. A drink costs 20 Tk. It releases a drink when the deposit is 20 or more and keeps the change as the deposit for the next purchase. The deposit is never more than 15 Tk. When the input CHANGE is given it releases the deposit. Outputs: Z1 = release drink, Z2 = release change. Inputs X1X2: 5 Tk = 00, 10 Tk = 01, 20 Tk = 10, CHANGE = 11. Use J-K flip-flops.

Answer

States remember the deposit: S0 = 0 Tk, S1 = 5, S2 = 10, S3 = 15 (the maximum). 4 states, 2 flip-flops, S0 = 00 … S3 = 11. All four input codes are real inputs (no don't-care columns). Mealy outputs Z1 Z2.

  • Add 5 or 10 and stay below 20: move to the new deposit, Z = 00.
  • Reach 20 or more: Z1 = 1 (drink), and the excess becomes the new deposit. From S3: +5 → 20 → S0; +10 → 25 → S1 (5 kept). A 20 Tk note always gives a drink and leaves the deposit unchanged.
  • CHANGE: Z2 = 1 and go to S0 (assumption: with nothing deposited, Z2 stays 0).

Equations: J1 = X1'X2 + y0X1', K1 = X2 + y0X1', J0 = X1'X2', K0 = X1'X2' + X1X2, Z1 = X1X2' + y1X1'X2 + y1y0X1', Z2 = y0X1X2 + y1X1X2 (y1 y0 = the deposit code).

2015–16 · 15 marks

Design a one-input, one-output serial 2's complementer using D flip-flops. The circuit accepts bits LSB first and produces the 2's complement. Include the state diagram, state table, equations and logic diagram.

Answer

Rule: copy the bits up to and including the first 1, then invert all later bits. Two states: A = "no 1 seen yet", B = "a 1 has been seen". A: x = 0 → A, z = 0; x = 1 → B, z = 1. B: z = x' always, stay in B. Mealy machine, reset to A (assumption).

Arrows: A —0/0→ A (loop), A —1/1→ B, B —0/1→ B (loop), B —1/0→ B (loop). The loops may be cut off in the drawing; the table has them.

Equations: D = x + y, z = x'y + xy' (T flip-flop version: T = y'x). One OR gate and one XOR gate.

Traps that cost marks

  • Falling back to the start state on every wrong bit. Use the longest tail that is still a prefix of the pattern.
  • Overlapping versus non-overlapping: after a detection the arrow goes to the suffix state (overlap) or S0 (no overlap). Read the question for the word "non-overlapping".
  • Missing arrows. Every state needs an arrow for every input value (two arrows for one input, four for two inputs).
  • Leaving out the assumptions: reset state, one clock = one minute or one note, Mealy or Moore.
  • Not marking the impossible input as a don't-care (Adnan's vending x2x1 = 11), or marking a real input as don't-care (the 2020–21 vending machine uses all four codes).
  • Writing the excitation table for the wrong flip-flop (T = Q ⊕ Q⁺, D = Q⁺, S-R forbids 11).
  • Mixing up the output: Mealy z may depend on x; a Moore output (traffic light, parity) must not.
  • For the roll-number question, doing a generic X and not your own: write the actual bits.
