Adnan sir marks it "5 mark question — CT, Final" and writes "question aste pare" (may come), with the practice list T→D, D→T, JK→SR. It is one method, always the same four steps, so it is cheap marks.

Target
The flip-flop you want to end up with.
Source
The flip-flop you have. You add gates around it so that it behaves like the target.
His "excitation requirement"
The textbook excitation table of the source: for Qn → Qn+1, which source inputs are needed. This is what step 2 uses. Learn the four tables of the previous chapter, section 7.

1. His method, four steps

  1. Target table. Write the characteristic table of the target: its inputs, Qn, and the wanted Qn+1. (He calls this table "excitation table" of the target.)
  2. Source excitation. For every row, take Qn → Qn+1 and read off from the source's excitation requirement what the source inputs must be. Put the answers in new columns.
  3. K-map. Each source input is a function of (target inputs, Qn). Draw one K-map per source input, with x for don't-cares. Simplify.
  4. Circuit. Target inputs and Q (or Q') go through the gates you found into the source inputs. The clock goes straight to the source. The output is the source's Q.

Then verify: pick two or three rows and check that the finished circuit gives the target's Qn+1. This costs 30 seconds and earns the marks the examiner is looking for ("verify using state transitions").

Which way round? His board writes "T→D" for the practice list. His worked ones are "D from T: T = D ⊕ Q" and "JK from T: T = J Q' + K Q". So "A → B" means "use A to build B". If a question says "design a D flip-flop using a T flip-flop", the target is D and the source is T. Read the question word by word and write "Target: D, source: T" at the top of your answer.

D flip-flop from a T flip-flop: T = D ⊕ Q (one XOR gate)

Verify. D = 1, Q = 0: T = 1 ⊕ 0 = 1, toggle, Q becomes 1 = D ✓. D = 1, Q = 1: T = 0, hold, Q stays 1 = D ✓. D = 0, Q = 1: T = 1, toggle, Q becomes 0 ✓. D = 0, Q = 0: T = 0, hold, 0 ✓.

In words: "the T flip-flop must toggle exactly when D differs from the present Q".

What to write (conversion, 5–10 marks)

  1. One line: "Target = D, Source = T. T = Qn ⊕ Qn+1."
  2. The table: target inputs, Qn, Qn+1, then the source input column.
  3. The K-map (or the XOR identity) and the equation, boxed.
  4. The circuit: gates, source flip-flop with its clock, labelled D, CLK, Q.
  5. A two-row verification.

His practice list: T → D, D → T, JK → SR

Build (a) D from T, (b) T from D, (c) SR from JK (and also JK from SR).

Answer
  1. D from T: T = D ⊕ Q (section 2).
  2. T from D: the D must be the next state: D = Qn+1 = T ⊕ Q.
    T flip-flop from a D flip-flop: D = T ⊕ Q (one XOR gate)
  3. SR from JK: J = S ; K = R. Connect J = S and K = R. S = R = 1 is a don't-care for an SR flip-flop, so it is simply never used (this JK would toggle). JK from SR: S = JQ' ; R = KQ. J = K = 1 can never give S = R = 1, because S = J Q' and R = K Q cannot both be 1.
    JK flip-flop from an SR flip-flop: S = J Q', R = K Q. J = K = 1 can never give S = R = 1.

  2. JK into T (a T flip-flop from a JK): J = K = T. D into JK (a JK flip-flop from a D): D = J Q' + K' Q.
    JK flip-flop from a D flip-flop: D = J Q' + K' Q
  3. T into JK (a JK from a T): T = J Q' + K Q. JK into T: J = K = T.
  4. SR from D with a 4×1 MUX. Target SR, source D, D = Qn+1. SR = 00 keeps Q, SR = 01 resets (0), SR = 10 sets (1), SR = 11 is a don't-care. With S and R on the select lines, the MUX data inputs are I0 = Q, I1 = 0, I2 = 1, I3 = x. Choose x = 1: the equation D = S + R'Q (engine result) is the same as the MUX.
    SR flip-flop from a D flip-flop and a 4×1 MUX: S and R are the selects. The data inputs are Q, 0, 1, 1 for SR = 00, 01, 10, 11 (I3 = 1 uses the don't-care).

6. Check yourself: a different way to confirm

You can always test the finished circuit with the characteristic equation of the source. Put the input equations into it and simplify; you must get the characteristic equation of the target. Example, JK from T: Qn+1 = T ⊕ Q = (J Q' + K Q) ⊕ Q. When Q = 0 this is J, when Q = 1 this is K' (K·1 ⊕ 1). Together: J Q' + K' Q ✓.

Traps that cost marks

  • Target and source are easy to swap. Write "Target = ..., Source = ..." as the first line.
  • Use the source flip-flop's excitation requirement (its own table) in step 2, not the target's.
  • Do not forget the don't-cares (x) of the JK and SR requirements. They are what make T = J Q' + K Q this small. Without them the equation is correct but bigger.
  • The clock goes to the source flip-flop directly. Never through the gates.
  • The Q feedback to the gates comes from the source flip-flop output (Q for the D = T ⊕ Q circuit, Q and Q' for JK from T).
  • For SR as a target, the row S = R = 1 is a don't-care. Write x, do not invent a value.
  • If the paper asks to "verify using state transitions", draw the state diagram or the table of Qn → Qn+1 for the finished circuit. A statement is not enough.
