Synchronous counters for any sequence

Past term-final questions on this topic: 2017–18 Q5(a) (20 marks, count 0→1→2→5→4→6 with S-R flip-flops), 2020–21 Q5(a) (20, count 0→2→4→7→5→3 with S-R), 2021–22 Q5(a) (20, the same sequence with one J-K, one T and one D flip-flop), 2022–23 Q7(b) (13, count 1→2→5→7 with J-K, then analyse the unused states). Older papers asked the same thing with other sequences: T flip-flops 1,2,5,7 with invalid states going to the next state (2014–15, 15), J-K 1,2,4,7 (2013–14, 20), T 0,1,3,7,6,4 (2012–13, 15), a 3-bit Gray counter with J-K (2011–12 and 2014–15, 15), D 1,4,5,7,2 (2016–17, 10). Adnan sir also teaches the mod-N counter with T flip-flops, the up-down BCD counter and the "undefined states" problem. A synchronous-counter question has come in every paper from 2020–21 to 2022–23 and is a safe 13–20 marks.

1. The recipe: Adnan sir's 8 steps, applied to a counter

A counter has no input and no output. So the "state diagram" is just a ring, and the "state table" is a list of present state → next state. Use this exact order in the exam. The textbook name is in the third column.

2. The four excitation requirement tables (memorise)

This is step 5. It answers: "to make Q go from Q to Q⁺, what must the inputs be?" An x is a don't-care and is worth a lot in the K-map.

Q → Q⁺S RJ KTD
0 → 00 x0 x00
0 → 11 01 x11
1 → 00 1x 110
1 → 1x 0x 001

How to remember: T = Q ⊕ Q⁺ (toggle only when the bit changes). D = Q⁺. J is "set", K is "reset": J = 1 sets, K = 1 clears, and the other one is x because it cannot matter. S-R is the same without the toggle row, so 0→0 and 1→1 each have one x.

Try the drill: type the S R, J K, T or D values for a random Q sequence.

3. First example: Adnan sir's 2-bit binary counter (JK)

00 → 01 → 10 → 11 → 00. Two flip-flops. Work down the table below, then read the equations off the K-maps. His result is J₂ = K₂ = y₁ and J₁ = K₁ = 1 (his FF numbering 1, 2); here Q1 is the MSB, so J1 = K1 = Q0 and J0 = K0 = 1. Press "Clock" to watch it count.

Pattern worth knowing: a JK flip-flop with J = K = 1 toggles on every clock, and with J = K = (all lower bits ANDed) it toggles only when every lower bit is 1. That is the binary up-counter, and it is why T flip-flops make the cheapest counter (section 7).

4. Counting with S-R flip-flops

2017–18 Q5(a) · 20 marks

Design a synchronous counter that counts 0 → 1 → 2 → 5 → 4 → 6 → 0 … using S-R flip-flops. Draw the circuit diagram.

Answer

Six states, so ⌈log₂ 6⌉ = 3 flip-flops. States 3 and 7 are unused: write x in every column of their rows.

Equations: S2 = Q2'Q1, R2 = Q2Q1, S1 = Q2'Q0 + Q2Q1'Q0', R1 = Q1, S0 = Q2'Q0', R0 = Q0.

Unused-state check (do it, it is cheap). State 7 goes to 0, which is in the sequence. But state 3 = 011 gives S1 = 1 and R1 = 1 together, the forbidden S-R input, so Q1 is undefined if the circuit ever starts in state 3. The question did not ask for this, so most solutions skip it. Fix: send 3 to 4 instead of leaving it a don't-care. Only S1 changes, to S1 = Q2'Q1'Q0 + Q2Q1'Q0' (= Q1'(Q2 ⊕ Q0)); now 3 → 4 and 7 → 0.

2020–21 Q5(a) · 20 marks

Design a synchronous counter that counts 0 → 2 → 4 → 7 → 5 → 3 → 0 … using S-R flip-flops. Draw the circuit diagram.

Answer

Equations: S2 = Q1Q0', R2 = Q1'Q0, S1 = Q1', R1 = Q1, S0 = Q2, R0 = Q2'. Unused states 1 and 6 go to 2 and 5, both in the sequence, so the counter is self-starting. S and R are never both 1: S1 = Q1' and R1 = Q1 are complements, S2 = Q1Q0' and R2 = Q1'Q0 cannot both be 1, and S0 = Q2, R0 = Q2' are complements.

5. Mixing flip-flop types

2021–22 Q5(a) · 20 marks

Design a synchronous counter 0 → 2 → 4 → 7 → 5 → 3 → 0 … using one J-K, one T and one D flip-flop. Draw the circuit.

Answer

Same sequence as above, so the same state table. The only new work is that each bit has its own excitation table: use the J-K rows for one bit, T rows for another, D rows for the third. Any assignment of types to bits is allowed. Pick the cheap one by looking at the bit patterns:

  • Q1 goes 0,1,0,1,0,1: it flips on every clock. Give it the T flip-flop: T1 = 1, no gate at all.
  • Q0 goes 0,0,1,1,1,0 and Q2 goes 0,1,1,1,0,0 (one step ahead): the next Q0 equals the present Q2. Give Q0 the D flip-flop: D0 = Q2, just a wire.
  • Q2 gets the J-K.

Equations: J2 = Q1Q0', K2 = Q1'Q0, T1 = 1, D0 = Q2. Five literals in total. Unused states 1 and 6 go to 2 and 5, so it self-starts.

The assignment matters for more than gate count. Swapping to T on Q2, J-K on Q1 and D on Q0 also costs 5 literals, but then unused states 1 and 6 are not rescued (lab below: it is a lock-out, 1 and 6 swap with each other). Always run the unused-state check on the final circuit.

Circuit to draw: three flip-flops on one clock line. Q2 is a J-K with J2 from an AND of Q1 and Q0' and K2 from an AND of Q1' and Q0. Q1 is a T flip-flop with T tied to logic 1. Q0 is a D flip-flop with D connected directly to Q2.

What to write: a counter design (20 marks)

  1. State diagram. Circles labelled with the state numbers, arrows in sequence order, one arrow from the last state back to the first. Label the arrows "clk".
  2. State table and assignment. "n states, so ⌈log₂ n⌉ = k flip-flops; state number in binary is the code, Q2 is the MSB." PS and NS columns.
  3. Excitation requirement table for the FF type(s): the four rows (0→0, 0→1, 1→0, 1→1).
  4. Excitation table. One row for every binary state from 000 to 111. Used states: the FF inputs. Unused states: x in every cell. Say "unused states are don't-cares".
  5. One K-map per FF input (S2 R2 S1 R1 S0 R0, or J K, or T, or D). Mark x cells, circle groups, write the equation under each map.
  6. Circuit diagram: flip-flops, one common clock, gates for each equation, Q and Q' lines labelled.
  7. Unused-state check: for each unused state, plug into the equations and write where it goes. One line each.

6. Analysing the unused states (self-start check)

2022–23 Q7(b) · 13 marks

Using J-K flip-flops, design a synchronous counter that counts 1, 2, 5, 7, 1, 2, … Analyse the final circuit to ensure that if it enters any of the unused states, after a finite number of clock cycles it comes to a used state.

Answer

Four states, so two flip-flops would do for the count, but the codes 1, 2, 5, 7 need three bits. Unused states: 0, 3, 4, 6.

Equations: J2 = Q0', K2 = Q1, J1 = K1 = 1, J0 = 1, K0 = Q2' (J2 = Q1 is an equally small cover; the unused-state result below is the same for both, checked with the engine).

The analysis (the part worth the marks). Put each unused state into the equations and read off the next state:

0 = 0001 01 11 1111 = 7in the sequence
3 = 0110 11 11 1000 = 00 → 7: in the sequence after 2 clocks
4 = 1001 01 11 0111 = 7in the sequence
6 = 1101 11 11 0001 = 1in the sequence

7. Counters with T flip-flops, and mod-N

Adnan sir's mod-N counter is a T-flip-flop counter. The T inputs have a pattern, so you can write the equations without any K-map.

Binary up-counter
T0 = 1, T1 = Q0, T2 = Q1Q0, … In words: a bit toggles when all the bits below it are 1.
With enable x (his N = 8 example)
The machine counts only when x = 1. T0 = x, T1 = x y0, T2 = x y0 y1, … Ti = x · y0 · y1 ⋯ yi−1. The Mealy output Z = x y0 y1 y2 = 1 on the arrow S7 → S0 ("cycle complete").
N = 2k
Same pattern with k flip-flops. His N = 128 example: 7 flip-flops, T6 = y5y4y3y2y1y0x and Z = y6…y0x.

The engine rebuilds his N = 8 table and confirms the equations:

N not a power of 2 (his N = 12, 81, 99). Use k = ⌈log₂ N⌉ flip-flops (N = 12: 4 flip-flops), count up in binary, and clear everything the moment the count reaches N. This needs flip-flops with an asynchronous CLEAR (and PRESET) that are active low.

  1. N = 12: the first state with Q3 = 1 and Q2 = 1 is 1100 = 12.
  2. A NAND gate on Q3 and Q2 gives 0 at that moment. Feed it to the CLEAR of all four flip-flops.
  3. The flip-flops return to 0000 straight away, so the valid count is 0 … 11. State 12 shows for a glitch only (his note).

Down counter or up-down: counting down from 0 wraps to all 1s, so detect "all ones" and PRESET to N−1. His N = 99 example: clear when the count reaches 99 = 1100011 (AND of y6 y5 y4' y3' y2' y1 y0 into CLEAR), and on the way down, when all seven bits are 1, preset to 98 = 1100010 (PRESET the bits that are 1 in 98, CLEAR the bits that are 0).

8. BCD up-down counter

His example: an up-down decade counter with J-K flip-flops. x = 0 counts up, x = 1 counts down; the states are 0 to 9, states 10 to 15 are don't-cares. That is 4 flip-flops and a 5-variable K-map (x y3 y2 y1 y0), drawn as two 4×4 maps. His notes leave the K-maps empty; the engine fills them in:

J3 = y2'y1'y0'x + y2y1y0x', K3 = y0'x + y0x', J2 = y1y0x' + y3y0'x, K2 = y1'y0'x + y1y0x', J1 = y3'y0x' + y2y0'x + y3y0'x, K1 = y0'x + y0x', J0 = K0 = 1. Self-start: states 10 to 15 all reach 0 to 9 within two clocks for both x = 0 and x = 1 (listed above under the table when you open the K-maps).

Likely exam use: you will not be asked for all eight maps. Write the state table, the transition table and two equations, then say "the rest are found the same way".

9. The lock-out problem and its fix

A counter with unused states has lock-out when an unused state leads only to other unused states, forming a cycle. After power-up in one of them, the counter never joins the sequence. Adnan sir calls this the "undefined states" problem (his example is the 0 → 5 → 4 → 6 → 7 counter, with states 1, 2, 3 undefined).

Example: count 1 → 2 → 5 → 7 with T flip-flops (this is the 2014–15 question). With don't-cares used freely the equations are T2 = Q1, T1 = 1, T0 = Q2', and the unused states form the cycle 0 → 3 → 4 → 6 → 0:

Two cures, both from his notes:

  1. Synchronous cure: define the unused states. Do not leave them as don't-cares; give each a next state inside the sequence (the old question said "any invalid state goes to the immediate next valid state": 0→1, 3→5, 4→5, 6→7). Redesign. Cost: more gates, and if the circuit wakes in an unused state the first clock pulse is "wasted" getting into the sequence (his "initialisation problem").
  2. Asynchronous cure: a power-on reset line on the CLEAR/PRESET inputs that forces a valid state (his Bangla note: reset to 000 or a valid state). No extra gates in the logic, but the flip-flops need CLEAR/PRESET pins.

The fixed equations are T2 = Q2'Q1 + Q1Q0, T1 = Q0 + Q2'Q1, T0 = Q2'Q1' + Q0'. They match the textbook answer of the old question, and the check under the table shows every unused state entering the count.

10. Other counter questions from the older papers

2011–12 and 2014–15 · 15 marks · Gray-code counter

Design a 3-bit synchronous Gray-code counter with J-K flip-flops. Show the state diagram, state table, equations and circuit.

Answer

Sequence 0, 1, 3, 2, 6, 7, 5, 4, back to 0 (each step changes one bit). All 8 states are used, so no don't-cares among states.

J2 = Q1Q0', K2 = Q1'Q0', J1 = Q2'Q0, K1 = Q2Q0, J0 = Q2'Q1' + Q2Q1, K0 = Q2'Q1 + Q2Q1'.

2016–17 · 10 marks · and 2012–13 · 15 marks

Synchronous counter 1 → 4 → 5 → 7 → 2 → 1 with D flip-flops (2016–17, "no measure for the unused states"). Synchronous counter 0, 1, 3, 7, 6, 4 with T flip-flops (2012–13).

Answer

D, 1-4-5-7-2: D2 = Q1', D1 = Q2Q0, D0 = Q0' + Q2Q1'. Unused 0 → 5, 3 → 0 → 5, 6 → 1: self-starting.

T, 0-1-3-7-6-4: T2 = Q2 ⊕ Q1, T1 = Q1 ⊕ Q0, T0 = (Q2 ⊕ Q0)'. The unused states 2 and 5 swap with each other (2 → 5 → 2): a lock-out loop, so say so and add the cure from section 9.

Traps that cost marks

  • Forgetting the x rows for the unused states, or writing 0 in them. The don't-cares are what make the equations short.
  • Using the wrong excitation table. T = Q ⊕ Q⁺, not Q⁺. D = Q⁺. J-K 1→1 is x 0, not 0 x.
  • S-R: S = R = 1 is forbidden. Check the equations never make both 1 in a used state (and, ideally, in an unused one).
  • K-map axis order. Rows and columns go 00, 01, 11, 10, not 00, 01, 10, 11.
  • Skipping the unused-state check when the question says "analyse" (2022–23). It is the whole point of the question.
  • Forgetting that all flip-flops share one clock in a synchronous counter. Draw the single clock line to every flip-flop.
  • Calling the transition table "the excitation table". In Adnan sir's usage: transition table = binary PS/NS; excitation requirement = the 4-row FF table; excitation table = the FF inputs for every PS.
