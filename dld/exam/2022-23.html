Q1(a) · 13 marks · M − N with (r−1)'s complement

Describe the steps to find M − N using the (r−1)'s complement, where M and N are n-digit unsigned numbers and r is the base.

Time guide: about 13 min.

Answer
  1. Write N with n digits (pad with leading zeros).
  2. Form the (r−1)'s complement of N: replace every digit d by (r−1) − d (base 10: 9's complement; base 2: 1's complement).
  3. Add it to M: M + ((rⁿ − 1) − N).
  4. If there is an end carry (M ≥ N): discard it and add 1 to the least significant digit (end-around carry). The result is M − N, positive.
  5. If there is no end carry (M < N): the sum is the (r−1)'s complement of the answer; take the (r−1)'s complement of the sum and put a minus sign: −(complement).
caseworkresult
72532 − 13250 (base 10)N has 9's complement 86749; 72532 + 86749 = 159281: end carry 1 → 59281 + 159282
13250 − 72532 (base 10)9's complement of 72532 = 27467; 13250 + 27467 = 40717, no end carry → 9's complement of 40717 = 59282−59282
1010100 − 1000011 (base 2)1's complement of 1000011 = 0111100; 1010100 + 0111100 = 10010000: end carry 1 → 0010000 + 1 = 00100010010001 (= 17)

Note: the paper prints "r−1's complement". Same method with the r's complement: add it, discard any end carry (no +1 step); if there is no end carry, the answer is negative and equals the r's complement of the sum.

Q3(a) · 14 marks · universal gates

What do you mean by a universal gate? Show that both NAND and NOR are universal.

Time guide: about 14 min.

Answer

A universal gate is one gate type from which any Boolean function can be built, because it can make NOT, AND and OR (a complete set).

from NANDfrom NOR
NOT x(x·x)' = x'(x+x)' = x'
AND((xy)')' : NAND, then NAND as NOT(x'+y')' : NOR each input as NOT, then NOR
OR(x'y')' : NAND each input as NOT, then NAND((x+y)')' : NOR, then NOR as NOT

Since AND, OR, NOT can build every function (SOP), NAND alone and NOR alone can too. Same idea: 2024–25 Q2(a).

Q3(b) · 14 marks · SOP and POS

Simplify F(A,B,C,D) = Σ(0,1,2,5,8,9,10) into (a) sum-of-products and (b) product-of-sums.

Time guide: about 14 min.

Answer

(a) SOP (group the 1s): F = B'D' + B'C' + A'C'D

(b) POS (group the 0s, read each group as a sum): F = (C' + D')(B' + D)(A' + B')

The two forms are equal (checked by the engine on all 16 rows).

Q3(c) · 7 marks · dual of XOR

Show that the dual of the exclusive-OR is equal to its complement.

Time guide: about 7 min.

Answer
  1. A ⊕ B = AB' + A'B.
  2. Dual (swap + and ·): (A + B')(A' + B).
  3. Expand: AA' + AB + B'A' + B'B = 0 + AB + A'B' + 0 = AB + A'B' = A ⊙ B.
  4. (A ⊕ B)' = A ⊙ B (truth table: 1 when A = B).

So the dual of XOR = XNOR = the complement of XOR. (Checked on all four input rows.)

Q4(a) · 10 marks · product of maxterms by the distributive law

Convert F = xy + x'z to a product of maxterms using the distributive law.

Time guide: about 10 min.

Answer
  1. F = xy + x'z. Distribute + over ·: (a·b + c = (a + c)(b + c)): F = (xy + x')(xy + z).
  2. xy + x' = (x + x')(y + x') = x' + y; xy + z = (x + z)(y + z).
  3. F = (x' + y)(x + z)(y + z).
  4. Add the missing variable to each factor (a = a + zz' etc.): x' + y = (x' + y + z)(x' + y + z') = M4·M5; x + z = (x + y + z)(x + y' + z) = M0·M2; y + z = (x + y + z)(x' + y + z) = M0·M4.
  5. Drop repeats: F = ΠM(0, 2, 4, 5) = (x+y+z)(x+y'+z)(x'+y+z)(x'+y+z') (checked against the truth table).

Q6(a) · 10 marks · negative-edge master-slave D flip-flop

Draw the block diagram of a negative-edge triggered master-slave D flip-flop using D latches.

Time guide: about 10 min.

Answer
master-slave D flip-flop

Wiring: D → master D latch; master Q → slave D; slave Q is the output. The master latch is enabled when CLK = 1 (transparent), the slave when CLK = 0 (through an inverter). Use an inverter in front of the master enable of a positive-edge version instead.

Operation: CLK = 1: master follows D, slave holds (output stable). CLK falls: master closes holding D, slave opens and copies it, so Q changes at the falling edge only. CLK = 0: master closed, slave transparent but its input is frozen.

Q6(b) · 5 marks · ring counter

Write a short note about a ring counter.

Time guide: about 5 min.

Answer
  • A shift register whose last output is fed back to the first input (D0 = Qn−1); one flip-flop holds 1 and the 1 circulates: 1000 → 0100 → 0010 → 0001 → 1000.
  • n flip-flops give n states (mod-n counter); the outputs are one-hot, so no decoder is needed to pick a state (timing signals, sequencers).
  • Must be initialised to a valid state (one 1): else the wrong pattern circulates forever; fix with preset/clear or by D0 = (Q0 + … + Qn−2)' (self-correcting).
  • Output frequency is fclk/n. Costly in flip-flops compared with a binary counter (2n states) but simple and fast. The Johnson (twisted-ring) counter gives 2n states.

Q7(a) · 12 marks · 4-bit ripple count-down counter with T flip-flops

Show the logic diagram of a four-bit binary ripple (asynchronous) countdown counter using T flip-flops that trigger on the negative edge of the clock.

Time guide: about 12 min.

Answer

All T inputs = 1 (toggle on every active edge). Stage 0 is clocked by the clock. Down counting: bit i+1 must toggle when bit i goes 0 → 1 (borrow); for negative-edge flip-flops that is when Qi' goes 1 → 0, so clock stage i+1 from Qi' (for an up counter use Qi).

4-bit ripple down counter, negative-edge T flip-flops

Count sequence (Q3 Q2 Q1 Q0): 0000 → 1111 → 1110 → 1101 → … → 0001 → 0000 (16 states, mod 16, counts down). Each flip-flop divides the frequency by 2. The delay accumulates through the chain (ripple), so it is slower than a synchronous counter.

Q8(a) · 12 marks · races in fundamental-mode circuits

What is a race in a fundamental-mode circuit? Explain critical and non-critical races with examples.

Time guide: about 12 min.

Answer

Race: when an input change makes two or more state variables change at once (e.g. y1y2 from 00 to 11), their delays differ, so the circuit passes through an intermediate state (01 or 10) depending on which variable wins.

Non-critical race: every possible path ends in the same stable state. Example (column x = 1): rows 00 → 11; the intermediate rows 01 and 10 are unstable and also point to 11, so both paths end in 11.

row (y1 y2)x = 0x = 1
00 (a)(a)d
01 (b)ad
10 (c)cd
11 (d)a(d)

Critical race: different paths end in different stable states. Example (column x = 1): 00 → 11 again, but the intermediate row 01 is stable in that column, so if y2 changes first the circuit stops in 01 instead of 11.

row (y1 y2)x = 0x = 1
00 (a)(a)d
01 (b)a(b)
10 (c)cd
11 (d)a(d)

Cure: choose the state assignment so that each unstable transition changes one variable only (adjacent codes), or route through extra unstable rows (Gray-like). Non-critical races are harmless; critical races must be removed.
