Q1(a) · 8 marks · dual and complement

Analyze whether the dual and the complement of F = ABC + A(B+C) + A'B'C' are the same. Justify.

Time guide: about 8 min.

Answer

Dual (swap + and ·, keep literals): Fd = (A + B + C)(A + BC)(A' + B' + C').

Complement (De Morgan: swap + and · and complement every literal): F' = (A' + B' + C')(A' + B'C')(A + B + C).

The only difference is the middle factor: the dual has A + BC, the complement has A' + B'C'. Truth tables (engine):

minterms (1s)
F0, 5, 6, 7
Fd3, 4, 5, 6
F'1, 2, 3, 4

Not the same: Fd ≠ F' (e.g. at ABC = 101 the dual is 1 but the complement is 0). In general F' = Fd(A', B', C'): the complement equals the dual with all inputs complemented, so the two are equal only for self-dual functions, and F is not self-dual.

Q1(c) · 7 marks · PI vs EPI

Differentiate prime implicant and essential prime implicant.

Time guide: about 7 min.

Answer

Prime implicant (PI): a product term (a group of 1s on the K-map, size a power of 2) that cannot be enlarged, i.e. it is not contained in a bigger implicant of the function.

Essential prime implicant (EPI): a PI that covers at least one minterm (its responsible minterm) covered by no other PI. It must appear in every minimal cover.

Example F(A,B,C,D) = Σ(0, 1, 2, 5, 6, 7, 8, 9, 10, 14): 6 PIs (A'C'D, A'BD, A'BC, B'C', B'D', CD'); EPIs: B'C' (responsible minterm 9); CD' (responsible minterm 14). The other PIs are optional: pick as few as needed to cover what the EPIs leave. Minimal: F = B'C' + CD' + A'BD.

Q2(a) · 10 marks · minterm expansion

Express F = (x'+y)(x+z)(y+z) in minterms.

Time guide: about 10 min.

Answer
  1. (x' + y)(x + z) = x'x + x'z + xy + yz = x'z + xy + yz (x'x = 0).
  2. Multiply by (y + z): (x'z + xy + yz)(y + z) = x'yz + x'z + xy + xyz + yz + yz = x'z + xy + yz.
  3. yz is the consensus of x'z and xy, so F = x'z + xy.
  4. Add the missing variable: x'z = x'z(y + y') = x'yz + x'y'z (m3, m1); xy = xy(z + z') = xyz + xyz' (m7, m6).

F = Σ(1, 3, 6, 7) (checked against the truth table of the original product). Equivalently F = Π(0,2,4,5).

Q3(b) · 11 marks · Boolean algebra proof

Show by Boolean algebra that F = xyz' + wx'y' + (x'+z+w)(x'+z+w') + xyz + wx'y simplifies to F = xy + wx' + x' + z (as printed).

Time guide: about 11 min.

Answer
  1. xyz' + xyz = xy(z' + z) = xy
  2. wx'y' + wx'y = wx'(y' + y) = wx'
  3. (x' + z + w)(x' + z + w') = (x' + z) + ww' = x' + z ((a + w)(a + w') = a with a = x' + z)
  4. So F = xy + wx' + x' + z (the printed result)
  5. Further: wx' + x' = x' (absorption), so F = xy + x' + z, and x' + xy = x' + y, so F = x' + y + z.

Note: xy + wx' + x' + z is correct but not minimal; the minimal form is x' + y + z (checked by truth table over all 16 rows). Say this in the answer.

Q6(b) · 6 marks · the JK flip-flop problem

What is the problem in the construction of a J-K flip-flop? How can it be overcome?

Time guide: about 6 min.

Answer

Problem: race-around. With J = K = 1 a level-triggered JK latch toggles. While the clock is high, the new Q is fed back to the input gates and Q toggles again after each gate delay tpd; if the clock pulse width tw is longer than tpd the output toggles several times and the final value is unpredictable.

  • Master-slave JK: master follows J, K while the clock is high, slave copies the master when it is low; Q changes once per pulse.
  • Edge-triggered JK (a short pulse at the clock edge): the inputs are sampled only at the edge.
  • Make the clock pulse narrower than the loop delay (unreliable).
Q6(c) · 6 marks · modulo-100 ripple down counter with JK flip-flops

Draw a modulo-100 ripple down counter using J-K flip-flops and basic gates.

Time guide: about 6 min.

Answer

Two decade (mod-10) ripple down counters in cascade: units digit and tens digit, each four JK flip-flops with J = K = 1 (toggle), negative-edge triggered. Down counter: stage i+1 is clocked by Qi' of stage i (Q' falls when Q rises = borrow).

Units digit (tens digit is identical)

Mod 10: a plain down counter goes 0000 → 1111 after 0. When it reaches 1111 reload 1001 (= 9): a 4-input NAND on Q3 Q2 Q1 Q0 drives the asynchronous clear of Q2 and Q1 (active low), giving 1001. The count is 9, 8, …, 1, 0, 9, …

Tens digit: its clock is Q3' of the units digit. Q3 rises only when the units digit goes 0 → 9 (the borrow), so the tens digit decreases exactly then. Tens digit has its own NAND(1111) → clear Q2, Q1.

Result: 99, 98, …, 10, 09, …, 01, 00, 99 (behaviour checked over two full cycles). 8 JK flip-flops, 2 NAND gates.
