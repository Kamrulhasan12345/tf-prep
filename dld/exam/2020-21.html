Q1(a) · 15 marks · decoder as adder

Design a circuit that adds two 2-bit numbers X₁X₀ and Y₁Y₀ using a 2-to-4 decoder with inputs I₀, I₁, active-low outputs O₃'..O₀' and active-low enables EN₁', EN₂'. Use the minimum number of extra gates.

Answer

Time: about 13 min

Idea. The sum has 3 bits S₂S₁S₀. Put the low bits X₀, Y₀ on the decoder (I₁ = X₀, I₀ = Y₀); then O₃' = 0 exactly when X₀Y₀ = 1 (carry C₁) and O₁', O₂' are the two minterms of S₀. Enables tied to 0.

What to write (15 marks)

  1. Truth statement: S = X + Y, 3-bit result. S₀ = X₀⊕Y₀, C₁ = X₀Y₀, S₁ = X₁⊕Y₁⊕C₁, S₂ = X₁Y₁ + (X₁⊕Y₁)C₁.
  2. Decoder wiring: I₁ = X₀, I₀ = Y₀, EN₁' = EN₂' = 0. Active-low output Ok' is 0 when X₀Y₀ = k (binary).
  3. Residual table (engine, select pair X₀Y₀):
    X₀Y₀ (decoder line)00011011
    S₀0110
    S₁X1'Y1 + X1Y1'X1'Y1 + X1Y1'X1'Y1 + X1Y1'X1'Y1' + X1Y1
    S₂X1Y1X1Y1X1Y1Y1 + X1
  4. S₀ = O₁ + O₂ = (O₁'·O₂')' : one NAND. C₁ = O₃ = NOT O₃' : one inverter. P = X₁⊕Y₁ (XOR). S₁ = P ⊕ C₁ (XOR). S₂ = X₁Y₁ + P·C₁ (2 AND + 1 OR).
  5. Draw the circuit, label outputs, state: 7 extra gates (NAND, NOT, 2 XOR, 2 AND, OR).

Assumption: "minimum" means the fewest gates among the six possible select pairs; this pair (low bits) needs only one XOR pair because the other residues collapse to the shared term X₁⊕Y₁. Checked against all 16 input combinations.

Q3(c) · 5 marks · NOR-only

Express f(A,B,C) = Π(0,2,3,5,7) with NOR gates.

Answer

Time: about 4 min

f = Π(0,2,3,5,7) = Σ(1,4,6). Minimal POS from the zeros: f = (A + C)(A + B')(A' + C'). NOR-NOR form: each sum term is one NOR, then one NOR combines them and one more NOR inverts (or invert the output once).

Q4(a) · 10 marks · maximum of two 3-bit numbers

Design a circuit that finds the larger of two 3-bit numbers X₂X₁X₀ and Y₂Y₁Y₀. Explain with 7 and 3.

Answer

Time: about 9 min

What to write (10 marks)

  1. Bit equality Ei = Xi ⊙ Yi (XNOR).
  2. Greater-than: G = X₂Y₂' + E₂X₁Y₁' + E₂E₁X₀Y₀' (X > Y).
  3. Select: Zi = G·Xi + G'·Yi (a quad 2×1 MUX with select G).
  4. Example X = 7 = 111, Y = 3 = 011: E₂ = 0, X₂Y₂' = 1·1 = 1, so G = 1 and Z = X = 111 = 7.

Checked for all 64 input pairs. When X = Y, G = 0 and Z = Y, which equals X, so the tie is harmless.

Q4(b) · 12 marks · BCD adder-subtractor

Design a BCD adder-subtractor: A and B are 4-bit BCD digits, S = 0 gives A + B, S = 1 gives A − B.

Answer

Time: about 10 min

What to write (12 marks)

  1. Idea: subtract by adding the 10's complement. 10's complement of B = (9's complement of B) + 1, and the "+1" is the carry-in S.
  2. 9's-complement selector (BCD codes 10–15 never occur: don't-cares). B' = B when S = 0, 9 − B when S = 1. Engine equations:
    B′3 = S'B3 + SB3'B2'B1'
    B′2 = S'B2 + B2B1' + SB2'B1
    B′1 = B1
    B′0 = S'B0 + SB0'
  3. Binary adder 1: Z = A + B' + S (Cin = S).
  4. Correction: K = Cout + Z₃Z₂ + Z₃Z₁. Binary adder 2 adds 0KK0 (= 6 if K = 1) to Z. Output digit = low 4 bits; K = decimal carry.
  5. S = 1 reading: K = 1 means A ≥ B (result positive, drop K). K = 0 means A < B: the result is negative; the digit shown is the 10's complement of |A − B|.

9 + 7 (S = 0): 1001 + 0111 = 1 0000, Z = 0000, Cout = 1 so K = 1: 0000 + 0110 = 0110, carry 1 → 16 (carry 1, digit 6).
9 − 7 (S = 1): 9's complement of 7 = 2 = 0010; 1001 + 0010 + 1 = 1100, K = Z₃Z₂ = 1: 1100 + 0110 = 1 0010 → digit 2, K = 1 (positive) → +2.

Checked exhaustively for all 100 digit pairs and both values of S.

Q4(c) · 13 marks · 4-bit carry look-ahead adder

Design a 4-bit CLA adder taking X₃X₂X₁X₀ and Y₃Y₂Y₁Y₀. Show the steps and the role of the different carries.

Answer

Time: about 11 min

What to write (13 marks)

  1. Per bit: Pi = Xi ⊕ Yi (propagate), Gi = XiYi (generate). Sum Si = Pi ⊕ Ci, carry Ci+1 = Gi + PiCi.
  2. Expand so every carry depends only on P, G and C₀ (all computed in parallel):
    C₁ = G₀ + P₀C₀
    C₂ = G₁ + P₁G₀ + P₁P₀C₀
    C₃ = G₂ + P₂G₁ + P₂P₁G₀ + P₂P₁P₀C₀
    C₄ = G₃ + P₃G₂ + P₃P₂G₁ + P₃P₂P₁G₀ + P₃P₂P₁P₀C₀
  3. Roles: C₀ = carry in from outside; C₁, C₂, C₃ = internal carries produced by look-ahead (no ripple wait); C₄ = carry out. G says "this bit makes a carry by itself", P says "this bit passes an incoming carry".
  4. Delay: P/G (1 XOR/AND) + carry (2 gate levels) + sum XOR = 4 gate delays, independent of n; a ripple adder needs 2 per bit.

Checked for all 512 input combinations (X, Y, C₀).

Q5(c) · 5 marks · BCD ripple down counter, D flip-flops

Design a BCD ripple down counter using D flip-flops.

Answer

Time: about 4 min

Q8(b) · 10 marks · race-free assignment, modified flow table

For the reduced flow table below find a valid assignment without a critical race and give the modified flow table.

     | 00    | 01    | 11    | 10
a    | (a)/0 | b/-   | (a)/1 | b/-
b    | a/-   | (b)/0 | c/-   | (b)/0
c    | a/-   | (c)/1 | (c)/0 | b/-
Answer

Time: about 9 min

  1. Transitions needed: a↔b, b↔c, c→a (column 00), so a, b, c form a triangle: three mutually adjacent states cannot sit on a 2-bit square without one multi-bit move.
  2. Try a = 00, b = 01, c = 11. Only c → a (11 → 00) changes two bits. Its two paths go through b (01), where column 00 sends the circuit to a (unstable, harmless) and through the unused code 10, which we make a transit row pointing to a in column 00. So the race is non-critical. Prefer Adnan sir's version in the exam: route c → a through the spare row (c → x10 → a, each step one bit) so there is no race at all. That is worked in Races and race-free assignment §4. Both answers are valid; his is the one he marks.
  3. Modified flow table (added row x10):
    a: (a)/0 b/- (a)/1 b/-
b: a/- (b)/0 c/- (b)/0
x10: a/- - - -
c: a/- (c)/1 (c)/0 b/-
  4. Equations (engine, y₂y₁ = code): Y₂ = y1x1x2 + y2x2, Y₁ = x1'x2 + x1x2' + y1x2, z = y1'x2 + y2x1'.
