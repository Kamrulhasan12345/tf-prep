Q2(a) · 10 marks · simplify (A+B)'(A'+B')'

Simplify (A + B)'(A' + B')' to the minimum number of literals.

Time guide: about 4 min.

Answer
  1. (A + B)' = A'B' (De Morgan).
  2. (A' + B')' = AB (De Morgan).
  3. Product: A'B'·AB = (A'A)(B'B) = 0·0 = 0.

Answer: 0 (zero literals; the truth table is 0 on all four rows).

Q2(b) · 10 marks · AB + CDE with NAND gates only

Draw a circuit for AB + CDE using only NAND gates.

Time guide: about 8 min.

Answer

AB + CDE = ((AB)'(CDE)')': NAND-NAND (De Morgan). Two first-level NANDs (2-input and 3-input), one 2-input NAND at the output: 3 gates.

Q2(c) · 7 marks · sum of minterms by algebra

Express F(A,B,C) = A + B'C as a sum of minterms using Boolean algebra.

Time guide: about 6 min.

Answer
  1. A = A(B + B')(C + C') = ABC + ABC' + AB'C + AB'C'.
  2. B'C = B'C(A + A') = AB'C + A'B'C.
  3. F = ABC + ABC' + AB'C + AB'C' + AB'C + A'B'C; drop the repeated AB'C.

F = A'B'C + AB'C' + AB'C + ABC' + ABC = Σ(1, 4, 5, 6, 7) (m1 + m4 + m5 + m6 + m7; checked by truth table).

Q2(d) · 8 marks · M − N using the r's complement

Given two n-digit unsigned numbers M and N in base r, give the steps to find M − N using complements.

Time guide: about 8 min.

Answer
  1. Write N with n digits and form its r's complement: rⁿ − N (digit-wise (r−1) − d, then add 1 at the LSD).
  2. Add to M: M + (rⁿ − N).
  3. End carry present (M ≥ N): discard it; the result is M − N.
  4. No end carry (M < N): the sum equals rⁿ − (N − M); the answer is −(r's complement of the sum).

Q4(a) · 10 marks · 4-bit incrementer from half adders

Design a 4-bit incrementer using only half adders.

Time guide: about 10 min.

Answer

Output = A + 1. Chain four half adders: the first adds A0 and a constant 1; each carry goes to the next half adder's second input. Sum Si = Ai ⊕ Ci, Ci+1 = AiCi, C0 = 1.

4-bit incrementer (bit 0 on the right)

Check: A = 0111 → S = 1000 (all carries ripple); A = 1111 → 0000 with C4 = 1. Equations: S0 = A0', S1 = A1 ⊕ A0, S2 = A2 ⊕ A1A0, S3 = A3 ⊕ A2A1A0.

Q4(b) · 10 marks · F = Σ(3,5,6,7) with an active-low 3×8 decoder and AND gates

Implement F(x,y,z) = Σ(3,5,6,7) using an active-low 3×8 decoder and AND gates.

Time guide: about 10 min.

Answer

Active-low outputs: Di' = 0 when minterm i is selected. An AND of outputs is 0 if any of them is selected. So AND of the outputs of the zero minterms gives F: F' = Σ(0,1,2,4), and AND(D0', D1', D2', D4') = (D0 + D1 + D2 + D4)' = F.

(The other method: NAND of D3', D5', D6', D7' also gives F, but the question asks for AND gates.) Check: xyz = 011: D3' = 0, none of D0', D1', D2', D4' is 0, so F = 1. xyz = 000: D0' = 0, F = 0.

Q6(c) · 5 marks · MOD-13 ripple up/down counter, positive-edge JK

A MOD-13 counter counts 0000 to 1100. Design the MOD-13 ripple up/down counter with positive-edge triggered JK flip-flops and basic gates.

Time guide: about 5 min.

Answer

Four JK flip-flops with J = K = 1 (toggle). Mode input M: M = 0 up, M = 1 down. Positive-edge flip-flops: up counting clocks stage i+1 from Qi' (Q falls, Q' rises); down counting from Qi. So clki+1 = M'·Qi' + M·Qi (two AND gates, one OR, one NOT per stage).

Mod-13 up/down ripple counter
  • Up (M = 0): after 1100 the next state would be 1101 = 13: a NAND of Q3, Q2, Q0 and M' drives the asynchronous clear (active low) of all four flip-flops → 0000. Sequence 0 … 12, 0 …
  • Down (M = 1): after 0000 the counter goes to 1111 = 15: a NAND of Q3, Q2, Q1, Q0 and M clears Q1 and Q0, giving 1100 = 12. Sequence 12, 11, …, 0, 12 …

M is in both detector gates so that the up-detector (which also sees 1111) does not clear everything during a down count. Sequences checked for both modes.

A  | C,0 | B,0
B  | A,1 | D,0
C  | B,1 | A,1
D  | D,1 | C,0

Time guide: about 5 min.

Answer

Outputs on the arrows into each state: A ← B(1), C(1): only 1 → A/1. B ← A(0), C(1): split B0, B1. C ← A(0), D(0): C/0. D ← B(0), D(1): split D0, D1.
