Questions that come back

These questions were asked verbatim or with the same table in two or more papers (or in a 2026 class test). The examiner re-uses them. If you can write these 17 answers from memory you have most of a 210-mark paper's repeatable marks. Each entry: the question, the years, a full answer computed with the engine, and a link to the chapter. The first eight carry a drill box: write the answer on paper first, then mark yourself.

How to use this page on 18 Nov (40 minutes)

  1. Set a timer for 40 minutes. Phone away. Paper and pen, no screen answers.
  2. Pick 4 of the first 8 questions: the two you feel weakest on, one from pulse mode (2 or 3) and one more.
  3. For each: read only the question, write the full answer on paper (about 8-10 minutes each; stop at the time).
  4. Then open the drill box, press the marking button, and tick only what your paper really has. A missed tick is the thing to fix.
  5. For each missed tick, read that part of the worked answer once. Do not re-read the rest.
  6. Last 5 minutes: look at sections 9-17 (the short ones), read only the answers you cannot recite.

1. Incompletely specified machine: implication table, compatibles, bounds, minimal machine

15–25 marks · 2019–20 Q3b (25) = 2017–18 Q7b (15) (same table) · the same task in 2018-19 Q7a, 2020-21 Q7b, 2021-22 Q7b, 2023-24 Q7a with other tables · asked in 6 of the last 8 papers

2017–18 Q7(b) 15 · 2019–20 Q3(b) 25
Incompletely specified machine (PS: x = 0 | x = 1, entries NS, Z): A: A,− | B,1; B: G,− | D,0; C: B,1 | B,−; D: A,1 | B,−; E: C,− | A,−; F: F,− | C,−; G: G,− | G,−. Derive the implication table, the maximal compatibles and maximal incompatibles, the upper and lower bounds, and the minimal machine.
Answer
  1. Implication table. Compatible pairs (no output conflict on a specified output, implied pairs not incompatible): BC, AD, BD, BE, AF, DF, AG, BG, CG, DG, EG, FG. Crossed out (output conflict or an implied pair crossed): the rest.
  2. Maximal compatibles (merger diagram: largest cliques of the compatible pairs): (ADFG) (BCG) (BDG) (BEG).
  3. Maximal incompatibles (cliques of the crossed pairs): (ACE) (CDE) (CEF) (AB) (BF) (G).
  4. Bounds. Upper u = min(states of the original machine, number of maximal compatibles) = min(7, 4) = 4. Lower l = largest maximal incompatible = 3 (set (ACE)).
  5. Trial and error from l = 3 (covering + closed + minimum): no closed cover with 3 states exists (every 3-set breaks closure), so the minimal machine has 4 states: (ADFG) (BCG) (BDG) (BEG) (the four maximal compatibles themselves).
  6. Minimal machine (NS, Z; x = 0 | x = 1):
PSx=0x=1
(ADFG)(ADFG), 1(BCG), 1
(BCG)(BCG), 1(BDG), 0
(BDG)(ADFG), 1(BDG), 0
(BEG)(BCG)(ADFG), 0

What to write (20–25 marks)

  1. The implication table drawn (triangle), each cell: X, tick, or the implied pairs, with crossing-out passes labelled.
  2. List of compatible pairs; merger diagram; the maximal compatibles and maximal incompatibles as sets.
  3. u = min(…) and l = max(…), "l ≤ k ≤ u".
  4. Trial: the chosen set, then the three checks written as three ticks: covering (every state appears), closed (all implied sets inside a chosen set), minimum.
  5. The reduced table, new states named α β γ δ, and where an entry has a choice, say which you chose.

2. Pulse-mode vending machine, 3 Tk, level output, SR latches

Candy costs 3 Tk. The machine accepts 1 Tk and 2 Tk coins only, one at a time. A level output delivers the candy when the amount received is 3 Tk or more. The excess stays deposited for the next candy. Design a pulse-mode circuit with S-R flip-flops and draw it.

7. Mealy vs Moore: block diagrams, difference, example

10 marks · 2011–12, 2013–14, 2015–16, 2022–23 Q7c, 2024–25 Q8a (one tag, five sessions) · the conversion between the two is in 2018–19 Q8c, 2021–22 Q8c, 2023–24 Q8c

2024–25 Q8(a) · 2022–23 Q7(c) · 10 marks
Draw the block diagrams of Mealy and Moore state machines. State the difference between the two models with a simple example.
Answer

Block diagrams. Both: input X → next-state logic (also fed by the present state) → state register (flip-flops, clock) → present state, fed back. Mealy: the output logic takes the present state and the input X: Z = f(state, X). Moore: the output logic takes the present state only: Z = f(state).

8. PLA for F1 = Σ(0,1,2,4) and F2 = Σ(0,5,6,7)

2022–23 Q2(b) · 2014–15 QB #314 · 2011–12 QB #316 · 15 marks
Tabulate the PLA programming table for F1(A,B,C) = Σ(0,1,2,4) and F2(A,B,C) = Σ(0,5,6,7). Minimise the number of product terms. (2014–15: 3 inputs, 4 product terms, 2 outputs; 2011–12 adds F3 = Σ(0,3,5,7).)
Answer
  1. Minimise each function and its complement: F1 = A'B' + A'C' + B'C'; F1' = BC + AC + AB (= AB + AC + BC). F2 = A'B'C' + AC + AB; F2' = A'C + A'B + AB'C'.
  2. Choose true or complement for each output so that the total number of distinct product terms is smallest: F1 complemented (F1' = AB + AC + BC) and F2 true (F2 = AB + AC + BC + A'B'C'), sharing AB, AC, BC. Engine optimum: 4 product terms (BC, AC, AB, A'B'C'), output polarities (F1, F2) = (C, T).

Programming table (inputs: 1 = true literal, 0 = complemented, – = absent; outputs: 1 = term connected). The XOR fuse on F1 is programmed for "complement": F1' = BC + AC + AB; F2 = AC + AB + A'B'C'.

9. BCD adder-subtractor (9 + 7 and 9 − 7)

12 marks · 2016–17, 2017–18 (9+4), 2020–21 Q4b (verbatim three times) · BCD adder alone in 2014–15 (15)

2016–17 · 2017–18 Q2(b) · 2020–21 Q4(b) · 12 marks
Design a BCD adder-subtractor for 4-bit BCD numbers A and B and a selector S: S = 0 gives A + B, S = 1 gives A − B. Explain the operations 9 + 7 and 9 − 7 with your circuit.
Answer
  1. Selector stage. For S = 1 the second operand becomes the 9's complement of B (S also enters as carry-in, which makes it the 10's complement). Engine, from the truth table with 1010–1111 as don't-cares: w = B3'B2'B1', x = B2 ⊕ B1, y = B1, z = B0'. A 2-way choice per bit (S = 0: B, S = 1: 9's complement) feeds adder 1.
  2. BCD adder. Adder 1 adds A + operand + S → Z with carry K. Correction needed when K + Z3Z2 + Z3Z1 = 1. Adder 2 adds 0 C C 0 (0110 when C = 1). BCD digit = adder 2 sum; carry-out = C.
  3. Reading the result. S = 0: digit + 10·carry. S = 1: carry-out 1 means A ≥ B, the digit is A − B (discard the carry); carry-out 0 means A < B, the digit is the 10's complement of B − A (negative result).

9 + 7 (S = 0): A = 1001, B = 0111: 1001 + 0111 = 1 0000; K = 1 → add 0110: 0110, carry 1 → 16 (0001 0110).

9 − 7 (S = 1): 9's complement of 7 = 0010. 1001 + 0010 + 1 = 1100 (12 > 9) → add 0110 → 1 0010: digit 0010, carry-out 1 → +2. (All 100 digit pairs, both modes, were checked.)

What to write (12 marks)

  1. Block diagram: selector (9's complement) → adder 1 → correction gate → adder 2 (adds 0CC0) → digit; carry C.
  2. The correction equation C = K + S3S2 + S3S1 and why (sum 10–15, or a carry).
  3. The 9's-complement equations or truth table.
  4. Both worked examples with the intermediate binary sums written.

11. Complementer with half adders

4–6 marks · 2026 CT2 Q2(a),(b) (4+4) = 2023–24 Q4(a) (6, 4-bit version) · cheap marks, and the CT2 idea is Tanzima ma'am's favourite

2026 CT2 Q2 · 2023–24 Q4(a)
Using only half adders, design a circuit that outputs the 1's complement of the input when the control C = 1 and passes the input unchanged when C = 0 (2023–24: 4-bit input, 6 marks; CT2: 2-bit input with 2 half adders, then the 2's complement with up to 4 half adders).
Answer

A half adder's sum output is x ⊕ y, and a ⊕ C = a' when C = 1, a when C = 0. So one half adder per bit, inputs (ai, C), use the sum output; the carry is unused: yi = ai ⊕ C. 4-bit: four half adders (HAi: ai, C → yi). 2-bit: two.

2's complement (CT2 Q2b, 2-bit, 4 half adders): y = (a ⊕ C) + C. HA1 (a0, C): x0 = a0 ⊕ C. HA2 (x0, C): sum y0 = a0, carry c = x0·C = a0'·C. HA3 (a1, C): x1 = a1 ⊕ C. HA4 (x1, c): y1 = x1 ⊕ c. Check C = 1: a = 01 → y = 11; a = 10 → 10; a = 00 → 00; a = 11 → 01 (all 2's complements); C = 0: unchanged (checked for every input).

What to write

  1. The one line "sum of a half adder = XOR, a ⊕ C = a' when C = 1".
  2. The drawing: one HA per bit, labelled inputs (ai, C), sum → output, carry marked "unused".
  3. For the 2's complement: the four half adders with every intermediate signal named, and a 4-row check.

14. Serial parity generator

8–10 marks · 2018–19 Q6b = 2020–21 Q6b (verbatim)

2018–19 Q6(b) · 2020–21 Q6(b)
Design a serial parity generation circuit. It receives a bit stream and outputs p = 0 for an even number of 1s so far, p = 1 for an odd number.
Answer

Two states: EVEN (p = 0) and ODD (p = 1). An input 1 toggles the state; an input 0 keeps it. Moore (p is a function of the state): EVEN –0→ EVEN, EVEN –1→ ODD, ODD –0→ ODD, ODD –1→ EVEN. One flip-flop y (EVEN = 0, ODD = 1): next state y⁺ = x ⊕ y. With a T flip-flop: T = x; with D: D = x ⊕ y; with JK: J = K = x. Output p = y. Reset to EVEN before each stream. (Mealy alternative: p = x ⊕ y, which shows the parity including the current bit in the same period.) Trace x = 1 0 1 1: y = 1, 1, 0, 1 → p = 1 1 0 1.

What to write (8–10 marks)

  1. State diagram (2 circles, arrows x), state table, one flip-flop.
  2. Excitation: T = x. Equation of the output: p = y.
  3. Circuit: one T flip-flop with x on T, p = Q, reset.

15. The dual of XOR is its complement

7 marks · 2019–20 Q7b = 2022–23 Q3c (verbatim)

2019–20 Q7(b) · 2022–23 Q3(c)
Show that the dual of the exclusive-OR is equal to its complement.
Answer

x ⊕ y = xy' + x'y. Dual (swap + and ·, keep literals): (x + y')(x' + y). Expand: xx' + xy + x'y' + yy' = 0 + xy + x'y' + 0 = xy + x'y'. Complement of x ⊕ y: (xy' + x'y)' = (x' + y)(x + y') = xy + x'y' (same steps). So the dual equals the complement: the XNOR. Truth table: x y = 00, 01, 10, 11: dual = 1, 0, 0, 1; complement = 1, 0, 0, 1.

16. BCD ripple down counter with D flip-flops
