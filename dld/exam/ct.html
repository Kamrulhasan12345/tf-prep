CT1 · 15 July 2026

CT1 Q1 · 5 marks
Simplify xy + x'z + yz using Boolean algebra.
Answer

yz is the consensus of xy and x'z, so it is redundant: xy + x'z. Proof: yz = yz(x + x') = xyz + x'yz; xy + xyz = xy(1 + z) = xy and x'z + x'yz = x'z(1 + y) = x'z. Write each line with its law. (Engine: x'z + xy.) Also 2024–25 Q1c (7 marks) and 2014–15.

CT1 Q2 · 3 marks
Formulate a weighted binary code for the decimal digits 0–5 with weights 4, 1, 2.
Answer

Bit order (w4, w1, w2): value = 4·b4 + 1·b1 + 2·b2.

digit012345
b4 b1 b2000010001011100110

Each digit is written as a sum of weights: 3 = 1 + 2, 5 = 4 + 1. Unused patterns: 101 (6) and 111 (7). Since 4, 2, 1 are the binary weights, the code is just binary with the middle and last bits swapped: unique, so no choice to make.

CT1 Q3 · 4 marks
How can we complement a function using the duality-based method? Show an example.
Answer

Method: (1) take the dual (swap AND and OR, swap 0 and 1, keep every literal); (2) complement each literal. The result is F'. Example F = x(y'z' + yz): dual = x + (y' + z')(y + z); complement the literals: F' = x' + (y + z)(y' + z') = x' + yz' + y'z. Check: F = 1 at 100 and 111 (x = 1 and y = z); F' (computed) is 0 exactly there (engine truth-table check, all 8 rows). Why it works: F'(x1..xn) = dual(F)(x1'..xn'), so complementing every literal of the dual gives F'.

CT1 Q4 · 4 marks
Two implementations of the same expression need the same number of gates and the same number of gate inputs but differ in the number of logic levels. Which do you prefer? Justify.
Answer

The one with fewer levels (two-level SOP/POS rather than multilevel). Propagation delay = sum of the gate delays on the longest path, so fewer levels is faster. The cost (gates and gate inputs) is equal, so there is no penalty. Two-level forms also map directly onto NAND-NAND or NOR-NOR with one gate type. (Caveat to mention in one line: multilevel can save fan-in or gates in other circuits.)

CT1 Q5 · 4 marks
Write the steps to perform subtraction M − N using radix complement.
Answer
  1. Take the r's complement of N (n digits): rn − N (binary: invert and add 1; decimal: 9's complement + 1).
  2. Add it to M: sum = M + rn − N.
  3. If an end carry occurs (M ≥ N): discard it; the sum is M − N.
  4. If no end carry (M < N): the result is negative: take the r's complement of the sum and put a minus sign in front.

Example (ma'am's slide): 5623 − 65438 (five digits: 05623 + 34562): 10's complement of 65438 = 34562; 05623 + 34562 = 40185, no carry → −(10's complement of 40185) = −59815.

Simplify F(A,B,C,D,E) = Σ(0,2,5,7,8,16,18,21) with don't-cares d(10, 31) using a K-map (skeleton given). (i) Identify all prime implicants. (ii) Obtain the minimum SOP.
Answer

Groups: {0, 2, 8, 10(d)} (A = 0, C = 0, E = 0); {0, 2, 16, 18} spans the two maps (B = 0, C = 0, E = 0); {5, 7} (A'B'CE); {5, 21} spans the maps (B'CD'E). Minterm 31 is a lone don't-care with no neighbour, and {5, 7, 21, 23} is not allowed because 23 is neither 1 nor d.

(i) Prime implicants (4): A'B'CE, B'CD'E, A'C'E', B'C'E'. (ii) All four are essential (responsible minterms: 8 for A'C'E', 16 and 18 for B'C'E', 7 for A'B'CE, 21 for B'CD'E), so F = A'C'E' + B'C'E' + A'B'CE + B'CD'E. Minterm 10 is used (inside A'C'E'), 31 is not used.

CT2 Q2(a) · 4 marks · Q2(b) · 4 marks
Using only 2 half adders, design a circuit that outputs the 1's complement of a 2-bit input a1a0 when C = 1 and passes it unchanged when C = 0. (b) Modify it so that C = 1 gives the 2's complement; up to 4 half adders, no other gates.
Answer

(a) yi = ai ⊕ C. A half adder's sum is x ⊕ y: HA1 (a1, C) → y1; HA2 (a0, C) → y0. The carries are unused.

(b) y = (a ⊕ C) + C. HA1 (a0, C): x0 = a0 ⊕ C. HA2 (x0, C): sum y0 = a0, carry c = x0·C = a0'·C. HA3 (a1, C): x1 = a1 ⊕ C. HA4 (x1, c): y1 = x1 ⊕ c (its carry is the overflow, unused). C = 1: 00→00, 01→11, 10→10, 11→01 (the 2's complements); C = 0 unchanged (checked for all 8 input combinations). Same as 2023–24 Q4(a) with 4 bits. Repeats page, section 11.

CT1 (MMI)

MMI CT1 Q1 · 4 marks
Write the steps of subtraction using 2's complement.
Answer
  1. Write N with the same number of bits as M (n bits); take its 2's complement (invert all bits, add 1).
  2. Add M and the 2's complement of N.
  3. End carry 1: discard it; the result is M − N (M ≥ N).
  4. No end carry: M < N; the result is the 2's complement of the sum, with a minus sign.

Example 11010 − 1101 (26 − 13): 2's complement of 01101 = 10011; 11010 + 10011 = 1 01101 → carry, discard → 01101 = 13.

MMI CT1 Q3 · 8 marks
F = xy'z + x'y'z + w'xy + wx'y + wxy. Use Boolean algebra to simplify to a minimum number of literals and draw the logic diagram.
Answer

xy'z + x'y'z = y'z(x + x') = y'z. w'xy + wxy = xy(w' + w) = xy. Remaining: wx'y. So F = y'z + xy + wx'y. Then xy + wx'y = y(x + wx') = y(x + w) = xy + wy. F = y'z + xy + wy (6 literals). Engine: y'z + xy + wy.

Circuit: AND(y', z), AND(x, y), AND(w, y), then a 3-input OR; one inverter for y'.

CT2 (MMI)

MMI CT2 Q1 · 8 marks
Why isn't XOR a universal gate? If one input of a NAND gate is 1, what is the output? Why are NAND and NOR gates preferable in fault-tolerant systems?
Answer

XOR is not universal: XOR is linear (mod 2): any circuit made only of XOR gates computes a parity of its inputs, so it can never produce AND, OR or a constant 1 (all-zero input gives 0). It cannot make NOT either unless a constant 1 is supplied. NAND with one input 1: (x·1)' = x', an inverter. Fault tolerance (likely intended answer): they are universal, so one gate type builds every function; a spare NAND (or NOR) can replace any failed gate, and fewer distinct component types are needed (simpler redundancy and testing); uniform two-level NAND-NAND logic has short, regular paths. State this as your reasoning, the question is open-ended.

CT3 (MN)

MN CT3 Q1 · 8 marks
Implement ¬(P → (Q ∨ S)) → R using an 8 × 1 MUX.
Answer

P → X = P' + X. So P → (Q ∨ S) = P' + Q + S, and its negation is P·Q'·S'. Then (P Q' S') → R = (P Q' S')' + R = P' + Q + S + R. This is 0 only for P = 1, Q = R = S = 0 (minterm 8 of PQRS), so F = Σ(all except 8). Four variables on an 8 × 1 MUX: P, Q, R on S2 S1 S0, S on the data lines. Engine: I0..I7 = 1, 1, 1, 1, S, 1, 1, 1. Only PQR = 100 (I4) depends on S: I4 = S, all others 1. No extra gates.

CT4 (RZS, 20 marks)

RZS CT4 Q1 · 6 marks
What is the race-around condition in a JK flip-flop? How does the master-slave configuration resolve it?
Answer

Race-around: with J = K = 1 a level-triggered JK flip-flop toggles. While the clock stays 1 for longer than the propagation delay tpd of the loop, the toggled Q feeds back and toggles it again, repeatedly: the output oscillates and the final value is unpredictable. Master-slave: two flip-flops in series. Master enabled while CLK = 1, slave while CLK = 0 (inverted clock). During CLK = 1 only the master changes and the slave holds Q, so the feedback to J, K does not change; at the falling edge the master is frozen and the slave copies it once. One toggle per clock period. (Other cures: edge triggering, or a clock pulse shorter than tpd.)

Adnan sir · "CT #1, 20 mark question" · 20–25 marks
Incompletely specified machine (NS, Z; x = 0 | x = 1): A: B,1 | D,0; B: −,− | B,0; C: E,0 | D,−; D: B,1 | A,0; E: −,− | C,1; F: −,0 | E,1. Find the implication table, maximal compatibles and incompatibles, the bounds and the minimal machine.
Answer

Compatible pairs: AB, BC, AD, BD (AB and BD imply each other and BD/AB: a cycle, so both stay). Maximal compatibles: (ABD) (BC) (E) (F). Maximal incompatibles: (ACEF) (CDEF) (BEF). Upper bound u = min(6, 4) = 4; lower bound l = max(4, 4, 3) = 4. l = u, so no trial and error: the maximal compatibles are the minimal machine (4 states α = (ABD), β = (BC), γ = E, δ = F):

(ABD)(ABD), 1(ABD), 0
(BC)E, 0(ABD), 0
E–(BC), 1
F–, 0E, 1

This is the same answer as in his notes. The three properties to state: covering (every state in some set), closed (every implied set inside a chosen set), minimum. Full method on the repeats page.
