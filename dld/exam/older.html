1. Proofs and Boolean algebra (priority: recent papers barely ask these)

Pattern: the old papers ask for a named proof (5-10 marks). Write every line; each line is a mark. Cite the law beside each step.

What to write (any algebraic proof, 5-10 marks)

  1. "To prove: LHS = RHS". Start from one side only and finish at the other side. Never "move terms across the equals sign".
  2. One transformation per line, the law named in the margin (absorption, consensus, distributive, complement x + x' = 1, identity).
  3. If a truth table is allowed, do it as well: all 2n rows, both sides computed, "columns equal, so proved".
  4. A final line: "Hence LHS = RHS. Q.E.D."
2014–15 · QB #11 · 8 marks · also CT1 2026 Q1 and 2024–25 Q1c (xy + x'z + yz)
State and prove the consensus theorem using Boolean algebra.
Answer

Statement. xy + x'z + yz = xy + x'z. The term yz (the consensus of xy and x'z) is redundant. Dual: (x + y)(x' + z)(y + z) = (x + y)(x' + z).

Proof.

  1. xy + x'z + yz = xy + x'z + yz(x + x')   (x + x' = 1, identity)
  2. = xy + x'z + xyz + x'yz   (distribute)
  3. = (xy + xyz) + (x'z + x'yz)   (regroup)
  4. = xy(1 + z) + x'z(1 + y)   (factor)
  5. = xy + x'z   (1 + z = 1, 1 + y = 1). Q.E.D.

Dual proof. By the duality principle, the dual of a true identity is true. Or directly: (x + y)(x' + z) = xz + x'y + yz (x·x' = 0), and multiplying by (y + z) gives back xz + x'y + yz.

Engine check: x'z + xy.

2015–16 · QB #7 · 10 marks
Prove: (x + y)(x' + z)(y + z) = (x + y)(x' + z).
Answer

This is the dual of the consensus theorem.

  1. LHS = (x + y)(x' + z)(y + z + x·x')   (y + z = y + z + xx', since xx' = 0)
  2. = (x + y)(x' + z)(x + y + z)(x' + y + z)   (distributive: A + BC = (A + B)(A + C))
  3. (x + y)(x + y + z) = x + y   (absorption: P(P + z) = P with P = x + y)
  4. (x' + z)(x' + y + z) = x' + z   (absorption, P = x' + z)
  5. So LHS = (x + y)(x' + z) = RHS. Q.E.D.
2011–12 · QB #16 · 5 marks
Prove that x(x + y) = x.
Answer

x(x + y) = x·x + x·y   (distributive) = x + xy   (x·x = x) = x·1 + x·y = x(1 + y) = x·1 = x. Q.E.D.

Truth-table check: for xy = 00, 01, 10, 11 the left side is 0, 0, 1, 1, the same as x.

2011–12 · QB #15 · 8 marks
Give an example of the non-associativity of the 3-input NOR operator.
Answer

NOR is commutative but not associative: (A ↓ B) ↓ C ≠ A ↓ (B ↓ C).

Take A = 1, B = 0, C = 0. (A ↓ B) = (1 + 0)' = 0, then 0 ↓ C = (0 + 0)' = 1. B ↓ C = (0 + 0)' = 1, then A ↓ 1 = (1 + 1)' = 0. The two groupings give 1 and 0, so NOR is not associative.

That is why a 3-input NOR is not two 2-input NORs in series: the 3-input gate is defined as (A + B + C)', which equals neither grouping. Same for NAND (2015–16 QB #25: take x = y = 1, z = 0: (x ↑ y) ↑ z = 0 ↑ 0 = 1, x ↑ (y ↑ z) = 1 ↑ 1 = 0).

2015–16 · QB #42 · 7 marks
Show that the XOR operation is not distributive over AND.
Answer

Claim to refute: x ⊕ (y·z) = (x ⊕ y)·(x ⊕ z). Counter-example x = 1, y = 1, z = 0: left = 1 ⊕ (1·0) = 1 ⊕ 0 = 1. Right = (1 ⊕ 1)(1 ⊕ 0) = 0·1 = 0. Not equal, so the law fails. (The other way round, AND is distributive over XOR: x(y ⊕ z) = xy ⊕ xz, true.)

2015–16 · QB #43 · 10 marks
Why is the XOR operation called an odd function? Convert a ⊕ b ⊕ c ⊕ d to canonical maxterm form.
Answer

a ⊕ b ⊕ c ⊕ d = 1 exactly when an odd number of inputs are 1 (XOR adds mod 2), hence "odd function". Its complement (XNOR chain) is the even function.

The minterms are the input rows with an odd number of 1s: a⊕b⊕c⊕d = Σ(1, 2, 4, 7, 8, 11, 13, 14). The maxterms are the other (even-weight) rows: F = Π(0, 3, 5, 6, 9, 10, 12, 15) = (a + b + c + d)(a + b + c' + d')(a + b' + c + d')(a + b' + c' + d)(a' + b + c + d')(a' + b + c' + d)(a' + b' + c + d)(a' + b' + c' + d'). (Each maxterm Mi has a variable complemented where bit i is 1.)

2015–16 · QB #8 · 5 marks
How many distinct Boolean functions are there of n Boolean variables?
Answer

A truth table has 2n rows. For each row the output can independently be 0 or 1. So the number of different truth tables (functions) is 2 × 2 × … (2n times) = 22n. n = 1: 4; n = 2: 16; n = 3: 256; n = 4: 65 536. Equivalently: every function is a sum of some subset of the 2n minterms, and a set of size 2n has 22n subsets.

2013–14 · QB #26 · 5 marks · 2012–13 QB #49 · 8+4+3
Define odd function, even function, don't-care conditions. (2012–13: canonical vs standard form; which is preferable for gates; which comes from a truth table.)
Answer

Odd function: 1 when an odd number of inputs are 1 (XOR chain). Even function: 1 when an even number of inputs are 1 (XNOR chain). Don't care: an input combination that never occurs, or whose output does not matter; marked X and used as 0 or 1, whichever gives the larger groups.

Canonical vs standard: canonical = every term contains all variables (sum of minterms, product of maxterms). Standard = terms may omit variables (any SOP or POS, usually minimised). All canonical forms are standard, not the reverse. (b) The standard (minimised) form: fewer gates and inputs. (c) A truth table reads off directly as the canonical sum of minterms (rows with F = 1) or product of maxterms (rows with F = 0).

2016–17 · QB #38 · 5 marks
Using NOR gates, evaluate p ⊕ (q ∨ r) ⊕ ((p ∧ q) → r).
Answer

Implication a → b = a' + b, so (p ∧ q) → r = (pq)' + r = p' + q' + r. Build the truth table over p q r: the function is 1 only for pqr = 000, 101, 111 (minterms 0, 5, 7).

Minimal SOP: p'q'r' + pr. Minimal POS: (p + r')(p + q')(p' + r). For all-NOR logic use the POS: one NOR per sum term, then one NOR to combine, then a NOR used as an inverter (NOR-NOR gives the complement, so invert once). Needs the complements p', q', r', each a NOR with tied inputs.

2011–12 · QB #84 · 10 marks
Subtract the unsigned binary numbers 11010 − 1101 using (i) 2's complement, (ii) 1's complement.
Answer

M = 11010 (26), N = 01101 (13), n = 5 bits.

(i) 2's complement. 1's complement of N = 10010, +1 = 10011. M + 10011 = 11010 + 10011 = 1 01101. End carry 1: discard it. Result +01101 = 13.

(ii) 1's complement. 1's complement of N = 10010. M + 10010 = 1 01100. End carry 1: add it back (end-around carry): 01100 + 1 = 01101 = 13.

2016–17 · QB #77 · 2 marks
Difference between r's complement and (r − 1)'s complement?
Answer

(r − 1)'s complement of an n-digit N is (rn − 1) − N: subtract each digit from r − 1 (binary: flip bits; decimal: 9's complement). r's complement is (r − 1)'s complement + 1 = rn − N (binary 2's, decimal 10's). With r's complement an end carry is discarded; with (r − 1)'s it is added back (end-around carry).

2013–14 · QB #106 · 5 marks (also 2024–25)
How do you check overflow when adding two binary numbers, signed and unsigned?
Answer

Unsigned: overflow if there is a carry out of the MSB. Signed (2's complement): overflow if the carry into the sign bit differs from the carry out of it; equivalently, two operands of the same sign give a result of the opposite sign. Adding numbers of opposite signs never overflows. Example 4-bit: 0101 + 0100 = 1001 (5 + 4 gives a negative result): carry in = 1, carry out = 0, overflow.

2011–12 · QB #35 · 6+6 marks (same function: 2017–18 Q1b, 2018–19 Q1b)
Using NOR-OR and OR-NAND, implement F(A,B,C,D) = Σ(0, 4, 8, 9, 10, 11, 12, 14). Both normal and complement inputs are available.
Answer

Minimal SOP: F = C'D' + AB' + AD'. Both forms realise this SOP (each product is made by a first-level gate of the complemented literals).

  • NOR-OR: each product is one NOR: C'D' = NOR(C, D), AB' = NOR(A', B), AD' = NOR(A', D); the second level is one OR gate.

Differentiate prime implicant and essential prime implicant of a K-map.
Answer

Prime implicant: a product term (group of 1s, size a power of 2) that cannot be enlarged. Essential PI: a PI that covers at least one 1 (its responsible minterm) that no other PI covers; it must be in every minimal cover. 2012–13 · QB #175 · 4+4 marks · 2022–23 Q7(c) sibling
Explain the undefined condition in SR flip-flops. How is it solved in JK flip-flops?
Answer

In a NOR latch S = R = 1 forces both outputs to 0, so Q = Q' = 0 (not complementary). When S and R return to 0 together the two gates race and the final state depends on which is faster: unpredictable. So S = R = 1 is forbidden. In a JK flip-flop the outputs are fed back: S = J·Q', R = K·Q. S and R can never both be 1 (Q' and Q are never both 1), and J = K = 1 becomes a defined toggle. The price is the race-around, cured by master-slave or edge triggering.

Answer

When a mechanical switch closes, the contact bounces for a few ms, so the signal makes several 0↔1 transitions: a counter would count many pulses. Fix: a single-pole double-throw switch drives the S' and R' inputs of a NAND latch (each input pulled up). The first contact with the new terminal sets (or resets) the latch; during bounce the switch is off both terminals, S' = R' = 1: hold. Only one clean transition appears at Q.

2011–12 QB #273 · 2014–15 QB #271 · 10-12 marks
Draw and explain a 4-bit binary count-up ripple counter with T flip-flops (2014–15: with D flip-flops).
Answer

Four flip-flops, FF0 clocked by CLK, each next flip-flop clocked by the previous stage's output. T version (negative-edge triggered, T = 1): CLK of FF(i+1) = Qi; Qi falling toggles Qi+1. Advantages and disadvantages of the Mealy and Moore models. Problems with redundant states (QB #240, 2012-13 and 2013-14, 6 marks).

Mealy: fewer states (output also depends on the input), reacts in the same clock period; output can glitch if the input glitches and changes asynchronously. 10. Pulse mode and fundamental mode (excitation → transition table, static-1 hazard, races: priority)

2011–12 · QB #239 · 4 marks
Restrictions on the duration of input pulses for pulse-mode circuits.
Answer

(1) Pulses must be wide enough to trigger the memory elements (at least the minimum pulse width). (2) They must be short enough that the memory changes only once: the pulse must end before the new state feeds back and could re-trigger. (3) The interval between successive pulses must be long enough for the circuit to settle. (4) Pulses never occur on two inputs at the same time.

Procedure to assign the output to unstable states of a flow table.
Answer
  1. Stable states: the output is given by the specification.
  2. An unstable entry lies between a starting stable state and the final stable state of the transition. If both have the same output, give the unstable entry that same value (no glitch).
  3. If the two outputs differ, the output of the unstable entry is a don't care (it may change early or late), unless the question says it must change quickly or slowly: then assign the new value (quick) or the old value (slow).
  4. Use the don't cares to simplify the output K-map.

2011–12 QB #264 · 2016–17 QB #261 · 4+8, 10 marks (also 2022–23 Q8a)
What is a race in fundamental-mode circuits? Explain critical and non-critical races with an example.
Answer

A race occurs when a change of input makes two or more state variables change at once; the variables change in an unpredictable order because of unequal delays. Non-critical: whatever the order, the circuit ends in the same stable state. Critical: different orders end in different stable states, so the circuit may reach the wrong one.

Example (from the question above): column x1x2 = 11, state y = 00, next state 11 (two bits). If y1 changes first the circuit passes 10 and stays at 10; if both change, it ends at 11: critical. In column 01, 11 → 00 passes through 01 or 10; both go to 00: non-critical. Cure: choose the state assignment so every transition changes one variable (adjacent codes), adding extra rows when needed (shared-row or multiple-row assignment).

What is a static-1 hazard? Give an example in an asynchronous sequential circuit.
Answer

A static-1 hazard: the output should stay 1 when one input changes, but it momentarily drops to 0 (a glitch) because two product terms that both cover the 1s switch with unequal delays: one term falls before the other rises. In an asynchronous sequential circuit such a glitch on the next-state line Y can be fed back through the delay and flip the state wrongly.

Example: Y = x1·y + x1'·x2. Take y = 1, x2 = 1, x1 = 1 → 0. Before: x1y = 1. After: x1'x2 = 1. The two 1s (minterms 111 and 011 of x1x2y... adjacent cells) are covered by different terms; the term x1y turns off before x1'x2 turns on (it passes through the inverter), so Y glitches 1 → 0 → 1. Cure: add the consensus term y·x2: Y = x1y + x1'x2 + x2y. The new term stays at 1 across the change. In general: cover every pair of adjacent 1s by a common product term (draw the K-map, add redundant overlapping groups).
