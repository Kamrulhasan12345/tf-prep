Q1(c) · 7 marks · laws and theorems

Using laws and theorems prove and simplify xy + x'z + yz = xy + x'z. (i) Apply the laws. (ii) Prove step by step that yz is redundant.

Time guide: about 5 min.

Answer
  1. yz = yz·1 = yz(x + x') (identity, complement)
  2. = xyz + x'yz (distributive)
  3. So xy + x'z + yz = xy + x'z + xyz + x'yz
  4. = xy(1 + z) + x'z(1 + y) (regroup)
  5. = xy·1 + x'z·1 = xy + x'z (1 + a = 1).

Hence yz is redundant: it is the consensus term of xy and x'z (x and x' are opposite, the remaining literals y and z). Check: the two sides have the same truth table (verified by the engine over all 8 rows).

Q2(a) · 10 marks · universal gates, cost, minimality

Why are NAND and NOR called universal gates? How is hardware cost related to Boolean simplification? If a function is already minimal, how can you verify it?

Time guide: about 10 min.

Answer

Universal: any Boolean function can be built from AND, OR, NOT. NAND alone builds all three, and so does NOR alone.

from NANDfrom NOR
NOT x(x·x)' = x'(x+x)' = x'
AND((xy)')' (NAND then NAND-as-NOT)(x' + y')' (NOR each input as NOT, then NOR)
OR(x'·y')' (NAND each input as NOT, then NAND)((x+y)')' (NOR then NOR-as-NOT)

Cost vs simplification. Each literal is a gate input and each product term is a gate. Fewer literals and terms mean fewer gates and inputs, less area, less power, shorter delay and fewer wires. Cost is measured as number of gates and gate inputs.

Is it already minimal? Draw the K-map (or run tabulation): (1) list all prime implicants; (2) every group in the cover must be a prime implicant (cannot be enlarged); (3) no group can be removed without uncovering a 1 (every chosen PI covers at least one 1 no other chosen PI covers); (4) no other cover has fewer terms, or the same terms with fewer literals. If these hold, the expression is minimal.

Q2(c) · 15 marks · POS and tabulation

Simplify F = Σ(3,4,6,7,9,11,12,14,15) to product-of-sums. What is the main purpose of the tabulation (Quine-McCluskey) method and how does it systematically help compared to K-map?

Time guide: about 15 min.

Answer

Group the 0s (minterms 0, 1, 2, 5, 8, 10, 13) and read each group as a sum term, with a variable complemented when it is 1 in the group. F = (B + D)(A + B + C)(B' + C + D') (equally minimal alternative: (B + D)(A + C + D')(B' + C + D')).

Tabulation. Purpose: to find all prime implicants and a minimum cover by a mechanical procedure that works for any number of variables and can be programmed. Compared with K-maps: K-maps depend on seeing groups visually and are practical only up to 4–5 variables; tabulation groups minterms by number of 1s, combines pairs that differ in one bit, repeats until nothing combines, then uses a prime implicant chart to pick the essential PIs and a cover. It does not miss a PI.

Q3(b) · 12 marks · carry look-ahead adder

Explain the working principle of a Carry Look-Ahead adder. Derive C1..C4 using generate and propagate.

Time guide: about 12 min.

Answer

Principle. In a ripple adder, bit i waits for the carry of bit i−1, so delay grows with n. The CLA computes every carry directly from the inputs A, B and C0 with two-level logic, so all carries are ready after about three gate delays.

Define for each bit: generate Gi = AiBi (carry produced here), propagate Pi = Ai ⊕ Bi (carry passed on). Then Ci+1 = Gi + PiCi and Si = Pi ⊕ Ci.

C1 = G0 + P0C0
C2 = G1 + P1G0 + P1P0C0
C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0
C4 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0

(Each equation is obtained by substituting the previous carry into Ci+1 = Gi + PiCi. All four were checked against a ripple adder for every input combination.)

Circuit: one XOR and one AND per bit (P, G), a look-ahead block of AND-OR gates for C1..C4, and one XOR per bit for the sum.

What to write (12 marks)

  1. Why ripple is slow, why CLA is fast.
  2. Definitions of G and P and Ci+1 = Gi + PiCi.
  3. C1, C2, C3, C4 expanded.
  4. Block diagram: P/G generators, look-ahead logic, sum XORs.

Q3(c) · 11 marks · overflow

What is overflow in binary arithmetic? Explain how overflow is detected in signed addition and subtraction, with examples.

Time guide: about 11 min.

Answer

Overflow = the true result does not fit in the n bits available, so the stored result is wrong. Unsigned: overflow is the carry out of the MSB (Cn = 1). Signed (2's complement, range −8..+7 for 4 bits): overflow happens only when two operands of the same sign give a result of the opposite sign.

Detection: V = Cn ⊕ Cn−1 (carry into the sign bit XOR carry out of it). Rules: (+) + (+) = (−) → overflow; (−) + (−) = (+) → overflow; (+) + (−) never overflows. For subtraction A − B = A + B' + 1 use the same V on the adder.

Q4(a) · 16 marks · serial shift register timing and errors

A 4-bit shift register is used for serial data transmission. (i) Analyze the timing relationship between input data, clock and output. (ii) Explain how errors may propagate in serial communication using shift registers.

Time guide: about 16 min.

Answer

(i) On every active clock edge each flip-flop copies its left neighbour and Q0 copies the serial input, so a bit moves one stage per clock. The data must be stable for set-up time before the edge and hold time after it. A bit entered at clock 1 appears at Q0 after clock 1 and at Q3 after clock 4 (four clock delay). Input 1,0,1,1,0,0 (first bit first):

Q0 shows the input one clock late, Q1 two clocks late, and so on. After 4 clocks the 4-bit word is in the register (Q3 Q2 Q1 Q0 = oldest to newest bit) and can be read in parallel (serial-in parallel-out), or taken from Q3 as serial output delayed by 4 clocks.

(ii) Error propagation:

  • A wrong bit at the input (noise at the sampling instant) is stored and then shifted through every stage; one bad bit appears at every later stage in turn, and corrupts the word when it is read.
  • A clock glitch or missing clock edge shifts one time too many or too few: all bits after it are misaligned (bit slip), so the whole rest of the word is wrong, not one bit.
  • Violating set-up or hold time can make a stage capture the old or the new value (or go metastable), and that value then moves down the chain.
  • A stuck flip-flop forces one bit position wrong in every word.
  • There is no built-in error correction: add a parity bit, CRC or framing bits to detect errors, and resynchronise the clock.
Q4(b) · 12 marks · master-slave timing and race-around

A clocked sequential circuit uses master-slave configuration. (i) Explain how signal propagation through master and slave stages affects timing. (ii) Analyze and justify the possibility of race-around under non-ideal clock (finite rise and fall time).

Time guide: about 12 min.

Answer

(i) A master-slave flip-flop is two latches in series with opposite enables. Clock high: the master is transparent and follows J, K (using the slave's frozen Q), the slave is closed, so Q does not change. Clock low: the master is closed (holds the value it captured at the falling edge) and the slave copies the master, so Q changes once per clock pulse, at the falling edge. The output can never feed back to the input during the same pulse, because the master and the slave are never open together. Timing: set-up before the clock falls, hold after; clock-to-Q delay = slave delay; the clock period must exceed master delay + slave delay + set-up.

(ii) Race-around with real clock edges. Ideal: the slave opens exactly when the master closes. With finite rise and fall time, the clock (and the inverted clock that enables the slave) crosses its threshold slowly, and the inverter adds delay. For a short time both latches may be partly open (overlap). With J = K = 1 the new Q travels back through the open master, the master toggles again, and Q can toggle more than once: race-around returns. Also, while the clock is high the master can catch a glitch on J or K ("1s catching") even if the input returns to its correct value before the edge.

Remedies: use an edge-triggered flip-flop (samples only at the edge); make sure the clock edges are fast and the master closes before the slave opens (non-overlapping clocks); keep the clock pulse narrower than the loop delay in an unclocked JK; keep J, K stable while the clock is high.

Working: three output states: logic 0, logic 1 and high impedance (Hi-Z, output electrically disconnected). With C = 1 it acts as a buffer; with C = 0 the output floats and does not load or drive the line.
