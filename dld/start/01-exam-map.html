What the exam asks, and how to answer

I analysed the 8 term finals from 2017–18 to 2024–25 question by question, plus the 316-question bank going back to 2011–12, both teachers' class notes, and your 2026 class tests.

1. The paper

  • 210 marks, 3 hours, two sections in separate scripts. Each section: 4 questions of 35 marks, answer 3.
  • Since 2022–23 the first question of each section (Q1 and Q5) is compulsory. So you choose 2 of the remaining 3 in each section.
  • Section A = combinational (Tanzima ma'am's half). Section B = sequential (Adnan sir's half). In 2024–25 a few sequential parts slipped into A, so learn both halves anyway.
  • Time: 6 questions in 180 minutes = 30 minutes per 35-mark question, about 1 minute per mark. A 20-mark design gets 17 minutes, then move on.

2. What your teachers told you

Adnan sir, last lecture (Lec 19, 26 Sep 2026) wrote this TF outline on the board: "TF: 1 set → Fundamental mode, State assignment · State minimisation · Synchronous sequential · Pulse mode, counter". That is four sets, matching Section B's four questions. Expect:

  1. a fundamental-mode question (primitive flow table → reduced table → race-free state assignment),
  2. a state-minimisation question (partitions / implication table / compatibles with bounds),
  3. a synchronous design (sequence detector or word problem or analysis; Mealy/Moore),
  4. pulse mode plus a counter part.

He also said "see Nelson for practice".

Tanzima ma'am gave no explicit TF hints in the notes, but your CT2 Q2 is almost word for word 2023–24 Q4(a) (the 1's complement with half adders). She reuses past TF questions. The solved papers are the best predictor for Section A.

4. How to choose your questions

  1. Read all four questions of the section first (2 minutes). Write the compulsory one first while you are fresh.
  2. Pick the two where you know the method for the biggest part. A 20–25 mark part decides the question; small 5–7 mark theory parts are bonus.
  3. Section B: the fundamental-mode question is the longest to write. If you are fast at it, it is safe marks; if not, it is the one to leave.
  4. Never leave a chosen question blank at the end: write the tables you know (truth table, state table, excitation table). Method marks are real.

5. How to write any design answer

The order that collects the marks

  1. Restate the design in one or two lines: inputs, outputs, what 1 means. State every assumption (enable polarity, MSB, initial state, overlapping or not).
  2. Truth table or state diagram first, then the state table.
  3. Tables in the standard layout: transition table with the state assignment written beside it, then the excitation table with one column per flip-flop input.
  4. K-maps, one per output and per flip-flop input, with the groups circled and the equation under each.
  5. Final equations in a box.
  6. The circuit diagram, fully labelled: every input, output, select line, enable, clock, flip-flop name (Q₁, Q₀). Unlabelled wires lose marks.
  7. One line of verification: "check: input 1011 gives …", or "unused state 6 → 5, so the counter self-starts".
