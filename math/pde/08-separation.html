Separation of variables: wave, heat, Laplace

The last PDE question (Q8, 17 to 25 marks) is a boundary value problem for the vibrating string or the heated bar, solved by separation of variables and a Fourier sine series. It has come in every MATH 241 paper (2022-23 8(b), 2023-24 8(a) and 8(b), 2024-25 8(a) and 8(b)). You write the same skeleton every time; only the integral changes.

Types. (1) wave, fixed ends, initial shape (and velocity); (2) heat, ends at 0; (3) heat, ends at non-zero temperatures (steady state plus transient); (4) heat, insulated ends; (5) Laplace on a rectangle; (6) d'Alembert on the whole line. every year weak spot Types 3 to 6 are not in Farid sir's notes; type 3 came in 2023-24, the rest are in the syllabus (not taught in class). Mandatory: 7 cards. Farid sir only read the 1-D wave equation.

1. The whole method on one page

  1. Write \(u=X(x)\,T(t)\) and substitute. Divide so that all \(x\) is on one side, all \(t\) on the other. Both sides must equal a constant \(\mu\).
  2. Boundary conditions give \(X\)'s conditions. \(u(0,t)=X(0)T(t)=0\) for all \(t\); \(T\not\equiv0\) (else \(u\equiv0\)), so \(X(0)=0\). Likewise \(X(L)=0\).
  3. The three cases for \(\mu\). Solve \(X''=\mu X\) with \(X(0)=X(L)=0\) for \(\mu\gt0\), \(\mu=0\), \(\mu\lt0\). Only \(\mu\lt0\) gives a non-zero \(X\). Write all three; the marks are there.
  4. Solve for \(T\) with the same \(\mu=-\lambda^2\), \(\lambda_n=n\pi/L\).
  5. Superpose \(u=\sum u_n\) (the PDE and the boundary conditions are linear and homogeneous).
  6. Initial conditions fix the constants: Fourier sine series coefficients, or match terms if \(f\) is already a sum of sines.
  7. Interpret (say what the answer means physically; asked in 2022-23 and 2016-17).

Standard integrals (all checked by computer algebra)

Here \(n=1,2,3,\dots\), so \(\sin n\pi=0\) and \(\cos n\pi=(-1)^n\). Note \(1-(-1)^n\) is 2 for odd \(n\) and 0 for even \(n\).

Integral over \((0,L)\)Value
\(\displaystyle\int_0^L\sin\frac{m\pi x}L\sin\frac{n\pi x}L\,dx\)\(0\) if \(m\ne n\); \(\dfrac L2\) if \(m=n\) (this is why the coefficient has \(\frac2L\))
\(\displaystyle\int_0^L\sin\frac{n\pi x}L\,dx\)\(\dfrac{L\,(1-(-1)^n)}{n\pi}\)
\(\displaystyle\int_0^Lx\sin\frac{n\pi x}L\,dx\)\(\dfrac{L^2(-1)^{n+1}}{n\pi}\)
\(\displaystyle\int_0^L(L-x)\sin\frac{n\pi x}L\,dx\)\(\dfrac{L^2}{n\pi}\)
\(\displaystyle\int_0^L(Lx-x^2)\sin\frac{n\pi x}L\,dx\)\(\dfrac{2L^3(1-(-1)^n)}{n^3\pi^3}\)
\(\displaystyle\int_0^Lx\cos\frac{n\pi x}L\,dx\) (insulated ends)\(\dfrac{L^2((-1)^n-1)}{n^2\pi^2}\)

2. Wave equation: vibrating string, fixed ends

Problem
\(u_{tt}=c^2u_{xx}\), \(0\lt x\lt L\), \(t\gt0\); \(u(0,t)=u(L,t)=0\); \(u(x,0)=f(x)\) (initial shape); \(u_t(x,0)=g(x)\) (initial velocity). \(u\) is the transverse displacement.
Solution
\(u=\displaystyle\sum_{n\ge1}\Big(E_n\cos\frac{n\pi ct}L+F_n\sin\frac{n\pi ct}L\Big)\sin\frac{n\pi x}L\), with \(E_n=\dfrac2L\displaystyle\int_0^Lf\sin\frac{n\pi x}Ldx\), \(F_n=\dfrac2{n\pi c}\displaystyle\int_0^Lg\sin\frac{n\pi x}Ldx\).

Released from rest means \(g=0\), so \(F_n=0\) (the \(\sin\) in time never appears).

Recipe · wave

  1. State the problem with all four conditions, and identify \(c,\ L,\ f,\ g\).
  2. \(u=XT\): \(\dfrac{X''}X=\dfrac{T''}{c^2T}=\mu\).
  3. Three cases for \(X\) (below).
  4. \(T''+c^2\lambda^2T=0\): \(T=E\cos c\lambda t+F\sin c\lambda t\), \(\lambda=n\pi/L\).
  5. \(u=\sum(E_n\cos+F_n\sin)\sin\). Put \(t=0\): \(f=\sum E_n\sin\), so \(E_n\) is the sine coefficient of \(f\). Differentiate in \(t\), put \(t=0\): \(g=\sum\frac{n\pi c}LF_n\sin\).
  6. Integrate by parts for \(E_n\) (full lines). If \(f\) is already \(\sum a\sin\frac{n\pi x}L\), read \(E_n\) off.
  7. Write \(u\), then the interpretation.

What to write

The four conditions; "let \(u=X(x)T(t)\)"; \(X''/X=T''/c^2T=\mu\); "since \(u(0,t)=u(L,t)=0\) for all \(t\), \(X(0)=X(L)=0\)"; Case 1, Case 2, Case 3 each with its conclusion; the \(T\) equation; the superposition; "\(u(x,0)=f\) gives \(E_n=\dots\)"; the integral done in full; the final series (write a few terms); the interpretation.

Traps

  • Constant of separation. Writing \(\mu=\lambda^2\) and then taking \(X=\cos\lambda x\) is wrong. For \(X''=\lambda^2X\) the solutions are exponentials. The trig case is \(\mu=-\lambda^2\).
  • Frequency in time uses \(c\). \(\cos\frac{n\pi ct}{L}\), not \(\cos\frac{n\pi t}L\). With \(c=4,\ L=2\): \(\cos2n\pi t\).
  • Which coefficient. Initial shape \(\to E_n\) (cosine in time). Initial velocity \(\to F_n\), and divide by \(\frac{n\pi c}L\). Forgetting the division is the usual error.
  • Even \(n\) give \(E_n=0\) for a symmetric shape like \(x(2-x)\). Write the sum over odd \(n\) only if you are sure; or keep \(1-(-1)^n\).
  • If \(f\) is a finite sum of sines, do not integrate, match terms, but convert \(\sin\pi x\) on \((0,2)\) to \(\sin\frac{2\pi x}2\), i.e. \(n=2\) (another common slip).
  • The note-takers' class example said \(E_n=0\) for all \(n\); it is wrong, \(E_2=1\) (see the class card).

3. Heat equation: bar with ends at 0

Problem
\(u_t=c^2u_{xx}\), \(0\lt x\lt L\); \(u(0,t)=u(L,t)=0\); \(u(x,0)=f(x)\). (If given as \(4u_t=u_{xx}\), then \(u_t=\frac14u_{xx}\), \(c^2=\frac14\). If no constant is given, write \(c^2\) for the diffusivity.)
Solution
\(u=\displaystyle\sum_{n\ge1}b_n\sin\frac{n\pi x}Le^{-c^2n^2\pi^2t/L^2}\), \(b_n=\dfrac2L\displaystyle\int_0^Lf\sin\frac{n\pi x}Ldx\).

Recipe · heat, ends at 0

  1. \(u=XT\): \(\dfrac{X''}X=\dfrac{T'}{c^2T}=\mu\).
  2. Three cases for \(X\) with \(X(0)=X(L)=0\): the same as for the wave equation. Only \(\mu=-\lambda^2\), \(X_n=\sin\frac{n\pi x}L\).
  3. \(T'=-c^2\lambda^2T\): \(T_n=e^{-c^2n^2\pi^2t/L^2}\) (only one constant, there is just one time derivative).
  4. Superpose; \(u(x,0)=f\): match terms or find \(b_n\).
  5. Interpret.

Traps

  • For \(\mu=\lambda^2\gt0\) the time factor is \(e^{c^2\lambda^2t}\), which blows up. That is physically impossible for a bar with ends at 0 (and \(X\) is zero anyway). Mention both.
  • The exponent is \(-c^2\lambda_n^2t\), with \(\lambda_n=n\pi/L\), so \(-\dfrac{c^2n^2\pi^2t}{L^2}\). Write it once in general and substitute.
  • A note-taker once wrote \(T=e^{-\lambda^2k^2T}\); it is \(e^{-c^2\lambda^2t}\).
  • With matching terms, the \(n\) is found from \(\sin\frac{n\pi x}L\), e.g. \(L=2\): \(\sin\frac{5\pi x}2\) is \(n=5\). Then the time factor uses the same \(n\).

4. Heat, ends at non-zero temperatures 2023-24 8(b)

If the ends are held at \(u(0,t)=T_1\), \(u(L,t)=T_2\), the boundary conditions are not homogeneous, so separation fails directly. Split off the steady state.

Recipe · steady state plus transient

  1. Steady state \(u_s(x)\): no \(t\)-dependence, so \(u_s''=0\), \(u_s=ax+b\) with \(u_s(0)=T_1,\ u_s(L)=T_2\): \(u_s=T_1+(T_2-T_1)\dfrac xL\).
  2. Put \(u=u_s(x)+w(x,t)\). Since \(u_s''=0\) and \(u_s\) is constant in \(t\), \(w_t=c^2w_{xx}\), \(w(0,t)=w(L,t)=0\), \(w(x,0)=f(x)-u_s(x)\).
  3. Solve for \(w\) exactly as in section 3: \(w=\sum b_n\sin\frac{n\pi x}Le^{-c^2n^2\pi^2t/L^2}\), \(b_n=\frac2L\int_0^L(f-u_s)\sin\frac{n\pi x}Ldx\).
  4. \(u=u_s+w\). As \(t\to\infty\), \(w\to0\) and \(u\to u_s\).
  5. "The bar was in steady state before": then \(f\) is the old steady line (\(u''=0\) with the old end temperatures).

5. Heat, insulated ends not taught, not asked yet

Insulated ends mean no heat flows through them: \(u_x(0,t)=u_x(L,t)=0\). Now the condition is on \(X'\), and the three cases change: \(\mu=0\) survives.

Solution
\(u=\dfrac{a_0}2+\displaystyle\sum_{n\ge1}a_n\cos\frac{n\pi x}Le^{-c^2n^2\pi^2t/L^2}\), \(a_n=\dfrac2L\displaystyle\int_0^Lf\cos\frac{n\pi x}Ldx\) (including \(n=0\)).

8. Past questions: solve every one

Each card below is a complete answer: separation, three cases, coefficient integral, final series, and the sentence on what it means. Do the five paper questions first, then the two class examples.

One-minute summary

  • \(u=XT\), \(X''/X=\mu\). \(X(0)=X(L)=0\): \(\mu\gt0\to X\equiv0\) (exponentials); \(\mu=0\to X=Ax+B\equiv0\); \(\mu=-\lambda^2\to X=\sin\frac{n\pi x}L\), \(\lambda=\frac{n\pi}L\).
  • Wave: \(u=\sum\big(E_n\cos\frac{n\pi ct}L+F_n\sin\frac{n\pi ct}L\big)\sin\frac{n\pi x}L\); \(E_n=\frac2L\int_0^Lf\sin\); \(F_n=\frac2{n\pi c}\int_0^Lg\sin\).
  • Heat: \(u=\sum b_n\sin\frac{n\pi x}Le^{-c^2n^2\pi^2t/L^2}\), \(b_n=\frac2L\int_0^Lf\sin\). Non-zero ends: \(u=u_s+w\), \(u_s=T_1+(T_2-T_1)\frac xL\), \(w(x,0)=f-u_s\).
  • \(\int_0^L(Lx-x^2)\sin\frac{n\pi x}L=\frac{2L^3(1-(-1)^n)}{n^3\pi^3}\); \(\frac2L\int_0^Lx\sin\frac{n\pi x}L=\frac{2L(-1)^{n+1}}{n\pi}\); \(\frac2\pi\int_0^\pi(\pi-x)\sin nx=\frac2n\).
  • Finite sine sum as \(f\): match terms (\(\sin\pi x\) on \((0,2)\) is \(n=2\)). Insulated ends: cosine series with a constant term. Laplace: \(\sin\frac{n\pi x}a\sinh\frac{n\pi y}a\).
  • d'Alembert: \(u=\frac12[f(x-ct)+f(x+ct)]+\frac1{2c}\int_{x-ct}^{x+ct}g\).
  • Interpretation: standing waves \(\sin\frac{n\pi x}L\) with frequency \(\frac{nc}{2L}\) (wave); modes decay like \(e^{-c^2n^2\pi^2t/L^2}\) to the end temperature or steady state (heat).
