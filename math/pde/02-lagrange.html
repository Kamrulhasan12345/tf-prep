Type A · General solution of \(Pp+Qq=R\)

Lagrange equation
\(P(x,y,z)\,p+Q(x,y,z)\,q=R(x,y,z)\), linear in \(p,q\).
Auxiliary equations
\(\dfrac{dx}{P}=\dfrac{dy}{Q}=\dfrac{dz}{R}\).
General solution
If \(u(x,y,z)=c_1\) and \(v(x,y,z)=c_2\) are two independent integrals of the auxiliary equations, the general solution is \(\phi(u,v)=0\) (or \(F(u,v)=0\)), \(\phi\) an arbitrary function.
Ratio rule
\(\dfrac ab=\dfrac cd=\dfrac{\lambda a+\mu c}{\lambda b+\mu d}\) for any multipliers \(\lambda,\mu\) (and the same with three ratios).

Why it works: \(\phi(u,v)=0\) gives (Chapter 1) \(Pp+Qq=R\) with \(P=u_yv_z-u_zv_y\) etc., and these are exactly proportional to the direction \((P,Q,R)\) that lies in both level surfaces \(u=c_1\), \(v=c_2\). So the solution surface is made of curves \(u=c_1,\ v=c_2\).

The six ways to get an integral (his "Methods")

  1. Multipliers (Method 1). Choose \(l,m,n\) (functions of \(x,y,z\)) with \(lP+mQ+nR=0\). Then \(l\,dx+m\,dy+n\,dz=0\). If this is an exact differential \(du=0\), you have \(u=c_1\). Common sets: \((1,1,1)\), \((x,y,z)\), \((\tfrac1x,\tfrac1y,\tfrac1z)\), \((y,x,-1)\), \((x,y,-1)\), \((1,-1,0)\).
  2. Take two ratios that separate. Often \(\dfrac{dx}{P}=\dfrac{dy}{Q}\) involves only \(x,y\) (or two variables), and integrates at once.
  3. Use one integral to find the other. Having found \(u=c_1\), use it to eliminate one variable from another pair of ratios, then integrate. This is the "substitution" method on the slides.
  4. Exact differentials by choosing multipliers that make numerator \(d(\cdot)\) and denominator a recognisable total.
  5. Linear ODE in one variable along the curve (for instance \(\dfrac{dz}{dy}+\dfrac zy=2\)).
  6. Homogeneous ODE in \(x,y\): put \(y=vx\).

Recipe · \(\phi(u,v)=0\)

  1. Write the auxiliary equations \(\dfrac{dx}{P}=\dfrac{dy}{Q}=\dfrac{dz}{R}\) in full (this earns a mark by itself).
  2. Look for a multiplier set with \(lP+mQ+nR=0\). Check it by multiplying out before using it.
  3. Integrate \(l\,dx+m\,dy+n\,dz=0\) to get \(u=c_1\).
  4. For the second integral try another multiplier set. If none works, use \(u=c_1\) to remove one variable from a pair of ratios and integrate (Method 3).
  5. Check independence: \(u\) and \(v\) must not be functions of each other.
  6. Write \(\boxed{\phi(u,v)=0}\) (the answer is a relation, not a formula for \(z\)).

What to write

The statement "auxiliary equations \(\frac{dx}P=\frac{dy}Q=\frac{dz}R\)". For each multiplier set, the line \(lP+mQ+nR=0\) (show the cancellation). The integrated result with its constant. Finally: "the general solution is \(\phi(c_1,c_2)=0\), i.e. \(\phi(u,v)=0\)".

Traps

  • A multiplier set that does not satisfy \(lP+mQ+nR=0\). Multiply out every time.
  • Two integrals that are not independent (for example \(u\) and \(u^2\)).
  • Dropping a factor when integrating the logs: \(\dfrac{dx}x+\dfrac{dy}y+\dfrac{dz}z=0\) gives \(xyz=c\), and \(\dfrac3x,\dfrac3y,\dfrac1z\) gives \(x^3y^3z=c\) (the 3 becomes a power).
  • Leaving the answer as \(u=c_1,v=c_2\). The general solution is \(\phi(u,v)=0\).

Type B · Integral surface through a given curve

This is the every-year question: "find the integral surface of \(Pp+Qq=R\) which contains the curve \(\dots\)". The surface is the one member of the family \(\phi(u,v)=0\) that passes through the curve.

Recipe · surface through a curve

  1. Find two independent integrals \(u(x,y,z)=c_1\), \(v(x,y,z)=c_2\) of the auxiliary equations. (Use Type A.)
  2. Write the curve either as parametric \(x=x(t),\ y=y(t),\ z=z(t)\), or as two equations (for example \(x=1,\ y=0\), or \(z=1,\ x^2+y^2=1\)).
  3. Substitute the curve into \(u=c_1\) and \(v=c_2\). This turns \(c_1,c_2\) into functions of \(t\) (or of one variable).
  4. Eliminate \(t\) between them to get one relation \(G(c_1,c_2)=0\).
    • Parametric curve: solve one of \(c_1(t),c_2(t)\) for \(t\), put into the other.
    • Curve given by two equations: use both curve equations to remove two of \(x,y,z\); what is left should be one free variable in each of \(c_1,c_2\). Remove it. Use the curve's equations as identities (for \(x^2+y^2=1\), the combination \(\frac12[(x+y)^2+(x-y)^2]\) equals 1).
  5. Replace \(c_1\to u\) and \(c_2\to v\): \(G(u,v)=0\) is the surface. Simplify.
  6. Check. Put the curve's points back into the final surface; the left side must vanish.

What to write

The two integrals \(u=c_1\), \(v=c_2\) with the multipliers; the curve equations; the substituted values of \(c_1,c_2\); the elimination line \(G(c_1,c_2)=0\); the final surface in \(x,y,z\), boxed. A one-line check at the end earns trust.

Traps

  • Use the curve to write \(c_1,c_2\) as functions of one variable. If the curve is \(z=1,\ x^2+y^2=1\), then \(x+y\) and \(y-x\) are tied by \((x+y)^2+(y-x)^2=2\); that is the relation to use, not a parametrisation by hand.
  • Putting \(c_1,c_2\) back as the wrong integrals (for instance replacing \(c_2\) by \(v\) with a different sign convention). Define \(u,v\) once and keep them.
  • His slide Application 1 and Application 3 have printed answers that are wrong (see the cards below). Learn the corrected ones.
  • Forgetting the check. A surface that does not contain the curve is a very common lost mark.

One-minute summary

  • \(Pp+Qq=R\): auxiliary equations \(\dfrac{dx}P=\dfrac{dy}Q=\dfrac{dz}R\); two independent integrals \(u=c_1,v=c_2\); answer \(\phi(u,v)=0\).
  • Multiplier sets to try: \((1,1,1)\), \((x,y,z)\), \((\tfrac1x,\tfrac1y,\tfrac1z)\), \((y,x,-1)\), \((x,y,-1)\). Always check \(lP+mQ+nR=0\).
  • Second integral: use the first one to eliminate a variable (Method 3), a linear ODE, or a homogeneous ODE.
  • Surface through a curve: substitute the curve into \(u=c_1\), \(v=c_2\), eliminate the parameter to get \(G(c_1,c_2)=0\), then \(c_1\to u,\ c_2\to v\). Check the curve lies on it.
