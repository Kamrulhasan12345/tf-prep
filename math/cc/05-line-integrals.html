Complex line integrals

Compute \(\int_C f(z)\,dz\) by writing the path as a function of one real parameter. A line-integral question came in every one of the three MATH 241 papers (2022-23, 2023-24, 2024-25), and two of them were her own class examples.

Types. Straight segments and polylines, arcs of circles, \(\bar z\,dz\), \(\int dz/z\) on a semicircle (marked "TF" in her notes). every year Mandatory: 4 cards. A short extra section covers the ML-inequality, which came in 2024-25 but she never taught.

The method

Complex line integral
\(\displaystyle\int_C f(z)\,dz=\int_C(u\,dx-v\,dy)+i\int_C(v\,dx+u\,dy)\) where \(f=u+iv\) and \(dz=dx+i\,dy\). This is her boxed formula.
Parametrised form
If \(C\) is \(z=z(t)\), \(a\le t\le b\), then \(\displaystyle\int_C f(z)\,dz=\int_a^b f\big(z(t)\big)\,z'(t)\,dt\). This is the one that is fastest in the exam.

Recipe · line integral by parametrisation

  1. Parametrise each piece. Straight segment from \(z_1\) to \(z_2\): \(z=z_1+t(z_2-z_1)\), \(0\le t\le1\), \(dz=(z_2-z_1)\,dt\). Circle: \(z=c+re^{i\theta}\), \(dz=ire^{i\theta}d\theta\). A curve given as \(y=g(x)\): take \(x=t\), \(y=g(t)\).
  2. Put \(x(t),y(t)\) into \(f\). For \(\bar z\) use \(x-iy\). Never leave \(z,\bar z\) and \(x,y\) mixed.
  3. Multiply by \(z'(t)\) and integrate from the start value to the end value of \(t\).
  4. If the path has several pieces, integrate each piece and add them.
  5. If \(f\) is analytic (e.g. \(z^2+3z\)) you may use an antiderivative: \(\int_{z_1}^{z_2}f\,dz=F(z_2)-F(z_1)\). It does not work for \(\bar z\) or for \(3xy+iy^2\).

What to write

The parametrisation of every piece with its \(t\)-range, \(dz\), the integrand after substitution, the integral and its value, then the sum. For an arc, state the direction ("from \(-1\) to \(1\)"). Box the final complex number.

Traps

  • Not adding the pieces of a polyline (a senior solution did the legs and never summed them).
  • Wrong direction. Reversing a path flips the sign of the integral, so \(\int_{-1\to1}\) and \(\int_{1\to-1}\) differ in sign.
  • Forgetting \(dz\). The integrand is \(f(z(t))\,z'(t)\), not just \(f(z(t))\).
  • Leaving \(\bar z\) as \(\bar z\) in the integral. Write \(t^2-it\), not "\(\overline{t^2+it}\)".

Path dependence

For a real integral \(\int P\,dx+Q\,dy\) the value is the same on every path only if \(P_y=Q_x\). Her first class example: \(\int(2y+x^2)dx+(3x-y)dy\) from \((0,3)\) to \((2,4)\) has \(P_y=2\ne Q_x=3\), and indeed three paths give three different answers (below). The complex analogue: for an analytic \(f\) the integral depends only on the end points; for a non-analytic \(f\) such as \(\bar z\) it depends on the path (\(10-\frac83i\) along a parabola, \(10-8i\) along straight pieces, to the same end point \(4+2i\)).

Worked examples (her class examples, Lec 10)

The semicircle \(\int dz/z\) (she wrote "TF")

Use \(z=e^{i\theta}\) on the unit circle, so \(\dfrac{dz}{z}=i\,d\theta\). The integral is just \(i\) times the change in \(\theta\). Going from \(-1\) to \(1\): the upper arc has \(\theta\) running from \(\pi\) down to \(0\) (change \(-\pi\)), the lower arc has \(\theta\) from \(-\pi\) up to \(0\) (change \(+\pi\)).

Trap · orientation

Both students' class notes take \(\theta:0\to\pi\) for the upper arc (that is \(1\to-1\)) and get \(+\pi i\), which flips the signs. The question gives \(-\pi i\) (upper) and \(+\pi i\) (lower), so the direction must be \(-1\to1\). Say the direction in your answer. Also, \(z=0\) is not on the curve (the curve is \(|z|=1\)); a remark in the notes says it is, and that is wrong.

Optional extras

Came in papers, not taught: the ML-inequality

She never mentioned this in class, but 2024-25 Q5(c) (10 marks) and 2012-13 asked it. It is cheap marks if you know the three lines.

ML-inequality
If \(|f(z)|\le M\) on the curve \(C\) and \(C\) has length \(L\), then \(\left|\int_C f\,dz\right|\le ML\).

Recipe · bound an integral

  1. Find \(M\): bound the numerator from above and the denominator from below using the triangle inequality, \(|a\pm b|\ge|a|-|b|\) and \(|a\pm b|\le|a|+|b|\).
  2. Find \(L\): the arc length (a quarter of the circle \(|z|=2\) has \(L=\frac14\cdot2\pi\cdot2=\pi\)).
  3. Write the answer as \(\le ML\).

What to write

State the inequality, then "on \(C\), \(|z|=2\), so \(|z^2-1|\ge|z|^2-1=3\), so \(\left|\frac1{z^2-1}\right|\le\frac13\)", then \(L=\pi\), then the product.

Trap

The denominator needs a lower bound, so use \(|z^2-1|\ge|z|^2-1\) (reverse triangle inequality), never \(\le|z|^2+1\). Using the wrong direction gives a bound that is not valid.

One-minute summary

  • \(\int_Cf\,dz=\int f(z(t))\,z'(t)\,dt\). Segment: \(z=z_1+t(z_2-z_1)\), \(dz=(z_2-z_1)dt\). Circle: \(z=c+re^{i\theta}\), \(dz=ire^{i\theta}d\theta\).
  • \(\int_Cf\,dz=\int(u\,dx-v\,dy)+i\int(v\,dx+u\,dy)\).
  • Several pieces: add them. Reverse the direction: change the sign.
  • \(\int_C\bar z\,dz\), \(0\to4+2i\): \(10-\frac83i\) along \(z=t^2+it\); \(10-8i\) along \(0\to2i\to4+2i\).
  • \(\int dz/z\) on the unit semicircle from \(-1\) to \(1\): \(-\pi i\) (upper), \(+\pi i\) (lower). \(\oint_{|z|=1}dz/z=2\pi i\).
  • \(\oint\bar z\,dz=2i\times\text{(area enclosed)}\), anticlockwise. Triangle \(0,1+i,-2\): \(2i\).
  • ML: \(\left|\int_Cf\,dz\right|\le ML\). \(\left|\int_C\frac{dz}{z^2-1}\right|\le\frac\pi3\) on the first-quadrant arc of \(|z|=2\).
