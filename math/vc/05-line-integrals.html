Line integrals and work done along a path

"Find the work done by the force \(\vec F\) along this path" came in all three MATH 241 papers (2022-23 Q2(b), 2023-24 Q2(c), 2024-25 Q2(b)), 10 to 13 marks each. It is the same job every time: turn the path into one parameter, substitute, integrate.

One type, every year. every year Work along a given path (lines, parabola, curve given as an intersection, closed curve), plus the potential shortcut. 8 mandatory cards, 6 optional extras. The Green's-theorem version of closed-path work is in the next chapter.

1. What you are computing

Line integral / work
\[W=\int_C\vec F\cdot d\vec r=\int_C F_1\,dx+F_2\,dy+F_3\,dz,\qquad \vec F=F_1\hat i+F_2\hat j+F_3\hat k,\quad d\vec r=dx\,\hat i+dy\,\hat j+dz\,\hat k.\]
Closed path
\(\oint_C\) means start and end at the same point. Counter-clockwise is the positive direction.
Conservative field
\(\nabla\times\vec F=\vec 0\). Then \(\vec F=\nabla\phi\) and \(\int_A^B\vec F\cdot d\vec r=\phi(B)-\phi(A)\), whatever the path. On a closed path the work is 0.

The idea: on the path, \(x,y,z\) are not independent. Write all three with one letter \(t\), so \(dx=x'(t)\,dt\) etc., and the line integral becomes an ordinary integral \(\int_{t_0}^{t_1}(\dots)\,dt\).

2. Parametrising the paths that come up

PathParametrisationDifferentials
Straight segment \(P\to Q\)\(\vec r=P+t(Q-P)\), \(0\le t\le1\)\(dx,dy,dz\) = the components of \(Q-P\), times \(dt\)
Segment parallel to an axis, e.g. \((1,0,0)\to(1,1,0)\)\(x=1,\ z=0,\ y=t\)\(dx=dz=0\): only \(F_2\,dy\) survives
Curve \(y=2x^2\) in the plane\(x=t,\ y=2t^2\) (or just use \(dy=4x\,dx\))\(dx=dt,\ dy=4t\,dt\)
Curve given as two equations, \(x^2=4y,\ 3x^3=8z\)Put \(x=t\). Then \(y=t^2/4,\ z=3t^3/8\)\(dx=dt,\ dy=\tfrac t2dt,\ dz=\tfrac{9t^2}8dt\)
Circle radius \(a\), counter-clockwise\(x=a\cos t,\ y=a\sin t,\ 0\le t\le2\pi\)\(dx=-a\sin t\,dt,\ dy=a\cos t\,dt\)
Ellipse \(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\)\(x=a\cos t,\ y=b\sin t\)\(dx=-a\sin t\,dt,\ dy=b\cos t\,dt\)
Helix\(x=\cos t,\ y=\sin t,\ z=t\)\(dz=dt\)

For a curve given by one equation like \(y=x^2\), you may either pick \(x=t\) or keep \(x\) as the variable and replace \(dy\) by \(2x\,dx\). Both give the same integrand.

Recipe · work along a given path

  1. Write \(W=\int_C F_1\,dx+F_2\,dy+F_3\,dz\).
  2. Parametrise the path (table above). If the path has several pieces (lines from point to point to point), do one piece at a time.
  3. Substitute \(x,y,z\) and \(dx,dy,dz\) into \(F_1\,dx+F_2\,dy+F_3\,dz\). Do not forget the differentials: \(dx=x'(t)\,dt\).
  4. Integrate from the start value of \(t\) to the end value. On a return leg the limits run backwards.
  5. Add the pieces. Box the sum.
  6. Check: if \(\nabla\times\vec F=\vec0\), the potential gives the answer in one line. For a closed plane curve, Green's theorem is a cross-check.

What to write

(1) "\(W=\int_C\vec F\cdot d\vec r=\int F_1dx+F_2dy+F_3dz\)". (2) The parametrisation with \(t\)-limits and the three differentials. (3) The substituted integrand in \(t\), then the integration. (4) For several pieces, a line per piece with its own value, then the sum. (5) The boxed answer with units if given.

Traps

  • Dropping \(dx=x'(t)\,dt\). Our class note did exactly this in the \(x=2t^2\) example and got 61/30 instead of 1763/210.
  • Wrong direction on a leg. The limits follow the direction of travel, so a leg from \((1,1)\) back to \((0,0)\) has \(t\) from 1 down to 0.
  • On a segment where a coordinate is constant, its differential is 0 and its \(F\)-component drops out. On \((1,0,0)\to(1,1,0)\), \(z=0\) kills \(-14yz\).
  • Mixing the point order: "\((0,0,0)\to(1,0,0)\to(1,1,0)\to(1,1,1)\)" is three legs, not one straight line.

Corrections to the class notes (so your copy is right)

  • \(\int_1^2(u^2\hat i+2u^3\hat j-5\hat k)du=\frac73\hat i+\frac{15}2\hat j-5\hat k\), not \(\frac73\hat i+7\hat j\).
  • \(\vec A=(2y+3)\hat i+xy\hat j+(yz-x)\hat k\) along \(x=2t^2,y=t,z=t^3\): the answer is \(\frac{1763}{210}\), not \(\frac{61}{30}\). With Schaum's original \(xz\hat j\) the answer is \(\frac{288}{35}\).
  • Helix work \(\vec F=(z,z,x)\): \(\frac\pi2-1\), not \(\frac1{\sqrt3}\).
  • Circle of radius 3: the integrand is \(9-\frac92\sin2t\) (the note's \(-9\sin^2t\) should be \(+9\sin^2t\)); the answer \(18\pi\) is right.
  • \(\oint\sin y\,dx+x(1+\cos y)\,dy\) on \(x^2+y^2=a^2\) is \(\pi a^2\), not "96π".
  • The triangle \((0,0),(2,0),(2,2)\) gives \(-2\). The textbook's version with vertex \((2,1)\) gives \(-1\).

4. The potential shortcut

Before parametrising anything, test for \(\nabla\times\vec F=\vec 0\). If it holds, the work between two points does not depend on the path, so a long parametrisation is wasted effort.

Recipe · conservative field

  1. Compute \(\nabla\times\vec F\) from the determinant with rows \((\hat i,\hat j,\hat k),(\partial_x,\partial_y,\partial_z),(F_1,F_2,F_3)\). If it is \(\vec0\), continue.
  2. Find \(\phi\) with \(\phi_x=F_1,\ \phi_y=F_2,\ \phi_z=F_3\) by integrating \(F_1\) in \(x\), then adding what is missing.
  3. \(W=\phi(B)-\phi(A)\). A closed path gives \(W=0\).
  4. If the curl is not 0, do the parametrisation. The example \(C25\) above shows three different paths giving 5, \(\frac{23}3\), \(\frac{13}3\): path matters.

Trap

A closed path does not make the work 0 unless the field is conservative. In the circle and ellipse questions below the answers \(18\pi\) and \(96\pi\) are non-zero, because the field is not conservative.

Optional extras (older MATH 147 papers and class)

One-minute summary

  • \(W=\int_C\vec F\cdot d\vec r=\int F_1dx+F_2dy+F_3dz\); put everything in terms of \(t\), do not forget \(dx=x'(t)\,dt\).
  • Segment \(P\to Q\): \(\vec r=P+t(Q-P)\), \(t:0\to1\). Constant coordinate means zero differential.
  • Intersection of surfaces (\(x^2=4y,\ 3x^3=8z\)): put \(x=t\), solve the others. Answer 16 for \(\vec F=(3x^2,\,2xz-y,\,z)\), \(x:0\to2\).
  • Circle \(x=a\cos t,\ y=a\sin t\); ellipse \(x=a\cos t,\ y=b\sin t\); \(t:0\to2\pi\) counter-clockwise.
  • Curl \(=\vec0\): \(\phi\) with \(\nabla\phi=\vec F\); \(W=\phi(B)-\phi(A)\); closed path gives 0.
  • Return legs have limits backwards. Final answers to remember: \(\frac{20}3\), 16, \(-6\), \(\frac{1763}{210}\), \(\frac\pi2-1\), \(18\pi\), \(96\pi\), \(-2\).
