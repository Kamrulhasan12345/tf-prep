Changing Tables (ALTER, DROP, DEFAULT) and Computing in SELECT

Two topics that Lectures 3–5 use but do not teach, and that exams and lab work expect: the rest of the DDL (dropping a table, adding, removing, renaming and changing columns, default values, TRUNCATE), and the expressions, aliases and Oracle single-row functions that can appear in a SELECT list or a WHERE clause.

1. Removing a table: DROP TABLE (textbook §2.3.4)

DROP TABLE Laptop2;

Removes the table completely: its rows and its schema. Afterwards the name no longer exists, and any query on it fails (ORA-00942). Compare the three ways of "getting rid of" data:

If other tables have foreign keys referencing T, Oracle refuses to drop it unless you write DROP TABLE T CASCADE CONSTRAINTS, which also removes those foreign keys. (The playground has no TRUNCATE; use DELETE FROM T there.)

2. Changing a table: ALTER TABLE (textbook §2.3.4)

A table that already holds data can have its schema changed without dropping it:

ALTER TABLE MovieStar ADD phone CHAR(16);              -- new column, NULL in every existing row
ALTER TABLE MovieStar DROP COLUMN birthdate;           -- the column and its values disappear
ALTER TABLE MovieStar RENAME COLUMN address TO addr;   -- rename a column
ALTER TABLE MovieStar RENAME TO Star;                  -- rename the table
ALTER TABLE MovieStar MODIFY (address VARCHAR2(100));  -- change a column's type or size (Oracle)
  • The textbook writes ALTER TABLE MovieStar DROP birthdate; Oracle needs the word COLUMN (or the form DROP (birthdate)).
  • Oracle also accepts a parenthesised list: ALTER TABLE MovieStar ADD (phone CHAR(16), email VARCHAR2(40));
  • MODIFY can always enlarge a column; it can shrink one only if every existing value still fits. The playground's SQLite has no MODIFY.
  • Adding and dropping constraints with ALTER TABLE (ADD CONSTRAINT, DROP CONSTRAINT) is part of Lecture 6.

3. Default values (textbook §2.3.5)

DEFAULT
A value written after an attribute's type, used whenever a row is inserted without a value for that attribute (a partial insert), and for existing rows when the column is added by ALTER TABLE. Without DEFAULT, the default is NULL. The value can be a constant or a system value such as SYSDATE.
CREATE TABLE MovieStar (
    name       VARCHAR2(50) PRIMARY KEY,
    address    VARCHAR2(50),
    gender     CHAR(1) DEFAULT '?',
    birthdate  DATE    DEFAULT DATE '1900-01-01'
);
ALTER TABLE MovieStar ADD phone CHAR(16) DEFAULT 'unlisted';

(The textbook's example uses DATE '0000-00-00' as an "unknown" date. Oracle rejects it: there is no year 0 or month 0. Use NULL for an unknown date, or a clearly artificial real date.) Writing the keyword DEFAULT in a VALUES list also asks for the default explicitly: INSERT INTO MovieStar VALUES ('Ali', 'Dhaka', DEFAULT, NULL, DEFAULT);

4. Expressions and aliases in SELECT

The SELECT list may contain expressions, not only column names. Lecture 5 already used model + 1100 and price + 500.

  • Arithmetic: + − * / on numbers, with the usual precedence (* and / before + and −; use parentheses). salary * 12 is an annual salary.
  • Column alias: expression AS name (AS is optional) names an output column. A name with spaces or a fixed case needs double quotes: salary * 12 AS "Annual Salary". An alias can be used in ORDER BY but not in WHERE (WHERE is evaluated before SELECT, so the alias does not exist yet).
  • Concatenation: || joins strings: first_name || ' ' || last_name. In Oracle a NULL operand is treated as an empty string here; in most other systems (and in the playground) the result is NULL.
  • dual: Oracle's one-row table for computing an expression without a real table: SELECT 7 * 6 FROM dual;

Two playground differences to keep in mind: SQLite divides integers as integers (7 / 2 gives 3; Oracle gives 3.5), so write 7 / 2.0 there; and ROUND with a negative number of places is not supported.

6. Conditional values: CASE and DECODE

SELECT last_name, salary,
       CASE
         WHEN salary >= 15000 THEN 'high'
         WHEN salary >= 7000  THEN 'medium'
         ELSE 'low'
       END AS band
FROM   Employees;

A searched CASE tests its WHEN conditions in order and returns the THEN value of the first TRUE one, or the ELSE value (NULL if there is no ELSE). Oracle's older DECODE function compares one expression with a list of values:

SELECT last_name,
       DECODE(department_id, 90, 'Executive', 60, 'IT', 50, 'Shipping', 'Other') AS dept
FROM   Employees;

is the same as CASE department_id WHEN 90 THEN 'Executive' WHEN 60 THEN 'IT' WHEN 50 THEN 'Shipping' ELSE 'Other' END. (One difference: DECODE treats two NULLs as equal, CASE does not.) The playground supports both forms.

Summary: DROP TABLE removes rows and schema; TRUNCATE removes all rows quickly (DDL, no rollback); DELETE removes chosen rows (DML). ALTER TABLE adds (ADD col type [DEFAULT v]), drops (DROP COLUMN), renames and (Oracle) modifies columns. DEFAULT gives the value used when none is supplied. SELECT lists may hold arithmetic, ||, CASE and single-row functions such as UPPER, SUBSTR, ROUND, NVL, TO_CHAR; AS names the output column.
