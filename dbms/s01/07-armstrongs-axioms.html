Armstrong's Axioms and Equivalent FD Sets

Three simple rules are enough to derive every FD that follows from a given set. This chapter states them, derives the extra rules from them step by step (including the slide's “prove it” exercise), and defines when two sets of FDs are equivalent.

1. The three axioms (slide 29)

Write X, Y, Z, W for sets of attributes, and XY for X ∪ Y.

Reflexivity
If {B₁, …, Bₘ} ⊆ {A₁, …, Aₙ}, then A₁…Aₙ → B₁…Bₘ. These are the trivial FDs. Example: title year → title.
Augmentation
If A₁…Aₙ → B₁…Bₘ, then A₁…AₙC₁…Cₖ → B₁…BₘC₁…Cₖ for any attributes C. Add the same attributes to both sides. Example: from title year → length, title year genre → length genre. (Remove duplicate attributes from each side.)
Transitivity
If A₁…Aₙ → B₁…Bₘ and B₁…Bₘ → C₁…Cₖ, then A₁…Aₙ → C₁…Cₖ (Chapter 4).

The slide calls these rules sound and complete:

  • Sound: every FD they derive really follows (holds in every instance that satisfies the given FDs). Each axiom can be checked with the two-tuple argument of Chapter 4. For augmentation: if two tuples agree on XC, they agree on X, hence on Y (given X → Y), and they agree on C, so they agree on YC.
  • Complete: every FD that follows can be derived with them. (The proof uses the closure argument; the closure algorithm of Chapter 5 is the practical way to decide “does it follow?”.)

2. Additional rules (slide 30)

These can be derived from the three axioms, so using them never adds anything new; they just shorten proofs.

Decomposition (splitting)
If X → YZ then X → Y and X → Z.
Union (combining)
If X → Y and X → Z then X → YZ.
Pseudotransitivity
If X → Y and YZ → W then XZ → W. (Slide 31 writes it as: X → Y and YW → Z give XW → Z. Same rule, letters renamed.)
Composition (addition)
If X → Y and Z → W then XZ → YW.

3. Proofs from the axioms (slides 31–32)

Decomposition (slide 31)

  1. X → YZ (given)
  2. YZ → Y and YZ → Z (reflexivity: Y ⊆ YZ, Z ⊆ YZ)
  3. X → Y (transitivity on 1 and YZ → Y)
  4. X → Z (transitivity on 1 and YZ → Z)

Pseudotransitivity (slide 31: “Prove it [exercise]”)

Prove: if X → Y and YW → Z, then XW → Z.

Left-side augmentation (slide 32)

Show that if X → Z then XY → Z. Adding attributes to the left side of an FD keeps it true.

  1. X → Z (given)
  2. XY → ZY (augmentation with Y)
  3. XY → Z (decomposition of 2)

Intuition from the slide: X → Z says “knowing X fixes Z”. If two tuples agree on X and Y, they in particular agree on X, so they agree on Z. Knowing more (X and Y) still fixes Z. This is why every superset of a key is a superkey.

Union and composition

Union: X → Y, X → Z ⊢ X → YZ
  1. X → XY (augment X → Y with X; XX = X)
  2. XY → YZ (augment X → Z with Y)
  3. X → YZ (transitivity 1, 2)
Composition: X → Y, Z → W ⊢ XZ → YW
  1. XZ → YZ (augment X → Y with Z)
  2. YZ → YW (augment Z → W with Y)
  3. XZ → YW (transitivity 1, 2)

4. Equivalence of FD sets (slide 33)

S follows from T
Every relation instance that satisfies all FDs in T also satisfies all FDs in S. Check it FD by FD: for each X → Y in S, compute X⁺ using T and see whether Y ⊆ X⁺ (or derive it with the inference rules).
S and T are equivalent
S follows from T, and T follows from S. Equivalent sets allow exactly the same instances.

Example: are S = {A → B, B → C, A → C} and T = {A → B, B → C} equivalent?

T follows from S: T ⊆ S, so trivially yes. S follows from T: A → B and B → C are in T; for A → C, compute A⁺ under T = {A, B, C} ∋ C. Yes. So S ≡ T: the FD A → C adds nothing. Removing such redundant FDs is the first idea behind the minimal basis (Chapter 8).

Non-example: {AB → C} and {A → C}. A → C implies AB → C (left augmentation), but under {AB → C}, A⁺ = {A}, so A → C does not follow. Not equivalent.

Write down the six rules with examples to find out the closure of a set of functional dependencies.

Show worked answer

The closure F⁺ of a set of FDs F is the set of all FDs that follow from F. It is generated by Armstrong's three axioms plus three derived rules. Examples use R(studentID, name, dept, deptHead, course, grade) with F = {studentID → name dept, dept → deptHead, studentID course → grade}.

  1. Reflexivity: if Y ⊆ X then X → Y. Example: studentID course → course.
  2. Augmentation: if X → Y then XZ → YZ. Example: from dept → deptHead, dept course → deptHead course.
  3. Transitivity: if X → Y and Y → Z then X → Z. Example: studentID → dept and dept → deptHead give studentID → deptHead.
  4. Union: if X → Y and X → Z then X → YZ. Example: studentID → name and studentID → deptHead give studentID → name deptHead.
  5. Decomposition: if X → YZ then X → Y and X → Z. Example: studentID → name dept gives studentID → name and studentID → dept.
  6. Pseudotransitivity: if X → Y and YW → Z then XW → Z. Example: add the FD dept course → room (each department teaches a course in one room). With studentID → dept (X = studentID, Y = dept, W = course) we get studentID course → room.

The first three (Armstrong's axioms) are sound and complete; rules 4–6 are derived from them (proofs in section 3) and only shorten derivations.

Summary: Armstrong's axioms are reflexivity (trivial FDs), augmentation (add the same attributes to both sides) and transitivity. They are sound and complete. Decomposition, union, pseudotransitivity and composition are derived from them in two or three steps. Two FD sets are equivalent when each follows from the other; test it FD by FD with closures.
