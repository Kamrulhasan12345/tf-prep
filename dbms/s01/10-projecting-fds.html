Which FDs Hold After Decomposition? Projecting FDs

After a relation is split, each piece needs its own FDs, both to check its normal form and to decide whether to split again. This chapter gives the projection algorithm, answers the slide's “why can we remove A → D?”, and provides a tool.

1. The question (slide 43)

Suppose R with FD set S is decomposed, and R₁ is one of the pieces. Which FDs hold on R₁? The answer is the set S₁ of all FDs that

  1. logically follow from S, and
  2. involve only attributes of R₁.

This is called projecting S onto R₁. Note that S₁ is not just “the FDs of S whose attributes all lie in R₁”. An FD can hold on R₁ because of a chain through attributes that R₁ no longer has. In the slide's example, A → C holds on R₁(A, C, D) even though the chain A → B → C passes through B, which R₁ does not contain.

2. The algorithm (slide 44)

project(S, R₁):
  Step 1. S₁ := ∅.
  Step 2. For each set of attributes X ⊆ R₁, compute X⁺ using S
          (all of S, including FDs that mention attributes outside R₁).
  Step 3. Add to S₁ every nontrivial FD X → A with A in both X⁺ and R₁.
  (Book, Algorithm 3.12, step 3: then simplify S₁ to a minimal basis.)

The number of subsets is 2|R₁|, so the textbook suggests two shortcuts:

  • The empty set and the set of all attributes of R₁ never give a nontrivial FD; skip them.
  • If X⁺ already contains every attribute of R₁, skip every superset of X: any FD it gives already follows from X → (all of R₁).

3. Slide 44's example

R(A, B, C, D) has A → B, B → C, C → D. Project onto R₁(A, C, D).

  • {A}⁺ = {A, B, C, D}. Inside R₁: A → C and A → D. (A → B holds in R but means nothing in R₁, which has no B.)
  • {C}⁺ = {C, D}: C → D.
  • {D}⁺ = {D}: nothing.
  • Supersets of A are skipped (A⁺ covers R₁). The only remaining pair is {C, D}: {C, D}⁺ = {C, D}, nothing new.
  • S₁ = {A → C, A → D, C → D}.

Slide 44: “we can remove A → D, why?”

A → D follows from the other two by transitivity: A → C and C → D give A → D. Removing it leaves an equivalent set, so the minimal basis of the projection is {A → C, C → D}. (Check with step 3 of Chapter 8: A⁺ under {A → C, C → D} = {A, C, D} contains D.)

Quick check

Summary: the FDs of a piece R₁ are all FDs that follow from the original set and mention only R₁'s attributes. Compute them by closing every subset X of R₁ with the original FDs and keeping X → A for each new A inside R₁, then simplify to a minimal basis. Chains through dropped attributes still count: projecting A → B → C → D onto ACD gives A → C and C → D.
