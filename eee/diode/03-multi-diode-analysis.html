Circuits with Several Diodes

State guessing appeared in 2011–12, 2014–15 and 2022–23 (10⅔ to 16 marks), diode logic in 2016–17, and this batch's own CT-1 Q2 was "find the range of Rx for which only one diode is on". Sadat sir wrote "v. v. important: find range of Rx for which only one diode will be on" next to Sedra P4.9, and 2022–23 asked exactly that. One method does all of it: the case method. Assume a state for every diode, solve a linear circuit, check, and write down why each rejected case fails.

1. The case method

With n diodes there are \(2^n\) on/off combinations. Exactly one is consistent (for normal circuits). You do not have to try all of them: rule out the impossible ones by a one-line argument first.

Method · case method (Sadat L5)

  1. List the cases and strike the impossible ones with a reason: "both off: no current, so node X sits at +10 V and D2 is forward biased ✗"; "D1 alone: current would enter X from both sides with no way out ✗".
  2. Pick a likely case (diodes pointing from a high rail toward a low rail are usually on).
  3. Replace on diodes by a short (ideal) or a 0.7 V battery (CVD) or battery + \(r_D\) (PWL); off diodes by an open.
  4. Solve the node voltages and branch currents (KCL / KVL; work in V, mA, kΩ).
  5. Check: each on diode carries current from anode to cathode (\(I > 0\)); each off diode has \(V_{AK} < V_{D0}\) (\(\le 0\) for ideal). With CVD check on-diodes by current only.
  6. If any check fails, change that diode's state and repeat. Write the failed case in the answer: it earns method marks and is the "justify" the question asks for.

Worked example: Sadat L5, notes p.15 (Sedra Fig. 4.6(a) with a 0.7 V drop)

Change the 5 kΩ to 10 kΩ and the same "both on" case gives \(I_1 = 0.93 - 1 = -0.07\) mA ✗; then D1 off, D2 on: \(I = (10 - 0.7 + 10)/20 = 0.965\) mA, \(V_o = -10 + 10\times0.965 = -0.35\) V, and D1 sees only 0.35 V < 0.7 V ✓ (Sadat L5, notes p.16).

2. Range of a resistor for which a given set of diodes conducts

The "v. v. important" type. The question fixes the states ("D1 off and D2 on", "only one diode on") and asks for the resistor values that make that state consistent.

Method · range of R

  1. Decide which state is meant. If the question says "only one diode", argue which one (the others are impossible alone).
  2. Solve that state with R kept as a symbol: currents and node voltages as functions of R.
  3. Write the checks as inequalities: on diodes \(I(R) > 0\); off diodes \(V_{AK}(R) < V_{D0}\).
  4. Solve each inequality for R (multiply out; R is positive). Intersect them.
  5. Cross-check: at the boundary the off diode is exactly at its threshold with zero current, so the neighbouring state (both on) gives the same boundary from the other side.

Worked example: Sadat L6, notes p.17–19 (CVD, then PWL)

3. Diode logic gates (type D-05) and selectors

Method · diode gates

  1. OR / max selector: only the diode from the highest input conducts (if two inputs tie, both share). \(v_Y = v_{max} - V_{D0}\) (ideal: \(v_{max}\)); every other diode is reverse biased by \(v_Y - v_k\). If all inputs are below \(V_{D0}\), all are off and \(v_Y\) = 0.
  2. AND / min selector: the diode to the lowest input conducts: \(v_Y = v_{min} + V_{D0}\); if \(v_{min} + V_{D0} \ge 5\) V every diode is off and \(v_Y\) = 5 V.
  3. Check with the case method if the cut-in voltages differ: with \(V_\gamma\) = 1.2, 0.1, 0.7 V on the 3, 2, 1 V inputs, the 2 V diode wins (\(v_o = 1.9\) V; the 3 V diode sees 1.1 V < 1.2 V) (Sadat L5, notes p.13).
  4. Cascaded gates: work stage by stage from the inputs; every conducting diode shifts the level by 0.7 V, so a logic 1 degrades through the chain.

Traps (where marks go)

  • Checking only the currents of on diodes and never the reverse voltage of off diodes (or the reverse).
  • Ideal diodes: on means 0 V, not 0.7 V.
  • Not stating which cases are impossible and why: in "justify" questions this is the marks.
  • Range questions: forgetting that R is in the denominator; flipping the inequality when multiplying by a negative bracket. Multiply out with positive quantities only.
  • Direction of the asked current: I is defined by the arrow in the figure; a negative value means the diode is off, not "current the other way".
  • A figure with a diode drawn backwards changes the logic function (2016–17): say which orientation you used.

Exam questions

2022–23 · Sec A · Q2(b) · 15 marks

Determine the range of values of resistor R such that D1 does not conduct and D2 conducts. Assume ideal diodes.

Show worked answer

State: D1 off (open), D2 on (short). Then one loop: +5 V → 5 kΩ → X → D2 → R → −5 V.

\(I = \dfrac{5 - (-5)}{5 + R} = \dfrac{10}{5 + R}\) mA (R in kΩ), \(V_X = 5 - 5I = 5 - \dfrac{50}{5 + R} = \dfrac{5R - 25}{5 + R}\) V.

D2 on needs \(I > 0\): true for every R ≥ 0.

D1 off needs \(V_{AK} = V_X - 0 \le 0\): \(5R - 25 \le 0\) → \(R \le 5\) kΩ.

Cross-check with both on: \(V_X\) = 0, \(I_{5k} = 1\) mA, \(I_R = 5/R\); \(I_{D1} = 1 - 5/R > 0\) needs \(R > 5\) kΩ, the complementary range ✓.

Answer: 0 ≤ R ≤ 5 kΩ.

2016–17 · Sec B · Q8(b) · 10 marks

Determine the Boolean expression for \(V_o\) in terms of the four input voltages (logic 0 = 0 V, logic 1 = +5 V). All resistors 1 kΩ.

Netlist as read from the hand-drawn figure: 1 kΩ from +5 V to A, diodes A → V1 and A → V2; 1 kΩ from +5 V to B, diode B → A and diode B → +5 V; 1 kΩ from +5 V to C, diodes C → V3 and C → V4; diodes B → E and C → E with 1 kΩ from E to ground; diode E → \(V_o\), diode ground → \(V_o\), 1 kΩ from \(V_o\) to ground. (A senior copy draws the B–A diode the other way; with that orientation the output is never low, so this reading is the intended one.)

Show worked answer

Stage 1 (A, C): AND gates. A is low (0.7 V) if V1 or V2 is 0; A is high only when V1 = V2 = 1. Same for C with V3, V4.

Stage 2 (B): the B → A diode makes B follow A one drop higher: when A = 0.7 V, B = 1.4 V; when A is high the B → A diode is off and B is pulled up by its resistor (the B → +5 V diode only stops B rising above 5.7 V). So B = A (level shifted): B carries V1·V2.

Stage 3 (E): diodes from B and C into E with a pull-down: an OR gate, E = B + C.

Stage 4 (\(V_o\)): diodes from E and from ground into \(V_o\), pull-down: \(V_o\) = max(E, 0) − 0.7, which passes E's logic level and keeps \(V_o\) ≥ 0.

Result: \(V_o = V_1V_2 + V_3V_4\) (AND–OR).

Levels with 0.7 V diodes (checked by solving all 16 input cases): logic 0 gives \(V_o\) = 0 V (A = 0.7, B = 1.4, E = 0.7). One AND high gives E = 1.67 V, \(V_o\) = 0.97 V; both high give E = 2.33 V, \(V_o\) = 1.63 V. With ideal diodes: 0 V, 1.67 V, 2.5 V. The "1" level is far below 5 V: the drawback of cascading diode logic.

2014–15 · Sec A · Q1(a) · 10⅔ marks

Find the values of I and V. Use the 0.7 V drop diode model.

Show worked answer

Impossible cases: both off: no current, V = −10 V, so D2 (anode at 0 V) would be forward biased by 10 V ✗. D1 off, D2 on: V = −0.7 V, a = +10 V, so D1 sees 10.7 V forward ✗.

Try D1 on, D2 off: \(I = \dfrac{10 - 0.7 + 10}{5 + 3} = 2.41\) mA, \(V = -10 + 3\times2.41 = -2.76\) V. D2 then has \(V_{AK} = 0 - (-2.76) = 2.76\) V > 0.7 V: it would conduct ✗.

Both on: V = −0.7 V, so node a = V + 0.7 = 0 V. \(I_{D1} = (10 - 0)/5 = 2\) mA; \(I = (-0.7 + 10)/3 = 3.1\) mA; \(I_{D2} = I - I_{D1} = 1.1\) mA > 0 ✓ (both currents positive).

Answer: I = 3.1 mA, V = −0.7 V.

2011–12 · Sec B · Q5(a) · 16 marks  |  = Sedra Example 4.2(b) and Exercise 4.4(e); circuit (ii) also CT1(B) 2018

Assuming the diodes to be ideal, find I and V in circuits (i) and (ii). In (i), I is the current in D1 (from ground into node x).

Show worked answer

(i) Both on: x = 0, V = 0. \(I_{D2} = (10 - 0)/5 = 2\) mA, current in 10 kΩ \(= (0 + 10)/10 = 1\) mA, so \(I = 1 - 2 = -1\) mA ✗.

D1 off, D2 on: \(I_{D2} = \dfrac{10 + 10}{5 + 10} = 1.333\) mA; \(V = V_x = -10 + 10\times1.333 = 3.33\) V. D1 has \(V_{AK} = 0 - 3.33 < 0\) ✓. I = 0, V = 3.33 V.

(ii) OR (max) selector: only the +3 V diode conducts. V = 3 V, I = 3/1 = 3 mA. The +2 V and +1 V diodes are reverse biased by 1 V and 2 V ✓.

Class tests and assignment

CT-1, this batch (Jan 2026), Sec A · Q2 · 10 marks (teacher's variant of Sedra P4.9)

The diodes have \(V_D\) = 0.7 V (CVD). Find the range of \(R_x\) for which only one diode turns on. Which diode is it? Justify.

Show worked answer

D1 alone is impossible: current would flow into X from +5 V (through D1) and from +10 V (through 9.5 kΩ), with D2 off there is no path out of X ✗.

Both off is impossible: no current, \(V_X\) = 10 V, which forward-biases D2 (10 V > 3 + 0.7) ✗.

So the single diode must be D2. \(I = \dfrac{10 - 0.7 - 3}{9.5 + R_x} = \dfrac{6.3}{9.5 + R_x}\) mA; \(V_X = 10 - 9.5I\).

D1 stays off if \(V_{AK} = 5 - V_X < 0.7\), i.e. \(V_X > 4.3\) V: \(9.5\times\dfrac{6.3}{9.5 + R_x} < 5.7\) → \(59.85 < 54.15 + 5.7R_x\) → \(R_x > 1\) kΩ.

Cross-check (both on): \(V_X\) = 4.3 V, \(I_{9.5k} = 5.7/9.5 = 0.6\) mA, \(I_{Rx} = (4.3 - 0.7 - 3)/R_x = 0.6/R_x\); \(I_{D1} = 0.6/R_x - 0.6 > 0\) needs \(R_x < 1\) kΩ, the complement ✓.

Answer: only D2 conducts, for \(R_x > 1\) kΩ.

Assignment · Q1

Each diode has \(V_D\) = 0.7 V. Find the diode currents, \(V_A\) and \(V_B\).

Show worked answer

Guess: D1 on (it points from +5 V toward −10 V), D3 on (from ground toward −5 V), D2 off. Check that guess.

Left branch: \(I_{D1} = \dfrac{5 - 0.7 + 10}{5 + 5} = 1.43\) mA; \(V_A = 5 - 5\times1.43 = -2.15\) V.

Right branch: D3 on gives \(V_B = -0.7\) V; \(I_{D3} = (-0.7 + 5)/5 = 0.86\) mA.

D2: \(V_{AK} = V_A - V_B = -2.15 + 0.7 = -1.45\) V < 0.7 V, off ✓, \(I_{D2}\) = 0. Both on-currents positive ✓.

(Had you guessed D2 on, it would need \(V_A = V_B + 0.7\); the left branch cannot supply it: the other 7 combinations all fail a check.)

Highlighted textbook problems

Sedra 7e P4.9 · highlighted by the teacher: "v. v. important · practice with PL model · find range of Rx for which only one diode will be on"

Ideal diodes; find I (the current in D1) and V. (a) 12 kΩ from +3 V to A, D1 from A to ground, D2 from A to V, 6 kΩ from V to −3 V. (b) The same with 6 kΩ on top and 12 kΩ below. Teacher's extension: replace the top resistor by \(R_x\) and find the range of \(R_x\) for which only one diode is on, with ideal, CVD and PL (0.7 V, 10 Ω) diodes.

Show worked answer

(a) Both on: \(V_A = 0\), \(I_{12k} = 3/12 = 0.25\) mA, \(I_{6k} = 3/6 = 0.5\) mA, \(I_{D1} = 0.25 - 0.5 < 0\) ✗. D1 off, D2 on: \(I = 6/18 = 0.333\) mA, \(V_A = V = 3 - 12\times0.333 = -1\) V; D1 reverse biased ✓. I = 0, V = −1 V.

(b) Both on: \(I_{6k} = 0.5\) mA, \(I_{12k} = 0.25\) mA, \(I_{D1} = 0.25\) mA > 0 ✓. I = 0.25 mA, V = 0.

Range (the single diode must be D2: D1 alone leaves the 6 kΩ branch dead but then V = −3 V and D2 is forward biased). D2 on: \(I = \dfrac{3 - V_{D0} + 3}{R_x + 6 + r_D}\); D1 off needs \(V_A = 3 - R_xI < V_{D0}\).

Ideal: \(3(R_x + 6) < 6R_x\) → \(R_x > 6\) kΩ. CVD: \(2.3(R_x + 6) < 5.3R_x\) → \(R_x > 4.6\) kΩ. PL (\(r_D\) = 0.01 kΩ): \(2.3(R_x + 6.01) < 5.3R_x\) → \(R_x > 4.608\) kΩ. (Only the conducting diode's \(r_D\) enters, because the off diode carries no current.)

Also highlighted: P4.2 (four single-diode circuits; answers (a) −3 V, 0.6 mA (b) 0, +3 V (c) +3 V, 0.6 mA (d) 0, −3 V) and P4.3 (OR/AND pairs; (a) D2 on, 2 V, 2.5 mA (b) D1 on, 1 V, 1 mA). Work them from the book's figures.

Key terms

Quick check

Summary: list the cases, strike the impossible ones with a reason, solve the likely one, check every diode (on: \(I > 0\); off: \(V_{AK} < V_{D0}\)), and write down every rejected case. For "range of R" keep R as a symbol in the fixed state and turn the checks into inequalities; the boundary is where the off diode reaches its threshold with zero current. OR gate = max − 0.7, AND gate = min + 0.7.
