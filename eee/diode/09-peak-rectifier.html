The Peak Rectifier: Ripple, Conduction Angle and Diode Current

This is the most frequent diode numerical in recent finals. It was compulsory in 2023–24 (Q1(b), bridge with C, 15 marks) and in 2024–25 (Q5(b), half-wave with C, 20 marks), and it appeared in 2014–15, 2015–16, 2016–17 and 2017–18. The "comment on RC" theory part came in 2018–19 and 2019–20. Every question uses the same seven formulas in the same order: learn the order and the three traps (f or 2f, the diode drops, and what "average diode current" means), and these are full marks.

1. What the capacitor does

Put a capacitor \(C\) across the load \(R\) of a rectifier. While the input rises, the diode conducts and charges \(C\) to the peak \(V_p\). Just after the peak the input falls faster than the capacitor can discharge through \(R\), so the diode turns off and \(C\) feeds the load alone. The output decays slowly (time constant \(RC\)) until the next input peak catches up with it; the diode then conducts for a short interval \(\Delta t\) and tops \(C\) up again.

\(V_p\)
Peak output: input peak minus the diode drops in the conducting path (HW and centre-tap: one \(V_D\); bridge: \(2V_D\)).
\(V_r\)
Peak-to-peak ripple: \(V_p\) minus the lowest output just before the diode turns on again. "10 % ripple" means \(V_r = 0.1V_p\).
\(I_L\)
Load current, almost constant: Sedra takes \(I_L \approx V_p/R\). Some solutions use \(V_{dc}/R\); both are accepted (about 3 % apart) if you say which.
\(\omega\Delta t\)
Conduction angle in radians. The fraction of a cycle the diode conducts is \(\omega\Delta t/2\pi\).
\(i_{D,av}\), \(i_{D,max}\)
Average diode current during conduction and peak diode current. Sedra's "average diode current" means the average over \(\Delta t\), not over the whole cycle.

2. Ripple voltage (derivation asked as theory)

After the peak the diode is off and \(C\) discharges through \(R\): \(v_O = V_pe^{-t/RC}\). The discharge lasts almost a full period \(T\) (half-wave), so the lowest output is \(V_L = V_pe^{-T/RC}\). With \(RC \gg T\), use \(e^{-x} \approx 1 - x\) (the Maclaurin step Sadat sir showed, notes p.28):

\[ V_r = V_p - V_L = V_p\left(1 - e^{-T/RC}\right) \approx V_p\frac{T}{RC} = \frac{V_p}{fRC} = \frac{I_L}{fC} \]

For a full-wave rectifier (centre-tap or bridge) the capacitor is recharged twice per cycle, so the discharge lasts \(T/2\):

\[ V_r = \frac{V_p}{2fRC},\qquad V_{dc} = V_p - \tfrac12 V_r \ \text{(both)} \]

Validity: \(V_r \ll V_p\) (ripple under about 20 %), i.e. \(RC \gg T\) (HW) or \(RC \gg T/2\) (FW). The ripple frequency is \(f\) for HW and \(2f\) for FW.

3. Conduction angle

Take \(t = 0\) at the input peak. The diode switches on at \(t = -\Delta t\), where the input equals the lowest output:

\[ V_p\cos(\omega\Delta t) = V_p - V_r \;\Rightarrow\; 1 - \tfrac12(\omega\Delta t)^2 \approx 1 - \frac{V_r}{V_p} \;\Rightarrow\; \omega\Delta t = \sqrt{\frac{2V_r}{V_p}} \]

Fraction of the cycle the diode conducts \(= \omega\Delta t/2\pi\). In a full-wave circuit this is still the fraction for each diode (or diode pair); the capacitor is being charged for twice that fraction of the time.

4. Diode currents (derivation)

Average during conduction (charge balance, half-wave). In steady state the charge put into \(C\) during \(\Delta t\) equals the charge it gives the load over the period: \(i_{C,av}\Delta t = CV_r\). With \(CV_r = I_LT\) (from \(V_r = I_L/fC\)) and \(\Delta t = (\omega\Delta t)/\omega = (\omega\Delta t)T/2\pi\):

\[ i_{C,av} = \frac{I_LT}{\Delta t} = \frac{2\pi I_L}{\omega\Delta t} = \pi I_L\sqrt{\frac{2V_p}{V_r}},\qquad i_{D,av} = i_{C,av} + I_L = I_L\left(1 + \pi\sqrt{\frac{2V_p}{V_r}}\right) \]

Peak. At the start of conduction the capacitor current is \(i_C = C\,dv_I/dt = C\omega V_p\sin(\omega\Delta t) \approx C\omega V_p(\omega\Delta t)\). With \(\omega C = 2\pi fC = 2\pi I_L/V_r\):

\[ i_{C,max} = \frac{2\pi I_L V_p}{V_r}\sqrt{\frac{2V_r}{V_p}} = 2\pi I_L\sqrt{\frac{2V_p}{V_r}},\qquad i_{D,max} = I_L\left(1 + 2\pi\sqrt{\frac{2V_p}{V_r}}\right) \]

Full-wave: \(C\) is half as large for the same ripple, so the \(\pi\) terms halve (\(\tfrac12\sqrt{2V_p/V_r} = \sqrt{V_p/2V_r}\)):

\[ i_{D,av} = I_L\left(1 + \pi\sqrt{\frac{V_p}{2V_r}}\right),\qquad i_{D,max} = I_L\left(1 + 2\pi\sqrt{\frac{V_p}{2V_r}}\right) \]

Sadat sir's class sheet (Ikra p.25, Khairul s.40–42) writes the same results in Neamen's form with \(V_M = V_p\): full-wave \(i_{D,peak} = \frac{V_M}{R}\bigl(1 + \pi\sqrt{2V_M/V_r}\bigr)\), \(i_{D,avg} = \frac{V_M}{R}\bigl(1 + \frac{\pi}{2}\sqrt{2V_M/V_r}\bigr)\), \(i_{C,peak} = \pi\frac{V_M}{R}\sqrt{2V_M/V_r}\), \(i_{C,avg} = \frac{\pi}{2}\frac{V_M}{R}\sqrt{2V_M/V_r}\); half-wave doubles every \(\pi\) term. Since \(\frac12\sqrt{2V_M/V_r} = \sqrt{V_M/2V_r}\), these are identical to the boxes above.

Averaged over the whole cycle the diode current is simply \(I_L\) (HW) or \(I_L/2\) per diode (FW). Give this too if a question says "average over the cycle" (Neamen's design example asks for it: \(i_{D,av}\times\Delta t/T\)).

5. PIV and the summary table

With a capacitor the output stays near \(V_p\) while the input swings to \(-V_s\). Half-wave: the diode sees \(V_p + V_s = 2V_s - V_D \approx 2V_p\). Centre-tap: \(2V_s - V_D\). Bridge: \(V_s - V_D\) (an off diode is in parallel with an on diode plus the load).

6. Peak rectifier from a ripple spec (types D-06, D-07)

Method · seven steps, always in this order

  1. Peak input: \(V_s = \sqrt2V_{rms}\) of the secondary. With a transformer, divide the primary rms by the turns ratio first (120 V, 10:1 → 12 V rms → 16.97 V).
  2. Peak output: \(V_p = V_s - V_D\) (HW, CT) or \(V_s - 2V_D\) (bridge). \(I_L = V_p/R\) (say if you use \(V_{dc}/R\)).
  3. Ripple: \(V_r\) from the spec (x % of \(V_p\), or volts). Then \(C = \dfrac{V_p}{fRV_r}\) (HW) or \(\dfrac{V_p}{2fRV_r}\) (FW).
  4. DC output: \(V_{dc} = V_p - V_r/2\).
  5. Conduction: \(\omega\Delta t = \sqrt{2V_r/V_p}\) rad; fraction \(= \omega\Delta t/2\pi\).
  6. Currents: HW \(i_{D,av} = I_L(1+\pi\sqrt{2V_p/V_r})\), \(i_{D,max} = I_L(1+2\pi\sqrt{2V_p/V_r})\); FW use \(\sqrt{V_p/2V_r}\).
  7. PIV: HW and CT \(2V_s - V_D\); bridge \(V_s - V_D\).

Worked example: 2024–25 Sec B Q5(b), half-wave

Worked example: 2023–24 Sec A Q1(b), bridge

Variant: C is given, find the ripple

Run the method backwards: \(V_r = V_p/(fRC)\) or \(V_p/(2fRC)\), then steps 4 to 7. Check \(V_r/V_p\): if it is not small (say above 0.2), the linear formulas are poor; say so and, if asked, use the exact \(V_r = V_p(1 - e^{-T/RC})\) (or \(T/2\) for FW).

Variant: design the supply (choose the transformer and C)

Method · design from a required output (Neamen, Khairul s.43–44)

  1. \(R = V_{p}/I_L\) from the required peak output and load current.
  2. Required secondary peak: \(V_s = V_p + 2V_D\) (bridge) or \(V_p + V_D\) (CT per half, HW). Secondary rms \(= V_s/\sqrt2\).
  3. Turns ratio \(N_1/N_2 = V_{line,rms}/V_{s,rms}\).
  4. \(V_r\) from the ripple spec; \(C = V_p/(2fRV_r)\) (FW) or \(V_p/(fRV_r)\) (HW).
  5. Diode ratings: \(i_{D,max}\) and PIV as above.

Variant: triangular input (2016–17)

With a triangle of peak \(V_{pk}\) and frequency \(f\), the input slope is \(S = 4V_{pk}f\) (it rises \(2V_{pk}\) in \(T/2\)). The output discharges almost linearly at \(V_p/RC\) for the time \(T - \Delta t\), and the diode turns on when the rising input meets it, \(\Delta t = V_r/S\) before the peak:

\[ V_r = \frac{V_p}{RC}(T - \Delta t),\quad \Delta t = \frac{V_r}{S} \;\Rightarrow\; V_r = \frac{V_pT/RC}{1 + V_p/(RCS)};\qquad i_C = CS,\quad i_{D,max} \approx CS + \frac{V_p}{R} \]

During conduction the capacitor current is constant (\(C\,dv/dt\) with a constant slope), so the average and the peak diode current are nearly equal. The shortcut \(V_r \approx V_pT/RC\) (ignoring \(\Delta t\)) is also accepted.

7. Comment on the RC time constant (theory, 2018–19, 2019–20)

  • Need \(RC \gg T\) (HW) or \(RC \gg T/2\) (FW), so the output barely decays between peaks: \(V_r \approx V_p/(fRC)\) or \(V_p/(2fRC)\).
  • Larger \(RC\): smaller ripple and \(V_{dc} = V_p - V_r/2\) closer to \(V_p\).
  • But larger \(RC\) shortens the conduction angle \(\omega\Delta t = \sqrt{2V_r/V_p}\), so the same charge must enter in a shorter time: the peak diode current \(i_{D,max} \approx I_L(1 + 2\pi\sqrt{2V_p/V_r})\) grows, and the switch-on surge (empty capacitor) grows too.
  • Small \(RC\): large ripple, lower \(V_{dc}\), gentler diode currents. Choose the smallest \(C\) that meets the ripple spec and check the diode's peak and surge ratings.
  • Full-wave halves the ripple for the same \(C\) (or halves \(C\) for the same ripple).

Traps (where marks go)

  • f vs 2f: \(V_r = V_p/(fRC)\) for half-wave, \(V_p/(2fRC)\) for full-wave and bridge.
  • Forgetting the diode drops in \(V_p\): a bridge loses \(2V_D\). One 2023–24 senior solution used 16.97 V instead of 15.37 V and got C = 1.414 mF (wrong; correct 1.28 mF).
  • \(V_{dc}\) with a filter is \(V_p - V_r/2\), not the unfiltered average \((2/\pi)V_s - 2V_D\). The same senior solution wrote 9.2 V (correct 14.87 V) and every current after it was wrong.
  • "Average diode current" = average during conduction, \(I_L(1+\pi\sqrt{\cdot})\), hundreds of mA, not \(I_L\). The Gemini question bank gives \(I_L\) for 2024–25: wrong.
  • Using the half-wave current formula for a full-wave circuit: the square root becomes \(\sqrt{V_p/2V_r}\).
  • "10 % ripple" is a fraction of the peak output \(V_p\), not of \(V_s\) or \(V_{rms}\).
  • PIV of a half-wave peak rectifier is about \(2V_p\), not \(V_p\) (that is the no-capacitor value).

Exam questions

2024–25 · Sec B · Q5(b) · 20 marks · compulsory

A half-wave rectifier with a 1 kΩ load operates from a 120 V (rms) 60 Hz household supply through a 10-to-1 step-down transformer. A capacitor C is connected across the load so that the peak-to-peak ripple is 10 % of the peak output. The diode has a 0.7 V drop at any current. (i) Find C. (ii) Find the new C for a 1 % ripple. (iii) Find the average output voltage in each case. (iv) For what fraction of the cycle does the diode conduct in each case? (v) Find the average and peak diode currents in each case.

Show worked answer

Secondary: \(12\) V rms, \(V_s = 12\sqrt2 = 16.97\) V. \(V_p = 16.97 - 0.7 = 16.27\) V. \(I_L \approx V_p/R = 16.27\) mA.

(i) \(V_r = 0.1\times16.27 = 1.627\) V. \(C = \dfrac{V_p}{fRV_r} = \dfrac{1}{0.1\times60\times1000} = 166.7\ \mu\)F.

(ii) \(V_r = 0.1627\) V, \(C = \dfrac{1}{0.01\times60\times1000} = 1667\ \mu\)F.

(iii) \(V_{dc} = V_p - V_r/2\): \(16.27 - 0.81 = 15.46\) V (10 %); \(16.27 - 0.08 = 16.19\) V (1 %).

(iv) \(\omega\Delta t = \sqrt{2V_r/V_p} = \sqrt{0.2} = 0.447\) rad → \(0.447/2\pi = 7.1\%\) of the cycle (10 %); \(\sqrt{0.02} = 0.141\) rad → 2.25 % (1 %).

(v) \(\sqrt{2V_p/V_r} = \sqrt{20} = 4.47\) (10 %) and \(\sqrt{200} = 14.14\) (1 %).

10 %: \(i_{D,av} = 16.27(1 + \pi\times4.47) = 245\) mA; \(i_{D,max} = 16.27(1 + 2\pi\times4.47) = 473\) mA.

1 %: \(i_{D,av} = 16.27(1 + \pi\times14.14) = 739\) mA; \(i_{D,max} = 16.27(1 + 2\pi\times14.14) = 1.46\) A.

Comment: ten times less ripple needs ten times the capacitance and triples the diode currents. (With \(I_L = V_{dc}/R\): 233/450 mA and 736 mA/1.455 A.) The cycle-average diode current is just \(I_L\), about 16 mA; that is not what "average diode current" asks for.

2023–24 · Sec A · Q1(b) · 15 marks · compulsory

Consider a bridge rectifier with a filter capacitor C placed across the load resistor R = 100 Ω, for the case in which the transformer secondary delivers a sinusoid of 12 V (rms) at 60 Hz. Assume \(V_D\) = 0.8 V. (i) Find C such that the ripple across R is no larger than 1 V peak-to-peak. (ii) What is the dc voltage at the output? (iii) Find the load current. (iv) Find the average and peak diode currents. (v) What is the peak reverse voltage across each diode?

Show worked answer

\(V_s = 12\sqrt2 = 16.97\) V. Bridge: two drops, \(V_p = 16.97 - 1.6 = 15.37\) V.

(i) \(C = \dfrac{V_p}{2fRV_r} = \dfrac{15.37}{2\times60\times100\times1} = 1.281\) mF (1281 µF).

(ii) \(V_{dc} = 15.37 - 0.5 = 14.87\) V.

(iii) \(I_L = V_{dc}/R = 148.7\) mA (Sedra's \(V_p/R\) gives 153.7 mA).

(iv) \(\sqrt{V_p/2V_r} = \sqrt{7.685} = 2.772\); \(\omega\Delta t = \sqrt{2/15.37} = 0.361\) rad.

\(i_{D,av} = 0.1487(1 + \pi\times2.772) = 1.44\) A; \(i_{D,max} = 0.1487(1 + 2\pi\times2.772) = 2.74\) A. (With \(I_L = V_p/R\): 1.49 A and 2.83 A.) Each diode's average over the whole cycle is \(I_L/2 = 74\) mA.

(v) PIV \(= V_s - V_D = 16.97 - 0.8 = 16.17\) V.

Senior solution warning: one circulating solution ("EEE263 TF 23-24 solution") ignores the diode drops and uses the unfiltered average: C = 1.414 mF, \(V_{dc}\) = 9.2 V, \(I_L\) = 92 mA, \(i_D\) = 0.93 A / 1.776 A. All wrong except the PIV. The other file ("eee 23-24 solve") has 1.28 mF, 14.87 V, 0.148 A, 1.43 A, 2.72 A: correct to rounding.

2018–19 · Sec A · Q1(c) · 10 marks  |  also 2019–20 Sec A Q1(a) (second half of a 20-mark question)

Comment on the value of the RC time constant for a rectifier circuit.

Show worked answer

Draw a peak-rectifier output (Figure 1) with \(V_p\), \(V_r\), \(\Delta t\) marked, then write the points of section 7:

(1) The filter works only if \(RC \gg T\) (HW) or \(RC \gg T/2\) (FW); then \(V_r \approx V_p/(fRC)\) or \(V_p/(2fRC)\). (2) Increasing \(RC\) reduces the ripple and raises \(V_{dc} = V_p - V_r/2\) toward \(V_p\). (3) But the conduction angle \(\omega\Delta t = \sqrt{2V_r/V_p}\) shrinks, so the diode must deliver the whole period's charge in a shorter pulse: \(i_{D,max} = I_L(1 + 2\pi\sqrt{2V_p/V_r})\) rises (example: 10 % ripple gives about 29 \(I_L\), 1 % gives about 90 \(I_L\)), and the inrush when \(C\) starts empty is larger. (4) Too small an \(RC\) gives large ripple. So choose the smallest \(C\) that meets the ripple specification and pick diodes rated for the peak and surge current.

2017–18 · Sec A · Q4(a) · 10⅔ marks  |  Sedra example

Consider a peak rectifier fed by a 60 Hz sinusoid having a peak value \(V_p\) = 100 V. Let the load resistance R = 10 kΩ. Find the value of the capacitance C that will result in a peak-to-peak ripple of 2 V. Also calculate the fraction of the cycle during which the diode is conducting and the average and peak values of the diode current.

Show worked answer

Ideal diode (none given), half-wave. \(I_L = 100/10 = 10\) mA.

\(C = \dfrac{V_p}{fRV_r} = \dfrac{100}{60\times10^4\times2} = 83.3\ \mu\)F.

\(\omega\Delta t = \sqrt{2\times2/100} = 0.2\) rad → \(0.2/2\pi = 3.18\%\) of the cycle.

\(\sqrt{2V_p/V_r} = \sqrt{100} = 10\): \(i_{D,av} = 10(1 + 10\pi) = 324\) mA; \(i_{D,max} = 10(1 + 20\pi) = 638\) mA.

2016–17 · Sec B · Q5(a) · 20 marks

Consider a half-wave peak rectifier fed with a voltage having a triangular waveform with 20 V peak-to-peak amplitude, zero average and 1 kHz frequency. Load resistance R = 100 Ω and filter capacitor C = 100 µF. The diode has a forward drop of 0.7 V when conducting. Find (i) the average dc output voltage, (ii) the time interval during which the diode conducts, (iii) the average diode current during conduction, (iv) the maximum diode current.

Show worked answer

\(V_{pk} = 10\) V, \(T = 1\) ms, slope \(S = 20\text{ V}/0.5\text{ ms} = 40\) V/ms. \(V_p = 10 - 0.7 = 9.3\) V. \(RC = 100\times100\ \mu\text{F} = 10\) ms \(\gg T\) ✓.

Ripple and conduction: linear discharge at \(V_p/RC = 0.93\) V/ms for \(T - \Delta t\), and \(\Delta t = V_r/S\): \(V_r = \dfrac{0.93\times1}{1 + 0.93/40} = 0.909\) V, \(\Delta t = 0.909/40 = 22.7\ \mu\)s.

(i) \(V_{dc} = 9.3 - 0.909/2 = 8.85\) V. (ii) \(\Delta t \approx 22.7\ \mu\)s.

(iii) During conduction \(i_C = C\,dv/dt = 100\ \mu\text{F}\times40\text{ V/ms} = 4.0\) A (constant), plus the load \(\approx 8.85/100 = 0.088\) A: \(i_{D,av} \approx 4.09\) A.

(iv) \(i_{D,max} \approx 4.0 + 9.3/100 = 4.09\) A (the current is almost flat during the short pulse).

Shortcut \(V_r \approx V_pT/RC = 0.93\) V gives \(\Delta t = 23.3\ \mu\)s and \(V_{dc} = 8.84\) V; also accepted. Exact exponential discharge: \(\Delta t = 21.7\ \mu\)s, \(V_r = 0.867\) V.

2015–16 · Sec A · Q1(b) · 16⅔ marks

Draw the circuit diagram of a full-wave rectifier with a filter capacitor. Assume the input is a sinusoidal signal with 10 kHz frequency and 7.07 V rms voltage, the load is a 1 kΩ resistor and the capacitor used is 1 µF. The diode has a forward voltage drop of 0.7 V. Find (i) the ripple voltage; (ii) the PIV and duty cycle; (iii) the peak output voltage.

Show worked answer

The topology is not specified: state it. Draw the bridge (Figure 4). \(V_s = 7.07\sqrt2 = 10.0\) V.

Bridge: (iii) \(V_p = 10 - 1.4 = 8.6\) V. (i) \(V_r = \dfrac{8.6}{2\times10^4\times1000\times10^{-6}} = 0.43\) V (exact \(V_p(1 - e^{-T/2RC}) = 0.419\) V). (ii) PIV \(= V_s - V_D = 9.3\) V. \(\omega\Delta t = \sqrt{2\times0.43/8.6} = 0.316\) rad, so each diode conducts \(0.316/2\pi = 5.03\%\) of the cycle (the capacitor charges 10.1 % of the time).

If you draw a centre-tapped circuit with 7.07 V rms on each half: \(V_p = 9.3\) V, \(V_r = 0.465\) V, PIV \(= 2V_s - V_D = 19.3\) V, duty 5.03 %.

2014–15 · Sec A · Q1(c) · 20 marks

A peak rectifier circuit is operated with a 1 kΩ load and a diode that can be modelled to have a 0.7 V drop at any current. It is fed by a 50 Hz sinusoid and the capacitor is chosen to provide a peak-to-peak ripple of 10 % of the peak output voltage. (i) What is the value of the capacitor? (ii) What fraction of the cycle does the diode conduct? (iii) What is the average diode current? (iv) What is the peak diode current? Consider the load current \(I_L\) = 15 mA.

Show worked answer

\(I_L = 15\) mA with 1 kΩ gives \(V_p = 15\) V (input peak 15.7 V); \(V_r = 1.5\) V.

(i) \(C = \dfrac{I_L}{fV_r} = \dfrac{15\text{ mA}}{50\times1.5} = 200\ \mu\)F.

(ii) \(\omega\Delta t = \sqrt{0.2} = 0.447\) rad → 7.12 % of the cycle.

(iii) \(i_{D,av} = 15(1 + \pi\sqrt{20}) = 225.7\) mA. (iv) \(i_{D,max} = 15(1 + 2\pi\sqrt{20}) = 436.5\) mA.

Class examples

Khairul s.43–44 · Neamen design example (also pasted in Sadat sir's class notes, Ikra p.28)

A full-wave rectifier is to produce a peak output of 12 V, deliver 120 mA to the load and have a ripple of not more than 5 %. A 120 V (rms), 60 Hz line is available. Design it: choose the circuit, the transformer turns ratio, C, and give the diode ratings.

Show worked answer

Bridge (no centre tap, lower PIV). \(R = 12/0.12 = 100\) Ω. \(V_s = 12 + 2(0.7) = 13.4\) V peak = 9.48 V rms; \(N_1/N_2 = 120/9.48 = 12.7\).

\(V_r = 0.05\times12 = 0.6\) V; \(C = \dfrac{12}{2\times60\times100\times0.6} = 1667\ \mu\)F.

\(i_{D,max} = 0.12(1 + \pi\sqrt{2\times12/0.6}) = 2.50\) A (Neamen's full-wave form \(1 + \pi\sqrt{2V_M/V_r}\) is the same as Sedra's \(1 + 2\pi\sqrt{V_p/2V_r}\)). Average over the whole period: \(\frac{1}{\pi}\sqrt{2V_r/V_M}\,I_L(1 + \frac{\pi}{2}\sqrt{2V_M/V_r}) = 132\) mA. PIV \(= 13.4 - 0.7 = 12.7\) V.

Key terms

Quick check

Summary: \(V_s = \sqrt2V_{rms}\) → \(V_p\) (subtract one or two \(V_D\)) → \(C = V_p/(fRV_r)\) (HW) or \(V_p/(2fRV_r)\) (FW) → \(V_{dc} = V_p - V_r/2\) → \(\omega\Delta t = \sqrt{2V_r/V_p}\) → \(i_{D,av} = I_L(1+\pi\sqrt{2V_p/V_r})\), \(i_{D,max} = I_L(1+2\pi\sqrt{2V_p/V_r})\) with \(\sqrt{V_p/2V_r}\) for full-wave → PIV \(2V_s - V_D\) (HW, CT) or \(V_s - V_D\) (bridge). Larger \(C\): less ripple, bigger diode current pulses.
