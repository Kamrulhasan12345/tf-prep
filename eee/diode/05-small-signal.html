The Small-Signal Model

Small-signal diode questions appeared in both of the last two papers: the 2023–24 compulsory Q1(a) (a diode phase shifter, 20 marks) and 2024–25 Q7(b)(ii) (load regulation of a diode string), plus 2014–15 (16 marks), this batch's CT-1 Q1 and assignment Q2. Sadat sir starred the superposition example in class. The recipe is always the same: DC first, then \(r_d = nV_T/I_D\), then an AC circuit with the DC sources killed.

1. Derivation of \(r_d\) (write it like this)

Bias the diode at \(V_D, I_D\) and add a small \(v_d\):

\[ i_D = I_Se^{(V_D + v_d)/nV_T} = I_D\,e^{v_d/nV_T} = I_D\left[1 + \frac{v_d}{nV_T} + \frac{1}{2!}\left(\frac{v_d}{nV_T}\right)^2 + \dots\right] \]

If \(v_d \ll nV_T\) keep two terms: \(i_D \approx I_D + \dfrac{I_D}{nV_T}v_d\), so \(i_d = \dfrac{I_D}{nV_T}v_d\) and

\[ r_d = \frac{v_d}{i_d} = \frac{nV_T}{I_D}\qquad\left(= \left.\frac{\partial v_D}{\partial i_D}\right|_{I_D}\right) \]

25 Ω at 1 mA (n = 1). Validity: \(|v_d|\) of about 5–10 mV. It is the inverse slope of the tangent at Q.

2. The superposition recipe

Method · DC + small signal

  1. DC (signal off): find \(I_D\) of every diode (CVD, or exponential with SOLVE).
  2. \(r_d = nV_T/I_D\) for each.
  3. AC: kill the DC sources (DC voltage source → short, DC current source → open), short large capacitors only if they are coupling caps, replace each diode by \(r_d\).
  4. Solve the AC circuit (divider, current divider, impedance).
  5. Total = DC + AC, e.g. \(i_o = 0.6345 + 5.90\times10^{-4}\cos\omega t\) mA.

Worked example: Sadat L5, notes p.12

3. Diode voltage regulators

A string of N diodes fed through R holds a nearly constant voltage. With \(r_d\) per diode:

\[ \text{line regulation } \frac{\Delta V_o}{\Delta V_S} = \frac{Nr_d}{Nr_d + R},\qquad \text{load regulation } \frac{\Delta V_o}{\Delta I_L} = -(Nr_d\parallel R) \]

Valid while the load current is small compared with the bias current (2024–25: 1 mA on 7.9 mA, fine; CT 2022: a 150 Ω load taking about half the current, not fine).

4. Phase shifter: the diode as a current-controlled resistor

With a DC current source I biasing the diode and a capacitor C to ground, the AC circuit is \(v_i\) → \(r_d\) → C: an RC low-pass with \(R = r_d = nV_T/I\). Changing I changes the phase.

\[ \frac{V_o}{V_i} = \frac{1}{1 + j\omega Cr_d},\qquad \phi = -\tan^{-1}(\omega Cr_d);\qquad \phi = -45^\circ \iff r_d = \frac{1}{\omega C},\ I = nV_T\omega C \]

Scaling I by k divides \(r_d\) by k: \(\phi = -\tan^{-1}(1/k)\) from the −45° point (k = 0.1 → −84.3°, k = 10 → −5.7°).

5. How small is small?

Exact: \(\Delta i/I_D = e^{v_d/nV_T} - 1\); linear model: \(v_d/nV_T\). For a limit x on the change: \(v_d = nV_T\ln(1 + x)\) (positive) and \(nV_T\ln(1 - x)\) (negative).

Traps (where marks go)

  • Leaving the DC current source in the AC circuit: it is an open.
  • Putting R in series with the string for \(R_{out}\): it is in parallel.
  • Sign: \(V_o\) falls when load current is drawn; the phase is a lag (negative). A senior solution of 2023–24 gives "95.7° to 174.3°": a 180° error. The answer is −84.3° to −5.7°.
  • ±10 mV is not ±40 %: the exact changes are +49.2 % and −33.0 %.
  • Carry \(I_D\) to 4 figures: the CT-1 script wrote 4.3589 mA instead of 4.3655 mA (it only moves \(r_d\) from 5.933 to 5.942 Ω, but costs the 4th digit).

Exam questions

2023–24 · Sec A · Q1(a) · 20 marks · compulsory

I is a dc current source and \(V_i\) a sinusoid of small amplitude (< 10 mV) and frequency 100 kHz; C = 10 nF. (i) Representing the diode by \(r_d\) (a function of I), sketch the circuit for finding the sinusoidal output \(V_o\) across the capacitor. (ii) Find the phase shift between \(V_i\) and \(V_o\). (iii) Find I for a phase shift of −45°. (iv) Find the range of phase shift as I varies from 0.1 to 10 times that value. n = 1.

Show worked answer

(i) DC: I flows down through the diode (and \(V_i\)'s branch) so \(r_d = V_T/I\). AC: the current source is open; \(V_i\) drives \(r_d\) in series to node a, and C from a to ground.

(ii) \(\dfrac{V_o}{V_i} = \dfrac{1/j\omega C}{r_d + 1/j\omega C} = \dfrac{1}{1 + j\omega Cr_d}\), so \(\phi = -\tan^{-1}(\omega CV_T/I)\) (\(V_o\) lags).

(iii) −45° when \(\omega Cr_d = 1\): \(r_d = \dfrac{1}{2\pi\times10^5\times10^{-8}} = 159.15\) Ω, \(I = 25\text{ mV}/159.15\text{ Ω} = 0.157\) mA (157 µA).

(iv) I = 15.7 µA: \(r_d\) = 1591.5 Ω, \(\phi = -\tan^{-1}10 = -84.3°\). I = 1.57 mA: \(r_d\) = 15.9 Ω, \(\phi = -\tan^{-1}0.1 = -5.7°\). Range: −84.3° to −5.7° (lagging). (A senior solution writes 95.7° to 174.3°: wrong by 180°.)

2024–25 · Sec B · Q7(b)(ii) · part of 15 marks (part (i) in Chapter 4)

Three identical diodes (\(I_S = 10^{-16}\) A) fed from +10 V through R hold \(V_o\) = 2.4 V (I = 7.896 mA, R = 962.5 Ω). If 1 mA is drawn by a load, find the change in output voltage.

Show worked answer

\(r_d = 25/7.896 = 3.166\) Ω; string \(3r_d = 9.50\) Ω. AC: supply shorted, so \(R_o = 9.50\parallel962.5 = 9.405\) Ω. \(\Delta V_o = -1\times9.405 = -9.41\) mV (−9.50 mV ignoring R; exact −10.0 mV).

2014–15 · Sec A · Q1(b) · 16 marks

The small-signal model is said to be valid for voltage variations of about 10 mV. To what percentage current change does this correspond (n = 1, both polarities)? What is the maximum allowable signal (positive or negative) if the current change is limited to 10 %?

Show worked answer

\(\Delta i/I_D = e^{v_d/V_T} - 1\): +10 mV → \(e^{0.4} - 1\) = +49.2 %; −10 mV → \(e^{-0.4} - 1\) = −33.0 % (the linear model would say ±40 %).

10 % limit: \(v_d = 25\ln1.1 = +2.38\) mV and \(25\ln0.9 = -2.63\) mV. The binding one is about 2.4 mV in magnitude (the linear model would say 2.5 mV).

Class tests and assignment

CT-1, this batch (Jan 2026), Sec A · Q1 · 10 marks

Using the small-signal model, find an expression for \(i_o\) if \(I_x = 5 + 0.1\cos\omega t\) mA. The diode follows the exponential model with \(I_s\) = 0.1 pA. (\(I_x\) feeds node A; 1 kΩ from A to ground carries \(i_o\); the diode from A to ground.)

Show worked answer

Using Sadat sir's \(V_T\) = 25.9 mV. DC: \(5 = V_D/1 + 10^{-10}e^{V_D/0.0259}\) (mA) → SOLVE: \(V_D\) = 0.6345 V. \(I_R\) = 0.6345 mA, \(I_D = 5 - 0.6345 = 4.3655\) mA (the scanned script wrote 4.3589: a slip).

\(r_d = 25.9/4.3655 = 5.933\) Ω.

AC: 0.1 cos ωt mA splits between 1 kΩ and \(r_d\): \(i_o = 0.1\times\dfrac{5.933}{1000 + 5.933}\cos\omega t = 5.90\times10^{-4}\cos\omega t\) mA.

\(i_o = 0.6345 + 5.90\times10^{-4}\cos\omega t\) mA. (With 25 mV: 0.6126 + 5.67×10⁻⁴ cos ωt mA.)

CT-1(C) 2022 (earlier batch)

+5 V — 180 Ω — \(V_o\); two diodes (0.7 V at 10 mA) to ground. Find the line regulation and the output resistance, and the change when 150 Ω is connected.

Show worked answer

DC (Chapter 4): \(V_o\) = 1.434 V, I = 19.8 mA, \(r_d = 25/19.8 = 1.262\) Ω each. Line regulation \(= 2.524/(2.524 + 180) = 13.8\) mV/V. \(R_{out} = 2.524\parallel180 = 2.49\) Ω. 150 Ω load: small-signal \(\Delta V_o \approx -(1.434/150)\times2.49 = -23.8\) mV, but exact gives −31 mV: the load (9.5 mA) is not small against 19.8 mA.

Assignment · Q2 (posted solution uses \(V_T\) = 26 mV)

+5 V — 10 kΩ — node N; 10 kΩ from N to ground; \(v_s = 2\sin\omega t\) mV through 10 kΩ into N; diode from N to O; 20 kΩ from O to ground. The diode has 0.2 mA at 0.7 V. Find \(v_o\).

Show worked answer

Thevenin at N: \(V_{TH} = 5/3\) V, \(R_{TH}\) = 3.33 kΩ. DC: \((1.667 - V_D)/23.33 = 0.2e^{(V_D - 0.7)/0.026}\) → \(V_D\) = 0.660 V, \(I_D\) = 43.1 µA, \(V_O\) = 0.863 V. \(r_d = 26/0.0431 = 603\) Ω. AC: \(v_{th} = v_s/3\); \(v_o/v_s = \frac13\times\frac{20}{3.333 + 0.603 + 20} = 0.2785\). \(v_o\) = 0.863 V + 0.557 sin ωt mV.

Key terms

Quick check

Summary: \(r_d = nV_T/I_D\) from the Maclaurin series, valid for a few mV. DC first, then AC with DC voltage sources shorted and current sources opened, diode → \(r_d\), then add. Strings: line \(Nr_d/(Nr_d + R)\), load \(-(Nr_d\parallel R)\). Phase shifter: \(\phi = -\tan^{-1}(\omega CnV_T/I)\).
