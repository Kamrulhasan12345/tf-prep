I–V Regions, Triode Resistance and Channel-Length Modulation

The equation sheet behind every MOSFET question. In the finals it appears directly as a 10-mark numerical (2023–24: find \(\lambda\), \(V_A\), \(r_o\) from two points) and as region-and-equation theory for PMOS (2024–25, 8 marks) and NMOS (2022–23, 7 marks). Everywhere else it is the region check at the end of a bias problem. Learn the table in section 1 cold, including the PMOS column: the exam and Sadat sir both mark a wrong PMOS sign.

Units: mA, V, kΩ, mA/V². Sedra's law \(i_D = \tfrac12k_n'(W/L)V_{OV}^2\) throughout.

1. The region table

NMOSPMOS
Cut-off\(v_{GS} < V_t\); \(i_D = 0\)\(v_{SG} < |V_{tp}|\); \(i_D = 0\)
Triode (continuous channel)\(v_{GS} \ge V_t\) and \(v_{DS} < v_{OV}\) (⇔ \(v_{GD} > V_t\) ⇔ \(V_D < V_G - V_t\))\(v_{SG} \ge |V_{tp}|\) and \(v_{SD} < |v_{OV}|\) (⇔ \(v_{DG} > |V_{tp}|\) ⇔ \(V_D > V_G + |V_{tp}|\))
Saturation (pinched off)\(v_{GS} \ge V_t\) and \(v_{DS} \ge v_{OV}\) (⇔ \(V_D \ge V_G - V_t\))\(v_{SG} \ge |V_{tp}|\) and \(v_{SD} \ge |v_{OV}|\) (⇔ \(V_D \le V_G + |V_{tp}|\))
\[ \text{triode: } i_D = k_n\Big[v_{OV}v_{DS} - \tfrac12v_{DS}^2\Big],\qquad \text{saturation: } i_D = \tfrac12k_nv_{OV}^2(1 + \lambda v_{DS}),\qquad k_n = k_n'\tfrac WL \]

For a PMOS replace \(v_{GS}\to v_{SG}\), \(v_{DS}\to v_{SD}\), \(V_t\to|V_{tp}|\), \(k_n\to k_p\): every voltage is measured from the source, positive as written. The source of a PMOS is its higher-voltage terminal. The boundary between triode and saturation is the parabola \(i_D = \tfrac12k_nv_{DS}^2\) (set \(v_{DS} = v_{OV}\) in either equation: both give \(\tfrac12k_nv_{OV}^2\), so the current is continuous).

2. Which region? (practice question type)

Method · region identification

  1. Find the source: NMOS = lower of the two end terminals, PMOS = higher.
  2. \(V_{GS}\) (PMOS: \(V_{SG}\)) and \(V_{OV} = V_{GS} - V_t\) (PMOS: \(V_{SG} - |V_{tp}|\)). If \(V_{OV} \le 0\): cut-off, \(i_D = 0\). Stop.
  3. \(V_{DS}\) (PMOS: \(V_{SD}\)). If \(V_{DS} \ge V_{OV}\): saturation, \(i_D = \tfrac12kV_{OV}^2\). Else triode, \(i_D = k[V_{OV}V_{DS} - \tfrac12V_{DS}^2]\).
  4. Write the comparison as a sentence ("1.5 V < 2 V ∴ triode"). Gate and drain tied together: \(V_{GD} = 0\), so saturation or cut-off, never triode.

3. Triode: the MOSFET as a resistor

For small \(v_{DS}\) (\(v_{DS} \ll v_{OV}\)) the \(\tfrac12v_{DS}^2\) term is negligible: \(i_D \approx k_nv_{OV}v_{DS}\), a linear conductance controlled by the gate.

\[ r_{DS} = \frac{v_{DS}}{i_D}\Big|_{v_{DS}\to0} = \frac{1}{k_nV_{OV}} = \frac{1}{k_n'(W/L)(V_{GS} - V_t)} \]

Example (Sedra Example 5.3): \(V_{GS}\) = 5 V, \(V_t\) = 1 V, \(k_n\) = 1 mA/V², \(V_{DS}\) = 0.1 V: exact \(i_D = 1[4(0.1) - 0.005] = 0.395\) mA, \(v_{DS}/i_D\) = 253 Ω against \(1/(k_nV_{OV})\) = 250 Ω (kΩ × mA/V² = 1). The two agree to 1% while \(V_{DS} \ll V_{OV}\).

4. Channel-length modulation: \(\lambda\), \(V_A\), \(r_o\) (type M-01)

Beyond pinch-off the effective channel length shrinks, so the saturation current rises almost linearly with \(v_{DS}\):

\[ i_D = I_D'(1 + \lambda v_{DS}),\quad I_D' = \tfrac12k_nV_{OV}^2,\quad V_A = \frac1\lambda,\quad r_o = \Big[\frac{\partial i_D}{\partial v_{DS}}\Big]^{-1} = \frac{1}{\lambda I_D'} = \frac{V_A}{I_D'} \approx \frac{V_A}{I_D} \]

\(I_D'\) is the current without CLM. The extended saturation lines all meet the \(v_{DS}\) axis at \(-V_A\) (so \(V_A\) is the Early-like voltage, 10–100 V in these papers). \(r_o\) is the slope reciprocal of the saturation line; it is large, so in bias problems \(\lambda\) is set to 0 unless the question gives it.

Method · two operating points (M-01)

  1. Write \(i_1 = I_D'(1 + \lambda v_1)\) and \(i_2 = I_D'(1 + \lambda v_2)\) at the same \(v_{GS}\). Convert a percentage first: "rises 10 %" means \(i_2 = 1.10\,i_1\), not \(1.01\,i_1\).
  2. Divide: \(i_2/i_1 = (1 + \lambda v_2)/(1 + \lambda v_1)\) ⇒ \(\lambda = \dfrac{i_2 - i_1}{i_1v_2 - i_2v_1}\).
  3. \(V_A = 1/\lambda\).
  4. \(r_o = \Delta v_{DS}/\Delta i_D = (v_2 - v_1)/(i_2 - i_1)\), which equals \(V_A/I_D'\) with \(I_D' = i_1/(1 + \lambda v_1)\).

Variants. Given \(V_A\) and one point: \(I_D' = i_1/(1 + v_1/V_A)\), then \(i_D\) at any other \(v_{DS}\). Given \(\lambda\) and \(I_D\): \(r_o \approx 1/(\lambda I_D)\). Quoting \(r_o = V_A/I_D\) with the measured current gives 18 kΩ here instead of 20 kΩ; it is accepted only if you say so.

5. PMOS sign conventions in one example

PMOS, \(V_{tp}\) = −1 V, \(k_p\) = 1 mA/V², source at +5 V, gate at +3 V. \(V_{SG} = 2\) V, \(|V_{OV}| = 1\) V. Drain at 3.5 V: \(V_{SD} = 1.5\ge1\), saturation, \(i_D = \tfrac12(1)(1)^2 = 0.5\) mA. Drain at 4.5 V: \(V_{SD} = 0.5 < 1\), triode, \(i_D = 1[1(0.5) - \tfrac12(0.25)] = 0.375\) mA. The equivalent drain test, \(V_D \le V_G + |V_{tp}| = 4\) V, gives the same verdict, and is quicker when the node voltages are given. The current flows out of the drain, from source to drain, so \(V_D = I_DR_D\) for a drain resistor to ground.

Traps (where marks go)

  • Reading "10 %" as 1 % (a senior file did, and got a wrong \(\lambda\)). \(i_2 = 1.10\,i_1\).
  • \(r_o\) from \(V_A/i_D\) at the measured current: 18 kΩ instead of 20 kΩ. Use \(\Delta v/\Delta i\) or state your convention.
  • PMOS threshold as \(V_{tp}\) = −1 V in a formula written with \(V_{SG}\). Use \(|V_{tp}|\) with \(V_{SG}\), or \(V_{tp}\) with \(V_{GS}\), never mixed.
  • Applying the saturation formula first without writing the check; or calling a diode-connected device triode.
  • Triode boundary written \(v_{DS} = V_t\). It is \(v_{DS} = v_{OV}\).

Exam questions

2023–24 · Sec A · Q3(b) · 10 marks

For a particular MOSFET in saturation at constant \(v_{GS}\), \(i_D\) = 2 mA at \(v_{DS}\) = 4 V. \(i_D\) increases by 10 % when \(v_{DS}\) is doubled. What values of \(r_o\), \(V_A\) and \(\lambda\) correspond to these observations?

Show worked answer

Model \(i_D = I_D'(1 + \lambda v_{DS})\). Point 1: \(i_1\) = 2 mA at \(v_1\) = 4 V. Point 2: \(v_2\) = 8 V and \(i_2 = 1.10\times2 = 2.2\) mA.

Divide: \(\dfrac{2.2}{2} = \dfrac{1 + 8\lambda}{1 + 4\lambda}\) ⇒ \(2.2 + 8.8\lambda = 2 + 16\lambda\) ⇒ \(7.2\lambda = 0.2\) ⇒ \(\lambda = 0.0278\ \mathrm{V^{-1}}\).

\(V_A = 1/\lambda = 36\) V.

\(I_D' = 2/(1 + 0.0278\times4) = 1.8\) mA. \(r_o = V_A/I_D' = 36/1.8 = 20\) kΩ. Check: \(r_o = \Delta v_{DS}/\Delta i_D = 4\text{ V}/0.2\text{ mA} = 20\) kΩ ✓.

(\(V_A/i_D = 36/2 = 18\) kΩ is the approximation with the measured current; 20 kΩ is the consistent value. If the 10 % is read as 1 %, the numbers come out wrong by a factor of about 10.)

2024–25 · Sec A · Q4(c) · 8 marks

Explain the different operation regions of an enhancement PMOS with properly labelled \(I_D\)–\(V_{SD}\) plots. Derive the threshold conditions for operating in these regions.

Show worked answer

Source at the higher voltage; \(V_{tp} < 0\); every voltage below is measured from the source.

Cut-off. \(v_{SG} < |V_{tp}|\): no hole channel is induced, \(i_D = 0\).

Channel exists for \(v_{SG} \ge |V_{tp}|\); define \(|v_{OV}| = v_{SG} - |V_{tp}|\). The channel at distance \(x\) from the source is induced if \(v_{SG}(x) = v_{SG} - v(x)\) exceeds \(|V_{tp}|\), where \(v(x)\) rises from 0 at the source to \(v_{SD}\) at the drain. The condition is tightest at the drain end:

Triode: the channel reaches the drain, \(v_{SG} - v_{SD} > |V_{tp}|\), i.e. \(v_{SD} < v_{SG} - |V_{tp}| = |v_{OV}|\) (equivalently \(v_{DG} > |V_{tp}|\), or \(V_D > V_G + |V_{tp}|\)). Then \(i_D = k_p'(W/L)\big[(v_{SG} - |V_{tp}|)v_{SD} - \tfrac12v_{SD}^2\big]\): a curve rising from the origin, a resistor \(1/(k_p|v_{OV}|)\) at small \(v_{SD}\).

Saturation: at \(v_{SD} = |v_{OV}|\) the channel is pinched off at the drain (\(v_{DG} = |V_{tp}|\)); for \(v_{SD} \ge |v_{OV}|\) (\(V_D \le V_G + |V_{tp}|\)): \(i_D = \tfrac12k_p'(W/L)(v_{SG} - |V_{tp}|)^2(1 + |\lambda|v_{SD})\), flat with a slight slope.

Plot: \(i_D\) against \(v_{SD}\), one curve for each \(v_{SG}\) above \(|V_{tp}|\), larger \(v_{SG}\) higher; the curves leave the origin, flatten at \(v_{SD} = |v_{OV}|\), and the turning points lie on the parabola \(i_D = \tfrac12k_pv_{SD}^2\). The \(v_{SG} \le |V_{tp}|\) curve is the axis.

2022–23 · Sec A · Q1(c) · 7 marks · compulsory

Briefly explain the I–V characteristics of an n-channel enhancement MOSFET with necessary plots.

Show worked answer

Transfer curve (\(i_D\) against \(v_{GS}\), fixed \(v_{DS}\) in saturation): zero for \(v_{GS} < V_t\) (cut-off), then the parabola \(i_D = \tfrac12k_n(v_{GS} - V_t)^2\).

Output curves (\(i_D\) against \(v_{DS}\), one curve per \(v_{GS} = V_t + v_{OV}\)):

  • Triode, \(v_{DS} < v_{OV}\): \(i_D = k_n[v_{OV}v_{DS} - \tfrac12v_{DS}^2]\). Linear near the origin with slope \(k_nv_{OV}\), i.e. a resistor \(r_{DS} = 1/(k_nv_{OV})\), then bending.
  • Saturation, \(v_{DS} \ge v_{OV}\): \(i_D = \tfrac12k_nv_{OV}^2(1 + \lambda v_{DS})\): almost flat; extended back the lines meet the \(v_{DS}\) axis at \(-V_A\), slope \(1/r_o\).
  • Boundary: the parabola \(i_D = \tfrac12k_nv_{DS}^2\). Cut-off: \(v_{GS} < V_t\), the axis.

Quick check

Summary: cut-off \(V_{OV} \le 0\); triode \(V_{DS} < V_{OV}\), \(i_D = k[V_{OV}V_{DS} - \tfrac12V_{DS}^2]\), \(r_{DS} = 1/(kV_{OV})\); saturation \(V_{DS} \ge V_{OV}\), \(i_D = \tfrac12kV_{OV}^2(1 + \lambda V_{DS})\). From two points: \(\lambda = (i_2 - i_1)/(i_1v_2 - i_2v_1)\), \(V_A = 1/\lambda\), \(r_o = \Delta v/\Delta i = V_A/I_D'\). 2023–24 answer: 0.0278 V⁻¹, 36 V, 20 kΩ.
