MOSFET DC Analysis

A single-MOSFET bias problem (M-03) came in 2011–12 and 2020–21, a stack of transistors with resistors (M-05) in 2019–20 for 28 marks, and a two-stage circuit (M-06) in 2013–14 and 2016–17. The same skill is the first half of every CS-amplifier question, which appears every year. Sadat sir flagged MOSFET numericals as "important for exam" and wants two things written every time: the region check, and the reason a quadratic root is rejected.

1. The toolkit for every DC problem

Work in mA, kΩ, V and mA/V²: then kΩ × mA = V and \(k_n\) in mA/V² times V² gives mA. The gate draws no current, so a gate divider is an exact voltage divider and the drain current equals the source current. There is only one current per transistor, \(I_D\).

\[ \text{saturation: } I_D = \tfrac12 k_n V_{OV}^2,\quad V_{OV} = V_{GS} - V_t,\quad \text{valid if } V_{DS} \ge V_{OV}\ \ (\Leftrightarrow V_D \ge V_G - V_t) \]
\[ \text{triode: } I_D = k_n\left[V_{OV}V_{DS} - \tfrac12 V_{DS}^2\right],\quad \text{valid if } 0 \le V_{DS} < V_{OV} \]

Here \(k_n = k_n'(W/L) = \mu_nC_{ox}(W/L)\). For a PMOS use \(V_{SG}\), \(V_{SD}\), \(|V_{tp}|\) and \(k_p\): saturation needs \(V_{SD} \ge |V_{OV}|\), i.e. \(V_D \le V_G + |V_{tp}|\). If a question gives a capital \(K_n\) (Neamen), the law is \(I_D = K_n(V_{GS} - V_t)^2\) with no ½: say which one you used.

Method · assume, solve, verify (every problem)

  1. Write the gate voltage (divider, ground, or a fixed source).
  2. Assume saturation (state it). Write \(V_{GS}\) in terms of \(I_D\) from the source side, then substitute into the square law.
  3. Solve. A quadratic gives two roots: reject the one with \(V_{GS} < V_t\) (the channel would not exist, so no current could flow; write this sentence).
  4. Find \(V_S\), \(V_D\). Check \(V_{DS} \ge V_{OV}\). Write "∴ saturation, assumption correct".
  5. If the check fails, redo with the triode equation and check \(V_{DS} < V_{OV}\).

2. Single MOSFET, analysis (type M-03)

The standard circuit: divider \(R_{G1}\), \(R_{G2}\) sets \(V_G\); \(R_D\) to \(V_{DD}\); \(R_S\) to ground. With \(V_x = V_G - V_t\), KVL around the gate–source loop gives \(V_G = V_{GS} + I_DR_S\), and substituting the square law gives a quadratic in \(V_{OV}\):

\[ \tfrac12 k_nR_S\,V_{OV}^2 + V_{OV} - V_x = 0 \;\Rightarrow\; V_{OV} = \frac{-1 + \sqrt{1 + 2k_nR_SV_x}}{k_nR_S} \]

The other root is negative (\(V_{GS} < V_t\)) and is always rejected. Sedra and Sadat sir write the same thing as a quadratic in \(I_D\) (for Sedra Example 5.4: \(18I_D^2 - 25I_D + 8 = 0\), roots 0.5 and 0.889 mA). Either form is fine; the \(V_{OV}\) form has one obviously wrong root.

Worked example: Sedra Example 5.4 (Sadat L20, notes p.90)

A PMOS that ends in triode (CT 2019)

A PMOS with its source at \(V_{DD}\), a gate divider and \(R_D\) to ground: \(V_{SG}\) is fixed by the divider, so the saturation current is immediate. Then \(V_D = I_DR_D\) must satisfy \(V_{SD} \ge |V_{OV}|\). If it does not, the transistor is in triode and with \(x = V_{SD}\):

\[ k_p\left(|V_{OV}|x - \tfrac12x^2\right) = \frac{V_{DD} - x}{R_D} \;\Rightarrow\; \tfrac{k_p}{2}x^2 - \left(k_p|V_{OV}| + \tfrac{1}{R_D}\right)x + \frac{V_{DD}}{R_D} = 0 \]

Take the root with \(0 < x < |V_{OV}|\); the larger root breaks the triode condition.

Triode on purpose: Sedra Example 5.3 (Khairul s.17)

Gate tied to \(V_{DD}\) = 5 V, source grounded, \(R_D\) to set \(V_D\) = 0.1 V; \(V_t\) = 1 V, \(k_n\) = 1 mA/V². \(V_{OV}\) = 4 V and \(V_{DS}\) = 0.1 V < 4 V, so triode: \(I_D = 1[4\times0.1 - \tfrac12(0.1)^2] = 0.395\) mA, \(R_D = (5-0.1)/0.395 = 12.4\) kΩ, and \(r_{DS} = V_{DS}/I_D = 253\) Ω (≈ \(1/(k_nV_{OV}) = 250\) Ω). A small \(V_{DS}\) with a large \(V_{OV}\) makes the MOSFET a resistor; this is also CT-4 2018 part (a).

3. Single MOSFET, design (type M-03)

Method · design for given \(I_D\) and \(V_D\)

  1. \(R_D = (V_{DD} - V_D)/I_D\).
  2. \(V_{OV} = \sqrt{2I_D/k_n}\) (the positive root: a negative \(V_{OV}\) means \(V_{GS} < V_t\), cut-off).
  3. \(V_{GS} = V_t + V_{OV}\), so \(V_S = V_G - V_{GS}\); \(R_S = (V_S - V_{SS})/I_D\).
  4. Check: \(V_D \ge V_G - V_t\). For a PMOS: \(V_G = V_S - V_{SG}\), and saturation needs \(V_D \le V_G + |V_{tp}|\), which gives the largest allowed \(R_D\).

Worked example: Sedra Example 5.2 (Sadat L19, notes p.89)

Sadat sir solved this one through a quadratic in \(V_S\) to show the root rejection; the worked example follows his route.

PMOS design: Sedra Example 5.5 (Khairul s.19)

PMOS source at +5 V, gate divider, \(R_D\) to ground; \(V_{tp}\) = −1 V, \(k_p\) = 1 mA/V²; want \(I_D\) = 0.5 mA, \(V_D\) = 3 V. \(|V_{OV}| = \sqrt{2\times0.5/1} = 1\) V, \(V_{SG} = 2\) V so \(V_G = 3\) V (choose the divider for 3 V, e.g. 2 MΩ over 3 MΩ). \(R_D = 3/0.5 = 6\) kΩ. Saturation needs \(V_D \le V_G + |V_{tp}| = 4\) V, so \(R_{D,max} = 4/0.5 = 8\) kΩ.

4. Stacked transistors (type M-05)

A vertical chain \(V_{DD}\) → R → Q1 → Q2 → R → ground. One current flows through everything. Diode-connected devices are always saturated (\(V_{GD} = 0 < V_t\); Sadat L20: "G and D shorted: saturation or cut-off, never triode"), so there is nothing to assume. Identical devices carry the same current, so they have the same \(V_{GS}\).

Method · stack with series resistors

  1. KVL down the chain: \(V_{DD} - V_{SS} = I(R_{top} + R_{bot}) + nV_{GS}\).
  2. Substitute \(I = \tfrac12k_nV_{OV}^2\), \(V_{GS} = V_t + V_{OV}\): \(\tfrac12k_n(R_{top}+R_{bot})V_{OV}^2 + nV_{OV} + (nV_t - V_{DD}) = 0\).
  3. Positive root (reject the negative one: \(V_{GS} < V_t\)).
  4. Build node voltages from both ends and check they meet: \(V_{top} - V_{bottom} = nV_{GS}\). Symmetric circuits put the middle node at \(V_{DD}/2\).
  5. Gate-biased pair (Q1 gate at a fixed voltage, Q2 gate grounded, \(R_S\) to \(-V_{SS}\)): equal currents and equal \(k\) give equal \(V_{GS} = x\) with \(\tfrac12k_n(x - V_t)^2 = (V_{SS} - x)/R_S\). Check Q2: its drain (= Q1's source) must be at least \(-V_t\).

Worked example: 2019–20 Sec A Q4(b)

Sadat sir's other route (notes p.92): write the square law for each device and divide, \(\pm1 = \dfrac{5 - I - V_B - 0.9}{V_B - I - 0.9}\). The "+" sign gives \(V_B\) = 2.5 V (symmetry). The "−" sign gives \(I\) = 1.6 mA, but then \(V_{GS1} = 0.9\) V = \(V_t\) and the square law gives zero current: a contradiction, so it is rejected.

5. Two-stage circuits (type M-06)

The drain of M1 drives the gate of M2 directly. Because no gate current flows, solving stage 1 first and then stage 2 is exact, unlike a BJT cascade where the base current loads stage 1 (Sadat L21, notes p.93).

Method · cascaded DC

  1. Solve stage 1 completely (section 2) and check it.
  2. \(V_{G2} = V_{D1}\). Assume M2 saturated: \(I_{D2} = \tfrac12k_n(V_{D1} - V_t)^2\), \(V_{D2} = V_{DD} - I_{D2}R_{D2}\).
  3. Check \(V_{D2} \ge V_{D1} - V_t\). A large \(V_{OV2}\) usually fails (the "saturated" current would make \(V_{D2}\) negative).
  4. Triode: with \(x = V_{D2}\), \(\dfrac{V_{DD} - x}{R_D} = k_n\left[V_{OV2}x - \tfrac12x^2\right]\), i.e. \(\tfrac{k_nR_D}{2}x^2 - (k_nR_DV_{OV2} + 1)x + V_{DD} = 0\). Take the root with \(0 < x < V_{OV2}\).
  5. Design direction: start from the stage whose terminal voltages are fixed (a follower with its drain at \(V_{DD}\) and a given \(V_{DS}\) fixes its source), then work back through \(V_{G2} = V_{D1}\) to \(R_{D1}\), \(R_{S1}\) and the divider.

Worked example: 2013–14 Sec B Q8(a)

Traps (where marks go)

  • No region check written, or no reason given for rejecting a root. Both cost marks with Sadat sir.
  • Rejecting "the larger current" by habit. The rule is: reject the root with \(V_{GS} < V_t\) (in Example 5.4 that happens to be the larger \(I_D\), 0.889 mA).
  • Taking \(V_{OV}\) as \(V_{GS}\): the Gemini answer to 2019–20 Q4(b) reports \(V_4\) = 1.60 V this way; the right value is 2.50 V.
  • Assuming the second stage is saturated: in 2013–14 Q8(a) the "saturated" current is 6.125 mA, which would need \(V_o < 0\).
  • Capital \(K_n\) (Neamen, no ½) versus \(k_n\) (Sedra, with ½): 2016–17 Q7(b) changes every resistor.
  • Sign of \(V_{SS}\): \(R_S = (V_S - V_{SS})/I_D\) with \(V_{SS} = -2.5\) V gives \(V_S + 2.5\).

Exam questions

2020–21 · Sec B · Q8(b) · 23⅓ marks  |  = Sedra Exercise D5.8 (highlighted by the teacher)

Design the circuit (NMOS, gate grounded, \(R_D\) from +2.5 V to the drain, \(R_S\) from the source to −2.5 V) so that the transistor operates at \(I_D\) = 0.3 mA and \(V_D\) = 0.4 V. The NMOS has \(V_t\) = 1 V, aspect ratio 40 and process transconductance parameter 60 µA/V². Neglect channel-length modulation.

Show worked answer

\(k_n = k_n'(W/L) = 0.06\times40 = 2.4\) mA/V². \(R_D = (2.5 - 0.4)/0.3 = 7\) kΩ.

Assume saturation: \(0.3 = \tfrac12\times2.4\times V_{OV}^2 \Rightarrow V_{OV}^2 = 0.25\), \(V_{OV} = +0.5\) V (the root −0.5 V would mean \(V_{GS} = 0.5\text{ V} < V_t\): no channel, rejected).

\(V_{GS} = 1.5\) V, \(V_G = 0\) so \(V_S = -1.5\) V; \(R_S = (-1.5 + 2.5)/0.3 = 3.33\) kΩ.

Check: \(V_{DS} = 0.4 - (-1.5) = 1.9\text{ V} \ge V_{OV} = 0.5\) V (equivalently \(V_D = 0.4 \ge V_G - V_t = -1\)). ∴ saturation, assumption correct. \(R_D\) = 7 kΩ, \(R_S\) = 3.33 kΩ.

2019–20 (held Jan 2021) · Sec A · Q4(b) · 28 marks  |  Sedra P5.57(b), highlighted · Sadat L20 notes p.91–92

Find the node voltages \(V_3\), \(V_4\), \(V_5\): 1 kΩ from +5 V to \(V_3\); Q1 diode-connected from \(V_3\) (drain and gate) to \(V_4\) (source); Q2 diode-connected from \(V_4\) to \(V_5\); 1 kΩ from \(V_5\) to ground. \(V_t\) = 0.9 V, \(k_n'(W/L)\) = 1.5 mA/V².

Show worked answer

Both devices have \(V_{GD} = 0 < V_t\): saturated whenever they conduct (no assumption needed). Same current \(I\) and same \(k_n\), so the same \(V_{GS}\).

KVL: \(5 = 1\cdot I + V_{GS} + V_{GS} + 1\cdot I = 2I + 2(0.9 + V_{OV})\) with \(I = 0.75V_{OV}^2\): \(1.5V_{OV}^2 + 2V_{OV} - 3.2 = 0\).

\(V_{OV} = \dfrac{-2 + \sqrt{4 + 19.2}}{3} = 0.939\) V (the other root, −2.27 V, gives \(V_{GS} < V_t\): rejected). \(V_{GS} = 1.839\) V, \(I = 0.75\times0.939^2 = 0.661\) mA.

\(V_5 = 0.661\) V, \(V_4 = 0.661 + 1.839 = 2.500\) V, \(V_3 = 5 - 0.661 = 4.339\) V. Check: \(V_3 - V_4 = 1.839 = V_{GS}\) ✓, and \(V_4 = V_{DD}/2\) by symmetry.

(The question bank's Gemini answer gives \(V_4\) = 1.60 V: it used \(V_{OV}\) as \(V_{GS}\). Wrong.)

2016–17 · Sec B · Q7(b) · 20⅔ marks

Two-stage direct-coupled NMOS circuit between +5 V and −5 V: divider \(R_1\) (from +5 V) and 337 kΩ (to −5 V) set \(V_{G1}\); M1 has \(R_{D1}\) to +5 V and \(R_{S1}\) to −5 V; M2's gate is M1's drain, M2's drain is at +5 V and \(R_{S2}\) goes from its source to −5 V. \(K_{n1}\) = 500 µA/V², \(K_{n2}\) = 200 µA/V², \(V_{T1} = V_{T2}\) = 1.2 V. Design for \(I_{D1}\) = 0.1 mA, \(I_{D2}\) = 0.3 mA, \(V_{DS1} = V_{DS2}\) = 5 V.

Show worked answer

Capital \(K_n\) is Neamen's parameter: \(I_D = K_n(V_{GS} - V_T)^2\) (no ½). State this.

M2 first (its drain is fixed): \(V_{S2} = 5 - 5 = 0\) V, so \(R_{S2} = (0 + 5)/0.3 = 16.67\) kΩ. \(V_{GS2} = 1.2 + \sqrt{0.3/0.2} = 2.425\) V, so \(V_{G2} = V_{D1} = 2.425\) V.

M1: \(R_{D1} = (5 - 2.425)/0.1 = 25.75\) kΩ. \(V_{S1} = V_{D1} - 5 = -2.575\) V, \(R_{S1} = (-2.575 + 5)/0.1 = 24.25\) kΩ. \(V_{GS1} = 1.2 + \sqrt{0.1/0.5} = 1.647\) V, \(V_{G1} = -2.575 + 1.647 = -0.928\) V.

Divider: current in 337 kΩ \(= (-0.928 + 5)/337 = 12.08\) µA; \(R_1 = (5 + 0.928)/0.01208 = 490.6\) kΩ.

Checks: \(V_{DS1} = 5 > V_{OV1} = 0.447\), \(V_{DS2} = 5 > 1.225\): both saturated.

If the parameters are read as Sedra's \(k_n\) (with ½), the same steps give \(R_{S2}\) = 16.67 kΩ, \(R_{D1}\) = 20.68 kΩ, \(R_{S1}\) = 29.32 kΩ, \(V_{G1}\) = −0.235 V, \(R_1\) = 370.3 kΩ (this is the senior solution file's reading). Write which convention you use.

2013–14 · Sec B · Q8(a) · 16⅔ marks

Find \(V_o\) (Figure 6). Both NMOS: \(V_t\) = 1 V, λ = 0, \(\mu_nC_{ox}(W/L)\) = 1 mA/V²; \(V_{DD}\) = 5 V, both drain resistors 1 kΩ, M1's gate at +2 V.

Show worked answer

M1 (assume saturation): \(I_{D1} = \tfrac12(2 - 1)^2 = 0.5\) mA, \(V_{D1} = 5 - 0.5 = 4.5\) V. Check \(V_{DS1} = 4.5 \ge V_{OV1} = 1\) ✓.

M2: \(V_{GS2} = 4.5\) V, \(V_{OV2} = 3.5\) V. If saturated, \(I_{D2} = \tfrac12(3.5)^2 = 6.125\) mA and \(V_o = 5 - 6.125 < 0\): impossible. ∴ M2 is in triode.

\(5 - V_o = 1\times\left[3.5V_o - \tfrac12V_o^2\right] \Rightarrow V_o^2 - 9V_o + 10 = 0 \Rightarrow V_o = 1.298\) V or 7.70 V. Reject 7.70 V (it exceeds \(V_{DD}\) and \(V_{OV2}\)).

2011–12 · Sec A · Q3(b) · 20 marks  |  = Sedra Example 5.4 · Khairul s.18 · Sadat L20 notes p.90

Determine all node voltages and the drain current (Figure 1): \(V_{DD}\) = +10 V, \(R_{G1} = R_{G2}\) = 10 MΩ, \(R_D = R_S\) = 6 kΩ, \(V_t\) = 1 V, \(k_n'(W/L)\) = 1 mA/V², λ = 0.

Show worked answer

No gate current: \(V_G = 10\times\frac{10}{20} = 5\) V.

The 2019–20 chain (5 V, two 1 kΩ resistors) but Q2 now has \(k_n\) = 1 mA/V², \(V_t\) = 1 V (Q1 keeps 1.5 mA/V², 0.9 V). Find \(V_A\) (top), \(V_B\) (middle), \(V_C\) (bottom) and \(I\).

Assignment Q7 (EEE 263 assignment set) · cascode bias design

Two NMOS in cascode: M1 (gate \(G_1\), source to −5 V through \(R_S\) = 10 kΩ, bypassed) and M2 on top (source = M1's drain, gate \(G_2\), drain to +5 V through \(R_D\)). A three-resistor divider \(R_1\) (+5 V to \(G_2\)), \(R_2\) (\(G_2\) to \(G_1\)), \(R_3\) (\(G_1\) to ground), \(R_1 + R_2 + R_3\) = 300 kΩ. \(k_n\) = 0.8 mA/V², \(V_t\) = 1.2 V. Design for \(I_D\) = 0.4 mA and \(V_{DS1} = V_{DS2}\) = 2.5 V.

Show worked answer

\(V_{OV} = \sqrt{2\times0.4/0.8} = 1\) V, \(V_{GS} = 2.2\) V for both.

\(V_{S1} = -5 + 0.4\times10 = -1\) V; \(V_{G1} = 1.2\) V; \(V_{D1} = -1 + 2.5 = 1.5\) V = \(V_{S2}\); \(V_{G2} = 3.7\) V; \(V_{D2} = 4.0\) V, so \(R_D = 1/0.4 = 2.5\) kΩ.

Divider current \(5/300 = 1/60\) mA: \(R_3 = 1.2\times60 = 72\) kΩ, \(R_2 = 2.5\times60 = 150\) kΩ, \(R_1 = 1.3\times60 = 78\) kΩ. Both \(V_{DS} = 2.5 \ge 1\): saturated.

Summary: gate current is zero, so dividers are exact and stages solve one after another. Assume saturation, write \(V_{GS}\) from the source side, solve the square law, reject the root with \(V_{GS} < V_t\) (say why), then check \(V_{DS} \ge V_{OV}\) (PMOS: \(V_{SD} \ge |V_{OV}|\)). Stacks: one current, equal \(V_{GS}\) for identical devices, one quadratic in \(V_{OV}\).
