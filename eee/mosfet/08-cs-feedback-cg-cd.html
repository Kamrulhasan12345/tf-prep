Feedback-Biased CS, Common-Gate and Common-Drain Amplifiers

The drain-to-gate resistor circuit (M-12) has been set in four finals (2022–23, 2019–20, 2017–18, 2015–16), for 17 to 31⅔ marks each, and always with the same three results: bias, gain with \(R_L\), and a Miller input resistance \(R_G/(1 - A_v)\). The other two configurations are mostly derivation questions (CG: 2013–14, 26⅔ marks), with the common-drain follower flagged by Sadat sir as "numerical, important for exam". Work in mA, V, kΩ, mA/V, MΩ for \(R_G\), Sedra's \(i_D = \tfrac12k_nV_{OV}^2\); the only Neamen-convention question in this part of the course, \(K_n(V_{GS} - V_t)^2\) with no ½, is 2016–17 Q7(b) in chapter 3. Every question here uses Sedra's \(k_n\).

1. Drain-to-gate feedback bias

A large resistor \(R_G\) (MΩ) joins drain and gate. The gate draws no current, so there is no drop across \(R_G\) and \(V_G = V_D\), i.e. \(V_{GS} = V_{DS}\) and \(V_{GD} = 0 < V_t\): the device is always saturated (no region check needed, say so). The same resistor gives negative feedback that stabilises \(I_D\): if \(I_D\) rises, \(V_D\) falls and pulls \(V_{GS}\) down.

Method · DC bias

  1. \(I_G = 0\) ⇒ \(V_{GS} = V_D\). Saturated automatically.
  2. With \(R_D\): \(V_{DD} = I_DR_D + V_{GS}\) with \(I_D = \tfrac12k_nV_{OV}^2\), \(V_{GS} = V_t + V_{OV}\): \(\tfrac12k_nR_D\,V_{OV}^2 + V_{OV} + (V_t - V_{DD}) = 0\), so \(V_{OV} = \dfrac{-1 + \sqrt{1 + 2k_nR_D(V_{DD} - V_t)}}{k_nR_D}\). Reject the negative root (\(V_{GS} < V_t\)).
  3. With a current source \(I\): \(I_D = I\), \(V_{OV} = \sqrt{2I/k_n}\), \(V_{GS} = V_D = V_t + V_{OV}\). If \(k_n\) is not given but \(V_D\) is: \(k_n = 2I/(V_D - V_t)^2\).
  4. \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\).
  5. New current in a current-source circuit: \(V_{OV}' = V_{OV}\sqrt{I'/I}\), \(V_D' = V_t + V_{OV}'\), then redo step 4.

2. Small-signal gain and the Miller input resistance

At signal frequencies the supply is ground and the capacitors are shorts. \(R_G\) now connects output to input, so it is not in parallel with a grounded node: the gate is not isolated. Write KCL at the output node with \(v_{gs} = v_i\) and \(v_o\) across \(R_D\parallel R_L\parallel r_o\):

\[ \frac{v_o - v_i}{R_G} + g_mv_i + v_o\Big(\frac1{r_o} + \frac1{R_D} + \frac1{R_L}\Big) = 0 \]\[ A_v = \frac{v_o}{v_i} = \frac{\frac1{R_G} - g_m}{\frac1{r_o} + \frac1{R_D} + \frac1{R_L} + \frac1{R_G}} \approx -g_m\,(r_o\parallel R_D\parallel R_L) \]

(\(R_D\) is absent with a current-source load; an ideal current source is an open circuit for signals.) \(R_G\) is 10 MΩ against kΩ-sized loads, so the approximation is within a fraction of a percent. The input current is \(i_i = (v_i - v_o)/R_G = v_i(1 - A_v)/R_G\): the resistor looks \(1 - A_v\) times smaller from the input (Miller effect):

\[ R_{in} = \frac{v_i}{i_i} = \frac{R_G}{1 - A_v} = \frac{R_G}{1 + |A_v|} \]

Because \(R_{in}\) is much less than \(R_G\), the source loading must be counted (\(G_v = \frac{R_{in}}{R_{in} + R_{sig}}A_v\)) if \(R_{sig}\) is given.

Largest input signal. The output swing must not push the drain below the saturation edge. With \(V_{GS} = V_D\): at the negative output peak \(v_{DS,min} = V_D - |A_v|\hat v_i\) must stay at least \(v_{GS} - V_t = V_{OV} + \hat v_i\) (the gate also rises by \(\hat v_i\)). So \(V_D - V_{OV} - \hat v_i \ge |A_v|\hat v_i\), and since \(V_D - V_{OV} = V_t\):

\[ \hat v_i \le \frac{V_t}{1 + |A_v|} \]

Not \(V_{OV}\), not \(0.1V_{OV}\) (that is the linearity limit of chapter 6). Sedra quotes 0.34 V for the 2015–16 numbers (exact 0.350 V).

Method · M-12 end to end

  1. DC bias: \(V_{OV}\), \(I_D\), \(V_{GS} = V_D\) (section 1).
  2. \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\).
  3. \(A_v = \dfrac{1/R_G - g_m}{1/r_o + 1/R_D + 1/R_L + 1/R_G}\) (all conductances in mS when resistances are in kΩ; \(1/R_G\) = 10⁻⁴ mS for 10 MΩ).
  4. \(R_{in} = R_G/(1 - A_v)\).
  5. If asked: \(\hat v_i \le V_t/(1 + |A_v|)\); draw the small-signal model (\(g_mv_{gs}\) in parallel with \(r_o\), \(R_D\), \(R_L\), and \(R_G\) from gate to drain).

Worked example: 2017–18 Sec A Q2(a) / 2015–16 Sec A Q3(b)

3. Common-gate amplifier (type M-T6)

Gate at AC ground, signal into the source, output at the drain. It is non-inverting with a low input resistance.

Derivation (2013–14 Q7(a), \(r_o \to \infty\)). In the T model the gate is grounded, so \(v_{gs} = -v_i\) (the source is at \(v_i\)) and the current in \(1/g_m\) is \(i = v_i/(1/g_m) = g_mv_i\), flowing source-to-drain-side, i.e. out of the drain.

\(R_{in}\) (looking into the source): \(R_{in} = v_i/i = 1/g_m\). Low, because the input drives the source terminal directly.

\(A_{vo}\) (no \(R_L\)): the current \(g_mv_i\) leaves the drain and flows up through \(R_D\) from ground, so \(v_o = +g_mv_iR_D\): \(A_{vo} = g_mR_D\) (non-inverting). With \(R_L\): \(A_v = g_m(R_D\parallel R_L) = A_{vo}\dfrac{R_L}{R_L + R_o}\).

\(R_o\): set \(v_i = 0\): the dependent source carries no current (\(i = 0\)), so \(R_o = R_D\).

Overall gain: \(\dfrac{v_i}{v_{sig}} = \dfrac{1/g_m}{1/g_m + R_{sig}}\), so

\[ G_v = \frac{v_o}{v_{sig}} = \frac{1/g_m}{R_{sig} + 1/g_m}\;g_m(R_D\parallel R_L) = \frac{R_D\parallel R_L}{R_{sig} + 1/g_m} \]

With \(r_o\) (full marks if asked): \(R_{in} \approx \dfrac{r_o + R_D\parallel R_L}{1 + g_mr_o}\) (about \(1/g_m\) if \(r_o \gg R_D\parallel R_L\)) and \(R_{out} = R_D\parallel\big[r_o + R_{sig}(1 + g_mr_o)\big]\): a large resistance in the drain path, much bigger than \(R_D\) when \(R_{sig}\) is not small.

Use: a current buffer and a voltage amplifier with low input resistance, good at high frequency; it loads the source heavily, so \(G_v\) is limited by the divider \(\dfrac{1/g_m}{R_{sig} + 1/g_m}\) (compare CE/CB for the BJT).

4. Common-drain (source follower) (type M-T6)

Drain at AC ground (supply), input at the gate, output at the source. Gain just below 1, \(R_{in} = \infty\) (set only by the bias network \(R_G\)), low output resistance: a buffer, the MOSFET analogue of the emitter follower (Sadat: "similar to common collector"). Because the source resistance stays in the signal path, Sadat sir uses the T model.

Gain. \(i = \dfrac{v_i}{1/g_m + R_S\parallel R_L}\) and \(v_o = i\,(R_S\parallel R_L)\), so \(A_v = \dfrac{R_S\parallel R_L}{1/g_m + R_S\parallel R_L}\;(<1)\), and \(A_{vo} = \dfrac{R_S}{R_S + 1/g_m}\) (\(\to 1\) for \(R_S \gg 1/g_m\)).

\(R_{in}\): the gate carries no current, so \(R_{in} = R_G\) (\(= R_{G1}\parallel R_{G2}\); \(\infty\) if there is no bias network).

\(R_o\) (test source \(v_x\) at the output, \(v_i = 0\)): \(i_x = v_x/R_S + v_x/(1/g_m)\), so \(R_o = R_S\parallel\dfrac1{g_m}\), roughly \(1/g_m\).

\(G_v\) \(= \dfrac{R_G}{R_G + R_{sig}}A_v\). Check against Khairul's slide (\(R_S\) removed): \(A_v = R_L/(R_L + 1/g_m)\), \(R_o = 1/g_m\).

\[ A_v = \frac{R_S\parallel R_L}{\frac1{g_m} + R_S\parallel R_L},\qquad R_{in} = R_G,\qquad R_o = R_S\parallel\frac1{g_m},\qquad G_v = \frac{R_G}{R_G + R_{sig}}A_v \]

The follower's DC bias is an ordinary chapter-3 problem (divider, \(R_S\) from the source to ground or \(-V_{SS}\); a PMOS version, as Sadat drew it, has \(R_S\) to \(V_{DD}\) and the drain grounded). The body effect is a second-order correction (\(V_{SB} = V_o\)) ignored in exam answers.

Traps (where marks go)

  • \(R_{in} = R_G\) in the feedback circuit. It is \(R_G/(1 - A_v)\) (2.33 MΩ, not 10 MΩ).
  • Forgetting \(R_L\) in the gain, or \(r_o\): the exam gives \(V_A\) and a load on purpose (\(r_o\) = 47 kΩ is not negligible against 10 kΩ).
  • Calling the feedback transistor "saturated if \(V_{DS} \ge V_{OV}\)" and checking: it is saturated by construction (\(V_{GD} = 0\)), but you must say why.
  • Taking the negative root of the \(V_{GS}\) quadratic (\(V_{GS}\) = −2.2 V in 2015–16).
  • Maximum input written as \(V_{OV}\) or \(2V_{OV}\): it is \(V_t/(1 + |A_v|)\).
  • Current-source circuit: \(I_D\) is the source current at any \(V_{DD}\); when \(I\) changes, \(V_D\) changes (2.456 V at 1 mA) because \(V_D = V_{GS}\).
  • CG: forgetting that \(G_v\) includes the input divider (\(1/g_m\) against \(R_{sig}\)); CD: gain greater than 1 means a slip.

Exam questions

2022–23 · Sec A · Q3(b) · 17 marks  |  = Sedra Ex. 7.x · highlighted P7.31 (same circuit)

In the circuit, the NMOS transistor has \(|V_t|\) = 0.9 V and \(V_A\) = 50 V and is operated with \(V_D\) = 2 V. What is the voltage gain \(v_o/v_i\)? What do \(V_D\) and the gain become for \(I\) = 1 mA? (A 500 µA current source from \(V_{DD}\) into the drain, \(R_G\) = 10 MΩ from drain to gate, source grounded, input capacitor-coupled to the gate, output capacitor-coupled from the drain to \(R_L\) = 10 kΩ.)

Show worked answer

DC. \(V_{GS} = V_D\) = 2 V (no drop in \(R_G\); saturated since \(V_{GD}\) = 0). \(V_{OV} = 2 - 0.9 = 1.1\) V. \(I_D = I\) = 0.5 mA, so \(k_n = 2I/V_{OV}^2 = 1/1.21 = 0.826\) mA/V².

Small signal. \(g_m = 2I_D/V_{OV} = 1/1.1 = 0.909\) mA/V. \(r_o = V_A/I_D = 50/0.5 = 100\) kΩ. The current source is an open circuit for signals, so only \(r_o\), \(R_L\) and \(R_G\) load the output:

\(A_v = \dfrac{1/R_G - g_m}{1/r_o + 1/R_L + 1/R_G} = \dfrac{0.0001 - 0.909}{0.01 + 0.1 + 0.0001} = \) −8.26 V/V (≈ \(-g_m(r_o\parallel R_L)\) = −0.909 × 9.09). Input resistance \(R_{in} = 10/(1 + 8.26)\) = 1.08 MΩ.

\(I\) = 1 mA. \(k_n\) is unchanged, so \(V_{OV} = \sqrt{2(1)/0.826} = 1.556\) V (= 1.1\(\sqrt2\)) and \(V_D = V_{GS} = 0.9 + 1.556 = 2.456\) V. \(g_m = 2/1.556\) = 1.286 mA/V, \(r_o = 50/1 = 50\) kΩ.

\(A_v = \dfrac{0.0001 - 1.286}{0.02 + 0.1 + 0.0001} = \) −10.7 V/V. (Sedra: −8.3, 2.46 V, −10.7.)

2019–20 (held Jan 2021) · Sec A · Q2(b) · 30 marks

For the circuit, find the small-signal input impedance and voltage gain. \(V_t\) = 1.2 V, \(k_n'(W/L)\) = 0.5 mA/V², \(V_A\) = 55 V. (\(V_{DD}\) = +20 V, \(R_D\) = 20 kΩ, \(R_G\) = 15 MΩ from drain to gate, \(R_L\) = 25 kΩ through a coupling capacitor, input coupled to the gate.)

Show worked answer

DC. \(V_{GS} = V_D\) ⇒ saturated. \(20 = I_D(20) + V_{GS}\), \(I_D = \tfrac12(0.5)(V_{GS} - 1.2)^2 = 0.25(V_{GS} - 1.2)^2\):

\(20 = 5(V_{GS} - 1.2)^2 + V_{GS}\) ⇒ \(5V_{GS}^2 - 11V_{GS} - 12.8 = 0\) ⇒ \(V_{GS} = \dfrac{11 + \sqrt{121 + 256}}{10} = 3.042\) V (reject −0.842 V: below \(V_t\)).

\(V_{OV}\) = 1.842 V, \(I_D = 0.25(1.842)^2\) = 0.848 mA, \(V_D\) = 3.04 V.

Small signal. \(g_m = k_nV_{OV} = 0.5\times1.842\) = 0.921 mA/V; \(r_o = 55/0.848\) = 64.9 kΩ.

\(A_v = \dfrac{1/15000 - 0.921}{1/64.9 + 1/20 + 1/25 + 1/15000}\) = \(\dfrac{-0.921}{0.01541 + 0.05 + 0.04 + 0.0000667}\) = −8.73 V/V.

Input impedance: \(R_{in} = R_G/(1 - A_v) = 15/9.73\) = 1.54 MΩ.

2017–18 · Sec A · Q2(a) · 20 marks  |  also 2015–16 Sec A Q3(b) · 31⅔ marks (bias, model, gain, \(R_{in}\), largest input)

2017–18: Determine the voltage gain \(v_o/v_i\) of the common-source amplifier shown. \(V_t\) = 1.5 V, \(k_n'(W/L)\) = 0.25 mA/V², \(V_A\) = 50 V. 2015–16: same circuit: (i) calculate the DC bias point (\(I_D\) and \(V_D\)); (ii) draw the small-signal equivalent circuit; (iii) the small-signal voltage gain; (iv) the input resistance; (v) the largest allowable input signal voltage. (\(V_{DD}\) = +15 V, \(R_D\) = 10 kΩ, \(R_G\) = 10 MΩ drain to gate, \(R_L\) = 10 kΩ via a capacitor.)

Show worked answer

(i) Bias. \(V_{GS} = V_D\) (\(I_G\) = 0) ⇒ saturated. \(15 = 10I_D + V_{GS}\), \(I_D = 0.125(V_{GS} - 1.5)^2\): with \(V_{OV}\): \(1.25V_{OV}^2 + V_{OV} - 13.5 = 0\) ⇒ \(V_{OV} = \dfrac{-1 + \sqrt{1 + 67.5}}{2.5} = 2.911\) V (reject −3.71 V: \(V_{GS} < V_t\)).

\(V_{GS} = V_D\) = 4.41 V, \(I_D = 0.125(2.911)^2\) = 1.059 mA.

(ii) Model. \(R_G\) from the gate node to the drain node; \(v_{gs}\) = \(v_i\) across the input; dependent source \(g_mv_{gs}\) from drain to ground in parallel with \(r_o\), \(R_D\), \(R_L\) (source at ground).

(iii) Gain. \(g_m = k_nV_{OV}\) = 0.25 × 2.911 = 0.728 mA/V, \(r_o = 50/1.059\) = 47.2 kΩ.

\(A_v = \dfrac{10^{-4} - 0.728}{1/47.2 + 1/10 + 1/10 + 10^{-4}} = \dfrac{-0.728}{0.2213} = \) −3.29 V/V.

(iv) \(R_{in}\) = \(10/(1 + 3.29)\) = 2.33 MΩ.

(v) Largest input. The drain must stay in saturation: \(v_{DS} \ge v_{GS} - V_t\) at the negative output peak, giving \(\hat v_i \le V_t/(1 + |A_v|) = 1.5/4.29\) = 0.35 V (Sedra quotes 0.34 V).

2013–14 · Sec B · Q7(a) · 26⅔ marks

Derive the expressions for input resistance, output resistance and overall voltage gain of a common-gate (CG) amplifier.

Show worked answer

Circuit: gate at AC ground, \(v_{sig}\) with \(R_{sig}\) into the source, \(R_D\) from drain to supply (AC ground), load \(R_L\) coupled to the drain. Replace the MOSFET by its T model (gate open, \(1/g_m\) between the source and the internal node, current source \(g_mv_{gs}\) from drain to internal node), \(r_o \to \infty\).

\(v_{gs} = -v_i\), so the current in \(1/g_m\) is \(i = v_i/(1/g_m) = g_mv_i\), flowing from the source into the device and out of the drain.

Input resistance: \(R_{in} = v_i/i = \) \(1/g_m\).

Output resistance: \(v_i = 0\) kills \(i\); the transistor is an open circuit at the drain: \(R_o = R_D\). (With \(r_o\): \(R_{out} = R_D\parallel[r_o + R_{sig}(1 + g_mr_o)]\).)

Gain: \(v_o = i(R_D\parallel R_L) = g_mv_i(R_D\parallel R_L)\) ⇒ \(A_{vo} = g_mR_D\), \(A_v = g_m(R_D\parallel R_L)\) (non-inverting). Source divider \(v_i/v_{sig} = \dfrac{1/g_m}{1/g_m + R_{sig}}\):

\[ G_v = \frac{v_o}{v_{sig}} = \frac{1/g_m}{R_{sig} + 1/g_m}\;g_m(R_D\parallel R_L) = \frac{R_D\parallel R_L}{R_{sig} + 1/g_m} \]

With \(r_o\) included, \(R_{in} \approx \dfrac{r_o + R_D\parallel R_L}{1 + g_mr_o}\).

Sedra 7e P7.31 · highlighted by the teacher (the 2022–23 circuit with \(|V_t|\) = 0.5 V)

As the 2022–23 circuit: 500 µA current source into the drain, \(R_G\) = 10 MΩ drain to gate, \(R_L\) = 10 kΩ; \(|V_t|\) = 0.5 V, \(V_A\) = 50 V, \(V_D\) = 1 V. Find the gain, then the new \(V_D\) and gain for \(I\) = 1 mA.

Show worked answer

\(V_{OV} = 1 - 0.5 = 0.5\) V, \(g_m = 2(0.5)/0.5\) = 2 mA/V, \(r_o\) = 50/0.5 = 100 kΩ. \(A_v = (10^{-4} - 2)/(0.01 + 0.1 + 10^{-4})\) = −18.2 V/V.

1 mA: \(V_{OV} = 0.5\sqrt2 = 0.707\) V, \(V_D\) = 1.207 V, \(g_m\) = 2.83 mA/V, \(r_o\) = 50 kΩ, \(A_v = (10^{-4} - 2.83)/(0.02 + 0.1 + 10^{-4})\) = −23.5 V/V (Sedra −23.6, rounding).

Sedra 7e P7.122 · highlighted by the teacher (follower, CG, and their cascade)

(a) A source follower with \(g_m\) = 10 mA/V is fed by a 10 kΩ source resistance \(R_S\) (no load): find \(A_{vo}\) and \(R_o\). (b) A CG amplifier with \(g_m\) = 10 mA/V, a 10 kΩ source resistance, \(R_D\) = 5 kΩ and \(R_L\) = 2 kΩ: find \(R_{in}\) and the gain. (c) Cascade (a) driving (b): find \(v_o/v_i\).

Show worked answer

\(1/g_m\) = 100 Ω. (a) \(A_{vo} = \dfrac{10}{10 + 0.1}\) = 0.99, \(R_o = 10\text{ k}\parallel100\ \Omega\) = 99 Ω.

(b) \(R_{in} = 100\ \Omega\parallel10\text{ k}\) = 99 Ω; gain \(g_m(R_D\parallel R_L) = 10\times1.4286\) = 14.3 V/V.

(c) Stage 1 output resistance 99 Ω drives stage 2 input resistance 99 Ω: divider 0.5. \(v_o/v_i = 0.99\times0.5\times14.3\) = 7.07 V/V.

Source follower: \(g_m\) = 2 mA/V, \(R_S\) = 5 kΩ, \(R_L\) = 5 kΩ, \(R_G\) = 1 MΩ, \(R_{sig}\) = 100 kΩ. Find \(A_v\), \(R_{in}\), \(R_o\), \(G_v\). (Sadat's circuit is a PMOS with \(R_S\) to \(V_{DD}\) and the drain grounded; the small-signal result is identical.)

Practice

Key terms

Quick check

Summary: drain-to-gate \(R_G\): \(V_{GS} = V_D\), always saturated; \(V_{DD} = I_DR_D + V_{GS}\) (quadratic, positive \(V_{OV}\)) or \(V_{GS} = V_t + \sqrt{2I/k_n}\) for a current source. \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\), \(A_v = \dfrac{1/R_G - g_m}{1/r_o + 1/R_D + 1/R_L + 1/R_G} \approx -g_m(r_o\parallel R_D\parallel R_L)\), \(R_{in} = R_G/(1 - A_v)\), \(\hat v_i \le V_t/(1 + |A_v|)\). CG: \(R_{in} = 1/g_m\), \(A_v = g_m(R_D\parallel R_L)\), \(R_o = R_D\), \(G_v = (R_D\parallel R_L)/(R_{sig} + 1/g_m)\). CD: \(A_v = \dfrac{R_S\parallel R_L}{1/g_m + R_S\parallel R_L}\), \(R_{in} = R_G\), \(R_o = R_S\parallel 1/g_m\). Remember −8.26 V/V, −10.7 V/V, −8.73 V/V and 1.54 MΩ, −3.29 V/V and 2.33 MΩ.
