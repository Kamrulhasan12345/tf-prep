Current Mirrors, Differential-Pair Sharing and Complementary Stages

Transistors that share a gate voltage or a source node are a recurring DC question: current mirror and pair sharing (M-04: 2024–25 for 17 marks, 2018–19 for 20, 2016–17 for 26) and the NMOS/PMOS pair with a load resistor (M-07: 2022–23 for 20 marks, 2015–16 for 15, 2014–15 for 20). One idea solves all of them: devices with equal \(V_{GS}\) carry currents in the ratio of their \(W/L\). Work in mA, V, kΩ, mA/V², Sedra's \(i_D = \tfrac12k_nV_{OV}^2\), with the region check written at the end.

1. The current mirror

M1 has its gate tied to its drain, so \(V_{GD} = 0\) and it is saturated (Sadat L23: "G and D shorted ∴ saturation"). Its current is forced by the reference branch and it sets \(V_{GS}\). M2 shares the gate and the source, so it has the same \(V_{GS}\); as long as M2 is saturated, its current is the reference current scaled by the geometry:

\[ I_{REF} = \frac{V_{DD} - V_{GS}}{R},\quad V_{GS} = V_t + \sqrt{\frac{2I_{REF}}{k_1}} \]\[ I_O = I_{REF}\,\frac{(W/L)_2}{(W/L)_1}\cdot\frac{1 + \lambda V_{DS2}}{1 + \lambda V_{DS1}} \quad(\text{pure ratio when } \lambda = 0) \]

Saturation of M2 needs \(V_{D2} \ge V_{GS} - V_t = V_{OV}\). Seen from its drain, the mirror output has resistance \(r_{o2} = V_A/I_O\): a good current source. The \(\lambda\) ratio above is the small error between the two drain voltages.

Method · mirror with resistors

  1. Reference branch: M1 is saturated. \(V_{DD} = I_{REF}R + V_t + V_{OV}\) with \(I_{REF} = \tfrac12k_1V_{OV}^2\). Positive root of the quadratic; reject \(V_{GS} < V_t\). (If \(I_{REF}\) is given: \(V_{OV} = \sqrt{2I_{REF}/k_1}\), then solve for \(R\) directly.)
  2. \(I_O = I_{REF}\cdot m\), \(m = (W/L)_2/(W/L)_1\) (equal \(L\): width ratio).
  3. Output node: \(V_{D2} = V_{DD} - I_OR_D\) (or the voltage across a diode-connected load).
  4. Check \(V_{D2} \ge V_{OV}\). If not, M2 is in triode: \(\tfrac{k_2}{2}x^2 - (k_2V_{OV} + 1/R_D)x + V_{DD}/R_D = 0\), small root \(x < V_{OV}\), and \(I_O\) is no longer \(mI_{REF}\).

Worked example: 2018–19 Sec A Q4(b)

Mirror with a diode-connected load (2016–17 Q7(a)). If the load on each branch is itself a diode-connected NMOS from \(V_{DD}\) (Q2 above Q1, Q4 above Q3), the two stacks have equal \(V_{GS}\) in every device: \(V_{GS1} = X\) and \(V_{GS2} = V_{DD} - X\) with the same current and \(k\) give \(X = V_{DD}/2\). Making the output pair \(m\) times wider multiplies the current by \(m\) but leaves the node voltage at \(V_{DD}/2\), because the widths of Q3 and Q4 scale together.

2. Differential pair: how the tail current splits

Two transistors with joined sources and equal gate voltages have the same \(V_{GS}\), hence the same \(V_{OV}\), whatever their sizes, so \(I_1/I_2 = (W/L)_1/(W/L)_2 = m\). The tail source fixes \(I_1 + I_2 = I_{tail}\):

\[ I_1 = I_{tail}\frac{m}{1+m},\quad I_2 = \frac{I_{tail}}{1+m},\quad V_{OV} = \sqrt{\frac{2I_2}{k_2}} \]\[ V_S = V_G - V_t - V_{OV},\quad V_{Di} = V_{DD} - I_iR_{Di} \]

Method · pair with equal gate voltages

  1. Same \(V_G\) and \(V_S\) ⇒ same \(V_{GS}\) ⇒ \(I_1:I_2 = (W/L)_1:(W/L)_2\).
  2. Split \(I_{tail}\): \(I_2 = I_{tail}/(1+m)\).
  3. \(V_{OV}\) from either device (they are equal); \(V_S = V_G - V_t - V_{OV}\) (a negative number for a grounded gate).
  4. \(V_{D1}\), \(V_{D2}\) from the drain resistors. Check \(V_D \ge V_G - V_t\) for each. A drain may sit below 0 V and still be saturated; compare with \(V_G - V_t\), not with 0.

Worked example: 2024–25 Sec A Q3(b)

3. Complementary NMOS/PMOS pair with a load (type M-07)

One NMOS and one PMOS share the gate input; the supplies are ±V, and a resistor goes from the output to ground. The question: \(i_{DN}\), \(i_{DP}\) and \(v_o\) for given \(v_I\), with matched \(k_n = k_p\) and \(V_{tn} = -V_{tp}\). There are two topologies; identify which first.

Method · follower (sources joined)

  1. Which device can be on? NMOS needs \(v_I - v_O > V_t\); PMOS needs \(v_O - v_I > |V_{tp}|\). At \(v_O = 0\): if \(|v_I| \le V_t\) both are off and \(i_{DN} = i_{DP} = 0\), \(v_o = 0\) (the dead zone of a class-B follower).
  2. For \(v_I > V_t\) only the NMOS conducts: \(v_o = IR\) with \(I = \tfrac12k(v_I - v_o - V_t)^2\). With \(u = v_I - V_t\): \(v_o^2 - (2u + \tfrac{2}{kR})v_o + u^2 = 0\); take the smaller root (the larger one has \(v_{GS} = v_I - v_o < V_t\): reject).
  3. \(i_{DN} = v_o/R\), \(i_{DP} = 0\). Check \(V_{DS} = V - v_o \ge V_{OV} = u - v_o\) ✓ (always true for \(v_I \le V\)).
  4. For \(v_I < -V_t\) the PMOS conducts: mirror image, \(v_o\) negative, \(i_{DP} = |v_o|/R\).

Method · inverter (drains joined) at \(v_I = \pm V\)

  1. At \(v_I = -V\): NMOS off (\(V_{GS} = 0\)); PMOS has \(V_{SG} = 2V\), \(|V_{OV}| = 2V - |V_t|\), large.
  2. Try saturation: \(\tfrac12k(2V - V_t)^2\) is many mA, which would put \(v_o\) above \(+V\): impossible ∴ PMOS in triode. With \(x = V_{SD}\): \(\tfrac k2x^2 - (kV_{OV} + \tfrac1R)x + \tfrac VR = 0\), small root with \(x < V_{OV}\).
  3. \(v_o = V - x\), \(i_{DP} = v_o/R\), \(i_{DN} = 0\). Mirror image for \(v_I = +V\) (\(v_o = -(V - x)\), \(i_{DN} = |v_o|/R\)).
  4. \(v_I = 0\): both on, matched ⇒ \(v_o = 0\), each device \(\tfrac12k(V - V_t)^2\), both saturated if \(V \ge V_{OV}\).

An unmatched inverter at \(v_I\) = 0 (Sadat L22, notes p.96–97)

Inverter between ±2.5 V, 1 kΩ to ground, \(k_p\) = 2, \(k_n\) = 1 mA/V², \(V_{tn} = -V_{tp} = 1\) V, \(v_I = 0\). Both on, \(V_{OV} = 1.5\) V each. Assume both saturated: \(I_{DP}\) = 2.25 mA, \(I_{DN}\) = 1.125 mA, \(v_o = (2.25 - 1.125)(1) = 1.125\) V, so \(V_{SD,p} = 1.375 < 1.5\): PMOS not saturated. Take PMOS triode, NMOS saturated (\(I_{DN}\) = 1.125 mA since \(V_{DS,n} = v_o + 2.5 \ge 1.5\)): \(I_{DP} = 2[1.5x - \tfrac12x^2]\) with \(x = V_{SD}\) and \(v_o = I_{DP} - 1.125 = 2.5 - x\), so \(x^2 - 4x + 3.625 = 0\), \(x\) = 1.388 or 2.612 V. Reject 2.612 V (> 1.5, not triode). \(V_{SD}\) = 1.388 V, \(I_{DP}\) = 2.237 mA, \(v_o\) = 1.112 V, and \(1.388 < 1.5\) confirms the triode assumption. "Both can't be in triode" (Sadat's margin note): try the cases in order and check each.

Traps (where marks go)

  • Not writing the saturation check for a mirror output: the paper marks \(V_{D2} \ge V_{OV}\) separately (2018–19: 6 V ≥ 2 V).
  • Declaring Q1 triode because \(V_{D1}\) is negative in the diff pair. Compare \(V_D\) with \(V_G - V_t = -1\) V, not with zero.
  • Forgetting that a larger \(R_D\) pushes the mirror output out of saturation, after which the ratio no longer holds.
  • Follower at \(v_I = 0\): the answer is zero current, not 1.125 mA (that is the inverter at \(v_I = 0\)).
  • Assuming saturation for the conducting inverter device (gives an impossible 8 mA).
  • Taking the larger quadratic root in the follower (\(v_o\) = 2.157 V gives \(V_{GS} < V_t\)).
  • PMOS signs: \(V_{SG}\), \(V_{SD}\), \(|V_{tp}|\); current out of the drain into the load.

Exam questions

2024–25 · Sec A · Q3(b) · 17 marks  |  = Sedra mismatched pair, qbank S5-Q9

In the circuit, \((W/L)_1 = 2(W/L)_2 = 20\). Both NMOS have \(V_t\) = 1 V and \(\mu_nC_{ox}\) = 100 µA/V². Find the node voltages \(V_1\), \(V_2\), \(V_3\). (Both gates at 0 V; \(R_{D1} = R_{D2}\) = 40 kΩ from +5 V to the drains \(V_1\), \(V_2\); sources joined at \(V_3\); a 200 µA current source from \(V_3\) to the negative supply.)

Show worked answer

The gates and sources are common, so \(V_{GS1} = V_{GS2}\); equal \(V_{OV}\) means \(I_1/I_2 = (W/L)_1/(W/L)_2 = 2\). \(I_1 + I_2\) = 200 µA ⇒ \(I_1\) = 133.3 µA, \(I_2\) = 66.7 µA.

\(k_2 = 0.1\times10 = 1\) mA/V² (\(k_1\) = 2). Assume saturation: \(V_{OV} = \sqrt{2(0.0667)/1} = 0.365\) V (check with Q1: \(\sqrt{2(0.1333)/2}\) = 0.365 ✓).

\(V_{GS} = 1.365\) V, so \(V_3 = 0 - 1.365 = -1.365\) V.

\(V_1 = 5 - 0.1333\times40 = -0.333\) V, \(V_2 = 5 - 0.0667\times40 = 2.333\) V.

Check (saturation, \(V_D \ge V_G - V_t = -1\) V): \(V_1 = -0.333 \ge -1\) ✓ (\(V_{DS1} = 1.032 \ge 0.365\)), \(V_2 = 2.333 \ge -1\) ✓. ∴ both saturated; Q1 is saturated although its drain is below ground.

2022–23 · Sec A · Q2(a) · 20 marks · compulsory  |  = 2014–15 Sec A Q4(a) (\(v_I\) = ±2.5 V) · Sadat L22 notes p.94

The NMOS and PMOS in the circuit are matched with \(k_n = k_p\) = 1 mA/V² and \(V_{tn} = -V_{tp}\) = 1 V. Assuming λ = 0 for both, find the drain currents \(i_{DN}\), \(i_{DP}\) and the output voltage \(v_O\) for \(v_I\) = 0 and \(v_I\) = +2.5 V. (Complementary source follower: QN drain at +2.5 V, QP drain at −2.5 V, sources joined at \(v_O\), 10 kΩ from \(v_O\) to ground.)

Show worked answer

\(v_I\) = 0. Try \(v_O\) = 0: \(V_{GSN} = 0 < V_t\) and \(V_{SGP} = 0 < |V_{tp}|\): both off, no current, so \(v_O = 0\) is consistent. \(i_{DN} = i_{DP} = 0\), \(v_O = 0\).

\(v_I\) = +2.5 V. QP has \(V_{SG} = v_O - 2.5 < 0\) for any \(v_O \le 2.5\): off. QN on. Assume saturation: \(i_{DN} = \tfrac12(1)(2.5 - v_O - 1)^2 = v_O/10\) ⇒ \((1.5 - v_O)^2 = 0.2v_O\) ⇒ \(v_O^2 - 3.2v_O + 2.25 = 0\) ⇒ \(v_O\) = 1.043 V or 2.157 V.

Reject 2.157 V: \(V_{GS} = 2.5 - 2.157 = 0.343 < V_t\), no channel. \(v_O\) = 1.043 V, \(i_{DN}\) = 0.1043 mA, \(i_{DP}\) = 0.

Check: \(V_{GS} = 1.457\) V, \(V_{OV} = 0.457\) V, \(V_{DS} = 2.5 - 1.043 = 1.457 \ge 0.457\) ∴ saturated ✓.

(2014–15 also asks \(v_I\) = −2.5 V: mirror image, QP on: \(v_O\) = −1.043 V, \(i_{DP}\) = 0.104 mA, \(i_{DN}\) = 0.)

2018–19 · Sec A · Q4(b) · 20 marks  |  Sedra Exercise D5.10 pattern

Find \(R\) so that \(I_{D1}\) = 0.4 mA. Also find \(V_{D1}\), \(V_{D2}\) and \(I_{D2}\). Q1 and Q2 are identical: \(V_t\) = 2 V, \(\mu_nC_{ox}\) = 20 µA/V², \(L\) = 10 µm, \(W\) = 100 µm. (R from +10 V to the drain/gate of Q1; Q2 shares Q1's gate, with 10 kΩ from +10 V to its drain; both sources grounded.)

Show worked answer

\(k_n = 0.02\times10 = 0.2\) mA/V². Q1 is diode-connected (\(V_{GD} = 0\)): saturated. \(0.4 = \tfrac12(0.2)V_{OV}^2\) ⇒ \(V_{OV}\) = 2 V (reject −2 V: \(V_{GS} < V_t\)), \(V_{GS} = 4\) V.

\(V_{D1} = V_{GS} = 4\) V, \(R = (10 - 4)/0.4 = 15\) kΩ.

Q2 has the same \(V_{GS}\) and the same \(W/L\), so (if saturated) \(I_{D2}\) = 0.4 mA, \(V_{D2} = 10 - 0.4\times10 = 6\) V. Check: \(V_{D2} = 6 \ge V_{OV} = 2\) ✓ saturated, so the mirror holds.

2016–17 · Sec B · Q7(a) · 26 marks

For all the MOSFETs \(|V_t|\) = 1 V, \(\mu_nC_{ox}\) = 50 µA/V², \(L\) = 1 µm, \(W\) = 10 µm. Find \(V\) and \(I\). If Q3 and Q4 are made to have \(W\) = 100 µm, find \(V\) and \(I\) in that case. (All NMOS. Q2: drain and gate at +5 V, source X. Q1: drain and gate at X, source ground. Q4: drain and gate at +5 V, source at \(V\). Q3: gate at X, drain at \(V\), source ground.)

The figure is redrawn from the senior solution's netlist; check the node names against the paper.

Show worked answer

\(k = 0.05\times10 = 0.5\) mA/V² for \(W\) = 10 µm.

Reference stack Q2–Q1. Both diode-connected (saturated), same current, same \(k\): same \(V_{GS}\). \(V_{GS1} = X\), \(V_{GS2} = 5 - X\) ⇒ \(X\) = 2.5 V. \(I = \tfrac12(0.5)(2.5 - 1)^2 = 0.5625\) mA.

Case 1 (all \(W\) = 10 µm): Q3 has \(V_{GS3} = X\) = 2.5 V like Q1, so \(I_3 = 0.5625\) mA. Q4 is identical to Q2, with the same current, so \(V_{GS4} = 2.5\) V and \(V = 5 - 2.5\) = 2.5 V, \(I\) = 0.5625 mA. Check Q3: \(V_{DS3} = 2.5 \ge V_{OV} = 1.5\) ✓.

Case 2 (Q3, Q4 \(W\) = 100 µm, \(k\) = 5 mA/V²): Q3 still has \(V_{GS3}\) = 2.5 V, so \(I_3 = \tfrac12(5)(1.5)^2 = 5.625\) mA (10 times larger). Q4, also 10 times wider and carrying the same current, has the same \(V_{GS4}\) as before: \(\tfrac12(5)(V_{GS4} - 1)^2 = 5.625\) ⇒ \(V_{GS4} = 2.5\) V, so \(V\) = 2.5 V and \(I\) = 5.625 mA (the Q3–Q4 branch; the Q1–Q2 branch is unchanged at 0.5625 mA). Check: \(V_{DS3} = 2.5 \ge 1.5\) ✓.

The output current scales by 10 but \(V\) does not, because the load device scaled with the output device.

2015–16 · Sec A · Q3(a) · 15 marks

The CMOS inverter circuit has \(k_n'(W_n/L_n) = k_p'(W_p/L_p)\) = 1 mA/V² and \(V_{tn} = -V_{tp}\) = 1 V. Find (i) \(i_{DN}\), (ii) \(i_{DP}\), (iii) \(v_O\) for \(v_{in}\) = −2.5 V. (Supplies ±2.5 V; 10 kΩ load from \(v_O\) to ground.)

Show worked answer

\(v_{in} = -2.5\) V: QN has \(V_{GS} = -2.5 - (-2.5) = 0 < V_t\): off, \(i_{DN} = 0\). QP has \(V_{SG} = 2.5 - (-2.5) = 5\) V, \(|V_{OV}| = 4\) V.

Assume saturation: \(i_{DP} = \tfrac12(1)(4)^2 = 8\) mA, which would need \(v_O = 80\) V > the 2.5 V supply: impossible ∴ QP is in triode.

\(x = V_{SD}\), \(v_O = 2.5 - x\): \(4x - \tfrac12x^2 = (2.5 - x)/10\) ⇒ \(5x^2 - 41x + 2.5 = 0\) ⇒ \(x\) = 0.0614 V or 8.14 V. Reject 8.14 V (> \(|V_{OV}|\) = 4 V and > 2.5 V).

\(v_O = 2.5 - 0.0614 = 2.439\) V, \(i_{DP} = 2.439/10 = 0.244\) mA, \(i_{DN}\) = 0. Check \(V_{SD} = 0.061 < 4\) ✓ triode.

2014–15 · Sec A · Q4(a) · 20 marks

The NMOS and PMOS in the circuit (the complementary follower of Figure 3, left) have \(k_n'(W_n/L_n) = k_p'(W_p/L_p)\) = 1 mA/V² and \(V_{tn} = -V_{tp}\) = 1 V, λ = 0. Find \(i_{DN}\), \(i_{DP}\), \(v_O\) for \(v_I\) = +2.5 V and −2.5 V.

Show worked answer

\(v_I\) = +2.5 V: QP off; QN: \((1.5 - v_O)^2 = 0.2v_O\) ⇒ \(v_O^2 - 3.2v_O + 2.25 = 0\) ⇒ 1.043 V (reject 2.157 V: \(V_{GS} < V_t\)). \(v_O\) = 1.043 V, \(i_{DN}\) = 0.104 mA, \(i_{DP}\) = 0. Saturated: \(V_{DS}\) = 1.457 ≥ \(V_{OV}\) = 0.457.

\(v_I\) = −2.5 V: the mirror image. QN is off (\(V_{GS} = -2.5 - v_O < 0\)); QP on with \(V_{SG} = v_O + 2.5\): \(\tfrac12(v_O + 2.5 - 1)^2 = -v_O/10\). With \(y = -v_O\): \((1.5 - y)^2 = 0.2y\) ⇒ \(y\) = 1.043 V. \(v_O\) = −1.043 V, \(i_{DP}\) = 0.104 mA, \(i_{DN}\) = 0.

Sedra 7e Exercise D5.10 · highlighted by the teacher

A diode-connected NMOS is fed from 1.8 V through \(R\); \(V_D\) = 0.7 V; \(V_t\) = 0.5 V, \(k_n\) = 0.4 mA/V² per unit \(W/L\), \(W/L\) = 0.72/0.18 (= 4). Find \(R\). A second, identical transistor Q2 is added as a mirror with \(R_2\) in its drain to 1.8 V: find \(R_2\) so that Q2 is at the edge of saturation.

Show worked answer

\(k_n = 0.4\times4 = 1.6\) mA/V². \(V_{OV} = 0.7 - 0.5 = 0.2\) V, \(I = \tfrac12(1.6)(0.04) = 0.032\) mA. \(R = (1.8 - 0.7)/0.032 = 34.4\) kΩ.

Q2 is identical with the same \(V_{GS}\): \(I_2 = 0.032\) mA. Edge of saturation: \(V_{D2} = V_{OV} = 0.2\) V ⇒ \(R_2 = (1.8 - 0.2)/0.032 = 50\) kΩ. A larger \(R_2\) would put Q2 in triode and the mirror would no longer copy the current.

Practice

Key terms

Quick check

Summary: equal \(V_{GS}\) ⇒ currents in the ratio of \(W/L\). Mirror: diode-connected M1 sets \(V_{GS}\) (\(I_{REF} = (V_{DD} - V_{GS})/R\)); \(I_O = I_{REF}\,(W/L)_2/(W/L)_1\) while \(V_{D2} \ge V_{OV}\); output resistance \(r_o\). Pair with equal gates: \(I_1:I_2 = (W/L)_1:(W/L)_2\), \(I_1 + I_2 = I_{tail}\), \(V_S = V_G - V_t - V_{OV}\); a drain below 0 V can still be saturated. Complementary follower: dead zone \(|v_I| \le V_t\), else \(v_o^2 - (2u + 2/kR)v_o + u^2 = 0\) (smaller root, \(u = |v_I| - V_t\)); inverter with a load: the conducting device is in triode, small root of \(\tfrac k2x^2 - (kV_{OV} + 1/R)x + V/R = 0\). Answers to remember: 133.3/66.7 µA and −0.333/2.333/−1.365 V; 1.043 V and 0.1043 mA; 2.439 V and 0.244 mA.
