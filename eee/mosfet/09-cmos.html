CMOS Inverter and Gates

CMOS logic was examined from 2013–14 to 2021–22 (gate synthesis, sizing, delay) and dropped with the other digital topics in 2022–23; the class covered only the DC behaviour of an NMOS–PMOS pair. Read this after the amplifier chapters. The inverter's DC analysis with a resistive load (2015–16) is in Chapter 5.

1. The CMOS inverter

A PMOS (source to \(V_{DD}\), drain to the output) and an NMOS (source to ground, drain to the output) share the gate (input); the two drains form the output. Input low: PMOS on (triode, \(v_{SD} \approx 0\)), NMOS off, output = \(V_{DD}\). Input high: the reverse, output = 0. In either steady state one transistor is off, so no static current flows, and the output swings rail to rail.

Switching threshold \(V_M\) (both saturated, equal currents): \(\tfrac12k_n(V_M - V_{tn})^2 = \tfrac12k_p(V_{DD} - V_M - |V_{tp}|)^2\):

\[ V_M = \frac{r\,(V_{DD} - |V_{tp}|) + V_{tn}}{1 + r}, \qquad r = \sqrt{k_p/k_n} \]

A matched inverter (\(k_p = k_n\), \(V_{tn} = |V_{tp}|\)) has \(V_M = V_{DD}/2\). Since \(\mu_n \approx 2\)–\(3\,\mu_p\), matching needs \((W/L)_p = (\mu_n/\mu_p)(W/L)_n\).

2. Static CMOS gates (type M-08)

Method · minimal static CMOS gate

  1. Simplify the function (Boolean algebra or K-map); check with a truth table.
  2. Write the output as a complement: \(Y = \overline{f}\).
  3. Pull-down network (NMOS) realises f: AND → series, OR → parallel.
  4. Pull-up network (PMOS) is the dual: series ↔ parallel, same inputs.
  5. Transistor count = 2 × number of literals in f (+2 for each inverter needed for a complemented input).

3. Sizing and delay (type M-09)

Method · equal worst-case resistance to a unit inverter

  1. Unit inverter: \(W_n = 1\), \(W_p = r = \mu_n/\mu_p\). A device of width W has resistance \(R/W\) (×r for PMOS).
  2. For every series path in each network, k devices in series each get width k (×r for PMOS), so the path resistance is R.
  3. A device on paths of different lengths takes the width of its longest path; size the remaining devices so each path totals exactly R (e.g. \(1/W_A + 1/3 = 1 \Rightarrow W_A = 1.5\)).
  4. \(t_{p,max} = 0.69RC_L\). For \(t_{p,min}\), turn on every parallel branch and reduce to the smallest \(R_{eq}\) for rise and for fall.

Traps

  • The pull-up is the dual of the pull-down, not a copy.
  • Static CMOS is inverting: implement \(\overline{f}\); an AND needs a NAND plus an inverter.
  • PMOS widths carry the extra factor \(\mu_n/\mu_p\).
  • Minimum delay must use input combinations that can actually occur together.

Exam questions

2020–21 · Sec B · Q5(a) · 20 marks

A gate network: \(N_1 = \text{NOR}(B, C)\), \(N_2 = \text{NAND}(A, B)\), \(N_3 = \text{NOR}(C, N_2)\), \(N_4 = \text{NOR}(N_1, N_3)\), \(Y = \text{NAND}(A, N_4)\). Implement Y in CMOS with the minimum number of transistors.

Show worked answer

\(\overline{N_3} = C + N_2 = C + \overline{AB}\), so \(N_4 = (B + C)(C + \overline{A} + \overline{B}) = C + B\overline{A}\). Then \(A\cdot N_4 = AC + AB\overline{A} = AC\), so \(Y = \overline{AC}\): a 2-input NAND of A and C, 4 transistors (two series NMOS, two parallel PMOS).

2020–21 · Sec B · Q5(b) · 26⅔ marks

A CMOS gate has pull-down network \((A \parallel (B\text{–}C))\) in series with D, i.e. \(Y = \overline{(A + BC)D}\); its pull-up is the dual \((A\text{–}(B\parallel C)) \parallel D\). With \(\mu_n = 3\mu_p\), size the transistors for the same worst-case resistance as a unit inverter (\(W_n = 1\), \(W_p = 3\)) and find the minimum and maximum propagation delays.

Show worked answer

NMOS: longest path B–C–D (3 in series): B = C = D = 3. Path A–D: \(1/W_A + 1/3 = 1 \Rightarrow W_A = 1.5\).

PMOS: path A–(B or C) has 2 in series: A = B = C = 2 × 3 = 6; D alone: 3.

Delays: \(t_{p,max} = 0.69RC_L\) (each worst path equals R). Fastest fall (all NMOS on): \((R/1.5 \parallel 2R/3) + R/3 = R/3 + R/3 = 2R/3\). Fastest rise (all PMOS on): \((R/2 + R/4) \parallel R = 3R/7\). So \(t_{p,min} = 0.69\times\tfrac37RC_L \approx 0.296RC_L\).

2013–14 · Sec B · Q5(b) · 15 marks

A CMOS inverter on a 5 V supply is driven by a 0/5 V square wave (high 0–5 s, low 5–10 s, …). Sketch the output.

Show worked answer

The output is the logical inverse: 0 V while the input is 5 V, 5 V while it is 0 V, rail to rail, with ideally no static current. Real transitions are not instantaneous: the edges take about \(0.69R_{on}C_L\).

Practice

Quick check

Summary: CMOS inverter: rail-to-rail, no static current, \(V_M = \frac{r(V_{DD} - |V_{tp}|) + V_{tn}}{1 + r}\) with \(r = \sqrt{k_p/k_n}\). Gates: NMOS pull-down realises \(\overline{Y}\) (AND series, OR parallel), PMOS pull-up is its dual. Size every series path to the unit-inverter resistance; \(t_p = 0.69RC_L\).
