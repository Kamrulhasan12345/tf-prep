The Common-Source Amplifier

The single most reliable MOSFET question. A CS amplifier (this chapter or the feedback-biased version in chapter 8) has been set in every paper from 2019–20 to 2024–25, and the full version was a 35-mark question in 2024–25 (also 46⅔ marks in 2011–12). There are two kinds: M-10 gives you the bias numbers and asks only the small-signal part (2023–24, 2021–22); M-11 makes you solve the DC bias first, then the AC part, then a signal limit or a circuit change (2024–25, 2020–21, 2011–12). Sadat sir: "MOSFET → numerical problem important for exam", and for amplifiers he wants \(R_{in}\), \(R_o\), \(A_v\), \(G_v\) derived, not quoted.

Units: mA, kΩ, V, mA/V, MΩ for gate resistors (keep \(R_{in}\) in kΩ when you combine it with \(R_{sig}\)). Sedra convention \(i_D = \tfrac12k_nV_{OV}^2\) unless the question writes Neamen's capital \(K_n\).

1. The circuit and the five-step procedure

Procedure (Sadat notes p.101) · any MOSFET amplifier

  1. DC analysis. Capacitors open. Find \(I_D\), \(V_{OV}\), \(V_D\); check saturation (\(V_{DS} \ge V_{OV}\), i.e. \(V_D \ge V_G - V_t\)).
  2. DC sources off. \(V_{DD}\) → ground. (DC current sources → open.)
  3. Capacitors short. \(C_1\), \(C_2\) connect; \(C_S\) shorts \(R_S\), so the source is at signal ground.
  4. Small-signal model. \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\); hybrid-π when the source is grounded, T model when a resistance stays in the source.
  5. AC analysis. \(R_{in}\), \(R_o\), \(A_{vo}\), \(A_v\), \(G_v\), signal limits.

2. Derivation of Rin, Ro, Avo, Av, Gv

This is the 2012–13 question (26⅔ marks) and the core of every numerical. After steps 2–4, Figure 1 becomes:

Input resistance. The gate draws no current, so looking into the gate terminal we see only the bias network: \(R_{in} = R_{G1}\parallel R_{G2}\) (\(= \infty\) if the gate network is not given).

Input divider. \(v_i = v_{gs} = v_{sig}\dfrac{R_{in}}{R_{in}+R_{sig}}\).

Open-circuit gain (\(R_L\) removed). The current \(g_mv_{gs}\) flows down through \(r_o\parallel R_D\) from ground to the drain node, so \(v_o = -g_mv_{gs}(r_o\parallel R_D)\) and \(A_{vo} = \dfrac{v_o}{v_i}\Big|_{R_L=\infty} = -g_m(R_D\parallel r_o)\).

Output resistance. Set \(v_{sig} = 0\). Then \(v_{gs} = 0\), the dependent source is dead (open), and a test source at the output sees \(R_o = R_D\parallel r_o\).

Gain with load. \(v_o = -g_mv_{gs}(R_D\parallel r_o\parallel R_L)\), so \(A_v = \dfrac{v_o}{v_i} = -g_m(R_D\parallel r_o\parallel R_L) = A_{vo}\dfrac{R_L}{R_L+R_o}\).

Overall gain. \(G_v = \dfrac{v_o}{v_{sig}} = \dfrac{R_{in}}{R_{in}+R_{sig}}\,A_v = -\dfrac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_D\parallel r_o\parallel R_L)\).

\[ R_{in} = R_{G1}\parallel R_{G2},\quad R_o = R_D\parallel r_o,\quad A_{vo} = -g_m(R_D\parallel r_o) \]\[ G_v = -\frac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_D\parallel r_o\parallel R_L) \]

Signal limits. (a) Small-signal (linearity): \(\hat v_{gs} \le 0.1V_{OV}\) (or whatever fraction is stated), so \(\hat v_{sig,\max} = 0.1V_{OV}\,\dfrac{R_{in}+R_{sig}}{R_{in}}\). (b) Saturation (Sedra P7.118): at the negative output peak the drain must stay above \(v_G - V_t\): \(V_D - |A_v|\hat v_{g} \ge V_G + \hat v_{g} - V_t\), so \(\hat v_g \le \dfrac{V_D - V_G + V_t}{1+|A_v|}\) (source bypassed, \(v_g = v_{gs}\)). (c) Required input for a given output: \(\hat v_{sig} = \hat v_o/|G_v|\).

3. Type M-10: CS amplifier from given bias numbers

No DC solving: the question states \(I_D\) and \(V_{OV}\) (or \(\mu_nC_{ox}\), W/L and \(I_D\)) and asks the small-signal quantities. Often no circuit is drawn: assume the standard CS of Figure 2 with \(R_{in} = \infty\) unless a gate network is given.

Method · M-10 (8 lines)

  1. \(g_m = 2I_D/V_{OV}\), or \(g_m = \sqrt{2k_n'(W/L)I_D}\).
  2. \(r_o = V_A/I_D\) (∞ if no \(V_A\)).
  3. \(R_{in} = R_G\) (∞ if no gate network, then \(v_{gs} = v_{sig}\)).
  4. \(R_o = R_D\parallel r_o\).
  5. \(A_{vo} = -g_mR_o\) (no \(R_L\) here).
  6. \(A_v = -g_m(R_D\parallel r_o\parallel R_L) = A_{vo}R_L/(R_L+R_o)\).
  7. \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\).
  8. Required \(\hat v_{sig} = \hat v_o/|G_v|\); linear limit \(\hat v_{gs} \le 0.1V_{OV}\).

Worked example: 2023–24 Sec B Q7(b)

4. Type M-11: full CS amplifier (DC bias, then AC)

Method · M-11

  1. DC (caps open): \(V_G = V_{DD}\dfrac{R_{G2}}{R_{G1}+R_{G2}}\); \(V_{GS} = V_G - I_DR_S\); \(I_D = \tfrac12k_n(V_G - V_t - I_DR_S)^2\).
  2. Expand to a quadratic in \(I_D\): \(\tfrac12k_nR_S^2I_D^2 - (k_nR_SV_x + 1)I_D + \tfrac12k_nV_x^2 = 0\) with \(V_x = V_G - V_t\). Two roots: keep the one with \(V_{GS} > V_t\); write why the other is rejected.
  3. \(V_{OV} = V_{GS} - V_t\), \(V_S = I_DR_S\), \(V_D = V_{DD} - I_DR_D\); saturation: \(V_{DS} \ge V_{OV}\).
  4. \(g_m = 2I_D/V_{OV}\) (= \(k_nV_{OV}\)); \(r_o = V_A/I_D\) (bias computed without λ).
  5. AC (bypassed \(R_S\) → 0): \(R_{in} = R_{G1}\parallel R_{G2}\), \(R_o = R_D\parallel r_o\), \(A_v = -g_m(r_o\parallel R_D\parallel R_L)\), \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\).
  6. Limit: \(\hat v_{sig,\max} = 0.1V_{OV}\dfrac{R_{in}+R_{sig}}{R_{in}}\).
  7. To raise that limit N times without moving the bias: leave \(R_s = (N-1)/g_m\) of \(R_S\) unbypassed (section 5).

Worked example: 2024–25 Sec A Q2 (35 marks), parts (i)–(iv)

5. CS with a source resistance Rs (source degeneration)

If part (or all) of the source resistance is not bypassed, use the T model (Khairul s.44–45). The resistance \(R_s\) is in series with \(1/g_m\):

Gate current is zero, so \(v_i\) appears across \(1/g_m + R_s\): \(i = \dfrac{v_i}{1/g_m + R_s} = \dfrac{g_m}{1+g_mR_s}v_i\).

The part across \(1/g_m\) is \(v_{gs}\): \(v_{gs} = v_i\dfrac{1/g_m}{1/g_m + R_s} = \dfrac{v_i}{1+g_mR_s}\).

The same \(i\) leaves the drain node: \(v_o = -i(R_D\parallel R_L)\). Hence

\[ A_{vo} = -\frac{g_mR_D}{1+g_mR_s},\qquad A_v = -\frac{g_m(R_D\parallel R_L)}{1+g_mR_s} = -\frac{R_D\parallel R_L}{1/g_m + R_s},\qquad R_{in} = R_G,\ \ R_o = R_D \]

Rule (Khairul s.44): gain from gate to drain = −(total resistance in the drain) / (total resistance in the source).

Why do it? The gain drops by \(1 + g_mR_s\), but \(v_{gs}\) is also divided by \(1 + g_mR_s\), so the input can be \((1 + g_mR_s)\) times larger before the small-signal limit is reached, and the gain becomes less sensitive to \(g_m\) (more predictable). Choosing \(R_s = 1/g_m\) doubles the allowed input and halves the gain. The DC bias does not change because the total DC source resistance stays \(R_S\): split \(R_S\) into \(R_s\) (unbypassed) + \(R_S - R_s\) (bypassed by \(C_S\)).

Method · CS with Rs

  1. DC exactly as before (all of \(R_S\) counts).
  2. \(A_v = -\dfrac{g_m(R_D\parallel R_L)}{1+g_mR_s}\) (neglect \(r_o\) unless told), \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\).
  3. Linear limit: \(\hat v_{gs} = \hat v_i/(1+g_mR_s) \le 0.1V_{OV}\), so \(\hat v_{sig,\max} = 0.1V_{OV}(1+g_mR_s)\dfrac{R_{in}+R_{sig}}{R_{in}}\).
  4. For an N-times larger input: \(R_s = (N-1)/g_m\).

6. The saturation (swing) limit

A different limit, asked in Sedra P7.118/P7.119 (highlighted by the teacher): the largest input for which the transistor stays in saturation. At the instant the gate is at its most positive, the drain is at its lowest. Condition \(v_D \ge v_G - V_t\):

\[ V_D - |A_v|\hat v_g \;\ge\; V_G + \hat v_g - V_t \quad\Longrightarrow\quad \hat v_g \le \frac{V_D - V_G + V_t}{1+|A_v|} \]\[ \hat v_{sig} = \hat v_g\frac{R_{in}+R_{sig}}{R_{in}},\qquad \hat v_o = |A_v|\hat v_g \]

(Source bypassed, so \(v_g = v_{gs}\). For a PMOS, the condition is \(v_D \le v_G + |V_{tp}|\).)

Traps (where marks go)

  • Wrong quadratic root. The larger \(I_D\) root makes \(V_{GS} = V_G - I_DR_S < V_t\) (2024–25: 0.653 mA gives \(V_{GS}\) = 0.43 V). Reject it and say so.
  • \(R_{in}\) = series sum. \(R_{G1}\) goes to \(V_{DD}\), which is AC ground: \(R_{in} = R_{G1}\parallel R_{G2}\) (10 M ∥ 5 M = 3.33 MΩ, not 15 MΩ).
  • Forgetting \(C_S\). A bypassed \(R_S\) is zero for AC; an unbypassed one divides the gain by \(1 + g_mR_s\).
  • \(R_L\) in \(A_{vo}\). \(A_{vo}\) is the open-circuit gain; \(R_L\) enters only \(A_v\) and \(G_v\).
  • Leaving out \(r_o\) when \(V_A\) or λ is given (or putting λ into the bias when told to ignore it).
  • Convention. "\(k_n\) = 0.5 mA/V²" means \(i_D = \tfrac12k_nV_{OV}^2\); Neamen's \(K_n\) has no ½ (2020–21 gives −2.65 V/V vs −5.21 V/V). State which.
  • Sign. CS gains are negative (inverting). Write the minus sign on \(A_{vo}\), \(A_v\), \(G_v\).

Exam questions

2024–25 · Sec A · Q2(i)–(v) · 35 marks  |  = Sedra 7e P7.33 (highlighted by the teacher) plus parts (iv)–(v)

The circuit in the figure is a common-source amplifier. All capacitors are open at DC and short at AC. \(V_t\) = 1 V, \(\mu_nC_{ox}(W/L)\) = 4 mA/V², \(V_A\) = 100 V. (i) Find DC \(V_D\) and \(I_D\) (ignore the Early effect for bias). (ii) Find \(g_m\), \(r_o\) and draw the small-signal equivalent. (iii) Determine expressions and values of \(R_{in}\), \(R_o\) and the overall gain \(v_o/v_{sig}\). (iv) Calculate the maximum peak \(v_{sig}\) while maintaining \(v_{gs} \le 0.1V_{OV}\). (v) Suggest a circuit modification that allows the maximum \(v_{sig}\) of (iv) to be doubled while keeping the small-signal approximation, without changing the DC bias point.

Show worked answer

(i) DC. \(V_G = 15\times\dfrac{5}{10+5} = 5\) V. \(V_{GS} = 5 - 7I_D\), \(I_D = \tfrac12\times4\,(5 - 7I_D - 1)^2 = 2(4 - 7I_D)^2\).

\(98I_D^2 - 113I_D + 32 = 0 \Rightarrow I_D = 0.5\) mA or 0.653 mA. For 0.653 mA, \(V_{GS} = 5 - 4.57 = 0.43\text{ V} < V_t\): the transistor would be off, contradiction, so reject. \(I_D\) = 0.5 mA, \(V_S\) = 3.5 V, \(V_{GS}\) = 1.5 V, \(V_{OV}\) = 0.5 V, \(V_D = 15 - 0.5\times16 = 7\) V. \(V_{DS} = 3.5\text{ V} > V_{OV}\): saturated ✓.

(ii) \(g_m = 2I_D/V_{OV} = 2\times0.5/0.5 = 2\) mA/V; \(r_o = V_A/I_D = 100/0.5 = 200\) kΩ. Small-signal circuit: Figure 2 with \(R_{sig}\) = 200 kΩ, \(R_G\) = 3.33 MΩ, \(g_mv_{gs}\), \(r_o\) = 200 kΩ, \(R_D\) = 16 kΩ, \(R_L\) = 16 kΩ; source grounded (\(C_3\) shorts the 7 kΩ).

(iii) \(R_{in} = R_{G1}\parallel R_{G2} = 10\parallel5 = 3.33\) MΩ. \(R_o = R_D\parallel r_o = 16\parallel200 = 14.8\) kΩ.
\(\dfrac{v_{gs}}{v_{sig}} = \dfrac{3333}{3333+200} = 0.943\); \(\dfrac{v_o}{v_{gs}} = -g_m(r_o\parallel R_D\parallel R_L) = -2\times(200\parallel16\parallel16) = -2\times7.69 = -15.4\) V/V;
\(G_v = 0.943\times(-15.4) = -14.5\) V/V.

(iv) \(\hat v_{gs} \le 0.1\times0.5 = 50\) mV, so \(\hat v_{sig} \le 50/0.943 = 53\) mV.

(v) Split \(R_S\) = 7 kΩ into \(R_s\) = 0.5 kΩ (not bypassed) in series with 6.5 kΩ (bypassed by \(C_3\)). The DC source resistance is still 7 kΩ, so the bias is unchanged. Now \(v_{gs} = v_i/(1+g_mR_s) = v_i/(1 + 2\times0.5) = v_i/2\), so \(v_{sig}\) can be doubled to about 106 mV with \(v_{gs}\) still ≤ 50 mV. The price: the gain about halves, \(A_v \approx -g_m(R_D\parallel R_L)/(1+g_mR_s) = -2\times8/2 = -8\) V/V (\(r_o\) neglected), \(G_v \approx -7.5\) V/V. General rule: \(R_s = 1/g_m\).

2023–24 · Sec B · Q7(b) · 15 marks

A CS amplifier is connected to a source \(v_{sig}\) with resistance \(R_{sig}\) and uses a MOSFET with \(\mu_nC_{ox}\) = 400 µA/V², W/L = 10, \(V_A\) = 10 V. It is biased at \(I_D\) = 0.2 mA and uses \(R_D\) = 6 kΩ. Find \(R_{in}\), \(A_{vo}\) and \(R_o\). If a 10 kΩ load is connected, what is the overall voltage gain \(G_v\)? If a 0.2 V peak sine wave is required at the output, what must the peak amplitude of \(v_{sig}\) be?

Show worked answer

No gate network is given, so \(R_{in} = \infty\) and \(v_{gs} = v_{sig}\) (\(R_{sig}\) carries no current).

\(k_n = 0.4\times10 = 4\) mA/V². \(g_m = \sqrt{2\times4\times0.2} = 1.265\) mA/V (\(V_{OV} = 2\times0.2/1.265 = 0.316\) V). \(r_o = 10/0.2 = 50\) kΩ.

\(R_{in} = \infty\). \(R_o = R_D\parallel r_o = 6\parallel50 = 5.36\) kΩ. \(A_{vo} = -g_mR_o = -1.265\times5.357 = -6.78\) V/V.

With \(R_L\) = 10 kΩ: \(G_v = A_v = -g_m(6\parallel50\parallel10) = -1.265\times3.488 = \) −4.41 V/V (check: \(A_{vo}R_L/(R_L+R_o) = -6.78\times10/15.36 = -4.41\)).

\(\hat v_{sig} = 0.2/4.41 = \) 45.3 mV. (Note: that is \(0.14V_{OV}\); within Sedra's 0.2\(V_{OV}\) guideline, slightly above the 0.1\(V_{OV}\) rule.)

2021–22 · Sec B · Q7(b) · 20 marks  |  Sedra exercise, also Khairul s.43

A CS amplifier utilizes a MOSFET biased at \(I_D\) = 0.25 mA with \(V_{OV}\) = 0.25 V and \(R_D\) = 20 kΩ. The amplifier is fed with a signal source having \(R_{sig}\) = 100 kΩ, and a 20 kΩ load is connected to the output. Find \(R_{in}\), \(A_{vo}\), \(R_o\), \(A_v\) and \(G_v\).

Show worked answer

\(g_m = 2I_D/V_{OV} = 2\times0.25/0.25 = 2\) mA/V. No \(V_A\): \(r_o = \infty\). No gate network: \(R_{in} = \infty\).

\(R_{in} = \infty\); \(A_{vo} = -g_mR_D = -2\times20 = -40\) V/V; \(R_o = R_D = 20\) kΩ; \(A_v = -g_m(R_D\parallel R_L) = -2\times10 = -20\) V/V; \(G_v = A_v = -20\) V/V (since \(R_{in} = \infty\), \(v_i = v_{sig}\)).

(Khairul's slide adds: if the input peak is limited to 10 % of \(2V_{OV}\) = 50 mV, the output peak is 20 × 0.05 = 1 V.)

2012–13 · Sec B · Q6(a) · 26⅔ marks

For the CS amplifier, derive the expressions for input resistance (\(R_{in}\)), output resistance (\(R_{out}\)), open-circuit voltage gain (\(A_{vo}\)) and overall voltage gain (\(G_v\)).

Show worked answer

Draw Figure 1 (discrete CS with divider bias and bypassed \(R_S\)); state: capacitors short for signals, \(V_{DD}\) at AC ground, transistor saturated with \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\). Draw Figure 2.

\(R_{in}\): \(i_g = 0\), so \(R_{in} = R_{G1}\parallel R_{G2} = R_G\).

\(A_{vo}\): \(v_i = v_{gs}\). With the output open, \(g_mv_{gs}\) flows through \(R_D\parallel r_o\) into the drain node from ground: \(v_o = -g_mv_{gs}(R_D\parallel r_o)\), so \(A_{vo} = -g_m(R_D\parallel r_o)\).

\(R_{out}\): with \(v_{sig} = 0\): \(v_{gs} = 0\), so \(g_mv_{gs} = 0\) (open). A test voltage \(v_x\) at the output drives \(i_x = v_x/R_D + v_x/r_o\), so \(R_{out} = R_D\parallel r_o\).

\(G_v\): \(v_{gs} = v_{sig}\dfrac{R_G}{R_G+R_{sig}}\); with \(R_L\): \(v_o = -g_mv_{gs}(R_D\parallel r_o\parallel R_L)\). So

\[ G_v = \frac{v_o}{v_{sig}} = -\frac{R_G}{R_G+R_{sig}}\,g_m(R_D\parallel r_o\parallel R_L) = \frac{R_{in}}{R_{in}+R_{sig}}\,A_{vo}\,\frac{R_L}{R_L+R_{out}} \]

Comment: \(R_{in}\) is very high (MΩ), so \(G_v \approx A_v\); the gain is moderate because \(g_m\) of a MOSFET is small; the output resistance \(R_D\) is fairly high, so a low-resistance load reduces the gain.

2011–12 · Sec A · Q4(a)(b)(c) · 46⅔ marks

A common-source amplifier circuit is shown in the figure. (a) Prove that this circuit is operating in the saturation region. (b) Draw the small-signal equivalent circuit. (c) Find \(g_m\), \(R_{in}\), \(R_{out}\), \(A_v\) and \(G_v\). Assume \(V_t\) = 1 V, \(k_n'W/L\) = 2 mA/V², \(V_A\) = 100 V. (+15 V; \(R_{G1}\) = 10 MΩ, \(R_{G2}\) = 5 MΩ; \(R_D\) = 7.5 kΩ; \(R_S\) = 3 kΩ bypassed; \(R_{sig}\) = 100 kΩ; \(R_L\) = 10 kΩ.)

Show worked answer

(a) \(V_G = 15\times5/15 = 5\) V. Assume saturation: \(I_D = \tfrac12\times2\,(5 - 3I_D - 1)^2 = (4 - 3I_D)^2 \Rightarrow 9I_D^2 - 25I_D + 16 = 0 \Rightarrow I_D = 1\) mA or 1.78 mA. 1.78 mA gives \(V_{GS} = 5 - 5.33 = -0.33\) V < \(V_t\): reject. So \(I_D\) = 1 mA, \(V_S\) = 3 V, \(V_{GS}\) = 2 V, \(V_{OV}\) = 1 V, \(V_D = 15 - 7.5 = 7.5\) V. \(V_{DS} = 4.5\text{ V} > V_{OV} = 1\) V, i.e. \(V_D = 7.5 > V_G - V_t = 4\) V: saturation confirmed.

(b) Figure 2 with \(R_G\) = 10 M ∥ 5 M, \(r_o\), \(R_D\) = 7.5 kΩ, \(R_L\) = 10 kΩ, source grounded.

Sedra 7e P7.118 · highlighted by the teacher · also Khairul s.47 (statement only)

The NMOS transistor in the CS amplifier (5 V supply; 300 kΩ/200 kΩ gate divider; \(R_D\) = 5 kΩ; \(R_S\) = 2 kΩ bypassed by \(C_S\); \(R_{sig}\) = 120 kΩ; \(R_L\) = 5 kΩ) has \(V_t\) = 0.7 V and \(V_A\) = 50 V. (a) Neglecting the Early effect, verify that the MOSFET is in saturation with \(I_D\) = 0.5 mA and \(V_{OV}\) = 0.3 V. What must \(k_n\) be? What is \(V_D\)? (b) Find \(R_{in}\) and \(G_v\). (c) Find the largest \(\hat v_{sig}\) for which the transistor stays in saturation, and the output amplitude. (d) What resistance \(R_s\) in series with \(C_S\) lets you double \(\hat v_{sig}\)? What output results?

Show worked answer

(a) \(V_G = 5\times200/500 = 2\) V. With 0.5 mA: \(V_S\) = 1 V, \(V_{GS}\) = 1 V, \(V_{OV}\) = 0.3 V ✓. \(k_n = 2I_D/V_{OV}^2 = 1/0.09 = 11.1\) mA/V². \(V_D = 5 - 2.5 = 2.5\) V; \(V_{DS} = 1.5 > 0.3\) ✓ saturated.

(b) \(R_{in} = 300\parallel200 = 120\) kΩ. \(g_m = 2\times0.5/0.3 = 3.33\) mA/V, \(r_o = 100\) kΩ. \(G_v = -\dfrac{120}{240}\times3.33\times(5\parallel5\parallel100) = -0.5\times3.33\times2.44 = -4.07\) V/V.

(c) \(|A_v| = 8.13\). \(\hat v_g \le \dfrac{V_D - V_G + V_t}{1+|A_v|} = \dfrac{2.5 - 2 + 0.7}{9.13} = 0.131\) V, so \(\hat v_{sig} = 0.131/0.5 = 0.263\) V and \(\hat v_o = 8.13\times0.131 = 1.07\) V.

(d) Manual's answer: keep \(v_{gs}\) as in (c) by making \(1 + g_mR_s = 2\): \(R_s = 1/g_m = 300\) Ω; the output stays about 1.07 V. A stricter check (the saturation condition with the doubled \(v_g\) and the reduced gain \(|A'| = 8.13/(1+g_mR_s)\)): \(0.263(1+|A'|) \le 1.2 \Rightarrow |A'| \le 3.56 \Rightarrow R_s \ge 0.385\) kΩ, and then \(\hat v_o = 3.56\times0.263 = 0.94\) V. Either is accepted if the reasoning is written.

A PMOS CS amplifier runs from ±2.5 V: source to +2.5 V through \(R_S\) (bypassed), drain to −2.5 V through \(R_D\), gate driven directly by \(v_{sig}\) (zero DC). \(V_{tp}\) = −0.7 V, \(V_A\) very large. (a) Select \(R_S\) for \(I_D\) = 0.3 mA and \(|V_{OV}|\) = 0.3 V. (b) Select \(R_D\) for \(G_v\) = −10 V/V. (c) Find the largest \(\hat v_{sig}\) for saturation and the output amplitude. (d) If \(\hat v_{sig}\) is limited to 50 mV, how large can \(R_D\) be made while staying saturated? What is the new \(G_v\)?

Show worked answer

(a) \(V_G = 0\); \(V_{SG} = 0.7 + 0.3 = 1\) V, so \(V_S = 1\) V and \(R_S = (2.5-1)/0.3 = 5\) kΩ.

(b) \(g_m = 2\times0.3/0.3 = 2\) mA/V; \(G_v = -g_mR_D = -10 \Rightarrow R_D = 5\) kΩ; \(V_D = -2.5 + 0.3\times5 = -1\) V.

(c) PMOS saturation: \(v_D \le v_G + |V_{tp}|\). When \(v_g\) swings to \(-\hat v\), \(v_d = +10\hat v\): \(-1 + 10\hat v \le -\hat v + 0.7 \Rightarrow \hat v \le 1.7/11 = 0.155\) V; \(\hat v_o = 1.55\) V.

(d) With \(\hat v = 0.05\) V: \(V_D + g_mR_D\hat v \le -\hat v + 0.7\), \(V_D = -2.5 + 0.3R_D\): \(-2.5 + 0.3R_D + 0.1R_D \le 0.65 \Rightarrow R_D \le 7.875\) kΩ; \(G_v = -2\times7.875 = -15.75\) V/V.

Key terms

Quick check

Summary: DC first (divider \(V_G\), quadratic in \(I_D\), reject the root with \(V_{GS} < V_t\), check \(V_{DS} \ge V_{OV}\)), then \(g_m = 2I_D/V_{OV}\), \(r_o = V_A/I_D\). AC: \(R_{in} = R_{G1}\parallel R_{G2}\), \(R_o = R_D\parallel r_o\), \(A_{vo} = -g_m(R_D\parallel r_o)\), \(A_v = -g_m(R_D\parallel r_o\parallel R_L)\), \(G_v = \frac{R_{in}}{R_{in}+R_{sig}}A_v\). An unbypassed \(R_s\) divides gain and \(v_{gs}\) by \(1+g_mR_s\) (gain = −drain R / source R); \(R_s = 1/g_m\) doubles the allowed input without moving the bias. Small-signal limit \(\hat v_{gs} \le 0.1V_{OV}\); saturation limit \(\hat v_g \le (V_D - V_G + V_t)/(1+|A_v|)\).
