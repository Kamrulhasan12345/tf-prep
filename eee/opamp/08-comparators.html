Comparators and Interfaces

An op-amp with no feedback is a comparator: its output slams to one rail or the other depending on which input is larger. Comparator-plus-logic design questions came in 2016–17 and 2017–18 (about 50 marks) and not since. Comparators with positive feedback (Schmitt triggers) are in Oscillators Chapter 5; this chapter covers the open-loop comparator and how to connect it to digital logic.

1. The open-loop comparator

\[ v_O = \begin{cases} L_+ & v_+ > v_- \\ L_- & v_+ < v_- \end{cases} \]
  • Zero-crossing detector: signal on +, − grounded. A sine in gives a square wave out at the same frequency.
  • Level detector: a reference \(V_{ref}\) on − (from a resistor divider): output high whenever \(v_i > V_{ref}\).
  • Logic levels: with ±15 V supplies the output is about ±13 V, not 0/5 V. Use a single 0/+5 V supply, or clamp the output with a resistor and a diode (or a 5.1 V Zener), to drive gates.
  • Noise: near the threshold an open-loop comparator chatters; add hysteresis (a Schmitt trigger) if the input is noisy.

2. Several thresholds: the resistor ladder

Method · range detector / coder

  1. List the thresholds \(T_1 < T_2 < \cdots\).
  2. Build a resistor string from \(V_{ref}\) to ground carrying a chosen current I (say 1 mA): each segment \(R = \Delta V / I\). The taps give the reference voltages.
  3. One comparator per threshold (input on +, tap on −): the outputs form a thermometer code (e.g. 000, 100, 110, 111).
  4. Write the truth table from thermometer code to the required output bits; impossible codes are don't-cares; minimise with a K-map (or use a multiplexer).

3. Waveform conversion chains

Comparator → square wave; T flip-flop → halves the frequency; integrator → triangle (slope = \(V_{sq}/RC\)). Design the RC from the required triangle: slope = peak / ramp time.

Traps

  • Comparator outputs are about ±13 V unless you provide logic levels.
  • Thermometer codes that cannot occur are don't-cares; use them in the K-map.
  • An inverting integrator ramps down for a positive input: pick the flip-flop output (Q or Q̄) that makes the ramp go the required way.
  • T flip-flop: state the triggering edge and the initial state.

Exam questions

2017–18 · Sec B · Q5(c) · 20⅔ marks

The input is \(v_{in} = 5\sin\) with period 10 ms (100 Hz). The required output is a triangle that rises from 0 to +2 V over 0–10 ms and returns to 0 at 20 ms (50 Hz). Design it with op-amps and digital circuits; +5 V is logic 1 and −5 V is logic 0.

Show worked answer
  1. Zero-crossing comparator (±5 V output levels): a ±5 V square wave at 100 Hz.
  2. T flip-flop with T = 1, clocked by that square wave: a 50 Hz square wave. Use Q̄, which is −5 V during 0–10 ms.
  3. Inverting integrator: with −5 V in, the output rises at \(5/RC\) V/s. Needed: 2 V in 10 ms = 200 V/s, so \(RC = 5/200 = 25\) ms (C = 1 µF, R = 25 kΩ). During 10–20 ms the input is +5 V and the output falls back to 0.

Reset the integrator capacitor at start-up so the triangle starts at 0 V.

2016–17 · Sec A · Q1(b) · 25 marks

Design a circuit with op-amps and digital logic that outputs a 3-bit code depending on the input range: 0–1.2 V → 010, 1.2–3.2 V → 110, 3.2–3.5 V → 001, 3.5–5 V → 111 (5 V = 1, 0 V = 0).

Show worked answer

References: a string from 5 V carrying 1 mA: 1.5 kΩ (5 → 3.5 V), 0.3 kΩ (3.5 → 3.2 V), 2 kΩ (3.2 → 1.2 V), 1.2 kΩ (1.2 → 0 V).

Comparators (single 0/5 V supply so outputs are logic levels): \(C_1 = [v > 1.2]\), \(C_2 = [v > 3.2]\), \(C_3 = [v > 3.5]\). Thermometer codes \(C_1C_2C_3\): 000, 100, 110, 111.
