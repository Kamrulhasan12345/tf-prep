Log, Antilog and Nonlinear Circuits

Put a diode, a BJT or a MOSFET where a resistor used to be and the op-amp computes a logarithm, an exponential, a square root or a square. These questions appeared in 2011–12, 2013–14, 2014–15, 2015–16, 2017–18, 2019–20 and 2021–22 (10 to 27 marks), about 145 marks in all, but none since 2021–22: treat this as medium-low priority. The derivations are short and always the same idea, so learn the one idea and the two classic designs (multiplier and frequency doubler).

1. One idea: virtual ground fixes the current

With the + input grounded and negative feedback, the − input sits at 0 V and takes no current. So whatever device is at the input carries a current set by \(v_I\) alone, and the same current must flow through the feedback device. The output is whatever voltage makes the feedback device carry that current.

Device at the input
Its I–V law is applied to \(v_I\): \(i = f(v_I)\). With a resistor in feedback, \(v_O = -R\,f(v_I)\).
Device in the feedback
The inverse law is applied: \(i = v_I/R\) and \(v_O = -f^{-1}(v_I/R)\).
Diode law used
\(i_D = I_S\,e^{v_D/\eta V_T}\) (forward bias, \(v_D \gg V_T\)); \(V_T\) = 25 mV here (Sadat's notes use 25.9 mV), \(\eta = 1\) unless given.
MOSFET law used
Saturation: \(i_D = \tfrac12 k_n'(W/L)(v_{GS} - V_t)^2 = K(v_{GS}-V_t)^2\) with \(K = \tfrac12 k_n'W/L\). Valid only if \(v_{DS} \ge v_{OV}\), i.e. \(v_{GD} \le V_t\).

2. Log amplifier (type O-02)

Derivation (2011–12, 26⅔ marks, is exactly this):

  1. Virtual ground: \(v_- = 0\), so \(i = v_I/R\), and all of it flows into the diode (\(i_- = 0\)).
  2. The diode's anode is at 0 V and its cathode at \(v_O\): \(v_D = 0 - v_O = -v_O\).
  3. \(\dfrac{v_I}{R} = I_S\,e^{-v_O/\eta V_T}\;\Rightarrow\; \boxed{v_O = -\eta V_T \ln\dfrac{v_I}{R\,I_S}}\).
  4. Conditions: \(v_I > 0\) (otherwise the diode is reverse biased and the loop opens), \(v_I/R \gg I_S\), constant temperature.

Each factor of 10 in \(v_I\) moves \(v_O\) by \(-\eta V_T\ln10 = -57.6\) mV (\(\eta\) = 1). The output is small (a few hundred mV) and depends on temperature through \(V_T\) and \(I_S\); practical log amps add a matched second diode to cancel \(I_S\).

BJT version (transdiode log amp). Replace the diode with an npn whose base is grounded, collector at the − input and emitter at the output: \(i_C = I_S e^{v_{BE}/V_T}\) with \(v_{BE} = -v_O\), so \(v_O = -V_T\ln\dfrac{v_I}{RI_S}\). The BJT follows the exponential law over many more decades than a diode (no \(\eta\), base current is not in the loop), which is why real log amps use it.

3. Antilog (exponential) amplifier

Derivation: the diode has \(v_D = v_I - 0 = v_I\), so \(i = I_S e^{v_I/\eta V_T}\). This current flows on through R to the output: \(0 - v_O = iR\), so

\[ v_O = -R\,I_S\,e^{v_I/\eta V_T} \qquad (v_I > 0,\; v_I \gg V_T) \]

Assumptions to state (2013–14 asked for them): ideal op-amp; diode forward biased with \(v_I \gg V_T\) so the "−1" in the diode equation is negligible; \(I_S\) and \(V_T\) constant (fixed temperature). The output is inverted and must stay inside the rails, so \(v_I\) can only range over a few hundred mV.

4. MOSFET in the loop: square root and square

Method · MOSFET feedback (square root)

  1. \(I_D = v_I/R_1\) (needs \(v_I > 0\); current flows from the − input into the drain).
  2. Gate at 0 V, source at \(v_O\): \(v_{GS} = -v_O\). Saturation: \(I_D = K(-v_O - V_t)^2\).
  3. \(v_O = -V_t - \sqrt{I_D/K} = -V_t - \sqrt{\dfrac{v_I}{KR_1}}\). Keep the root with \(v_{GS} > V_t\).
  4. Region check: \(V_D = -I_DR_D\), \(V_{DS} = V_D - v_O\). Saturation needs \(V_{DS} \ge V_{OV}\). With \(R_D = 0\): \(V_{GD} = 0 < V_t\), always saturated.

Squarer (MOSFET at the input). Drain at the virtual ground, gate held at \(V_t\) by a DC source, source driven by \(-v_I\) (from an inverter). Then \(v_{GS} = V_t + v_I\), \(v_{OV} = v_I\), \(I_D = K v_I^2\), drawn out of the − node, so it is supplied from the output through \(R_f\): \(v_O = +KR_f\,v_I^2\). \(V_{DS} = v_I = V_{OV}\): exactly at the edge of saturation (fine, but say so). For \(v_I < 0\) the device is off and \(v_O = 0\).

5. Log–antilog multiplier (type O-03)

Logs turn a product into a sum: \(\ln X_1 + \ln X_2 = \ln X_1X_2\). Chain: two log amps, an inverting summer, an antilog amp, an inverter.

Method · design \(V_o = k\,X_1X_2\)

  1. Log amps (input resistor \(R_{in}\), diode in feedback): \(V_{1}' = -V_T\ln\dfrac{X_1}{I_SR_{in}}\), \(V_{2}' = -V_T\ln\dfrac{X_2}{I_SR_{in}}\).
  2. Unity inverting summer (equal R): \(V_s = +V_T\ln\dfrac{X_1X_2}{(I_SR_{in})^2}\).
  3. Antilog (diode in, \(R_{out}\) feedback): \(V_a = -R_{out}I_S\,e^{V_s/V_T} = -\dfrac{R_{out}}{I_SR_{in}^2}X_1X_2\).
  4. Choose \(R_{in}\), then \(R_{out} = k\,I_SR_{in}^2\). Unity inverter for the sign.
  5. Variants: squarer = one log amp + an inverting amplifier of gain 2 (\(2\ln X = \ln X^2\)); divider = subtract the logs (difference amplifier).

All diodes must match (same \(I_S\), \(\eta\), temperature), and \(X_1, X_2 > 0\): this is a one-quadrant multiplier. A bipolar signal (a sine) needs a DC offset first, removed afterwards.

6. Frequency doubler and \(\sin^2\)

Doubling a frequency is trigonometry, then op-amp blocks:

\[ \sin^2\theta = \tfrac12 - \tfrac12\cos2\theta, \qquad 2\sin\theta\cos\theta = \sin2\theta \]
  • 90° shift: a differentiator with \(RC = 1/\omega\) turns \(\sin\omega t\) into \(-\cos\omega t\) exactly. An integrator turns \(\cos\omega t\) into \(\frac{1}{\omega RC}\sin\omega t\) exactly (because \(\sin 0 = 0\)), but turns \(\sin\omega t\) into \(\frac{\cos\omega t - 1}{\omega RC}\): a DC error unless pre-charged.
  • DC removal: subtract a constant with a summer fed from a rail, or block it with a series capacitor.
  • Squaring a sine with a diode multiplier needs a positive offset first (log of a negative number does not exist).

Traps (where marks go)

  • Diode at the input is the antilog, diode in the feedback is the log. (Even the bank's solution first calls 2019–20's circuit a log amp.)
  • Sign: both are inverting; the log amp needs \(v_I > 0\).
  • Using \(V_{GS}\) root with \(V_{GS} < V_t\); forgetting the saturation check when the drain has a resistor (2017–18: the stated saturation is actually false).
  • Mixing \(K\) and \(\tfrac12k_n'W/L\): write which one you use.
  • Multiplier: \(R_{out} = kI_SR_{in}^2\) (units V·Ω/V); forgetting the final inverter.
  • Generating cos from sin with an uncharged integrator (DC error); feeding a bipolar sine into a diode log amp.

Exam questions

2021–22 · Sec A · Q1(a) · 20 marks

You have two sources, \(v_1 = \sin(100t)\) V and \(v_2 = 1\) V. Design a circuit using op-amps that produces \(v_o = \sin^2(50t)\) V, and show that it does.

Show worked answer

Identity: \(\sin^2(50t) = \tfrac12 - \tfrac12\cos(100t)\). So we need \(\cos100t\) from \(\sin100t\), then half of \((1 - \cos100t)\).

Stage 1, differentiator on \(v_1\): C = 1 µF in series, R = 10 kΩ feedback, \(RC\) = 0.01 s: \(v_A = -RC\dfrac{d}{dt}\sin100t = -0.01\times100\cos100t = -\cos100t\).

Stage 2, non-inverting averager: \(v_A\) and \(v_2\) each through 10 kΩ to the + input; op-amp as a follower (output tied to −). \(v_+ = \dfrac{v_A + v_2}{2}\), so \(v_o = \dfrac{1 - \cos100t}{2} = \sin^2(50t)\) ✓.

Show it works: at \(t = 0\), \(v_A = -1\), \(v_o = 0 = \sin^2 0\) ✓; at \(50t = \pi/2\), \(\cos100t = -1\), \(v_o = 1\) ✓. Note: using an integrator to make the cosine (as the bank's solution does) gives \(v_A = \tfrac12(\cos100t - 1)\) from an uncharged capacitor and the output comes out 0.5 V too high.

2019–20 · Sec B · Q6(a) · 17 marks (exam held Jan 2021)

Deduce the equation for the output voltage \(V_0\) in the circuit (diode from \(V_i\) to the inverting input, anode at \(V_i\); \(R_F\) from the inverting input to the output; + input grounded). Explain the function of the circuit.

Show worked answer

Virtual ground: \(v_- = 0\), so the diode voltage is \(V_i\) and \(I_D = I_S e^{V_i/\eta V_T}\) (\(V_i > 0\), \(V_i \gg V_T\)).

No current enters the op-amp, so \(I_D\) flows through \(R_F\): \(\dfrac{0 - V_0}{R_F} = I_S e^{V_i/\eta V_T}\), so \(\boxed{V_0 = -R_FI_S\,e^{V_i/\eta V_T}}\).

Function: an antilog (exponential) amplifier: the output is proportional to the exponential of the input, inverted. Used with log amps to multiply, divide and raise to powers. Limits: only positive \(V_i\); temperature-dependent through \(I_S\) and \(V_T\); \(|V_0|\) must stay inside the rails. (The question index labels this a log amplifier; with the diode at the input it is the antilog.)

2017–18 · Sec B · Q5(a) · 10 marks

Find \(V_0\) in Figure 3: 2 V source through 1 kΩ to the inverting input; feedback path 1 kΩ from the inverting input to the drain of an NMOS whose gate is grounded and source is the output. The MOSFET is in saturation with \(k_n'(W/L)\) = 1 mA/V² and \(V_t\) = 0.7 V. Ideal op-amp, ±15 V.

Show worked answer

Virtual ground: \(I = 2/1 = 2\) mA, flowing from the − input through 1 kΩ into the drain.

Saturation: \(2 = \tfrac12(1)(V_{GS} - 0.7)^2 \Rightarrow V_{OV} = 2\) V, \(V_{GS} = 2.7\) V (the root with \(V_{GS} > V_t\)).

Gate at 0 V: \(V_S = -2.7\) V, so \(\boxed{V_0 = -2.7\text{ V}}\) (within ±15 V).

Check (worth writing): \(V_D = 0 - 2\times1 = -2\) V, \(V_{DS} = -2 - (-2.7) = 0.7\) V \(< V_{OV}\) = 2 V, so the device is really in triode. The examiner states saturation, so −2.7 V is the expected answer; the self-consistent triode solution is \(V_0 = -3.09\) V (\(V_{OV}\) = 2.39 V, \(V_{DS}\) = 1.09 V), which is what the simulator link on Figure 3 shows.

2015–16 · Sec B · Q6(a) · 26⅔ marks

You have \(V_{in}(t) = \sin(4000\pi t)\) V. Design a frequency-multiplier circuit using op-amps that doubles the input frequency to give \(V_{out}(t) = \sin(8000\pi t)\) V. Use resistors, capacitors, inductors and diodes (\(I_S = 10^{-6}\) A) as needed. Show the calculations and specify all design values.

Show worked answer

Let \(\omega = 4000\pi\). Plan: shift the sine positive, square it with log–antilog, subtract the unwanted terms to leave \(-\cos2\omega t\), then integrate to get \(\sin2\omega t\). Op-amps ±15 V, \(V_T\) = 25 mV.

1. Level shift (inverting summer, \(R_f\) = 10 kΩ): \(V_{in}\) through 10 kΩ and the −15 V rail through 75 kΩ: \(V_x = -[V_{in} + \tfrac{10}{75}(-15)] = 2 - \sin\omega t\), always between 1 and 3 V (positive, so the log amp works).

2. Squarer: log amp (\(R_{in}\) = 100 kΩ, diode feedback): \(-V_T\ln\dfrac{V_x}{I_SR_{in}}\) (diode current 10–30 µA). Inverting amplifier of gain 2 (10 kΩ / 20 kΩ): \(+V_T\ln\dfrac{V_x^2}{(I_SR_{in})^2}\). Antilog (diode in, \(R_{out}\) feedback): \(S = -\dfrac{R_{out}}{I_SR_{in}^2}V_x^2\). With \(R_{out} = I_SR_{in}^2 = 10^{-6}\times10^{10} = 10\) kΩ: \(S = -V_x^2\).

3. Remove the extra terms. \(V_x^2 = 4 - 4\sin\omega t + \sin^2\omega t = 4.5 - 4\sin\omega t - \tfrac12\cos2\omega t\). Using \(-4\sin\omega t = 4V_x - 8\): \(-\cos2\omega t = -[\,2S + 8V_x - 7\,]\). Inverting summer with \(R_f\) = 20 kΩ: from \(S\) 10 kΩ, from \(V_x\) 2.5 kΩ, from the −15 V rail \(20\times15/7 = 42.9\) kΩ. Output \(-\cos2\omega t\).

4. 90° shift: integrator with \(RC = 1/(2\omega) = 1/(8000\pi) = 39.8\) µs (C = 10 nF, R = 3.98 kΩ): \(-\dfrac{1}{RC}\displaystyle\int_0^t(-\cos2\omega t)\,dt = \dfrac{\sin2\omega t}{2\omega RC} = \sin(8000\pi t)\) ✓. No DC error because \(\sin0 = 0\).

Six op-amps; checked numerically (error below \(10^{-13}\) V). No inductor is needed. Alternative (the bank's): make \(\cos\omega t\) with a 90° shifter and multiply \(2\sin\omega t\cos\omega t\) with a log–antilog multiplier. It needs offsets on both inputs, because sin and cos go negative, and the bank's version omits them.

2015–16 · Sec B · Q5(a) · 20⅔ marks

(i) Find \(V_{out}\) as a function of \(V_{in}\) for the circuit: \(V_{in}\) through R to the inverting input; NMOS M1 with drain at the inverting input, gate grounded, source at the output; + input grounded; ±15 V. (ii) Using this, realise \(V_{out} = 3V_{in}^2\); extra op-amps and a DC source are allowed. \(V_{TH}\) = 0.5 V.

Show worked answer

(i) \(I_D = V_{in}/R\) (\(V_{in} > 0\)). \(V_G = V_D = 0\), so \(V_{GD} = 0 < V_t\): always saturated. \(V_{GS} = -V_{out}\): \(\dfrac{V_{in}}{R} = K(-V_{out} - 0.5)^2\), so \(\boxed{V_{out} = -0.5 - \sqrt{\dfrac{V_{in}}{KR}}}\), a square-root amplifier (\(K = \tfrac12k_n'W/L\)).

(ii) Squaring is the inverse of a square root, so move the MOSFET to the input: OA1 inverter (10 kΩ/10 kΩ) gives \(-V_{in}\). M1: source at \(-V_{in}\), gate at a 0.5 V DC source, drain at OA2's virtual ground; \(R_f\) from OA2's output to its − input. \(V_{GS} = 0.5 + V_{in}\), \(V_{OV} = V_{in}\), \(I_D = KV_{in}^2\) drawn out of the node, so \(V_{out} = +KR_fV_{in}^2\).

\(K\) is not given: assume \(K\) = 1 mA/V², then \(R_f\) = 3 kΩ gives \(V_{out} = 3V_{in}^2\) (V, mA, kΩ). M1 sits at the edge of saturation (\(V_{DS} = V_{in} = V_{OV}\)); valid for \(V_{in} \ge 0\).

2014–15 · Sec B · Q6(b) · 26⅔ marks

Design a circuit that gives \(V_o = 10\,X_1X_2\) using diodes with \(I_S = 10^{-6}\) A. Specify all resistor values.

Show worked answer

Log amps (\(R_{in}\) = 100 kΩ, diode feedback): \(I_SR_{in} = 0.1\) V, so outputs \(-V_T\ln(10X_1)\) and \(-V_T\ln(10X_2)\).

Inverting summer (all 10 kΩ): \(+V_T\ln(100X_1X_2)\).

Antilog (diode in, \(R_{out}\) feedback): \(-R_{out}I_S\times100X_1X_2 = -10^{-4}R_{out}X_1X_2\). \(R_{out} = kI_SR_{in}^2 = 10\times10^{-6}\times(10^5)^2 = 100\) kΩ gives \(-10X_1X_2\).

Inverter (10 kΩ/10 kΩ): \(V_o = +10X_1X_2\) ✓. Five op-amps; requires \(X_1, X_2 > 0\) and matched diodes at the same temperature (\(V_T\) cancels).

Key terms

Quick check

Summary: virtual ground fixes the current; the feedback device decides \(v_O\). Log amp (diode in feedback): \(v_O = -\eta V_T\ln(v_I/RI_S)\). Antilog (diode at input): \(v_O = -RI_Se^{v_I/\eta V_T}\). MOSFET in feedback: \(v_O = -V_t - \sqrt{v_I/KR}\) (check saturation); MOSFET at the input with gate at \(V_t\): \(v_O = KR_fv_I^2\). Multiplier: log, log, sum, antilog, invert, with \(R_{out} = kI_SR_{in}^2\). Frequency doubling: trig identity, 90° shift with \(RC = 1/\omega\), watch DC errors and positive-only inputs.
