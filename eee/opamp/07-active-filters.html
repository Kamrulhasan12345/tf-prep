Active Filters

Filter analysis and design came in every paper from 2011–12 to 2017–18 (about 180 marks in all) and not once since 2018–19; the class notes only sketch them. Do this chapter after the high-priority ones. Everything reduces to two first-order sections and one rule: replace C by \(1/(sC)\) and use \(H = -Z_f/Z_{in}\).

1. First-order sections

FilterCircuit (inverting)\(H(s)\)Gain, cutoff
Low-pass\(R_1\) in; \(R_f \parallel C_f\) feedback\(-\dfrac{R_f/R_1}{1 + sR_fC_f}\)\(|A| = R_f/R_1\), \(f_c = \dfrac{1}{2\pi R_fC_f}\)
High-pass\(C_1\) in series with \(R_1\); \(R_f\) feedback\(-\dfrac{R_f}{R_1}\cdot\dfrac{sR_1C_1}{1 + sR_1C_1}\)\(|A| = R_f/R_1\), \(f_c = \dfrac{1}{2\pi R_1C_1}\)
Band-pass (one op-amp)\(R_1\)–\(C_1\) in series in; \(R_2 \parallel C_2\) feedback\(-\dfrac{sR_2C_1}{(1 + sR_1C_1)(1 + sR_2C_2)}\)\(\omega_L = \frac{1}{R_1C_1}\), \(\omega_H = \frac{1}{R_2C_2}\) (needs \(R_1C_1 > R_2C_2\)); mid-band gain \(-R_2/R_1\)

A first-order section rolls off at −20 dB/decade = −6 dB/octave: for \(f \gg f_c\), \(|H| \propto 1/f\), so ×10 in f costs 20 dB and ×2 costs \(20\log2 = 6.02\) dB. At \(f_c\): −3 dB and ∓45°.

Method · analyse a filter circuit (O-08)

  1. Replace every C by \(1/(sC)\); write \(H = -Z_f/Z_{in}\) (or KCL at each virtual ground for several op-amps).
  2. Bring \(H(s)\) to a standard form. Type from the limits: \(s \to 0\) and \(s \to \infty\). Order = degree of the denominator.
  3. \(f_c = \omega_c/2\pi\). To ask "does a signal at f pass?", evaluate \(|H(j2\pi f)|\).
  4. Check the pole: a pole in the right half-plane means positive feedback (unstable).

Method · design (O-09)

  1. LPF: choose \(C_f\) so that \(R_f = \dfrac{1}{2\pi f_cC_f}\) is between 1 kΩ and 1 MΩ; then \(R_1 = R_f/|A|\).
  2. HPF: choose \(C_1\), \(R_1 = \dfrac{1}{2\pi f_cC_1}\), \(R_f = |A|R_1\).
  3. Wide band-pass (\(f_H/f_L \ge 10\)): HPF(\(f_L\)) cascaded with LPF(\(f_H\)); gains multiply.
  4. Band-stop: LPF(\(f_L\)) and HPF(\(f_H\)) in parallel into a summer; narrow notch: input minus a band-pass.
  5. −40 dB/dec with one op-amp: unity-gain Sallen–Key, \(R_1 = R_2 = R\), \(C_1\) (feedback) \(= 2C_2\) (to ground), \(R = \dfrac{1}{2\pi f_c\sqrt{C_1C_2}}\) (Butterworth, Q = 0.707).
  6. State the op-amp requirement: gain–bandwidth ≥ gain × \(f_c\).

Traps

  • ω vs f: \(\sin(1000\pi t)\) is 500 Hz, not 1000 Hz.
  • In a cascade the stages interact: a 20 k–200 kHz HPF+LPF has true −3 dB points of 16.9 kHz and 237 kHz (fine to ignore when \(f_H/f_L \ge 10\), but say so).
  • "40 dB" is ambiguous (−40 dB/dec slope, or 40 dB gain): give the one you assume and mention the other.
  • Band-pass from one op-amp needs \(R_1C_1 > R_2C_2\), otherwise the corner frequencies are swapped.

Exam questions

2017–18 · Sec B · Q6(b) · 10⅔ marks

Design a second-order band-pass filter with \(f_{CL}\) = 20 kHz and \(f_{CH}\) = 200 kHz.

Show worked answer

\(f_H/f_L = 10\): cascade a first-order HPF (20 kHz) and a first-order LPF (200 kHz), unity gain each.

HPF: \(C_1\) = 1 nF, \(R_1 = \dfrac{1}{2\pi\times20\text{k}\times1\text{n}} = 7.96\) kΩ, \(R_{f1}\) = 7.96 kΩ. LPF: \(C_2\) = 100 pF, \(R_{f2} = \dfrac{1}{2\pi\times200\text{k}\times100\text{p}} = 7.96\) kΩ, \(R_2\) = 7.96 kΩ. Overall gain +1 (two inversions). (The interaction moves the true −3 dB points to 16.9 kHz and 237 kHz, with mid-band gain 0.909.)

2017–18 · Sec B · Q6(a) · 18 marks  |  also 2016–17 Sec A Q2(a) (20 marks)

For the op-amp circuit with \(R_1\) and \(C_1\) in series at the input and \(R_2 \parallel C_2\) in the feedback path, determine the type of filter by computing the transfer function.

Show worked answer

\(Z_{in} = R_1 + \frac{1}{sC_1} = \frac{1 + sR_1C_1}{sC_1}\), \(Z_f = \frac{R_2}{1 + sR_2C_2}\). \(H = -\frac{Z_f}{Z_{in}} = -\dfrac{sR_2C_1}{(1 + sR_1C_1)(1 + sR_2C_2)}\).

\(s \to 0\): \(H \to 0\); \(s \to \infty\): \(H \to 0\); in between (for \(R_1C_1 > R_2C_2\)) \(|H| \approx R_2/R_1\). So it is a band-pass filter, second order, with \(\omega_L = 1/(R_1C_1)\), \(\omega_H = 1/(R_2C_2)\), mid-band gain \(-R_2/R_1\).

2016–17 · Sec A · Q1(a) · 21⅔ marks

A non-inverting amplifier (\(R_1\) to ground, \(R_2\) feedback) has its + input fed from \(V_{in}\) through \(R_{in}\), with \(C_{in}\) from the + input to ground and a capacitor C from the + input to the output. Find the differential equation the circuit solves (i) without C and (ii) with C. For what C does it become a plain non-inverting amplifier?

Show worked answer

Let \(A = 1 + R_2/R_1\), so \(v_+ = V_{out}/A\). KCL at the + node: \(\frac{V_{in} - v_+}{R_{in}} = C_{in}\dot v_+ + C(\dot v_+ - \dot V_{out})\).

(i) C = 0: \(A\,V_{in} = V_{out} + R_{in}C_{in}\,\dot V_{out}\) (first-order low-pass, DC gain A).

(ii) \(A\,V_{in} = V_{out} + R_{in}[C_{in} + C(1 - A)]\,\dot V_{out}\). The derivative term vanishes when \(C = \dfrac{C_{in}}{A - 1} = C_{in}\dfrac{R_1}{R_2}\), leaving \(V_{out} = A\,V_{in}\).

2015–16 · Sec B · Q8(a) · 23⅔ marks

Op-amp 1 is an inverting summer: \(V_{in}\) enters through a capacitor C and a 2R resistor in series, and the output \(v_o\) is fed back through 5R; its output drives op-amp 2, an inverting integrator (R in, 2C feedback) whose output is \(v_o\). (i) Find H(s), the type, order and cutoff. (ii) With R = 10 kΩ and C = 0.1 µF, can a 100 Hz signal pass without distortion?

Show worked answer

KCL at op-amp 1's virtual ground with op-amp 2 giving \(x = -2sRC\,v_o\): it reduces to \(sC\,V_{in} - sC\,v_o + v_o/(5R) = 0\), so \(H(s) = \dfrac{s}{s - 1/(5RC)}\).

First order, high-pass form, \(|\text{pole}| = 1/(5RC) = 200\) rad/s, \(f_c = 1/(10\pi RC) = 31.8\) Hz. (ii) At 100 Hz, \(|H| = \frac{628}{\sqrt{628^2 + 200^2}} = 0.95\): it would pass. But the pole is in the right half-plane (two inversions and the 5R path give positive feedback), so as drawn the circuit is unstable and saturates; state both the intended high-pass answer and this remark.

2015–16 · Sec B · Q8(b) · 23 marks

\(v_{in} = 5 + 3\cos(300\pi t - 30°) + 8\sin(1000\pi t) + 7\sin(1600\pi t + 45°)\). Design Filter 1 and Filter 2 (in parallel) and a summing amplifier to obtain \(V_{out} = 7 + 12\sin(1000\pi t)\).

Show worked answer

Components at 0, 150, 500 and 800 Hz. Keep DC (×1.4) and 500 Hz (×1.5).

Filter 1: inverting LPF, gain 1.4, \(f_c\) ≈ 11 Hz (far below 150 Hz): \(R_i\) = 10 kΩ, \(R_f\) = 14 kΩ ∥ \(C_f\) = 1 µF (\(f_c\) = 11.4 Hz). Filter 2: inverting band-pass at 500 Hz, gain 1.5, e.g. multiple-feedback with C = 0.1 µF, Q = 5: \(R_3\) = 31.8 kΩ, \(R_1\) = 10.6 kΩ, \(R_2\) = 328 Ω. Summer: inverting, unity (all 10 kΩ), so the two inversions cancel. Remark: 800 Hz is less than an octave from 500 Hz, so a Q = 5 band-pass still leaks some of it; a higher Q or a second stage improves rejection.

2014–15 · Sec B · Q7(a) · 20 marks

Write the magnitude response of a −20 dB/decade low-pass filter. Why is it called −20 dB/decade? Can it also be called −6 dB/octave?

Show worked answer

\(|H(f)| = \dfrac{A_0}{\sqrt{1 + (f/f_c)^2}}\); in dB, \(20\log A_0 - 10\log(1 + (f/f_c)^2)\). For \(f \gg f_c\), \(|H| \approx A_0f_c/f\): ten times the frequency gives one tenth the gain, −20 dB. Doubling f gives \(-20\log2 = -6.02\) dB, so yes, −6 dB/octave. At \(f_c\): −3 dB, phase −45°.

2014–15 · Sec B · Q7(b) · 20 marks

Design a notch filter that eliminates 8–12 kHz. Give all values.

Show worked answer

Notch = input − band-pass. Band-pass (multiple feedback, \(A_0 = -1\)): \(f_0 = \sqrt{8\times12} = 9.80\) kHz, BW = 4 kHz, \(C_1 = C_2\) = 1 nF: \(R_3 = \frac{1}{\pi\,BW\,C} = 79.6\) kΩ, \(R_1 = R_3/(2|A_0|) = 39.8\) kΩ, \(\frac{1}{R_2} = 4\pi^2f_0^2C^2R_3 - \frac{1}{R_1}\) → \(R_2\) = 3.62 kΩ. Then an inverting summer adds \(v_{in}\) and the band-pass output (all 10 kΩ): zero at 9.80 kHz, −3 dB at 8 and 12 kHz. (Alternative: LPF at 8 kHz in parallel with HPF at 12 kHz, summed.)

2013–14 · Sec B · Q7(b) · 15 marks

Design a "40 dB" low-pass filter with \(f_c\) = 1 kHz using only one op-amp.

Show worked answer

Reading −40 dB/decade: unity-gain Sallen–Key Butterworth, \(C_2\) = 10 nF (to ground), \(C_1\) = 20 nF (feedback), \(R = \frac{1}{2\pi\cdot1000\sqrt{20\text{n}\times10\text{n}}} = 11.25\) kΩ for both resistors. Reading 40 dB gain: first-order inverting LPF with \(C_f\) = 10 nF, \(R_f\) = 15.9 kΩ, \(R_1\) = 159 Ω (|A| = 100).

2013–14 · Sec B · Q6(b) · 15 marks

A system blocks 20 Hz and 20 kHz but passes 10 kHz. Draw its frequency response and its block diagram.

Show worked answer

A band-pass with 20 Hz < \(f_L\) < 10 kHz and 10 kHz < \(f_H\) < 20 kHz: block diagram HPF(\(f_L\)) → LPF(\(f_H\)); response flat around 10 kHz, −3 dB at \(f_L\) and \(f_H\), −20 dB/dec per order outside.

2011–12 · Sec A · Q2(a) · 16 marks

Draw a −20 dB/dec low-pass filter and write its design procedure. Design one with a cutoff of 100 kHz.

Show worked answer

Figure 1. Procedure: choose \(C_f\); \(R_f = 1/(2\pi f_cC_f)\); \(R_1 = R_f/|A|\). With \(C_f\) = 100 pF: \(R_f = \frac{1}{2\pi\times10^5\times10^{-10}} = 15.9\) kΩ; unity gain → \(R_1\) = 15.9 kΩ. The op-amp needs GBW ≥ 100 kHz × gain.

Practice

Quick check

Summary: LPF: \(R_f\parallel C_f\) feedback, \(f_c = 1/(2\pi R_fC_f)\); HPF: series \(C_1R_1\) input, \(f_c = 1/(2\pi R_1C_1)\); gain \(R_f/R_1\); band-pass = HPF + LPF; −20 dB/dec = −6 dB/oct; analyse with \(H = -Z_f/Z_{in}\) and read the type from the limits.
