The Ideal Op-Amp; Inverting and Non-Inverting Amplifiers

Every op-amp question starts here. A network-analysis question (find \(v_o\), node voltages, branch currents) appeared in 2014–15, 2018–19, 2020–21 and 2023–24 (16⅔ to 23⅓ marks; the 2023–24 one is the T-network, 17 marks). The theory parts (ideal properties, why \(v_d \approx 0\), gain with finite \(A\)) appeared in 2011–12, 2012–13 (twice), 2013–14 and 2023–24. Two rules and one KCL equation solve all of them.

1. The ideal op-amp

An op-amp amplifies the difference between its two inputs: \(v_o = A(v_+ - v_-) = A\,v_d\), where \(A\) is the open-loop gain (the op-amp alone, no external parts). The output cannot go beyond the supply: it saturates at \(\pm L\), close to the rails (BUET papers take \(L\) = |supply|).

Open-loop gain \(A\)
Ideal ∞; real \(10^5\) to \(10^8\) (741: \(2\times10^5\)).
Input resistance \(R_i\)
Ideal ∞, so no current flows into either input. Real \(10^5\) to \(10^{13}\) Ω.
Output resistance \(R_o\)
Ideal 0, so the output is a perfect voltage source. Real 10 to 100 Ω.
Others (ideal)
Infinite bandwidth and slew rate, infinite CMRR (common-mode gain 0), zero offset voltage and bias currents, no drift.
Closed-loop gain
The gain of the whole circuit, \(v_o/v_i\), set by the external resistors. Sadat sir's note: "open-loop gain of the op-amp; closed-loop gain of the circuit".

Why \(v_d = 0\) with negative feedback (the graphical answer, 2012–13)

Draw the transfer characteristic \(v_o\) versus \(v_d\): a steep line of slope \(A\) through the origin, flat at \(+L\) and \(-L\). The linear strip is only \(\pm L/A\) wide: with \(L\) = 13 V and \(A = 2\times10^5\) it is \(\pm 65\) µV. Negative feedback holds the op-amp inside that strip (if \(v_o\) rises, the feedback raises \(v_-\), which pulls \(v_o\) back). Any finite output therefore needs only microvolts at the input, negligible next to signal volts, so we write \(v_d \approx 0\): the virtual short. If \(v_+\) is grounded, \(v_-\) is a virtual ground. Without negative feedback (comparator, Schmitt trigger) the op-amp sits on a flat part and \(v_d \ne 0\).

\[ \text{Golden rules (negative feedback, ideal op-amp):}\qquad v_+ = v_-, \qquad i_+ = i_- = 0 \]

2. Inverting and non-inverting amplifiers

Inverting (derivation as written in an exam). \(v_+ = 0\), so \(v_- = 0\) (virtual ground). No current enters the op-amp, so the current in \(R_1\) all flows through \(R_2\):

\[ \frac{v_I - 0}{R_1} = \frac{0 - v_O}{R_2} \;\Rightarrow\; \frac{v_O}{v_I} = -\frac{R_2}{R_1}, \qquad R_{in} = R_1 \]

Non-inverting. \(v_- = v_+ = v_I\). KCL at \(v_-\): \(\dfrac{0 - v_I}{R_1} = \dfrac{v_I - v_O}{R_2}\), so

\[ \frac{v_O}{v_I} = 1 + \frac{R_2}{R_1}, \qquad R_{in} = \infty \]

Voltage follower (\(R_2 = 0\) or \(R_1 = \infty\)): output tied to \(v_-\), input to \(v_+\): \(v_O = v_I\). Used as a buffer: infinite input resistance, zero output resistance.

The op-amp output current is whatever the output node needs: \(i_O = i_{feedback} + i_{load}\). With no load in the inverting amplifier, \(i_O = -v_I/R_1\) (it sinks the input current).

3. Finite open-loop gain (derivation asked in 2012–13)

Keep \(i_- = 0\) but let \(A\) be finite. Then \(v_- = -v_O/A\) (not zero). KCL at \(v_-\):

\[ \frac{v_I + v_O/A}{R_1} = \frac{-v_O/A - v_O}{R_2} \;\Rightarrow\; G = \frac{v_O}{v_I} = \frac{-R_2/R_1}{1 + \dfrac{1 + R_2/R_1}{A}} \]

For the non-inverting amplifier the same steps give \(G = \dfrac{1 + R_2/R_1}{1 + (1 + R_2/R_1)/A}\). In both, \(1 + R_2/R_1\) is the noise gain; the gain error is about \(-(1 + R_2/R_1)/A\). To keep the error below \(\varepsilon\) you need \(A \gtrsim (1 + R_2/R_1)/\varepsilon\).

Method · gain with finite A

  1. Ideal gain: \(-R_2/R_1\) (inverting) or \(1 + R_2/R_1\) (non-inverting).
  2. Noise gain \(\beta^{-1} = 1 + R_2/R_1\) (same for both).
  3. \(G = G_{ideal}/(1 + \beta^{-1}/A)\).
  4. Percentage error \(= (G/G_{ideal} - 1)\times100\%\) (negative: the real gain is smaller).

Full non-ideal model: \(R_i\), \(R_o\) and \(A\) (Sadat L24 notes p.106 = Khairul s.5–6)

When \(R_i\) and \(R_o\) are given too, the virtual short is not allowed ("∵ non-ideal ∴ \(v_d = 0\) method won't work"). Replace the op-amp by Figure 1 and write node equations. Sadat sir's trick: the circuit is linear, so set \(v_o = 1\), find \(v_d\) from the output node, then find the \(v_s\) that produces it; the gain is \(1/v_s\).

4. Network analysis (type O-01)

Method · find vo, node voltages and currents

  1. Find every \(v_+\) first. Grounded: 0. Through a divider from sources: \(v_+ = \sum V_k \times\) (its divider ratio); no current enters \(+\), so the divider is unloaded.
  2. Virtual short: \(v_- = v_+\).
  3. KCL at \(v_-\): \(\sum_k \dfrac{V_k - v_-}{R_k} + \dfrac{v_o - v_-}{R_f} = 0\); solve for \(v_o\). Or superposition: each source alone, the others set to zero.
  4. Walk outward: once a node voltage is known, every resistor current follows from Ohm's law; KCL at each internal node gives the next current. State each current's direction.
  5. Cascades: solve stage by stage, left to right; an op-amp output is an ideal source, so the next stage does not load it.
  6. Rail check: if \(|v_o| > L\), the output is \(\pm L\) and the virtual short no longer holds.

The T-network (Sedra §2.2; 2020–21 and 2023–24)

A huge inverting gain normally needs a huge \(R_2\). The T-network gets it with ordinary resistors. Labels as in Sedra / 2020–21: \(R_2\) from \(v_-\) to node X, \(R_4\) from X to ground, \(R_3\) from X to the output.

Derivation. Virtual ground: \(i_1 = v_I/R_1\), and all of it flows through \(R_2\), so \(v_X = 0 - i_1R_2 = -\dfrac{R_2}{R_1}v_I\). Current down \(R_4\): \(i_4 = v_X/R_4\) (negative: it actually flows up from ground into X). KCL at X: \(i_3 = i_1 - i_4 = i_1\left(1 + \dfrac{R_2}{R_4}\right)\). Then \(v_O = v_X - i_3R_3\):

\[ A_v = \frac{v_O}{v_I} = -\frac{R_2 + R_3 + R_2R_3/R_4}{R_1} = -\frac{R_2}{R_1}\left(1 + \frac{R_3}{R_2} + \frac{R_3}{R_4}\right), \qquad A_i = \frac{i_3}{i_1} = 1 + \frac{R_2}{R_4} \]

\(A_i\) is the current the op-amp output sinks divided by the input current (no load).

Worked example: 2023–24 Sec B Q6(b)

Non-inverting input fed through a divider (2014–15)

Here \(v_+ \ne 0\). Find it first with the divider, then use superposition: \(v_o = v_+\left(1 + \dfrac{R_f}{R_1}\right) - V_a\dfrac{R_f}{R_1}\). If \(v_+\) and \(V_a\) are both non-zero, neither term alone is the answer.

Variants. Cascaded non-inverting stages (2018 CT: multiply the gains); several inputs on both sides (next chapter); cascaded summers with a sine input evaluated at a given \(t\) (2018–19, next chapter).

Traps (where marks go)

  • Assuming \(v_- = 0\) when \(v_+\) is driven through a divider (2014–15: \(v_+ = 4\) V).
  • Using the virtual short in a non-ideal problem: when \(A\), \(R_i\), \(R_o\) are given, write nodal equations with the model.
  • T-network labels differ between papers: 2020–21 (Sedra) has \(R_4\) to ground and \(R_3\) to the output; 2023–24 has \(R_3\) to ground and \(R_4\) to the output. Read the figure, not the formula.
  • Current directions: say "\(i_3\) = 5 mA from ground into X" rather than a bare signed number.
  • Rail check: 2023–24's T-network lands exactly on −15 V. Say that it is at the rail edge.
  • "Current gain" with no load means op-amp output current / input current.

Exam questions

2023–24 · Sec B · Q6(b) · 17 marks

For the circuit of the figure, find all the marked node voltages and branch currents. \(V_{in}\) = 5 V; all resistors 1 kΩ. \(R_1\) from \(V_{in}\) to the inverting input (current \(i_1\)); \(R_2\) from the inverting input to node X (\(i_2\)); \(R_3\) from X to ground (\(i_3\), drawn upward, from ground into X); \(R_4\) from X to the output (\(i_4\), drawn toward the output). Non-inverting input grounded.

Show worked answer

Ideal op-amp with negative feedback: \(v_+ = 0 \Rightarrow v_- = 0\) (virtual ground); no current into the op-amp. Units: V, kΩ, mA.

\(i_1 = \dfrac{5 - 0}{1} = 5\) mA. KCL at \(v_-\): \(i_2 = i_1 = 5\) mA (flows from \(v_-\) toward X).

\(V_X = v_- - i_2R_2 = 0 - 5\times1 = -5\) V.

\(i_3 = \dfrac{0 - V_X}{R_3} = \dfrac{0 - (-5)}{1} = 5\) mA, from ground up into X (positive in the marked direction).

KCL at X: \(i_4 = i_2 + i_3 = 5 + 5 = 10\) mA, from X to the output.

\(V_O = V_X - i_4R_4 = -5 - 10\times1 = -15\) V. Check with the formula (here the shunt resistor is \(R_3\)): \(A_v = -(R_2 + R_4 + R_2R_4/R_3)/R_1 = -3\), \(V_O = -15\) V ✓.

Rail remark: −15 V is exactly the edge of a ±15 V supply; with a real op-amp (saturating 1–2 V inside the rails) the output would clip. The op-amp output sinks \(i_4\) = 10 mA.

2023–24 · Sec B · Q8(a) · 15 marks (characteristics part; the VTC part is in Comparators)

Write down the characteristics of an ideal op-amp. Draw the voltage transfer characteristic of the circuit: \(V_{in}\) through \(R_1\) to the non-inverting input, \(R_2\) from the non-inverting input to the output, inverting input grounded.

Show worked answer

Characteristics: (1) infinite open-loop gain \(A\); (2) infinite input resistance, so \(i_+ = i_- = 0\); (3) zero output resistance; (4) infinite bandwidth and slew rate; (5) infinite CMRR (zero common-mode gain); (6) zero offset voltage, offset current and drift. With negative feedback these give \(v_+ = v_-\).

VTC: the feedback goes to \(+\): positive feedback, so the output sits at \(\pm L\) (no virtual short). By superposition \(v_+ = V_{in}\dfrac{R_2}{R_1+R_2} + v_o\dfrac{R_1}{R_1+R_2}\). The output flips when \(v_+\) crosses 0: from \(-L\) to \(+L\) at \(V_{TH} = L R_1/R_2\), from \(+L\) to \(-L\) at \(V_{TL} = -LR_1/R_2\). A non-inverting hysteresis loop (Schmitt trigger) of width \(2LR_1/R_2\).

2020–21 · Sec B · Q8(a) · 23⅓ marks

Determine the closed-loop voltage gain and current gain of the ideal op-amp network: \(R_1\) from \(v_I\) to the inverting input; \(R_2\) from the inverting input to X; \(R_4\) from X to ground; \(R_3\) from X to \(v_O\); non-inverting input grounded (Figure 3).

Show worked answer

Virtual ground at \(v_-\), \(i_- = 0\). Input current \(i_I = v_I/R_1\), and it flows through \(R_2\): \(i_2 = i_I\).

\(v_X = 0 - i_2R_2 = -\dfrac{R_2}{R_1}v_I\).

Current from X to ground in \(R_4\): \(i_4 = \dfrac{v_X}{R_4} = -\dfrac{R_2}{R_1R_4}v_I\).

KCL at X (into X = out of X): \(i_2 = i_4 + i_3\) where \(i_3\) flows X → \(v_O\): \(i_3 = i_I - i_4 = \dfrac{v_I}{R_1}\left(1 + \dfrac{R_2}{R_4}\right)\).

\(v_O = v_X - i_3R_3 = -\dfrac{R_2}{R_1}v_I - \dfrac{R_3}{R_1}\left(1 + \dfrac{R_2}{R_4}\right)v_I\).

\[ A_v = \frac{v_O}{v_I} = -\frac{R_2 + R_3 + R_2R_3/R_4}{R_1}. \]

Current gain: the op-amp output must sink \(i_3\) (no load), so \(A_i = \dfrac{i_3}{i_I} = 1 + \dfrac{R_2}{R_4}\).

Comment: with \(R_1 = R_2 = 1\) MΩ, \(R_4\) = 1 kΩ, \(R_3\) = 1 MΩ, \(A_v \approx -1002\) with no resistor above 1 MΩ, high gain and high input resistance together.

2014–15 · Sec B · Q5(a) · 16⅔ marks

What is the output voltage \(V_o\)? A 2 V source drives the inverting input through 2 kΩ, with 5 kΩ from the inverting input to the output. A 7 V source drives the non-inverting input through 3 kΩ, with 4 kΩ from the non-inverting input to ground. Ideal op-amp, ±15 V.

Show worked answer

No current into \(+\): unloaded divider, \(V_+ = 7\times\dfrac{4}{3+4} = 4\) V. Virtual short: \(V_- = 4\) V.

KCL at \(V_-\): \(\dfrac{2 - 4}{2} = \dfrac{4 - V_o}{5} \Rightarrow -1 = \dfrac{4 - V_o}{5} \Rightarrow V_o = 9\) V.

Superposition check: \(V_o = 4\left(1 + \dfrac{5}{2}\right) - 2\times\dfrac{5}{2} = 14 - 5 = 9\) V. Within ±15 V, so linear operation holds.

2013–14 · Sec B · Q7(c) · 5 marks  |  also 2011–12 Sec A Q2(b) (10 marks, "properties"), 2018 CT3(B) (6 marks)

What are the characteristics of an ideal op-amp?

Show worked answer
  • Open-loop gain \(A = \infty\).
  • Input resistance \(R_i = \infty\): \(i_+ = i_- = 0\).
  • Output resistance \(R_o = 0\): output voltage independent of load.
  • Infinite bandwidth (gain flat at all frequencies) and infinite slew rate.
  • CMRR = ∞: responds only to \(v_+ - v_-\).
  • Zero input offset voltage, zero bias and offset currents, no drift with temperature.

Consequence with negative feedback: \(v_+ = v_-\) (virtual short). Output limited to \(\pm L\) by the supplies. For 10 marks, add the equivalent circuit (Figure 1 with \(R_i = \infty\), \(R_o = 0\)) and the transfer characteristic.

2012–13 · Sec B · Q8(c) · 13⅔ marks

Derive the closed-loop gain of an inverting op-amp amplifier as a function of its open-loop gain \(A\), given that \(A\) is not infinite.

Show worked answer

Figure 2 (left). The op-amp still draws no input current, and \(v_O = A(v_+ - v_-) = -Av_-\), so \(v_- = -v_O/A\).

Current in \(R_1\): \(i_1 = \dfrac{v_I - v_-}{R_1} = \dfrac{v_I + v_O/A}{R_1}\). It all flows through \(R_2\): \(v_O = v_- - i_1R_2 = -\dfrac{v_O}{A} - \dfrac{R_2}{R_1}\left(v_I + \dfrac{v_O}{A}\right)\).

Collect \(v_O\): \(v_O\left[1 + \dfrac{1}{A}\left(1 + \dfrac{R_2}{R_1}\right)\right] = -\dfrac{R_2}{R_1}v_I\), so

\[ G = \frac{v_O}{v_I} = \frac{-R_2/R_1}{1 + (1 + R_2/R_1)/A}. \]

As \(A \to \infty\), \(G \to -R_2/R_1\). To keep \(G\) close to ideal, \(A \gg 1 + R_2/R_1\). Example: \(R_2/R_1 = 100\), \(A = 10^4\): \(G = -100/1.0101 = -99.0\), a 1 % error. The inverting input is no longer exactly 0: \(v_- = -v_O/A\).

2012–13 · Sec B · Q7(b) · 12 marks

Explain graphically why, in a closed-loop feedback op-amp circuit, the differential voltage \(E_d\) is taken as zero.

Show worked answer

Sketch \(v_o\) against \(E_d = v_+ - v_-\): a straight line through the origin of slope \(A\), clipped at \(+L\) and \(-L\). The linear region spans \(-L/A \le E_d \le L/A\).

Numbers: \(L \approx 13\) V, \(A \approx 2\times10^5\) give \(|E_d| \le 65\) µV. On a sketch with the \(E_d\) axis in volts the linear part is practically vertical, lying on the \(v_o\) axis.

With negative feedback the op-amp is held in the linear region (a rise in \(v_o\) feeds back to \(v_-\) and reduces \(E_d\)). So whatever finite output the circuit produces, \(E_d\) is at most tens of microvolts, negligible against the input signals. Hence \(E_d \approx 0\), i.e. \(v_+ \approx v_-\) (virtual short). It does not hold in open loop or with positive feedback, where the output saturates.

Class tests and assignment

2018 CT2(A) · 10 marks

Find \(v_0\) and \(i_0\). A 20 mV source drives the \(+\) input of op-amp 1, which has 12 kΩ from output to \(-\) and 3 kΩ from \(-\) to ground. Op-amp 1's output drives the \(+\) input of op-amp 2, which has 10 kΩ from output to \(-\) and 4 kΩ from \(-\) to ground. \(i_0\) is op-amp 2's output current.

Show worked answer

Stage 1 non-inverting: \(v_x = 20\text{ mV}\times(1 + 12/3) = 100\) mV. Stage 2: \(v_0 = 100\times(1 + 10/4) = 350\) mV.

No load, so op-amp 2's output current flows down its feedback chain (10 k + 4 k): \(i_0 = 0.35/14 = 0.025\) mA = 25 µA.

2022 CT3(A) · 10 marks

\(R_1\) from \(v_-\) to ground, \(R_2\) from \(v_-\) to \(v_o\); \(v_I\) through \(R_3\) to \(v_+\), \(R_4\) from \(v_+\) to ground. (a) Feedback type? (b) Inverting or non-inverting? (c) Derive \(v_o/v_I\) and draw the VTC.

Show worked answer

(a) Negative feedback (output returns to \(-\)), voltage-series type. (b) Non-inverting. (c) \(v_+ = v_I\dfrac{R_4}{R_3+R_4}\), \(v_o = v_+\left(1 + \dfrac{R_2}{R_1}\right)\), so \(\dfrac{v_o}{v_I} = \dfrac{R_4}{R_3+R_4}\left(1 + \dfrac{R_2}{R_1}\right)\). VTC: a straight line through the origin with that slope, flat at \(\pm L\) for \(|v_I| > L/\text{gain}\).

Assignment Q8 (EEE 263 assignment) · super-diode, gain 2

\(v_I\) drives the \(+\) input; the op-amp output \(v_A\) feeds a diode (anode at \(v_A\)) whose cathode is \(v_o\); \(R\) from \(v_o\) to \(v_-\), \(R\) from \(v_-\) to ground; \(R_L\) from \(v_o\) to ground. Rails ±12 V, diode 0.7 V. Find \(v_o\), \(v_-\), \(v_A\) over the range of \(v_I\).

Show worked answer

\(v_I \le 0\): the diode cannot pass current backwards, so the loop is open; the op-amp saturates at \(v_A = -12\) V, the diode is off, \(v_o = v_- = 0\).

\(v_I > 0\): the diode conducts and closes the loop: non-inverting gain \(1 + R/R = 2\): \(v_- = v_I\), \(v_o = 2v_I\), \(v_A = 2v_I + 0.7\).

Upper limit: \(v_A\) reaches +12 V when \(2v_I + 0.7 = 12\), \(v_I = 5.65\) V. Beyond that \(v_A = 12\) V, \(v_o = 11.3\) V, \(v_- = 5.65\) V (fixed; the virtual short is lost).

Quick check

Summary: with negative feedback an ideal op-amp obeys \(v_+ = v_-\) and \(i_\pm = 0\). Find \(v_+\) first, then KCL at \(v_-\), then walk outward with Ohm's law, and check the rails. Inverting \(-R_2/R_1\), non-inverting \(1 + R_2/R_1\), follower 1. Finite \(A\): divide by \(1 + (1 + R_2/R_1)/A\). T-network: \(-(R_2 + R_3 + R_2R_3/R_4)/R_1\), current gain \(1 + R_2/R_4\). With \(R_i\), \(R_o\) given, use the model and nodal analysis (set \(v_o\) = 1).
