Summers, the Difference Amplifier and the V-to-I Converter

Linear-combination questions come in three shapes: analyse a cascade of summers (2018–19, 20 marks), design a one-op-amp circuit for \(a v_1 - b v_2\) (2013–14, 2015–16, 2022–23; 14 to 15 marks), and the Howland voltage-to-current converter (2024–25, 18 marks, the newest type). All three are superposition plus the two golden rules from Chapter 1.

1. Inverting summer

Several inputs \(v_k\), each through \(R_k\), into the virtual-ground node; \(R_f\) from that node to the output. Each input current \(v_k/R_k\) is independent of the others (the node is held at 0 V), and their sum flows through \(R_f\):

\[ v_o = -\left(\frac{R_f}{R_1}v_1 + \frac{R_f}{R_2}v_2 + \frac{R_f}{R_3}v_3\right) \]

Both signs with two op-amps (Sedra Fig. 2.10, Khairul s.12, Sadat p.107): stage 1 sums \(v_1, v_2\) with feedback \(R_a\); its output enters stage 2 through \(R_b\) together with \(v_3\) through \(R_3\), feedback \(R_c\):

\[ v_o = \frac{R_a}{R_1}\frac{R_c}{R_b}v_1 + \frac{R_a}{R_2}\frac{R_c}{R_b}v_2 - \frac{R_c}{R_3}v_3 \]

Method · design a two-stage summer for vₒ = p v₁ + q v₂ − r v₃

  1. Pick \(R_a = R_b = R_3\) = 10 kΩ (any convenient value).
  2. Negative term: \(R_c/R_3 = r \Rightarrow R_c = r\,R_3\).
  3. Positive terms carry the stage-2 gain \(R_c/R_b = r\): \(R_1 = R_a r/p\), \(R_2 = R_a r/q\).
  4. Check by substituting back; check the largest output against the rails.

2. Non-inverting summer and the general formula

Inputs through \(R_1, R_2\) into the \(+\) node (nothing else on \(+\)); \(R_3\) from \(-\) to ground, \(R_4\) feedback. Superposition (Sadat p.107–108): with \(V_2\) off, \(v_+ = V_1R_2/(R_1+R_2)\), and so on:

\[ v_o = \left(1 + \frac{R_4}{R_3}\right)\frac{R_2V_1 + R_1V_2}{R_1 + R_2} \]

Each input is weighted by the conductance of its own resistor (a smaller resistor gives a larger weight).

General case (Khairul s.14): inputs on both sides. Let \(R_N\) = parallel of everything at the \(-\) node except \(R_F\), and \(R_P\) = parallel of everything at the \(+\) node (including any resistor to ground):

\[ v_O = -\sum_{-\text{ side}} \frac{R_F}{R_k}v_k + \left(1 + \frac{R_F}{R_N}\right)\sum_{+\text{ side}} \frac{R_P}{R_j}v_j \]

The factor \(1 + R_F/R_N\) (the noise gain) multiplies every \(+\)-side input. Grounded resistors at the \(-\) node raise it; that is the lever for single-op-amp designs below.

3. Difference amplifier

Derivation by superposition (Sadat p.103). \(v_1\) off: inverting amplifier, \(v_o' = -\dfrac{R_2}{R_1}v_2\). \(v_2\) off: divider then non-inverting amplifier, \(v_o'' = \dfrac{R_4}{R_3+R_4}\left(1 + \dfrac{R_2}{R_1}\right)v_1\). Add:

\[ v_o = \frac{R_4}{R_3+R_4}\left(1 + \frac{R_2}{R_1}\right)v_1 - \frac{R_2}{R_1}v_2 \;\;\xrightarrow{\;R_4/R_3 = R_2/R_1\;}\;\; v_o = \frac{R_2}{R_1}(v_1 - v_2) \]

With all four equal, \(v_o = v_1 - v_2\): the subtractor. If the ratios are mismatched, a common-mode input \(v_1 = v_2 = v_{cm}\) leaks through: \(A_{cm} = \dfrac{R_4R_1 - R_2R_3}{R_1(R_3+R_4)}\), so CMRR depends on resistor matching. Differential input resistance (with \(R_3 = R_1\)) is only \(2R_1\).

Instrumentation amplifier (idea). Put a non-inverting stage in front of each input (two op-amps sharing a resistor \(2R_1\) between their inverting inputs, feedback \(R_2\) each), then a difference amplifier \(R_3, R_4\). Input resistance is infinite and the gain \(\left(1 + \dfrac{R_2}{R_1}\right)\dfrac{R_4}{R_3}\) is set by one resistor (\(2R_1\)) without disturbing the matching.

4. One op-amp for vo = a v1 − b v2 (type O-04)

Method · single op-amp synthesis

  1. Negative term to the \(-\) input: \(v_2\) through \(R_1\), feedback \(R_f\) with \(R_f/R_1 = b\) (e.g. \(R_1\) = 10 kΩ, \(R_f = 10b\) kΩ).
  2. The positive term sees the noise gain \(1 + R_f/R_N\). With only \(R_1\) at the \(-\) node that is \(1 + b\).
  3. \(a < 1 + b\): attenuate \(v_1\) with a divider on \(+\): \(\dfrac{R_4}{R_3+R_4} = \dfrac{a}{1+b}\). (Pure difference \(a = b\): \(R_3 = R_1\), \(R_4 = R_f\).)
  4. \(a = 1 + b\): \(v_1\) straight to \(+\).
  5. \(a > 1 + b\): a divider can only reduce, so instead raise the noise gain: \(v_1\) straight to \(+\) and add \(R_x\) from \(-\) to ground: \(1 + b + R_f/R_x = a \Rightarrow R_x = \dfrac{R_f}{a - 1 - b}\).
  6. Check: \(v_1 = 1, v_2 = 0\) gives \(a\); \(v_1 = 0, v_2 = 1\) gives \(-b\) (the grounded \(R_x\) does not change the inverting gain).

Worked example: 2013–14 Sec B Q6(c), z = 5V₁ − 3V₂

5. Howland voltage-to-current converter (type O-10)

A difference amplifier whose \(+\) side is loaded: \(R_1\) from \(V_{in}\) to \(v_-\), \(R_2\) from \(v_-\) to \(V_{out}\); \(R_3\) from \(V_{out}\) to node L (= \(v_+\)), \(R_4\) and the load \(R_L\) from L to ground. Positive feedback through \(R_3\) and negative feedback through \(R_2\) balance so that the load current does not depend on \(R_L\).

Derivation. Inverting side (no input current): \(V_{out} = v_-\left(1 + \dfrac{R_2}{R_1}\right) - V_{in}\dfrac{R_2}{R_1}\), and \(v_- = v_+ = V_L\). KCL at L: \(\dfrac{V_{out} - V_L}{R_3} = \dfrac{V_L}{R_4} + i_L\). Substitute \(V_{out}\):

\[ i_L = -\frac{R_2}{R_1R_3}V_{in} + V_L\left(\frac{R_2}{R_1R_3} - \frac{1}{R_4}\right) \;\;\xrightarrow{\;R_2/R_1 = R_3/R_4\;}\;\; i_L = -\frac{R_2}{R_1R_3}V_{in} \]

With the bridge balanced the \(V_L\) term vanishes: \(i_L\) is set by \(V_{in}\) alone, whatever \(R_L\) is. Compliance: this holds only while \(|V_{out}| < L\). For \(R_1 = R_2\), \(R_3 = R_4\): \(V_{out} = 2V_L - V_{in} = -V_{in}(1 + 2R_L/R_3)\), so \(R_{L,max} = \dfrac{R_3}{2}\left(\dfrac{L}{|V_{in}|} - 1\right)\).

Method · Howland numbers

  1. \(V_{out} = V_L(1 + R_2/R_1) - V_{in}R_2/R_1\) (= \(2V_L - V_{in}\) when \(R_1 = R_2\)).
  2. KCL at L: \((V_{out} - V_L)/R_3 = V_L/R_4 + V_L/R_L\). Substitute, solve \(V_L\).
  3. \(i_L = V_L/R_L\); then \(V_{out}\).
  4. Rail check. If \(|V_{out}| > L\): \(V_{out} = \pm L\), the virtual short fails, and \(V_L = V_{out}\dfrac{R_4\parallel R_L}{R_3 + R_4\parallel R_L}\), \(i_L = V_L/R_L\).

Worked example: 2024–25 Sec A Q3(a)

Traps (where marks go)

  • Non-inverting gain is \(1 + R_f/R_N\) where \(R_N\) includes every grounded resistor at the \(-\) node, not \(R_f/R\).
  • A divider on \(+\) can only reduce: for \(5V_1 - 3V_2\) you need the extra \(R_x\) to ground (2013–14).
  • "Single op-amp" means no inverter stage: the sign of each term must come from which input it enters.
  • Cascades: stage 2 sees stage 1's output with its sign. In 2018–19 the intermediate node is −15 V; keep the minus sign.
  • \(\sin(100\pi \times 1) = 0\), not 1 (2018–19 at t = 1 s).
  • Howland: forgetting the current in \(R_4\) at node L; forgetting the compliance (rail) check.

Exam questions

2024–25 · Sec A · Q3(a) · 18 marks

The circuit functions as a voltage-to-current converter. The op-amp is biased with ±20 V and is linear while \(V_{out}\) is within the rails (\(V_1 = V_2\) valid). \(R_1 = R_2\) = 10 kΩ, \(R_3 = R_4\) = 1 kΩ, \(R_L\) = 100 Ω. Calculate \(i_L\) and \(V_{out}\) for \(V_{in}\) = −5 V.

Show worked answer

Units V, kΩ, mA. No current into the inputs. KCL at \(V_1\): \(\dfrac{V_{in} - V_1}{10} = \dfrac{V_1 - V_{out}}{10} \Rightarrow V_1 = \dfrac{V_{in} + V_{out}}{2}\), and \(V_1 = V_2\), so \(V_{out} = 2V_2 - V_{in}\).

KCL at \(V_2\): \(\dfrac{V_{out} - V_2}{1} = \dfrac{V_2}{1} + \dfrac{V_2}{0.1}\). Substitute: \(2V_2 - V_{in} - V_2 = 11V_2 \Rightarrow -V_{in} = 10V_2 \Rightarrow V_2 = -V_{in}/10 = 0.5\) V.

\(i_L = V_2/R_L = 0.5/0.1 = 5\) mA (downward through \(R_L\)).

\(V_{out} = 2(0.5) - (-5) = 6\) V, inside ±20 V, so the linear assumption holds.

Check with the balanced-bridge result (\(R_2/R_1 = R_3/R_4 = 1\)): \(i_L = -V_{in}R_2/(R_1R_3) = -(-5)/1 = 5\) mA, independent of \(R_L\). Compliance: \(V_{out} = 5(1 + 2R_L/1) \le 20 \Rightarrow R_L \le 1.5\) kΩ.

2022–23 · Sec B · Q8(b) · 15 marks

Suppose you have two inputs \(v_1\) and \(v_2\). Design a subtractor circuit using op-amps so that the output voltage is \(v_o = v_1 - v_2\).

Show worked answer

Circuit: Figure 3 with all four resistors equal, e.g. \(R_1 = R_2 = R_3 = R_4\) = 10 kΩ: \(v_2\) through \(R_1\) to \(-\), \(R_2\) from \(-\) to the output, \(v_1\) through \(R_3\) to \(+\), \(R_4\) from \(+\) to ground.

Proof (superposition). \(v_1 = 0\): inverting amplifier, \(v_o' = -\dfrac{R_2}{R_1}v_2 = -v_2\). \(v_2 = 0\): \(v_+ = v_1\dfrac{R_4}{R_3+R_4} = \dfrac{v_1}{2}\), non-inverting gain \(1 + R_2/R_1 = 2\), so \(v_o'' = v_1\).

Total \(v_o = v_1 - v_2\). General condition: \(R_4/R_3 = R_2/R_1\) gives \(v_o = (R_2/R_1)(v_1 - v_2)\); equal resistors give unity gain. Use 1 % (or matched) resistors: any mismatch gives a common-mode gain \(A_{cm} = (R_4R_1 - R_2R_3)/(R_1(R_3+R_4))\).

2018–19 · Sec B · Q5(a) · 20 marks

Find the expression of \(v_o\) in terms of the input voltages and resistances. Also calculate \(v_o\) at \(t\) = 1 s given \(v_1\) = 2 V, \(v_2\) = 5 V, \(v_3\) = 1 V and \(v_4 = 5\sin(100\pi t)\). Stage 1: \(v_1\) through 1 kΩ and \(v_2\) through 5 kΩ into the inverting node, 5 kΩ feedback, output \(x\). Stage 2: \(v_3\) through 500 Ω, \(x\) through 1 kΩ, \(v_4\) through 500 Ω into the inverting node, 1 kΩ feedback. Both \(+\) inputs grounded.

Show worked answer

Stage 1 (inverting summer): \(x = -\left(\dfrac{5}{1}v_1 + \dfrac{5}{5}v_2\right) = -(5v_1 + v_2)\).

Stage 2: \(v_o = -\left(\dfrac{1}{0.5}v_3 + \dfrac{1}{1}x + \dfrac{1}{0.5}v_4\right) = -(2v_3 + x + 2v_4)\).

Substitute: \(v_o = 5v_1 + v_2 - 2v_3 - 2v_4\). In terms of resistors: \(v_o = \dfrac{R_{f1}R_{f2}}{R_1R_x}v_1 + \dfrac{R_{f1}R_{f2}}{R_2R_x}v_2 - \dfrac{R_{f2}}{R_3}v_3 - \dfrac{R_{f2}}{R_4}v_4\).

At \(t\) = 1 s: \(v_4 = 5\sin(100\pi) = 0\). \(x = -(10 + 5) = -15\) V, \(v_o = -(2 - 15 + 0) = 13\) V.

Note: \(x = -15\) V is at the edge of a ±15 V supply (no rails are given; with ideal op-amps the answer is 13 V).

2015–16 · Sec B · Q5(b) · 14 marks

Design a circuit using a single op-amp that performs \(V_o = 3(V_1 - V_2)\), where \(V_1\) and \(V_2\) are input signals (AC or DC). Specify values of all resistors used.

Show worked answer

Difference amplifier (Figure 3) with \(R_2/R_1 = R_4/R_3 = 3\): \(R_1\) = 10 kΩ (\(V_2\) → \(-\)), \(R_2\) = 30 kΩ (\(-\) → output), \(R_3\) = 10 kΩ (\(V_1\) → \(+\)), \(R_4\) = 30 kΩ (\(+\) → ground).

Check: \(V_o = \dfrac{30}{40}\left(1 + \dfrac{30}{10}\right)V_1 - \dfrac{30}{10}V_2 = 0.75\times4\,V_1 - 3V_2 = 3(V_1 - V_2)\) ✓. Works for AC and DC since there are no capacitors.

2013–14 · Sec B · Q6(c) · 15 marks

Implement \(z = 5V_1 - 3V_2\) using only one op-amp, where \(V_1\) and \(V_2\) are input signals.

Show worked answer

\(-3V_2\): \(V_2\) through \(R_1\) = 10 kΩ to \(-\), \(R_f\) = 30 kΩ feedback.

\(+5V_1\): the noise gain with only \(R_1\) is \(1 + 3 = 4 < 5\), and a divider cannot amplify. So connect \(V_1\) directly to \(+\) and add \(R_x\) from \(-\) to ground: \(1 + \dfrac{30}{10} + \dfrac{30}{R_x} = 5 \Rightarrow R_x = 30\) kΩ.

Check: \(z = V_1\left(1 + \dfrac{30}{10\parallel30}\right) - \dfrac{30}{10}V_2 = V_1(1 + 4) - 3V_2 = 5V_1 - 3V_2\) ✓. Optional bias-current resistor in series with \(+\): \(R_1\parallel R_f\parallel R_x = 6\) kΩ.

Class tests and slide examples

2018 CT3(B) · 8 marks

Use the two-stage weighted summer (Figure 2) to obtain \(v_o = 2v_1 + v_2 - 3v_3\).

Show worked answer

\(v_o = \dfrac{R_a}{R_1}\dfrac{R_c}{R_b}v_1 + \dfrac{R_a}{R_2}\dfrac{R_c}{R_b}v_2 - \dfrac{R_c}{R_3}v_3\). Choose \(R_a = R_b = R_3\) = 10 kΩ.

\(R_c/R_3 = 3 \Rightarrow R_c\) = 30 kΩ, so \(R_c/R_b = 3\). Then \(3R_a/R_1 = 2 \Rightarrow R_1\) = 15 kΩ and \(3R_a/R_2 = 1 \Rightarrow R_2\) = 30 kΩ. Check: \(\tfrac{10}{15}\cdot3 = 2\), \(\tfrac{10}{30}\cdot3 = 1\), \(-3\) ✓.

Khairul s.16 · Alexander–Sadiku Practice Problem 5.10

\(v_1\) = 7 V into a follower (op-amp A); \(v_2\) = 3.1 V into an inverting amplifier with 10 kΩ input and 50 kΩ feedback (op-amp B). A's output through 20 kΩ and B's output through 30 kΩ enter an inverting summer with 60 kΩ feedback (op-amp C). Find \(v_o\).

Show worked answer

A: \(v_A = 7\) V. B: \(v_B = -5\times3.1 = -15.5\) V. C: \(v_o = -\left(\dfrac{60}{20}(7) + \dfrac{60}{30}(-15.5)\right) = -(21 - 31) = 10\) V. (In general \(v_o = -3v_1 + 10v_2\).)

Key terms

Quick check

Summary: inverting summer \(-\sum (R_f/R_k)v_k\); non-inverting side inputs are weighted by their divider and multiplied by the noise gain \(1 + R_f/R_N\). Difference amp \((R_2/R_1)(v_1 - v_2)\) when \(R_4/R_3 = R_2/R_1\). One op-amp for \(av_1 - bv_2\): \(R_f/R_1 = b\), then a divider if \(a < 1 + b\) or \(R_x = R_f/(a - 1 - b)\) if \(a > 1 + b\). Howland: balanced bridge gives \(i_L = -V_{in}R_2/(R_1R_3)\) independent of \(R_L\), valid while \(V_{out}\) stays inside the rails.
