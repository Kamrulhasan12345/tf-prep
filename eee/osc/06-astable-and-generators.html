Astable, Monostable and Square–Triangle Generators

A Schmitt trigger plus a timing element makes a waveform generator. Triangle/square generators came every year from 2018–19 to 2022–23 (16 to 27 marks), an op-amp one-shot in 2021–22, and the batch's assignment had an RL-timed astable. Every result here comes from two facts: a capacitor (or inductor) relaxes exponentially, and an integrator turns a constant into a ramp. Schmitt thresholds are in Chapter 5; the 555 versions are in Chapter 7. Not covered in the class notes this term (see exam strategy §9), but examined.

1. Three kinds of multivibrator

Bistable
Two stable states; stays in either until triggered. The Schmitt trigger.
Astable
No stable state (two quasi-stable states): switches back and forth by itself. A square-wave oscillator.
Monostable (one-shot)
One stable state. A trigger flips it into the quasi-stable state for a fixed time T, then it returns by itself.

The one formula every timing derivation uses (Khairul s.8): a capacitor charging through R toward \(V_\infty\) from \(V_{0^+}\):

\[ v(t) = V_\infty - (V_\infty - V_{0^+})\,e^{-t/\tau}, \quad \tau = RC \quad\Rightarrow\quad t = \tau\ln\frac{V_\infty - V_{0^+}}{V_\infty - v(t)} \]

2. The op-amp astable (type S-05)

Derivation (an exam answer). Let the output be \(L_+\). The + input sits at \(\beta L_+\). C charges from \(\beta L_-\) toward \(L_+\); when \(v_-\) reaches \(\beta L_+\) the op-amp flips to \(L_-\). Using the capacitor law with \(V_\infty = L_+\), \(V_{0^+} = \beta L_-\), \(v(T_1) = \beta L_+\):

\[ T_1 = \tau\ln\frac{L_+ - \beta L_-}{L_+ - \beta L_+} = \tau\ln\frac{1 - \beta(L_-/L_+)}{1-\beta}, \qquad T_2 = \tau\ln\frac{1 - \beta(L_+/L_-)}{1-\beta} \]

With symmetric levels \(L_- = -L_+\):

\[ T = 2\tau\ln\frac{1+\beta}{1-\beta}, \qquad f = \frac{1}{T} \]

Handy choices: \(\beta = 0.5\) gives \(T = 2\tau\ln3 = 2.197\,RC\); \(\beta = 0.462\) (\(R_2/R_1 = 1.164\)) gives \(T \approx 2RC\).

Method · astable analysis or design

  1. \(\beta = R_1/(R_1 + R_2)\) from the divider on the + input.
  2. Symmetric levels: \(T = 2RC\ln\frac{1+\beta}{1-\beta}\). Unequal levels: compute \(T_1\) and \(T_2\) separately.
  3. Design: choose β (say 0.5), choose C (so that R lands between about 1 kΩ and 1 MΩ), then \(R = T / \left(2C\ln\frac{1+\beta}{1-\beta}\right)\).

The RL-timed astable (assignment Q9)

Replace R–C by L–R: the inductor sits between the output and the − input and a resistor goes from the − input to ground. The resistor voltage (proportional to the inductor current) is the continuous quantity, and it relaxes with \(\tau = L/R\). The period has the same form, \(T = 2\tau\ln\frac{1+\beta}{1-\beta}\).

Assignment Q9: L = 10 mH, R = 200 Ω, divider 35 kΩ (output to +) and 30 kΩ (+ to ground), rails ±13 V

\(\beta = 30/65 = 6/13\), so the thresholds are ±6 V. \(\tau = L/R = 10\text{ mH}/200\ \Omega = 50\) µs. The resistor voltage moves exponentially between −6 V and +6 V toward ±13 V: \(T = 2\times50\text{ µs}\times\ln\frac{13+6}{13-6} = 100\ln(19/7)\) µs \(= 99.85\) µs. The output is a ±13 V square wave at about 10.0 kHz.

3. The op-amp monostable (one-shot)

Circuit (Khairul s.11–12, Sedra Fig. 18.28): the astable of Figure 1 with a diode \(D_1\) across C (anode at the − input) and a trigger network (\(C_2\), \(R_4\), \(D_2\)) into the + input.

  1. Stable state: \(v_O = L_+\); C would charge toward \(L_+\) but \(D_1\) clamps \(v_-\) at \(V_{D1} \approx 0.7\) V, which is below \(\beta L_+\), so nothing changes.
  2. Trigger: a negative pulse through \(D_2\) pulls \(v_+\) below \(V_{D1}\): the output flips to \(L_-\) and \(v_+ = \beta L_-\).
  3. Timing: C discharges from \(V_{D1}\) toward \(L_-\); when \(v_-\) reaches \(\beta L_-\) the output returns to \(L_+\).
  4. Recovery: C must recharge to \(V_{D1}\) before the next trigger, otherwise the pulse comes out shorter.
\[ T = RC\ln\frac{V_{D1} - L_-}{\beta L_- - L_-} = RC\ln\frac{V_{D1} + L}{L(1-\beta)} \;\approx\; RC\ln\frac{1}{1-\beta}\quad(V_{D1} \ll L) \]

Example: \(\beta = 0.5\), \(L = 13\) V, \(V_{D1} = 0.7\) V gives \(T = RC\ln(13.7/6.5) = 0.746\,RC\) (0.693 RC if the diode drop is ignored; say which you used).

4. Square–triangle generator (type S-08)

Derivation (2022–23 compulsory part, 20 marks).

  1. The Schmitt + input: \(v_+ = \dfrac{R_2 v_1 + R_1 v_2}{R_1 + R_2}\). It switches when \(v_+ = 0\), i.e. when \(v_1 = -\dfrac{R_1}{R_2}v_2\). So the thresholds are \(V_{TH} = -L_-\dfrac{R_1}{R_2}\), \(V_{TL} = -L_+\dfrac{R_1}{R_2}\); symmetric: \(\pm L\dfrac{R_1}{R_2}\).
  2. While \(v_2 = L_+\), the integrator output falls with slope \(-L_+/(RC)\), from \(V_{TH}\) to \(V_{TL}\): \(T_1 = RC\dfrac{V_{TH} - V_{TL}}{L_+}\). While \(v_2 = L_-\) it rises: \(T_2 = RC\dfrac{V_{TH} - V_{TL}}{-L_-}\).
  3. Symmetric levels: \(V_{pp} = 2L\dfrac{R_1}{R_2}\), \(T_1 = T_2 = 2RC\dfrac{R_1}{R_2}\):
\[ T = 4RC\,\frac{R_1}{R_2}, \qquad f = \frac{R_2}{4RCR_1}, \qquad V_{pp,\triangle} = 2L\frac{R_1}{R_2} \]

Why non-inverting: the integrator already inverts. An inverting Schmitt would make the loop latch instead of oscillate.

Method · design for f and Vpp

  1. State the saturation level L (13 V is Sedra's usual; 15 V if told the output swings to the rails).
  2. Amplitude first: \(R_1/R_2 = V_{pp}/(2L)\). Pick \(R_2\) (say 10 kΩ), get \(R_1\).
  3. Frequency next: \(RC = \dfrac{R_2}{4fR_1}\). Pick C, get R.
  4. If the bistable is given (thresholds and levels fixed, 2019–20), only RC is free: \(T = RC(V_{TH} - V_{TL})\left(\frac{1}{L_+} + \frac{1}{|L_-|}\right)\).

Sawtooth variant (2021–22)

Make the two ramps unequal: feed the integrator through two diode-steered paths, \(D_1\) in series with \(R_a\) (used while \(v_2 = L_+\)) and \(D_2\) reversed in series with \(R_b\) (used while \(v_2 = L_-\)). With ideal diodes and symmetric levels: \(T_{fall} = 2R_aC\dfrac{R_1}{R_2}\), \(T_{rise} = 2R_bC\dfrac{R_1}{R_2}\), \(f = \dfrac{R_2}{2R_1C(R_a + R_b)}\). Choose \(R_b \ll R_a\) for a fast flyback.

Traps

  • Triangle generator: the Schmitt must be non-inverting; draw R₁ from the triangle output, not from the square output.
  • \(V_{pp} = 2LR_1/R_2\), not \(LR_1/R_2\); and \(T = 4RCR_1/R_2\), not \(2RCR_1/R_2\) (that is half a period).
  • Astable: \(T = 2RC\ln\frac{1+\beta}{1-\beta}\) uses the natural log; \(\beta\) is \(R_1/(R_1+R_2)\), not \(R_1/R_2\).
  • Monostable: the timing starts at the diode clamp \(V_{D1}\), not at 0 V or \(\beta L_+\).
  • Always state the assumed saturation level L; answers with 13 V and 15 V are both accepted if stated.

Exam questions

2022–23 · Sec B · Q5(b) · 20 marks · compulsory

Draw and explain the operation of a triangular-wave generator circuit using op-amps and a Schmitt trigger. Derive the frequency of oscillation.

Show worked answer

Circuit: Figure 2: op-amp 1 is a non-inverting Schmitt trigger (− input grounded; R₁ from the triangle output \(v_1\) to the + input; R₂ from its own output \(v_2\) to the + input). Op-amp 2 is an inverting integrator (R from \(v_2\) to its − input, C from − input to \(v_1\), + grounded).

Operation: while \(v_2 = +L\) the integrator ramps \(v_1\) down at \(L/(RC)\) V/s. When \(v_1\) reaches \(-LR_1/R_2\), the Schmitt's + input crosses zero and \(v_2\) flips to \(-L\); \(v_1\) now ramps up until it reaches \(+LR_1/R_2\), and the Schmitt flips back. \(v_1\) is a triangle between \(\pm LR_1/R_2\), \(v_2\) a square wave ±L.

Thresholds: \(v_+ = \dfrac{R_2v_1 + R_1v_2}{R_1+R_2} = 0 \Rightarrow v_1 = -\dfrac{R_1}{R_2}v_2\), so \(V_{TH,TL} = \pm L\dfrac{R_1}{R_2}\), \(\Delta V = 2L\dfrac{R_1}{R_2}\).

Frequency: each ramp lasts \(\dfrac{T}{2} = \dfrac{\Delta V}{L/RC} = 2RC\dfrac{R_1}{R_2}\), so \(T = 4RC\dfrac{R_1}{R_2}\) and \(f = \dfrac{R_2}{4RCR_1}\). (For unequal levels: \(T_1 = RC\Delta V/L_+\), \(T_2 = RC\Delta V/|L_-|\).)

2021–22 · Sec A · Q4(a) · 23 marks

Draw a sawtooth-wave generator circuit using op-amps. Explain the operation of the circuit.

Show worked answer

Use the triangle generator of Figure 2 but replace the integrator's input resistor by two parallel diode paths: \(D_1\) + \(R_a\) conducting when \(v_2 = +L\), and \(D_2\) (reversed) + \(R_b\) conducting when \(v_2 = -L\), with \(R_b \ll R_a\).

While \(v_2 = +L\), current flows through \(R_a\): the output falls slowly with slope \(L/(R_aC)\) from \(+LR_1/R_2\) to \(-LR_1/R_2\), taking \(T_{fall} = 2R_aC\,R_1/R_2\). The Schmitt then flips; current flows through \(R_b\) and the output rises quickly, \(T_{rise} = 2R_bC\,R_1/R_2\). The result is a sawtooth (slow ramp, fast flyback) of peak-to-peak \(2LR_1/R_2\) and \(f = \dfrac{R_2}{2R_1C(R_a + R_b)}\). (Alternative: an integrator with a switch across C that resets it rapidly.)

2021–22 · Sec A · Q2(a) · 26⅔ marks

Draw a one-shot multivibrator circuit using an op-amp. Explain the operation of the circuit.

Show worked answer

Circuit: op-amp with R₂ from output A to the + input C and R₁ from C to ground (\(\beta = R_1/(R_1+R_2)\)); R from A to the − input B; C from B to ground; D₁ from B (anode) to ground; trigger: a negative pulse through C₂ to node E (R₄ to ground), D₂ from C (anode) to E.

Operation: stable state \(v_A = L_+\), \(v_C = \beta L_+\), \(v_B\) clamped at \(V_{D1}\) by D₁. A negative trigger pulls \(v_C\) below \(v_B\) through D₂, so the output switches to \(L_-\) and \(v_C = \beta L_-\). C now discharges from \(V_{D1}\) toward \(L_-\): \(v_B(t) = L_- - (L_- - V_{D1})e^{-t/RC}\). When \(v_B = \beta L_-\) the comparator flips back to \(L_+\).

Pulse width: \(T = RC\ln\dfrac{V_{D1} - L_-}{\beta L_- - L_-} \approx RC\ln\dfrac{1}{1-\beta}\). Example β = 0.5, L = 13 V: \(T = 0.746RC\). After the pulse, C must recharge to \(V_{D1}\) (recovery time) before the next trigger.

2019–20 · Sec B · Q7(b) · 18 marks

A bistable multivibrator with a given non-inverting transfer characteristic (levels \(L_+\), \(L_-\); thresholds \(V_{TL} < 0 < V_{TH}\)) is provided. Design a signal generator based on it that produces a square wave \(v_2\) (high for \(T_1\), low for \(T_2\)) and a triangle \(v_1\) between \(V_{TL}\) and \(V_{TH}\). Choose component values for 1 MHz.

Show worked answer

Connect an inverting integrator (R, C) from the bistable output \(v_2\) to \(v_1\), and \(v_1\) back to the bistable input. The bistable is given, so only RC is designed.

\(T_1 = RC\dfrac{V_{TH} - V_{TL}}{L_+}\), \(T_2 = RC\dfrac{V_{TH} - V_{TL}}{-L_-}\), so \(T = RC(V_{TH} - V_{TL})\left(\dfrac{1}{L_+} + \dfrac{1}{|L_-|}\right) = 1\) µs.

For a symmetric characteristic (\(L_\pm = \pm L\), \(V_{TH,TL} = \pm V_T\)): \(T = 4RC\,V_T/L\). If, for example, \(V_T = L\) (thresholds equal to the levels, \(R_1 = R_2\)), \(RC = 250\) ns: C = 100 pF, R = 2.5 kΩ. Read \(V_T\) and L from the given figure and substitute.

2018–19 · Sec B · Q7(c) · 16 marks

Design a circuit using a bistable multivibrator which generates a triangular waveform with oscillation frequency 2 kHz and 10 V peak-to-peak amplitude.

Show worked answer

Use Figure 2. Assume \(L = \pm13\) V.

Amplitude: \(2L\dfrac{R_1}{R_2} = 10 \Rightarrow \dfrac{R_1}{R_2} = \dfrac{10}{26} = 0.385\). Take \(R_2\) = 26 kΩ, \(R_1\) = 10 kΩ.

Frequency: \(f = \dfrac{R_2}{4RCR_1} = 2000 \Rightarrow RC = \dfrac{1}{4\times2000\times0.385} = 325\) µs. With C = 10 nF, R = 32.5 kΩ.

(With \(L = \pm15\) V: \(R_1/R_2 = 1/3\), \(RC = 375\) µs, R = 37.5 kΩ at 10 nF. Either is right if L is stated.)
