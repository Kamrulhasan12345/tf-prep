Comparators, Bistables and Schmitt Triggers

Asked in 2012–13 (zero-crossing detector), 2014–15 (design from switching points, 15 marks), 2016–17 (find the circuit from a transfer curve) and 2023–24 (draw the VTC, 15 marks). The Schmitt trigger is also the heart of every square/triangle generator in the next chapter. One decision decides the whole question: is the circuit inverting or non-inverting? Get that from the curve before writing any equation.

1. Comparator and zero-crossing detector

An op-amp with no feedback is a comparator: \(v_O = L_+\) when \(v_+ > v_-\), \(L_-\) otherwise (\(L_\pm\) ≈ the rails, or Zener-clamped levels). With \(v_I\) on + and − grounded it is a zero-crossing detector: a sine in, a square wave out, switching at each zero crossing. Put \(v_I\) on − for the inverted output; put a reference \(V_R\) on the other input to switch at \(V_R\). Weakness: near the threshold, noise on \(v_I\) makes the output chatter (many false transitions). Cure: hysteresis by positive feedback, i.e. a Schmitt trigger.

2. Bistable circuits

Connect the output to the + input through a divider (\(R_2\) from \(v_O\) to +, \(R_1\) from + to ground). Positive feedback: any disturbance grows, so the output sits at \(L_+\) or \(L_-\), never in between (the state \(v_+ = v_O = 0\) is metastable, like a ball on a hilltop, Khairul s.3–5). The input only triggers the change. This is a bistable multivibrator, also called a Schmitt trigger.

Inverting Schmitt (input on −)

\[ \beta = \frac{R_1}{R_1 + R_2},\qquad V_{TH} = \beta L_+,\qquad V_{TL} = \beta L_- \]

Output high for very negative \(v_I\); it drops to \(L_-\) when \(v_I\) rises past \(V_{TH}\), and returns to \(L_+\) when \(v_I\) falls below \(V_{TL}\): a clockwise loop. (Khairul FG s.4 prints the second threshold as "\(V_{TH} = L_+R_1/(R_1 + R_2)\)": a typo for \(V_{TL} = L_-R_1/(R_1 + R_2)\).)

With \(R_1\) returned to a reference \(V_R\) instead of ground: \(v_+ = \dfrac{v_OR_1 + V_RR_2}{R_1 + R_2}\), so \(V_{TH} = \dfrac{L_+R_1 + V_RR_2}{R_1 + R_2}\), \(V_{TL} = \dfrac{L_-R_1 + V_RR_2}{R_1 + R_2}\), and the width is \(V_{TH} - V_{TL} = (L_+ - L_-)\dfrac{R_1}{R_1 + R_2}\).

Non-inverting Schmitt (input through R₁ to +)

Superposition: \(v_+ = v_I\dfrac{R_2}{R_1 + R_2} + v_O\dfrac{R_1}{R_1 + R_2}\). Switching happens when \(v_+\) crosses the − input (0 V):

\[ V_{TH} = -L_-\frac{R_1}{R_2},\qquad V_{TL} = -L_+\frac{R_1}{R_2},\qquad \text{with } V_R \text{ on } -:\; v_I = \frac{V_R(R_1 + R_2) - v_OR_1}{R_2} \]

Output low for very negative \(v_I\); it jumps to \(L_+\) at \(V_{TH}\) (computed with \(v_O = L_-\)) and back at \(V_{TL}\) (with \(v_O = L_+\)): a counter-clockwise loop. Width \((L_+ - L_-)R_1/R_2\). Note \(R_1/R_2\) here, \(R_1/(R_1 + R_2)\) for the inverting one.

Method · analysis (find the VTC)

  1. Polarity: input on − → inverting; input through a resistor to + → non-inverting.
  2. Write \(v_+\) by superposition (input, output, reference).
  3. Switching when \(v_+ = v_-\). Substitute \(v_O = L_+\) and \(v_O = L_-\) to get the two thresholds. Pair each threshold with the state that is ending.
  4. Draw the loop with arrows and label \(L_\pm\), \(V_{TH}\), \(V_{TL}\).

Method · design from a VTC or switching points

  1. Read the polarity: output high for very negative input → inverting; low → non-inverting. (This is where the bank's AI answer to 2016–17 went wrong.)
  2. Read \(L_+\), \(L_-\), \(V_{TH}\), \(V_{TL}\). If \(L_+ \ne -L_-\), say how: asymmetric supplies or Zener clamps at the output.
  3. Inverting: \(\dfrac{R_1}{R_1 + R_2} = \dfrac{V_{TH} - V_{TL}}{L_+ - L_-}\); pick \(R_1\) = 10 kΩ (to \(V_R\)), get \(R_2\); then \(V_R = \dfrac{V_{TH}(R_1 + R_2) - L_+R_1}{R_2}\).
  4. Non-inverting: \(\dfrac{R_1}{R_2} = \dfrac{V_{TH} - V_{TL}}{L_+ - L_-}\); then \(V_R = \dfrac{V_{TH}R_2 + L_-R_1}{R_1 + R_2}\) (on the − input).
  5. Check by recomputing both thresholds.

Traps (where marks go)

  • Wrong polarity. Look at the output for very negative input first.
  • \(R_1/(R_1 + R_2)\) (inverting) versus \(R_1/R_2\) (non-inverting).
  • Pairing a threshold with the wrong output state: \(V_{TH}\) of the non-inverting circuit uses \(v_O = L_-\).
  • Sign of \(V_R\); always recompute both thresholds.
  • Asymmetric levels (+22 V, −12 V) cannot come from ±15 V rails: state the supplies or the Zener clamp.

Exam questions

2023–24 · Sec B · Q8(a) · 15 marks

Write down the characteristics of an ideal op-amp. Draw the voltage transfer characteristics of the circuit in the figure (\(V_{in}\) through \(R_1\) to the + input; \(R_2\) from \(V_o\) to the + input; − input grounded; Figure 2). (VTC shows the variation of output voltage in response to variations in input voltage.)

Show worked answer

Ideal op-amp: infinite open-loop gain, infinite input resistance (zero input current), zero output resistance, infinite bandwidth, infinite CMRR (responds only to \(v_+ - v_-\)), zero offset, infinite slew rate. With negative feedback this gives the virtual short; here the feedback is positive, so the output saturates at \(\pm V_{sat}\) (= \(L_\pm\)).

Analysis: \(V_+ = V_{in}\dfrac{R_2}{R_1 + R_2} + V_o\dfrac{R_1}{R_1 + R_2}\). The output switches when \(V_+\) crosses 0, i.e. at \(V_{in} = -V_o\dfrac{R_1}{R_2}\).

While \(V_o = -V_{sat}\): it switches up at \(V_{TH} = +V_{sat}\dfrac{R_1}{R_2}\). While \(V_o = +V_{sat}\): it switches down at \(V_{TL} = -V_{sat}\dfrac{R_1}{R_2}\).

VTC (Figure 3, right): for large negative \(V_{in}\), \(V_o = -V_{sat}\); increasing \(V_{in}\), the output stays low until \(V_{TH} = +V_{sat}R_1/R_2\), then jumps to \(+V_{sat}\); decreasing \(V_{in}\), it stays high until \(V_{TL} = -V_{sat}R_1/R_2\), then falls. A rectangular hysteresis loop of width \(2V_{sat}R_1/R_2\), traversed counter-clockwise: a non-inverting Schmitt trigger (bistable).

2016–17 · Sec A · Q2(b) · 11⅔ marks

Determine the op-amp circuit that generates the transfer characteristic shown: \(V_{out}\) = −12 V for \(V_{in}\) below −8 V and +22 V for \(V_{in}\) above −8 V (one vertical switching edge at −8 V; the −12 V level is continued as a dashed line toward 0 V on the paper).

Show worked answer

Polarity: output low for very negative input, high for positive input → non-inverting. (The question bank's AI answer uses an inverting Schmitt with \(V_{in}\) on −; that circuit gives +22 V for very negative input, the opposite of the curve. Wrong.)

Reading 1 (single edge, no hysteresis): a comparator with \(V_{in}\) on the + input and \(V_R\) = −8 V on the − input (a divider from the negative supply, or a −8 V source). Output levels +22 V and −12 V: run the op-amp from asymmetric supplies (about +24 V and −14 V), or clamp the output with Zeners (e.g. back-to-back Zeners giving +22 V / −12 V through a series resistor).

Reading 2 (the dashed line as the lower branch of a loop): \(V_{TL}\) = −8 V, \(V_{TH}\) = 0 V. Non-inverting Schmitt with \(V_R\) on −: switching at \(V_{in} = [V_R(R_1 + R_2) - V_oR_1]/R_2\).

\(V_{TH}\) (with \(V_o = -12\)): \(0 = [V_R(R_1 + R_2) + 12R_1]/R_2\). \(V_{TL}\) (with \(V_o = +22\)): \(-8 = [V_R(R_1 + R_2) - 22R_1]/R_2\). Subtract: \(8 = 34R_1/R_2\), so \(R_2 = 4.25R_1\) (\(R_1\) = 10 kΩ, \(R_2\) = 42.5 kΩ). Then \(V_R = -12R_1/(R_1 + R_2) = -2.286\) V. Check: thresholds −8.0 V and 0.0 V.

2014–15 · Sec B · Q5(b) · 15 marks

Design a Schmitt trigger that triggers from +16 V to −16 V at an input voltage of 12 V and triggers from −16 V to +16 V at an input voltage of 8 V. Specify all the values of resistors used and the reference DC voltage.

Show worked answer

High → low as the input rises (at 12 V): inverting Schmitt. \(L_\pm = \pm16\) V, \(V_{TH}\) = 12 V, \(V_{TL}\) = 8 V. Circuit: \(v_I\) to −; \(R_2\) from \(v_O\) to +; \(R_1\) from + to \(V_R\): \(v_+ = \dfrac{v_OR_1 + V_RR_2}{R_1 + R_2}\).

\(12(R_1 + R_2) = 16R_1 + V_RR_2\) and \(8(R_1 + R_2) = -16R_1 + V_RR_2\). Subtract: \(4(R_1 + R_2) = 32R_1 \Rightarrow R_2 = 7R_1\).

With \(R_1\) = 10 kΩ, \(R_2\) = 70 kΩ: \(12\times80 = 160 + 70V_R \Rightarrow V_R = 800/70 = 11.43\) V.

Check: \(V_{TH} = (16\times10 + 11.43\times70)/80 = 12.0\) V; \(V_{TL} = (-160 + 800)/80 = 8.0\) V. Op-amp on ±16 V-saturating supplies (e.g. ±18 V).

2012–13 · Sec B · Q7(c) · 15 marks

Draw a zero-crossing detector circuit using an op-amp and briefly describe its operation.

Show worked answer

Circuit: op-amp with no feedback; \(v_I\) to the + input, − input grounded (optionally a series input resistor and back-to-back diodes for input protection; Zeners at the output to set the levels).

Operation: with very high open-loop gain, \(v_O = +V_{sat}\) when \(v_I > 0\) and \(-V_{sat}\) when \(v_I < 0\); the output changes state each time the input crosses zero. A sine input becomes a square wave of the same frequency (draw both waveforms aligned). With \(v_I\) on −, the output is inverted.

Limitations: noise near zero causes multiple false transitions (fixed by hysteresis, i.e. a Schmitt trigger with small thresholds); finite slew rate limits the edge speed at high frequency. Uses: sine-to-square conversion, zero-crossing timing, phase measurement, triggering.

Key terms

Quick check

Summary: decide polarity first. Inverting (input on −): \(V_{TH,TL} = \dfrac{L_\pm R_1 + V_RR_2}{R_1 + R_2}\), clockwise. Non-inverting (input via \(R_1\) to +): switching at \(v_I = [V_R(R_1 + R_2) - v_OR_1]/R_2\), so \(V_{TH} = -L_-R_1/R_2\), \(V_{TL} = -L_+R_1/R_2\) without reference, counter-clockwise. Design: width gives the resistor ratio, one threshold gives \(V_R\); recompute both.
