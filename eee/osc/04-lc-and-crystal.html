LC Oscillators: Colpitts, Hartley and the Crystal

Colpitts is the oscillator derivation of recent papers: 2018–19 (20 marks), 2020–21 (26⅔, MOSFET small-signal), 2022–23 (20) and 2024–25 (18, compulsory). It alternates with Wien, so expect one of the two. Every version gives the same two results: \(\omega_0 = 1/\sqrt{L\,C_1C_2/(C_1 + C_2)}\) and a gain condition set by the capacitor ratio. The only trap is which capacitor is on top of that ratio; this chapter gives a label-free rule so you cannot get it wrong.

1. The LC resonator (Sadat p.122–123, Khairul s.24–25)

Charge C to \(V_0\), connect it across L. With \(i_C + i_L = 0\):

\[ C\frac{dv}{dt} + i_L = 0 \;\Rightarrow\; C\frac{d^2v}{dt^2} + \frac{v}{L} = 0 \;\Rightarrow\; \frac{d^2v}{dt^2} + \omega_0^2v = 0,\quad \omega_0 = \frac{1}{\sqrt{LC}} \]

So \(v_C = V_0\cos\omega_0t\) and \(i_L \propto \sin\omega_0t\): energy swings between C and L, 90° apart. Equivalently \(Z_L + Z_C = 0\): \(j\omega L + 1/(j\omega C) = 0 \Rightarrow \omega_0 = 1/\sqrt{LC}\). A real tank loses energy in its resistance; the amplifier's job is to replace it. Colpitts and Hartley are ways of tapping the tank to get the feedback signal.

2. Colpitts: the label-free rule

Split the tank capacitance into two capacitors in series with L between them: one across the amplifier output, one across the amplifier input. The loop current circulates through L, \(C_{out}\) and \(C_{in}\) in series, so

\[ \omega_0 = \frac{1}{\sqrt{L\,C_T}},\qquad C_T = \frac{C_{in}C_{out}}{C_{in} + C_{out}} \;(\text{series, not } C_1 + C_2) \]

The same current flows through both capacitors in opposite senses, so the voltages across them are in antiphase with ratio of their reactances: \(\beta = V_{in}/V_{out} = -\dfrac{1/(\omega C_{in})}{1/(\omega C_{out})} = -\dfrac{C_{out}}{C_{in}}\). The network gives 180°, the amplifier must be inverting with

\[ |A| \ge \frac{C_{in}}{C_{out}} \qquad (\text{capacitor at the amplifier input over capacitor at its output}) \]

Op-amp Colpitts as taught (Sadat p.124, Khairul s.26–27)

Exam derivation: amplifier \(A = -R_2/R_1\) (∠180°). Tank current \(I_1\) (the amplifier input draws ≈ 0): \(V_f = \dfrac{I_1}{j\omega_0C_1}\), \(V_o = -\dfrac{I_1}{j\omega_0C_2}\), so \(\beta = V_f/V_o = -C_2/C_1\) (∠180°: "phase handled automatically"). Resonance of L with \(C_1\), \(C_2\) in series: \(\omega_0 = 1/\sqrt{LC_T}\). Barkhausen \(A\beta = 1\): \(\dfrac{R_2}{R_1}\cdot\dfrac{C_2}{C_1} = 1\), i.e. \(R_2/R_1 = C_1/C_2\); to start, \(R_2/R_1 \ge C_1/C_2\).

A more rigorous op-amp form (useful if the examiner wants β(jω) written out): non-inverting amplifier, R from the output to node A, L from A to ground, \(C_1\) from A to B and \(C_2\) from B to ground, B to the + input. \(Z_A = L \parallel (C_1 \text{ series } C_2)\) is infinite at \(\omega_0 = 1/\sqrt{LC_T}\), so \(V_A = V_o\) and \(\beta = V_B/V_o = C_1/(C_1 + C_2)\) (real, phase 0 exactly there). Gain: \(1 + R_f/R_1 \ge 1 + C_2/C_1\). Same frequency, same rule (input capacitor \(C_2\) over output-side \(C_1\)).

3. MOSFET Colpitts by KCL (2020–21: show ω₀ and C₂/C₁ = gₘR)

Write it exactly like this in the exam:

  1. Gate node (no gate current): the current through \(C_2\) comes through L: \(sC_2v_{gs} = \dfrac{v_d - v_{gs}}{sL} \Rightarrow v_d = v_{gs}(1 + s^2LC_2)\).
  2. Drain node (sum of currents leaving = 0): \(g_mv_{gs} + \dfrac{v_d}{R} + sC_1v_d + sC_2v_{gs} = 0\) (the current into L equals the current in \(C_2\)).
  3. Substitute and divide by \(v_{gs} \ne 0\): \(g_m + (1 + s^2LC_2)\Big(\dfrac1R + sC_1\Big) + sC_2 = 0\), i.e.
    \[ s^3LC_1C_2 + s^2\frac{LC_2}{R} + s(C_1 + C_2) + \Big(g_m + \frac1R\Big) = 0 \]
  4. Put \(s = j\omega_0\): imaginary part \(-\omega_0^3LC_1C_2 + \omega_0(C_1 + C_2) = 0 \Rightarrow \omega_0 = \dfrac{1}{\sqrt{L\,\frac{C_1C_2}{C_1 + C_2}}}\).
  5. Real part: \(-\omega_0^2\dfrac{LC_2}{R} + g_m + \dfrac1R = 0 \Rightarrow g_mR = \omega_0^2LC_2 - 1 = \dfrac{C_1 + C_2}{C_1} - 1 = \dfrac{C_2}{C_1}\).

So sustained oscillation needs \(g_mR = C_2/C_1\) (gate capacitor over drain capacitor), and start-up needs \(g_mR > C_2/C_1\). A BJT works the same way with \(R' = r_o \parallel R_C \parallel R_L\) and the base input resistance ignored (\(g_mR' \ge C_2/C_1\); with \(r_\pi\) included, \(h_{fe} \ge (h_{ie}/R')(C_2/C_1)\) approximately). The DC bias uses an RF choke so that only the tank sets the AC load.

Method · Colpitts numbers

  1. \(C_T = C_1C_2/(C_1 + C_2)\); \(f_0 = 1/(2\pi\sqrt{LC_T})\).
  2. Identify the input (gate/base/\(v_f\)) capacitor and the output (drain/collector/\(v_o\)) capacitor.
  3. Transistor: \(g_mR \ge C_{in}/C_{out}\) → \(R_{min}\) or \(g_{m,min}\). Op-amp: \(|A| \ge C_{in}/C_{out}\).

4. Hartley (Sadat p.125, Khairul s.29–31)

The dual: split the inductor, one capacitor C between the taps. \(\omega_0 = 1/\sqrt{(L_1 + L_2)C}\) (series inductors; mutual inductance ignored). Now the reactances are \(\omega L\), so \(\beta = -L_{in}/L_{out}\) and \(|A| \ge L_{out}/L_{in}\). Sadat/Khairul: \(L_1\) at \(v_f\), \(L_2\) at \(v_o\), so \(R_2/R_1 \ge L_2/L_1\); MOSFET form: \(g_mR \ge L_{drain}/L_{gate}\). Not yet asked in a term final, but it is in both teachers' notes.

5. Crystal oscillators (type S-04)

\[ Z(s) = \frac{1}{sC_p}\cdot\frac{s^2 + 1/(LC_s)}{s^2 + (C_p + C_s)/(LC_sC_p)} \]
\[ \omega_s = \frac{1}{\sqrt{LC_s}},\qquad \omega_p = \frac{1}{\sqrt{L\,\frac{C_sC_p}{C_s + C_p}}} \approx \omega_s\Big(1 + \frac{C_s}{2C_p}\Big) \]
  • Below \(f_s\): capacitive. At \(f_s\) (series resonance): \(X = 0\). Between \(f_s\) and \(f_p\): inductive (very narrow band, about 0.1%). At \(f_p\) (parallel resonance): \(|X| \to \infty\). Above \(f_p\): capacitive again.
  • Q is \(10^4\) to \(10^6\) (\(Q = \omega_sL/r\)), so the frequency is extremely stable. In a Pierce (Colpitts-type) oscillator the crystal replaces L and operates in its inductive band, so \(f_0\) lies between \(f_s\) and \(f_p\), essentially fixed by the crystal.

6. RL/LC networks with a non-inverting amplifier (2015–16)

The 2015–16 paper used a Wien-type ladder with inductors: L in series from the output to node m, \(R_1\) from m to ground, \(R_2\) from m to the + input, L from the + input to ground; amplifier gain \(1 + R_f/R_i = 3\) (\(R_f\) = 40 kΩ, \(R_i\) = 20 kΩ). Same nodal method as Chapter 2:

\[ \frac{1}{\beta} = 2 + \frac{R_2}{R_1} + j\Big(\frac{\omega L}{R_1} - \frac{R_2}{\omega L}\Big) \;\Rightarrow\; \omega_0 = \frac{\sqrt{R_1R_2}}{L},\quad \beta(\omega_0) = \frac{1}{2 + R_2/R_1} \]

Traps (where marks go)

  • Using \(C_1 + C_2\): the capacitors are in series around the loop.
  • The ratio upside down. Rule: input capacitor over output capacitor (Colpitts), output inductor over input inductor (Hartley). Always say which capacitor is at the gate.
  • In the KCL derivation, forgetting the L current at the drain node (it equals the \(C_2\) current).
  • Calling the crystal capacitive between \(f_s\) and \(f_p\): that band is inductive.
  • Crystal: \(f_p\) uses the series combination \(C_sC_p/(C_s + C_p)\), not \(C_s + C_p\). Keep the pF exponents.

Exam questions

2024–25 · Sec A · Q1(a) · 18 marks · compulsory

With an appropriate circuit diagram, describe the operation of an op-amp based Colpitts oscillator. Derive the frequency of oscillation and explain how this circuit satisfies the conditions for sustained oscillation.

Show worked answer

Circuit (Figure 1): inverting amplifier, \(R_1\) into the − input, \(R_2\) feedback, + grounded: \(A = -R_2/R_1\) (180°). Feedback network: \(C_2\) from \(v_o\) to ground, L from \(v_o\) to \(v_f\), \(C_1\) from \(v_f\) to ground; \(v_f\) drives \(R_1\).

Operation: the \(C_1\)–L–\(C_2\) tank resonates; energy exchanges between L and the capacitors. The tank voltage across \(C_2\) (output) and \(C_1\) (input) are 180° apart, so the network adds 180° to the amplifier's 180°: positive feedback at one frequency. The amplifier replaces the energy lost in the tank and in \(R_1\).

Frequency: with the amplifier input drawing negligible current, one current \(I_1\) circulates through \(C_2\), L and \(C_1\). The loop impedance must be zero: \(j\omega L + \dfrac{1}{j\omega C_1} + \dfrac{1}{j\omega C_2} = 0 \Rightarrow \omega_0^2L = \dfrac{1}{C_1} + \dfrac{1}{C_2}\), so \(\omega_0 = \dfrac{1}{\sqrt{LC_T}}\), \(C_T = \dfrac{C_1C_2}{C_1 + C_2}\), \(f_0 = \dfrac{1}{2\pi\sqrt{LC_T}}\).

Feedback factor: \(V_f = \dfrac{I_1}{j\omega_0C_1}\), \(V_o = -\dfrac{I_1}{j\omega_0C_2}\), so \(\beta = -\dfrac{C_2}{C_1}\).

Sustained oscillation (Barkhausen): \(A\beta = \Big(-\dfrac{R_2}{R_1}\Big)\Big(-\dfrac{C_2}{C_1}\Big) = 1\): phase 0° (180° + 180°) and \(R_2/R_1 = C_1/C_2\). For start-up \(R_2/R_1\) slightly greater than \(C_1/C_2\); the amplitude then settles by op-amp saturation (or a limiter).

(Alternative accepted form: non-inverting amplifier with series R and the tapped tank, \(\beta = C_1/(C_1 + C_2)\) at \(\omega_0\), \(R_f/R_1 \ge C_2/C_1\) with \(C_2\) the capacitor at the input. Same \(\omega_0\).)

2022–23 · Sec B · Q7(a) · 20 marks

Derive the expression of oscillation frequency for a Colpitts oscillator. Then derive the conditions for Barkhausen criteria to be satisfied.

Show worked answer

Draw a transistor Colpitts (common-source MOSFET or common-emitter BJT with RF choke bias): \(C_1\) drain (collector) to ground, \(C_2\) gate (base) to ground, L between drain and gate; R = total resistance at the drain. Then follow Section 3:

Gate node: \(v_d = v_{gs}(1 + s^2LC_2)\). Drain node: \(g_mv_{gs} + v_d(1/R + sC_1) + sC_2v_{gs} = 0\). Characteristic equation: \(s^3LC_1C_2 + s^2LC_2/R + s(C_1 + C_2) + (g_m + 1/R) = 0\).

Frequency: imaginary part at \(s = j\omega_0\): \(\omega_0^2 = \dfrac{C_1 + C_2}{LC_1C_2}\), \(f_0 = \dfrac{1}{2\pi\sqrt{L\,C_1C_2/(C_1 + C_2)}}\).

Barkhausen magnitude condition: real part: \(g_mR = C_2/C_1\) (loop gain exactly 1). Start-up: \(g_mR > C_2/C_1\). Phase condition: the CS stage gives 180°, the \(C_1\)–L–\(C_2\) network another 180° at \(\omega_0\) (\(\beta = -C_1/C_2\) from drain to gate), total 360°.

(Approximate method from the bank: \(A_v = -g_mR'\), \(\beta = -C_1/C_2\), \(A_v\beta \ge 1 \Rightarrow g_mR' \ge C_2/C_1\). Same result.)

2020–21 · Sec A · Q3(b) · 26⅔ marks  |  also 2018–19 Sec B Q7(a), 20 marks (ω₀ part only)

Draw the circuit of the Colpitts oscillator. Then using the small-signal model of the MOSFET show that the frequency of oscillation is \(\omega_0 = 1/\sqrt{L\,C_1C_2/(C_1 + C_2)}\) and \(C_2/C_1 = g_mR\). (2018–19: "For the Colpitts oscillator, show that the frequency of oscillation is \(\omega_0 = 1/\sqrt{LC_1C_2/(C_1+C_2)}\).")

Show worked answer

Circuit: NMOS common source, drain fed from \(V_{DD}\) through an RF choke, gate biased through a large resistor; \(C_1\) from drain to ground, \(C_2\) from gate to ground, L from drain to gate. Small-signal model: Figure 2 (R = \(r_o \parallel R_L\) ∥ tank loss resistance, source grounded).

1. Gate node: \(sC_2V_{gs} + \dfrac{V_{gs} - V_d}{sL} = 0 \Rightarrow V_d = V_{gs}(1 + s^2LC_2)\).

2. Drain node: \(g_mV_{gs} + \dfrac{V_d}{R} + sC_1V_d + sC_2V_{gs} = 0\).

3. Substitute: \(V_{gs}\Big[g_m + (1 + s^2LC_2)\Big(\dfrac1R + sC_1\Big) + sC_2\Big] = 0\). Oscillation means \(V_{gs} \ne 0\): \(s^3LC_1C_2 + s^2\dfrac{LC_2}{R} + s(C_1 + C_2) + g_m + \dfrac1R = 0\).

4. \(s = j\omega\): \(\Big[g_m + \dfrac1R - \dfrac{\omega^2LC_2}{R}\Big] + j\big[\omega(C_1 + C_2) - \omega^3LC_1C_2\big] = 0\). Both parts vanish.

5. Imaginary: \(\omega_0^2 = \dfrac{C_1 + C_2}{LC_1C_2}\Rightarrow \omega_0 = \dfrac{1}{\sqrt{L\frac{C_1C_2}{C_1 + C_2}}}\). (Shown.)

6. Real: \(g_m + \dfrac1R = \dfrac{\omega_0^2LC_2}{R} = \dfrac{1}{R}\cdot\dfrac{C_1 + C_2}{C_1}\) \(\Rightarrow g_mR = \dfrac{C_2}{C_1}\). (Shown.) For start-up \(g_mR\) is made slightly larger than \(C_2/C_1\).

Note: the question bank prints \(C_1/C_2 = g_mR\); that only holds if \(C_1\) is the gate capacitor. State your labels.

2018–19 · Sec B · Q7(b) · 10⅔ marks

Draw the equivalent circuit of a piezoelectric crystal. Qualitatively draw the crystal reactance versus frequency and identify the inductive and capacitive reactance regions.

Show worked answer

Figure 3 (left): series L, \(C_s\), r (mechanical resonance: mass, compliance, loss) in parallel with \(C_p\) (electrode capacitance), \(C_p \gg C_s\).

Neglecting r: \(Z = jX = \dfrac{1}{sC_p}\cdot\dfrac{s^2 + \omega_s^2}{s^2 + \omega_p^2}\), \(\omega_s = 1/\sqrt{LC_s}\), \(\omega_p = 1/\sqrt{L C_sC_p/(C_s + C_p)}\), with \(\omega_p\) slightly above \(\omega_s\).

Reactance plot (Figure 3, right): \(X < 0\) (capacitive) for \(\omega < \omega_s\), rising to 0 at \(\omega_s\); \(X > 0\) (inductive) between \(\omega_s\) and \(\omega_p\), rising to \(+\infty\) at \(\omega_p\); \(X < 0\) (capacitive) above \(\omega_p\), approaching 0 from below. The oscillator uses the narrow inductive band, giving very stable frequency (Q ~ \(10^4\)–\(10^6\)).

2015–16 · Sec B · Q7(a) · 26 marks

For the oscillator circuit given (op-amp with \(R_i\) = 20 kΩ to ground and \(R_f\) = 40 kΩ feedback, rails ±\(V_{bias}\); L from \(V_o\) to node m, \(R_1\) from m to ground, \(R_2\) from m to the + input, L from the + input to ground): (i) derive the expression for the oscillation frequency f₀; (ii) obtain the relationship between \(R_1\) and \(R_2\) for sustained oscillation; (iii) specify the bias conditions and values of L, \(R_1\), \(R_2\) to obtain a 20 V peak-to-peak, 500 kHz sinusoidal signal.

Show worked answer

(i) + input draws no current: \(v_p = v_m\dfrac{sL}{R_2 + sL}\). KCL at m: \(\dfrac{v_o - v_m}{sL} = \dfrac{v_m}{R_1} + \dfrac{v_m}{R_2 + sL}\), so \(\dfrac{v_o}{v_m} = 1 + \dfrac{sL}{R_1} + \dfrac{sL}{R_2 + sL}\).

\(\dfrac{1}{\beta} = \dfrac{v_o}{v_p} = \Big(1 + \dfrac{R_2}{sL}\Big)\Big(1 + \dfrac{sL}{R_1}\Big) + 1 = 2 + \dfrac{R_2}{R_1} + \dfrac{sL}{R_1} + \dfrac{R_2}{sL}\).

At \(s = j\omega\): \(\dfrac1\beta = 2 + \dfrac{R_2}{R_1} + j\Big(\dfrac{\omega L}{R_1} - \dfrac{R_2}{\omega L}\Big)\). Non-inverting amplifier (0°), so Im = 0: \(\omega_0 = \dfrac{\sqrt{R_1R_2}}{L}\), \(f_0 = \dfrac{\sqrt{R_1R_2}}{2\pi L}\).

(ii) \(\beta(\omega_0) = \dfrac{1}{2 + R_2/R_1}\); \(A = 1 + 40/20 = 3\). \(A\beta \ge 1\): \(3 \ge 2 + R_2/R_1 \Rightarrow R_1 \ge R_2\) (equal to sustain, \(R_1\) slightly larger to start).

(iii) 20 V p-p = 10 V peak, so the op-amp must not saturate below 10 V: \(\pm V_{bias}\) ≈ ±12 V to ±15 V. With \(R_1 = R_2 = R\): \(\omega_0 = R/L = 2\pi\times500\) kHz. Choose L = 1 mH: \(R = 2\pi\times5\times10^5\times10^{-3} = 3.14\) kΩ. (In practice \(R_2\) slightly below \(R_1\), plus a limiter to hold 10 V peak.)

Class test

Class test 2018 (CT3-B) · 6 marks · Sedra exercise

A 4 MHz quartz crystal has L = 0.13 H, C = 0.012 pF and C′ = 4 pF. Find \(f_s\) and \(f_p\).

Show worked answer

\(f_s = \dfrac{1}{2\pi\sqrt{0.13\times0.012\times10^{-12}}} = 4.0296\) MHz.

\(C_sC_p/(C_s + C_p) = 0.012\times4/4.012 = 0.011964\) pF; \(f_p = \dfrac{1}{2\pi\sqrt{0.13\times0.011964\times10^{-12}}} = 4.0356\) MHz. \(f_p - f_s = 6.04\) kHz (0.15%).

Key terms

Quick check

Summary: Colpitts: \(\omega_0 = 1/\sqrt{LC_T}\), \(C_T = C_1C_2/(C_1 + C_2)\); gain ≥ (input capacitor)/(output capacitor): Sadat's op-amp \(R_2/R_1 \ge C_1/C_2\), Sedra's MOSFET \(g_mR = C_2/C_1\) from the two-node KCL (imaginary part → \(\omega_0\), real part → gain). Hartley: \(\omega_0 = 1/\sqrt{(L_1 + L_2)C}\), gain ≥ \(L_{out}/L_{in}\). Crystal: series L–\(C_s\)–r ∥ \(C_p\); \(f_s = 1/(2\pi\sqrt{LC_s})\), \(f_p\) with \(C_sC_p/(C_s + C_p)\); inductive only between them.
