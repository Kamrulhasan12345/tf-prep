The RC Phase-Shift Oscillator

Asked in 2015–16 (20⅔ marks), 2017–18 (18) and 2021–22 (26⅔, a full derivation). Three numbers carry the whole topic: 29 and \(\sqrt6\) for the plain ladder, 8 and \(\sqrt3\) when buffers separate the sections. The derivation is long but mechanical, and the 2015–16 circuit has a twist (the last section is loaded) that most solutions miss.

1. The idea: 180° from the amplifier, 180° from the network

An inverting amplifier gives 180°. For a loop phase of 0° (360°), the RC network must give another 180° at \(\omega_0\). One RC section gives less than 90° (it only reaches 90° at zero or infinite frequency, where it passes nothing), so at least three sections are needed. The network attenuates; the amplifier gain must make up the loss.

2. Buffered sections: ω₀ = 1/(√3 RC), gain 8 (Sadat p.119–121, Khairul s.19–22)

The followers draw no current, so each section is an independent divider:

\[ \frac{V_1}{V_o} = \frac{R}{R + \frac{1}{j\omega C}} = \frac{j\omega RC}{1 + j\omega RC}, \qquad \beta(j\omega) = \Big(\frac{j\omega RC}{1 + j\omega RC}\Big)^3, \qquad A = -\frac{R_2}{R} \]

Expand \((1 + x)^3 = 1 + 3x + 3x^2 + x^3\) with \(x = j\omega RC\):

\[ \beta(j\omega) = \frac{-j\omega RC(\omega RC)^2}{(1 - 3\omega^2R^2C^2) + j\omega RC(3 - \omega^2R^2C^2)} \]

\(\angle A = 180^\circ\), so we need \(\angle\beta = 180^\circ\). The numerator is imaginary, so the real part of the denominator must vanish:

\[ 1 - 3\omega_0^2R^2C^2 = 0 \;\Rightarrow\; \omega_0 = \frac{1}{\sqrt3\,RC}, \qquad \beta(\omega_0) = \frac{-\frac13}{3 - \frac13} = -\frac18, \qquad \frac{R_2}{R} \ge 8 \]

Why "phase shift" (Sadat p.121, Khairul s.22): at \(\omega_0\), each section gives \(\dfrac{j/\sqrt3}{1 + j/\sqrt3} = \tfrac12\angle60^\circ\). Three of them: \(\tfrac18\angle180^\circ\). The inverting amplifier with gain 8 restores 1∠360°.

3. The unbuffered ladder: ω₀ = 1/(√6 RC), gain 29 (2021–22 derivation)

Now each section loads the previous one, so work backwards from the virtual ground with a current \(i\) in the last R. Let \(k = \dfrac{1}{sRC}\) (so a capacitor drops \(i\cdot kR\)):

  • Node c (third R): \(v_c = iR\). The third C carries \(i\): \(v_b = iR + ikR = iR(1 + k)\).
  • Second R carries \(v_b/R = i(1 + k)\); second C carries \(i + i(1 + k) = i(2 + k)\): \(v_a = v_b + i(2 + k)kR = iR(1 + 3k + k^2)\).
  • First R carries \(i(1 + 3k + k^2)\); first C carries \(i(2 + k) + i(1 + 3k + k^2) = i(3 + 4k + k^2)\): \(v_o = v_a + i(3 + 4k + k^2)kR\).
\[ v_o = iR\,(1 + 6k + 5k^2 + k^3), \qquad \text{amplifier output } = -R_f\,i \;\Rightarrow\; L = \frac{-R_f/R}{1 + 6k + 5k^2 + k^3} \]

At \(s = j\omega\), \(k = -jX\) with \(X = \dfrac{1}{\omega RC}\): \(k^2 = -X^2\), \(k^3 = jX^3\).

\[ 1 + 6k + 5k^2 + k^3 = (1 - 5X^2) + j(X^3 - 6X) \]

Phase: \(L\) must be real and positive, so the bracket must be real (and negative): \(X^2 = 6\), i.e. \(\omega_0 = \dfrac{1}{\sqrt6\,RC}\), \(f_0 = \dfrac{1}{2\pi\sqrt6\,RC}\).

Magnitude: bracket \(= 1 - 30 = -29\), so \(L = \dfrac{R_f}{29R} \ge 1\): \(\boxed{R_f \ge 29R}\) (i.e. \(\beta = -1/29\), \(|A| \ge 29\)).

Low-pass ladder (series R, shunt C, driven by an amplifier with high input resistance): by the same algebra with \(k = sRC\), \(\omega_0 = \sqrt6/(RC)\) and the gain is again 29.

Method · phase-shift analysis

  1. Identify the topology: buffers between sections? high-pass (series C) or low-pass (series R)? Is the last section loaded by the amplifier's input resistor?
  2. Write \(\beta\): a product of sections if buffered; work back from the virtual ground (or nodal analysis) if not.
  3. Inverting amplifier: \(\beta(\omega_0)\) must be real and negative. Set the imaginary part of the denominator (or of \(1/\beta\)) to zero → \(\omega_0\).
  4. \(|A| \ge 1/|\beta(\omega_0)|\) → \(R_f\) (or \(R_2\)) relation. Say "slightly greater" for start-up.
  5. Design: pick C, compute R from the \(\omega_0\) formula, then \(R_f\) from the gain.

4. Buffered, but the last section is loaded (2015–16)

First two sections: \(\dfrac{1}{1 + sRC}\) each. Third: \(Z_p = R_i \parallel \dfrac{1}{sC}\), so \(\dfrac{V_f}{V_{in3}} = \dfrac{Z_p}{R + Z_p} = \dfrac{1}{1 + R/R_i + sRC}\). With \(a = 1 + R/R_i\) and \(x = \omega RC\):

\[ L(j\omega) = -\frac{R_f}{R_i}\cdot\frac{1}{(1 + jx)^2(a + jx)}, \qquad (1 + jx)^2(a + jx) = \big[a(1 - x^2) - 2x^2\big] + j\big[x(1 - x^2) + 2ax\big] \]

Imaginary part zero: \(x^2 = 1 + 2a = 3 + 2R/R_i\). Real part there: \(a(-2a) - 2(1 + 2a) = -2(a + 1)^2\). So

\[ \omega_0 = \frac{\sqrt{3 + 2R/R_i}}{RC}, \qquad \frac{R_f}{R_i} \ge 2\Big(2 + \frac{R}{R_i}\Big)^2 \iff R_f \ge 8R_i + 8R + \frac{2R^2}{R_i} \]

With \(R_i = R\): \(\omega_0 = \sqrt5/(RC)\), \(R_f = 18R\). Only if \(R_i \gg R\) does it reduce to the textbook \(\sqrt3/(RC)\) and 8. Many solutions quote √3 and 8 here; write the exact result and say what it reduces to.

5. Transistor versions

Replace the op-amp by a single-transistor inverting stage: a common-source MOSFET (gain \(-g_mR_D\)) or common-emitter BJT (\(-g_mR_C\)). The ladder is unchanged, so the conditions are the same in the ideal case: \(\omega_0 = 1/(\sqrt6\,RC)\) and \(|A| = g_mR_D \ge 29\). Two practical corrections (state them, no need to compute unless asked): the stage's output resistance \(R_D\) adds to the first section, and for a BJT the base input resistance \(r_\pi \parallel R_B\) replaces (or is in parallel with) the last shunt R. A MOSFET's infinite gate resistance makes it the cleaner choice: take \(v_{gs}\) across the third R.

Traps (where marks go)

  • Using \(1/(2\pi\sqrt6RC)\) and 29 for a buffered circuit. Buffered = \(\sqrt3\) and 8.
  • Forgetting that the third R (into the virtual ground) is part of the network. Without it the ladder has only two shunt R's.
  • High-pass vs low-pass: \(\sqrt6\) (or \(\sqrt3\)) goes in the denominator for high-pass, numerator for low-pass.
  • Missing \(2\pi\) when the question asks for \(f_0\).
  • 2015–16: ignoring the loading of the last section by \(R_i\).
  • The amplifier must be inverting; β at \(\omega_0\) is negative.

Exam questions

2021–22 · Sec A · Q1(b) · 26⅔ marks

For an R-C phase shift oscillator, derive the expression of oscillation frequency. Also derive the conditions for Barkhausen criteria to be satisfied. You may assume that in the feedback part of the oscillator all the resistors are of the same value and all the capacitors are of the same value.

Show worked answer

Draw Figure 2: inverting amplifier (\(R_f\) feedback; + grounded); three C–R sections from the output, the third R being the amplifier's input resistor to the virtual ground. Barkhausen: \(A\beta = 1\) (magnitude 1, phase 0°). The amplifier gives 180°, so the network must give 180°.

Let \(i\) be the current into the virtual ground through the third R and \(k = 1/(sRC)\). Working back: \(v_c = iR\); \(v_b = iR(1 + k)\); current in second C \(= i(2 + k)\), \(v_a = iR(1 + 3k + k^2)\); current in first C \(= i(3 + 4k + k^2)\); \(v_o = iR(1 + 6k + 5k^2 + k^3)\).

The amplifier output (the new \(v_o\)) is \(-R_fi\). Loop gain: \(L = \dfrac{-R_f/R}{1 + 6k + 5k^2 + k^3}\).

With \(s = j\omega\), \(k = -j/(\omega RC)\): denominator \(= \Big[1 - \dfrac{5}{\omega^2R^2C^2}\Big] + j\Big[\dfrac{1}{\omega^3R^3C^3} - \dfrac{6}{\omega RC}\Big]\).

Frequency (phase condition): \(L\) real requires the imaginary part zero: \(\omega_0^2R^2C^2 = \dfrac16\), so \(\omega_0 = \dfrac{1}{\sqrt6\,RC}\), \(f_0 = \dfrac{1}{2\pi\sqrt6\,RC}\).

Gain (magnitude condition): at \(\omega_0\) the denominator is \(1 - 5\times6 = -29\), so \(\beta = -\dfrac{1}{29}\) and \(L = \dfrac{R_f}{29R}\). Barkhausen \(|L| = 1\) gives \(R_f = 29R\) (\(|A| = 29\)); for start-up \(R_f\) slightly greater than \(29R\), with amplitude limited by saturation or a limiter.

2017–18 · Sec B · Q6(c) · 18 marks

For the oscillator circuit shown (Figure 1: inverting amplifier with \(R_f\); three CR sections, each separated by a buffer; the third R returns to the amplifier's inverting input), find the oscillation frequency (ω), β-network gain (β) and amplifier gain (A). Also design this oscillator for an oscillation frequency of 1 kHz. Note: each stage is separated by a buffer, hence each stage gives a phase shift of 60° and three stages give a total of 180°. Here β = V₂/V₁. (The figure draws the buffers' feedback to the wrong input; read them as voltage followers.)

Show worked answer

Each section: \(\dfrac{j\omega RC}{1 + j\omega RC}\), phase \(90^\circ - \tan^{-1}(\omega RC)\). For 60° per stage: \(\tan^{-1}(\omega_0RC) = 30^\circ\), \(\omega_0RC = 1/\sqrt3\):

\(\omega_0 = \dfrac{1}{\sqrt3\,RC}\), \(f_0 = \dfrac{1}{2\pi\sqrt3\,RC}\).

Each stage's magnitude at \(\omega_0\): \(\dfrac{1/\sqrt3}{\sqrt{1 + 1/3}} = \dfrac12\). So \(\beta = V_2/V_1 = \big(\tfrac12\big)^3\angle180^\circ = -\dfrac18\).

\(A\beta = 1 \Rightarrow A = -8\), i.e. \(R_f/R = 8\) (slightly more to start).

Design for 1 kHz: \(RC = \dfrac{1}{2\pi\sqrt3\times1000} = 91.89\) µs. Choose C = 10 nF: R = 9.19 kΩ (use 9.1 kΩ); \(R_f = 8R = 73.5\) kΩ (use 75 kΩ, slightly above).

2015–16 · Sec B · Q7(b) · 20⅔ marks

For the RC phase-shift oscillator shown (Figure 3: inverting amplifier A1 with \(R_i\), \(R_f\), ±15 V; three R–C low-pass sections, the first two followed by voltage followers A2, A3, the third feeding \(V_f\) back through \(R_i\); all R equal, all C equal): (i) determine the oscillation frequency f₀ and obtain the relationship between \(R_i\) and \(R_f\) for sustained oscillation; (ii) how can you generate a 100 kHz signal from this oscillator?

Show worked answer

(i) Sections 1 and 2 are buffered: \(\dfrac{1}{1 + sRC}\) each. Section 3 is loaded by \(R_i\) (to the virtual ground): \(\dfrac{V_f}{V_{in3}} = \dfrac{1}{1 + R/R_i + sRC}\). Amplifier \(-R_f/R_i\).

\(L(j\omega) = \dfrac{-R_f/R_i}{(1 + jx)^2(a + jx)}\), \(x = \omega RC\), \(a = 1 + R/R_i\). The denominator is \([a(1 - x^2) - 2x^2] + j[x(3 + 2R/R_i - x^2)]\).

Imaginary part zero: \(x^2 = 3 + 2R/R_i\), so \(f_0 = \dfrac{\sqrt{3 + 2R/R_i}}{2\pi RC}\).

Real part at \(\omega_0\): \(-2(a + 1)^2 = -2(2 + R/R_i)^2\). Sustained oscillation: \(\dfrac{R_f}{R_i} = 2\Big(2 + \dfrac{R}{R_i}\Big)^2\), i.e. \(R_f = 8R_i + 8R + 2R^2/R_i\).

With \(R_i = R\): \(f_0 = \dfrac{\sqrt5}{2\pi RC}\), \(R_f = 18R_i\). (If \(R_i \gg R\), this reduces to the ideal buffered result \(f_0 = \sqrt3/(2\pi RC)\), \(R_f = 8R_i\).)

(ii) Choose RC for 100 kHz. With \(R_i = R\) and C = 100 pF: \(R = \dfrac{\sqrt5}{2\pi\times10^5\times10^{-10}} = 35.6\) kΩ, \(R_i\) = 35.6 kΩ, \(R_f = 18R = 641\) kΩ (slightly more to start). Use op-amps with enough gain-bandwidth and slew rate at 100 kHz (the ±15 V output swing at 100 kHz needs a slew rate above \(2\pi f V_p \approx 9\) V/µs), or tune frequency by changing C (ganged) since \(f_0 \propto 1/C\).
