The Wien-Bridge Oscillator (and Any "Find f₀ and the Start Condition" Circuit)

The Wien bridge was asked in 2012–13, 2013–14, 2014–15, 2019–20 (28⅔ marks, the general unequal-component derivation) and 2023–24 (17 marks, compulsory). It alternates with Colpitts as the "derive the oscillator" question. Your own CT-4 used the same method on a two-section RC/RL circuit. This chapter teaches the general derivation once, the equal-component shortcut, design, the limiter version, and the cascade method so that any unfamiliar oscillator can be done on a blank page.

1. Circuit and operating principle

A non-inverting amplifier \(A = 1 + R_2/R_1\) (0° phase) drives a lead-lag network: a series arm \(Z_S = R_A + 1/(sC_A)\) from the output to the + input, and a shunt arm \(Z_P = R_B \parallel C_B\) from the + input to ground (Sadat's notation).

  • Low frequencies: \(C_A\) is open, so \(\beta \to 0\) with a phase lead (+90°).
  • High frequencies: \(C_B\) shorts the + input, \(\beta \to 0\) with a phase lag (−90°).
  • At one frequency \(\omega_0\) in between, the phase is exactly 0°. The amplifier also has 0°, so the loop phase is 0° only there: that is the oscillation frequency. At \(\omega_0\) (equal parts) \(\beta = 1/3\), so the amplifier must supply a gain of at least 3.
  • Why "bridge" (Sadat p.119): \(Z_S\), \(Z_P\), \(R_2\), \(R_1\) form a four-arm bridge across the output, with the op-amp inputs across its middle. At \(\omega_0\) with gain exactly 3 the bridge is balanced.

2. General derivation (unequal parts: 2019–20, 28⅔ marks)

Write this as the exam answer. Break the loop at the + input (it draws no current, so \(Z_S\) and \(Z_P\) form a plain divider):

\[ Z_S = R_A + \frac{1}{sC_A} = \frac{1 + sR_AC_A}{sC_A}, \qquad Z_P = R_B \parallel \frac{1}{sC_B} = \frac{R_B}{1 + sR_BC_B} \]
\[ \begin{aligned} \beta(s) = \frac{Z_P}{Z_P + Z_S} &= \frac{sR_BC_A}{sR_BC_A + (1 + sR_AC_A)(1 + sR_BC_B)} \\ &= \frac{sR_BC_A}{(1 + s^2R_AR_BC_AC_B) + s(R_AC_A + R_BC_B + R_BC_A)} \end{aligned} \]
\[ A(j\omega)\beta(j\omega) = \Big(1 + \frac{R_2}{R_1}\Big)\frac{j\omega R_BC_A}{(1 - \omega^2R_AR_BC_AC_B) + j\omega(R_AC_A + R_BC_B + R_BC_A)} \]

Phase condition. The numerator is purely imaginary, so the phase is 0 when the real part of the denominator vanishes; then the \(j\omega\) cancels:

\[ 1 - \omega_0^2R_AR_BC_AC_B = 0 \;\Rightarrow\; \omega_0 = \frac{1}{\sqrt{R_AR_BC_AC_B}}, \qquad f_0 = \frac{1}{2\pi\sqrt{R_AR_BC_AC_B}} \]

Magnitude condition. At \(\omega_0\): \(\beta(\omega_0) = \dfrac{R_BC_A}{R_AC_A + R_BC_B + R_BC_A}\). Require \(A\beta(\omega_0) \ge 1\):

\[ 1 + \frac{R_2}{R_1} \ge \frac{R_AC_A + R_BC_B + R_BC_A}{R_BC_A} = 1 + \frac{R_A}{R_B} + \frac{C_B}{C_A} \;\Rightarrow\; \frac{R_2}{R_1} \ge \frac{R_A}{R_B} + \frac{C_B}{C_A} \]

In the 2019–20 labels (\(C_1\), \(R_1\) series; \(R_2 \parallel C_2\) shunt; gain \(A_V\)) this is exactly the "show that" in the paper: \(A_V \ge 1 + R_1/R_2 + C_2/C_1\). The question bank prints \(C_1/C_2\): a misprint. Derive the ratio from your own labels and you cannot get it wrong (the shunt capacitor is on top).

3. Equal parts: f₀ = 1/(2πRC), gain 3

With \(R_A = R_B = R\) and \(C_A = C_B = C\), divide through (Khairul s.16–17):

\[ \begin{gathered} L(j\omega) = \frac{1 + R_2/R_1}{3 + j\big(\omega RC - \frac{1}{\omega RC}\big)} \\ \omega_0 = \frac{1}{RC},\quad \beta(\omega_0) = \frac{1}{3},\quad 1 + \frac{R_2}{R_1} \ge 3 \iff R_2 \ge 2R_1 \end{gathered} \]

Choose \(R_2/R_1\) slightly greater than 2 (e.g. 2.03 to 2.1) so oscillation starts, and limit the amplitude (Section 4). Exactly 2 only sustains an oscillation that already exists; much more than 2 gives a clipped, distorted sine.

Method · Wien analysis

  1. Identify the series arm (\(R_A, C_A\)) and shunt arm (\(R_B \parallel C_B\)), and the amplifier gain \(1 + R_2/R_1\).
  2. \(f_0 = 1/(2\pi\sqrt{R_AR_BC_AC_B})\) (equal parts: \(1/(2\pi RC)\)). If \(\omega\) is asked, do not divide by \(2\pi\).
  3. \(1/\beta(\omega_0) = 1 + R_A/R_B + C_B/C_A\) (equal parts: 3).
  4. Start condition: \(R_2/R_1 \ge R_A/R_B + C_B/C_A\) (equal: \(R_2 \ge 2R_1\)), "slightly greater" in practice.

Method · Wien design for a given f₀ (or ω₀)

  1. Choose equal parts. Pick a standard \(C\) (1 nF to 1 µF) so that \(R = 1/(2\pi f_0C)\) lands between about 1 kΩ and 100 kΩ (small R loads the op-amp; huge R is noisy and comparable to op-amp input resistance).
  2. \(R = 1/(2\pi f_0 C)\) (or \(R = 1/(\omega_0C)\)).
  3. Gain: \(R_1 = 10\) kΩ, \(R_2 = 20\) kΩ for exactly 3; state "\(R_2\) slightly above 20 kΩ (e.g. 21 kΩ) plus a diode limiter" for reliable start-up.
  4. State \(\beta(\omega_0) = 1/3\) if asked for "the gain of the feedback network".

4. Amplitude stabilisation: Wien with a diode limiter (Sedra Fig. 18.6, Khairul s.18)

Set \(R_2/R_1\) a little above 2 so the poles sit just in the right half-plane; the oscillation grows until the diodes start to conduct and reduce the effective gain. With the limiter, the output is a clean sine of predictable amplitude.

Poles. \(1 - L(s) = 0\) with \(L = \dfrac{1 + R_2/R_1}{3 + sCR + 1/(sCR)}\) gives \((sCR)^2 - (A - 3)(sCR) + 1 = 0\). With \(A = 3.03\): \(sCR = 0.015 \pm j\,0.9999\), i.e. \(s = \frac{10^5}{16}(0.015 \pm j)\): right half-plane, so it grows.

Amplitude. In steady state at \(\omega_0\), the + input is \(v_O/3\), and the − input \(v_1\) equals it. \(D_2\) turns on at the positive peak when \(v_b = v_1 + V_D\), where \(v_b = v_O\frac{R_6}{R_5 + R_6} - 15\frac{R_5}{R_5 + R_6}\):

\[ 0.75\,\hat v_O - 3.75 = \frac{\hat v_O}{3} + 0.7 \;\Rightarrow\; \hat v_O = \frac{4.45}{0.4167} = 10.68\text{ V} \;\Rightarrow\; 21.36\text{ V peak-to-peak} \]

5. The general method for any "find f₀ and the start condition" circuit (your CT-4)

CT-4 gave a circuit you had not seen: two passive first-order sections, each followed by an op-amp (a voltage follower after the first, a non-inverting amplifier \(K = 1 + R_2/R_1\) after the second), with \(V_o\) fed back to the start. Because each section feeds an op-amp input (no current), the sections do not load each other and the loop gain is just a product.

Section (series → shunt)Transfer functionTime constantType
R series, C shunt\(\dfrac{1}{1 + s\tau}\)\(\tau = RC\)low-pass
C series, R shunt\(\dfrac{s\tau}{1 + s\tau}\)\(\tau = RC\)high-pass
R series, L shunt\(\dfrac{s\tau}{1 + s\tau}\)\(\tau = L/R\)high-pass
L series, R shunt\(\dfrac{1}{1 + s\tau}\)\(\tau = L/R\)low-pass

Method · cascade of buffered sections

  1. Write each section's transfer function from the table (a divider: shunt / (series + shunt)). Multiply by the amplifier gains: \(L(s) = K\,H_1(s)H_2(s)\).
  2. Set \(s = j\omega\). One low-pass and one high-pass: \(L = \dfrac{K\,j\omega\tau_{HP}}{(1 - \omega^2\tau_1\tau_2) + j\omega(\tau_1 + \tau_2)}\). Numerator imaginary → real part of the denominator = 0: \(\omega_0 = 1/\sqrt{\tau_1\tau_2}\) (the geometric mean of the two corner frequencies).
  3. At \(\omega_0\): \(L = K\,\tau_{HP}/(\tau_1 + \tau_2)\). Start: \(K > 1 + \tau_{LP}/\tau_{HP}\).
  4. Unfamiliar or loaded network? Do nodal analysis for \(\beta(j\omega)\) instead, then the same two conditions. Or write the characteristic equation \(1 - L(s) = 0\) as a polynomial: oscillation at \(s = j\omega_0\) needs the \(s^1\) coefficient to be zero (sustain) or negative (start), and \(\omega_0^2\) = (constant term)/(\(s^2\) coefficient).

Set A: \(\tau_1 = R_AC_A\) (low-pass), \(\tau_2 = L_B/R_B\) (high-pass).

\[ \begin{gathered} L(s) = \frac{K s\tau_2}{(1 + s\tau_1)(1 + s\tau_2)},\quad \omega_0 = \frac{1}{\sqrt{\tau_1\tau_2}} = \sqrt{\frac{R_B}{R_AC_AL_B}} \\ K > 1 + \frac{\tau_1}{\tau_2} \iff \frac{R_2}{R_1} > \frac{R_AR_BC_A}{L_B} \end{gathered} \]

Set B: \(\tau_1 = R_AC_A\) (high-pass), \(\tau_2 = L_B/R_B\) (low-pass). Same \(\omega_0\); the roles swap:

\[ \begin{gathered} L(s) = \frac{K s\tau_1}{(1 + s\tau_1)(1 + s\tau_2)},\quad \omega_0 = \sqrt{\frac{R_B}{R_AC_AL_B}} \\ K > 1 + \frac{\tau_2}{\tau_1} \iff \frac{R_2}{R_1} > \frac{L_B}{R_AR_BC_A} \end{gathered} \]

Pole check (why ">" is the start condition): \(1 - L = 0\) gives \(\tau_1\tau_2s^2 + (\tau_1 + \tau_2 - K\tau_{HP})s + 1 = 0\); the poles cross into the right half-plane exactly when \(K\tau_{HP} > \tau_1 + \tau_2\). With \(\tau_1 = \tau_2\) the minimum gain is 2 (compare Wien's 3, where the two sections load each other).

Variants. The 2015–16 paper (Q7(a), 26 marks) used a Wien-type ladder with inductors (series L, shunt \(R_1\), then \(R_2\), shunt L); it is worked in Chapter 4 by the same nodal method. The assignment's RL oscillator with an op-amp integrator-like stage is in the class-test block below.

Traps (where marks go)

  • ω versus f: "ω₀ = 1000 rad/s" means \(RC = 1\) ms, no \(2\pi\).
  • The amplifier is non-inverting (gain \(1 + R_2/R_1\), not \(R_2/R_1\)). "Gain 3" means \(R_2 = 2R_1\).
  • Unequal parts: \(R_2/R_1 \ge R_A/R_B + C_B/C_A\). The capacitor ratio is shunt over series; the bank's \(C_1/C_2\) is a misprint.
  • Say both: exactly 3 to sustain, slightly more than 3 to start, plus amplitude control.
  • In CT-4-type circuits the minimum gain is \(1 + \tau_{LP}/\tau_{HP}\): put the low-pass time constant on top. Swapping them is the classic Set A / Set B mistake.

Exam questions

2023–24 · Sec B · Q5(a) · 17 marks · compulsory

Define Barkhausen criterion. Describe the operating principle of an op-amp based Wien bridge oscillator. Derive the conditions for the Barkhausen criterion to be satisfied in this oscillator and the expression of oscillation frequency.

Show worked answer

Barkhausen criterion. For an amplifier \(A\) with positive feedback through \(\beta\), \(A_f = A/(1 - A\beta)\). The circuit oscillates at \(\omega_0\) (finite output, zero input) when \(A(j\omega_0)\beta(j\omega_0) = 1\): \(|A\beta| = 1\) and \(\angle A\beta = 0^\circ\) (360°). In practice \(|A\beta|\) is made slightly greater than 1 for start-up, with non-linear amplitude limiting.

Circuit and principle. Draw Figure 1 with equal parts: non-inverting amplifier \(A = 1 + R_2/R_1\); series \(R\)–\(C\) from output to the + input; parallel \(R \parallel C\) from the + input to ground. The RC network is a lead-lag (band-pass) network: lead at low frequency, lag at high frequency, zero phase at one frequency. Since the amplifier has 0° phase, the loop phase is 0° only there, so the circuit oscillates at that frequency; the amplifier gain makes up the network's loss of 3.

Derivation. \(Z_s = R + \dfrac{1}{sC}\), \(Y_p = \dfrac{1}{R} + sC\). \(\beta = \dfrac{Z_p}{Z_p + Z_s} = \dfrac{1}{1 + Z_sY_p} = \dfrac{1}{3 + sCR + \frac{1}{sCR}}\).

\(L(j\omega) = \dfrac{1 + R_2/R_1}{3 + j\big(\omega CR - \frac{1}{\omega CR}\big)}\).

Phase condition: imaginary part zero, \(\omega_0CR = \dfrac{1}{\omega_0CR}\), so \(\omega_0 = \dfrac{1}{RC}\), \(f_0 = \dfrac{1}{2\pi RC}\).

Magnitude condition: at \(\omega_0\), \(\beta = 1/3\), so \(1 + R_2/R_1 = 3\), i.e. \(R_2 = 2R_1\) to sustain; \(R_2/R_1\) slightly greater than 2 to start, with a diode limiter (or the op-amp's saturation) to hold the amplitude.

(General case, for full marks if you have time: \(\omega_0 = 1/\sqrt{R_AR_BC_AC_B}\) and \(R_2/R_1 \ge R_A/R_B + C_B/C_A\), Section 2.)

2019–20 (exam held January 2021) · Sec B · Q7(a) · 28⅔ marks

Consider the circuit of resistors, capacitors and an op-amp in the figure (C₁ and R₁ in series from \(v_o\) to the + input; R₂ ∥ C₂ from the + input to ground; R₃ from \(v_o\) to the − input; R₄ from the − input to ground). (i) What conditions must hold for it to operate as a sinusoidal oscillator? (ii) Derive the oscillation frequency. (iii) The op-amp with R₃ and R₄ forms a non-inverting amplifier of gain \(A_V\); show that \(A_V \ge 1 + R_1/R_2 + C_2/C_1\) for sustained oscillation. (iv) If R₁ = R₂ = 10 kΩ and C₁ = C₂ = 0.1 µF, design R₃ and R₄ so that oscillation sustains.

Show worked answer

(i) Barkhausen: the loop gain \(A_V\beta(j\omega_0) = 1\), i.e. \(|A_V\beta| = 1\) and total loop phase 0° (360°) at one frequency \(\omega_0\); for start-up \(|A_V\beta|\) slightly greater than 1, with amplitude limiting.

(ii) \(Z_1 = R_1 + \dfrac{1}{sC_1}\), \(Z_2 = \dfrac{R_2}{1 + sR_2C_2}\). \(\dfrac{1}{\beta} = 1 + \dfrac{Z_1}{Z_2} = 1 + \Big(R_1 + \dfrac{1}{sC_1}\Big)\Big(\dfrac{1}{R_2} + sC_2\Big)\)

\(= 1 + \dfrac{R_1}{R_2} + \dfrac{C_2}{C_1} + sR_1C_2 + \dfrac{1}{sR_2C_1}\). At \(s = j\omega\): \(\dfrac{1}{\beta} = 1 + \dfrac{R_1}{R_2} + \dfrac{C_2}{C_1} + j\Big(\omega R_1C_2 - \dfrac{1}{\omega R_2C_1}\Big)\).

The amplifier has 0° phase, so \(\beta\) must be real: \(\omega_0R_1C_2 = \dfrac{1}{\omega_0R_2C_1}\), giving \(\omega_0 = \dfrac{1}{\sqrt{R_1R_2C_1C_2}}\), \(f_0 = \dfrac{1}{2\pi\sqrt{R_1R_2C_1C_2}}\).

(iii) At \(\omega_0\): \(\beta = \dfrac{1}{1 + R_1/R_2 + C_2/C_1}\). Sustained oscillation needs \(A_V\beta \ge 1\): \(A_V = 1 + \dfrac{R_3}{R_4} \ge 1 + \dfrac{R_1}{R_2} + \dfrac{C_2}{C_1}\). (Shown.)

(iv) \(f_0 = \dfrac{1}{2\pi\sqrt{10^4\cdot10^4\cdot10^{-7}\cdot10^{-7}}} = \dfrac{1}{2\pi\times10^{-3}} = 159.2\) Hz. \(A_V \ge 1 + 1 + 1 = 3\), so \(R_3 \ge 2R_4\). Choose \(R_4\) = 10 kΩ, \(R_3\) = 20 kΩ (sustain); in practice \(R_3\) ≈ 21 kΩ (slightly above 2R₄) with a diode limiter for start-up and a clean amplitude.

2014–15 · Sec B · Q8(a) · 20 marks (17 + 3)

Design a Wien bridge oscillator with an oscillation frequency of 1 kHz. What is the gain of the feedback network of your design? Specify all values of resistors and capacitors used.

Show worked answer

Draw Figure 1 with equal parts. \(f_0 = 1/(2\pi RC)\).

Choose \(C\) = 10 nF: \(R = \dfrac{1}{2\pi\times1000\times10^{-8}} = 15.92\) kΩ (use 15.9 kΩ, or 16 kΩ giving 995 Hz).

Feedback network gain at \(f_0\): \(\beta = V_f/V_o = 1/3\) (phase 0°).

Amplifier: \(A = 1 + R_2/R_1 \ge 3\). \(R_1\) = 10 kΩ, \(R_2\) = 20 kΩ (to sustain); choose \(R_2\) slightly larger, e.g. 21 kΩ, so oscillation starts, and add a diode limiter (or rely on saturation) to fix the amplitude.

Final values: \(R_A = R_B\) = 15.9 kΩ, \(C_A = C_B\) = 10 nF, \(R_1\) = 10 kΩ, \(R_2\) = 20 kΩ (≈ 21 kΩ for start-up). Check: \(f_0 = 1/(2\pi\times15.9\text{k}\times10\text{n}) = 1.00\) kHz.

2013–14 · Sec B · Q6(a) · 16⅔ marks

Design a Wien-bridge oscillator with an oscillation frequency of 1000 rad/s. Available capacitors are 0.1 µF, 1 µF and 100 pF.

Show worked answer

\(\omega_0 = 1/(RC) = 1000\) rad/s, so \(RC = 1\) ms (ω is given: no \(2\pi\)).

Try each capacitor: 0.1 µF → \(R\) = 10 kΩ; 1 µF → \(R\) = 1 kΩ (heavy load on the op-amp output); 100 pF → \(R\) = 10 MΩ (too large: comparable to stray and input resistances, noisy). Choose C = 0.1 µF, R = 10 kΩ.

Gain: \(1 + R_2/R_1 \ge 3\): \(R_1\) = 10 kΩ, \(R_2\) = 20 kΩ (slightly more, e.g. 21 kΩ, for reliable start-up, with a limiter). \(f_0 = 1000/2\pi = 159\) Hz.

2012–13 · Sec B · Q8(a) · 17 marks

Draw a Wien-bridge oscillator circuit and describe its operating principle.

Show worked answer

Draw Figure 1 (equal R and C). Principle, in points:

1. It is a positive-feedback loop: non-inverting amplifier \(A = 1 + R_2/R_1\) (phase 0°) and the RC lead-lag network \(\beta\) feeding the + input.

2. The network gives a phase lead at low frequency and a lag at high frequency; at \(f_0 = 1/(2\pi RC)\) its phase is 0° and \(\beta = 1/3\). Only at this frequency is the loop phase 0°, so only this frequency is sustained (Barkhausen).

3. Magnitude: \(A\beta = 1\) needs \(A = 3\), i.e. \(R_2 = 2R_1\). For start-up \(R_2\) is made slightly larger than \(2R_1\): noise at \(f_0\) grows.

4. Amplitude is stabilised by a non-linear element: diode limiter across the feedback (Sedra), a lamp/thermistor in \(R_1\)/\(R_2\), or a JFET as a variable resistor (AGC), which reduces the gain to exactly 3 at the final amplitude.

5. The four arms \(Z_s\), \(Z_p\), \(R_2\), \(R_1\) form a bridge across the output with the op-amp inputs across its diagonal; it balances at \(f_0\) with gain 3. Used for audio-frequency sine generators (low distortion, easy tuning with a ganged capacitor).

Class tests and assignment

CT-4 (your batch, Jan 2026) · Set A (odd IDs)

Assuming ideal op-amps in the given oscillator (Figure 3: \(R_A\) series and \(C_A\) shunt, voltage follower, \(R_B\) series and \(L_B\) shunt, non-inverting amplifier with \(R_1\), \(R_2\), output fed back to the input), find (i) the frequency of oscillation, (ii) the condition for oscillation to start.

Show worked answer

The follower and the ideal + input draw no current, so the sections do not load each other. Let \(\tau_1 = R_AC_A\), \(\tau_2 = L_B/R_B\), \(K = 1 + R_2/R_1\).

\(H_1 = \dfrac{1}{1 + s\tau_1}\) (RC low-pass), \(H_2 = \dfrac{sL_B}{R_B + sL_B} = \dfrac{s\tau_2}{1 + s\tau_2}\) (RL high-pass). \(L(s) = \dfrac{Ks\tau_2}{(1 + s\tau_1)(1 + s\tau_2)}\).

\(L(j\omega) = \dfrac{Kj\omega\tau_2}{(1 - \omega^2\tau_1\tau_2) + j\omega(\tau_1 + \tau_2)}\). Numerator imaginary, so phase 0 needs \(1 - \omega_0^2\tau_1\tau_2 = 0\):

(i) \(\omega_0 = \dfrac{1}{\sqrt{\tau_1\tau_2}} = \sqrt{\dfrac{R_B}{R_AC_AL_B}}\), \(f_0 = \dfrac{1}{2\pi}\sqrt{\dfrac{R_B}{R_AC_AL_B}}\).

(ii) At \(\omega_0\): \(L = \dfrac{K\tau_2}{\tau_1 + \tau_2}\). Start: \(L > 1 \Rightarrow 1 + \dfrac{R_2}{R_1} > 1 + \dfrac{\tau_1}{\tau_2} \Rightarrow \dfrac{R_2}{R_1} > \dfrac{R_AR_BC_A}{L_B}\) (equality just sustains).

CT-4 (your batch, Jan 2026) · Set B (even IDs)

Same question for Figure 4: \(C_A\) series and \(R_A\) shunt, voltage follower, \(L_B\) series and \(R_B\) shunt, non-inverting amplifier \(K = 1 + R_2/R_1\).

Show worked answer

\(H_1 = \dfrac{s\tau_1}{1 + s\tau_1}\) (CR high-pass, \(\tau_1 = R_AC_A\)), \(H_2 = \dfrac{R_B}{R_B + sL_B} = \dfrac{1}{1 + s\tau_2}\) (LR low-pass, \(\tau_2 = L_B/R_B\)).

\(L(j\omega) = \dfrac{Kj\omega\tau_1}{(1 - \omega^2\tau_1\tau_2) + j\omega(\tau_1 + \tau_2)}\).

(i) Same frequency: \(\omega_0 = \sqrt{\dfrac{R_B}{R_AC_AL_B}}\).

(ii) At \(\omega_0\): \(L = \dfrac{K\tau_1}{\tau_1 + \tau_2} > 1 \Rightarrow \dfrac{R_2}{R_1} > \dfrac{\tau_2}{\tau_1} = \dfrac{L_B}{R_AR_BC_A}\).

Numerical check (\(R_A\) = 1 kΩ, \(C_A\) = 0.1 µF, \(R_B\) = 2 kΩ, \(L_B\) = 50 mH): \(\omega_0\) = 20 krad/s (3.18 kHz); minimum \(K\) = 5 for Set A, 1.25 for Set B.

Assignment Q10 (EEE 263 assignment, same set as EDC 2-1) · op-amp oscillator with inductors

Find the oscillation frequency and the condition for sustained oscillation. Op-amp 1: + grounded, − input node \(n_1\), feedback inductor \(L\) from \(n_1\) to its output \(v_f\). Network: \(L\) from \(v_o\) to node \(v_1\); \(R\) from \(v_1\) to \(n_1\); \(R\) from \(v_1\) to \(v_f\). Op-amp 2 is inverting: \(R_1\) from \(v_f\) to its − input, \(R_2\) to its output \(v_o\).

Show worked answer

The two stages load each other through node \(v_1\), so use nodal analysis and the characteristic equation.

Op-amp 1 (virtual ground at \(n_1\)): \(v_1/R = -v_f/(sL)\), so \(v_1 = -\dfrac{R}{sL}v_f\). Op-amp 2: \(v_o = -Kv_f\) with \(K = R_2/R_1\).

KCL at \(v_1\): \(\dfrac{v_o - v_1}{sL} = \dfrac{v_1}{R} + \dfrac{v_1 - v_f}{R}\). Substitute and multiply by \(s^2L^2R/v_f\):

\(s^2L^2 + sLR(2 - K) + R^2 = 0\).

Poles on the \(j\omega\) axis need the \(s\) term to vanish: \(K = R_2/R_1 = 2\). Then \(s^2 = -R^2/L^2\): \(\omega_0 = R/L\), \(f_0 = R/(2\pi L)\). For start-up \(R_2 > 2R_1\) (poles move into the right half-plane).

Practice

Key terms

Quick check

Summary: Wien = non-inverting amplifier + lead-lag network. General: \(\omega_0 = 1/\sqrt{R_AR_BC_AC_B}\), \(R_2/R_1 \ge R_A/R_B + C_B/C_A\). Equal parts: \(f_0 = 1/(2\pi RC)\), \(\beta = 1/3\), \(R_2 = 2R_1\) (slightly more to start, limiter for amplitude). Design: pick C so R is 1–100 kΩ, then \(R = 1/(2\pi f_0C)\). For any new circuit: break the loop, multiply buffered sections (or do nodal analysis), phase 0 → \(\omega_0\), \(|L(\omega_0)| \ge 1\) → gain. For one LP and one HP buffered section: \(\omega_0 = 1/\sqrt{\tau_1\tau_2}\), \(K > 1 + \tau_{LP}/\tau_{HP}\).
