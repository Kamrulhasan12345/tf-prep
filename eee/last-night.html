Diodes

Exponential\(i = I_S(e^{v/nV_T} - 1)\); \(V_2 - V_1 = nV_T\ln(I_2/I_1) = 2.3nV_T\log_{10}(I_2/I_1)\) (≈ 60n mV per decade)
Small signal\(r_d = nV_T/I_D\); valid for \(v_d \ll nV_T\) (≈ 5–10 mV)
Temperature\(dV_D/dT \approx -2\) mV/°C at constant current; \(I_S\) doubles every 5 °C (≈ 15 %/°C); thermal resistance \(\theta = \Delta T/P\) (°C/W), \(P = I V_D\) in the final state
Zener\(V_Z = V_{Z0} + r_zI_Z\); line reg \(r_z/(R + r_z)\); load reg \(-\Delta I_L(r_z\parallel R)\); \(R_{L,min}\): \(I_Z = I_{ZK}\) at lowest supply
Half-wave\(V_{o,peak} = V_s - V_{D0}\); \(V_{avg} \approx (V_s - V_{D0})/\pi\); PIV = \(V_s\); conduction from \(\theta = \sin^{-1}(V_{D0}/V_s)\) to \(\pi - \theta\)
Full-wave (centre tap)\(V_{avg} \approx 2(V_s - V_{D0})/\pi\); PIV = \(2V_s - V_{D0}\)
Bridge\(V_{o,peak} = V_s - 2V_{D0}\); \(V_{avg} \approx 2(V_s - 2V_{D0})/\pi\); PIV = \(V_s - V_{D0}\)
Peak rectifier, half-wave\(V_r = \dfrac{V_p}{fCR}\); \(\omega\Delta t = \sqrt{2V_r/V_p}\); \(i_{D,av} = I_L(1 + \pi\sqrt{2V_p/V_r})\); \(i_{D,max} = I_L(1 + 2\pi\sqrt{2V_p/V_r})\)
Peak rectifier, full-wave / bridge\(V_r = \dfrac{V_p}{2fCR}\); \(i_{D,av} = I_L(1 + \pi\sqrt{V_p/2V_r})\); \(i_{D,max} = I_L(1 + 2\pi\sqrt{V_p/2V_r})\); \(V_{dc} \approx V_p - V_r/2\); \(I_L \approx V_{dc}/R\) (or \(V_p/R\))
ClamperNeeds \(RC \gg T\); the capacitor charges to the peak (minus any bias and \(V_{D0}\)); output = input shifted by that DC level

BJT

Large signal\(i_C = I_Se^{v_{BE}/V_T}\); \(i_C = \beta i_B = \alpha i_E\); \(\alpha = \beta/(\beta+1)\); \(i_E = (\beta+1)i_B\)
Modes (npn)Active: BE forward, \(V_{CE} \ge 0.3\) V (Sedra: \(V_{CB} \ge 0\)). Saturation: \(V_{CE} = 0.2\) V, \(\beta_{forced} = I_C/I_B < \beta\). Cutoff: \(V_{BE} < 0.5\) V
Bias loop\(I_E = \dfrac{V_{TH} - V_{BE}}{R_E + R_{TH}/(\beta+1)}\); stable if \(R_E \gg R_{TH}/(\beta+1)\)
Early effect\(r_o = V_A/I_C\) = 1/slope of \(i_C\)–\(v_{CE}\); \(i_C = I_Se^{v_{BE}/V_T}(1 + v_{CE}/V_A)\)
Small-signal\(g_m = I_C/V_T\); \(r_\pi = \beta/g_m\); \(r_e = \alpha/g_m \approx V_T/I_E\); \(r_\pi = (\beta+1)r_e\); valid for \(v_{be} \ll V_T\)
CE\(R_{in} = R_B\parallel r_\pi\); \(A_{vo} = -g_m(R_C\parallel r_o)\); \(R_o = R_C\parallel r_o\); \(G_v = -\dfrac{R_{in}}{R_{in} + R_{sig}}\,g_m(R_C\parallel R_L\parallel r_o)\)
CE with \(R_e\)\(R_{in} = (\beta+1)(r_e + R_e)\); \(A_{vo} = -\dfrac{\alpha R_C}{r_e + R_e}\); \(R_o = R_C\); \(G_v = -\dfrac{\beta(R_C\parallel R_L)}{R_{sig} + (\beta+1)(r_e + R_e)}\)
CB\(R_{in} = r_e\); \(A_{vo} = \alpha R_C/r_e = g_mR_C\); \(R_o = R_C\); \(G_v = \dfrac{\alpha(R_C\parallel R_L)}{R_{sig} + r_e}\) (positive)
CC (follower)\(R_{in} = (\beta+1)(r_e + R_L')\), \(R_L' = R_E\parallel R_L\parallel r_o\); \(A_{vo} \approx 1\); \(R_o = r_e + R_{sig}/(\beta+1)\) (∥ \(R_E\)); \(G_v = \dfrac{R_L'}{R_L' + r_e + R_{sig}/(\beta+1)}\)

4. Traps

Where marks go

  • Bridge rectifier: two diode drops, not one; PIV is \(V_s - V_{D0}\) for a bridge but \(2V_s - V_{D0}\) for a centre-tap.
  • Peak rectifier: half-wave and full-wave formulas differ by the factor 2 in \(V_r\) and in the \(\sqrt{\;}\) terms.
  • Zener: \(V_{Z0}\), not \(V_{ZT}\), in the KVL; ON check before anything else when a load is present.
  • Diode thermal: \(\Delta V = 0.7 - 0.58 = 0.12\) V (one circulating solution writes 0.22 V and gets 110 °C instead of 60 °C).
  • BJT: \(I_E\) vs \(I_C\) mixed up in the collector KVL; forgetting to check the mode; pnp signs.
  • MOSFET: \(k_n'\) vs \(k_n = k_n'W/L\); Sedra's ½ vs Neamen's \(K\) (state which); keeping the negative \(V_{OV}\) root.
  • Op-amp integrator with an uncharged capacitor: the output has a DC term (sin → −cos + 1, not −cos).
  • 555 with D < 50 %: the plain astable cannot do it; add the steering diode.
  • Gains in dB vs V/V; \(f\) vs \(\omega\) (\(2\pi\)); \(\mu\)F vs mF typos.
