How to Use This Book

EEE 263 marks come from numericals. Reading a solution feels like learning, but in the exam the page is blank. This book is built so that you produce answers yourself: every problem type has a recipe, a worked example you uncover one line at a time, and a practice box with fresh numbers every time you press the button.

1. The loop for one problem type (about 25 minutes)

The loop

  1. Recognise (1 min). Read the "How to spot it" line. In the exam, naming the type is half the battle: once you know it is a "Zener regulator, find the R range" question, you know the five steps.
  2. Recipe (3 min). Read the numbered method box. Say each step out loud in your own words.
  3. Worked example (5 min). Press "Reveal step" one line at a time. Before each reveal, write what you think the next line is. Where a step asks for a value, type it first. Being wrong here is cheap and is exactly what makes it stick.
  4. Guided practice (5 min). In the practice box, press "Guided steps" and fill in each intermediate value.
  5. Solo practice (10 min). Press "New problem", solve on paper, type the final values, press Check. Three in a row without opening the solution marks the type mastered ★. Your progress is saved in this browser and shown on the problem-type atlas.
  6. Past paper. Do the matching past question under the chapter, timed (about 1.5 minutes per mark is the exam pace: a 15-mark part in about 20 minutes, writing included).

2. Why this works

  • Retrieval beats rereading. Producing an answer, even a wrong one, strengthens memory far more than reading the same solution again.
  • Faded examples. Fully worked → partly worked (guided) → solo is the fastest route from "I follow it" to "I can do it".
  • Varied numbers. A fixed example can be memorised; random values force the method. If you can solve five random versions, the exam version is the sixth.
  • Mixing. Once several types are mastered, use the mixed practice on the atlas page: choosing which recipe to use is a skill the exam tests and single-topic practice does not.
  • Spacing. Come back to a mastered type a day later and do one solo problem. If it fails, the streak resets: that is the signal to redo the loop.

3. Answer format that collects method marks

Examiners mark the method, not only the final number. A script that earns full marks usually has:

  1. A redrawn, labelled circuit (node names, currents with directions, assumed states).
  2. The assumption stated: "Assume D₁ on, D₂ off" / "Assume Q₁ active" / "Assume saturation".
  3. Equations written symbolically first, then numbers, then the result with a unit.
  4. The verification line: "I_D₁ = 1.2 mA > 0 ✓, V_D₂ = −3 V < 0 ✓, so the assumption holds."
  5. Final answers boxed or underlined.

5. Typing answers

Each answer box shows its unit. Type a bare number in that unit (4.36 in a box marked mA), or add your own prefix or unit: 4.36m, 4.36 mA, 0.00436 A and 4.36e-3 are all accepted. Answers within 2% are marked correct, so ordinary rounding is fine.

Summary: recognise → recipe → uncover the worked example line by line, predicting each line → guided practice → three solo in a row → timed past paper → one more solo tomorrow. Write assumptions and verification lines in every answer.
