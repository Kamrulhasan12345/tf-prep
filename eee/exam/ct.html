CT-1: Diodes (20 marks, Section A)

CT-1 · Jan 2026 · Q1 · part of a 20-mark CT

Using the small-signal model, find an expression for the current \(i_o\) if \(I_x = 5 + 0.1\cos\omega t\) mA. The diode follows the exponential model with \(I_s = 0.1\) pA.

Full solution

Units: mA, kΩ, V. \(V_T = 25.9\) mV (as in the scanned script; Sadat sir's notes use it). Values for \(V_T = 25\) mV are given in brackets.

1. DC analysis. Set the ac part to zero, so \(I_x = 5\) mA. KCL at A:

\[ 5 = \frac{V_D}{1} + I_s e^{V_D/V_T}\quad(\text{mA}) \]

Solve by iteration: \(V_D = V_T\ln(I_D/I_s)\) with \(I_D = 5 - V_D/1\).

  • Start \(V_D = 0.7\): \(I_D = 4.3\) mA, \(V_D = 0.0259\ln\dfrac{4.3\times10^{-3}}{10^{-13}} = 0.63415\) V.
  • \(I_D = 5 - 0.63415 = 4.36585\) mA, \(V_D = 0.63454\) V.
  • \(I_D = 4.36546\) mA, \(V_D = 0.63454\) V (converged).

So \(V_D = 0.6345\) V [0.6126 V], \(I_R = 0.6345\) mA [0.6126 mA] and \(I_D = 5 - 0.6345 = 4.3655\) mA [4.3874 mA].

2. Small-signal resistance. \(r_d = \dfrac{V_T}{I_D} = \dfrac{25.9\text{ mV}}{4.3655\text{ mA}} = 5.933\ \Omega\) [5.698 Ω].

3. AC analysis. Replace the diode by \(r_d\). The ac source \(0.1\cos\omega t\) mA splits between 1 kΩ and \(r_d\) (current divider):

\[ i_{o,ac} = 0.1\cos\omega t\cdot\frac{r_d}{1000 + r_d} = 0.1\times\frac{5.933}{1005.933}\cos\omega t = 5.90\times10^{-4}\cos\omega t\ \text{mA} \]

4. Total.

\[ i_o = 0.6345 + 5.90\times10^{-4}\cos\omega t\ \text{mA} = 0.6345\text{ mA} + 0.590\cos\omega t\ \mu\text{A} \]

With \(V_T = 25\) mV: \(i_o = 0.6126 + 5.67\times10^{-4}\cos\omega t\) mA. Either value of \(V_T\) gets full marks if you state it.

Slip in the scanned script

The scanned answer script (which scored 20) wrote \(I_D = 4.3589\) mA. The correct value is 4.3655 mA with \(V_T = 25.9\) mV (4.3874 mA with 25 mV). The slip is only in the 4th significant digit, so \(r_d\) and the final answer barely change (5.942 Ω and \(5.91\times10^{-4}\) mA instead of 5.933 Ω and \(5.90\times10^{-4}\) mA). Keep 4–5 digits through the iteration so this does not happen to you.

CT-1 · Jan 2026 · Q2 · part of a 20-mark CT · teacher's variant of Sedra P4.9

The diodes have \(V_D = 0.7\) V (constant-voltage-drop model). Find the range of \(R_x\) for which only one diode turns on. Which diode is it? Justify your answer.

Teacher's priority: very important

Next to Sedra P4.9 in the highlighted textbook the teacher wrote "v. v. important / Practice with PL model / Find range of Rx for which only one diode will be on". This CT question is his own version of it. Expect this type in the term final, possibly with the piecewise-linear model (0.7 V plus \(r_D\)).

Full solution

Units: mA, kΩ, V. There are four possible states. Rule out the impossible ones first.

1. D₁ alone on is impossible. With D₂ off, no current can leave X. But a conducting D₁ pushes current into X, and the 9.5 kΩ resistor also pushes current into X (from +10 V). KCL at X fails, so D₁ cannot conduct alone.

2. Both off is impossible. With no current, \(V_X = 10\) V and \(V_Y = 3\) V, so D₂ sees 7 V forward. It must be on.

3. Assume D₂ on, D₁ off. One loop: +10 V → 9.5 kΩ → D₂ → \(R_x\) → +3 V.

\[ I = \frac{10 - 0.7 - 3}{9.5 + R_x} = \frac{6.3}{9.5 + R_x}\ \text{mA},\qquad V_X = 10 - 9.5\,I \]

4. Check D₁ off. D₁ is off while its voltage \(5 - V_X < 0.7\), i.e. \(V_X > 4.3\) V:

\[ 10 - \frac{9.5\times6.3}{9.5 + R_x} > 4.3 \;\Rightarrow\; \frac{59.85}{9.5 + R_x} < 5.7 \;\Rightarrow\; 9.5 + R_x > 10.5 \;\Rightarrow\; R_x > 1\ \text{k}\Omega \]

5. Cross-check with both on. Then \(V_X = 5 - 0.7 = 4.3\) V and \(V_Y = 3.6\) V. \(I_{9.5k} = (10 - 4.3)/9.5 = 0.6\) mA, \(I_{R_x} = (3.6 - 3)/R_x = 0.6/R_x\) mA. KCL at X: \(I_{D1} = I_{R_x} - I_{9.5k} = 0.6/R_x - 0.6\). This is positive (D₁ really on) only for \(R_x < 1\) kΩ. So the two states meet exactly at \(R_x = 1\) kΩ, which confirms step 4.

Spot values: \(R_x = 2\) kΩ gives \(I = 0.548\) mA, \(V_X = 4.80\) V (D₁ off, correct). \(R_x = 0.5\) kΩ would give \(V_X = 4.02\) V < 4.3 V, so D₁ turns on there.

Answer: only D₂ conducts, for \(R_x > 1\) kΩ. D₁ can never be the only diode on (step 1).

CT-4: Op-amp oscillators (Set A = odd IDs, Set B = even IDs)

CT-4 · Jan 2026 · Set A (odd IDs)

Assuming ideal op-amps in the given oscillator, find (i) the frequency of oscillation, (ii) the condition for oscillation to start.

Full solution

1. Break the loop and find each stage. The follower draws no input current and the non-inverting input draws none either, so no section loads another. The loop gain is the product of the three stage gains. Let \(\tau_1 = R_AC_A\) and \(\tau_2 = L_B/R_B\).

  • RC low-pass: \(H_1(s) = \dfrac{1/sC_A}{R_A + 1/sC_A} = \dfrac{1}{1 + s\tau_1}\).
  • Follower: gain 1.
  • RL high-pass: \(H_2(s) = \dfrac{sL_B}{R_B + sL_B} = \dfrac{s\tau_2}{1 + s\tau_2}\).
  • Non-inverting amplifier: \(K = 1 + R_2/R_1\).
\[ L(s) = \frac{K\,s\tau_2}{(1 + s\tau_1)(1 + s\tau_2)} \]

2. Put \(s = j\omega\).

\[ L(j\omega) = \frac{jK\omega\tau_2}{(1 - \omega^2\tau_1\tau_2) + j\omega(\tau_1 + \tau_2)} \]

3. Frequency (phase condition). The numerator is purely imaginary, so \(L\) is real and positive only when the denominator is purely imaginary too: \(1 - \omega_0^2\tau_1\tau_2 = 0\).

\[ \omega_0 = \frac{1}{\sqrt{\tau_1\tau_2}} = \sqrt{\frac{R_B}{R_AC_AL_B}},\qquad f_0 = \frac{1}{2\pi}\sqrt{\frac{R_B}{R_AC_AL_B}} \]

4. Magnitude condition. At \(\omega_0\): \(L(j\omega_0) = \dfrac{K\tau_2}{\tau_1 + \tau_2}\). Barkhausen \(L = 1\) gives \(K = 1 + \tau_1/\tau_2\), i.e. \(R_2/R_1 = \tau_1/\tau_2\).

5. Start-up condition. Oscillation starts when the loop gain at \(\omega_0\) is slightly above 1:

\[ 1 + \frac{R_2}{R_1} > 1 + \frac{R_AC_AR_B}{L_B}\quad\Longleftrightarrow\quad \frac{R_2}{R_1} > \frac{R_AR_BC_A}{L_B} \]

Equality only sustains the oscillation. Pole check: \(1 - L(s) = 0\) gives \(\tau_1\tau_2s^2 + (\tau_1 + \tau_2 - K\tau_2)s + 1 = 0\). The poles move into the right half-plane exactly when \(K > (\tau_1 + \tau_2)/\tau_2\).

Numeric check (the simulator values): \(\tau_1 = 0.1\) ms, \(\tau_2 = 25\) µs, \(\omega_0 = 20\,000\) rad/s, \(f_0 = 3.18\) kHz, \(K_{min} = 5\), so \(R_2 > 4R_1\) (42 kΩ with \(R_1\) = 10 kΩ starts).

Where marks go

Do not assume the Wien-bridge result \(K = 3\). Here the two sections are isolated by the follower, so \(K_{min} = 1 + \tau_{\text{low-pass}}/\tau_{\text{high-pass}}\) (equal time constants give \(K = 2\)). And state the start-up condition as an inequality: "=" only sustains.

Full method: Barkhausen criterion and amplitude limiters (compare Wien-bridge oscillator)

CT-4 · Jan 2026 · Set B (even IDs)

Assuming ideal op-amps in the given oscillator, find (i) the frequency of oscillation, (ii) the condition for oscillation to start.

Full solution

1. Stages (\(\tau_1 = R_AC_A\), \(\tau_2 = L_B/R_B\); no loading, as in Set A):

  • CR high-pass: \(H_1 = \dfrac{R_A}{R_A + 1/sC_A} = \dfrac{s\tau_1}{1 + s\tau_1}\).
  • LR low-pass: \(H_2 = \dfrac{R_B}{R_B + sL_B} = \dfrac{1}{1 + s\tau_2}\).
  • Amplifier: \(K = 1 + R_2/R_1\).
\[ L(s) = \frac{K\,s\tau_1}{(1 + s\tau_1)(1 + s\tau_2)},\qquad L(j\omega) = \frac{jK\omega\tau_1}{(1 - \omega^2\tau_1\tau_2) + j\omega(\tau_1 + \tau_2)} \]

2. Frequency. Same phase condition, \(1 - \omega_0^2\tau_1\tau_2 = 0\):

\[ \omega_0 = \frac{1}{\sqrt{\tau_1\tau_2}} = \sqrt{\frac{R_B}{R_AC_AL_B}},\qquad f_0 = \frac{1}{2\pi}\sqrt{\frac{R_B}{R_AC_AL_B}} \]

3. Magnitude. \(L(j\omega_0) = \dfrac{K\tau_1}{\tau_1 + \tau_2}\), so \(L = 1\) needs \(K = 1 + \tau_2/\tau_1\).

4. Start-up condition:

\[ 1 + \frac{R_2}{R_1} > 1 + \frac{L_B}{R_AR_BC_A}\quad\Longleftrightarrow\quad \frac{R_2}{R_1} > \frac{L_B}{R_AR_BC_A} \]

Pole check: \(\tau_1\tau_2s^2 + (\tau_1 + \tau_2 - K\tau_1)s + 1 = 0\), right-half-plane poles for \(K > (\tau_1 + \tau_2)/\tau_1\).

Numeric check (same values): \(f_0 = 3.18\) kHz again; \(K_{min} = 1 + 25/100 = 1.25\), so \(R_2 > 0.25R_1\).

Memory hook for both sets: \(\omega_0\) is the geometric mean of the two corner frequencies, \(\sqrt{\omega_{RC}\,\omega_{RL}}\). The minimum gain is \(1 + \dfrac{\tau\text{ of the low-pass section}}{\tau\text{ of the high-pass section}}\).

Full method: Barkhausen criterion and amplitude limiters

CT-1 (Dr. Md. Adnan): diodes

CT-1 · Jan 2025 · True/False · 5 marks

State true or false: (a) A clipper cuts the signal at the diode forward voltage. (b) The reverse current of a real diode is exactly zero. (c) Half-wave and full-wave rectifiers give the same output frequency. (d) A full-wave rectifier smooths better. (e) An ideal diode has \(r_f = 0\) and \(r_r = \infty\).

Full solution
  • (a) False in general. The clip level is the diode drop plus any reference/bias voltage in series with it, not the forward voltage alone.
  • (b) False. The saturation current \(I_s\) plus leakage current flows in reverse bias.
  • (c) False. The full-wave output repeats every half cycle, so its fundamental is \(2f\); the half-wave output stays at \(f\).
  • (d) True. Ripple \(V_r = V_p/(2fCR)\) for full-wave versus \(V_p/(fCR)\) for half-wave: half the ripple for the same C.
  • (e) True. Ideal diode: short when forward biased, open when reverse biased.

Full method: Clippers and transfer characteristics · Peak rectifier: ripple, conduction angle, diode current · Diode models: ideal, CVD, piecewise linear

CT-2 · Jan 2025 · likely Sedra 7e D7.40 (8 marks) + 7.41 (12 marks) · inferred mapping

(a) D7.40. Design the bias of the CE amplifier shown for \(I_E = 0.5\) mA, \(V_C = +6\) V, \(V_B = +5\) V and a divider current \(I_{R_{B2}} = 50\) µA. \(V_{CC} = 15\) V, β = 100, \(V_A = 100\) V. Find \(R_{B1}, R_{B2}, R_E, R_C\) and the small-signal parameters \(g_m, r_\pi, r_o\).

(b) 7.41. For this amplifier with \(R_{sig} = 10\) kΩ and \(R_L = 20\) kΩ (emitter fully bypassed by \(C_E\)), find \(R_{in}\), \(R_o\) and the overall gain \(G_v = v_o/v_{sig}\).

Full solution

Units: mA, kΩ, V. Sedra's answers take \(I_C \approx I_E\) where that is the intended approximation.

(a) Bias design.

  • \(V_E = V_B - 0.7 = 4.3\) V, so \(R_E = 4.3/0.5 = 8.6\) kΩ.
  • \(R_C = (15 - 6)/I_C = 9/0.5 = 18\) kΩ (with \(I_C = \alpha I_E = 0.495\) mA it is 18.18 kΩ; 18 kΩ is the standard answer).
  • \(R_{B2} = V_B/I_{R_{B2}} = 5/0.05 = 100\) kΩ.
  • \(I_B = I_E/(\beta + 1) = 0.5/101 = 0.00495\) mA. \(R_{B1}\) carries \(I_{R_{B2}} + I_B = 0.05495\) mA: \(R_{B1} = (15 - 5)/0.05495 = 182\) kΩ.
  • \(g_m = I_C/V_T = 0.5/0.025 = 20\) mA/V; \(r_\pi = \beta/g_m = 100/20 = 5\) kΩ; \(r_o = V_A/I_C = 100/0.5 = 200\) kΩ.

(b) Small-signal. With \(C_E\) a short, the emitter is at ac ground.

  • \(R_{in} = R_{B1}\parallel R_{B2}\parallel r_\pi = 182\parallel100\parallel5 = 4.64\) kΩ.
  • \(R_o = R_C\parallel r_o = 18\parallel200 = 16.51\) kΩ.
  • \(R_C\parallel r_o\parallel R_L = 18\parallel200\parallel20 = 9.05\) kΩ.
  • \(G_v = -\dfrac{R_{in}}{R_{in} + R_{sig}}\,g_m(R_C\parallel r_o\parallel R_L) = -\dfrac{4.64}{14.64}\times20\times9.05 = -57.3\) V/V.

Other candidates for the same 6th-edition pages (book answers): D7.35, CB bias with \(I_E = 1\) mA, ±2 V swing, +10/−5 V supplies: \(R_B = 0\), \(R_E = 4.3\) kΩ, \(R_C = 8.4\) kΩ. D7.36, collector-to-base feedback bias with \(I_E = 1\) mA, \(V_{CE} = 2.3\) V, \(V_{CC} = 10\) V, β = 100: \(R_C = (10 - 2.3)/1 = 7.7\) kΩ, \(R_B = (2.3 - 0.7)/(1/101) = 162\) kΩ.

CT-3 · Jan 2025 · Q1 · 8 marks · Sedra Exercise 5.15

The NMOS and PMOS transistors are matched: \(k_n'(W/L)_n = k_p'(W/L)_p = 1\) mA/V², \(V_{tn} = -V_{tp} = 1\) V, λ = 0. Find \(i_{DN}\), \(i_{DP}\) and \(v_O\) for \(v_I = 0\) V and \(v_I = +2.5\) V (the book also asks −2.5 V).

Full solution

Units: mA, kΩ, V. \(i_D = \tfrac12 k_n V_{OV}^2\) with \(k_n = 1\) mA/V².

\(v_I = 0\). Try \(v_O = 0\): then \(V_{GSN} = 0 - 0 = 0 < 1\) V and \(V_{SGP} = 0 - 0 = 0 < 1\) V, so both are off, no current flows and \(v_O = 0\) is consistent. \(i_{DN} = i_{DP} = 0\), \(v_O = 0\).

\(v_I = +2.5\) V. \(Q_P\): \(V_{SG} = v_O - 2.5\). Since \(v_O\) cannot exceed 2.5 V, \(V_{SG} < 0\): \(Q_P\) is off. \(Q_N\) works as a source follower; assume saturation. \(V_{GS} = 2.5 - v_O\), \(V_{OV} = 1.5 - v_O\):

\[ \tfrac12(1.5 - v_O)^2 = \frac{v_O}{10} \;\Rightarrow\; v_O^2 - 3.2v_O + 2.25 = 0 \;\Rightarrow\; v_O = \frac{3.2 \pm \sqrt{10.24 - 9}}{2} = 1.043\ \text{or}\ 2.157\ \text{V} \]

Reject 2.157 V: it gives \(V_{OV} = 1.5 - 2.157 < 0\) (transistor off). So \(v_O = 1.043\) V, \(i_{DN} = 1.043/10 = 0.104\) mA, \(i_{DP} = 0\).

Saturation check: \(V_{DS} = 2.5 - 1.043 = 1.457\) V \(\ge V_{OV} = 0.457\) V. ✓

\(v_I = -2.5\) V (by symmetry): \(Q_N\) off, \(v_O = -1.04\) V, \(i_{DP} = 0.104\) mA.

Assignment · Q1 · multi-diode, CVD

Each diode has \(V_D = 0.7\) V when conducting. Find the diode currents, \(V_A\) and \(V_B\).

Full solution

Units: mA, kΩ, V.

Guess: D₁ on, D₂ off, D₃ on. (D₃'s anode is at 0 V and \(R_3\) pulls B towards −5 V, so D₃ conducts. A is pulled down hard by the −10 V branch.)

Left branch (D₂ off, so \(R_1\), D₁, \(R_2\) are in series): \(I_{D1} = \dfrac{5 - 0.7 - (-10)}{5 + 5} = \dfrac{14.3}{10} = 1.43\) mA. \(V_A = 5 - 5\times1.43 = -2.15\) V.

Right branch: D₃ on, so \(V_B = 0 - 0.7 = -0.7\) V. \(I_{D3} = \dfrac{-0.7 - (-5)}{5} = 0.86\) mA.

Checks: \(I_{D1} = 1.43 > 0\) ✓, \(I_{D3} = 0.86 > 0\) ✓. D₂: \(V_A - V_B = -2.15 - (-0.7) = -1.45\) V < 0.7 V, so D₂ off ✓, \(I_{D2} = 0\).

Answer: \(I_{D1} = 1.43\) mA, \(I_{D2} = 0\), \(I_{D3} = 0.86\) mA, \(V_A = -2.15\) V, \(V_B = -0.7\) V.

Assignment · Q2 · small-signal

\(v_s = 2\sin\omega t\) mV. Using small-signal analysis, find \(v_o\). The diode follows the exponential model and conducts 0.2 mA at 0.7 V.

Full solution

Units: mA, kΩ, V. \(V_T = 26\) mV (the assignment's value; 25 mV changes only the 3rd digit, see below).

1. Thevenin at N (three 10 kΩ resistors): DC part \(V_{TH} = 5\times\dfrac{10\parallel10}{10 + 10\parallel10} = 5/3 = 1.667\) V; ac part \(v_{th} = v_s/3\); \(R_{TH} = 10\parallel10\parallel10 = 3.333\) kΩ. Series loop resistance \(3.333 + 20 = 23.33\) kΩ.

2. DC operating point. \(I_D = \dfrac{1.667 - V_D}{23.33}\), \(V_D = 0.7 + V_T\ln\dfrac{I_D}{0.2}\). Iterate:

  • \(V_D = 0.7\): \(I_D = 0.04143\) mA → \(V_D = 0.7 + 0.026\ln(0.2071) = 0.6591\) V.
  • \(I_D = 0.04318\) mA → \(V_D = 0.6602\) V.
  • \(I_D = 0.04314\) mA → \(V_D = 0.6601\) V (converged).

\(V_D = 0.660\) V, \(I_D = 43.1\) µA, \(V_O = 20\times0.04314 = 0.863\) V.

3. Small-signal. \(r_d = V_T/I_D = 26/0.04314\ \Omega = 603\ \Omega = 0.603\) kΩ.

\[ \frac{v_o}{v_s} = \frac13\cdot\frac{20}{3.333 + 0.603 + 20} = 0.2785 \;\Rightarrow\; v_o = 0.2785\times2\sin\omega t = 0.557\sin\omega t\ \text{mV} \]

Answer: \(v_O(t) = 0.863\text{ V} + 0.557\sin\omega t\ \text{mV}\). (With \(V_T = 25\) mV: \(V_D = 0.662\) V, 0.861 V + 0.558 sin ωt mV.)

Assignment · Q6 · diode-connected MOSFETs

All three NMOS transistors have \(k_n = 1\) mA/V² and \(V_t = 2\) V (λ = 0). Find \(v_o\) and \(i_o\).

Full solution

Diode-connected transistors have \(V_{DS} = V_{GS} > V_{OV}\), so they are always in saturation when on.

M1: \(V_{GS} = 5 - v_o\), \(V_{OV} = 3 - v_o\). M2, M3: \(V_{GS} = v_o\), \(V_{OV} = v_o - 2\). KCL at \(v_o\) (M1 current = M2 + M3):

\[ \tfrac12(1)(3 - v_o)^2 = 2\times\tfrac12(1)(v_o - 2)^2 \;\Rightarrow\; 9 - 6v_o + v_o^2 = 2v_o^2 - 8v_o + 8 \;\Rightarrow\; v_o^2 - 2v_o - 1 = 0 \]

\(v_o = 1 \pm \sqrt2\). Reject \(1 - \sqrt2 = -0.414\) V (below \(V_t\), M2 and M3 would be off). \(v_o = 1 + \sqrt2 = 2.414\) V.

\(i_o = \tfrac12(3 - 2.414)^2 = 3 - 2\sqrt2 = \) 0.172 mA through M1, split as 0.0858 mA in each of M2 and M3.

Assignment · Q9 · op-amp astable with RL timing

Find the period of oscillation and sketch \(V_{out}\) and \(V_x\). Rails ±13 V.

Full solution

2. Timing. \(V_x\) is the resistor voltage, \(V_x = iR\). The inductor current cannot jump, so \(V_x\) is continuous. With \(V_{out} = +13\) V, \(V_x\) rises exponentially towards 13 V with \(\tau = L/R = 10\text{ mH}/200\ \Omega = 50\) µs.

\[ T = 2\tau\ln\frac{19}{7} = 99.85\ \mu\text{s},\qquad f = 10.01\ \text{kHz} \]

Waveforms: \(V_{out}\) is a ±13 V square wave. \(V_x\) is a chain of exponential segments between −6 V and +6 V (heading towards ±13 V), switching at the peaks.

Assignment · Q10 · RL oscillator with two op-amps

Find the frequency of oscillation and the condition on \(R_2/R_1\) for oscillation. All R and L values are equal where labelled R and L.

Full solution

Let \(K = R_2/R_1\), so op-amp 2 gives \(v_o = -Kv_f\).

1. KCL at \(n_1\) (virtual ground, 0 V): \(\dfrac{v_1 - 0}{R} + \dfrac{v_f - 0}{sL} = 0 \Rightarrow v_1 = -\dfrac{R}{sL}v_f\).

2. KCL at \(v_1\): \(\dfrac{v_o - v_1}{sL} = \dfrac{v_1}{R} + \dfrac{v_1 - v_f}{R}\). Multiply by \(sLR\): \(R(v_o - v_1) = sL(2v_1 - v_f)\).

3. Substitute \(v_o = -Kv_f\) and \(v_1 = -Rv_f/(sL)\), divide by \(v_f\):

\[ -KR + \frac{R^2}{sL} = -2R - sL \;\Rightarrow\; s^2L^2 + sLR(2 - K) + R^2 = 0 \]

4. Oscillation: poles on the \(j\omega\) axis need the \(s\) term to vanish: \(K = 2\), i.e. \(R_2 = 2R_1\). Then \(s^2L^2 + R^2 = 0\), so

\[ \omega_0 = \frac{R}{L},\qquad f_0 = \frac{R}{2\pi L} \]

5. Start-up: \(K > 2\) (\(R_2 > 2R_1\)) makes the \(s\) coefficient negative, so the poles move into the right half-plane and the oscillation grows until the op-amps limit it.
