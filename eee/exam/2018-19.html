Question 1

2018–19 · Sec A · Q1(a) · 16⅔ marks

Draw the circuit of a full-wave bridge rectifier and show the output wave shape for a sinusoidal input.

Answer key
  • Four diodes in a bridge, transformer secondary across one diagonal, load R across the other.
  • Positive half cycle: one diagonal pair (\(D_1\), \(D_2\)) conducts; negative half: the other pair (\(D_3\), \(D_4\)); load current flows the same way both times.
  • \(v_O = |v_S| - 2V_D\): full-wave rectified sine at \(2f\), peak \(V_S - 2V_D\), zero (dead zone) while \(|v_S| < 2V_D\).
  • PIV per diode \(= V_S - V_D\) (about half the centre-tap value); no centre-tapped transformer needed; cost: two diode drops.

Full method: Rectifiers and battery chargers

2018–19 · Sec A · Q1(b) · 10 marks

For a full-wave bridge rectifier, find the value of peak current through the diode and PIV for the diode. Given \(V_s\) = 12 V (rms), \(V_{D0}\) = 0.7 V and R = 100 Ω.

Answer key

\(V_{s,peak} = 12\sqrt2 = 16.97\) V; \(V_{o,peak} = 16.97 - 2(0.7) = 15.57\) V.

\(I_{D,peak} = 15.57/0.1\text{ kΩ} = 155.7\) mA. PIV \(= V_{s,peak} - V_{D0} = 16.27\) V.

Full method: Rectifiers and battery chargers

2018–19 · Sec A · Q1(c) · 10 marks

Comment on the value of RC time constant for a rectifier circuit.

Answer key
  • Need \(RC \gg T\) (half wave) or \(RC \gg T/2\) (full wave); ripple \(V_r \approx V_p/(fRC)\) or \(V_p/(2fRC)\).
  • Larger RC: lower ripple, \(V_{DC} \approx V_p - V_r/2\) closer to \(V_p\).
  • But a shorter conduction angle \(\omega\Delta t \approx \sqrt{2V_r/V_p}\) and a much larger peak diode current \(i_{D,max} \approx I_L(1 + 2\pi\sqrt{V_p/2V_r})\), plus a big surge at switch-on.
  • Choose the smallest C that meets the ripple spec; check the diode's repetitive and surge current ratings.

Full method: Peak rectifier: ripple, conduction angle, diode current

2018–19 · Sec A · Q1(d) · 10 marks

For a sinusoidal input, draw the output waveshape for the circuit shown in Fig. for Q.1(d). (The amplitude of \(v_i\) and the value of V are not given.)

Answer key

The diode conducts when \(v_o < V\) (anode at V, cathode at the output). Ideal diode: \(v_o = V\) for \(v_i < V\) and \(v_o = v_i\) for \(v_i \ge V\), i.e. \(v_o = \max(v_i, V)\).

Question 2

2018–19 · Sec A · Q2(a) · 23 marks

Draw the energy band profile of a pnp transistor under zero bias and forward-active mode bias conditions.

Answer key
  • p⁺ emitter / thin, light n base / p collector on one position axis; label \(E_C\), \(E_V\), \(E_F\).
  • Zero bias: \(E_F\) flat; built-in barriers at EB and CB.
  • Forward active: EB barrier lowered by \(qV_{EB}\) (narrower depletion), CB barrier raised by \(q|V_{CB}|\) (wider depletion); quasi-Fermi levels split.
  • Holes injected from the emitter diffuse across the base and are swept into the collector; draw the two cases one above the other. Repeated in 2020–21 Q1(a).

For the common collector circuit shown in Fig. for Q.2(b), derive the expressions for \(A_v\), \(A_i\), \(R_i\) and \(R_o\) using the T model for the transistor.

Answer key

T model, \(r_o\) neglected: \(r_e\) in the emitter lead, \(\alpha i_e\) from the collector (AC ground); \(i_e = v_b/(r_e + R_L)\).

2018–19 · Sec A · Q3(b) · 20 marks

The circuit shown in Fig. for Q.3(b) is to be fabricated using a transistor type whose β can vary from 50 to 150. Design the circuit (find \(R_C\)) so that all fabricated circuits are guaranteed to be in the active mode (emitter junction forward biased and collector junction reverse biased). What is the range of collector voltages that the fabricated circuits may exhibit?

Answer key

\(I_B = (5 - 0.7)/100 = 43\) µA, independent of β. \(I_C\) = 2.15 mA (β = 50) to 6.45 mA (β = 150).

Worst case β = 150 must stay active. Collector junction reverse biased means \(V_C \ge V_B = 0.7\) V (Sedra edge of saturation \(V_{CE} = 0.3\) V is a common alternative): with \(V_C \ge 0.3\) V, \(R_C \le 9.7/6.45 = 1.50\) kΩ; with strictly \(V_{CB} \ge 0\), \(R_C \le 9.3/6.45 = 1.44\) kΩ. Choose \(R_C\) = 1.5 kΩ (or 1.4 kΩ for the strict reading); state which.

With 1.5 kΩ: \(V_C = 10 - 1.5I_C\) ranges from 0.325 V (β = 150) to 6.78 V (β = 50). With 1.4 kΩ: 0.97 V to 6.99 V.

Question 4

2018–19 · Sec A · Q4(a) · 26⅔ marks

What is the difference between enhancement type and depletion type MOSFETs? Draw \(I_D\) vs \(V_{GS}\) characteristics and \(I_D\) vs \(V_{DS}\) characteristics for different values of \(V_{GS}\) for enhancement type and depletion type MOSFETs.

Answer key
  • Enhancement: no channel at \(V_{GS} = 0\); for NMOS \(V_t > 0\), conducts only for \(V_{GS} > V_t\) (channel induced by the gate).
  • Depletion: channel implanted during fabrication, \(V_t < 0\) for NMOS; \(I_{DSS} = \frac12k_nV_t^2\) flows at \(V_{GS} = 0\); works in depletion mode (\(V_{GS} < 0\)) or enhancement mode (\(V_{GS} > 0\)). Draw the symbol with the solid channel line.
  • \(I_D\)–\(V_{GS}\) (saturation): same parabola \(\frac12k_n(V_{GS}-V_t)^2\), starting at \(V_t > 0\) for enhancement and at \(V_t < 0\) for depletion (crossing the axis at \(I_{DSS}\)).
  • \(I_D\)–\(V_{DS}\): same family shape (triode then saturation, boundary \(V_{DS} = V_{OV}\)); the depletion family includes curves for \(V_{GS} = 0\) and negative \(V_{GS}\).

Full method: Structure and operation

2018–19 · Sec B · Q5(b) · 26⅔ marks

Design an electronic analog computer using op-amps that can solve the following differential equation. Give a brief explanation of the operation of the designed computer: \(\dfrac{d^2v}{dt^2} + 4\dfrac{dv}{dt} + 5v - 5 = 0\).

Answer key

\(v'' = -(4v' + 5v - 5)\).

Summer (inverting, \(R_f\) = 100 kΩ) outputs \(v''\): \(+v'\) through 25 kΩ, \(+v\) through 20 kΩ, and −15 V through 300 kΩ (gives +5 V).

Integrator 1 (1 MΩ, 1 µF): \(v'' \to -v'\). Integrator 2: \(-v' \to +v\) (solution node). Inverter: \(-v' \to +v'\). Four op-amps (three if the summer is arranged to output \(-v''\)).

Operation: the loop forces the summer output to satisfy the equation; initial conditions by pre-charging the integrator capacitors. The solution settles to \(v = 1\) V (damped oscillation, roots \(-2 \pm j\)).

Full method: Analog computer for differential equations

Question 6

2018–19 · Sec B · Q6(a) · 16 marks

Design a circuit using op-amp(s) for the given input \(v_i(t)\) and output \(v_o(t)\) in Fig. for Q.6(a).

Waveforms (in words): \(v_i\) ramps linearly from 0 V at t = 0 to 10 V at t = 1 ms, then stays at 10 V. \(v_o\) is a constant positive level for 0 < t < 1 ms, then 0 V. The level is hand-written and hard to read; the question bank reads it as +1 V.

Answer key

Inverting differentiator (C = 0.1 µF in series at the input, R = 1 kΩ feedback) gives −1 V; follow it with a unity inverter (10 kΩ / 10 kΩ) to get +1 V. (For another level \(V_o\): \(RC = V_o/10^4\).)

2018–19 · Sec B · Q6(b) · 20 marks

Design a circuit using a 555 IC which results in a square wave with oscillation frequency of 100 kHz and 75 % duty cycle. Also draw your designed circuit and output wave shape.

Answer key

With C = 1 nF: \(R_B = 2.5\ \mu s/(0.693\times1\text{ nF}) = 3.61\) kΩ, \(R_A = 7.21\) kΩ. Draw the astable (pins 4, 8 to \(V_{CC}\); \(R_A\) to pin 7; \(R_B\) from 7 to 2, 6; C to ground; 0.01 µF on pin 5) and \(v_O\): high 7.5 µs, low 2.5 µs; \(v_C\) between \(V_{CC}/3\) and \(2V_{CC}/3\).

2018–19 · Sec B · Q6(c) · 10⅔ marks

Write down the Barkhausen criterion.

Answer key
  • Positive feedback: \(A_f = A/(1 - A\beta)\); an output with no input needs loop gain \(L(j\omega_0) = A(j\omega_0)\beta(j\omega_0) = 1\).
  • Magnitude: \(|A\beta| = 1\). Phase: \(\angle A\beta = 0°\) (mod 360°); the frequency where this holds is \(f_0\).
  • Start-up: make \(|A\beta|\) slightly > 1; a non-linearity (limiter, AGC) brings it back to 1. \(|A\beta| < 1\): decays; \(\gg 1\): clipped, distorted output.

Full method: Barkhausen criterion and amplitude limiters

Question 7

2018–19 · Sec B · Q7(a) · 20 marks

For the Colpitts oscillator, show that the frequency of oscillation is \(\omega_0 = 1\Big/\sqrt{L\,\dfrac{C_1C_2}{C_1+C_2}}\).

Answer key

Draw the circuit (CS MOSFET or CE BJT; \(C_2\) gate/base to ground, \(C_1\) drain/collector to ground, L between them, R = resistance at the drain). Small-signal model, KCL at the drain:

\[ s^3LC_1C_2 + s^2\frac{LC_2}{R} + s(C_1+C_2) + \left(g_m + \frac1R\right) = 0. \]

\(s = j\omega\); imaginary part zero: \(\omega(C_1+C_2) = \omega^3LC_1C_2\) ⇒ \(\omega_0 = 1\big/\sqrt{L\,C_1C_2/(C_1+C_2)}\) (L resonating with \(C_1\) and \(C_2\) in series). The real part gives the gain condition \(g_mR = C_2/C_1\) (asked in 2020–21).

Full method: Colpitts, Hartley and crystal oscillators

2018–19 · Sec B · Q7(b) · 10⅔ marks

Draw the equivalent circuit of a piezoelectric crystal. Qualitatively draw the crystal reactance versus frequency and identify the inductive and capacitive reactance regions.

Answer key
  • Model: series L–\(C_s\)–r (motional arm) in parallel with \(C_p\) (electrode capacitance), \(C_p \gg C_s\).
  • \(\omega_s = 1/\sqrt{LC_s}\) (series resonance, reactance 0); \(\omega_p = 1\big/\sqrt{L\,C_sC_p/(C_s+C_p)}\) (parallel resonance, reactance → ∞), just above \(\omega_s\).
  • Reactance plot: capacitive (negative) below \(f_s\), inductive (positive) between \(f_s\) and \(f_p\) (the narrow band used in oscillators), capacitive above \(f_p\).
  • Very high Q (10⁴–10⁶) gives excellent frequency stability; the crystal replaces L in a Colpitts (Pierce) oscillator.

Full method: Colpitts, Hartley and crystal oscillators

2018–19 · Sec B · Q7(c) · 16 marks

Design a circuit using a bistable multivibrator which generates a triangular waveform with oscillation frequency of 2 kHz. Given that the triangular wave has a 10 V peak-to-peak amplitude.

Answer key

Non-inverting bistable (\(R_1\) from the triangle to the + input, \(R_2\) from the square output) + inverting integrator (R, C). \(V_{pp} = 2LR_1/R_2\), \(f = \dfrac{R_2}{4RCR_1}\).

Take \(L = \pm13\) V: \(R_1/R_2 = 5/13 = 0.385\) (e.g. \(R_1\) = 10 kΩ, \(R_2\) = 26 kΩ). Half period 250 µs \(= RC\cdot10/13\) ⇒ RC = 325 µs; with C = 10 nF, R = 32.5 kΩ.

(With L = ±15 V: \(R_1/R_2 = 1/3\), RC = 375 µs, R = 37.5 kΩ. Either is accepted if L is stated.)

Full method: Astable, monostable, square–triangle generators

Question 8

2018–19 · Sec B · Q8(a) · 10⅔ marks

Consider the inverter of Fig. for Q.8(a) with a capacitor C connected between the output node and ground. If at t = 0 \(v_i\) goes from low to high, find the equation of the time for \(v_o\) to reach \(\frac12(V_{OL} + V_{OH})\). Also calculate the high-to-low propagation time for R = 25 kΩ and C = 20 pF.

Answer key

Model the NMOS as a switch with on-resistance \(R_{on}\). When \(v_i\) goes high, C discharges from \(V_{OH} = V_{DD}\) toward \(V_{OL} = V_{DD}R_{on}/(R + R_{on})\) with \(\tau = (R\parallel R_{on})C\):

\(v_o(t) = V_{OL} + (V_{OH} - V_{OL})e^{-t/\tau}\); reaching the midpoint needs \(e^{-t/\tau} = \frac12\) ⇒ \(t_{PHL} = \tau\ln2 = 0.69\,(R\parallel R_{on})C\).

Only R and C are given, so the paper expects \(t_P = 0.69RC = 0.69\times25\text{ kΩ}\times20\text{ pF} = 347\) ns. Note: strictly, 0.69RC is the low-to-high time (C charges through R when the switch opens); the high-to-low time is shorter, \(0.69(R\parallel R_{on})C\). Write both and state the assumption.

Full method: CMOS inverter and gates

2018–19 · Sec B · Q8(b) · 13 marks

Implement the function \(f(A,B,C,D) = \Sigma m(0, 4, 8, 9, 10, 11, 12)\) using CMOS.

Answer key

K-map: 8–11 → \(A\bar B\); 0, 4, 8, 12 → \(\bar C\bar D\). \(f = A\bar B + \bar C\bar D\), so \(\bar f = (\bar A + B)(C + D)\) and \(f = \overline{(\bar A + B)(C + D)}\) (checked over all 16 inputs).

One complex gate: PDN = (\(\bar A\) ∥ B) in series with (C ∥ D); PUN = (\(\bar A\) series B) in parallel with (C series D). 8 transistors + an inverter for \(\bar A\) = 10 transistors.

2018–19 · Sec B · Q8(d) · 7 marks

Implement the following function Y using CMOS transmission gate configuration: \(Y = AB + A\bar C\).

Answer key

\(Y = A(B + \bar C)\). Shannon expansion on B: \(Y = B\cdot A + \bar B\cdot A\bar C\). A 2:1 TG multiplexer with select B: TG1 (on when B = 1) passes A; TG2 (on when B = 0) passes \(A\bar C\), which is itself a TG mux on C: passes A when C = 0 and ground (0) when C = 1. Four TGs (each an nMOS–pMOS pair driven by the select and its complement) plus inverters for \(\bar B\), \(\bar C\). Checked over all 8 inputs.
