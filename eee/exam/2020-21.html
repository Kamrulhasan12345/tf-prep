Question 1

2020–21 · Sec A · Q1(a) · 16 marks

Draw the energy band profile of a pnp transistor under zero bias and forward-active mode bias conditions.

Answer key
  • Three regions p⁺ emitter / thin, lightly doped n base / p collector, drawn on one position axis; label \(E_C\), \(E_V\), \(E_F\).
  • Zero bias: \(E_F\) flat through the device (near \(E_V\) in the p regions, near \(E_C\) in the base); bands bend at both junctions, giving built-in barriers at EB and CB.
  • Forward active: EB forward biased, so the EB barrier falls by \(qV_{EB}\) and its depletion layer narrows; CB reverse biased, so the CB barrier rises by \(q|V_{CB}|\) and that depletion layer widens. \(E_F\) splits into quasi-Fermi levels.
  • Holes injected from the emitter cross the narrow base by diffusion and are swept down the CB barrier into the collector (for holes, "down" is up the band diagram: show the arrow).
  • Draw the two diagrams one above the other with the same horizontal axis. Same question as 2018–19 Q2(a).

Full method: Structure and modes of operation

2020–21 · Sec A · Q1(b) · 10⅔ marks

What is transistor biasing? Why do we need transistor biasing? How can you achieve biasing stability?

Answer key
  • Biasing: the DC voltages and currents that set the quiescent point (\(I_{CQ}\), \(V_{CEQ}\)) with no signal applied.
  • Why: keep the BJT in the active region over the whole signal swing (no clipping into cutoff or saturation), fix \(g_m = I_C/V_T\) and hence the gain, and make the point insensitive to the β spread and temperature (avoid thermal runaway).
  • Stability (\(S = \partial I_C/\partial I_{CO}\), smaller is better): emitter degeneration \(R_E\) (negative feedback), voltage-divider bias with \(R_{TH} \ll (\beta+1)R_E\) and \(V_{BB} \gg V_{BE}\), collector-to-base feedback, diode or thermistor compensation.
  • Show the 4-resistor circuit and \(I_E = \dfrac{V_{BB} - V_{BE}}{R_E + R_B/(\beta+1)}\).

Full method: Bias circuits, stability and bias design

The transistor in the circuit of the figure has β = 100 and exhibits \(V_{BE}\) = 0.7 V at \(i_C\) = 1 mA. Design the circuit so that a current of 2 mA flows through the collector and a voltage of +5 V appears at the collector. (The paper labels this figure "Fig. for Q 2(a)"; it belongs to Q1(c).)

Question 2

2020–21 · Sec A · Q2(a) · 26 marks

For a common collector amplifier, derive the expressions for \(R_i\), \(R_o\), \(A_v\) and \(A_i\) using the T model with Early effect for the transistor. Where is the common collector amplifier used?

Answer key

Draw the T model: \(r_e\) in the emitter, \(\alpha i_e\) from collector (AC ground) and \(r_o\) from emitter to AC ground, so \(r_o\) sits in parallel with \(R_L\). Source \(v_{sig}\), \(R_{sig}\) into the base.

  • \(R_i = (\beta+1)\,[\,r_e + (r_o\parallel R_L)\,]\) (in parallel with any bias resistor \(R_B\)).
  • \(A_v = \dfrac{v_o}{v_b} = \dfrac{r_o\parallel R_L}{r_e + r_o\parallel R_L} \approx 1\); overall \(G_v = A_v\dfrac{R_i}{R_i + R_{sig}}\).
  • \(R_o = r_o \parallel \left[r_e + \dfrac{R_{sig}}{\beta+1}\right]\) (\(R_{sig}\to R_{sig}\parallel R_B\) with a bias resistor).
  • \(A_i = \dfrac{i_o}{i_b} = (\beta+1)\dfrac{r_o}{r_o + R_L}\approx \beta+1\).
  • Uses: voltage buffer / impedance transformer between a high-resistance source and a low-resistance load, output stage of multistage amplifiers, DC level shifter (≈ 0.7 V).

Senior solution gap

The circulating BJT "TF Analysis" file derives \(R_{in}\), \(R_{out}\) and \(A_v\) but leaves out \(A_i\) and "where it is used": those are marks.

Full method: Common base and emitter follower

Question 3

2020–21 · Sec A · Q3(a) · 20 marks

Design an oscillator circuit using a 555 timer IC which has a square-wave output with oscillation frequency 20 kHz and duty cycle 25 %. Provide the necessary illustration of the designed circuit and draw the wave shape.

Answer key

\(T = 50\) µs, \(t_H = 12.5\) µs, \(t_L = 37.5\) µs. The standard astable always has \(D > 50\%\) (\(t_H = 0.693(R_A+R_B)C > t_L = 0.693R_BC\)), so modify it: put a diode across \(R_B\) (anode at pin 7) so C charges through \(R_A\) only and discharges through \(R_B\).

Then \(t_H = 0.693R_AC\), \(t_L = 0.693R_BC\). With C = 1 nF: \(R_A = \dfrac{12.5\ \mu s}{0.693\times1\text{ nF}} = 18.0\) kΩ, \(R_B = \dfrac{37.5\ \mu s}{0.693\times1\text{ nF}} = 54.1\) kΩ (ideal diode).

Alternative: design a 75 % astable (\(R_A = 2R_B\), e.g. \(R_B\) = 18.0 kΩ, \(R_A\) = 36.1 kΩ with 1 nF) and follow it with an inverter. Draw \(v_C\) between \(V_{CC}/3\) and \(2V_{CC}/3\) and \(v_O\) high for 12.5 µs, low for 37.5 µs.

Full method: The 555 timer

2020–21 · Sec A · Q3(b) · 26⅔ marks

Draw the circuit of the Colpitts oscillator. Then using the small-signal model of the MOSFET show that the frequency of oscillation is \(\omega_0 = 1\Big/\sqrt{L\,\dfrac{C_1C_2}{C_1+C_2}}\) and \(C_2/C_1 = g_mR\).

Answer key

Circuit (Sedra labels): CS MOSFET, \(C_2\) from gate to ground (source), \(C_1\) from drain to ground, \(L\) from drain to gate; \(R\) = all resistance at the drain (\(r_o\parallel R_L\parallel\) tank loss).

Gate voltage \(V_{gs}\); current in \(C_2\) is \(sC_2V_{gs}\), so the drain voltage is \(V_d = V_{gs}(1 + s^2LC_2)\). KCL at the drain:

\[ sC_2V_{gs} + g_mV_{gs} + \left(\tfrac{1}{R} + sC_1\right)(1 + s^2LC_2)V_{gs} = 0 \]

\[ s^3LC_1C_2 + s^2\frac{LC_2}{R} + s(C_1+C_2) + \left(g_m + \frac{1}{R}\right) = 0 \]

Put \(s = j\omega\). Imaginary part zero: \(\omega(C_1+C_2) - \omega^3LC_1C_2 = 0\) ⇒ \(\omega_0 = 1\big/\sqrt{L\,C_1C_2/(C_1+C_2)}\).

Real part zero: \(g_m + \frac1R - \omega_0^2\frac{LC_2}{R} = 0\) ⇒ \(\omega_0^2LC_2 = 1 + g_mR\); and \(\omega_0^2LC_2 = 1 + C_2/C_1\), so \(C_2/C_1 = g_mR\). For reliable start-up make \(g_mR\) slightly larger than \(C_2/C_1\).

Question-bank misprint

The question bank prints "\(C_1/C_2 = g_mR\)" and its Gemini answer moves \(C_1\) to the gate to match. The paper asks \(C_2/C_1 = g_mR\) with \(C_2\) gate–source. Rule without labels: \(g_mR\) = (gate-side capacitor)/(drain-side capacitor).

Full method: Colpitts, Hartley and crystal oscillators

Question 4

2020–21 · Sec A · Q4(a) · 26⅔ marks

Drawing appropriate circuits, show how you can generate triangular waves using a bistable multivibrator and appropriate op-amp circuits.

Answer key
  • Loop: non-inverting bistable (op-amp, − input grounded, \(R_1\) from the triangle output to the + input, \(R_2\) from the square output to the + input) drives an inverting integrator (\(R\), \(C\)); the integrator output (triangle) feeds the bistable input.
  • Bistable thresholds: \(V_{TH} = L\,R_1/R_2\), \(V_{TL} = -L\,R_1/R_2\) for saturation levels \(\pm L\).
  • While the square output is \(+L\), the triangle ramps down at \(L/RC\); when it hits \(V_{TL}\) the bistable flips to \(-L\) and the ramp reverses; and so on.
  • Half period: \(T/2 = RC\,(V_{TH} - V_{TL})/L = 2RC\,R_1/R_2\), so \(f = \dfrac{R_2}{4RCR_1}\); triangle peak-to-peak \(2L R_1/R_2\).
  • Sketch both waveforms aligned in time: square ±L, triangle between \(V_{TL}\) and \(V_{TH}\).

Full method: Astable, monostable, square–triangle generators

2020–21 · Sec A · Q4(b) · 20 marks · no longer examined

By drawing appropriate circuits, explain the operation of a dual-slope A/D converter.

Answer key

Integrator + comparator + counter + control logic. Phase 1: integrate \(-v_A\) for a fixed \(T_1 = 2^N\) clock periods. Phase 2: switch the input to \(+V_{REF}\) and count \(n\) clocks until the integrator returns to zero. \(v_A = V_{REF}\,n/2^N\): independent of R, C and clock accuracy; rejects mains hum if \(T_1\) is a multiple of 20 ms; slow but accurate (DVMs).

Question 5

2020–21 · Sec B · Q5(a) · 20 marks

The diagram in Figure for Q.5(a) shows a Boolean function Y implemented as a combinational circuit. Design a CMOS transistor-level implementation of the Boolean function using the minimum number of transistors.

Gate diagram (in words): G1 = NOR(B, C); G2 = NAND(A, B); G3 = NOR(C, G2); G4 = NOR(G1, G3); Y = NAND(A, G4).

Answer key

G1 = \(\overline{B+C}\), G2 = \(\overline{AB}\), G3 = \(\overline{C + \overline{AB}} = \bar C\,AB\).

G4 = \(\overline{G1 + G3} = (B + C)\,\overline{AB\bar C} = (B+C)(\bar A + \bar B + C) = C + \bar A B\).

Y = \(\overline{A\cdot G4} = \overline{AC + A\bar A B} = \overline{AC}\): a 2-input NAND of A and C. 4 transistors: two nMOS (A, C) in series to ground, two pMOS (A, C) in parallel to \(V_{DD}\). Truth table checked over all 8 inputs; B does not matter.

Full method: CMOS inverter and gates

2020–21 · Sec B · Q5(b) · 26⅔ marks

For the logic circuit shown in Figure for Q.5(b), choose transistor widths to achieve equal rise and fall resistance as a unit inverter. Assume \(\mu_n = 3\mu_p\). What is the minimum and maximum propagation delay in the circuit?

Answer key

Unit inverter: \(W_n = 1\), \(W_p = 3\) (both give resistance \(R\)). Size every worst-case path to \(R\).

nMOS: path B–C–D has three in series ⇒ B = C = D = 3. Path A–D: \(1/W_A + 1/3 = 1\) ⇒ A = 1.5.

pMOS: path A–B (or A–C) has two in series ⇒ A = B = C = 2×3 = 6; D alone ⇒ D = 3.

Delay (lumped load \(C_L\), \(t_p = 0.69R_{eq}C_L\)): maximum when only one worst path conducts, \(R_{eq} = R\) ⇒ \(t_{p,max} = 0.69RC_L\).

Fastest fall (all nMOS on): \((R/1.5 \parallel 2R/3) + R/3 = R/3 + R/3 = 2R/3\). Fastest rise (all pMOS on): \((R/2 + R/4)\parallel R = 3R/7\). So \(t_{p,min} = 0.69\times\frac37 RC_L = 0.296RC_L\) (and the fastest fall is \(0.46RC_L\)).

Full method: CMOS inverter and gates

Question 7

2020–21 · Sec B · Q7(a) · 20 marks

Design a circuit using ideal op-amps that would implement \(v_o \propto \int (v_1 + v_2)\,dt\). Write the final output expression in terms of the circuit components used in your design.

Answer key

Summing integrator: \(v_1\) through \(R_1\) and \(v_2\) through \(R_2\) into the inverting input; \(C\) from the inverting input to the output; + input grounded.

KCL at the virtual ground: \(v_1/R_1 + v_2/R_2 = -C\,dv_o/dt\) ⇒ \(v_o = -\dfrac{1}{C}\displaystyle\int\left(\frac{v_1}{R_1} + \frac{v_2}{R_2}\right)dt + v_o(0)\).

With \(R_1 = R_2 = R\): \(v_o = -\dfrac{1}{RC}\displaystyle\int(v_1 + v_2)\,dt\) (e.g. R = 100 kΩ, C = 1 µF, RC = 0.1 s). Add a unity inverter if a positive constant is wanted; a large resistor across C limits DC drift.

Full method: Building a given expression

Question 8

2020–21 · Sec B · Q8(a) · 23⅓ marks

Determine the closed-loop voltage gain and current gain of the ideal op-amp network shown in Figure for Q.8(a).

Answer key

Virtual ground: \(i_1 = v_I/R_1\) flows on through \(R_2\), so \(v_X = -R_2\,v_I/R_1\).

Current into ground through \(R_4\): \(v_X/R_4\); current through \(R_3\) toward the output: \(i_3 = i_1 - v_X/R_4 = i_1(1 + R_2/R_4)\).

\(v_O = v_X - i_3R_3\) ⇒ \[ A_v = \frac{v_O}{v_I} = -\frac{R_2}{R_1}\left(1 + \frac{R_3}{R_2} + \frac{R_3}{R_4}\right) = -\frac{R_2 + R_3 + R_2R_3/R_4}{R_1}. \]

Current gain (current delivered into the op-amp output over input current, no load): \(A_i = i_3/i_1 = 1 + R_2/R_4\). Point to note: a large gain with small resistor values (high input resistance \(R_1\) without a huge \(R_F\)).
