Question 1

2013–14 · Sec A · Q1(a) · 26 marks (printed 16 + 10)

Figure 1(a) shows a diode in series with a 1 Ω resistor driven by \(V_{in}\), and the I–V characteristic of the diode: I = 0 for −3 V < V < 1 V; above 1 V the forward branch is a straight line of slope 1 A/V (\(r_D\) = 1 Ω); at −3 V there is a vertical reverse-breakdown line. Figure 1(b) shows the input \(V_{in}\) (the text calls it "sinusoidal" but it is drawn as a staircase of equal-width steps): 0 → 1 → 2 → 3 → 2 → 1 → 0 V, then 0 → −1 → −2 → −3 → −2 → −1 → 0 V. Draw the output voltage \(V_{out}\) across the resistor with reference to Figure 1(b).

Answer key

Forward (\(V_{in} > 1\) V): \(I = (V_{in} - 1)/(r_D + R) = (V_{in}-1)/2\), so \(V_{out} = (V_{in} - 1)/2\).

Step by step: \(V_{in}\) = 0, 1, 2, 3, 2, 1, 0 → \(V_{out}\) = 0, 0, 0.5, 1.0, 0.5, 0, 0 V. Negative steps: the diode is off for −3 < V < 1, so \(V_{out}\) = 0; at the −3 V step the diode just reaches the breakdown edge, current ≈ 0 by this model, so \(V_{out}\) ≈ 0 throughout the negative half.

Full method: Diode models: ideal, CVD, piecewise linear

2013–14 · Sec A · Q1(b) · 10 marks

What would be the output voltage \(V_{out}\) across the resistor if the diode had a constant 0.7 V voltage drop?

Answer key

\(V_{out} = V_{in} - 0.7\) for \(V_{in} > 0.7\) V, else 0 (no breakdown in the CVD model). Steps: 0, 0.3, 1.3, 2.3, 1.3, 0.3, 0 V, then 0 for the whole negative half.

Full method: Diode models: ideal, CVD, piecewise linear

2013–14 · Sec A · Q1(c) · 10⅔ marks

What would be the output voltage if the diode and the resistor were connected in parallel?

Answer key

Both elements sit directly across the (ideal) source, so \(V_{out} = V_{in}\): the same staircase. The diode only changes the source current (\((V_{in}-1)/1\) A extra when \(V_{in} > 1\) V; at −3 V the breakdown branch would draw unlimited current from an ideal source).

Full method: Diode models: ideal, CVD, piecewise linear

Question 2

2013–14 · Sec A · Q2(a) · 20 marks

Draw the output waveshape \(v_o\) and also the \(v_i\)–\(v_o\) graph for the circuit shown. Assume a constant 0.7 V forward voltage drop across the diode. \(v_i = 3\sin\omega t\) V; \(v_o\) is the voltage across C (+ on the source side); C is initially uncharged.

Answer key

As drawn (anode at −1 V, cathode at x): the diode conducts when \(v_x \le -1.7\) V, i.e. \(v_i - v_o \le -1.7\) V. During the first positive half nothing happens (\(v_o\) = 0). When \(v_i\) falls below −1.7 V the diode conducts and \(v_o = v_i + 1.7\), reaching \(-3 + 1.7 = \) −1.3 V at \(3T/4\). After that the diode never conducts again (no discharge path): \(v_o\) = −1.3 V DC.

\(v_i\)–\(v_o\) graph: \(v_o\) = 0 at first, a slope-1 segment \(v_o = v_i + 1.7\) for \(v_i\) from −1.7 to −3 V, then a horizontal line at −1.3 V for all later \(v_i\). The voltage across the diode–battery branch is \(v_i - v_o = v_i + 1.3\) V: a sine from −1.7 V to +4.3 V (a clamped output).

Question-bank reading (anode at x, cathode at +1 V): conduction when \(v_i - v_o \ge 1.7\) V, first at \(\omega t = \arcsin(1.7/3)\); \(v_o\) follows \(v_i - 1.7\) up to +1.3 V at \(T/4\) and stays there; branch voltage \(v_i - 1.3\) swings from −4.3 V to +1.7 V. Either way the method is the same; state which orientation you read.

Full method: Clampers and voltage doublers

2013–14 · Sec A · Q2(b) · 6 marks · no longer examined

Why is digital processing of data advantageous over analog processing?

Answer key

Noise immunity and regeneration (noise does not accumulate); results reproducible and insensitive to component tolerance, temperature and ageing; programmable; storage without degradation; error correction, compression, encryption; cheap with VLSI scaling.

2013–14 · Sec A · Q2(c) · 5 marks · no longer examined

Why do we need to miniaturize a transistor as much as possible? If you continue to miniaturize the transistor (switch), what problems may surface?

Answer key

Benefits: more devices per chip, higher speed (shorter channel, smaller capacitance), lower energy per switching event, lower cost per transistor. Problems: short-channel effects and leakage (subthreshold, gate-oxide tunnelling), velocity saturation, heat/power density, process variation, interconnect delay.

2013–14 · Sec A · Q2(d) · 5 marks · no longer examined

Write a script in C that takes a sinusoidal input and provides a full-wave rectified output.

Answer key

Loop over samples \(n\): vin = A*sin(2*M_PI*f*n/fs); vout = fabs(vin); printf(...) (include math.h). Half-wave would be vout = vin > 0 ? vin : 0.

2013–14 · Sec A · Q2(e) · 10⅔ marks · no longer examined

How does your computer program rectify the sinusoidal input mentioned above? Is there any diode inside the processor? If not, what makes that act of rectification possible?

Answer key

The signal is sampled (ADC) into numbers; "rectification" is the arithmetic abs()/sign test on each number. No rectifier diode is in the data path; transistors acting as switches implement the logic (compare, conditional negate / clear sign bit) in the ALU. A DAC rebuilds an analog output if needed.

Question 3

2013–14 · Sec A · Q3(a) · 5 marks

Why do we need to bias a BJT at a proper Q-point before using it as an amplifier?

Answer key
  • The BJT amplifies only in the active region; the bias keeps it there for the whole signal swing.
  • A Q-point near the middle of the load line gives the largest symmetrical swing; too high clips in saturation, too low clips in cut-off.
  • The small-signal parameters (\(g_m = I_C/V_T\), \(r_\pi\)) and so the gain are set by the bias current.
  • A stable bias keeps all this fixed against β spread and temperature.

Full method: Bias circuits, stability and bias design

2013–14 · Sec A · Q3(b) · 16 marks

Figure 3(a) is an inverter gate built with an npn BJT and Figure 3(b) is its \(V_o\) vs \(V_{in}\) (base–emitter voltage) characteristic: \(V_o\) = 5 V up to (0.5 V, 5 V), a straight line down to (0.7 V, 0.2 V), then 0.2 V beyond. Copy Figure 3(b) exactly to scale and draw the collector current \(I_C\) vs \(V_{in}\) on the same graph; mention the coordinates of the bending points of the \(I_C\)–\(V_{in}\) graph.

Answer key

\(I_C = (5 - V_o)/0.48\) kΩ. Bending points: (0.5 V, 0 mA) and (0.7 V, 10 mA); zero below 0.5 V, linear between (slope 50 mA/V, i.e. \(I_C = 50(V_{in} - 0.5)\) mA), flat at 10 mA above 0.7 V (saturation: \((5-0.2)/0.48 = 10\) mA).

Full method: Load lines, transfer curves, switching

2013–14 · Sec A · Q3(c) · 15 marks

Modify both the \(V_o\)–\(V_{in}\) and \(I_C\)–\(V_{in}\) graphs if \(R_C\) is infinity.

Answer key

\(I_C = 0\) for every \(V_{in}\) (no collector path): the \(I_C\) graph lies on the axis. \(V_o\): taking \(R_C \to \infty\) as a limit, \(V_o = 5\) V below 0.5 V and drops vertically to ≈ \(V_{CE,sat}\) at \(V_{in}\) ≈ 0.5 V (the tiniest collector current saturates the transistor). Strictly at \(R_C = \infty\) the collector floats; say so.

Full method: Load lines, transfer curves, switching

2013–14 · Sec A · Q3(d) · 10⅔ marks

Modify both the \(V_o\)–\(V_{in}\) and \(I_C\)–\(V_{in}\) graphs if the supply voltage is decreased from 5 V to 2.5 V (\(R_C\) = 480 Ω).

Answer key

The active-region law \(I_C = 50(V_{in} - 0.5)\) mA is unchanged. \(I_{C,sat} = (2.5 - 0.2)/0.48 = 4.79\) mA, reached at \(V_{in} = 0.5 + 4.79/50 = 0.596\) V.

\(V_o\): (0.5 V, 2.5 V) → (0.596 V, 0.2 V), then 0.2 V. \(I_C\): (0.5 V, 0) → (0.596 V, 4.79 mA), then flat at 4.79 mA.

Full method: Load lines, transfer curves, switching

Question 4

2013–14 · Sec A · Q4(a) · 16 marks

Draw the small-signal circuit diagram of the CE circuit shown. Why is the circuit called a "small-signal" circuit?

Answer key
  • Small-signal circuit: DC sources → short (the emitter becomes AC ground), coupling capacitors → short. \(v_{sig}\) drives the base; \(R_B\) = 100 kΩ ∥ \(r_\pi\) from base to ground; controlled source \(g_mv_\pi\) (and \(r_o\)) from collector to ground; \(R_C\) = 8 kΩ ∥ \(R_L\) = 10 kΩ from collector to ground.
  • "Small signal": \(|v_{be}| \ll V_T\) (≲ 10 mV) so the exponential \(i_C\)–\(v_{BE}\) law can be replaced by its tangent at the Q-point; the circuit is then linear, DC and AC are analysed separately (superposition), and \(g_m = I_C/V_T\), \(r_\pi = \beta/g_m\) are set by the bias.

Full method: Common-emitter amplifier (models: Small-signal models: hybrid-π and T)

2013–14 · Sec A · Q4(b) · 20 marks

Can you determine the values of input resistance \(R_{in}\), output resistance \(R_{out}\) and voltage gain \(A_v\) of the given circuit? If \(v_{sig}\) ≈ 2 mV, find \(V_{out}\).

Answer key

Numerically, no: no β and no bias current are given (and as drawn there is no emitter resistor to set \(I_E\)). The expected answer is symbolic:

  • \(R_{in} = 100\text{ k}\parallel r_\pi\); \(R_{out} = 8\text{ k}\parallel r_o \approx 8\) kΩ; \(A_v = -g_m(r_o\parallel 8\text{ k}\parallel 10\text{ k}) \approx -g_m(4.44\text{ k}\Omega)\); \(V_{out} = A_v \times 2\) mV (no source resistance, so \(v_\pi = v_{sig}\)).
  • Illustration only, with an assumed \(I_C\) = 1 mA, β = 100: \(R_{in}\) = 2.44 kΩ, \(A_v\) = −177.8, \(V_{out}\) = −0.356 V.

Question-bank answer invents data

The Gemini question-bank answer assumes \(I_C\) = 1 mA and β = 100 without saying they are not given, and does not notice that the drawn bias cuts the transistor off. Give the symbolic answer and state any assumption explicitly.

Full method: Common-emitter amplifier

2013–14 · Sec A · Q4(c) · 10⅔ marks

Compare MOSFET and BJT in terms of their operating principles. Mention the advantages and disadvantages of each.

Answer key
  • BJT: bipolar, minority-carrier diffusion across the base; current controlled (\(i_C = \beta i_B\)), exponential \(i_C\)–\(v_{BE}\). MOSFET: unipolar, field effect, gate voltage induces a channel; square law.
  • MOSFET advantages: almost infinite input resistance, no static gate current, small area, near-ideal switch, CMOS low static power, scales well (VLSI).
  • BJT advantages: higher \(g_m\) per unit current (\(I_C/V_T\) vs \(2I_D/V_{OV}\)), higher gain, better high-frequency analog performance.
  • Drawbacks: MOSFET lower \(g_m\), gate oxide damaged by ESD; BJT base current loads the source, larger, thermal runaway.

Full method: Structure and operation

Question 5

2013–14 · Sec B · Q5(a) · 16⅔ marks

Design the circuit of the figure to obtain a current \(I_D\) of 80 µA. Given \(V_t\) = 0.6 V, \(\mu_nC_{ox}\) = 200 µA/V², L = 0.8 µm, W = 4 µm and \(V_A\) = 50 V.

\(k_n = 200 \times 4/0.8 = 1\) mA/V². \(80 = \tfrac12(1000)V_{OV}^2\) ⇒ \(V_{OV}\) = 0.4 V, \(V_{GS} = V_D\) = 1.0 V, R = (3 − 1)/0.08 = 25 kΩ. (Including λ = 1/50: \(V_{GS}\) = 0.996 V, R = 25.05 kΩ; bias design normally ignores λ.)

2013–14 · Sec B · Q5(b) · 15 marks

For the CMOS inverter shown, draw \(V_o\) for the input \(V_{in}\): a 0/5 V square wave, 5 V for 0–5 s, 0 for 5–10 s, 5 V for 10–15 s, 0 for 15–20 s, 5 V for 20–25 s.

Answer key

\(V_{in}\) = 5 V: \(M_n\) on, \(M_p\) off, \(V_o\) = 0. \(V_{in}\) = 0: \(M_p\) on, \(M_n\) off, \(V_o\) = 5 V. So \(V_o\) is the inverted square wave: 0 V for 0–5 s, 5 V for 5–10 s, 0 for 10–15 s, 5 V for 15–20 s, 0 for 20–25 s. Rail to rail, no static current; real edges have finite \(t_{PHL}\), \(t_{PLH}\).

2013–14 · Sec B · Q5(c) · 15 marks

Show that a proper connection of a diode, a resistor and an op-amp can perform the exponential (antilog) function. Mention the assumptions, if any.

Answer key
  • Circuit: diode from \(v_i\) (anode) to the inverting input (cathode), R from the inverting input to the output, + input grounded.
  • Virtual ground: diode voltage = \(v_i\), \(i_D = I_Se^{v_i/nV_T}\); the same current flows through R: \(v_o = -i_DR\) ⇒ \(v_o = -RI_Se^{v_i/nV_T}\).
  • Assumptions: ideal op-amp (virtual ground, no input current), \(v_i > 0\) and \(v_i \gg nV_T\) so the "−1" is negligible, constant temperature (\(I_S\), \(V_T\) fixed). Output is inverted.

Full method: Log, antilog and nonlinear circuits

Question 6

2013–14 · Sec B · Q6(a) · 16⅔ marks

Design a Wien-bridge oscillator with an oscillation frequency of 1000 rad/s. Available capacitors are 0.1 µF, 1 µF and 100 pF.

Answer key

\(\omega_0 = 1/(RC)\) = 1000 rad/s ⇒ RC = 1 ms. With C = 0.1 µF: R = 10 kΩ (sensible; 1 µF needs 1 kΩ, which loads the op-amp; 100 pF needs 10 MΩ, too large). Amplifier gain \(1 + R_f/R_1 = 3\): \(R_1\) = 10 kΩ, \(R_f\) = 20 kΩ (slightly more for start-up). Note ω is given: do not divide by 2π.

Full method: Wien-bridge oscillator

2013–14 · Sec B · Q6(b) · 15 marks (7 + 8)

A system blocks 20 Hz and 20 kHz but passes 10 kHz. (i) Draw the frequency response of the system. (ii) Draw a block diagram of the system.

Answer key
  • It is a band-pass filter with 20 Hz < \(f_L\) < 10 kHz and 10 kHz < \(f_H\) < 20 kHz (e.g. \(f_L\) = 5 kHz, \(f_H\) = 15 kHz).
  • Response: flat pass-band around 10 kHz, −3 dB at \(f_L\) and \(f_H\), roll-off of −20 dB/decade per order on each side, low at 20 Hz and 20 kHz.
  • Block diagram: high-pass (\(f_L\)) in cascade with low-pass (\(f_H\)).

Full method: Active filters

2013–14 · Sec B · Q6(c) · 15 marks

Implement \(z = 5V_1 - 3V_2\) using only one op-amp, where \(V_1\) and \(V_2\) are input signals.

Answer key

\(V_1\) directly to the + input; \(R_1\) = 10 kΩ from \(V_2\) to the − input; \(R_2\) = 30 kΩ feedback; \(R_x\) = 30 kΩ from the − input to ground.

\(z = V_1\left(1 + \dfrac{R_2}{R_1\parallel R_x}\right) - \dfrac{R_2}{R_1}V_2 = V_1(1 + 30/7.5) - 3V_2 = \) \(5V_1 - 3V_2\) ✓. (A divider on the + side cannot help: with \(R_2/R_1 = 3\) the + gain is at most 4, so the extra \(R_x\) is needed.)

Full method: Summers, difference amplifier, V-to-I

Question 7

2013–14 · Sec B · Q7(a) · 26⅔ marks

Derive the expressions for input resistance, output resistance and overall voltage gain of a common-gate (CG) amplifier.

Answer key
  • T-model, \(r_o\) neglected: signal \(v_{sig}\) with \(R_{sig}\) into the source, gate at AC ground, \(R_D\) from drain to ground, load \(R_L\).
  • \(i = -g_mv_{gs}\) flows in at the source with \(v_{gs} = -v_i\): \(R_{in} = 1/g_m\).
  • Output: set \(v_{sig}\) = 0, the drain sees a current source: \(R_{out} = R_D\); \(A_{vo} = g_mR_D\) (non-inverting).
  • \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_D\parallel R_L) = \dfrac{g_m(R_D\parallel R_L)}{1 + g_mR_{sig}}\).
  • With \(r_o\): \(R_{in} \approx (r_o + R_D\parallel R_L)/(1 + g_mr_o)\), \(R_{out} = R_D\parallel[r_o + R_{sig}(1 + g_mr_o)]\).

Full method: Feedback-biased CS, CG and CD

2013–14 · Sec B · Q7(b) · 15 marks

Design a 40 dB low-pass filter (LPF) with a cut-off frequency of 1 kHz. [You have only one op-amp.]

Answer key

"40 dB" is ambiguous; give the reading you take.

  • 40 dB pass-band gain (×100), first order: inverting LPF with \(C_f\) = 10 nF, \(R_f = 1/(2\pi \cdot 1000 \cdot 10\text{ nF}) = 15.9\) kΩ, \(R_1 = R_f/100 = 159\) Ω (or \(C_f\) = 1 nF, \(R_f\) = 159 kΩ, \(R_1\) = 1.59 kΩ, kinder to the source).
  • −40 dB/decade roll-off, second order: unity-gain Sallen–Key Butterworth, \(R_1 = R_2\) = 11.25 kΩ, \(C_1\) (to output) = 20 nF, \(C_2\) (to ground) = 10 nF, Q = 0.707, \(f_c = 1/(2\pi R\sqrt{C_1C_2})\) = 1 kHz.

Full method: Active filters

2013–14 · Sec B · Q7(c) · 5 marks

What are the characteristics of an ideal op-amp?

Answer key

Infinite open-loop gain, infinite input resistance (zero input currents), zero output resistance, infinite bandwidth and slew rate, infinite CMRR, zero offset voltage/current and drift. With negative feedback: virtual short (\(v_+ = v_-\)) and zero input current. Output limited to the rails.

Full method: The ideal op-amp; inverting and non-inverting

Question 8

2013–14 · Sec B · Q8(a) · 16⅔ marks

For the circuit shown, find the value of \(V_o\). For both NMOS, \(V_t\) = 1 V, λ = 0 and \(\mu_nC_{ox}(W/L)\) = 1 mA/V².

Answer key

2013–14 · Sec B · Q8(b) · 15 marks

What are the AC imperfections of a practical op-amp? How can we find the values of input offset voltage and input offset current?

Answer key
  • AC: finite open-loop gain falling at −20 dB/decade (constant gain–bandwidth product \(f_t = A_0f_b\)), slew-rate limit, full-power bandwidth \(f_M = SR/(2\pi V_{o,max})\), CMRR falling with frequency, non-zero output resistance.
  • \(V_{OS}\): ground the input of an amplifier with closed-loop gain \(1 + R_2/R_1\) (use small resistors so bias currents do not matter), measure \(V_o\): \(V_{OS} = V_o/(1 + R_2/R_1)\).
  • \(I_{OS}\): add equal large resistors R in series with each input (or \(R_3 = R_1\parallel R_2\) at +), measure the extra output due to the bias currents, \(I_{OS} = |I_{B1} - I_{B2}|\).

Full method: The ideal op-amp; inverting and non-inverting

2013–14 · Sec B · Q8(c) · 15 marks · no longer examined

Explain SCR and TRIAC operation with suitable examples.

Answer key

SCR: pnpn device (anode, cathode, gate); blocks both ways until a gate pulse (or breakover) latches it on in the forward direction; stays on until current falls below the holding current. Two-transistor model: \(I_A = (\alpha_2I_G + I_{CBO1} + I_{CBO2})/(1 - \alpha_1 - \alpha_2)\). TRIAC: two anti-parallel SCRs with one gate, conducts both ways. Examples: SCR phase-controlled rectifier; TRIAC light dimmer / fan regulator.

Full method: Special diodes and thyristors
