Question 1

2021–22 · Sec A · Q1(a) · 20 marks

Suppose you have two supply voltage sources, \(v_1 = \sin(100t)\) V and \(v_2 = 1\) V. Design a circuit using op-amps that will produce an output voltage \(v_o = (\sin 50t)^2\) V. Also show that this circuit produces this output.

Answer key

Identity. \(\sin^2(50t) = \tfrac12 - \tfrac12\cos(100t)\). We have \(v_2 = 1\) (the DC part) and need \(\cos 100t\), which is the derivative of \(v_1\): \(\dfrac{dv_1}{dt} = 100\cos 100t\).

Stage 1, differentiator (ideal op-amp, \(C = 1\ \mu\)F, \(R = 10\) kΩ, \(RC = 10\) ms): \(v_A = -RC\dfrac{dv_1}{dt} = -0.01\times 100\cos 100t = -\cos 100t\).

Stage 2, averager: \(v_A\) and \(v_2\) each through 10 kΩ to the + input of a voltage follower. Equal resistors, so \(v_+ = \dfrac{v_A + v_2}{2}\) (superposition, no current into the op-amp), and \(v_o = v_+\).

Show: \(v_o = \dfrac{-\cos 100t + 1}{2} = \dfrac{1 - \cos 100t}{2} = \sin^2(50t)\) ✓. Check at \(t = 0\): \(v_1\) is 0, \(dv_1/dt = 100\), \(v_A = -1\), \(v_o = 0\) ✓.

Common mark-loser

An integrator route ("integrate \(\sin 100t\) to get \(\cos\)") gives \(\tfrac12(\cos 100t - 1)\) from an uncharged capacitor, so the output is off by 0.5 V DC. Use the differentiator, which has no constant of integration.

Full method: Building a given expression

2021–22 · Sec A · Q1(b) · 26⅔ marks

For an R-C phase shift oscillator, derive the expression of oscillation frequency. Also derive the conditions for Barkhausen criteria to be satisfied. You may assume that in the feedback part of the oscillator all the resistors are of the same value and all the capacitors are of the same value.

Answer key

Circuit: an inverting amplifier (gain \(A = -R_f/R\), the last ladder resistor R is its input resistor) whose output feeds a three-section ladder: C in series, R to ground, three times. The ladder gives 180° of phase shift, the inverting amplifier the other 180°.

Loop equations (loop currents \(I_1, I_2, I_3\); \(V_o\) is the amplifier output, \(V_f = I_3R\) is fed back):

\[ V_o = I_1\!\left(R + \tfrac1{sC}\right) - I_2R \] \[ 0 = -I_1R + I_2\!\left(2R + \tfrac1{sC}\right) - I_3R \] \[ 0 = -I_2R + I_3\!\left(2R + \tfrac1{sC}\right) \]

Solving: \(\beta(s) = \dfrac{V_f}{V_o} = \dfrac{1}{1 + \dfrac{6}{sRC} + \dfrac{5}{(sRC)^2} + \dfrac{1}{(sRC)^3}}\). Put \(s = j\omega\) and \(x = 1/(\omega RC)\): \(\dfrac1\beta = (1 - 5x^2) + j\,(x^3 - 6x)\).

  • Phase condition (the ladder must give 180°, so \(1/\beta\) is real): imaginary part \(= 0\) ⇒ \(x^2 = 6\) ⇒ \(\omega_0 = \dfrac{1}{\sqrt6\,RC}\), \(f_0 = \dfrac{1}{2\pi\sqrt6\,RC}\).
  • Magnitude condition: at \(x^2 = 6\): \(1/\beta = 1 - 30 = -29\), so \(\beta = -1/29\). Barkhausen: \(A\beta = 1\) ⇒ \(A = -29\), i.e. \(R_f/R \ge 29\) (slightly above 29 to start, a limiter then sets the amplitude).

(If the ladder is made of series R and shunt C instead, \(\omega_0 = \sqrt6/RC\) and the required gain is again 29.)

Full method: RC phase-shift oscillator

Question 2

2021–22 · Sec A · Q2(a) · 26⅔ marks

Draw a one-shot multivibrator circuit using op amp. Explain the operation of the circuit.

Answer key

Circuit: a comparator with positive feedback divider \(R_1, R_2\) (\(\beta = R_1/(R_1+R_2)\), from \(v_O\) to the + input) and an \(R\)–\(C\) network from \(v_O\) to the − input. Diode D₁ across C clamps \(v_-\) at about +0.7 V. A trigger (a small Ct, Rt differentiator and diode D₂) injects a negative pulse at the + input.

  • Stable state: \(v_O = +L\). D₁ conducts, so \(v_- = V_D = 0.7\) V; \(v_+ = \beta L > 0.7\) V, so the state is held.
  • Trigger: a negative pulse pulls \(v_+\) below 0.7 V. The output flips to \(-L\), and \(v_+ = -\beta L\). D₁ turns off.
  • Quasi-stable state: C discharges from +0.7 V toward \(-L\) through R: \(v_-(t) = -L + (L + 0.7)e^{-t/RC}\). The output returns to +L when \(v_-\) reaches \(-\beta L\).
  • Pulse width: \(T = RC\ln\dfrac{L + V_D}{L(1-\beta)} \approx RC\ln\dfrac{1}{1-\beta}\). With \(\beta = 0.5\): \(T \approx 0.69\,RC\) (0.75 RC with L = 13 V and VD = 0.7 V).
  • Recovery: after the output returns, C recharges to 0.7 V through R and D₁; do not re-trigger until it has.

Full method: Astable, monostable, square–triangle generators

2021–22 · Sec A · Q2(b)(ii) · 10 marks

Design an astable multivibrator using 555 timer which has 10 ms period and 75% duty cycle.

Answer key

Astable: C charges through RA + RB and discharges through RB between VCC/3 and 2VCC/3. \(t_H = 0.693(R_A+R_B)C = 7.5\) ms, \(t_L = 0.693R_BC = 2.5\) ms ⇒ \(R_A = 2R_B\).

Choose C = 1 µF: \(R_B = \dfrac{2.5\text{ ms}}{0.693\times1\,\mu\text{F}} = \mathbf{3.61}\) kΩ, \(R_A = \mathbf{7.21}\) kΩ. Check: \(D = (R_A+R_B)/(R_A+2R_B) = 0.75\), \(T = 0.693(R_A+2R_B)C = 10\) ms ✓. Connections: RA from VCC to pin 7, RB from pin 7 to pins 6 and 2, C to ground, pin 5 through 0.01 µF to ground. (The same question appears in 2022–23 Q7(b).)

Full method: The 555 timer

Question 3

2021–22 · Sec A · Q3(a) · 17 marks · no longer examined

What are DAC circuits? How does an R-2R ladder DAC circuit operate? Explain using circuit diagram and mathematical analysis.

Answer key

A DAC converts an n-bit binary word \(b_{n-1}\dots b_0\) into an analog voltage proportional to its value. R-2R ladder: each bit switches a 2R leg between \(V_{ref}\) (bit = 1) and ground (bit = 0); R's join the leg nodes, and the LSB end is terminated with 2R to ground.

  • At every node the resistance looking toward the LSB end (leg 2R in parallel with the rest) is 2R, so each node splits into two equal halves: Thevenin resistance seen from any node toward the end is R.
  • Superposition: a single bit \(b_k\) at \(V_{ref}\) with the rest grounded contributes \(V_{ref}/2\) at its own node, halved at each step toward the output node: \(V_{ref}\,2^{k-n}\) at the output (MSB: \(V_{ref}/2\), next: \(V_{ref}/4\), ...).
  • \(v_A = V_{ref}\left(\dfrac{b_{n-1}}2 + \dfrac{b_{n-2}}4 + \dots + \dfrac{b_0}{2^n}\right)\), with Thevenin resistance R. 4-bit example: \(V_{ref}(8b_3 + 4b_2 + 2b_1 + b_0)/16\); word 1010 gives \(0.625V_{ref}\).
  • A voltage follower (or a non-inverting amplifier of gain \(1 + R_f/R_i\)) buffers the high-impedance node; an inverted ladder into an inverting summer with feedback R gives \(v_o = -V_{ref}\sum b_k2^{k-n}\).
2021–22 · Sec A · Q3(b) · 17 marks · no longer examined

Draw a simplified block diagram of PLL and briefly explain its operation.

Answer key

Blocks in a loop: phase detector (multiplier or XOR) compares the input \(f_i\) with the VCO output \(f_o\) and produces an error voltage; a low-pass loop filter removes the sum-frequency term and keeps the DC error \(v_e\); an optional amplifier; a VCO whose frequency is \(f_o = f_{free} + K_Vv_c\) closes the loop.

  • Free-running: \(v_c = 0\), VCO at \(f_{free}\). When \(f_i\) comes within the capture range, the error beat note passes the filter, pulls the VCO toward \(f_i\) and the loop locks: \(f_o = f_i\) with a constant phase difference.
  • Once locked, the loop tracks \(f_i\) over the wider lock range. Uses: FM demodulation (\(v_c\) is the output), frequency synthesis (divider in the loop), clock recovery.

Question 4

2021–22 · Sec A · Q4(a) · 23 marks

Draw a sawtooth wave generator circuit using op amp. Explain the operation of the circuit.

Answer key

Circuit: the square–triangle generator (non-inverting Schmitt trigger A1 plus inverting integrator A2) with the integrator's input resistor split into two parallel paths: D₁ in series with Ra (conducts when \(v_{sq} = +L\)) and D₂ in series with Rb (conducts when \(v_{sq} = -L\)).

  • Thresholds (A1 flips when its + input crosses 0): \(V_{TH} = +L\dfrac{R_2}{R_3}\), \(V_{TL} = -L\dfrac{R_2}{R_3}\); peak-to-peak \(2LR_2/R_3\).
  • Slow ramp down while \(v_{sq} = +L\): slope \(-L/(R_aC)\), so \(T_1 = 2\dfrac{R_2}{R_3}R_aC\).
  • Fast ramp up while \(v_{sq} = -L\): slope \(+L/(R_bC)\), so \(T_2 = 2\dfrac{R_2}{R_3}R_bC\).
  • \(f = \dfrac{1}{T_1 + T_2} = \dfrac{R_3}{2R_2C(R_a + R_b)}\). Example: \(R_2/R_3 = \tfrac12\), \(R_a = 100\) kΩ, \(R_b = 10\) kΩ, C = 0.1 µF: \(T_1 = 10\) ms, \(T_2 = 1\) ms, f = 90.9 Hz. (Ideal diodes; \(L \gg 0.7\) V.)

Full method: Astable, monostable, square–triangle generators

2021–22 · Sec A · Q4(b) · 23⅔ marks · no longer examined

Discuss basic operational characteristics and parameters of CMOS and TTL logic families.

Answer key
  • Parameters: noise margins \(NM_H = V_{OH,min} - V_{IH,min}\), \(NM_L = V_{IL,max} - V_{OL,max}\); propagation delay \(t_p\); fan-out; power dissipation; supply voltage; speed–power product.
  • TTL (BJT, multi-emitter input stage, totem-pole output): \(V_{CC}\) = 5 V; \(V_{OH} \approx 3.4\) V, \(V_{OL} \approx 0.2\) V, \(V_{IH} = 2\) V, \(V_{IL} = 0.8\) V (noise margins ≈ 0.4 V). Static power is drawn in both states; \(t_p\) ≈ 10 ns (standard); fan-out about 10.
  • CMOS (complementary MOSFETs): rails \(V_{OH} = V_{DD}\), \(V_{OL} = 0\); \(V_{IL} \approx V_{DD}/2\), noise margins ≈ 0.45 \(V_{DD}\); essentially zero static power (only dynamic \(CV_{DD}^2f\)); very high input resistance, so large fan-out; wide supply range; slower than TTL at the same node, but the lower power allows high integration.

2021–22 · Sec B · Q5(b) · 15 marks

Design a limiter circuit using only diodes and 10 kΩ resistors to provide an output signal limited to the range ±2.1 V. Assume that each diode has a 0.7 V drop when conducting.

Answer key

One conducting diode holds 0.7 V, so each limit needs \(2.1/0.7 = 3\) diodes in series. Positive limit: a string of 3 diodes from \(v_o\) to ground (anodes toward \(v_o\)). Negative limit: a second string of 3, reversed (antiparallel). The 10 kΩ goes in series with the input.

Operation: for \(|v_i| \le 2.1\) V no string conducts, so \(v_o = v_i\) (no load: no drop in the 10 kΩ). For \(v_i > 2.1\) V the upper string conducts and \(v_o = +2.1\) V; for \(v_i < -2.1\) V, \(v_o = -2.1\) V. The source current when limiting is \((|v_i| - 2.1)/10\) kΩ, which the resistor keeps small (e.g. 0.79 mA at \(|v_i| = 10\) V). Transfer characteristic: slope 1 for \(|v_i| \le 2.1\) V, flat at ±2.1 V beyond.

Full method: Clippers and transfer characteristics

Suppose for the bridge rectifier circuit shown in Fig. for Q. No. 5(c), \(v_s\) is a 12 V (rms) sinusoid, \(V_D\) = 0.7 V, and R = 100 Ω. Find the average of the output voltage \(v_o\), the peak diode current, and the PIV.

Question 6

2021–22 · Sec B · Q6(a) · 10⅔ marks

What is Early-effect in a BJT? Draw the I-V curve of a practical BJT showing the Early effect.

Answer key
  • Definition: in the active region a larger \(v_{CE}\) widens the reverse-biased collector–base depletion region, narrowing the neutral base. The base transport factor and the collector current rise slightly, so \(i_C\) is not flat versus \(v_{CE}\).
  • \(i_C = I_Se^{v_{BE}/V_T}\left(1 + \dfrac{v_{CE}}{V_A}\right)\), \(V_A\) = Early voltage (50–100 V). Output resistance \(r_o = \dfrac{V_A + V_{CE}}{I_C} \approx \dfrac{V_A}{I_C}\).
  • Curve: in each curve \(i_C\) slopes up in the active region; extended backward the straight lines all meet the \(v_{CE}\) axis at \(-V_A\).

Question 7

2021–22 · Sec B · Q7(a) · 26⅔ marks

Derive the expression of \(R_i\), \(R_o\), \(A_v\), and \(G_v\) for a common emitter amplifier with emitter resistance (\(R_e\)) using the T model.

Answer key

Circuit: signal \(v_{sig}\) with \(R_{sig}\) into the base; \(R_e\) unbypassed in the emitter; \(R_C\) in the collector and load \(R_L\) coupled to it. \(r_o\) is neglected. T model: base current \(i_b\), emitter current \(i_e = (\beta+1)i_b\), \(r_e\) in series with the emitter, dependent current \(\alpha i_e\) at the collector.

  • Input resistance. \(v_b = i_e(r_e + R_e)\) and \(i_b = i_e/(\beta+1)\), so \(R_i = \dfrac{v_b}{i_b} = (\beta+1)(r_e + R_e)\) (with a bias resistor \(R_B\): \(R_B\parallel R_i\)).
  • Voltage gain. \(i_e = \dfrac{v_b}{r_e + R_e}\), \(v_o = -\alpha i_e(R_C\parallel R_L)\), so \(A_v = \dfrac{v_o}{v_b} = -\dfrac{\alpha(R_C\parallel R_L)}{r_e + R_e}\). Open circuit: \(A_{vo} = -\dfrac{\alpha R_C}{r_e + R_e}\). For \(R_e \gg r_e\), \(A_v \approx -\dfrac{R_C\parallel R_L}{R_e}\), nearly independent of \(\beta\).
  • Output resistance. With \(v_{sig} = 0\) the dependent source is dead (\(i_e = 0\)): \(R_o = R_C\) (\(R_C\parallel r_o\) if kept; with \(R_e\) the transistor's own \(r_o\) rises to \(r_o[1 + g_mR_e r_\pi/(r_\pi + R_e + R_{sig})]\)).
  • Overall gain. \(G_v = \dfrac{R_i}{R_i + R_{sig}}A_v = -\dfrac{\beta(R_C\parallel R_L)}{R_{sig} + (\beta+1)(r_e + R_e)}\).
  • Effect of \(R_e\): \(R_i\) goes up by about \((1 + R_e/r_e)\), gain falls by the same factor (gain–bandwidth, linearity and stability traded for gain).

Full method: CE amplifier with emitter resistance

2021–22 · Sec B · Q7(b) · 20 marks

A CS amplifier utilizes a MOSFET biased at \(I_D\) = 0.25 mA with \(V_{ov}\) = 0.25 V and \(R_D\) = 20 kΩ. The amplifier is fed with a signal source having \(R_{sig}\) = 100 kΩ, and a 20 kΩ load is connected to the output. Find \(R_{in}\), \(A_{vo}\), \(R_o\), \(A_v\), and \(G_v\).

Answer key

\(g_m = \dfrac{2I_D}{V_{ov}} = \dfrac{2(0.25)}{0.25} = 2\) mA/V. No \(V_A\) is given, so \(r_o = \infty\).

  • \(R_{in} = \infty\) (gate, no DC path assumed in the amplifier itself).
  • \(A_{vo} = -g_mR_D = -2\times20 = \mathbf{-40}\) V/V.
  • \(R_o = R_D = \mathbf{20}\) kΩ.
  • \(A_v = -g_m(R_D\parallel R_L) = -2\times10 = \mathbf{-20}\) V/V.
  • \(G_v = \dfrac{R_{in}}{R_{in} + R_{sig}}A_v = \mathbf{-20}\) V/V (no loss in \(R_{sig}\) since \(R_{in} = \infty\)).

Full method: Common-source amplifier

Question 8

2021–22 · Sec B · Q8(a) · 16⅔ marks · no longer examined

Explain the read and write operation in a DRAM cell.

Answer key

1T1C cell: one access NMOS (gate on the word line WL, drain/source between the bit line BL and the storage capacitor \(C_S\)).

  • Write: WL high turns the transistor on; BL is driven to \(V_{DD}\) (write 1) or 0 (write 0) and \(C_S\) charges or discharges through it. WL goes low, trapping the charge.
  • Read: BL is precharged to \(V_{DD}/2\); WL high shares charge between \(C_S\) and the bit-line capacitance \(C_B\): \(\Delta V = \pm\dfrac{V_{DD}}{2}\dfrac{C_S}{C_S + C_B}\) (tens of mV). A sense amplifier amplifies it. The read is destructive, so the sensed value is written back (restore).
  • Charge leaks away, so every cell is refreshed every few ms.
2021–22 · Sec B · Q8(b) · 15 marks · no longer examined

Explain briefly the programming and erase operation in a Flash Memory.

Answer key

A flash cell is a MOSFET with a floating gate between the control gate and the channel; stored electrons shift \(V_t\) (low \(V_t\) = 1, high \(V_t\) = 0).

  • Program (NOR flash): high gate voltage (about 12 V) and a high drain voltage; hot electrons are injected from the channel onto the floating gate, raising \(V_t\).
  • Erase: electrons are removed by Fowler–Nordheim tunnelling to the source (or the substrate) with a high voltage of opposite polarity, lowering \(V_t\). It is done in blocks.
  • Read: apply a gate voltage between the two \(V_t\) values and sense whether the cell conducts.

From the K-maps: \(J_0 = \overline{Q_1}\), \(K_0 = 1\), \(J_1 = Q_0\), \(K_1 = 1\). Verification: start 00: \(J_0 = 1, K_0 = 1\) → \(Q_0\) sets; \(J_1 = 0\) → 01. From 01: \(J_0 = 1\) but \(K_0 = 1\) toggles \(Q_0\) to 0; \(J_1 = 1\) sets \(Q_1\) → 10. From 10: \(J_0 = 0\), \(K_0 = 1\) → \(Q_0 = 0\); \(K_1 = 1\) resets \(Q_1\) → 00. The unused state 11 goes to 00 (\(J_0 = 0, K_0 = 1\), \(J_1 = K_1 = 1\)), so it is self-starting.
