Question 1

2016–17 · Sec A · Q1(a) · 21⅔ marks

Determine the differential equation solved by the circuit given in Fig. for Q. No. 1: (i) when the capacitor C is absent; (ii) when the capacitor C is present. At what value of C does the circuit become a non-inverting amplifier?

Answer key

Ideal op-amp: \(v_- = v_+ \equiv v_p\). The − side is a non-inverting amplifier: \(v_{out} = A\,v_p\), \(A = 1 + R_2/R_1\).

(i) C absent. The + node is an RC low-pass: \(\dfrac{v_{in} - v_p}{R_{in}} = C_{in}\dfrac{dv_p}{dt}\), so \(v_{in} = v_p + R_{in}C_{in}\dot v_p\). With \(v_p = v_{out}/A\):

\[ A\,v_{in} = v_{out} + R_{in}C_{in}\,\frac{dv_{out}}{dt} \]

A first-order low-pass of DC gain A and time constant \(R_{in}C_{in}\).

(ii) C present. KCL at the + node (no current into the op-amp): \(\dfrac{v_{in} - v_p}{R_{in}} = C_{in}\dot v_p + C(\dot v_p - \dot v_{out})\). Put \(v_p = v_{out}/A\):

\[ A\,v_{in} = v_{out} + R_{in}\big[C_{in} + C(1 - A)\big]\frac{dv_{out}}{dt} \]

The feedback C makes the effective capacitance \(C_{in} - (A-1)C\) (positive feedback reduces it).

Non-inverting amplifier: the derivative term vanishes when \(C_{in} + C(1-A) = 0\): \(C = \dfrac{C_{in}}{A - 1} = C_{in}\dfrac{R_1}{R_2}\). Then \(v_{out} = A\,v_{in}\) exactly.

Full method: Active filters

Question 2

2016–17 · Sec A · Q2(a) · 20 marks

Determine the type of filter shown in the circuit in Fig. for Q. No. 2(a) by computing the transfer function in the frequency domain.

Answer key

Inverting amplifier: \(H = -Z_f/Z_{in}\) with \(Z_{in} = R_1 + \dfrac{1}{sC_1} = \dfrac{1 + sR_1C_1}{sC_1}\) and \(Z_f = \dfrac{R_2}{1 + sR_2C_2}\).

\[ H(s) = -\frac{sR_2C_1}{(1 + sR_1C_1)(1 + sR_2C_2)} \]
  • At low frequency \(H \to -sR_2C_1\) (rises 20 dB/dec, C₁ blocks DC); at high frequency \(H \to -\dfrac{R_2C_1}{R_1C_1R_2C_2\,s} \to 0\) (falls 20 dB/dec, C₂ shunts).
  • Hence a band-pass filter: lower corner \(\omega_L = \dfrac{1}{R_1C_1}\), upper corner \(\omega_H = \dfrac{1}{R_2C_2}\), needs \(R_1C_1 > R_2C_2\) so that \(\omega_L < \omega_H\).
  • Mid-band gain (between the corners): \(-R_2/R_1\) (inverting). Second order overall (one pole from each RC).

(The same circuit is 2017–18 Q6(a).)

2016–17 · Sec A · Q2(b) · 11⅔ marks

Determine the op-amp circuit that generates the transfer characteristic shown in Fig. for Q. No. 2(b).

Characteristic: \(V_{out} = -12\) V for \(V_{in} < -8\) V and \(V_{out} = +22\) V for \(V_{in} > -8\) V (one switching edge at \(V_{in} = -8\) V, non-inverting, asymmetric levels +22 V and −12 V; the original draws a short dashed segment from −8 V to 0 V on the lower level).

Answer key

Reading as a plain comparator: non-inverting comparator: \(V_{in}\) to the + input, a reference \(V_{REF} = -8\) V (a −8 V supply, or a divider from the negative rail) to the − input. Output saturates at the supply rails, so use supplies \(+V_{CC} = +22\) V and \(-V_{EE} = -12\) V: \(V_{out} = +22\) V when \(V_{in} > -8\), \(-12\) V when \(V_{in} < -8\). (If the op-amp rails are standard, limit the output with a Zener pair or a clamp to get +22/−12.)

Reading with the dashed segment as hysteresis (\(V_{TL} = -8\) V, \(V_{TH} = 0\) V): a non-inverting Schmitt trigger with a reference: \(V_{in}\) through \(R_1\) to the + input, \(V_{out}\) through \(R_2\) to the + input, \(V_{ref}\) at the − input. It switches when \(v_+ = V_{ref}\): \(V_{in} = V_{ref}\dfrac{R_1+R_2}{R_2} - V_{out}\dfrac{R_1}{R_2}\). \(V_{TH} = 0\) (with \(V_{out} = -12\)): \(V_{ref}(R_1+R_2) = -12R_1\); \(V_{TL} = -8\) (with \(V_{out} = +22\)): \(-8R_2 = V_{ref}(R_1+R_2) - 22R_1 = -34R_1\) ⇒ \(R_2 = 4.25R_1\) (e.g. 10 kΩ and 42.5 kΩ), \(V_{ref} = -12R_1/(R_1+R_2) = -2.29\) V.

An inverting Schmitt trigger gives the right thresholds but the wrong polarity (output +22 V for very negative input), so it does not match the drawn curve.

Question 3

2016–17 · Sec A · Q3(a) · 20 marks · no longer examined

Design a 4-bit up counter using T flip-flops. It should include a control pin called UP/DOWN. When UP/DOWN = 0 the circuit should behave as an up counter and when UP/DOWN = 1 as a down counter. The circuit should also have a synchronous active-low RESET pin.

Answer key

Synchronous counter, all clocks common. A bit toggles when all lower bits are 1 (counting up) or all lower bits are 0 (counting down). With \(U\) = UP/DOWN, \(E_j = Q_j \oplus U\) is 1 when \(Q_j = 1\) (up) or \(Q_j = 0\) (down). Toggle enables:

\(t_0 = 1\), \(t_1 = E_0\), \(t_2 = E_0E_1\), \(t_3 = E_0E_1E_2\).

Synchronous active-low reset: when the pin RN = 0 each flip-flop must go to 0 at the next clock, i.e. toggle only if \(Q_j = 1\). So \(T_j = RN\cdot t_j + \overline{RN}\cdot Q_j\) (normal toggle logic when RN = 1, \(T_j = Q_j\) when RN = 0).

Check: up from 0111: \(E_0 = E_1 = E_2 = 1\), so all of \(T_1..T_3\) = 1, giving 1000 ✓. Down from 1000: \(E_j = \overline{Q_j} = 1\) for j = 0, 1, 2 so all toggle: 0111 ✓.

2016–17 · Sec A · Q3(b) · 11⅔ marks · no longer examined

Triangular numbers are sequences formed by continuous summation of the natural numbers (1, 3, 6, 10, …; dot-triangle figure). Design the simplest possible logic circuit that outputs 1 whenever it detects a 4-bit triangular number.

Answer key

4-bit inputs \(ABCD\) (A = MSB). Triangular numbers up to 15: 1, 3, 6, 10, 15 (minterms 1, 3, 6, 10, 15; 0 is not counted). Minterms 1 and 3 combine (0001, 0011 → \(\bar A\bar BD\)); the others (0110, 1010, 1111) share no pair of adjacent cells. 6 and 10 differ in two bits but share \(CD'\) with \(A\oplus B\).

\[ f = \bar A\bar BD + (A \oplus B)\,C\bar D + ABCD \]

(= \(\bar A\bar BD + \bar ABC\bar D + A\bar BC\bar D + ABCD\), four product terms.) 0 can be added as a don't-care if the problem allows.

2016–17 · Sec A · Q3(c) · 15 marks · no longer examined

Show how a D flip-flop and a T flip-flop can be constructed from J-K flip-flops.

Answer key

JK characteristic: \(Q^+ = J\bar Q + \bar KQ\).

  • D from JK: \(J = D\), \(K = \bar D\) (an inverter between D and K): \(Q^+ = D\bar Q + DQ = D\).
  • T from JK: \(J = K = T\): \(Q^+ = T\bar Q + \bar TQ = T \oplus Q\) (toggles when T = 1, holds when T = 0).

Question 4

2016–17 · Sec A · Q4(a) · 25 marks · no longer examined

Show a CMOS implementation of edge-triggered D flip-flops with asynchronous reset.

Answer key

A master–slave pair of transparent latches built from CMOS transmission gates (TG: an NMOS and a PMOS in parallel with complementary gates CLK and CLK̄).

  • Master latch: input TG1 (on when CLK = 0) feeds a loop of two inverting stages; a feedback TG2 (on when CLK = 1) closes the loop. CLK = 0: transparent, follows D. CLK = 1: holds.
  • Slave latch: same structure with opposite clock phases: input TG3 (on when CLK = 1), feedback TG4 (on when CLK = 0). Output Q is taken from the slave.
  • On the rising edge the master freezes the value of D and the slave copies it: edge-triggered.
  • Asynchronous reset: replace the inverter in each loop (and the output stage) with a 2-input NOR gate, whose second input is RESET. When RESET = 1 the nodes are forced to Q = 0 regardless of CLK (static CMOS NOR: two series PMOS and two parallel NMOS).
  • Count: 4 TGs (8 transistors) + 4 inverting stages (inverters/NORs); about 20 to 24 transistors.
2016–17 · Sec A · Q4(b) · 21⅔ marks · no longer examined

Derive complex gates for the following logic functions, using as few transistors as possible: (i) \(f(X_1,X_2,X_3,X_4) = \sum m(0,4,6,8,9,15) + D(3,7,11,13)\); (ii) \(\bar f = (A + B)(C + D)(\bar A + B + D)\).

Answer key

A static CMOS gate output \(= \overline{\text{PDN function}}\). The NMOS pull-down network (PDN) must conduct when \(f = 0\), so its function is \(\bar f\). The pull-up network is the dual (series ↔ parallel).

(i) Minimise \(\bar f\) (zeros at 1, 2, 5, 10, 12, 14; don't-cares 3, 7, 11, 13): \(\bar f = \bar X_2X_3 + X_1X_2\bar X_4 + \bar X_1X_4\). (Check against the on-set 0, 4, 6, 8, 9, 15: none is covered ✓.) PDN: three branches in parallel: [\(\bar X_2\)–\(X_3\)], [\(X_1\)–\(X_2\)–\(\bar X_4\)], [\(\bar X_1\)–\(X_4\)] (7 NMOS); PUN: three groups in series: [\(\bar X_2 \parallel X_3\)], [\(X_1 \parallel X_2 \parallel \bar X_4\)], [\(\bar X_1 \parallel X_4\)] (7 PMOS). The gate output is \(f\) directly. Complemented inputs \(\bar X_1, \bar X_2, \bar X_4\) need three inverters (6 transistors): 20 transistors in all. (The alternative PDN = f needs more transistors and an extra output inverter.)

(ii) The given function is already the PDN function. Simplify first: \((A + B)(\bar A + B + D) = B + AD\), so \(\bar f = (B + AD)(C + D) = BC + BD + AD = BC + D(A + B)\). PDN: [B–C] ∥ [D–(A ∥ B)] (5 NMOS); PUN: [B ∥ C] in series with [D ∥ (A–B)] (5 PMOS). Output \(f\); 10 transistors, no inverters. (Unsimplified form: 7 + 7 plus an inverter for \(\bar A\).)

Question 5

2016–17 · Sec B · Q5(a) · 20 marks

Consider a half-wave peak rectifier fed with a voltage having a triangular waveform with 20 V peak-to-peak amplitude, zero average and 1 kHz frequency. Load resistance R = 100 Ω and filter capacitor C = 100 µF. The diode has a forward drop of 0.7 V when conducting. Find (i) the average dc output voltage, (ii) the time interval during which the diode conducts, (iii) the average diode current during conduction, (iv) the maximum diode current.

Answer key

Input: ±10 V triangle, T = 1 ms, so the slope is 20 V per 0.5 ms = 40 V/ms = 40 000 V/s. \(V_{o,max} = 10 - 0.7 = 9.3\) V. \(RC = 100 \times 100\,\mu\text{F} = 10\) ms ≫ T.

  • Ripple and conduction time. Linear discharge at \(V_{o,max}/RC = 930\) V/s for \(T - \Delta t\); the capacitor recharges at the slope 40 000 V/s for \(\Delta t\). \(V_r = 930(1\text{ ms} - \Delta t) = 40\,000\,\Delta t\) ⇒ \(\Delta t = \dfrac{0.93}{40\,930} = 22.7\ \mu\)s, \(V_r = 0.909\) V.
  • (i) \(V_{avg} \approx V_{o,max} - V_r/2 = 9.3 - 0.45 = \mathbf{8.85}\) V.
  • (ii) \(\Delta t \approx \mathbf{22.7\ \mu s}\) (about 2.3 % of the cycle; exponential discharge gives 21.7 µs).
  • (iii) During conduction \(i_D = C\,dv/dt + i_L = 100\,\mu\text{F}\times40\,000 + i_L = 4.0\ \text{A} + 0.09\ \text{A}\): \(i_{D,avg} \approx \mathbf{4.09}\) A.
  • (iv) \(i_{D,max} \approx 4.0 + 9.3/100 = \mathbf{4.09}\) A (the constant capacitor charging current dominates, so the peak and the conduction average nearly coincide).

Consider the circuit shown in Fig. for Q. 7(a). For all the MOSFETs \(|V_t|\) = 1 V, \(\mu_nC_{ox}\) = 50 µA/V², L = 1 µm and W = 10 µm. Find V and I. If Q₃ and Q₄ are made to have W = 100 µm, find V and I in that case.

Sedra law \(i_D = \tfrac12 k_n'(W/L)(V_{GS} - V_t)^2\); \(k_n'W/L = 50\times10 = 0.5\) mA/V² for the 10 µm devices. λ = 0.

Reference branch. Q₂ and Q₁ are identical and carry the same current: \(V_{GS2} = 5 - x\), \(V_{GS1} = x\) ⇒ \(x = 2.5\) V. \(I_{ref} = \tfrac12(0.5)(2.5 - 1)^2 = 0.5625\) mA.

Case 1 (all 10 µm). Q₃ has \(V_{GS3} = x = 2.5\) V, same size as Q₁: \(I = 0.5625\) mA (saturated if \(V > 1.5\) V). Q₄ is identical to Q₂: \(V_{GS4} = 5 - V = 2.5\) V ⇒ \(\mathbf{V = 2.5}\) V, \(\mathbf{I = 0.5625}\) mA. Check Q₃: \(V_{DS3} = 2.5 > V_{OV} = 1.5\) ✓.

Case 2 (Q₃, Q₄ at 100 µm). Both ten times larger, so Q₃ carries \(10\times0.5625 = 5.625\) mA from the same \(V_{GS} = 2.5\) V. Q₄ ten times larger with the same current as Q₂ would have: \(V_{GS4}\) stays 2.5 V, \(V = 2.5\) V. Check: \(\tfrac12(5)(5 - V - 1)^2 = 5.625\) ⇒ \(4 - V = 1.5\) ⇒ \(V = 2.5\) V ✓. \(\mathbf{V = 2.5}\) V, \(\mathbf{I = 5.625}\) mA.

Determine the Boolean expression for \(V_o\) in terms of the four input voltages for the circuit shown in Fig. for Q. 8(b).

(Diode logic: two 1 kΩ pull-up AND gates, one on \(V_1, V_2\) and one on \(V_3, V_4\), feed a diode OR stage with a 1 kΩ to ground; a last diode stage gives the output \(V_o\). Rails +5 V and ground; logic 1 = 5 V. The figure is a hand drawing and is not redrawn here.)

Answer key
  • AND stage: each pull-up node (A, C) sits at 5 V unless one of its input diodes pulls it down to that input: the node is high only if both inputs are high: \(A = V_1V_2\), \(C = V_3V_4\).
  • OR stage: diodes D₅, D₆ from A and C to the common node E, with 1 kΩ to ground: E is high if either A or C is high.
  • Result: \(V_o = V_1V_2 + V_3V_4\) (AND–OR).

Remark: with 0.7 V drops, a logic-high output degrades through the diode chain (to about 1 V to 4 V depending on the loading), so the levels are not restored. The D₃ shown in the scan has the wrong direction for the gate to work (a typesetting error); with the intended direction the expression above is exactly right for all 16 inputs.
