Question 1

2019–20 · Sec A · Q1(a) · 20 marks

Draw the circuit of a full-wave rectifier with centre-tapped secondary winding and the input and output voltage waveshapes. Comment on the values of the RC time constant for a rectifier circuit.

Answer key
  • Transformer with centre tap grounded; \(D_1\) from the top end and \(D_2\) from the bottom end, cathodes joined at the load R. Each half-winding gives \(v_S\).
  • \(D_1\) conducts on the positive half cycle, \(D_2\) on the negative; \(v_O = |v_S| - V_D\), a full-wave rectified sine at \(2f\), zero while \(|v_S| < V_D\). PIV = \(2V_S - V_D\).
  • With a filter C: need \(RC \gg T/2 = 1/(2f)\) (full wave; \(\gg T\) for half wave); ripple \(V_r \approx V_p/(2fRC)\).
  • Large RC: small ripple, \(V_{DC}\to V_p\), but a short conduction interval and large peak/surge diode currents. Small RC: big ripple. Choose the smallest C that meets the ripple spec.

Full method: Rectifiers and battery chargers · Peak rectifier: ripple, conduction angle, diode current

2019–20 · Sec A · Q1(b) · 16 marks

For the following circuit, draw the output waveshape for the given square input waveshape. Input: square wave \(v_i\) alternating between +10 V and −20 V with equal half periods.

Answer key

Ideal diode, \(RC \gg T\). The diode conducts whenever \(v_o\) tries to go below +5 V, so the minimum is clamped at +5 V.

During \(v_i = -20\) V the diode charges C until \(v_o = 5\) V: \(v_C = v_i - v_o = -25\) V (input side negative). Then \(v_o = v_i + 25\): square wave between +5 V and +35 V, same 30 V peak-to-peak. (With a 0.7 V diode: +5.7 V and +35.7 V.)

Full method: Clampers and voltage doublers

2019–20 · Sec A · Q1(c) · 10⅔ marks

Why is the third terminal (base or gate) used in a transistor?

Answer key
  • It separates the control path (B–E or G–S) from the power path (C–E or D–S): a small input controls a large output current, like a valve.
  • BJT: \(v_{BE}\) (base current) controls \(i_C = I_Se^{v_{BE}/V_T} = \beta i_B\); the thin, lightly doped base lets most injected carriers reach the collector.
  • MOSFET: insulated gate, \(i_G \approx 0\); the gate field forms and controls the channel, \(i_D = \frac12k_n(v_{GS}-V_t)^2\).
  • This gives amplification (power gain without loading the source) and switching (logic).

Full method: Structure and modes of operation

Question 2

2019–20 · Sec A · Q2(a) · 16⅔ marks

What is the Early effect for a BJT? What are the consequences of the Early effect on BJT behaviour?

Answer key
  • Base-width modulation: raising \(V_{CB}\) widens the CB depletion layer into the lightly doped base, so the effective base width falls.
  • The minority-carrier gradient steepens, so \(i_C\) rises with \(v_{CE}\): \(i_C = I_Se^{v_{BE}/V_T}(1 + v_{CE}/V_A)\); extrapolated \(i_C\)–\(v_{CE}\) lines meet at \(-V_A\) (sketch it).
  • Finite output resistance \(r_o = V_A/I_C\): limits CE gain to \(-g_m(R_C\parallel r_o)\); intrinsic gain \(g_mr_o = V_A/V_T\).
  • β rises slightly with \(v_{CE}\) (less base recombination); extreme case: punch-through when the base is fully depleted. Typical \(V_A\) = 50–150 V.

Full method: I–V characteristics and the Early effect

2019–20 · Sec A · Q2(b) · 30 marks

For the circuit shown in Fig. 2(b), find the small-signal input impedance and voltage gain. It is given that \(V_t\) = 1.2 V, \(k'_n(W/L)\) = 0.5 mA/V² and \(V_A\) = 55 V.

Answer key

DC: no gate current, so \(V_G = V_D\) and the device is saturated. \(20 = 20I_D + V_{GS}\) with \(I_D = 0.25(V_{GS}-1.2)^2\) ⇒ \(5V_{GS}^2 - 11V_{GS} - 12.8 = 0\) ⇒ \(V_{GS} = V_D = 3.04\) V (other root negative), \(I_D = 0.848\) mA.

\(g_m = k_nV_{OV} = 0.5\times1.84 = 0.921\) mA/V; \(r_o = 55/0.848 = 64.9\) kΩ.

Gain: \(A_v \approx -g_m(R_D\parallel R_L\parallel r_o) = -0.921\times9.49 = -8.73\) V/V (including the tiny feed-forward through \(R_G\) gives −8.73 as well).

Input resistance (Miller): \(R_{in} = \dfrac{R_G}{1 - A_v} = \dfrac{15}{9.73} = 1.54\) MΩ.

Question 3

2019–20 · Sec A · Q3(a) · 30 marks

For a BJT common-emitter amplifier with resistance in the emitter, derive the expressions for input impedance, output impedance, voltage gain and current gain. What are the advantages and disadvantages of adding resistance in the emitter?

Answer key

Draw the circuit (\(R_C\), unbypassed \(R_e\), \(R_L\), source \(R_{sig}\)) and its T model (\(r_e\) in series with \(R_e\)), \(r_o\) neglected.

  • \(i_e = v_b/(r_e + R_e)\) ⇒ \(R_{in} = (\beta+1)(r_e + R_e)\) (\(= r_\pi + (\beta+1)R_e\)); in parallel with \(R_B\) if present.
  • \(R_o = R_C\) (collector current source is ideal).
  • \(A_v = \dfrac{v_o}{v_b} = -\dfrac{\alpha(R_C\parallel R_L)}{r_e + R_e} \approx -\dfrac{R_C\parallel R_L}{R_e}\); \(G_v = -\dfrac{\beta(R_C\parallel R_L)}{R_{sig} + (\beta+1)(r_e + R_e)}\).
  • \(A_i = i_c/i_b = \beta\) (load current \(i_o = -\beta i_b R_C/(R_C+R_L)\)).
  • Advantages: input resistance larger by \(1 + g_mR_e\); gain set by resistors, less sensitive to β and temperature; better linearity (only part of \(v_i\) appears as \(v_{be}\), larger allowed input); wider bandwidth; better Q-point stability.
  • Disadvantages: gain reduced by the factor \(1 + g_mR_e\); less headroom and output swing.

Senior solution gap

The circulating BJT "TF Analysis" file only pastes Sedra's summary table for this 30-mark part and derives nothing. The marks are for the derivation from the T (or hybrid-π) model.

2019–20 · Sec A · Q3(b) · 16⅔ marks

Comment on the desired values of input impedance, output impedance, voltage gain and current gain of a BJT amplifier. Comment on the values of these four parameters for CB, CE and CC configurations.

Answer key
  • Ideal voltage amplifier: \(R_{in}\to\infty\), \(R_o\to0\), \(|A_v|\) large (current amplifier: \(R_{in}\to0\), \(R_o\to\infty\)).
  • CE: \(R_{in} = r_\pi\) (moderate, kΩ), \(R_o = R_C\parallel r_o\) (high), \(A_v = -g_m(R_C\parallel R_L)\) (large, inverting), \(A_i \approx \beta\).
  • CB: \(R_{in} \approx r_e\) (tens of Ω), \(R_o \approx R_C\) (high), \(A_v = +g_m(R_C\parallel R_L)\) (large, non-inverting), \(A_i = \alpha \approx 1\): current buffer, good at high frequency.
  • CC: \(R_{in} = (\beta+1)(r_e + R_E\parallel R_L)\) (high), \(R_o = r_e + R_{sig}/(\beta+1)\) (low), \(A_v \approx 1\), \(A_i \approx \beta+1\): voltage buffer.

Senior solution error

The circulating BJT "TF Analysis" file gives the CB overall gain with a negative sign (it is non-inverting, \(G_v = +\alpha(R_C\parallel R_L)/(r_e + R_{sig})\)), leaves the \(R_{sig}/(\beta+1)\) term out of the CC output resistance, and does not answer "desired values".

Full method: Common base and emitter follower

Question 4

2019–20 · Sec A · Q4(a) · 18⅔ marks

Showing different operating regions, describe the output characteristics of a MOSFET. Why does current saturation occur in a MOSFET as \(V_{DS}\) is increased?

Answer key
  • Family of \(i_D\)–\(v_{DS}\) curves for several \(v_{GS}\); boundary parabola \(v_{DS} = v_{OV}\) (\(i_D = \frac12k_nv_{DS}^2\)).
  • Cutoff: \(v_{GS} < V_t\), \(i_D = 0\). Triode: \(v_{DS} < v_{OV}\), \(i_D = k_n(v_{OV}v_{DS} - \frac12v_{DS}^2)\) (resistor-like near the origin, \(r_{DS} = 1/(k_nv_{OV})\)). Saturation: \(v_{DS} \ge v_{OV}\), \(i_D = \frac12k_nv_{OV}^2\).
  • Why it saturates: at \(v_{DS} = v_{OV}\) (\(v_{GD} = V_t\)) the channel pinches off at the drain end; extra \(v_{DS}\) drops across the depletion region at the drain, the channel voltage profile stays fixed, so \(i_D\) stays (almost) constant.
  • Channel-length modulation: the pinch-off point moves toward the source, \(i_D\) rises slightly, \(r_o = V_A/I_D\).

Full method: I–V, regions, channel-length modulation

For the circuit shown in Fig. 4(b), find the node voltages \(V_3\), \(V_4\) and \(V_5\). The NMOS transistors have \(V_t\) = 0.9 V and \(k'_n(W/L)\) = 1.5 mA/V².

Question 5

2019–20 · Sec B · Q5(a) · 17 marks

The input voltage \(v_I\) and output voltage \(v_O\) of an op-amp based circuit are given in the figures for Q.5(a) and (b) respectively. Design the circuit.

Waveforms (in words): \(v_I\) is a 1 V pulse from t = 0 to 1 ms and 0 afterwards. \(v_O\) is a linear ramp from 0 down to −10 V at t = 1 ms, then stays at −10 V.

Answer key

A ramp while the input is constant, holding when the input returns to 0: an inverting integrator, \(v_O = -\frac{1}{RC}\int v_I\,dt\).

Slope \(= -10\text{ V}/1\text{ ms} = -10^4\) V/s \(= -1\text{ V}/RC\) ⇒ \(RC = 0.1\) ms, e.g. R = 10 kΩ, C = 10 nF.

Full method: Integrator and differentiator

2019–20 · Sec B · Q5(b) · 29⅔ marks

Design a circuit using op-amps that can provide the solution to the equation \(3\dfrac{d^2v}{dt^2} + K\dfrac{dv}{dt} - 3v + 8 = 0\), where K = last digit of your student ID. Briefly discuss the operation of your designed circuit.

Answer key

Rearrange: \(v'' = -\frac{K}{3}v' + v - \frac83\).

Summer (inverting, \(R_f\) = 100 kΩ) producing \(v''\): input \(+v'\) through \(R_1 = 300/K\) kΩ; input \(-v\) through \(R_2\) = 100 kΩ; a constant from +15 V through \(R_3 = 100\times15/(8/3) = 562.5\) kΩ (gives \(-8/3\)). If K = 0, omit \(R_1\).

Integrator 1 (1 MΩ, 1 µF, RC = 1 s): \(v'' \to -v'\). Integrator 2: \(-v' \to v\) (the solution node). Inverters: \(-v' \to +v'\) and \(v \to -v\), fed back to the summer. Five op-amps.

Operation: the loop forces the summer output to equal the right-hand side, so it is \(v''\); initial conditions are set by pre-charging the integrator capacitors (switches open at t = 0). Note the \(-3v\) term makes the system unstable (exponentially growing solution) unless the initial conditions sit at the equilibrium \(v = 8/3\) V.

Full method: Analog computer for differential equations

Question 6

2019–20 · Sec B · Q6(a) · 17 marks

Deduce the equation for output voltage \(V_0\) in the circuit shown in Fig. for Q.6(a). Explain the function of this circuit.

Answer key

Virtual ground at the − input, so the diode voltage is \(V_i\): \(I_D = I_Se^{V_i/V_T}\) (\(V_i > 0\), forward biased). This current flows through \(R_F\): \(V_0 = -I_DR_F\).

\[ V_0 = -R_FI_S\,e^{V_i/V_T} \]

Function: antilog (exponential) amplifier; works only for \(V_i > 0\); temperature sensitive through \(I_S\) and \(V_T\). (Swapping the diode and \(R_F\) gives the log amplifier \(V_0 = -V_T\ln[V_i/(I_SR)]\).)

Known wrong answer

Some summaries (and the Gemini answer's opening line) call this a logarithmic amplifier and write \(V_0 = -V_T\ln[V_i/(I_SR_F)]\). With the diode at the input and the resistor in the feedback, it is the antilog circuit.

Full method: Log, antilog and nonlinear circuits

2019–20 · Sec B · Q6(b) · 29⅔ marks

Consider the 555 IC based circuit in Fig. for Q.6(b). (i) Draw the waveshapes of \(V_C\) and \(V_O\). (ii) Determine output low time \(t_{low}\) and output high time \(t_{high}\). (iii) Find the duty cycle and free-running frequency. (iv) How does the free-running frequency depend on C? Discuss with a graph. (v) Design the resistors and capacitor so that the duty cycle becomes 0.40.

Answer key

(i) \(V_C\) charges from 3.33 V to 6.67 V (exponential, through \(R_A + R_B\)) while \(V_O\) is high, and discharges back to 3.33 V through \(R_B\) while \(V_O\) is low.

(ii) \(t_{high} = 0.693(R_A + R_B)C = 0.693\times10\text{ k}\times0.5\ \mu\text{F} = 3.47\) ms; \(t_{low} = 0.693R_BC = 1.04\) ms.

(iii) T = 4.51 ms, f = 222 Hz, D = 3.47/4.51 = 0.769 (76.9 %).

(iv) \(f = \dfrac{1.44}{(R_A + 2R_B)C}\): inversely proportional to C, a rectangular hyperbola on an f–C plot (straight line of slope −1 on log–log axes).

(v) The basic astable always gives D > 0.5. Add a diode across \(R_B\) (anode at pin 7): \(t_H = 0.693R_AC\), \(t_L = 0.693R_BC\), \(D = R_A/(R_A + R_B) = 0.4\) ⇒ \(R_B = 1.5R_A\). Keeping f = 222 Hz with C = 0.5 µF: \(R_A + R_B = 13.0\) kΩ ⇒ \(R_A\) = 5.2 kΩ, \(R_B\) = 7.8 kΩ. (Any pair with \(R_B = 1.5R_A\) is right, e.g. 10 kΩ, 15 kΩ, 0.1 µF gives 577 Hz.)

Question 7

2019–20 · Sec B · Q7(a) · 28⅔ marks

Consider the circuit of resistors, capacitors and an op-amp in Fig. for Q.7(a). (i) What conditions must hold for it to operate as a sinusoidal oscillator? (ii) Derive the oscillation frequency. (iii) The op-amp with \(R_3\) and \(R_4\) forms a non-inverting amplifier of gain \(A_V\); show that \(A_V \ge 1 + R_1/R_2 + C_2/C_1\) for sustained oscillation. (iv) If \(R_1 = R_2\) = 10 kΩ and \(C_1 = C_2\) = 0.1 µF, design \(R_3\) and \(R_4\) so that oscillation sustains.

Answer key

(i) Barkhausen: loop gain \(A\beta(j\omega_0) = 1\): magnitude 1 and phase 0° at one frequency; in practice \(|A\beta|\) slightly > 1 with an amplitude limiter.

(ii) \(\beta = \dfrac{Z_2}{Z_1 + Z_2}\), \(Z_1 = R_1 + \frac{1}{sC_1}\), \(Z_2 = R_2\parallel\frac{1}{sC_2}\). \[ \frac1\beta = 1 + \frac{Z_1}{Z_2} = 1 + \frac{R_1}{R_2} + \frac{C_2}{C_1} + j\left(\omega R_1C_2 - \frac{1}{\omega R_2C_1}\right). \] Phase zero ⇒ \(\omega_0 = \dfrac{1}{\sqrt{R_1R_2C_1C_2}}\).

(iii) At \(\omega_0\), \(\beta = 1/(1 + R_1/R_2 + C_2/C_1)\) (real), so \(A_V\beta \ge 1\) ⇒ \(A_V = 1 + R_3/R_4 \ge 1 + R_1/R_2 + C_2/C_1\).

(iv) \(f_0 = \dfrac{1}{2\pi\times10\text{ k}\times0.1\ \mu\text{F}} = 159\) Hz; \(A_V \ge 3\) ⇒ \(R_3 \ge 2R_4\): e.g. \(R_4\) = 10 kΩ, \(R_3\) = 20 kΩ (slightly more, say 21 kΩ, for reliable start-up, with a diode limiter).

Question-bank misprint

The question bank prints "\(1 + R_1/R_2 + C_1/C_2\)". The derivation (and the paper) give \(C_2/C_1\).

2019–20 · Sec B · Q7(b) · 18 marks

Assume that a bistable multivibrator with the transfer characteristic of Fig. 7(b)(i) is provided. Design a signal generator based on it that generates the waveforms of Fig. 7(b)(ii). Also choose component values for which the frequency of oscillation is 1 MHz.

Figures (in words): (i) non-inverting hysteresis loop with output levels \(L_+\) and \(L_-\) and thresholds \(V_{TL}\) (negative) and \(V_{TH}\) (positive). (ii) square wave \(v_2\) between \(L_+\) and \(L_-\) with high time \(T_1\) and low time \(T_2\); triangle \(v_1\) between \(V_{TL}\) and \(V_{TH}\), falling during \(T_1\) and rising during \(T_2\).

Answer key

Close the loop with an inverting integrator: square output \(v_2\) → R → integrator (C in feedback) → triangle \(v_1\) → back to the bistable input.

While \(v_2 = L_+\), \(v_1\) falls at \(L_+/RC\) from \(V_{TH}\) to \(V_{TL}\): \(T_1 = RC\dfrac{V_{TH} - V_{TL}}{L_+}\); while \(v_2 = L_-\): \(T_2 = RC\dfrac{V_{TH} - V_{TL}}{-L_-}\).

\(T = T_1 + T_2 = RC(V_{TH} - V_{TL})\left(\dfrac{1}{L_+} + \dfrac{1}{|L_-|}\right) = 1\ \mu\)s. The bistable is given, so only R and C are designed. Symmetric example: \(L_\pm = \pm12\) V, \(V_{TH} = -V_{TL} = 6\) V ⇒ \(T = 4RC\times6/12 = 2RC\) ⇒ RC = 0.5 µs, e.g. C = 100 pF, R = 5 kΩ.

Question-bank note

The Gemini answer redesigns the bistable itself (takes \(R_1 = R_2\), RC = 250 ns). The bistable is given; state its \(L_\pm\), \(V_{TH}\), \(V_{TL}\) symbolically and size R, C from the formula above.

Question 8

2019–20 · Sec B · Q8(a) · 25⅔ marks

Implement \(f(A,B,C,D) = \Sigma m(1, 2, 4, 7, 14, 15)\) using (i) a CMOS circuit and (ii) a pseudo-NMOS circuit. Which would you prefer and why?

Answer key

K-map: 14, 15 → \(ABC\); 7, 15 → \(BCD\); 1, 2, 4 have no adjacent minterms. \(f = ABC + BCD + \bar A\bar B\bar CD + \bar A\bar BC\bar D + \bar AB\bar C\bar D\) (checked over all 16 inputs).

(i) CMOS complex gate: the PDN realises \(f\) (series nMOS for each product, products in parallel), giving \(\bar f\) at the gate output; an output inverter gives \(f\). The PUN is the dual (parallel pMOS within each product, products in series). Complemented inputs come from input inverters.

(ii) Pseudo-NMOS: the same PDN with a single pMOS load (gate grounded) instead of the PUN, then the inverter.

Prefer CMOS: no static power dissipation and rail-to-rail output (\(V_{OL}\) = 0, ratioless). Pseudo-NMOS uses fewer transistors (N + 1 instead of 2N) and is faster to switch low, but draws static current whenever the output is low and needs ratioed sizing.

Full method: CMOS inverter and gates

2019–20 · Sec B · Q8(b) · 21 marks

Design transistor W/L ratios for the logic \(Y = \overline{(AB + D)\cdot C}\) implemented in CMOS. Assume for the basic inverter \((W/L)_n = n = 2\) and \((W/L)_p = p = 7\) (the paper misprints "\((W/L)_n = p\)"), channel length 0.15 µm.

Answer key

PDN: (A series B) ∥ D, all in series with C. Worst path A–B–C (three in series): A = B = C = 3n = 6. Path D–C: \(1/W_D + 1/6 = 1/2\) ⇒ D = 3 (= 1.5n).

PUN (dual): (A ∥ B) in series with D, the pair in parallel with C. Worst path A–D (two in series): A = B = D = 2p = 14; C alone: C = p = 7.

With L = 0.15 µm: nMOS A, B, C: W = 0.90 µm; nMOS D: 0.45 µm; pMOS A, B, D: 2.1 µm; pMOS C: 1.05 µm. (Some texts size D as 2n = 4 by a simpler rule; the path rule above is exact.)

Full method: CMOS inverter and gates
