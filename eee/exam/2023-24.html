Question 1 COMPULSORY

2023–24 · Sec A · Q1(a) · 20 marks · compulsory · CO2

In the circuit in the figure, I is a DC current source and \(V_i\) is a sinusoidal signal of small amplitude (< 10 mV) at 100 kHz. (i) Representing the diode by its small-signal resistance \(r_d\) (a function of I), sketch the circuit for determining the sinusoidal output \(V_o\) across the capacitor. (ii) Find the phase shift between \(V_i\) and \(V_o\). (iii) Find the value of I that gives a phase shift of −45°. (iv) Find the range of phase shift as I is varied from 0.1 to 10 times the value found in (iii). Assume n = 1.

Answer key

(i) Small-signal circuit: kill the DC source I (open circuit); the diode becomes \(r_d = V_T/I\). Then \(V_i\) drives \(r_d\) in series with C to ground, and \(V_o\) is across C: an RC low-pass filter.

(ii) \(\dfrac{V_o}{V_i} = \dfrac{1}{1 + j\omega r_dC}\) ⇒ \(\phi = -\tan^{-1}(\omega r_dC) = -\tan^{-1}\!\left(\dfrac{\omega CV_T}{I}\right)\).

(iii) −45° ⇒ \(\omega r_dC = 1\) ⇒ \(r_d = 1/(2\pi\cdot10^5\cdot10^{-8})\) = 159.2 Ω ⇒ I = 25 mV/159.2 Ω = 0.157 mA.

(iv) I = 0.0157 mA: \(\omega r_dC = 10\), φ = −84.3°; I = 1.57 mA: \(\omega r_dC = 0.1\), φ = −5.7°. Range −84.3° to −5.7° (V_o lags V_i).

Senior solution error

One circulating solution ("EEE263 TF 23-24 solution") gives the range as 95.7° to 174.3°: a sign/180° error. The correct range is −84.3° to −5.7°; the other file ("eee 23-24 solve") has it right.

Full method: Small-signal model (type D-02)

Question 5 COMPULSORY

2023–24 · Sec B · Q5(a) · 17 marks · compulsory · CO3

Define the Barkhausen criterion. Describe the operating principle of an op-amp based Wien-bridge oscillator. Derive the conditions for the Barkhausen criterion to be satisfied in this oscillator and the expression for the oscillation frequency.

Answer key

Barkhausen: with amplifier gain A and feedback β, sustained oscillation at \(\omega_0\) needs \(A\beta(j\omega_0) = 1\): loop phase 0° (or 360°) and loop-gain magnitude 1 (slightly above 1 to start, limited by nonlinearity).

Circuit: non-inverting amplifier \(A = 1 + R_f/R_i\); positive feedback from the output through series \(R_1C_1\) (\(Z_s\)) to the + input, with parallel \(R_2C_2\) (\(Z_p\)) from + input to ground: \(\beta = Z_p/(Z_s + Z_p)\).

Derivation: \(\dfrac1\beta = 1 + \dfrac{Z_s}{Z_p} = 1 + \left(R_1 + \dfrac{1}{j\omega C_1}\right)\left(\dfrac{1}{R_2} + j\omega C_2\right) = 1 + \dfrac{R_1}{R_2} + \dfrac{C_2}{C_1} + j\left(\omega R_1C_2 - \dfrac{1}{\omega R_2C_1}\right)\).

Phase condition (imaginary part 0): \(\omega_0 = \dfrac{1}{\sqrt{R_1R_2C_1C_2}}\). Magnitude: \(1 + \dfrac{R_f}{R_i} = 1 + \dfrac{R_1}{R_2} + \dfrac{C_2}{C_1}\). Equal parts (R, C): \(f_0 = \dfrac{1}{2\pi RC}\), β = 1/3, so \(R_f/R_i = 2\) (gain 3).

Operation: at power-up noise is amplified; only \(f_0\) returns in phase with loop gain ≥ 1 and grows; amplitude is held by op-amp saturation or a diode limiter in the \(R_f\) path. (One senior file never states the real-part gain condition; it is required.)

Full method: Wien-bridge oscillator (type S-01) · Barkhausen criterion and amplitude limiters

  3. Op-amp 3, inverting summer with \(R_f\) = 10 kΩ: op-amp 1 output through 10 kΩ, op-amp 2 output through 10 kΩ, and \(V_2\) through a capacitor C = 4 µF (\(R_fC\) = 0.04 s). Output: \(-(-5\sin40t - 4) - R_fC\dfrac{dV_2}{dt} = 5\sin40t + 4 - 4\cos100t\). ✓

Question 6

2023–24 · Sec B · Q6(a) · 18 marks

With a proper connection diagram, explain the monostable mode of operation of a 555 timer. Design a 555 monostable multivibrator that produces an output pulse of duration T = 100 ms. Draw the output-voltage and trigger-voltage waveforms of your design.

Answer key

Question 7

2023–24 · Sec B · Q7(a) · 20 marks

Derive expressions for \(R_{in}\), \(R_o\), \(A_{vo}\), \(A_v\) and \(G_v\) of a common-emitter amplifier using the T model. The amplifier is driven by \(v_{sig}\) with source resistance \(R_{sig}\), and the transistor output resistance is \(r_o\).

Answer key

T model: \(r_e\) between the internal base point and emitter (emitter grounded), current source \(\alpha i_e\) from collector, \(r_o\) collector to emitter (to ground), \(R_C\) and \(R_L\) at the collector.

  • \(i_b = (1-\alpha)i_e = i_e/(\beta+1)\) with \(i_e = v_i/r_e\) ⇒ \(R_{in} = (\beta+1)r_e\) (\(= r_\pi\)).
  • \(A_{vo} = -\alpha(R_C\parallel r_o)/r_e = -g_m(R_C\parallel r_o)\).
  • \(R_o = R_C\parallel r_o\) (set \(v_{sig}\) = 0 ⇒ \(i_e\) = 0, the source is open).
  • \(A_v = -\alpha(R_C\parallel r_o\parallel R_L)/r_e\).
  • \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v = -\dfrac{\beta(R_C\parallel r_o\parallel R_L)}{R_{sig} + (\beta+1)r_e}\).

Senior solution error

"EEE263 TF 23-24 solution" pastes Sedra's CE-with-emitter-resistance result (with R_e, without r_o). That answers a different question; the paper asks for r_o and no R_e. The other file matches the question.

Question 8

2023–24 · Sec B · Q8(a) · 15 marks

Write down the characteristics of an ideal op-amp. Draw the voltage transfer characteristic (VTC: output voltage against input voltage) of the circuit in the figure.

Answer key

Ideal op-amp: infinite open-loop gain, infinite input resistance (zero input currents), zero output resistance, infinite bandwidth, zero offset (output 0 when \(v_+ = v_-\)), infinite CMRR.

Analysis (non-inverting Schmitt trigger, positive feedback): \(v_+ = \dfrac{R_2V_{in} + R_1v_O}{R_1 + R_2}\). The output switches when \(v_+\) crosses 0, i.e. at \(V_{in} = -(R_1/R_2)v_O\).

With \(v_O = L_-\) the output goes high at \(V_{TH} = -(R_1/R_2)L_- = +(R_1/R_2)|L_-|\); with \(v_O = L_+\) it goes low at \(V_{TL} = -(R_1/R_2)L_+\). VTC: a rectangular hysteresis loop of width \((R_1/R_2)(L_+ - L_-)\) centred on 0. Increasing \(V_{in}\) moves along \(L_-\) to \(V_{TH}\), jumps up to \(L_+\); decreasing moves along \(L_+\) to \(V_{TL}\), jumps down. Non-inverting: high input gives high output.

Full method: Bistables and Schmitt triggers (type S-09)

2023–24 · Sec B · Q8(c) · 8 marks

Derive the condition for small-signal operation of a simple CS NMOS amplifier. From it, find the expression for the MOSFET transconductance \(g_m\).

Answer key

\(v_{GS} = V_{GS} + v_{gs}\): \(i_D = \tfrac12k_n(V_{OV} + v_{gs})^2 = \tfrac12k_nV_{OV}^2 + k_nV_{OV}v_{gs} + \tfrac12k_nv_{gs}^2\) (DC term, linear signal term, distortion term).

Small-signal condition: the square term negligible against the linear one: \(\tfrac12k_nv_{gs}^2 \ll k_nV_{OV}v_{gs}\) ⇒ \(v_{gs} \ll 2V_{OV}\) (in practice \(v_{gs} \le 0.1V_{OV}\) or so).

Then \(i_d = k_nV_{OV}v_{gs}\) ⇒ \(g_m = k_nV_{OV} = \sqrt{2k_nI_D} = 2I_D/V_{OV}\).

One senior file writes \(v_{gs} \ll V_{OV}\), dropping the factor 2; the other leaves this part blank.
