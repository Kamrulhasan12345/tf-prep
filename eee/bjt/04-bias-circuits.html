Bias Circuits, Stability and Bias Design

Bias design (B-04) appeared in six papers, most recently as the compulsory 2022–23 Q5(a) (cascode, 15 marks) and 2021–22 Q6(b) (20 marks). Voltage-divider analysis (B-02) was asked four times up to 2016–17 and is the first step of every amplifier question. Both reduce to the same two tools: Thevenin the base network, and walk the node voltages backwards from the specification. Theory on "why bias, how to make it stable" adds 5–16 marks in several years.

1. Why a bias, and what makes it stable

A bias sets the quiescent point (\(I_{CQ}\), \(V_{CEQ}\)) with no signal applied. It must (i) keep the transistor in the active region for the whole signal swing (Q near the middle of the load line: too high clips at saturation, too low clips at cutoff); (ii) fix the small-signal parameters (\(g_m = I_C/V_T\)); (iii) make \(I_C\) insensitive to β (which varies between units and with temperature), to \(V_{BE}\) (−2 mV/°C) and to leakage \(I_{CBO}\) (prevents thermal runaway).

Fixed bias
\(R_B\) from \(V_{CC}\) to the base, no \(R_E\): \(I_C = \beta(V_{CC} - 0.7)/R_B\). \(I_C\) is proportional to β: bad.
Emitter (self) bias
Add \(R_E\): \(I_C = \beta(V_{BB} - 0.7)/(R_B + (\beta+1)R_E)\). With \(R_B\) = 100 kΩ, \(R_E\) = 1 kΩ, \(V_{BB}\) = 5 V: β 100 → 150 (×1.5) moves \(I_C\) only from 2.14 to 2.57 mA (×1.2). Sadat sir calls this "self-bias".
Stability factor
\(S = \partial I_C/\partial I_{CBO}\); smaller is better. Negative feedback through \(R_E\) (or collector-to-base \(R_B\)) reduces it.

2. Voltage-divider (four-resistor) bias (type B-02)

Derivation (2014–15 Q3(a), 16 marks). Thevenin at the base: \(V_{BB} = V_{CC}\dfrac{R_2}{R_1 + R_2}\), \(R_B = R_1\parallel R_2\). KVL around \(V_{BB}\) → \(R_B\) → B–E → \(R_E\) with \(I_B = I_E/(\beta+1)\):

\[ V_{BB} = \frac{I_E}{\beta+1}R_B + V_{BE} + I_ER_E \;\Rightarrow\; I_E = \frac{V_{BB} - V_{BE}}{R_E + R_B/(\beta+1)} \]

Conditions for \(I_E\) to be independent of β and \(V_{BE}\): \(R_E \gg R_B/(\beta+1)\) (in practice \((\beta+1)R_E \ge 10R_B\)) and \(V_{BB} \gg V_{BE}\). These fight each other (a large \(V_{BB}\) leaves less for \(V_{CE}\)), so the rule of thumb is one third of \(V_{CC}\) each for \(V_{BB}\), \(V_{CE}\) and \(I_CR_C\), with a divider current of about \(0.1I_E\). Feedback action of \(R_E\): if \(I_C\) rises (temperature, β), \(V_E = I_ER_E\) rises; with \(V_B\) held by the divider, \(V_{BE}\) falls, so \(I_B\) and therefore \(I_C\) fall back: negative feedback.

Method · divider-bias analysis

  1. Thevenin: \(V_{BB}\), \(R_B\) (combine any extra resistors to other rails first).
  2. \(I_E = (V_{BB} - 0.7 - V_{EE})/(R_E + R_B/(\beta+1))\); \(I_B = I_E/(\beta+1)\), \(I_C = \alpha I_E\).
  3. \(V_E = V_{EE} + I_ER_E\), \(V_B = V_E + 0.7\) (also \(= V_{BB} - I_BR_B\)), \(V_C = V_{CC} - I_CR_C\).
  4. Branch currents: \(I_{R1} = (V_{CC} - V_B)/R_1\), \(I_{R2} = V_B/R_2\); check \(I_{R1} = I_{R2} + I_B\).
  5. Mode check \(V_{CE} \ge 0.3\) V; if it fails, solve the saturation case (Chapter 3).

Worked example: 2015–16 Sec A Q4(a) = 2011–12 Sec B Q7(c) = Sedra Example 6.11

Other bias circuits, same idea. Two supplies (base through \(R_B\) to ground, \(R_E\) to \(-V_{EE}\)): \(I_E = (V_{EE} - 0.7)/(R_E + R_B/(\beta+1))\). Collector-to-base feedback: \(I_E = (V_{CC} - 0.7)/(R_C + R_E + R_B/(\beta+1))\) (Chapter 3, section 6). Current-source bias: a mirror sets \(I \approx I_{REF} = (V_{CC} + V_{EE} - 0.7)/R\), independent of β to first order.

3. Bias design (type B-04)

Method · choose resistors for a target operating point

  1. Currents first: \(I_B = I_C/\beta\), \(I_E = I_C(\beta+1)/\beta\) (with β "very large", \(I_E = I_C\) and base currents are ignored).
  2. If \(V_{BE}\) is given at another current, scale it: \(V_{BE2} = V_{BE1} + V_T\ln(I_{C2}/I_{C1})\) (from \(i_C = I_Se^{v_{BE}/V_T}\)).
  3. Emitter: \(V_E = V_B - V_{BE}\); \(R_E = (V_E - V_{EE})/I_E\) (use \(I_E\), not \(I_C\)).
  4. Collector: \(R_C = (V_{CC} - V_C)/I_C\).
  5. Divider: \(R_2 = V_B/I_{R2}\), \(R_1 = (V_{CC} - V_B)/(I_{R2} + I_B)\). Collector feedback: \(R_1\) goes from the collector, so \(R_C\) carries \(I_C + I_{R1}\).
  6. Stacked (cascode) bias: one string current, walk up the node voltages one junction at a time.
  7. Re-check the mode with the chosen values.

Worked example: cascode bias, 2022–23 Sec B Q5(a) (compulsory)

Design for a β spread (2018–19 Q3(b))

With a base resistor from a fixed supply, \(I_B\) does not depend on β, so \(I_C = \beta I_B\) spreads with β. The unit most likely to saturate is the one with \(\beta_{max}\): choose \(R_C \le (V_{CC} - V_{CE,EOS})/(\beta_{max}I_B)\), with the edge of saturation at \(V_{CE,EOS}\) = 0.3 V (Sedra; state it). The collector voltage then ranges from \(V_{CC} - \beta_{min}I_BR_C\) down to \(V_{CC} - \beta_{max}I_BR_C\).

Traps (where marks go)

  • Writing \(I_E = (V_{BB} - 0.7)/R_E\) and dropping \(R_B/(\beta+1)\): that is only the β = ∞ answer.
  • Taking the divider voltage as \(V_B\) when β is finite: the base current loads the divider (\(V_B = V_{BB} - I_BR_B\)).
  • \(R_E\) from \(I_C\) instead of \(I_E\); forgetting the \(V_{BE}\) scaling (0.760 V at 0.2 mA, 0.717 V at 2 mA).
  • Collector-feedback design: \(R_C\) carries \(I_C + I_{R1}\), not \(I_C\).
  • β-spread design using \(\beta_{min}\): the worst case for saturation is \(\beta_{max}\).

Exam questions

2022–23 · Sec B · Q5(a) · 15 marks · compulsory  |  Neamen cascode

Design the circuit to meet: \(V_{CE1} = V_{CE2}\) = 2.5 V, \(V_{RE}\) = 0.7 V, \(I_{C1} \approx I_{C2} \approx\) 1 mA and \(I_{R1} \approx I_{R2} \approx I_{R3} \approx\) 0.10 mA. \(V^+\) = 9 V.

Show worked answer

β large: base currents neglected, so one string current 0.1 mA flows through \(R_1, R_2, R_3\), and \(I_E \approx I_C\) = 1 mA in both transistors. \(V_{BE}\) = 0.7 V.

\(R_E = V_{RE}/I_E = 0.7/1 = 0.7\) kΩ. \(V_{B1} = V_{RE} + 0.7 = 1.4\) V → \(R_3 = 1.4/0.1 = 14\) kΩ.

\(V_{C1} = V_{E2} = 0.7 + 2.5 = 3.2\) V; \(V_{B2} = 3.9\) V → \(R_2 = (3.9 - 1.4)/0.1 = 25\) kΩ; \(R_1 = (9 - 3.9)/0.1 = 51\) kΩ.

\(V_{C2} = 3.2 + 2.5 = 5.7\) V → \(R_C = (9 - 5.7)/1 = 3.3\) kΩ. Both \(V_{CE}\) = 2.5 V ≥ 0.3 V: active ✓. (\(C_B\) only grounds \(B_2\) for signals; it does not affect the DC design.)

2021–22 · Sec B · Q6(b) · 20 marks  |  = Sedra P6.34 (highlighted by the teacher)

Design the circuit (base grounded, \(R_C\) to +1.5 V, \(R_E\) to −1.5 V) to establish \(I_C\) = 0.2 mA and \(V_C\) = 0.5 V. The transistor exhibits \(V_{BE}\) = 0.8 V at \(i_C\) = 1 mA, and β = 100.

Show worked answer

\(R_C = (1.5 - 0.5)/0.2 = 5\) kΩ.

\(V_{BE} = 0.8 + 0.025\ln(0.2/1) = 0.8 - 0.0402 = 0.760\) V; \(V_E = -0.760\) V. \(I_E = 0.2\times101/100 = 0.202\) mA. \(R_E = (-0.760 + 1.5)/0.202 = 3.66\) kΩ.

Check: \(V_{CE} = 0.5 + 0.760 = 1.26\) V ≥ 0.3 V, active.

2020–21 · Sec A · Q1(c) · 20 marks  |  = Sedra Example 6.2 · Sadat L16, notes p.76–77 · Khairul s.15

The transistor (base grounded, \(R_C\) to +15 V, \(R_E\) to −15 V) has β = 100 and exhibits \(V_{BE}\) = 0.7 V at \(i_C\) = 1 mA. Design the circuit so that a current of 2 mA flows through the collector and a voltage of +5 V appears at the collector.

Show worked answer

\(R_C = (15 - 5)/2 = 5\) kΩ. \(V_{BE} = 0.7 + 0.025\ln 2 = 0.717\) V, \(V_E = -0.717\) V. \(I_E = 2/0.99 = 2.02\) mA. \(R_E = (15 - 0.717)/2.02 = 14.283/2.02 = 7.07\) kΩ. \(V_{CE}\) = 5.72 V: active. (The class notes write "7.781 kΩ": an arithmetic slip.)

2020–21 · Sec A · Q1(b) · 10⅔ marks  |  also 2013–14 Sec A Q3(a) and 2012–13 Sec A Q3(a), 5 marks each

What is transistor biasing? Why do we need it? How can you achieve bias stability? (2012–13, 2013–14: Why do we need to bias a BJT at a proper Q-point before using it as an amplifier?)

Show worked answer

Biasing is applying DC voltages and currents that set the operating point (\(I_{CQ}\), \(V_{CEQ}\)) with no signal.

Why: the BJT amplifies only in the active region; the Q-point must sit near the middle of the load line so the signal swings both ways without reaching saturation (top clipped) or cutoff (bottom clipped). The bias also sets \(g_m = I_C/V_T\), hence the gain. Sketch: load line with Q too high, optimum and too low.

Stability: \(I_C\) must not drift with β (unit-to-unit spread, temperature), \(V_{BE}\) (−2 mV/°C) or \(I_{CBO}\) (doubles every ~10 °C; risk of thermal runaway). Achieved with negative feedback: emitter resistor \(R_E\) with a stiff divider (\((\beta+1)R_E \ge 10R_B\)), collector-to-base feedback, or a current-source/mirror bias; diode or thermistor compensation for \(V_{BE}\).

2018–19 · Sec A · Q3(b) · 20 marks

+5 V drives the base through 100 kΩ, \(R_C\) to +10 V, emitter grounded. β can vary from 50 to 150. Find \(R_C\) so that all fabricated circuits are guaranteed to be in the active mode. What is the range of collector voltages?

Show worked answer

\(I_B = (5 - 0.7)/100 = 43\) µA for every unit. \(I_C\) = 2.15 mA (β = 50) to 6.45 mA (β = 150).

Worst case β = 150, edge of saturation \(V_{CE}\) = 0.3 V: \(R_C \le 9.7/6.45 = 1.504\) kΩ → choose \(R_C\) = 1.5 kΩ.

\(V_C\) ranges from \(10 - 1.5\times6.45 = 0.325\) V (β = 150) to \(10 - 1.5\times2.15 = 6.775\) V (β = 50). (With 0.2 V as the edge: \(R_C \le\) 1.519 kΩ.)

Find \(I_C\) and \(V_{CE}\). β = 100. Base: 60 kΩ from a +5 V source, 30 kΩ from the +5 V rail, 20 kΩ to ground. 500 Ω from +10 V to the collector, 200 Ω from the emitter to −5 V.

Determine the voltages of all nodes and currents through all branches. β = 100. \(R_1\) = 100 kΩ from +15 V to the base, \(R_2\) = 50 kΩ to ground, \(R_C\) = 5 kΩ, \(R_E\) = 3 kΩ.

2014–15 · Sec A · Q3(a) 16 marks + Q3(b) 10⅔ marks

(a) Find the expression for the emitter current of the four-resistor bias circuit. What conditions should be satisfied? How does the feedback of \(R_E\) work? (b) \(R_1\) = 40 kΩ, \(R_2\) = 10 kΩ, \(R_C\) = 1.5 kΩ, \(R_E\) = 1 kΩ, \(V_{CC}\) = 12 V, β = 1000: find the bias point. How should \(R_1\), \(R_2\) be changed for a good bias design?

Show worked answer

(a) Derivation, conditions and feedback mechanism exactly as in section 2: \(I_E = (V_{BB} - V_{BE})/(R_E + R_B/(\beta+1))\); need \(R_E \gg R_B/(\beta+1)\) and \(V_{BB} \gg V_{BE}\).

(b) \(V_{BB}\) = 2.4 V, \(R_B\) = 8 kΩ. β = 1000 (as printed): \(I_E = 1.7/(1 + 8/1001) = 1.687\) mA, \(I_C\) = 1.685 mA, \(I_B\) = 1.685 µA, \(V_{CE} = 12 - 1.5\times1.685 - 1.687 = 7.79\) V. (If β = 100 was meant: \(I_C\) = 1.560 mA, \(V_{CE}\) = 8.09 V.)

Improvement: here \(R_B/(\beta+1)\) is already small compared with \(R_E\) for β = 1000, but for realistic β ≈ 100 it is 8 % of \(R_E\). Lower \(R_1\) and \(R_2\) in the same 4:1 ratio (keeping \(V_{BB}\)) so that \(R_B \approx 0.1\beta_{min}R_E\); the cost is more divider current and a lower input resistance.

2012–13 · Sec A · Q2(b) · 16 marks

Graphically explain the benefit of having \(R_E\) > 0 in a bias scheme with a battery \(V_B\) at the base, \(R_C\) to +15 V and \(R_E\) to ground.

Show worked answer

The base loop gives the bias line \(I_C \approx (V_B - V_{BE})/R_E\): a straight line of slope \(-1/R_E\) on the \(I_C\)–\(V_{BE}\) plane. The operating point is where it crosses the exponential device curve. When temperature rises the curve shifts left by about 2 mV/°C. With \(R_E\) = 0 the bias line is vertical at \(V_{BE} = V_B\), so \(I_C\) jumps up the steep exponential (Q₁ → Q₁′). With \(R_E\) > 0 the sloped line meets the shifted curve at nearly the same current (Q₂ → Q₂′): \(I_C\) is stabilised by negative feedback. The same argument covers spreads in \(I_S\) and β.

Key terms

Quick check

Summary: Thevenin the base: \(V_{BB} = V_{CC}R_2/(R_1 + R_2)\), \(R_B = R_1\parallel R_2\), then \(I_E = (V_{BB} - 0.7)/(R_E + R_B/(\beta+1))\). Stable bias needs \((\beta+1)R_E \gg R_B\) and \(V_{BB} \gg V_{BE}\); \(R_E\) works by negative feedback. Design runs backwards: \(R_C = \Delta V/I_C\), \(R_E = \Delta V/I_E\), scale \(V_{BE}\) by \(V_T\ln\) of the current ratio, divider \(R_2 = V_B/I_{R2}\), \(R_1 = \Delta V/(I_{R2} + I_B)\). For a β spread design at \(\beta_{max}\).
