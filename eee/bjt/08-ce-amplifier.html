The Common-Emitter Amplifier

A CE question was set in 2013–14, 2015–16, 2017–18, 2023–24 and twice in 2024–25 (Q6(a) and Q7(a)), 20 to 27 marks each. Half are derivations ("derive Rin, Ro, Avo, Av, Gv using the T model with ro"; "show the gain with the Early effect is …"), half are numericals with a bias circuit. Sadat sir said derive the expressions and skip numerical practice, but every recent paper also had a numerical: learn the derivation as a written answer and drill the numbers.

1. The circuit and its AC equivalent

The input goes to the base, the output is taken at the collector, and the emitter is at AC ground (grounded directly, or through a bypass capacitor). A typical discrete stage (Sedra Fig. 7.53/7.56): a source \(v_{sig}\) with resistance \(R_{sig}\) coupled to the base, a bias resistance \(R_B\) from base to (AC) ground, \(R_C\) from the collector to \(V_{CC}\), the emitter biased by a current source or a bypassed \(R_E\), and the load \(R_L\) coupled to the collector.

2. Derivation with the hybrid-π model

Write this as the answer to "derive \(R_{in}, R_o, A_{vo}, A_v, G_v\) for the CE amplifier".

  1. Input resistance. Looking in at the base, \(R_B\) is in parallel with \(r_\pi\) (the emitter is grounded): \(\;R_{in} = R_B \parallel r_\pi\) (\(= r_\pi\) if there is no \(R_B\)).
  2. Open-circuit gain. \(v_\pi = v_i\). With \(R_L\) removed, KCL at C: \(v_o/r_o + v_o/R_C + g_mv_\pi = 0\), so \(\;A_{vo} = \dfrac{v_o}{v_i} = -g_m(R_C\parallel r_o)\).
  3. Output resistance. Set \(v_{sig} = 0\): then \(v_\pi = 0\), the source \(g_mv_\pi\) is open, and the output sees \(\;R_o = R_C \parallel r_o\).
  4. Gain with load. \(\;A_v = -g_m(R_C\parallel r_o\parallel R_L) = A_{vo}\dfrac{R_L}{R_L + R_o}\).
  5. Overall gain. \(v_i = v_{sig}R_{in}/(R_{in}+R_{sig})\), so \(\;G_v = -\dfrac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_C\parallel r_o\parallel R_L)\). Without \(R_B\): \(G_v = -\dfrac{\beta(R_C\parallel r_o\parallel R_L)}{R_{sig} + r_\pi}\) (using \(g_mr_\pi = \beta\)).
\[ R_{in} = R_B\parallel r_\pi,\quad A_{vo} = -g_m(R_C\parallel r_o),\quad R_o = R_C\parallel r_o \]\[ G_v = -\frac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_C\parallel r_o\parallel R_L) \]

The minus sign means the CE stage inverts (180° phase shift). The gain is proportional to \(I_C\) (through \(g_m\)) and to the collector load.

3. The same results with the T model

In the T model the base current is \(i_e/(\beta+1)\) with \(i_e = v_i/r_e\), so \(R_{in} = (\beta+1)r_e = r_\pi\); the collector current is \(\alpha i_e = (\alpha/r_e)v_i = g_mv_i\), so every result above follows with \(g_m = \alpha/r_e\). The full written derivation is the 2023–24 Q7(a) answer below. One of the two circulating 2023–24 solution files answers this question with Sedra's CE-with-\(R_e\) derivation (no \(r_o\), \(R_{in} = (\beta+1)(r_e + R_e)\)): that is a different question and would not earn the marks.

4. The Early effect lowers the gain (type B-12 derivation)

With \(r_o\) finite the collector load is \(R_C \parallel r_o\) instead of \(R_C\). 2024–25 asked for this as a derivation from the large-signal law \(i_C = I_Se^{v_{BE}/V_T}(1 + v_{CE}/V_A)\); the result is \(A_v = -g_m(R_C\parallel r_o)\) with \(r_o = (V_A + V_{CE})/I_C\). The full answer is in the exam questions. Numbers: \(V_{CC}\) = 5 V, \(V_{CE}\) = 2.5 V, \(V_A\) = 100 V give −100 V/V without and −97.6 V/V with the Early effect.

5. How big can the signal be?

Method · signal limits (two different questions)

  1. Small-signal limit ("\(v_\pi\) is limited to 5 mV"): \(v_\pi = v_i = v_{sig}R_{in}/(R_{in}+R_{sig})\), so \(\hat v_{sig} = \hat v_\pi(R_{in}+R_{sig})/R_{in}\) and \(\hat v_o = |A_v|\hat v_\pi\).
  2. Large-signal limit ("maximum allowable input"): the collector may rise until cutoff, \(\Delta v_{o+} = I_C(R_C\parallel R_L)\) (\(I_CR_C\) if unloaded), and fall until saturation, \(\Delta v_{o-} = V_{CE} - 0.3\) V (Sadat's edge of saturation; 0.2 V or \(v_{CB}\ge 0\) in other books, so state yours). The smaller one sets \(\hat v_o\); divide by the gain to get the input.
  3. Check that the input you found still keeps \(v_\pi\) within about 10 mV; if not, say the small-signal answer is only approximate.

6. Full numerical CE with bias

Method · CE numerical (6 steps)

  1. DC (capacitors open): find \(I_E\), \(I_C\) and the node voltages. Current-source bias: \(I_E = I\), \(I_B = I/(\beta+1)\), \(V_B = -I_BR_B\), \(V_E = V_B - 0.7\). Divider bias: Thevenin \(V_{BB}\), \(R_{BB}\), then \(I_E = (V_{BB} - 0.7)/(R_E + R_{BB}/(\beta+1))\).
  2. Mode check: \(V_{CE} \ge 0.3\) V, so active. Write it.
  3. Parameters: \(g_m = I_C/V_T\), \(r_\pi = \beta/g_m\), \(r_o = V_A/I_C\).
  4. AC circuit: rails to ground, capacitors short, current source open. Collect everything from base to ground into \(R_B\) and everything from collector to ground into \(R_C\parallel R_L\parallel r_o\).
  5. \(R_{in} = R_B\parallel r_\pi\); \(A_{vo} = -g_m(R_C\parallel r_o)\); \(R_o = R_C\parallel r_o\).
  6. \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}\times[-g_m(R_C\parallel r_o\parallel R_L)]\).

Worked example: 2024–25 Sec B Q7(a)

Base resistor in series with the signal (2015–16)

When \(v_i\) is in series with the bias battery \(V_{BB}\) and a large \(R_{BB}\), the input divider is \(R_{BB}\) against \(r_\pi\): \(v_\pi = v_i\,r_\pi/(R_{BB}+r_\pi)\), so \(v_o/v_i = -g_mR_C\,r_\pi/(R_{BB}+r_\pi) = -\beta R_C/(R_{BB}+r_\pi)\). The gain is small because most of \(v_i\) is lost across \(R_{BB}\).

Traps (where marks go)

  • Ignoring \(r_o\) when \(V_A\) is given (2024–25 Q7(a), 2017–18 Q1(b)), or forgetting \(R_B\) in parallel with \(r_\pi\).
  • \(A_{vo}\) and \(R_o\) with \(R_L\) still connected. Both are defined with the load removed.
  • Dropping the minus sign. CE inverts.
  • The class example (β = 100, \(I_C\) = 1 mA, \(R_C = R_{sig} = R_L\) = 5 kΩ) is written \(G_v\) = −333 V/V in both students' notes (Raiyan p.81, Ikra p.63), a board slip: the right value is −33.3 V/V with \(V_T\) = 25 mV (−34 V/V with the notes' 25.9 mV and \(A_v\) rounded to −100). Also \(A_{vo} = -g_mR_C\) = −200 V/V was asked there but not written.
  • For the \(v_\pi\) limit, \(v_o = A_v v_\pi\) (or \(G_v v_{sig}\)), not \(A_v v_{sig}\).
  • In the T-model derivation, using \((\beta+1)\) and \(\alpha\) inconsistently: \(\alpha(\beta+1) = \beta\) is the identity that turns \(G_v\) into \(-\beta(\cdot)/(R_{sig} + (\beta+1)r_e)\).

Exam questions

2024–25 · Sec B · Q7(a) · 20 marks

The transistor in the figure is biased with a constant current \(I\) = 1 mA, β = 100, \(V_A\) = 100 V. (i) Find the DC voltages at the base, emitter and collector. (ii) Find \(r_\pi\), \(g_m\), \(r_o\) and draw the hybrid-π model. (iii) If Z is grounded, X is driven by \(v_{sig}\) through \(R_{sig}\) = 2 kΩ, and Y is connected to \(R_L\) = 8 kΩ, find the overall voltage gain \(v_y/v_{sig}\).

Show worked answer

(i) DC (all capacitors open). \(I_E = 1\) mA, \(I_B = 1/101 = 9.90\) µA, \(I_C = \alpha I_E = 0.990\) mA.

\(V_B = -I_BR_B = -0.0099\times10 = -0.099\) V; \(V_E = V_B - 0.7 = -0.799\) V; \(V_C = 10 - 0.990\times8 = 2.079\) V. \(V_{CE} = 2.878\) V ≥ 0.3 V, so the BJT is active ✓.

(ii) \(g_m = 0.990/0.025 = 39.6\) mA/V; \(r_\pi = 100/39.6 = 2.525\) kΩ; \(r_o = 100/0.990 = 101\) kΩ. Hybrid-π: \(r_\pi\) from B to E, \(g_mv_\pi\) from C to E, \(r_o\) from C to E (Figure 2 of this chapter).

(iii) Z grounded puts the emitter at AC ground through the capacitor: a CE stage. AC circuit: \(R_B\) = 10 kΩ from B to ground; \(R_C\) = 8 kΩ (top at \(V_{CC}\) = AC ground), \(r_o\) and \(R_L\) from C to ground; the current source is open.

\(R_{in} = R_B\parallel r_\pi = 10\parallel2.525 = 2.016\) kΩ; \(v_b/v_{sig} = 2.016/(2.016 + 2) = 0.502\).

\(R_L' = r_o\parallel R_C\parallel R_L = 101\parallel8\parallel8 = 3.848\) kΩ; \(v_y/v_b = -g_mR_L' = -39.6\times3.848 = -152.4\) V/V.

\(v_y/v_{sig} = 0.502\times(-152.4) = \mathbf{-76.5}\) V/V (−76.9 if \(I_C\) ≈ 1 mA is used).

2024–25 · Sec B · Q6(a) · 20 marks

The small-signal voltage gain of a BJT CE amplifier is \(A_v = -I_CR_C/V_T\) when \(i_C = I_Se^{v_{BE}/V_T}\) (no Early effect). Show that with \(i_C = I_Se^{v_{BE}/V_T}(1 + v_{CE}/V_A)\) the gain becomes

\[ A_v = -\frac{I_CR_C/V_T}{1 + \dfrac{I_CR_C}{V_A + V_{CE}}} = -\frac{(V_{CC} - V_{CE})/V_T}{1 + \dfrac{V_{CC} - V_{CE}}{V_A + V_{CE}}} \]

For \(V_{CC}\) = 5 V, \(V_{CE}\) = 2.5 V and \(V_A\) = 100 V, find the gain with and without the Early effect.

Show worked answer

Basic CE: \(R_C\) from \(V_{CC}\) to the collector, emitter grounded, input \(v_{BE}\) at the base. Output: \(v_{CE} = V_{CC} - i_CR_C\). The small-signal gain is the slope of the transfer curve at the bias point: \(A_v = \left.dv_{CE}/dv_{BE}\right|_Q\).

Write \(i_C = I_0(1 + v_{CE}/V_A)\) with \(I_0 = I_Se^{v_{BE}/V_T}\), so \(dI_0/dv_{BE} = I_0/V_T\). Differentiate (note \(v_{CE}\) depends on \(v_{BE}\)):

\[ \frac{di_C}{dv_{BE}} = \frac{I_0}{V_T}\Big(1 + \frac{v_{CE}}{V_A}\Big) + \frac{I_0}{V_A}\frac{dv_{CE}}{dv_{BE}} = \frac{I_C}{V_T} + \frac{I_0}{V_A}A_v \]

At Q, \(I_0 = I_C/(1 + V_{CE}/V_A) = I_CV_A/(V_A + V_{CE})\), so \(I_0/V_A = I_C/(V_A + V_{CE})\). From the output equation \(A_v = -R_C\,di_C/dv_{BE}\):

\[ A_v = -\frac{I_CR_C}{V_T} - \frac{I_CR_C}{V_A + V_{CE}}A_v \;\Rightarrow\; A_v\Big(1 + \frac{I_CR_C}{V_A + V_{CE}}\Big) = -\frac{I_CR_C}{V_T} \]

which is the first form. Since \(I_CR_C = V_{CC} - V_{CE}\), the second form follows. (Interpretation: \(r_o = (V_A + V_{CE})/I_C\), and the result is \(A_v = -g_mR_C/(1 + R_C/r_o) = -g_m(R_C\parallel r_o)\).) With \(V_A \to \infty\) it reduces to \(-I_CR_C/V_T\).

Numbers: \(V_{CC} - V_{CE} = 2.5\) V. Without the Early effect: \(A_v = -2.5/0.025 = \mathbf{-100}\) V/V. With it: \(A_v = -100/(1 + 2.5/102.5) = -100/1.0244 = \mathbf{-97.6}\) V/V (2.4% lower).

2023–24 · Sec B · Q7(a) · 20 marks  |  not in the senior QBank

Derive the expressions of \(R_{in}\), \(R_o\), \(A_{vo}\), \(A_v\) and \(G_v\) of a common-emitter amplifier with a source resistance using the T model. The amplifier is connected to a source \(v_{sig}\) with resistance \(R_{sig}\), and the output resistance of the transistor is \(r_o\).

Show worked answer

Circuit. \(v_{sig}\) in series with \(R_{sig}\) drives the base; the emitter is at AC ground; \(R_C\) from the collector to \(V_{CC}\) (AC ground); load \(R_L\) at the collector. Replace the BJT by the T model: \(r_e\) from the internal base node to E, a controlled source \(\alpha i_e\) from C to that node, and \(r_o\) from C to E. Since E is grounded, \(r_o\) is directly from C to ground, in parallel with \(R_C\) and \(R_L\). (Figure 3.)

\(R_{in}\). Apply \(v_i\) at the base. The emitter current is \(i_e = v_i/r_e\) (\(v_i\) appears across \(r_e\)). The base current is \(i_b = i_e - \alpha i_e = (1-\alpha)i_e = i_e/(\beta+1)\). So

\[ R_{in} = \frac{v_i}{i_b} = \frac{v_i}{v_i/[(\beta+1)r_e]} = (\beta+1)\,r_e \;(= r_\pi) \]

\(A_{vo}\) (remove \(R_L\)). The current \(\alpha i_e\) flows from C through the controlled source, so it is drawn out of the parallel combination \(R_C\parallel r_o\): \(v_o = -\alpha i_e(R_C\parallel r_o) = -\alpha\dfrac{v_i}{r_e}(R_C\parallel r_o)\).

\[ A_{vo} = \frac{v_o}{v_i} = -\frac{\alpha(R_C\parallel r_o)}{r_e} = -g_m(R_C\parallel r_o) \]

\(R_o\). Set \(v_{sig} = 0\). With no source, \(v_i = 0\), so \(i_e = 0\) and the controlled source \(\alpha i_e\) is an open circuit. Looking back into the collector (with \(R_L\) removed): \(R_o = R_C\parallel r_o\).

\(A_v\) (with \(R_L\)). Now the collector node sees \(R_C\parallel r_o\parallel R_L\):

\[ A_v = -\frac{\alpha(R_C\parallel r_o\parallel R_L)}{r_e} = A_{vo}\frac{R_L}{R_L + R_o} \]

\(G_v\). The source sees \(R_{sig}\) in series with \(R_{in}\): \(v_i/v_{sig} = R_{in}/(R_{in} + R_{sig})\). Then

\[ G_v = \frac{(\beta+1)r_e}{R_{sig} + (\beta+1)r_e}\cdot\left(-\frac{\alpha(R_C\parallel r_o\parallel R_L)}{r_e}\right) = -\frac{\beta\,(R_C\parallel r_o\parallel R_L)}{R_{sig} + (\beta+1)r_e} \]

using \(\alpha(\beta+1) = \beta\). If a bias resistance \(R_B\) is present, \(R_{in} = R_B\parallel(\beta+1)r_e\) and \(G_v = [R_{in}/(R_{in}+R_{sig})]A_v\).

2017–18 · Sec A · Q1(b) · 20 marks  |  Sedra example; Khairul s.42; Sadat notes p.80–81 (without VA)

A CE amplifier uses a BJT with β = 100 and \(V_A\) = 100 V, is biased at \(I_C\) = 1 mA and has a collector resistance \(R_C\) = 5 kΩ. Find \(R_{in}\), \(R_o\) and \(A_{vo}\). If the amplifier is fed from a signal source with a resistance of 5 kΩ and a load \(R_L\) = 5 kΩ is connected to the output, find the resulting \(A_v\) and \(G_v\). If \(\hat v_\pi\) is to be limited to 5 mV, what are the corresponding \(\hat v_{sig}\) and \(\hat v_o\) with the load connected?

Show worked answer

\(g_m = 1/0.025 = 40\) mA/V; \(r_\pi = 100/40 = 2.5\) kΩ; \(r_o = 100/1 = 100\) kΩ. (Emitter grounded: hybrid-π; no bias resistor is mentioned.)

\(R_{in} = r_\pi = 2.5\) kΩ. \(R_o = R_C\parallel r_o = 5\parallel100 = 4.76\) kΩ. \(A_{vo} = -g_m(R_C\parallel r_o) = -40\times4.762 = -190.5\) V/V.

\(A_v = -g_m(R_C\parallel r_o\parallel R_L) = -40\times(4.762\parallel5) = -40\times2.439 = -97.6\) V/V.

\(G_v = \dfrac{2.5}{2.5 + 5}\times(-97.6) = -32.5\) V/V.

\(\hat v_\pi = \hat v_i\) = 5 mV: \(\hat v_{sig} = 5\times\dfrac{2.5 + 5}{2.5} = 15\) mV; \(\hat v_o = |A_v|\hat v_\pi = 97.6\times5\text{ mV} = 0.488\) V.

Without \(V_A\) (Sedra's and Sadat's version): \(A_{vo}\) = −200, \(R_o\) = 5 kΩ, \(A_v\) = −100, \(G_v\) = −33.3 V/V, \(\hat v_o\) = 0.5 V.

2015–16 · Sec A · Q4(b) · 26⅔ marks  |  Sedra Example 7.x; Sadat slides B-s33–35; Khairul s.37–38

For the circuit shown, calculate (i) the DC bias point, (ii) the small-signal voltage gain, (iii) the maximum allowable input AC voltage. β = 100.

Show worked answer

(i) DC (\(v_{in}\) = 0): \(I_B = (3 - 0.7)/100 = 0.023\) mA; \(I_C = \beta I_B = 2.3\) mA; \(I_E = 2.323\) mA. \(V_C = 10 - 2.3\times3 = 3.1\) V, \(V_{CE} = 3.1\) V ≥ 0.3 V: active ✓ (\(V_B = 0.7 < V_C\), CBJ reverse).

\(v_o = -g_mR_Cv_\pi\), so \(A_v = -92\times3\times0.01075 = -\beta R_C/(R_{BB}+r_\pi) = -300/101.087 = \mathbf{-2.97}\) V/V (Sedra rounds to −3.04).

(iii) The output can rise until cutoff: \(I_CR_C = 6.9\) V (to \(v_C = 10\) V). It can fall until the edge of saturation: \(V_{CE} - 0.3 = 2.8\) V (Sadat's convention). The negative swing is the limit: \(\hat v_{in} = 2.8/2.968 = \mathbf{0.943}\) V peak. With \(V_{CE,sat}\) = 0.2 V: 2.9/2.968 = 0.977 V; with Sedra's \(v_{CB} \ge 0\) (collector not below 0.7 V): 2.4/2.968 = 0.81 V. State the criterion you use.

Check: at 0.94 V input, \(v_\pi = 0.01075\times0.94\) ≈ 10 mV, at the edge of the small-signal range, so the answer is approximate.

Sedra 7e P7.50 · highlighted by the teacher

Using the hybrid-π model (neglect \(r_o\)), show that for a CE amplifier fed by \(v_{sig}\) with resistance \(R_{sig}\) and with collector resistance \(R_C\): \(R_{in} = r_\pi\), \(v_\pi/v_{sig} = r_\pi/(r_\pi + R_{sig})\), \(v_o/v_\pi = -g_mR_C\), and hence \(v_o/v_{sig} = -\beta R_C/(r_\pi + R_{sig})\).

Show worked answer

Emitter grounded: the only element from base to ground is \(r_\pi\), so \(R_{in} = r_\pi\). The source sees \(R_{sig}\) in series with \(r_\pi\): \(v_\pi = v_{sig}r_\pi/(r_\pi + R_{sig})\). At the collector, \(g_mv_\pi\) flows down through the source, drawn from \(R_C\): \(v_o = -g_mv_\pi R_C\). Multiply: \(v_o/v_{sig} = -g_mr_\pi R_C/(r_\pi + R_{sig}) = -\beta R_C/(r_\pi + R_{sig})\) since \(g_mr_\pi = \beta\). Note the overall gain depends on β directly when \(R_{sig}\) is comparable to \(r_\pi\): one motivation for emitter degeneration (next chapter).

Key terms

Quick check

Summary: CE = input at the base, output at the collector, emitter at AC ground. \(R_{in} = R_B\parallel r_\pi\) (\(= (\beta+1)r_e\) with the T model), \(A_{vo} = -g_m(R_C\parallel r_o) = -\alpha(R_C\parallel r_o)/r_e\), \(R_o = R_C\parallel r_o\), \(A_v = -g_m(R_C\parallel r_o\parallel R_L)\), \(G_v = A_vR_{in}/(R_{in}+R_{sig}) = -\beta(R_C\parallel r_o\parallel R_L)/(R_{sig}+r_\pi)\) without \(R_B\). The Early effect enters only through \(r_o = (V_A + V_{CE})/I_C\). For numericals: DC first with the mode check, then \(g_m, r_\pi, r_o\), then the formulas; for signal limits use \(v_\pi = v_i\) or the cutoff/saturation swings.
