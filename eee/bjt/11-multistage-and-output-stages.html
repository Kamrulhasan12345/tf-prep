Multistage Amplifiers and Output Stages

The one cascaded BJT amplifier in the question set is 2016–17 Sec B Q8(a) (36⅔ marks: CE followed by an emitter follower, "find gm, rπ, re of both transistors, the overall gain, Rin and Rout"). It is medium priority: it is nothing new, only the CE and CC chapters chained with the loading done correctly, so if you can do those you can do this. Class A/B/AB output stages are only a short overview: not examinable per Sadat sir (he said skip push-pull).

1. Cascading and loading

Each stage is a two-port with its own \(R_{in}\), \(A_{vo}\), \(R_o\). Joined by a coupling capacitor, the input resistance of stage 2 becomes the load of stage 1, and the output resistance of stage 1 becomes the source resistance of stage 2. Units: mA, kΩ, V.

\[ R_{in} = R_{in1},\qquad A_{v1} = A_{vo1}\frac{R_{in2}}{R_{in2}+R_{o1}},\qquad A_v = A_{v1}A_{v2},\qquad R_{out} = R_{o2}\Big|_{R_{sig2} = R_{o1}} \]\[ G_v = \frac{R_{in1}}{R_{in1}+R_{sig}}\,A_{v1}A_{v2} \]

Two equivalent ways to find \(A_{v1}\): (a) put stage 2 into the collector load of stage 1, \(A_{v1} = -g_{m1}(R_{C1}\parallel R_{ib2})\); or (b) the Thevenin voltage-divider form above. Work from the load backwards: stage 2's \(R_{in}\) first, then stage 1's gain, then the front end. For a CE → CC amplifier with a follower \(R_{ib2} = (\beta+1)(r_{e2} + R_{E2}\parallel R_L)\):

  • stage 1 collector load: \(R_{C1}\parallel R_{B2}\parallel R_{ib2}\) (\(R_{B2} = R_3\parallel R_4\) if stage 2 has a divider);
  • \(A_{v2} = R_{E2}'/(r_{e2} + R_{E2}')\) with \(R_{E2}' = R_{E2}\parallel R_L\) (slightly below 1);
  • \(R_{in} = R_1\parallel R_2\parallel r_{\pi1}\) (emitter of stage 1 bypassed), \(R_{out} = R_{E2}\parallel\big[r_{e2} + (R_{C1}\parallel R_{B2})/(\beta+1)\big]\): the source resistance of stage 2 is the stage-1 collector side.

The follower at the end is there for the load: a 250 Ω load on a CE stage alone would kill the gain (\(R_C\parallel 250\approx 244\) Ω), but behind a follower it only sees \(R_{ib2}\approx\) tens of kΩ.

2. DC with several stages

With capacitor coupling the stages are DC-isolated: solve the bias of each stage separately (Thevenin base network, \(I_E\), \(I_C\), mode check). With direct coupling the base current of stage 2 is drawn from the collector node of stage 1 and must be included in KCL (Sadat, note p.93: ignoring it only approximates the BJT cascade; a MOSFET gate draws none, so there the answer is exact). Chapter 5 covers the DC part.

3. The current-source-biased amplifier (2024–25)

2024–25 Q7(a) used a transistor with an ideal current source \(I\) in the emitter (a bias circuit that fixes \(I_E = I\) regardless of β) and three terminals X, Y, Z coupled to the signal, the load and the emitter. Z grounded gives a CE stage (done in Chapter 8). With the source in a CE stage, AC: the source is open, the emitter bypass puts \(R_e = 0\); with an unbypassed \(R_e\) the Chapter 9 formulas apply. In a follower the same current source makes \(R_E = \infty\), so the emitter load is just \(R_L\) (and \(r_o\)). Chaining the two gives the drill below.

Method · two-stage small-signal gain (CE → CC)

  1. DC, stage by stage: \(I_{E1} = I_1\), \(I_{E2} = I_2\) (current-source bias); \(I_C = \alpha I_E\); mode check for each.
  2. Parameters of each transistor: \(r_e = V_T/I_E\), \(g_m\), \(r_\pi\).
  3. Small-signal circuit of the whole chain: rails and current sources off, capacitors short; stage 1 with \(R_{C}\), then stage 2 as a load.
  4. Backwards: \(R_{in2} = R_{B2}\parallel(\beta+1)(r_{e2} + R_L)\); \(A_{v2} = R_L/(r_{e2} + R_L)\); \(A_{v1} = -g_{m1}(R_C\parallel R_{in2})\); \(R_{in} = R_{B1}\parallel r_{\pi1}\); \(R_{out} = r_{e2} + (R_C\parallel R_{B2})/(\beta+1)\) (current source open).
  5. \(A_v = A_{v1}A_{v2}\); \(G_v = [R_{in}/(R_{in}+R_{sig})]A_v\).

Traps (where marks go)

  • Forgetting that stage 2 loads stage 1: using \(A_{v1} = -g_{m1}R_{C1}\) is the commonest loss.
  • Putting \(R_{in2}\) with \(R_L\) removed (it contains \(R_L\) for a follower), or forgetting the stage-2 bias divider \(R_3\parallel R_4\) in stage 1's load.
  • \(R_{out}\) of the last stage needs the stage-1 collector resistance as its source resistance: \(R_{C1}\parallel R_3\parallel R_4\) divided by \(\beta+1\).
  • Both stages must be DC solved separately: do not reuse \(I_{C1}\) for stage 2. Different \(I_C\) means different \(g_m\), \(r_\pi\), \(r_e\).
  • The figure of 2016–17 omits the supply voltage. State your assumption (10 V is the likely value, with 12 V given for comparison).

Exam questions

2016–17 · Sec B · Q8(a) · 36⅔ marks

For the circuit shown, determine the small-signal parameters \(g_m\), \(r_\pi\) and \(r_e\) for both transistors, the overall small-signal voltage gain \(A_v = v_o/v_s\), the input resistance \(R_{in}\) and the output resistance \(R_{out}\). β = 120.

Figure as read from the scan: stage 1 is a CE amplifier with R1 = 67.3 kΩ, R2 = 12.7 kΩ, RC1 = 10 kΩ, RE1 = 2 kΩ bypassed by CE; stage 2 is an emitter follower with R3 = 15 kΩ, R4 = 45 kΩ, RE2 = 1.6 kΩ and the load RL = 250 Ω capacitor-coupled to the emitter; vs is coupled to the base of Q1 with no source resistance. The supply voltage VCC is not legible. VCC = 10 V is assumed here (it gives IC2 ≈ 4 mA as in the textbook cascade); results for 12 V are at the end.

Show worked answer

DC, stage 1 (the coupling capacitors block DC): \(V_{BB1} = 10\times12.7/80 = 1.5875\) V, \(R_{BB1} = 67.3\parallel12.7 = 10.68\) kΩ. \(I_{E1} = \dfrac{1.5875 - 0.7}{2 + 10.68/121} = 0.425\) mA, \(I_{C1} = 0.4215\) mA, \(V_{CE1} = 10 - 0.4215\times10 - 0.425\times2 = 4.94\) V: active ✓.

DC, stage 2: \(V_{BB2} = 10\times45/60 = 7.5\) V, \(R_{BB2} = 15\parallel45 = 11.25\) kΩ. \(I_{E2} = \dfrac{7.5 - 0.7}{1.6 + 11.25/121} = 4.016\) mA, \(I_{C2} = 3.983\) mA, \(V_{CE2} = 10 - 4.016\times1.6 = 3.57\) V: active ✓.

Parameters. Q1: \(g_{m1} = 0.4215/0.025 = 16.86\) mA/V, \(r_{\pi1} = 120/16.86 = 7.12\) kΩ, \(r_{e1} = 25/0.425 = 58.8\) Ω. Q2: \(g_{m2} = 3.983/0.025 = 159.3\) mA/V, \(r_{\pi2} = 0.753\) kΩ, \(r_{e2} = 25/4.016 = 6.22\) Ω.

AC, from the output backwards. \(R_{E2}\parallel R_L = 1.6\parallel0.25 = 0.2162\) kΩ. \(R_{ib2} = (\beta+1)(r_{e2} + 0.2162) = 121\times0.2224 = 26.9\) kΩ. \(A_{v2} = 0.2162/(0.00622 + 0.2162) = \mathbf{0.972}\).

Stage 1 load: \(R_{C1}\parallel R_3\parallel R_4\parallel R_{ib2} = 10\parallel15\parallel45\parallel26.9 = 4.424\) kΩ. \(A_{v1} = -g_{m1}\times4.424 = -16.86\times4.424 = \mathbf{-74.6}\).

Overall: \(A_v = -74.6\times0.972 = \mathbf{-72.5}\) V/V (no source resistance, so \(G_v = A_v\)).

\(R_{in}\) \(= R_1\parallel R_2\parallel r_{\pi1} = 10.68\parallel7.12 = \mathbf{4.27}\) kΩ (emitter of Q1 bypassed).

\(R_{out}\) (source off, load removed): the source resistance seen by stage 2 is \(R_{C1}\parallel R_3\parallel R_4 = 10\parallel11.25 = 5.29\) kΩ: \(R_{out} = R_{E2}\parallel[r_{e2} + 5.29/121] = 1600\parallel(6.22 + 43.7)\) Ω \(= \mathbf{48.5}\) Ω.

If \(V_{CC}\) = 12 V: \(I_{C1}\) = 0.572 mA, \(I_{C2}\) = 4.86 mA; \(g_{m1}\) = 22.9, \(r_{\pi1}\) = 5.24 kΩ, \(r_{e1}\) = 43.3 Ω; \(g_{m2}\) = 194.5, \(r_{\pi2}\) = 617 Ω, \(r_{e2}\) = 5.10 Ω; \(R_{in}\) = 3.52 kΩ, \(A_v\) = −98.8, \(R_{out}\) = 47.4 Ω. State the assumption in the exam; the method carries the marks.

4. Output stages: class A, B, AB (overview, not examinable)

Not examinable per Sadat sir (he said skip push-pull). For completeness (Khairul s.52–54): the output stage drives a low-resistance load and is judged by efficiency and linearity.

Key terms

Quick check

Summary: In a cascade the \(R_{in}\) of each stage loads the stage before it and the \(R_o\) of each stage is the source resistance of the next: \(A_{v1} = A_{vo1}R_{in2}/(R_{in2}+R_{o1})\), \(A_v = A_{v1}A_{v2}\), \(R_{in} = R_{in1}\), \(R_{out}\) from the last stage with stage 1's output resistance as its source. Bias each stage separately (coupled by capacitors), then solve backwards from the load. A follower at the end buys a low \(R_{out}\). Class A/B/AB: overview only, not examinable.
