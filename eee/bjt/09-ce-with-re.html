The CE Amplifier with Emitter Resistance

B-08 was set in 2011–12 (36 marks), 2018–19 (26⅔), 2019–20 (30, the January 2021 paper) and 2021–22 (26⅔), plus class tests in 2018 and 2021. The two most recent ones are pure derivations ("derive Ri, Ro, Av, Gv for a CE amplifier with emitter resistance using the T model"), so the derivation below is a full-marks written answer. The numerical forms ask for Re so that Rin is a given multiple of Rsig. Sadat sir's rule: use the T model whenever the emitter is not grounded.

1. The circuit: why put a resistor in the emitter

Take the CE stage of the last chapter and leave a resistor \(R_e\) between the emitter and AC ground (that is, \(R_e\) is not bypassed). The input still goes to the base, the output is still at the collector. The bias is a current source or a divider as before; here we only need the AC picture. Units in this chapter: mA, kΩ, V, mA/V (so \(g_m\) = \(I_C\)/25 mV in mA/V and \(r_e\) = 25/\(I_E\) in Ω).

2. Derivation with the T model (write this in the exam)

Why the T model: \(r_e\) and \(R_e\) are in series on the emitter side, so the same current \(i_e\) flows through both, and the base current is simply \(i_e/(\beta+1)\). \(r_o\) is neglected unless the question gives \(V_A\).

  1. Input resistance seen into the base (test voltage \(v_i\) at the base, \(R_B\) and \(R_{sig}\) taken away). The emitter current is \(i_e = \dfrac{v_i}{r_e + R_e}\). The base current is \(i_b = (1-\alpha)i_e = \dfrac{i_e}{\beta+1}\). So \[ R_{ib} = \frac{v_i}{i_b} = (\beta+1)(r_e + R_e) \] This is the resistance-reflection rule: the resistance in the emitter circuit looks \(\beta+1\) times larger from the base. With a bias resistor, \(R_{in} = R_B\parallel R_{ib}\).
  2. Open-circuit gain (remove \(R_L\)). \(i_c = \alpha i_e = \alpha v_i/(r_e + R_e)\) flows down through the source, out of \(R_C\): \(v_o = -\alpha i_eR_C\), so \[ A_{vo} = \frac{v_o}{v_i} = -\frac{\alpha R_C}{r_e + R_e} \] (collector resistance over emitter resistance, times \(\alpha\)).
  3. Output resistance. Set \(v_{sig} = 0\), remove \(R_L\), test at the collector. The ideal current source \(\alpha i_e\) has infinite resistance, so \(R_o = R_C\) (no \(r_o\)). With \(r_o\) the result is larger (see the note below).
  4. Gain with the load. Replace \(R_C\) by \(R_C\parallel R_L\): \[ A_v = -\frac{\alpha(R_C\parallel R_L)}{r_e + R_e} = A_{vo}\frac{R_L}{R_L + R_o} \]
  5. Overall gain. The source drives \(R_{in}\) through \(R_{sig}\): \(v_i/v_{sig} = R_{in}/(R_{in}+R_{sig})\). Without \(R_B\), using \(\alpha(\beta+1) = \beta\): \[ G_v = \frac{(\beta+1)(r_e+R_e)}{R_{sig} + (\beta+1)(r_e+R_e)}\cdot\frac{-\alpha(R_C\parallel R_L)}{r_e+R_e} = -\frac{\beta\,(R_C\parallel R_L)}{R_{sig} + (\beta+1)(r_e + R_e)} \] With \(R_B\): \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\) with \(R_{in} = R_B\parallel R_{ib}\).
  6. Current gain. \(i_c/i_b = \beta\). The short-circuit current gain from a source current \(i_s\) (Norton form, \(R_{sig}\parallel R_B\) in front of the base) is \(A_{is} = -\beta R_B/(R_B + R_{ib})\), since only the fraction \(R_B/(R_B+R_{ib})\) of \(i_s\) enters the base.
\[ R_{ib} = (\beta+1)(r_e+R_e),\quad A_{vo} = -\frac{\alpha R_C}{r_e+R_e},\quad R_o = R_C,\quad G_v = -\frac{\beta(R_C\parallel R_L)}{R_{sig}+(\beta+1)(r_e+R_e)} \]

The same thing with the hybrid-π model (what the January 2021 answer uses): \(R_{ib} = r_\pi + (\beta+1)R_e\) and \(A_{vo} = -\beta R_C/[r_\pi + (\beta+1)R_e]\). Because \(r_\pi = (\beta+1)r_e\) the two forms are identical.

With \(r_o\): \(R_{ib}\) and the gain change by a few percent (\(r_o\) is large). The useful fact is that the output resistance rises to roughly \(R_o \approx R_C\parallel\{r_o[1 + g_m(R_e\parallel(r_\pi + R_{sig}\parallel R_B))]\}\): the emitter resistor makes the collector look like a better current source. Only quote this if \(V_A\) is given.

3. What the resistor buys and what it costs

Compare with \(R_e = 0\). Since \(r_e + R_e = r_e(1 + R_e/r_e) = r_e(1 + g_mR_e)\) (using \(g_m\approx 1/r_e\)):

  • \(R_{ib}\) rises by the factor \(1 + g_mR_e\).
  • The base-to-collector gain \(A_v\) falls by the same factor. For \(g_mR_e \gg 1\): \(A_v \approx -\alpha R_C/R_e\), set by two resistors and almost independent of \(\beta\), temperature and \(I_C\).
  • The transistor sees only a fraction of the input: \(v_\pi = v_i\,r_e/(r_e + R_e) = v_i/(1 + g_mR_e)\). So for the same distortion (same \(\hat v_\pi\)) the input signal can be larger by \(1 + g_mR_e\): the stage is more linear.
  • \(G_v\) depends much less on \(\beta\), and the high-frequency response improves.

It is negative feedback (\(R_e\) is the "emitter degeneration" resistance): the gain is what you pay for the other four. Costs: lower gain; the DC drop \(I_ER_e\) reduces the headroom (bias circuit and swings). A resistor placed in series with the collector load but between the collector and the output tap does not change \(i_c\), \(R_o\) or the gain (2018–19 trap below).

4. Procedure

Method · CE with Re (the teacher's five steps)

  1. DC (capacitors open): find \(I_E\) (current source: \(I_E = I\)), \(I_C = \alpha I_E\), node voltages, mode check \(V_{CE}\ge 0.3\) V. Skip it if \(I_C\) or \(r_e\) is given or the answer is symbolic.
  2. Parameters: \(r_e = V_T/I_E\) (VT = 25 mV; Sadat's notes use 25.9 mV), \(g_m = I_C/V_T\), \(r_\pi = \beta/g_m\). The mode check and the parameters use the same \(I_E\).
  3. Small-signal circuit with the T model (emitter not grounded): rails and current sources off, capacitors short. Draw it with \(R_B\) at the base, \(R_e\) under \(r_e\), \(R_C\parallel R_L\) at the collector. Do not delete the \(R_e\) that is not bypassed.
  4. \(R_{ib} = (\beta+1)(r_e+R_e)\); \(R_{in} = R_B\parallel R_{ib}\); \(A_{vo} = -\alpha R_C/(r_e+R_e)\); \(R_o = R_C\). Design: from a target \(R_{in} = kR_{sig}\) get \(R_{ib} = kR_{sig}R_B/(R_B - kR_{sig})\) (just \(kR_{sig}\) without \(R_B\); impossible if \(R_B\le kR_{sig}\)), then \(R_e = R_{ib}/(\beta+1) - r_e\).
  5. \(A_v = A_{vo}R_L/(R_L+R_o)\); \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\). Signal limit: \(\hat v_\pi = \hat v_i\,r_e/(r_e+R_e)\), so \(\hat v_i = \hat v_\pi(r_e+R_e)/r_e\) and \(\hat v_{sig} = \hat v_i(R_{in}+R_{sig})/R_{in}\). Collector swing: up \(I_C(R_C\parallel R_L)\), down to \(V_{CE}\) = 0.3 V (or \(V_{CB}\) = 0; state yours).

Test sources: \(R_{in}\) is always found with a test source at the base (all independent sources off, \(v_x\) and \(i_x\) at the input), as in step 1 of the derivation.

Worked example: full analysis (2011–12 Sec B Q8(b), parts v and vi)

Design \(R_e\) for a given \(R_{in}\) (2011–12, 2018–19)

The wording is "find \(R_e\) so that \(R_{in} = 4R_{sig}\)" (or 5). Do the algebra on \(R_{ib}\), not on \(R_{in}\), when a bias resistor is present. If \(\beta\) is not given with \(r_e\) separately, say whether you use \(\beta\) or \(\beta+1\) (they differ by 1%). Answers that differ by that much are accepted.

Design \(R_e\) for a target gain

Without \(R_B\): \(G_v = -\beta(R_C\parallel R_L)/[R_{sig} + (\beta+1)(r_e + R_e)]\). Solve for \(R_e\):

\[ R_e = \frac{1}{\beta+1}\left[\frac{\beta(R_C\parallel R_L)}{|G_v|} - R_{sig}\right] - r_e \]

The bracket must exceed \((\beta+1)r_e\), otherwise even \(R_e = 0\) gives a smaller gain than asked. Pick \(R_e\) first and the gain follows; the drill also asks how little \(G_v\) moves when \(\beta\) changes (the point of degeneration).

Traps (where marks go)

  • \(\beta\) versus \(\beta+1\): \(R_{ib} = (\beta+1)(r_e+R_e)\) but \(G_v\) has \(\beta\) in the numerator. Writing \(\beta\) in the denominator costs 1%, writing \(\beta+1\) on top is wrong.
  • Forgetting \(R_B\) in parallel when designing \(R_e\): solve for \(R_{ib}\) first (\(1/R_{ib} = 1/R_{in} - 1/R_B\)).
  • A resistor in series with the collector but ahead of the output tap (2018–19: the 2 kΩ below the 3 kΩ) carries \(i_c\) and does not enter \(A_v\) or \(R_o\). Only what is between the collector current and the output node counts.
  • Where the bypass capacitor sits decides which resistance is in the AC path (C across \(R_e\) removes it; C only across the current source keeps it).
  • Giving \(A_{vo}\) with \(R_L\) connected, or \(R_o\) from \(R_C\parallel R_L\). Both are defined with the load removed. The reflection rule applies only to the emitter side, not to \(R_C\).
  • Dropping \(r_e\): \(A_v \approx -R_C/R_e\) is only valid when \(R_e \gg r_e\); the design formulas keep \(r_e\) (here 25 Ω is not negligible against 200 Ω).

Exam questions

2021–22 · Sec B · Q7(a) · 26⅔ marks  |  also Class test 2 (2021): derive Rin, Rout

Derive the expressions of \(R_i\), \(R_o\), \(A_v\) and \(G_v\) for a common-emitter amplifier with emitter resistance \(R_e\) using the T model.

Show worked answer

Circuit. \(v_{sig}\) with \(R_{sig}\) at the base, collector resistor \(R_C\) (to \(V_{CC}\), AC ground), load \(R_L\) at the collector, \(R_e\) from the emitter to AC ground. Replace the BJT by the T model: \(r_e\) from base to emitter, a controlled source \(\alpha i_e\) from collector to emitter, \(r_o\) neglected (Figure 2). If a bias resistor \(R_B\) is present it is in parallel with the resistance into the base.

\(R_i\). A voltage \(v_i\) at the base drives \(i_e = v_i/(r_e + R_e)\). The base current is \(i_b = i_e - \alpha i_e = i_e/(\beta+1)\). Therefore

\[ R_{ib} = \frac{v_i}{i_b} = (\beta+1)(r_e + R_e),\qquad R_i = R_B\parallel R_{ib} \]

\(R_o\). With \(v_{sig} = 0\) (and \(R_L\) removed), \(i_e = 0\), so \(\alpha i_e\) is an open circuit: \(R_o = R_C\).

\(A_{vo}\) and \(A_v\). \(i_c = \alpha i_e = \alpha v_i/(r_e + R_e)\) flows through \(R_C\parallel R_L\) (with the load; through \(R_C\) alone for \(A_{vo}\)), so

\[ A_{vo} = -\frac{\alpha R_C}{r_e + R_e},\qquad A_v = \frac{v_o}{v_i} = -\frac{\alpha(R_C\parallel R_L)}{r_e + R_e} \]

\(G_v\). \(v_i = v_{sig}R_i/(R_i + R_{sig})\), so \(G_v = \dfrac{R_i}{R_i + R_{sig}}A_v\). With no \(R_B\) and \(\alpha(\beta+1) = \beta\):

\[ G_v = -\frac{\beta\,(R_C\parallel R_L)}{R_{sig} + (\beta+1)(r_e + R_e)} \]

For \(R_e \gg r_e\): \(A_v \approx -\alpha(R_C\parallel R_L)/R_e\), independent of \(\beta\). (The marks are for \(R_{ib}\), \(A_{vo}\)/\(A_v\), \(R_o\) and \(G_v\), each with the derivation line, not just the result.)

2019–20 (January 2021 paper) · Sec A · Q3(a) · 30 marks

For a BJT common-emitter amplifier with a resistance in the emitter, derive the expressions for the input impedance, output impedance, voltage gain and current gain. What are the advantages and disadvantages of adding a resistance in the emitter?

Show worked answer

Hybrid-π with \(r_o\) neglected (the T-model derivation of Q7(a) 2021–22 gives the same results). Signal \(v_b\) at the base, collector resistor \(R_C\), emitter resistor \(R_E\), base current \(i_b\).

Input resistance. \(v_b = i_b r_\pi + (i_b + g_mv_\pi)R_E = i_b[r_\pi + (\beta+1)R_E]\), since \(g_mv_\pi = \beta i_b\). So \(R_{in} = r_\pi + (\beta+1)R_E\) (in parallel with \(R_B\) if there is a bias network).

Output resistance. \(R_{out} = R_C\): looking into the collector, the collector current is independent of \(v_C\) (no \(r_o\)).

Voltage gain. \(i_c = \beta i_b = \beta v_b/[r_\pi + (\beta+1)R_E]\), so \(A_v = v_c/v_b = -\dfrac{\beta R_C}{r_\pi + (\beta+1)R_E} \approx -\dfrac{R_C}{R_E}\) when \((\beta+1)R_E \gg r_\pi\). With a load, \(R_C\to R_C\parallel R_L\).

Current gain. \(A_i = i_c/i_b = \beta\) (\(= -\beta\) with the load-current sign convention); the gain from the source current is reduced by the bias divider \(R_B/(R_B + R_{ib})\).

Advantages. (1) \(R_{in}\) is larger by \((\beta+1)R_E\). (2) The gain is set by resistors, nearly independent of \(\beta\), temperature and \(I_C\) (negative feedback). (3) Better linearity: only the fraction \(1/(1+g_mR_E)\) of the input appears across the base-emitter junction, so larger inputs are tolerated. (4) Wider bandwidth. (5) The DC bias point is more stable (\(R_E\) also feeds back at DC). Disadvantages. Voltage gain is reduced by \(1 + g_mR_E\); the DC drop across \(R_E\) takes away supply headroom and output swing.

2018–19 · Sec A · Q3(a) · 26⅔ marks  |  also 2011–12 Q8(b)(v)

For the circuit shown, find the value of \(R_E\) so that \(R_i\) is five times the value of \(R_s\). Then, using this value, find \(R_i\), \(R_o\), \(A_v\) and \(A_i\). You can neglect the Early effect. \(\beta\) = 100, \(r_e\) = 40 Ω.

Figure as read from the scan: Rs = 5 kΩ in series with the base, an unbypassed RE, collector circuit VCC – 3 kΩ – tap – 2 kΩ – collector, the output taken at the tap between the 3 kΩ and the 2 kΩ.

Show worked answer

\(R_i = R_{ib} = (\beta+1)(r_e + R_E)\) (no bias resistor drawn). Set \(R_i = 5R_s = 25\) kΩ: \(r_e + R_E = 25/101 = 247.5\) Ω, so \(R_E = 247.5 - 40 = \mathbf{207.5}\) Ω (210 Ω if \(\beta\) is used instead of \(\beta+1\)).

\(R_i = 25\) kΩ. The current \(i_c\) flows through the 2 kΩ and then the 3 kΩ, and \(v_o\) is taken at the tap, so only the 3 kΩ is the collector load. The 2 kΩ is in series with the collector current source and does not matter: \(R_o = \mathbf{3}\) kΩ.

\(v_o/v_b = -\alpha\times3/(r_e + R_E) = -0.990\times3/0.2475 = -12.0\) V/V. The source divider: \(v_b/v_s = 25/(25+5) = 0.8333\), so the overall gain \(v_o/v_s = -12.0\times0.8333 = \mathbf{-10}\) V/V (also \(-\beta\times3/(5 + 25) = -10\)).

\(A_i = i_c/i_b = \beta = \mathbf{100}\) (the current through the output terminal is \(i_c\)).

Consider the emitter-degenerated CE circuit of the figure. (i) Find the DC current \(I_C\) and the voltages \(V_C\), \(V_B\), \(V_E\); \(\beta\) = 100, \(V_{BE}\) = 0.7 V. (ii) What are the allowable signal swings at the collector in both directions? (iii) Determine \(r_\pi\), \(r_e\), \(g_m\) at this bias point. (iv) Draw the complete small-signal equivalent circuit (neglect \(r_o\)). (v) Find \(R_e\) such that \(R_{in} = 4R_{sig}\). (vi) For that \(R_e\) find \(A_{vo}\), \(R_{out}\), \(A_v\), \(G_v\) and the short-circuit current gain \(A_{is}\).

Figure as given in the question bank: Rsig = 5 kΩ, RB = 100 kΩ, RC = 8 kΩ to +10 V, RL = 5 kΩ, 1 mA current sink to −10 V with C3 across it. The printed β reads 1000 in one scan; β = 100 is used (the answers below match the standard solution).

Show worked answer

(i) The current source sets \(I_E = 1\) mA: \(I_B = 1/101 = 9.90\) µA, \(I_C = \alpha I_E = 0.990\) mA. \(V_B = -I_BR_B = -0.0099\times100 = -0.990\) V; \(V_E = -0.990 - 0.7 = -1.690\) V (the emitter terminal; \(R_e\) carries only the DC current \(I_E\), and the current source sits below it); \(V_C = 10 - 0.990\times8 = 2.079\) V. \(V_{CE} = 3.77\) V ≥ 0.3 V: active ✓.

(ii) Upward the collector swings until cutoff: \(\Delta v_C^+ = I_C(R_C\parallel R_L) = 0.990\times3.077 = \mathbf{+3.05}\) V. Downward until the collector junction is at zero bias (\(V_C = V_B\)): \(\Delta v_C^- = 2.079 - (-0.990) = \mathbf{3.07}\) V (3.47 V with Sedra's \(V_{CB} \ge -0.4\) V; state your criterion). The smaller, 3.05 V, limits the symmetrical swing.

(iii) \(g_m = 0.990/0.025 = 39.6\) mA/V, \(r_\pi = 100/39.6 = 2.525\) kΩ, \(r_e = 25/1 = 25\) Ω.

(iv) T model: \(R_{sig}\) to the base node, \(R_B\) base to ground, \(r_e\) base to emitter, \(R_e\) emitter to ground, \(\alpha i_e\) from collector to emitter, \(R_C\parallel R_L\) collector to ground (Figure 2).

(v) \(R_{in} = 4\times5 = 20\) kΩ \(= R_B\parallel R_{ib}\), so \(R_{ib} = 1/(1/20 - 1/100) = 25\) kΩ. \(R_{ib} = 101(0.025 + R_e) = 25\) gives \(R_e = 0.2475 - 0.025 = \mathbf{222.5}\) Ω (Sedra gets about 225 Ω using \(r_\pi\) = 2.5 kΩ).

(vi) \(r_e + R_e = 247.5\) Ω. \(A_{vo} = -\alpha R_C/(r_e+R_e) = -0.990\times8/0.2475 = \mathbf{-32.0}\) V/V (\(= -\beta R_C/R_{ib} = -100\times8/25\)). \(R_{out} = R_C = \mathbf{8}\) kΩ. \(A_v = A_{vo}R_L/(R_L+R_o) = -32.0\times5/13 = \mathbf{-12.3}\) V/V. \(G_v = A_v\times R_{in}/(R_{in}+R_{sig}) = -12.3\times20/25 = \mathbf{-9.85}\) V/V. \(A_{is} = -\beta R_B/(R_B + R_{ib}) = -100\times100/125 = \mathbf{-80}\) A/A.

\(R_{ib} = (\beta+1)(r_e + R_e)\); \(R_{in} = R_B\parallel R_{ib}\); \(R_o = R_C\) (with \(r_o\): see section 2). For the current-source bias the DC part fixes \(I_E = I\) and so \(r_e = V_T/I\); the current source itself (open) and \(C_3\) do not appear in the AC circuit, so \(R_e\) is the whole emitter resistance.

A divider-biased BJT (100 kΩ and 100 kΩ from a 5 V supply) has \(R_E\) = 3.6 kΩ and \(R_C\) = 3.3 kΩ and is operated at \(I_C\) ≈ 0.5 mA (so \(r_e\) = 50 Ω). The signal \(v_i\) is applied at the base through a coupling capacitor, and two outputs are taken: \(v_{o1}\) at the emitter and \(v_{o2}\) at the collector (the "phase splitter"). Show that \(v_{o1}/v_i = R_E/(R_E + r_e)\) and \(v_{o2}/v_i = -\alpha R_C/(R_E + r_e)\), and find their values. What is \(v_{o2}/v_i\) if the emitter output is grounded through a bypass capacitor?

Show worked answer

T model, \(i_e = v_i/(r_e + R_E)\) flows through \(R_E\) (no \(R_L\)): \(v_{o1} = i_eR_E = v_iR_E/(R_E + r_e)\) (an emitter follower). The collector current \(\alpha i_e\) flows down through the source, out of \(R_C\): \(v_{o2} = -\alpha i_eR_C = -\alpha v_iR_C/(R_E + r_e)\).

\(v_{o1}/v_i = 3.6/3.65 = \mathbf{0.986}\); \(v_{o2}/v_i = -(3.3/3.65)\alpha = \mathbf{-0.904}\) (taking \(\alpha \approx 1\); −0.895 with \(\alpha\) = 0.99). With \(R_E\) bypassed, \(r_e\) alone remains: \(v_{o2}/v_i = -g_mR_C = -(0.5/0.025)\times3.3 = \mathbf{-66}\) V/V. The two outputs are nearly equal and opposite, which is why it is called a phase splitter. The bias details of the textbook figure are not reproduced here; the problem gives \(I_C\).

Practice

Key terms

Quick check

Summary: An unbypassed emitter resistor makes the base see \(R_{ib} = (\beta+1)(r_e+R_e)\) (reflection rule); \(A_{vo} = -\alpha R_C/(r_e+R_e)\), \(R_o = R_C\), \(A_v = -\alpha(R_C\parallel R_L)/(r_e+R_e)\), \(G_v = -\beta(R_C\parallel R_L)/[R_{sig} + (\beta+1)(r_e+R_e)]\), and with \(R_B\) in parallel \(R_{in} = R_B\parallel R_{ib}\). Gain and \(R_{in}\) change by \(1+g_mR_e\): lower gain, higher \(R_{in}\), better linearity, less \(\beta\) dependence. Design: \(R_{ib}\) from the \(R_{in}\) target (undo \(R_B\) first), then \(R_e = R_{ib}/(\beta+1) - r_e\). Use the T model when the emitter is not grounded.
