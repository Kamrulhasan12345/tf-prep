DC Analysis: Active, Saturation, Cutoff

"Find all node voltages and branch currents, and verify the mode" is the most reliable BJT question in recent finals: it was asked in 2021–22, 2023–24 and 2024–25 (15–16 marks each), and every amplifier question starts with the same calculation. The whole method is one idea: assume a mode, solve with that mode's model, then check. This chapter drills single-transistor circuits in every form the papers use: base and emitter resistors, β very high then β finite, saturation, pnp with a measured voltage, collector feedback, and the "find the range" questions Sadat sir likes. It ends with the 2023–24 saturation-parameter question (type B-05).

1. The three DC models

Every DC question replaces the transistor by one of three simple models. Work in mA, kΩ and V (mA × kΩ = V). Conventions used here (Sadat sir's, also Sedra's): \(V_{BE} = 0.7\) V when the emitter junction conducts, the collector junction counts as forward biased only beyond 0.4 V, and \(V_{CE,sat} = 0.2\) V.

ModeModel (npn)Check that proves it
Activebattery \(V_{BE} = 0.7\) V from B to E; current source \(I_C = \beta I_B\) from C to E; \(I_E = (\beta+1)I_B\)\(V_{CE} \ge 0.3\) V (equivalently \(V_{BC} < 0.4\) V, i.e. \(V_{CB} > -0.4\) V) and \(I_B > 0\)
Saturationbattery 0.7 V from B to E; battery \(V_{CE,sat} = 0.2\) V from C to E; \(I_C\) set by the circuit\(I_B > 0\), \(I_C > 0\) and \(\beta_{forced} = I_C/I_B < \beta\)
Cutoffall three terminals open: \(I_B = I_C = I_E = 0\)\(V_{BE} < 0.7\) V with the transistor removed

For a pnp read every subscript backwards: \(V_{EB} = 0.7\) V, active needs \(V_{EC} \ge 0.3\) V, saturation uses \(V_{EC,sat} = 0.2\) V, and the currents flow into the emitter and out of the base and collector. Sedra's own examples use the stricter textbook test \(V_{CB} \ge 0\) (\(V_C \ge V_B\)); a transistor between \(V_{CB} = -0.4\) V and 0 is still active by Sadat sir's test, and both are accepted if you say which you use.

2. Assume and verify

Method · single-BJT DC analysis (types B-01)

  1. Glance: if the base–emitter loop cannot reach 0.7 V (base at or below the emitter supply), the transistor is cut off: all currents 0. Otherwise assume active.
  2. One KVL around the base–emitter loop, with \(I_E = (\beta+1)I_B\). For a base resistor \(R_B\) from \(V_{BB}\) and an emitter resistor \(R_E\) to \(V_{EE}\): \(\;I_B = \dfrac{V_{BB} - 0.7 - V_{EE}}{R_B + (\beta+1)R_E}\).
  3. \(I_C = \beta I_B\), \(I_E = (\beta+1)I_B\); then \(V_E\), \(V_B = V_E + 0.7\), \(V_C = V_{CC} - I_CR_C\).
  4. Write the check in words (Sadat sir: "must write this in the exam"): "\(V_{CE} = \ldots \ge 0.3\) V, so the active assumption was right."
  5. If the check fails, assume saturation: \(V_{BE} = 0.7\), \(V_{CE} = 0.2\). Now \(I_B\) and \(I_C\) are two unknowns: write the base loop and the collector loop (or one node equation at the emitter) and solve.
  6. Check \(\beta_{forced} = I_C/I_B < \beta\). If that also fails, recheck the arithmetic: one of the two assumptions must hold.

Worked example: the first problem of Sadat sir's BJT lectures (L11, notes p.48)

Variants. No \(R_E\): \(I_B = (V_{BB} - 0.7)/R_B\) directly (Sedra Ex 6.9: +5 V, 100 kΩ, 2 kΩ to +10 V gives \(I_C\) = 4.3 mA, \(V_C\) = 1.4 V, active). Base held at a fixed voltage (no \(R_B\)): \(V_E = V_B - 0.7\) at once, \(I_E = V_E/R_E\) (Sedra Ex 6.4: base +4 V, \(R_E\) = 3.3 kΩ, \(R_C\) = 4.7 kΩ to +10 V gives \(I_E\) = 1 mA, \(V_C\) = 5.3 V).

3. β very high first, then finite β

"Assume β very high" means \(I_B \to 0\): the base resistor drops nothing, so the base voltage is whatever the base network gives with no load (ground, or the divider voltage), and \(I_C = I_E\). It is a two-line answer. The follow-up "what happens if β = 100?" is the full KVL of section 2. The difference is the base-resistor drop \(I_BR_B\), which lowers \(V_B\), \(V_E\) and \(I_E\) a little, so \(V_C\) rises.

Method · β = ∞ then β finite

  1. β = ∞: \(V_B\) = open-circuit base voltage; \(V_E = V_B - 0.7\); \(I_E = (V_E - V_{EE})/R_E = I_C\); \(V_C = V_{CC} - I_CR_C\).
  2. β finite: \(I_B = \dfrac{V_{B,oc} - 0.7 - V_{EE}}{R_B + (\beta+1)R_E}\); \(V_B = V_{B,oc} - I_BR_B\); \(I_C = \beta I_B\) (not \(I_E\)) for \(V_C\).
  3. Check the mode in both cases.

Worked example: 2023–24 Sec A Q3(c)

4. Saturation

Saturation happens when the collector cannot drop as much voltage as \(\beta I_B\) would need: a large \(R_C\), a small \(R_B\) (big base current) or a small \(R_E\). Sadat sir's rule of thumb: raising \(R_B\) or \(R_E\), or lowering \(R_C\), makes the transistor "more active". In saturation \(I_C = \beta I_B\) is false; \(I_C\) is whatever the collector circuit lets through, and the ratio \(\beta_{forced} = I_C/I_B\) is smaller than β. Use \(V_{CE,sat} = 0.2\) V unless the question says otherwise (Sadat sir's notes: 0.1 V for "deep" saturation if asked; Sedra and the slides: 0.3 V at the edge, 0.2 V deep).

Method · saturation solution with an emitter resistor

  1. Put the emitter voltage \(V_E\) as the only unknown. Then \(V_B = V_E + 0.7\) and \(V_C = V_E + 0.2\).
  2. \(I_B = (V_{BB} - V_B)/R_B\), \(I_C = (V_{CC} - V_C)/R_C\), \(I_E = V_E/R_E\).
  3. KCL at the transistor: \(I_E = I_B + I_C\) gives one linear equation in \(V_E\).
  4. Report \(V_B, V_E, V_C, I_B, I_C\) and \(\beta_{forced} = I_C/I_B < \beta\).

Worked example: 2021–22 Sec B Q6(c) (also Sedra P6.60, highlighted)

Cutoff needs no work: with the base at 0 V and the emitter returned to ground through \(R_E\) the emitter junction cannot reach 0.7 V, so \(I_B = I_C = I_E = 0\), \(V_E = 0\) and \(V_C = V_{CC}\) (Sedra Ex 6.7 and highlighted Ex 6.20: \(V_{CE}\) = +10 V).

5. pnp transistors and measured voltages

Draw the pnp with the emitter at the top (it sits at the higher potential). Currents enter the emitter and leave by the base and the collector, so for a pnp with \(R_E\) from \(V^+\) and \(R_B\) from the base to ground: \(I_E = (V^+ - V_E)/R_E\), \(V_B = V_E - 0.7\), \(I_B = V_B/R_B\) (flowing out of the base into \(R_B\)), and \(V_C = V^- + I_CR_C\).

Method · α and β from a measured voltage (2024–25, Sedra Ex 6.14)

  1. From the measured \(V_E\): pnp \(V_B = V_E - 0.7\); npn \(V_B = V_E + 0.7\).
  2. \(I_B\) from the base resistor, \(I_E\) from the emitter resistor (Ohm's law across a resistor whose two end voltages you now know).
  3. \(I_C = I_E - I_B\); \(\alpha = I_C/I_E\); \(\beta = I_C/I_B\) (or \(\beta = I_E/I_B - 1\)).
  4. \(V_C\) from the collector resistor; finish with the mode check (\(V_{CB}\) reverse for a pnp means \(V_C < V_B + 0.4\)).

6. Collector-to-base feedback

When \(R_B\) runs from the collector (not from the supply) to the base, the collector resistor carries \(I_C + I_B = I_E\). KVL from \(V_{CC}\) through \(R_C\), \(R_B\), the B–E junction and \(R_E\):

\[ V_{CC} = I_ER_C + I_BR_B + 0.7 + I_ER_E \;\Rightarrow\; I_B = \frac{V_{CC} - 0.7}{R_B + (\beta+1)(R_C + R_E)} \]

This transistor cannot saturate: \(V_{CB} = I_BR_B > 0\) always, so the collector junction is always reverse biased. Still write the check.

7. "Find the range" and "find VBB" questions

Sadat sir's lecture 12 and his last practice class turn the mode test into an inequality: write the active-mode answer as a function of the unknown, then demand \(V_{CE} \ge 0.3\) V (or \(V_{CB} \le 0.4\) V for a pnp, \(V_{BC} \le 0.4\) V for an npn).

Method · range of a component for active mode

  1. Assume active and solve symbolically in the unknown (\(R_E\), \(V_{CC}\), \(R_C\), \(R_B\)…).
  2. Edge of saturation: set \(V_{CE} = 0.3\) V (or \(V_{CB} = 0.4\) V for a pnp); solve for the unknown.
  3. Decide the direction of the inequality from the rule "\(R_B\)↑, \(R_E\)↑, \(R_C\)↓ ⇒ more active".

Examples from the notes, recomputed: (i) 5 V–100 kΩ base, 10 kΩ collector to 10 V, β = 100: \(I_B = 4.3/(100 + 101R_E)\) and \(V_{CE} = 10 - (1000 + 101R_E)I_B \ge 0.3\) give \(R_E \ge 6.106\) kΩ. (ii) pnp, 1 kΩ from +10 V to the emitter, base 100 kΩ to +5 V, 2 kΩ from the collector to an unknown supply \(V_{CC}\): \(I_B = 4.3/201 = 0.02139\) mA, \(V_B = 7.139\) V, \(V_C = V_{CC} + 4.279\) V; active needs \(V_C - V_B \le 0.4\), so \(V_{CC} \le 3.261\) V.

Method · VBB for a given operating point (Sedra Ex 6.3, Sadat notes p.79)

  1. From the collector side: \(I_C = (V_{CC} - V_{CE})/R_C\) with \(V_{CE}\) = target (active), 0.3 V (edge of saturation, active equations still hold) or 0.2 V (saturation).
  2. Base current: \(I_B = I_C/\beta\) in active and at the edge; \(I_B = I_C/\beta_{forced}\) in saturation.
  3. \(V_{BB} = 0.7 + I_BR_B\).

8. Saturation parameters (type B-05)

Inside saturation the \(i_C\)–\(v_{CE}\) curve for fixed \(I_B\) is steep but not vertical. Two descriptions are asked:

Straight-line model
\(V_{CE,sat} = V_{CEoff} + I_CR_{CEsat}\): \(R_{CEsat}\) is the slope \(\Delta V_{CE}/\Delta I_C\) (a few ohms) and \(V_{CEoff}\) the intercept.
Ebers–Moll formula
With \(\beta_{forced} = I_C/I_B\): \(\;V_{CE,sat} = V_T\ln\dfrac{1 + (\beta_{forced}+1)/\beta_R}{1 - \beta_{forced}/\beta_F}\). \(\beta_F\) is the normal forward β, \(\beta_R\) the (small) reverse-active β.

Method · RCEsat, VCEoff, βF, βR from two points

  1. \(R_{CEsat} = \dfrac{V_2 - V_1}{I_{C2} - I_{C1}}\); \(V_{CEoff} = V_1 - I_{C1}R_{CEsat}\).
  2. At each point put \(s = I_C/I_B\), \(E = e^{V_{CE,sat}/V_T}\), \(x = 1/\beta_R\), \(y = 1/\beta_F\). The formula becomes \(E(1 - ys) = 1 + x(s+1)\), i.e. linear: \((s+1)\,x + Es\,y = E - 1\).
  3. Two points give two linear equations; solve (Cramer), then \(\beta_F = 1/y\), \(\beta_R = 1/x\).
  4. State \(V_T\): the answer is very sensitive to it.

Traps (where marks go)

  • Forgetting the \((\beta+1)\) on \(R_E\) in the base loop.
  • Declaring "active" without writing the check, or checking \(V_C > 0\) instead of \(V_{CE} \ge 0.3\) V.
  • Using \(I_E\) instead of \(I_C\) for the collector drop: the 2023–24 senior solution does this and gets \(V_1\) = 2.152 V instead of 2.183 V.
  • In saturation writing \(I_C = \beta I_B\). It is false; \(\beta_{forced}\) comes out of the solution.
  • Assuming saturation and not checking \(I_B > 0\): in Sadat sir's practice #2 (pnp, 5 kΩ from +10 V, base 100 kΩ to ground, 5 kΩ to −10 V) the saturation guess gives \(I_B = -5.9\) µA, so the transistor is actually active: \(I_B\) = 15.37 µA, \(V_C = -2.314\) V.
  • pnp signs: \(I_B\) flows out of the base, so a base resistor to ground gives a positive \(V_B = I_BR_B\).

Exam questions

2024–25 · Sec B · Q6(b) · 15 marks  |  = Sedra Exercise 6.14 (highlighted by the teacher) · Sadat L17, notes p.77 #1

For the circuit, find the labelled node voltages and branch currents given that \(V_E\) is measured to be +1.7 V and \(|V_{BE}|\) = 0.7 V. What are α and β of the pnp transistor?

Show worked answer

pnp, emitter on top: 5 kΩ from +10 V to E, 100 kΩ from B to ground, 5 kΩ from C to −10 V.

Base: the emitter junction conducts, \(V_B = V_E - V_{EB} = 1.7 - 0.7 = 1.0\) V. \(I_B = V_B/100\text{ k} = 0.010\) mA (out of the base, down through 100 kΩ).

Emitter: \(I_E = (10 - 1.7)/5 = 1.66\) mA.

Collector: \(I_C = I_E - I_B = 1.65\) mA; \(V_C = -10 + 5\times1.65 = -1.75\) V.

\(\alpha = I_C/I_E = 1.65/1.66 = 0.994\); \(\beta = I_C/I_B = 1.65/0.01 = 165\).

Mode check: \(V_{EC} = 1.7 - (-1.75) = 3.45\) V \(\ge 0.3\) V (\(V_{CB} = -2.75\) V, collector junction reverse biased), so the transistor is active and using \(V_{EB}\) = 0.7 V with \(\beta = I_C/I_B\) is valid.

2023–24 · Sec A · Q4(b) · 10 marks

A BJT for which \(I_B\) = 0.5 mA has \(v_{CEsat}\) = 140 mV at \(I_C\) = 10 mA and \(v_{CEsat}\) = 170 mV at \(I_C\) = 20 mA. Estimate (i) the saturation resistance \(R_{CEsat}\), (ii) the offset voltage \(V_{CEoff}\), (iii) \(\beta_F\), (iv) \(\beta_R\).

Show worked answer

(i) \(R_{CEsat} = \dfrac{170 - 140\text{ mV}}{20 - 10\text{ mA}} = 3\) Ω.

(ii) \(V_{CEoff} = 140\text{ mV} - 10\text{ mA}\times3\text{ Ω} = 110\) mV.

(iii), (iv) Forced betas: \(s_1 = 10/0.5 = 20\), \(s_2 = 20/0.5 = 40\). Ebers–Moll: \(V_{CEsat} = V_T\ln\dfrac{1 + (s+1)/\beta_R}{1 - s/\beta_F}\). With \(x = 1/\beta_R\), \(y = 1/\beta_F\), \(E = e^{V_{CEsat}/V_T}\): \((s+1)x + Es\,y = E - 1\). Take \(V_T\) = 25 mV:

Point 1: \(E_1 = e^{5.6} = 270.43\): \(21x + 5408.5y = 269.43\).
Point 2: \(E_2 = e^{6.8} = 897.85\): \(41x + 35914y = 896.85\).

Cramer: \(D = 21\times35914 - 5408.5\times41 = 532\,437\); \(x = (269.43\times35914 - 5408.5\times896.85)/D = 9.063\) → \(\beta_R = 0.110\); \(y = (21\times896.85 - 41\times269.43)/D = 0.014626\) → \(\beta_F = 68.4\).

Answers: \(R_{CEsat}\) = 3 Ω, \(V_{CEoff}\) = 110 mV, \(\beta_F \approx 68\), \(\beta_R \approx 0.11\). (With \(V_T\) = 26 mV: \(\beta_F\) = 71.8, \(\beta_R\) = 0.134; state your \(V_T\).) Neither senior solution finishes (iii) and (iv); one of them wrongly reports the forced betas 20 and 40 as "\(\beta_F\)".

2023–24 · Sec A · Q3(c) · 15 marks

For the circuit, find the labelled node voltages and branch currents. Assume β very high and \(|V_{BE}|\) = 0.7 V. What will happen if β is reduced to 100?

Show worked answer

npn: collector \(V_1\) through 1.6 kΩ to +5 V, emitter \(V_2\) through 2.2 kΩ to −5 V, base \(V_3\) through 22 kΩ to ground.

β very high: \(I_B = 0\), so no drop in 22 kΩ: \(V_3 = 0\). \(V_2 = -0.7\) V. \(I_E = (-0.7 + 5)/2.2 = 1.955\) mA \(= I_C\). \(V_1 = 5 - 1.6\times1.955 = 1.873\) V. Check: \(V_{CE} = 1.873 + 0.7 = 2.573\) V \(\ge 0.3\): active.

β = 100: KVL ground → 22 kΩ → B–E → 2.2 kΩ → −5 V: \(0 - 22I_B - 0.7 - 2.2\times101I_B = -5\), so \(I_B = \dfrac{4.3}{22 + 222.2} = 0.01761\) mA.

\(I_C = 100I_B = 1.761\) mA; \(I_E = 101I_B = 1.778\) mA. \(V_3 = -22\times0.01761 = -0.387\) V; \(V_2 = -1.087\) V; \(V_1 = 5 - 1.6\times1.761 = 2.183\) V.

Check: \(V_{CE} = 2.183 + 1.087 = 3.27\) V \(\ge 0.3\) V (\(V_{CB}\) = 2.57 V): still active. What happened: the base current now drops 0.39 V across 22 kΩ, lowering the emitter and reducing \(I_E\) by 9 %, so the collector rises by 0.31 V. (One senior solution writes \(V_1\) = 2.152 V: it used \(I_E\) instead of \(I_C\) for the collector drop.)

2021–22 · Sec B · Q6(c) · 16 marks  |  = Sedra P6.60 (highlighted, also asks RB = 100 kΩ and 1 kΩ)

For the circuit, find \(V_B\), \(V_E\) and \(V_C\) for \(R_B\) = 10 kΩ. Let β = 100.

Show worked answer

npn: \(R_B\) from +5 V to the base, 1 kΩ from +5 V to the collector, 1 kΩ from the emitter to ground.

Assume active: \(I_B = \dfrac{5 - 0.7}{10 + 101\times1} = 0.03874\) mA, \(I_C = 3.874\) mA, \(V_E = 101\times0.03874 = 3.913\) V, \(V_C = 5 - 3.874 = 1.126\) V. Then \(V_{CE} = -2.79\) V < 0.3 V: impossible, so not active.

Assume saturation (\(V_{BE}\) = 0.7, \(V_{CE}\) = 0.2): \(V_B = V_E + 0.7\), \(V_C = V_E + 0.2\). KCL \(I_E = I_B + I_C\):

\(\dfrac{V_E}{1} = \dfrac{5 - 0.7 - V_E}{10} + \dfrac{5 - 0.2 - V_E}{1} \;\Rightarrow\; 2.1V_E = 0.43 + 4.8 \;\Rightarrow\; V_E = 2.490\) V.

\(V_B = 3.190\) V, \(V_C = 2.690\) V; \(I_B = (5 - 3.190)/10 = 0.181\) mA, \(I_C = (5 - 2.690)/1 = 2.310\) mA, \(I_E = 2.490\) mA.

Check: \(\beta_{forced} = 2.310/0.181 = 12.8 < 100\) ✓ and both currents positive: saturated.

Highlighted extension (P6.60): \(R_B\) = 100 kΩ: \(I_B = 4.3/201 = 0.02139\) mA, \(V_E\) = 2.161 V, \(V_B\) = 2.861 V, \(V_C = 5 - 2.139 = 2.861\) V: \(V_{CB}\) = 0, so active (just at Sedra's boundary; \(V_{CE}\) = 0.70 V passes Sadat sir's test). \(R_B\) = 1 kΩ: saturated, \(3V_E = 4.3 + 4.8\), \(V_E\) = 3.033 V, \(V_B\) = 3.733 V, \(V_C\) = 3.233 V, \(\beta_{forced}\) = 1.77/1.27 = 1.39.

Highlighted textbook problems

Sedra 7e D6.22, D6.24 · highlighted by the teacher

Circuit of Sedra Example 6.4: base driven by a voltage source \(V_B\), \(R_E\) = 3.3 kΩ to ground, \(R_C\) = 4.7 kΩ to +10 V. (D6.22) What is the highest base voltage for which the transistor stays active (take α ≈ 1)? (D6.24) What base voltage gives saturation with \(\beta_{forced}\) = 5?

Show worked answer

D6.22: \(I_E = (V_B - 0.7)/3.3\), \(V_C = 10 - 4.7I_E\). Edge of active (collector junction forward by 0.4 V): \(V_C = V_B - 0.4\). So \(V_B - 0.4 = 10 - \frac{4.7}{3.3}(V_B - 0.7)\) → \(2.424V_B = 11.397\) → \(V_B\) = 4.70 V.

D6.24: saturation, \(V_E = V_B - 0.7\), \(V_C = V_E + 0.2\), \(I_C = (10 - V_C)/4.7\), \(I_E = (1 + 1/5)I_C = 1.2I_C\): \(\frac{V_B - 0.7}{3.3} = 1.2\,\frac{10.5 - V_B}{4.7}\) → \(8.66V_B = 44.87\) → \(V_B\) = 5.18 V.

Key terms

Quick check

Summary: assume active, write one base-loop KVL with \(I_E = (\beta+1)I_B\), get \(I_C = \beta I_B\) and the node voltages, then write the check \(V_{CE} \ge 0.3\) V. If it fails, use \(V_{BE}\) = 0.7 and \(V_{CE}\) = 0.2, solve one node equation and show \(\beta_{forced} < \beta\). β very high means no base-resistor drop and \(I_C = I_E\). pnp: emitter on top, currents out of base and collector. Measured voltages give α and β by Ohm's law on each resistor. Ranges come from setting \(V_{CE}\) = 0.3 V. Saturation parameters: slope and intercept of \(V_{CE,sat}\) vs \(I_C\), and the Ebers–Moll formula is linear in \(1/\beta_R\) and \(1/\beta_F\).
