Small-Signal Models: Hybrid-π and T

Since 2018–19 every term final has had one BJT amplifier derivation (CC, CE with Re, CB, CE with ro, CE with the Early effect), usually 14 to 30 marks, and the numerical amplifier questions (2024–25 Q7(a), 2017–18 Q1(b)) start with "find gm, rπ, ro and draw the hybrid-π model". Everything in the next four chapters is built from the four parameters on this page and one procedure. Learn the derivations here: they are asked as exam parts on their own ("why is it called a small-signal circuit?", 2013–14).

1. DC and AC are solved separately

In an amplifier every voltage and current is a DC bias value plus a small signal riding on it. Sedra's notation (Khairul s.31): \(i_C\) total, \(I_C\) DC, \(i_c\) signal, so \(i_C = I_C + i_c\) and \(v_{BE} = V_{BE} + v_{be}\). If the signal is small enough that the transistor behaves linearly around the bias point, superposition holds: find the DC operating point with the signal off, then find the signal with the DC sources off.

Coupling capacitor
Open at DC (it blocks the source's and load's DC from shifting the bias), short for the signal ("C = ∞"). Sadat calls the output one the "DC reject capacitor".
Bypass capacitor
A capacitor across \(R_E\) (or below part of it) shorts that resistance for the signal, so the emitter is at AC ground.
DC sources at AC
A DC voltage source becomes a short (every rail is AC ground); a DC current source becomes an open.

Method · the five-step amplifier procedure (Sadat notes p.62, Sedra)

  1. DC analysis with the signal off and capacitors open: find \(I_C\) (and check active mode). Skip it if \(I_C\) is given or the question is symbolic.
  2. Parameters: \(g_m = I_C/V_T\), \(r_\pi = \beta/g_m\), \(r_e = \alpha/g_m = V_T/I_E\), \(r_o = V_A/I_C\).
  3. DC off: short DC voltage sources (rails to ground), open DC current sources.
  4. Capacitors short; replace the BJT by its small-signal model (hybrid-π or T).
  5. Analyse the linear circuit for what is asked (\(R_{in}, R_o, A_{vo}, A_v, G_v\)). For \(R_{in}\) or \(R_o\) use a Thevenin test source \(v_x\) with all independent sources off: \(R = v_x/i_x\).

2. Deriving gm, rπ, re, ro

These derivations are short exam answers in their own right. Write them in this order.

Transconductance and the small-signal condition

In active mode \(i_C = I_S e^{v_{BE}/V_T}\). With \(v_{BE} = V_{BE} + v_{be}\):

\[ i_C = I_S e^{V_{BE}/V_T}\,e^{v_{be}/V_T} = I_C\,e^{v_{be}/V_T} = I_C\left(1 + \frac{v_{be}}{V_T} + \frac12\Big(\frac{v_{be}}{V_T}\Big)^2 + \cdots\right) \]

If \(v_{be} \ll V_T\) the square and higher terms are negligible (the second-order term is \(v_{be}/2V_T\) of the linear one), so

\[ i_C \approx I_C + \frac{I_C}{V_T}v_{be} \;\Rightarrow\; i_c = g_m v_{be},\qquad g_m = \frac{I_C}{V_T} = \left.\frac{\partial i_C}{\partial v_{BE}}\right|_{i_C = I_C} \]

Why "small signal": the circuit is called a small-signal circuit because it is valid only when \(v_{be} \ll V_T\) (in practice \(|v_{be}| \lesssim\) 5–10 mV), where the exponential can be replaced by its tangent at the bias point Q. Then the transistor is a linear element, superposition separates DC from AC, and the model parameters are fixed numbers set by the bias current. Geometrically, \(g_m\) is the slope of the \(i_C\)–\(v_{BE}\) curve at Q (Sadat slide B-s29).

Input resistance at the base, rπ

\[ i_B = \frac{i_C}{\beta} = I_B + \frac{g_m}{\beta}v_{be} \;\Rightarrow\; r_\pi \equiv \frac{v_{be}}{i_b} = \frac{\beta}{g_m} = \frac{V_T}{I_B} \]

Resistance looking into the emitter, re

\[ i_E = \frac{i_C}{\alpha} = I_E + \frac{g_m}{\alpha}v_{be} \;\Rightarrow\; r_e \equiv \frac{v_{be}}{i_e} = \frac{\alpha}{g_m} = \frac{V_T}{I_E} \approx \frac{1}{g_m} \]

Link: \(v_{be} = i_b r_\pi = i_e r_e\), and \(i_e = (\beta+1)i_b\), so \(r_\pi = (\beta + 1)\,r_e\). Also \(g_m v_{be} = \beta i_b = \alpha i_e\): the controlled source can be written any of three ways.

Output resistance from the Early effect, ro

Base-width modulation makes \(i_C = I_S e^{v_{BE}/V_T}(1 + v_{CE}/V_A)\), so \(i_C\) rises slowly with \(v_{CE}\). The slope is \(1/r_o\):

\[ r_o = \left[\frac{\partial i_C}{\partial v_{CE}}\right]^{-1} = \frac{V_A + V_{CE}}{I_C} \approx \frac{V_A}{I_C} \]

Put \(r_o\) between collector and emitter. If no \(V_A\) is given, \(r_o = \infty\) (Sadat: "ideally we assume \(r_o = \infty\)").

\[ g_m = \frac{I_C}{V_T},\quad r_\pi = \frac{\beta}{g_m},\quad r_e = \frac{\alpha}{g_m} = \frac{V_T}{I_E},\quad r_\pi = (\beta+1)r_e,\quad r_o = \frac{V_A}{I_C} \]

Units: mA, kΩ, V. With \(I_C\) in mA and \(V_T\) = 0.025 V, \(g_m\) comes out in mA/V and \(r_\pi = \beta/g_m\) in kΩ. This book uses \(V_T\) = 25 mV (Sedra, the slides); Sadat sir's notes use 25.9 mV. Either is accepted in the exam if you state it.

Method · parameters from the bias (4 steps)

  1. Get \(I_C\). If an emitter current source \(I\) sets the bias, \(I_E = I\) and \(I_C = \alpha I\) (not \(I\)).
  2. \(g_m = I_C/V_T\) (mA/V).
  3. \(r_\pi = \beta/g_m\) (kΩ) and \(r_e = V_T/I_E\) (Ω); check \(r_\pi = (\beta+1)r_e\).
  4. \(r_o = V_A/I_C\) if \(V_A\) is given, else \(\infty\).

3. The two models

The two are the same two-port: in the T model \(i_e = v_\pi/r_e\), so the base current is \(i_e/(\beta+1) = v_\pi/[(\beta+1)r_e] = v_\pi/r_\pi\), and the collector current is \(\alpha i_e = g_m v_\pi\). Either gives the same answer; one is just less algebra.

Sadat sir's rule (notes p.63): "When emitter grounded, π-model is advantageous. When emitter has resistance, T-model is advantageous."

4. Characterising any amplifier: Rin, Ro, Avo, Av, Gv

Every amplifier question asks for the same five numbers. They come from replacing the whole amplifier by a Thevenin-type two-port: an input resistance \(R_{in}\), and at the output a controlled source \(A_{vo}v_i\) in series with \(R_o\).

\(R_{in}\)
Resistance seen looking into the input (right of \(R_{sig}\)), with the load connected. Find it with a test source \(v_x\): \(R_{in} = v_x/i_x\). Turn off independent sources only; keep controlled ones.
\(A_{vo}\)
Open-circuit voltage gain \(v_o/v_i\) with \(R_L\) removed.
\(R_o\)
Resistance seen looking back into the output with \(v_{sig}\) = 0 and \(R_L\) removed.
\(A_v\)
\(v_o/v_i\) with the load: \(A_v = A_{vo}\dfrac{R_L}{R_L + R_o}\).
\(G_v\)
Overall gain \(v_o/v_{sig}\): \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\).
\(A_i\), \(G_m\)
Current gain \(i_o/i_i\); transconductance \(i_o/v_i\) with the output shorted. Asked less often.

What "good" means: a voltage amplifier wants \(R_{in} \gg R_{sig}\) (no loss at the input) and \(R_o \ll R_L\) (no loss at the output). A transconductance amplifier (voltage in, current out) wants \(R_{in}\) large and \(R_o\) large. A current amplifier wants \(R_{in}\) small and \(R_o\) large. Sadat's two common mistakes (notes p.70): forgetting to remove \(R_L\) when finding \(A_{vo}\), and forgetting to turn off independent sources when finding \(R_{in}\) or \(R_o\).

Method · gains from the amplifier model

  1. Input divider: \(v_i/v_{sig} = R_{in}/(R_{in}+R_{sig})\).
  2. Output divider: \(A_v = A_{vo}R_L/(R_L+R_o)\).
  3. \(G_v\) = (input divider) × \(A_v\). Keep the sign of \(A_{vo}\).

Traps (where marks go)

  • \(I_C = \alpha I\) when a current source \(I\) biases the emitter: 0.990 mA, not 1 mA (2024–25 Q7(a)). The difference is 1%, but write it.
  • \(r_e\) uses \(I_E\); \(g_m\) and \(r_\pi\) use \(I_C\).
  • Writing \(r_\pi = \beta r_e\): it is \((\beta+1)r_e\).
  • Leaving out \(r_o\) when \(V_A\) is given, or inventing an \(r_o\) when it is not.
  • Drawing the controlled source pointing up in an npn model: the signal current \(g_mv_\pi\) flows from C to E.
  • Sadat sir's two "common mistakes" (Raiyan p.70, Ikra p.56): not removing \(R_L\) when finding the open-circuit \(v_o\) (for \(A_{vo}\) and \(R_o\)); not turning off the independent sources when finding \(R_{in}\) or \(R_o\) with a Thevenin test source.
  • "Small signal" answered as "a small input": say \(v_{be} \ll V_T\), linearisation of the exponential, superposition.

Exam questions

2013–14 · Sec A · Q4(a) · 16 marks  |  part (b) of the same question (Rin, Rout, Av) is in the CE chapter

Draw the small-signal circuit diagram of the CE circuit of the figure. Why is the circuit called a "small-signal" circuit? (Figure: \(v_{sig}\) coupled by \(C_1\) to the base; \(R_B\) = 100 kΩ base to ground; \(R_C\) = 8 kΩ in the collector; a 10 V DC source at the emitter; the collector coupled by \(C_2\) to \(R_L\) = 10 kΩ.)

The printed figure draws the 10 V source with + at the emitter and the top of \(R_C\) at ground, which would cut the transistor off; the intended bias is presumably −10 V at the emitter end through a bias element. The small-signal circuit does not depend on this, because every DC source becomes AC ground.

Show worked answer

Small-signal circuit. Set DC sources to zero (the 10 V source and the rail become AC ground), short \(C_1\) and \(C_2\), and replace the BJT by the hybrid-π model (emitter at AC ground, so π is the natural choice):

\(v_{sig}\) drives the base directly; \(R_B\) = 100 kΩ and \(r_\pi\) are in parallel from base to ground, \(v_\pi = v_{sig}\); \(g_mv_\pi\) flows from C to ground through \(r_o \parallel R_C \parallel R_L\) = \(r_o \parallel 8\text{ k} \parallel 10\text{ k}\). So \(v_{out} = -g_m v_\pi (r_o\parallel 4.44\text{ kΩ})\).

Why "small signal". In active mode \(i_C = I_Ce^{v_{be}/V_T} = I_C(1 + v_{be}/V_T + \tfrac12(v_{be}/V_T)^2 + \dots)\). Only when \(v_{be} \ll V_T\) (about 5–10 mV at room temperature) can the higher terms be dropped, giving the linear relation \(i_c = g_mv_{be}\) with \(g_m = I_C/V_T\). The transistor is then replaced by linear elements (\(r_\pi\), \(g_mv_\pi\), \(r_o\)) whose values depend on the DC bias, and superposition lets the DC bias and the signal be analysed separately. The circuit is valid only for such small signals, hence the name.

2012–13 · Sec A · Q2(a) · 20 marks

The figure shows the basic structure of a transconductance amplifier (input resistance \(R_{in}\); output a controlled current source \(A\cdot v_{in}\) in parallel with \(R_{out}\); load \(R_L\)), to be implemented by a BJT. Given that \(R_{sig} \to 0\) and the load \(R_L\) can be much greater than \(R_{out}\), which of the three configurations (CE, CB, CC) will you choose for best performance? Explain why, and comment on its gain and loading.

Show worked answer

Ideal transconductance amplifier: voltage in, current out. It needs \(R_{in} \to \infty\) (so the whole \(v_{sig}\) appears at the input) and \(R_{out} \to \infty\) (so all of \(A v_{in}\) goes into the load): \(i_L = A v_{in}\dfrac{R_{out}}{R_{out}+R_L}\).

Choice: common emitter. The BJT itself is a transconductance device: \(i_c = g_m v_{be}\), input at the base, output current at the collector. In CE: \(R_{in} = r_\pi\) (moderate), \(G_m = g_m\), \(R_{out} = r_o\) (high, looking into the collector).

  • Because \(R_{sig} \to 0\), the modest \(R_{in} = r_\pi\) costs nothing: \(v_{in} = v_{sig}\).
  • CC is a voltage buffer: its output resistance is low (\(\approx r_e\)), the opposite of what a current output needs.
  • CB has \(R_{in} \approx r_e\) (tens of ohms) and is driven by a current; its current gain is only \(\alpha \approx 1\). It is a current buffer, not a transconductor.

Gain and loading. The short-circuit transconductance is \(g_m = I_C/V_T\). Since \(R_L\) can be much larger than \(R_{out} = r_o\), most of \(g_mv_{in}\) flows into \(r_o\) rather than the load: \(i_L = g_mv_{in}\,r_o/(r_o + R_L)\), and the delivered current falls. Adding emitter degeneration \(R_e\) raises the output resistance to about \(r_o(1 + g_mR_e)\) and makes \(G_m \approx 1/R_e\) (smaller, but set by a resistor and insensitive to \(\beta\) and temperature), which reduces this loading.

Quick check

Summary: solve DC first (capacitors open), then AC (DC sources off, capacitors shorted). From \(I_C\): \(g_m = I_C/V_T\), \(r_\pi = \beta/g_m\), \(r_e = \alpha/g_m = V_T/I_E\), \(r_\pi = (\beta+1)r_e\), \(r_o = V_A/I_C\). The model is linear only for \(v_{be} \ll V_T\). Hybrid-π when the emitter is grounded, T when the emitter has a resistance or receives the signal. Every amplifier is described by \(R_{in}\), \(A_{vo}\) (load removed), \(R_o\) (source off, load removed), then \(A_v = A_{vo}R_L/(R_L+R_o)\) and \(G_v = A_vR_{in}/(R_{in}+R_{sig})\).
