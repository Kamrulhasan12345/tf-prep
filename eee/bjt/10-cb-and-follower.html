Common Base and Emitter Follower

The CB amplifier was a compulsory derivation in 2022–23 (Q1(b), 14 marks) and a numerical in 2017–18 (26⅔). The common collector (emitter follower) was set in 2014–15, 2018–19, 2020–21 and, as the bootstrapped follower, in 2024–25 (Q5(a), 15 marks, compulsory). Both are derivations asked "using the T model", with the same five-step procedure as the CE stage: bias, parameters, small-signal circuit, \(R_{in}\)/\(R_o\)/\(A_{vo}\), \(A_v\)/\(G_v\). The T model is used because the emitter is not grounded in either stage.

1. Which terminal is common

CE: input at the base, output at the collector. CB: input at the emitter, output at the collector, base at AC ground. CC: input at the base, output at the emitter, collector at AC ground (it is tied to \(V_{CC}\)). Units: mA, kΩ, V.

2. Common base (type B-10)

Derivation (2022–23 Q1(b)). The source \(v_{sig}\) with \(R_{sig}\) feeds the emitter (through a coupling capacitor); the base is grounded; \(R_C\) goes to \(V_{CC}\) (AC ground) and \(R_L\) is at the collector. A bias resistor \(R_E\) from the emitter to the supply, if present, is in parallel with \(r_e\) at AC.

  1. \(R_{in}\). Test voltage \(v_i\) at the emitter, base at ground: \(r_e\) is all that lies between emitter and ground, so \(i_e = -v_i/r_e\) flows into the emitter terminal (with the usual \(i_e\) leaving the emitter) and \(R_{in} = v_i/(-i_e) = r_e\). With \(R_E\): \(R_{in} = r_e\parallel R_E \approx r_e\) (tens of ohms).
  2. \(A_{vo}\). \(i_c = \alpha i_e = -\alpha v_i/r_e\) flows through \(R_C\) in the sense that raises the collector for a rising \(v_i\): \(v_o = -i_cR_C = \alpha v_iR_C/r_e\). So \[ A_{vo} = \frac{\alpha R_C}{r_e} = g_mR_C \qquad(\text{positive: CB does not invert}) \]
  3. \(R_o\). Set \(v_{sig} = 0\): the emitter is driven by nothing, \(i_e = 0\), the source \(\alpha i_e\) is open, so \(R_o = R_C\) (with \(r_o\): \(R_C\parallel[r_o(1 + g_m(R_E\parallel R_{sig}))]\), only if \(V_A\) is given).
  4. \(A_v\) with the load. \(A_v = g_m(R_C\parallel R_L) = A_{vo}R_L/(R_L + R_o)\).
  5. \(G_v\). \(v_i/v_{sig} = R_{in}/(R_{in} + R_{sig})\), so \[ G_v = \frac{R_{in}}{R_{in}+R_{sig}}\,g_m(R_C\parallel R_L) = \frac{\alpha(R_C\parallel R_L)}{R_{sig} + r_e}\quad(R_{in} = r_e) \] "total resistance in the collector over the total resistance in the emitter circuit".
  6. Current gain \(i_c/i_e = \alpha \approx 1\): a current buffer.
\[ R_{in} = r_e,\quad A_{vo} = g_mR_C,\quad R_o = R_C,\quad G_v = \frac{\alpha(R_C\parallel R_L)}{R_{sig}+r_e} \;(>0) \]

Because \(R_{in}\) is so small, CB needs a low-resistance source: with \(R_{sig} = 1\) kΩ and \(r_e = 25\) Ω, 97.6% of \(v_{sig}\) is lost. It is used as a current buffer, at high frequencies (no Miller effect) and as the upper transistor of a cascode.

Method · CB numerical (5 steps)

  1. DC: base grounded, so \(V_E = -0.7\) V (npn) or \(+0.7\) V (pnp); \(I_E = |V_{supply} - V_E|/R_E\); \(I_C = \alpha I_E\); \(V_C = V_{CC} - I_CR_C\) (npn). Mode check: \(V_{CB}\) reverse-biased (\(V_{CB} \ge -0.4\) V in Sadat's convention).
  2. \(r_e = V_T/I_E\) (VT = 25 mV), \(g_m = I_C/V_T = \alpha/r_e\).
  3. AC: base to ground, \(V_{CC}\) to ground, current source open, capacitors short. Emitter node: \(R_E\parallel r_e\).
  4. \(R_{in} = r_e\parallel R_E\); \(A_{vo} = g_mR_C\); \(R_o = R_C\).
  5. \(A_v = g_m(R_C\parallel R_L)\); \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\). Positive.

Worked example: 2017–18 Sec A Q1(a) (pnp CB)

3. Common collector: the emitter follower (type B-09)

Define \(R_E' = R_E\parallel R_L\parallel r_o\) (the total AC resistance from the emitter to ground; a current-source bias means \(R_E = \infty\)).

Derivation (2020–21 Q2(a) with \(r_o\); 2018–19 Q2(b) is the same with \(r_o = \infty\) and no \(R_E\)).

  1. \(R_i\). The base voltage \(v_b\) appears across \(r_e\) in series with \(R_E'\): \(i_e = v_b/(r_e + R_E')\), \(i_b = i_e/(\beta+1)\), so \[ R_{ib} = \frac{v_b}{i_b} = (\beta+1)(r_e + R_E') \] The load is reflected up by \(\beta+1\). With a bias network, \(R_{in} = R_B\parallel R_{ib}\).
  2. \(A_v\). \(v_o = i_eR_E'\) and \(v_b = i_e(r_e + R_E')\): \[ A_v = \frac{v_o}{v_b} = \frac{R_E'}{r_e + R_E'} \;<1,\;\approx 1 \] Overall: \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\).
  3. \(R_o\). \(v_{sig} = 0\), load removed; apply \(v_x\) at the emitter, current \(i_x\) entering. The same current flows up through \(r_e\) to the base node, so the base current is \(i_x/(\beta+1)\) out of the base through \(R_{sig}\) (and \(R_B\) in parallel): \(v_x = i_x r_e + [i_x/(\beta+1)](R_{sig}\parallel R_B)\). The test source also feeds \(r_o\) and \(R_E\) in parallel: \[ R_o = r_o\parallel R_E\parallel\Big[r_e + \frac{R_{sig}\parallel R_B}{\beta+1}\Big] \] A circulating senior solution drops the \(R_{sig}/(\beta+1)\) term: that is only correct for \(R_{sig}\) = 0. The source resistance divided by \(\beta+1\) usually dominates \(r_e\).
  4. Current gain. \(i_b = i_e/(\beta+1)\) and the load current is the fraction of \(i_e\) that does not go into \(r_o\) (and \(R_E\)): \(A_i = i_o/i_b = (\beta+1)\dfrac{r_o\parallel R_E}{R_L + r_o\parallel R_E}\). With only \(R_L\): \(A_i = \beta+1\); with \(r_o\) and \(R_L\) only: \((\beta+1)r_o/(r_o + R_L)\).
\[ R_{ib} = (\beta+1)(r_e + R_E'),\quad A_v = \frac{R_E'}{r_e+R_E'},\quad R_o = r_o\parallel R_E\parallel\Big[r_e + \frac{R_{sig}\parallel R_B}{\beta+1}\Big] \]

A follower is a buffer: high \(R_{in}\) so little of \(v_{sig}\) is lost, low \(R_o\) so the load does not pull the output down (\(A_v = A_{vo}R_L/(R_L + R_o)\)), gain ≈ 1 (and a DC level shift of one \(V_{BE}\)). It is the output stage of multistage amplifiers.

Method · emitter follower (5 steps)

  1. DC: Thevenin of the base network (\(V_{BB}\), \(R_{BB}\)); \(I_E = (V_{BB} - 0.7 + V_{EE})/(R_E + R_{BB}/(\beta+1))\) (current source: \(I_E = I\)). Mode check \(V_{CE}\ge 0.3\) V.
  2. \(r_e = V_T/I_E\), \(r_\pi = (\beta+1)r_e\), \(r_o = V_A/I_C\) if \(V_A\) is given.
  3. AC: collector to ground, so \(r_o\) goes from the emitter to ground; \(R_E'= R_E\parallel R_L\parallel r_o\).
  4. \(R_{ib} = (\beta+1)(r_e + R_E')\); \(R_{in} = R_B\parallel R_{ib}\) (test source at the base). \(A_v = R_E'/(r_e + R_E')\).
  5. \(G_v = \dfrac{R_{in}}{R_{in}+R_{sig}}A_v\); \(R_o\) as above (remove \(R_L\), \(v_{sig}\) off, \(R_{sig}\parallel R_B\) in the base); \(A_i = (\beta+1)(r_o\parallel R_E)/(R_L + r_o\parallel R_E)\).

Worked example: 2014–15 Sec A Q3(c)

4. The bootstrapped follower (2024–25 Q5(a))

Without \(C_B\) the whole bias network (\(R_B + R_1\parallel R_2\)) sits from base to ground and limits \(R_{in}\) to \(\le\) 20 kΩ however large \((\beta+1)(r_e+R_E)\) is. With \(C_B\) shorting A to the emitter at AC: \(R_1\parallel R_2\) now hangs from the emitter to ground (in parallel with \(R_E\), so \(R_E' = R_E\parallel R_1\parallel R_2\)) and \(R_B\) connects the base to the emitter. Since the emitter follows the base (\(A_v \approx 1\)), the two ends of \(R_B\) move together and very little signal current flows through it: it looks like \(R_B/(1 - A_v)\), much larger than \(R_B\) (Miller-type effect). Exact: with \(v_\pi = v_b - v_e\), at the emitter \(v_\pi(1/r_e + 1/R_B) = v_e/R_E'\), so

\[ R_{in} = \frac{1 + R_E'(1/r_e + 1/R_B)}{1/r_\pi + 1/R_B}\;\approx\; R_{ib}\parallel\frac{R_B}{1 - A_v},\qquad A_v = \frac{R_E'(1/r_e + 1/R_B)}{1 + R_E'(1/r_e + 1/R_B)} \]

The ideal voltage amplifier has \(R_{in}\to\infty\), \(R_o\to 0\), large \(|A_v|\); the ideal current amplifier has \(R_{in}\to 0\), \(R_o\to\infty\). CE is the all-rounder, CC is the best voltage buffer, CB the best current buffer. Two errors in a circulating senior table: it gives CB a negative \(G_v\) (CB is non-inverting: \(G_v\) is positive), and its CC \(R_{out}\) leaves out the \(R_{sig}/(\beta+1)\) term (this chapter's \(R_o\) formula keeps it).

Traps (where marks go)

  • CB sign: \(A_{vo} = +g_mR_C\). The minus sign belongs to CE. Also the CB \(R_{in}\) is \(r_e\), not \(r_\pi\).
  • \(R_E'\) in the follower must contain \(R_L\) (and \(r_o\), \(R_E\) if present); \(R_o\) must contain \(R_{sig}/(\beta+1)\) and \(R_{sig}\parallel R_B\) when a bias network is drawn.
  • \(R_{in}\) of the follower includes \(R_B\) in parallel: that is the point of bootstrapping. Do not put \(R_1\parallel R_2\) at the base after \(C_B\) shorts it to the emitter.
  • Defining \(R_o\) or \(A_{vo}\) with \(R_L\) connected; not turning off independent sources when finding \(R_o\) and \(R_{in}\) (Sadat's two "common mistakes").
  • pnp CB (2017–18): \(I_E\) flows from the \(+10\) V rail through \(R_E\) into the emitter; \(V_E = +0.7\) V because the base is grounded. \(V_C\) is negative and the collector junction is still reverse-biased.
  • The follower gain is below 1: write \(0.976\), not 1, when asked for numbers.

Exam questions

2024–25 · Sec B · Q5(a) · 15 marks · compulsory

For the bootstrapped follower of the figure (supply +9 V, \(R_1 = R_2\) = 20 kΩ, \(R_B\) = 10 kΩ, \(R_E\) = 2 kΩ, \(R_{sig}\) = 10 kΩ, \(C_B\) from the divider midpoint to the emitter, β = 100): (i) find the DC emitter current and \(g_m\), \(r_e\), \(r_\pi\). (ii) Replace the BJT by its T model (neglect \(r_o\)) and find \(R_{in}\) and the voltage gain \(v_o/v_{sig}\). (iii) Repeat (ii) with \(C_B\) open-circuited. Compare and comment on the advantage of bootstrapping.

Show worked answer

(i) DC (capacitors open): Thevenin at A: \(V_{TH} = 9\times20/40 = 4.5\) V, \(R_1\parallel R_2 = 10\) kΩ, so the base resistance is \(R_{BB} = 10 + 10 = 20\) kΩ. \(I_E = \dfrac{4.5 - 0.7}{2 + 20/101} = \dfrac{3.8}{2.198} = \mathbf{1.729}\) mA; \(I_C = 1.712\) mA, \(V_E = 3.46\) V, \(V_{CE} = 5.54\) V ≥ 0.3: active ✓. \(g_m = 1.712/0.025 = 68.5\) mA/V, \(r_e = 25/1.729 = 14.46\) Ω, \(r_\pi = 100/68.5 = 1.46\) kΩ.

(ii) \(C_B\) shorted. AC: node A is joined to the emitter; \(R_1\parallel R_2\) = 10 kΩ goes from emitter to ground, so \(R_E' = 2\parallel10 = 1.667\) kΩ; \(R_B\) = 10 kΩ connects base and emitter. T model: \(i_e = (v_b - v_e)/r_e\), \(i_b = i_e/(\beta+1)\), current in \(R_B\): \((v_b - v_e)/R_B\). KCL at the emitter node: \((v_b - v_e)(1/r_e + 1/R_B) = v_e/R_E'\), giving \(v_e = x\,v_\pi\) with \(x = R_E'(1/r_e + 1/R_B) = 1.667\times(69.15 + 0.1) = 115.4\), \(v_b = (1+x)v_\pi\). Hence \(v_o/v_b = x/(1+x) = \mathbf{0.9914}\). The input current is \(i = v_\pi(1/r_\pi + 1/R_B)\), so

\[ R_{in} = \frac{1+x}{1/r_\pi + 1/R_B} = \frac{116.4}{0.685 + 0.1}\;\text{k}\Omega = \mathbf{148.4}\;\textbf{k}\Omega \]

(check: \(R_{ib}\parallel R_B/(1-A_v) = 169.8\parallel1163 = 148\) kΩ). The source divider: \(v_b/v_{sig} = 148.4/(148.4 + 10) = 0.937\). So \(v_o/v_{sig} = 0.937\times0.9914 = \mathbf{0.929}\).

(iii) \(C_B\) open. The base sees \(R_B + R_1\parallel R_2\) = 20 kΩ to ground in parallel with \(R_{ib} = 101(0.01446 + 2) = 203.5\) kΩ: \(R_{in} = 20\parallel203.5 = \mathbf{18.2}\) kΩ. \(v_o/v_b = 2/(2 + 0.01446) = 0.9928\); \(v_b/v_{sig} = 18.2/28.2 = 0.6456\): \(v_o/v_{sig} = \mathbf{0.641}\).

Comment. Bootstrapping raises \(R_{in}\) about 8 times (18.2 → 148.4 kΩ) and the overall gain from 0.641 to 0.929, because \(R_B\) and the bias divider no longer load the signal source: both ends of \(R_B\) move together, so it carries almost no AC current (it looks like \(R_B/(1-A_v) \approx 1.16\) MΩ), and the divider has been moved from the base to the low-impedance emitter.

2022–23 · Sec A · Q1(b) · 14 marks · compulsory  |  also Class test 2(B) 2021: derive Rin and Rout of a CB

For a common-base amplifier, using the appropriate small-signal equivalent model, derive the expressions of input resistance, output resistance, open-circuit voltage gain and overall voltage gain.

Show worked answer

T model (Figure 1), \(r_o\) neglected: base at AC ground, \(v_{sig}\) with \(R_{sig}\) at the emitter, \(R_C\) to AC ground, \(R_L\) at the collector (an emitter bias resistor \(R_E\), if present, adds in parallel with \(r_e\)).

\(R_{in}\). Only \(r_e\) lies between the emitter and ground, so \(i_e = -v_i/r_e\) and \(R_{in} = r_e\) (\(= r_e\parallel R_E\)).

\(R_o\). \(v_{sig} = 0\): \(i_e = 0\), the collector source is open: \(R_o = R_C\).

\(A_{vo}\). \(v_o = -\alpha i_eR_C = \alpha R_Cv_i/r_e\): \(\;A_{vo} = \alpha R_C/r_e = g_mR_C\), positive (non-inverting).

\(G_v\). \(v_i = v_{sig}r_e/(R_{sig} + r_e)\) and with the load \(v_o = \alpha(R_C\parallel R_L)v_i/r_e\):

\[ G_v = \frac{v_o}{v_{sig}} = \frac{r_e}{R_{sig}+r_e}\cdot\frac{\alpha(R_C\parallel R_L)}{r_e} = \frac{\alpha(R_C\parallel R_L)}{R_{sig}+r_e} \]

The current gain is \(\alpha\approx 1\); CB is therefore a current buffer with a very small \(R_{in}\) and good high-frequency behaviour (no Miller multiplication).

2020–21 · Sec A · Q2(a) · 26 marks

For a common-collector amplifier, derive the expressions for \(R_i\), \(R_o\), \(A_v\) and \(A_i\) using the T model with the Early effect for the transistor. Where is the common-collector amplifier used?

Show worked answer

Circuit: \(v_{sig}\) and \(R_{sig}\) at the base, collector at \(V_{CC}\) (AC ground), load \(R_L\) from the emitter to ground. T model with \(r_o\) from C to E; since C is AC ground, \(r_o\) is in parallel with \(R_L\) (Figure 2). (If a bias resistor or an emitter bias resistor exists, add \(R_B\) in parallel with \(R_i\) and \(R_E\) in parallel with \(R_L\).) Let \(R_E' = r_o\parallel R_L\).

\(R_i\). \(i_e = v_b/(r_e + R_E')\), \(i_b = i_e/(\beta+1)\): \(\;R_i = v_b/i_b = (\beta+1)(r_e + r_o\parallel R_L)\).

\(A_v\). \(v_o = i_eR_E'\): \(\;A_v = v_o/v_b = \dfrac{r_o\parallel R_L}{r_e + r_o\parallel R_L}\approx 1\); \(G_v = A_vR_i/(R_i+R_{sig})\).

\(R_o\). \(v_{sig} = 0\), \(R_L\) removed, test source at the emitter: the base current is \(i_x/(\beta+1)\) through \(R_{sig}\), so the part through the transistor is \(r_e + R_{sig}/(\beta+1)\), in parallel with \(r_o\): \(\;R_o = r_o\parallel[r_e + R_{sig}/(\beta+1)]\).

\(A_i\). \(i_o = i_e\,r_o/(r_o + R_L)\), \(i_b = i_e/(\beta+1)\): \(\;A_i = i_o/i_b = (\beta+1)\dfrac{r_o}{r_o + R_L}\).

Uses. Voltage buffer / impedance transformer between a high-resistance source and a low-resistance load; output stage of multistage amplifiers and power amplifiers; level shifter (about 0.7 V).

2014–15 · Sec A · Q3(c) · 20 marks

For the circuit shown, determine \(R_{in}\), \(R_{out}\), \(v_o/v_i\) and \(i_o/i_i\). The BJT is biased with \(I\) = 5 mA and has β = 100 and \(V_A\) = 100 V. Figure: npn emitter follower, collector at VCC, vs in series with Rs = 10 kΩ coupled to the base (no base resistor drawn), 5 mA current source from the emitter to −VEE, output coupled from the emitter to RL = 1 kΩ.

Show worked answer

\(I_C = \alpha\times5 = 4.95\) mA; \(g_m = 198\) mA/V, \(r_e = 25/5 = 5\) Ω, \(r_\pi = 100/198 = 0.505\) kΩ, \(r_o = 100/4.95 = 20.2\) kΩ. The current source is open at AC, so the emitter load is \(R_E' = r_o\parallel R_L = 20.2\parallel1 = 0.9528\) kΩ.

\(R_{in} = (\beta+1)(r_e + R_E') = 101\times(0.005 + 0.9528) = \mathbf{96.7}\) kΩ. \(v_o/v_i = R_E'/(r_e + R_E') = 0.9528/0.9578 = \mathbf{0.995}\) (\(v_i\) = voltage at the base). \(R_{out} = r_o\parallel[r_e + R_s/(\beta+1)] = 20.2\text{ k}\parallel(5 + 99.0)\,\Omega = \mathbf{103.5}\) Ω. \(i_o/i_i = (\beta+1)r_o/(r_o + R_L) = 101\times20.2/21.2 = \mathbf{96.2}\) A/A.

2019–20 (January 2021 paper) · Sec A · Q3(b) · 16⅔ marks

Comment on the desired values of input impedance, output impedance, voltage gain and current gain of a BJT amplifier. Comment on the values of these four parameters for the CB, CE and CC configurations.

Show worked answer

Desired values. A voltage amplifier wants \(R_{in}\) large (so the source is not loaded), \(R_o\) small (so the load does not reduce the gain) and \(|A_v|\) large. A current amplifier wants \(R_{in}\) small, \(R_o\) large and large \(A_i\).

CE: \(R_{in} = r_\pi\) (moderate), \(R_o\approx R_C\) (high), \(A_v = -g_m(R_C\parallel R_L)\) (large, inverting), \(A_i\approx\beta\): the all-round gain stage. CB: \(R_{in}\approx r_e\) (very low), \(R_o\approx R_C\) (high), \(A_v = +g_m(R_C\parallel R_L)\) (large, non-inverting), \(A_i\approx\alpha<1\): current buffer, good at high frequency. CC: \(R_{in} = (\beta+1)(r_e + R_E')\) (high), \(R_o\approx r_e + R_{sig}/(\beta+1)\) (low), \(A_v\approx1\), \(A_i = \beta+1\): voltage buffer.

A CB amplifier is biased at \(I_E\) = 0.33 mA, \(R_C = R_L\) = 12 kΩ, \(R_{sig}\) = 75 Ω, \(\alpha\) = 0.99. Find \(R_{in}\) and \(v_o/v_{sig}\).

Show worked answer

\(r_e = 25/0.33 = 75.8\) Ω, so \(R_{in} = r_e = \mathbf{75.8}\) Ω. \(G_v = \alpha(R_C\parallel R_L)/(R_{sig} + r_e) = 0.99\times6000/(75 + 75.8) = \mathbf{39.4}\) V/V (39.6 with the manual's \(r_e\) = 75 Ω).

Key terms

Quick check

Summary: CB: \(R_{in} = r_e\parallel R_E\), \(A_{vo} = g_mR_C\) (positive), \(R_o = R_C\), \(G_v = \alpha(R_C\parallel R_L)/(R_{sig}+r_e)\), \(A_i\approx\alpha\). CC: \(R_E' = R_E\parallel R_L\parallel r_o\), \(R_{ib} = (\beta+1)(r_e + R_E')\), \(A_v = R_E'/(r_e+R_E')\), \(R_o = r_o\parallel R_E\parallel[r_e + (R_{sig}\parallel R_B)/(\beta+1)]\), \(A_i = (\beta+1)\times\)(current fraction into \(R_L\)). Bootstrapping moves the bias divider to the emitter, making \(R_B\) look like \(R_B/(1-A_v)\). Derivations use the T model: DC, parameters, small-signal circuit, \(R_{in}\)/\(R_o\)/\(A_{vo}\), \(A_v\)/\(G_v\).
