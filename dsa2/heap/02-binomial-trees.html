Binomial Trees and Their Proofs

Asked in 2024–25 Q4(a) (kCi nodes at depth i, 8 marks) and Q4(c) (H1 vs H2, 7 marks), 2023–24 Q13(a) (nodes, height, root degree, 5 marks each), 2019–20 Q2(a) (10), 2018–19 Q6(a) (10), 2017–18 Q7(b) (5), and CT-4 (H1 vs H2, 10). These are induction proofs with a fixed shape. Learn the shape once and you can write all of them.

1. Why this exists

A binary heap merges two heaps in O(n): you copy the arrays and rebuild. We want merge in O(log n). The fix is a different shape: a binomial heap is a list of binomial trees, and merging works like adding two binary numbers. This chapter is only the trees. Chapter 3 builds the heap.

2. Definition

  • B0 is a single node.
  • Bk is two copies of Bk−1 linked: the root of one becomes a child of the root of the other. k is the order.

Unrolled, the root of Bk has k children, and they are the roots of Bk−1, Bk−2, ..., B1, B0. In this book the biggest child is drawn leftmost. Numbers below are labels, not keys.

3. The five properties

For the binomial tree Bk:
1. It has exactly \(2^k\) nodes.
2. Its height is k (a single node has height 0).
3. The root has degree k, and no other node has a higher degree.
4. The children of the root, from the left, are the roots of Bk−1, ..., B0.
5. There are \(\binom{k}{i}\) nodes at depth i, for \(i = 0, \dots, k\).

The name comes from property 5: the level sizes are the binomial coefficients. Consequence: a binomial tree with n nodes has \(k = \log_2 n\), so its root degree and its height are both \(\log_2 n\). That is where every O(log n) in the next chapter comes from.

4. Proofs, ready to copy

All five use induction on k and the same fact: Bk is two Bk−1, called A and C, where C's root hangs under A's root. Say that sentence first.

Proof 1 · Bk has \(2^k\) nodes

  1. Base k = 0: B0 is one node, \(2^0 = 1\).
  2. Hypothesis: Bk−1 has \(2^{k-1}\) nodes.
  3. Step: Bk consists of two copies of Bk−1, so it has \(2\cdot 2^{k-1} = 2^k\) nodes. ∎

Proof 2 · the height of Bk is k

  1. Base k = 0: one node, height 0.
  2. Hypothesis: Bk−1 has height k−1.
  3. Step: A keeps its height k−1 under its own root. C's root is one level below A's root, so C's deepest node is at depth \(1 + (k-1) = k\).
  4. Height of Bk = \(\max(k-1,\; k) = k\). ∎

Proof 3 · the root of Bk has degree k

  1. Base k = 0: a single node has degree 0.
  2. Hypothesis: the root of Bk−1 has degree k−1.
  3. Step: the root of Bk is A's root. It keeps its k−1 children and gains one more, C's root. Degree \(= (k-1)+1 = k\).
  4. No node has a higher degree: every non-root node sits inside a smaller binomial tree (property 4), whose root has a smaller degree. ∎

Proof 4 · the children of the root are the roots of Bk−1, ..., B0

  1. Base: B0 has no children (the empty list). B1 has one child, B0.
  2. Hypothesis: the root of Bk−1 has children that are roots of Bk−2, ..., B0.
  3. Step: Bk's root is A's root. Its old children are the roots of Bk−2, ..., B0. The new child is C's root, and C is a Bk−1. So the children are Bk−1, Bk−2, ..., B0. ∎

Proof 5 · there are \(\binom ki\) nodes at depth i in Bk (2024–25 Q4(a), 2019–20 Q2(a), 2018–19 Q6(a), 2017–18 Q7(b))

  1. Let \(D(k,i)\) be the number of nodes at depth i in Bk. Claim: \(D(k,i) = \binom ki\).
  2. Base k = 0: one node at depth 0 and none deeper. \(D(0,0) = 1 = \binom 00\) and \(D(0,i) = 0 = \binom 0i\) for \(i>0\).
  3. Hypothesis: \(D(k-1,i) = \binom{k-1}{i}\) for all i.
  4. Step: Bk = A plus C. A's nodes keep their depth. C hangs under A's root, so every node of C is one level deeper than it was in C.
  5. Depth i of Bk therefore holds: depth i of A, plus depth \(i-1\) of C. So \[ D(k,i) = D(k-1,i) + D(k-1,i-1) = \binom{k-1}{i} + \binom{k-1}{i-1}. \]
  6. Pascal's rule (prove it in one line so no mark is lost): \[ \binom{k-1}{i}+\binom{k-1}{i-1} = \frac{(k-1)!}{i!\,(k-1-i)!} + \frac{(k-1)!}{(i-1)!\,(k-i)!} = \frac{(k-1)!}{i!\,(k-i)!}\,\bigl[(k-i)+i\bigr] = \frac{k!}{i!\,(k-i)!} = \binom ki. \]
  7. Edge cases: for \(i=0\) the term \(\binom{k-1}{-1}\) is 0, and for \(i=k\) the term \(\binom{k-1}{k}\) is 0, so the identity still holds. ∎
  8. Check: \(\sum_i \binom ki = 2^k\), which agrees with Proof 1.
On paper: beside Proof 5 draw B2 split into A (left, solid) and C (right, dashed) with an arrow from C's root to A's root, and write the level counts of A as 1, 1 and of C shifted down as 0, 1, 1. Adding gives 1, 2, 1. Examiners like the picture because it shows the "depth i of A plus depth i−1 of C" step.

5. From n nodes to trees

A binomial heap with n nodes is a set of binomial trees, at most one of each order. Because each Bk has \(2^k\) nodes, the orders present are exactly the 1-bits of n written in binary. The structure is therefore unique for a given n.

Method · which trees does an n-node heap have?

  1. Write n in binary.
  2. Each 1 at bit position k means one Bk is present. A 0 means none.
  3. Check by adding \(2^k\) for each tree: the sum must be n.

Example, n = 19. \(19 = 16 + 2 + 1 = 10011_2\). The heap has B4 (16 nodes), B1 (2 nodes), B0 (1 node). \(16+2+1 = 19\). It has \(\lfloor \log_2 19\rfloor + 1 = 5\) bit positions, at most 5 trees, here 3. The largest degree is 4. Another: n = 26 = \(11010_2\) gives B4, B3, B1.

A heap with n nodes has at most \(\lfloor\log_2 n\rfloor + 1\) trees and every tree has height at most \(\lfloor\log_2 n\rfloor\). This is why find-min over the root list, union, and extract-min are all O(log n).

6. Prove or disprove: H1 and H2 (2024–25 Q4(c); CT-4 Q2)

Question. The highest-order tree in binomial heap H1 is Bm. The highest-order tree in H2 is Bm+1. "H2 must have more nodes than H1, regardless of how many trees are in each." Prove or disprove.

The statement is true. The tempting wrong idea is that H1 might compensate by having many trees, but a heap holds at most one tree of each order.

Proof

  1. H1's trees have distinct orders, all at most m. So H1 contains at most one each of B0, ..., Bm.
  2. The most nodes H1 can have is when it holds all of them: \(2^0 + 2^1 + \dots + 2^m = 2^{m+1} - 1\).
  3. H2 contains Bm+1, which alone has \(2^{m+1}\) nodes, and possibly more trees.
  4. So \(|H2| \ge 2^{m+1} > 2^{m+1} - 1 \ge |H1|\). The statement is true. ∎

Where marks go

  • Writing "disproved" after trying one example. A prove-or-disprove needs a general argument.
  • Forgetting the geometric sum \(2^{m+1}-1\). It is the whole proof; say it in words ("a heap with n nodes is the binary representation of n") if you like, but write the sum.
  • Assuming trees may repeat. Equal orders are always merged.
  • Using an exact count of trees: the claim says "regardless of how many".

7. Mandatory practice

Write each proof out in full, with the base, the hypothesis and the step labelled. There is no random generator for proofs, so be strict when you tick the points.
