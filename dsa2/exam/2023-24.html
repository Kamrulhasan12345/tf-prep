Set Cover (decision): given a universe \(U\), subsets \(S_1,\dots,S_m\subseteq U\) and an integer \(k\), is there a sub-collection of size \(\le k\) whose union is \(U\)? Prove that set cover is NP-complete. Hint: vertex cover is NP-complete.

Show answer

Chapter: Reductions, with proof templates.

  1. In NP. Certificate: the chosen sub-collection \(C\). Check \(|C|\le k\) and that the union of its sets equals \(U\): poly time.
  2. NP-hard: VERTEX COVER \(\le_p\) SET COVER. Given \((G=(V,E),k)\), build \(U=E\) and, for each vertex \(v\), the set \(S_v\) = the edges incident on \(v\). Keep the same \(k\). This takes \(O(|V|+|E|)\).
  3. Forward. If \(V'\) is a vertex cover with \(|V'|\le k\), then \(\{S_v : v\in V'\}\) has at most \(k\) sets, and every edge is incident to some \(v\in V'\), so the union is \(E=U\).
  4. Backward. If \(\{S_v : v\in V'\}\) with \(|V'|\le k\) covers \(U=E\), every edge lies in some \(S_v\), i.e. has endpoint \(v\in V'\). So \(V'\) is a vertex cover of size at most \(k\).
  5. Steps 1 to 4: set cover is in NP and NP-hard, so it is NP-complete. ∎

Example for the answer sheet. Triangle A-B-C with \(k=2\): \(U=\{AB,BC,AC\}\), \(S_A=\{AB,AC\}\), \(S_B=\{AB,BC\}\), \(S_C=\{BC,AC\}\). Any two of the sets cover \(U\), as any two vertices cover the triangle.

Where marks go

  • A circulating solution ends with "Set Cover is an NP problem". The conclusion must be NP-complete.
  • Write both directions of the iff.
2023–24 · Q4 · 9 + 6 marks

(a) Define the classes of problems P, NP, and NP-complete. Draw a Venn diagram showing the widely believed relationship among these classes. (9)
(b) What are some approaches to deal with an NP-complete problem? (6)

Show answer

Chapter: P, NP, co-NP, NP-complete.

(a) Definitions.

  • P: decision problems solvable by a deterministic algorithm in polynomial time.
  • NP: decision problems whose "yes" answers can be verified in polynomial time given a certificate (equivalently, solved in poly time by a non-deterministic machine).
  • NP-complete: problems that are in NP and NP-hard, where NP-hard means every problem in NP reduces to it in polynomial time.

Venn diagram (assuming \(P\ne NP\), the widely believed case). P sits inside NP. NP-complete is the overlap of NP and NP-hard. NP-hard also reaches outside NP.

(b) Approaches.

  1. Approximation algorithms with a proven ratio (vertex cover 2-approximation, TSP with triangle inequality).
  2. Branch and bound / backtracking: exact, exponential worst case, but pruning makes typical inputs fast.
  3. Dynamic programming in exponential time that beats brute force (Held-Karp \(O(n^22^n)\)).
  4. Randomized and heuristic methods (Monte Carlo, local search) with no worst-case guarantee.
  5. Special cases: solve restricted inputs in poly time (trees, small parameter).

Sorting by reversals: a reversal \((i,j)\) reverses \(\pi_i\dots\pi_j\). Extend the permutation with \(\pi_0=0\) and \(\pi_{n+1}=n+1\). A breakpoint is between \(\pi_i\) and \(\pi_{i+1}\) if they are not consecutive. Example: \([4\ 1\ 2\ 3]\) becomes \([0\ 4\ 1\ 2\ 3\ 5]\) with three breakpoints. (i) Give a lower bound on the number of reversals in terms of the number of breakpoints. (ii) Design an approximation algorithm with ratio at most 4. (Hint: maximal runs of contiguously increasing and decreasing elements.)

Show answer

Chapter: none in the book (topic is outside the notes; circulating solution A is the only source). Both parts are short.

(i) Lower bound: at least \(b/2\) reversals, where \(b\) is the number of breakpoints.

  1. The identity (extended) has 0 breakpoints. So the goal is to bring \(b\) down to 0.
  2. A reversal \((i,j)\) only changes the two adjacencies at its ends, \((\pi_{i-1},\pi_i)\) and \((\pi_j,\pi_{j+1})\). Inside the reversed block, adjacent pairs stay adjacent (in reverse order), so consecutive stays consecutive.
  3. So one reversal removes at most 2 breakpoints.
  4. Therefore at least \(\lceil b/2\rceil\) reversals are needed. Example \([4\,1\,2\,3]\): \(b=3\), bound \(\lceil 3/2\rceil=2\). The question's own two reversals are optimal.

(ii) 4-approximation. A strip is a maximal run between breakpoints. It is increasing or decreasing (a single element counts as increasing, except that 0 and \(n+1\) stay put).

APPROX-REVERSALS(pi)
  while pi has a breakpoint
     if pi has a decreasing strip of length >= 2
         reverse a decreasing strip chosen so that some breakpoint is removed
         (Kececioglu-Sankoff: take the decreasing strip containing the
          smallest element k, and reverse the block that puts k-1 next to k)
     else
         reverse any increasing strip with a breakpoint on both sides
         (this makes a decreasing strip, and does not add breakpoints)
  1. When a decreasing strip of length \(\ge 2\) exists, one reversal removes at least one breakpoint (Kececioglu and Sankoff's lemma).
  2. If there is none, one reversal of an increasing strip creates a decreasing strip of length \(\ge 2\) without adding breakpoints, then the next reversal removes one. So at worst 2 reversals per breakpoint removed.
  3. Cost of the algorithm \(\le 2b\). Optimum \(\ge b/2\) by part (i).
  4. Ratio \(\le 2b / (b/2) = 4\). ∎

Run on \([4\,1\,2\,3]\): no decreasing strip of length 2 (4 is single, 1 2 3 increasing), so reverse \([1\,2\,3]\) to get \([4\,3\,2\,1]\), now a decreasing strip: reverse the whole block to get \([1\,2\,3\,4]\). Two reversals.

2023–24 · Q6 · 15 marks

Explain branch-and-bound algorithms with an illustrative example.

Show answer

Chapter: Branch and bound; TSP by DP.

  1. Idea. Search the tree of all choices (take or skip each item) but keep, for every node, an upper bound on the best value any completion can reach (for a maximisation problem). Keep the best complete solution found so far. Prune any node whose bound is \(\le\) that best: it cannot improve it.
  2. Bound for 0/1 knapsack: value so far plus the fractional knapsack value of the remaining items (items sorted by value/weight). It is an overestimate because fractions are allowed.
  3. Order: best-first, expand the open node with the largest bound.

Example. Capacity 10; items A (w5, v25), B (w4, v40), C (w3, v60). Ratios C 20, B 10, A 5.

Answer: take B and C: weight 7, value 100. Root bound \(60+40+\tfrac35\cdot25=115\).

Where marks go

  • A circulating solution writes the bound after "pick A" (in its unsorted order A, B, C) as 95. It is 105: capacity 5 is left, take C (3, 60) and 2/4 of B (20), giving \(25+60+20=105\). With 105 that node cannot be pruned against best 100; it has to be explored (it gives A+C = 85 and A+B = 65, so the optimum 100 stays).
  • The pruning rule is "bound \(\le\) best", not anything with probability.

Currencies \(c_1,\dots,c_n\) with exchange rates \(r_{i,j}\) (one unit of \(c_i\) buys \(r_{i,j}\) units of \(c_j\)). Usually \(r_{i,j}r_{j,i}<1\). (i) Design an efficient algorithm: given the rates and two currencies \(s,t\), find the most advantageous sequence of exchanges converting \(s\) into \(t\). (ii) Sometimes there is a cycle with \(r_{i_1,i_2}\cdots r_{i_k,i_1}>1\). Give an efficient algorithm to detect such an anomaly. Hint: use a graph.

Show answer

Chapters: Relaxation, Bellman-Ford, DAG, Floyd-Warshall.

Model. Vertex per currency, directed edge \(i\to j\) for every rate \(r_{i,j}>0\). A sequence of exchanges is a path, and its gain is the product of rates. Maximising a product of positive numbers equals minimising the sum of \(-\log r\).

  1. Give edge \(i\to j\) the weight \(w(i,j)=-\ln r_{i,j}\). Then \(\prod r = e^{-\sum w}\), so the best sequence is the shortest path from \(s\) to \(t\).
  2. Weights can be negative (any rate above 1 gives \(w<0\)), so use Bellman-Ford from \(s\): \(V-1\) rounds of relaxing all edges, record parents, read the path back from \(t\). Time \(O(VE)\). If there is no negative cycle reachable, the answer is correct.
  3. (ii) Anomaly = negative cycle. A cycle has product \(>1\) iff \(\sum -\ln r<0\). Run Bellman-Ford with a virtual source joined to every vertex (or start every distance at 0). After \(V-1\) rounds do one more round: if any edge still relaxes, a negative cycle exists. \(O(VE)\).
  4. Alternative for all pairs: Floyd-Warshall on \(w\), a negative diagonal entry \(d[i][i]<0\) means \(i\) is on an anomaly. \(O(V^3)\).

Where marks go: the Dijkstra trap

  • A circulating solution runs Dijkstra with "relax by max of \(d[u]\cdot r(u,v)\)". That is only valid when every rate is \(\le1\) (equivalent to every weight \(\ge 0\)). The question only says \(r_{ij}r_{ji}<1\), so single rates can exceed 1 and longer cycles can give profit. Dijkstra can then be wrong. Use \(-\log r\) and Bellman-Ford.
  • For floating point, compare with a tolerance.
2023–24 · Q9 · 10 + 5 marks

Explain the Floyd-Warshall algorithm for the all-pairs shortest paths problem. In what context is Johnson's algorithm preferable to Floyd-Warshall?

Show answer

Chapters: Matrix squaring, Floyd-Warshall, closure, Johnson's algorithm.

  1. Subproblem. \(d_{ij}^{(k)}\) = shortest path length from \(i\) to \(j\) using only vertices \(1..k\) as intermediates.
  2. Recurrence. \(d^{(0)}_{ij}=w_{ij}\) (0 on the diagonal, \(\infty\) if no edge); \(d^{(k)}_{ij}=\min\bigl(d^{(k-1)}_{ij},\ d^{(k-1)}_{ik}+d^{(k-1)}_{kj}\bigr)\). Either the best path avoids \(k\), or it goes \(i\to k\to j\) using lower vertices only.
  3. Code. Three nested loops, \(k\) outermost. Time \(\Theta(V^3)\), space \(\Theta(V^2)\) (update in place). Keep a predecessor matrix to rebuild paths. A negative diagonal after the run means a negative cycle.
  4. Johnson's algorithm. Add a source \(s\) with 0-weight edges to all vertices, run Bellman-Ford from \(s\) (negative cycle: stop), set \(h(v)=\delta(s,v)\), reweight \(w'(u,v)=w(u,v)+h(u)-h(v)\ge 0\), run Dijkstra from every vertex, correct with \(d(u,v)=d'(u,v)-h(u)+h(v)\). Time \(O(VE+V\cdot E\log V)\) (or \(O(V^2\log V+VE)\) with Fibonacci heaps).
  5. Prefer Johnson for sparse graphs. With \(E\approx V\), Johnson is \(O(V^2\log V)\), much below \(V^3\). For dense graphs (\(E\approx V^2\)) Floyd-Warshall's \(V^3\) is as good and much simpler.

2023–24 · Q10(c) · 13 marks

Formulate a proof on the correctness of Dijkstra's algorithm.

Show answer

Chapter: Dijkstra: trace, proof, variants.

Theorem. With non-negative weights, when Dijkstra adds vertex \(u\) to the finished set \(S\), \(d[u]=\delta(s,u)\), and it stays so.

  1. Upper-bound property. Always \(d[v]\ge\delta(s,v)\): initially true (\(\infty\) and \(d[s]=0\)), and a relaxation sets \(d[v]=d[x]+w(x,v)\ge\delta(s,x)+w(x,v)\ge\delta(s,v)\) by the triangle inequality.
  2. Induction on the order in which vertices join \(S\). Base: \(s\) joins with \(d[s]=0=\delta(s,s)\).
  3. Step, by contradiction. Let \(u\) be the first vertex that joins \(S\) with \(d[u]\ne\delta(s,u)\). By step 1, \(d[u]>\delta(s,u)\). \(u\ne s\), and a path from \(s\) to \(u\) exists (otherwise \(\delta=\infty=d[u]\)).
  4. Take a shortest path \(p\) from \(s\) to \(u\). Let \(y\) be the first vertex on \(p\) not in \(S\), and \(x\) its predecessor, \(x\in S\).
  5. \(x\) joined \(S\) correctly: \(d[x]=\delta(s,x)\). When \(x\) joined, edge \((x,y)\) was relaxed, so \(d[y]\le d[x]+w(x,y)=\delta(s,y)\) (prefix of a shortest path is shortest). With step 1, \(d[y]=\delta(s,y)\).
  6. Uses non-negative weights: \(y\) comes before or equal to \(u\) on \(p\), so \(\delta(s,y)\le\delta(s,u)\).
  7. Uses the min-choice: \(u\) was chosen with the smallest \(d\) among vertices outside \(S\), and \(y\notin S\), so \(d[u]\le d[y]\).
  8. Chain: \(d[u]\le d[y]=\delta(s,y)\le\delta(s,u)\le d[u]\). So all are equal and \(d[u]=\delta(s,u)\), contradicting step 3.
  9. At the end every vertex is in \(S\), so all distances are correct. ∎

Where marks go

  • Steps 6 and 7 are the two places the algorithm's assumptions are used: non-negative weights, and choosing the minimum. A circulating solution draws the picture but never writes the chain in step 8. Write the chain.
  • With a negative edge, step 6 fails: this is why Dijkstra needs non-negative weights.

2023–24 · Q11(c) · 15 marks

Derive a proof for the max-flow min-cut theorem.

Show answer

Chapter: Max-flow min-cut, Edmonds-Karp.

Theorem. For a flow \(f\) the following are equivalent: (1) \(f\) is a maximum flow; (2) the residual network \(G_f\) has no augmenting path \(s\leadsto t\); (3) \(|f| = c(S,T)\) for some cut \((S,T)\).

  1. Lemma: flow across any cut. For any cut \((S,T)\), \(|f| = f(S,T)-f(T,S)\le f(S,T)\le c(S,T)\). (Sum flow conservation over the vertices of \(S\); internal edges cancel, \(s\in S\) contributes \(|f|\).) So every flow is at most every cut capacity, hence \(\max|f|\le\min c(S,T)\).
  2. (1) ⇒ (2). If there was an augmenting path, pushing its bottleneck (> 0) gives a bigger flow, contradicting maximality.
  3. (2) ⇒ (3). Assume no augmenting path. Let \(S\) = vertices reachable from \(s\) in \(G_f\), \(T=V\setminus S\). \(t\in T\), so \((S,T)\) is a cut. For an edge \((u,v)\) with \(u\in S,v\in T\): if \(f(u,v)0\), the residual edge \(u\to v\) exists, again \(v\) reachable. So \(f(v,u)=0\). Then \(|f|=f(S,T)-f(T,S)=c(S,T)-0=c(S,T)\).
  4. (3) ⇒ (1). By the lemma every flow \(f'\) has \(|f'|\le c(S,T)=|f|\). So \(f\) is maximum.
  5. Combining (1) ⇔ (2) ⇔ (3): the value of a maximum flow equals the capacity of a minimum cut. ∎

Where marks go

  • Say explicitly: edges from \(S\) to \(T\) are saturated and edges from \(T\) to \(S\) carry zero flow (step 3). One circulating solution omits it.

Prove that the height of an AVL tree with \(n\) elements is \(O(\log n)\).

Show answer

Chapter: Rotations and AVL trees. Height of a leaf is 0 (teacher's convention).

  1. Let \(N(h)\) be the fewest nodes in an AVL tree of height \(h\).
  2. The root has subtrees of heights \(h-1\) and, at the fewest, \(h-2\) (balance factor ±1). So \(N(h)=N(h-1)+N(h-2)+1\), \(N(0)=1\), \(N(1)=2\). Values 1, 2, 4, 7, 12, 20.
  3. Since \(N(h-1)\ge N(h-2)\): \(N(h) > 2N(h-2)\). Unrolling, \(N(h) \ge 2^{\lfloor h/2\rfloor}\) (bases \(N(0)=1,N(1)=2\)).
  4. A tree of height \(h\) has \(n\ge N(h)\ge 2^{(h-1)/2}\) nodes. Taking logs, \(h \le 2\log_2 n + 1 = O(\log n)\).
  5. Sharper: \(N(h)=F_{h+3}-1\ge\varphi^{h+3}/\sqrt5-2\), so \(h\le 1.44\log_2 n\). ∎

2023–24 · Q13(a) · 5 × 3 = 15 marks

Prove the following for a binomial tree \(B_k\) of order \(k\): i) the number of nodes is \(2^k\); ii) the height is \(k\); iii) the degree of the root is \(k\).

Show answer

Chapter: Binomial trees and their proofs. Definition: \(B_0\) is a single node. \(B_k\) is two copies of \(B_{k-1}\) with the root of one made the leftmost child of the root of the other. Induction on \(k\).

  1. Nodes. \(k=0\): \(2^0=1\). Step: \(B_k\) has two copies of \(B_{k-1}\): \(2\cdot2^{k-1}=2^k\). ∎
  2. Height. \(k=0\): one node, height 0. Step: the height of \(B_k\) is 1 (the new edge) plus the height of the child tree \(B_{k-1}\), \(=1+(k-1)=k\) (the other copy, containing the root, is no taller than the root plus the child tree). ∎
  3. Root degree. \(k=0\): degree 0. Step: the root of \(B_k\) is the root of one copy of \(B_{k-1}\) (degree \(k-1\)) with one more child, so \(k-1+1=k\). ∎

Choose values. \(6=110_2\): trees \(B_1\), \(B_2\). \(7=111_2\): trees \(B_0\), \(B_1\), \(B_2\).
