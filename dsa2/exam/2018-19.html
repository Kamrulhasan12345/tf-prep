i) Prove that an optimal minimum spanning tree is composed of optimal minimum spanning subtrees.

ii) Draw a minimum spanning tree of the graph G shown below such that the minimum spanning tree contains the edges with weights x and z.

Graph read from scan (vertices A..J): A–B 13, B–C z, C–D 2, D–E 6, A–F 11, A–G 1, B–G 14, B–H 8, C–H 12, D–H 9, D–I 6, D–J 7, E–J 5, F–G x, G–H 4, H–I 3, I–J 1. The values of x and z are not given.

Show answer

(i) Proof (optimal substructure), cut and paste.

  1. Let \(T\) be an MST of \(G\). Remove any edge \(e=(u,v)\) of \(T\). \(T\) splits into two trees \(T_1\) (on vertex set \(V_1\ni u\)) and \(T_2\) (on \(V_2\ni v\)).
  2. \(T_1\) uses only edges with both ends in \(V_1\), so it is a spanning tree of the induced subgraph \(G[V_1]\) (likewise \(T_2\) of \(G[V_2]\)). Claim: \(T_1\) is an MST of \(G[V_1]\) (and \(T_2\) of \(G[V_2]\); the argument is symmetric).
  3. Suppose not: there is a spanning tree \(T_1'\) of \(G[V_1]\) with \(w(T_1')<w(T_1)\).
  4. Then \(T'=T_1'\cup T_2\cup\{e\}\) is a spanning tree of \(G\): \(T_1'\) spans \(V_1\), \(T_2\) spans \(V_2\), and \(e\) joins them, so \(T'\) is connected with \((|V_1|-1)+(|V_2|-1)+1=|V|-1\) edges. Its weight is \(w(T_1')+w(T_2)+w(e)<w(T)\).
  5. This contradicts that \(T\) is an MST. So \(T_1\) and \(T_2\) are optimal. \(\blacksquare\)

(The same argument applies to every subtree of \(T\) hanging off an edge, so the optimal solution is built from optimal sub-solutions.)

Q2(a) · 15 marks

Johnson's Algorithm makes clever use of Bellman-Ford and Dijkstra's Algorithms to do All-Pairs-Shortest-Paths efficiently on sparse graphs. Explain the basic clever idea of Johnson's Algorithm.

Show answer

The clever idea: reweight the edges so none is negative, without changing which paths are shortest. Then run Dijkstra from every vertex.

Method

  1. Add a new vertex \(q\) with a 0-weight edge to every vertex.
  2. Run Bellman-Ford from \(q\). If it finds a negative cycle, stop and report it. Otherwise \(h(v)=\delta(q,v)\) for every \(v\) (\(h(v)\le0\)).
  3. Reweight: \(\hat w(u,v)=w(u,v)+h(u)-h(v)\).
  4. Run Dijkstra from each vertex \(u\) with \(\hat w\), getting \(\hat\delta(u,v)\).
  5. Undo: \(\delta(u,v)=\hat\delta(u,v)-h(u)+h(v)\).

Why \(\hat w\ge0\). Shortest distances obey the triangle inequality \(h(v)\le h(u)+w(u,v)\). Rearranged: \(w(u,v)+h(u)-h(v)\ge0\).

Why shortest paths are preserved. For any path \(p=v_0\to v_1\to\dots\to v_k\), the \(h\) terms telescope: \(\hat w(p)=w(p)+h(v_0)-h(v_k)\). The correction depends only on the endpoints, not on the path. So the path with minimum \(\hat w\) between \(v_0\) and \(v_k\) is also the path with minimum \(w\). The same holds for cycles (\(v_0=v_k\)): \(\hat w(c)=w(c)\), so negative cycles are the same ones.

Time. Bellman-Ford \(O(VE)\) once, plus \(V\) Dijkstra runs. With a Fibonacci heap that is \(O(V^2\log V+VE)\); with a binary heap \(O(VE\log V)\). On sparse graphs (\(E=O(V)\)) this is better than Floyd-Warshall's \(O(V^3)\).

Small example (engine): edges A→B 2, B→C −3, C→A 4, A→C 5.

Chapter: Johnson's algorithm.

Question 3

Q3(a) · 15 marks

i) What are the rotations that are required to balance an AVL tree? ii) How does a rotation balance an AVL tree? iii) What is the maximum height of an AVL tree having 10 nodes?

Show answer

(i) Four cases. Let \(z\) be the lowest node with \(|bf|=2\).

  • LL (left-left): the left child has \(bf\ge0\), the extra height is in the left subtree of the left child. One right rotation at \(z\).
  • RR: mirror. One left rotation at \(z\).
  • LR (left-right): the left child has \(bf<0\) (heavy on its right). Left rotation at the left child, then right rotation at \(z\) (a double rotation).
  • RL: mirror. Right rotation at the right child, then left rotation at \(z\).

(ii) How a rotation balances.

  1. A rotation changes the shape locally in \(O(1)\) time but keeps the in-order sequence (BST order is preserved).
  2. In the LL case, right-rotating at \(z\) lifts its tall left child \(y\) one level and pushes \(z\) one level down onto the shorter side. The tall subtree (\(y\)'s left) moves up by 1 and the short subtree (\(z\)'s right) moves down by 1: the heights now agree within 1.
  3. For the double case, the first rotation turns the zig-zag into a straight line, and the second balances it.
  4. After one (single or double) rotation, the subtree has the same height it had before the insertion, so no ancestor above is affected: one rebalancing suffices per insertion.

(iii) Maximum height with 10 nodes. Let \(N(h)\) be the least number of nodes of an AVL tree of height \(h\) (leaf = 0): \(N(0)=1,N(1)=2,N(h)=N(h-1)+N(h-2)+1\): \(1,2,4,7,12,\dots\)

  1. \(N(3)=7\le10<12=N(4)\).
  2. So a 10-node AVL tree can have height 3 but not 4. Maximum height = 3 (counting a single node as height 0). If your course counts a single node as height 1, write 4. State the convention.

Question 4

Q4(a) · 15 marks

i) When we insert a node into a red-black tree, we initially set the color of the new node to red. Why don't we choose to set the color to black?

ii) Would inserting a new node to a red-black tree and then immediately deleting it change the tree? Explain with an example.

iii) What is the ratio between the lengths of the longest path and the shortest path in a red-black tree?

Show answer

(i) Why red. A new black node adds 1 to the black height of every path through it, which breaks the black-height rule (property 5) on that one path, so every insertion would need a repair. A new red node adds no black, so black height is untouched. It can break only the rule "a red node has no red child", and only when its parent is red. If the parent is black (about half the time) nothing is needed. Otherwise the repair is one of 3 cases, and it is local.

(ii) Yes, it can change the tree. The insertion fix-up may recolour or rotate. Deleting the red leaf afterwards removes the leaf but does not undo them.

Example: tree \(T_0\) = 23B(8R(6B,15B(13R,19R)),27B(,29R)). Insert 11: case 1, then case 2, then case 3 (with a rotation at 23). Result: 15B(8R(6B,13B(11R,)),23R(19B,27B(,29R))). Now delete 11. It is a red leaf, so the delete needs no fix-up. Result: 15B(8R(6B,13B),23R(19B,27B(,29R))). The root is 15, not 23, so the tree is different from \(T_0\). (If the insertion hits a black parent there is no fix-up and the tree is restored: so "sometimes yes, sometimes no". The question asks "would it", and the answer is "not always".)

(iii) Ratio \(\le2\).

  1. Every root-to-NIL path has the same number of black nodes, \(bh\).
  2. The shortest path has at least \(bh\) nodes (all black). So shortest \(\ge bh\) (counting black nodes).
  3. No two red nodes are adjacent, so at most every second node on a path is red. The longest path has at most \(2\,bh\) nodes.
  4. So longest \(\le 2\cdot\) shortest: the ratio is at most 2. (Also gives height \(\le 2\log_2(n+1)\).)

Q4(b) · 15 marks

In a skip list with n entries, prove that i) the expected space used is O(n), and ii) the expected search and insertion time is O(log n).

Show answer

Setup. Level \(S_0\) holds all \(n\) keys. Each key in \(S_i\) is promoted to \(S_{i+1}\) by a fair coin flip: probability \(1/2\). \(h\) is the number of levels.

(i) Space.

  1. A key appears in \(S_i\) with probability \(1/2^i\). Expected number of keys in \(S_i\): \(n/2^i\).
  2. Expected total number of nodes: \(\sum_{i\ge0}n/2^i\le 2n\).
  3. The sentinels (\(-\infty,+\infty\)) add \(2h=O(\log n)\). So expected space \(=O(n)\). \(\blacksquare\)

(ii) Time.

  1. Height. The probability that some key reaches level \(c\log_2n\) is at most \(n\cdot2^{-c\log_2n}=n^{1-c}\). So with high probability \(h=O(\log n)\). In expectation: \(E[h]=\sum_{i\ge1}P(h\ge i)\le\sum_{i\ge1}\min(1,n/2^i)\le\lfloor\log_2n\rfloor+(1+\tfrac12+\tfrac14+\dots)\le\log_2n+2\) (the first \(\lfloor\log_2n\rfloor\) terms are at most 1, the rest halve each time).
  2. Search cost = number of steps of the search path. Look at the path backwards, from the found position at \(S_0\) up to the top. At each node on the path, we arrived either from the left (the node was not promoted: it has no tower above) or from above (it was promoted). A node was promoted with probability \(1/2\), so each step going backwards moves up with probability \(1/2\) and left otherwise.
  3. To climb \(h\) levels we need \(h\) "up" steps. The expected number of fair-coin flips to get \(h\) heads is \(2h\). So the expected length of the path is \(\le2h=O(\log n)\).
  4. Insertion = a search (\(O(\log n)\), which also records the last node visited on each level) + building the tower. The tower height is geometric with \(p=1/2\), expected 2 levels, and each level costs \(O(1)\) to splice in after the recorded node. So expected \(O(\log n)\). \(\blacksquare\)

Q5(a) · 12 marks

Assuming simple uniform hashing, prove that an unsuccessful search in separate chaining takes expected O(1+α) work, where α is the load factor.

Show answer
  1. Setup: \(n\) keys, \(m\) slots, \(\alpha=n/m\). Simple uniform hashing: any key is equally likely to hash to any slot, independent of others.
  2. An unsuccessful search for key \(k\) (not in the table): compute \(h(k)\) (\(O(1)\)), go to slot \(h(k)\), and scan the whole chain, because \(k\) is not there.
  3. Let \(n_j\) be the length of chain \(j\). \(E[n_j]=n\cdot\frac1m=\alpha\), because each of the \(n\) stored keys falls into slot \(j\) with probability \(1/m\) (linearity of expectation).
  4. \(h(k)\) is a uniformly random slot, so the expected chain length scanned is \(\sum_j\frac1m E[n_j]=\alpha\).
  5. Total expected work: \(\Theta(1)+\alpha=\Theta(1+\alpha)\). \(\blacksquare\)

Chapter: Chaining and open addressing.

Q5(b) · 6 marks

Quadratic probing does not necessarily probe all locations in hash tables. Do you agree with this statement? Justify your answer.

Show answer

Agree.

  1. The probe sequence is \(h(k,i)=(h(k)+i^2)\bmod m\) (or with \(c_1i+c_2i^2\)). It visits only the slots \(h(k)+(i^2\bmod m)\).
  2. Example, \(m=11\), \(h(k)=0\): \(i=0,1,2,\dots,10\) give squares \(0,1,4,9,16,25,36,49,64,81,100\), i.e. slots \(0,1,4,9,5,3,3,5,9,4,1\). Only the 6 slots \(\{0,1,3,4,5,9\}\) are ever probed. Slots 2, 6, 7, 8, 10 are never reached from this key.
  3. In general, \((i+m)^2\equiv i^2\) and \((m-i)^2\equiv i^2\pmod m\), so only \(i=0..\lfloor m/2\rfloor\) give new slots: at most \(\lfloor m/2\rfloor+1<m\) for \(m\ge3\). For an odd prime \(m\) it is exactly \((m+1)/2\), about half the table.
  4. Consequence: an insertion can fail even though the table has empty slots. It is guaranteed to succeed only if \(m\) is prime and the table is less than half full (\(\alpha<1/2\)); this is the known result.

Q6(a) · 10 marks

Prove that there are kCi nodes at depth i in a binomial heap Bk of order k.

Show answer

Let \(D(k,i)\) be the number of nodes at depth \(i\) in \(B_k\). Claim \(D(k,i)=\binom ki\).

  1. Base: \(B_0\) is one node at depth 0: \(D(0,0)=1\), and 0 elsewhere. Matches \(\binom0i\).
  2. Hypothesis: \(D(k-1,j)=\binom{k-1}j\) for all \(j\). Step: \(B_k\) is two \(B_{k-1}\) trees, one's root made the child of the other's root.
  3. A node at depth \(i\) in \(B_k\) is a depth-\(i\) node of the tree that kept the root, or a depth-\((i-1)\) node of the attached tree (it is one level lower now).
  4. \(D(k,i)=D(k-1,i)+D(k-1,i-1)=\binom{k-1}i+\binom{k-1}{i-1}=\binom ki\) by Pascal's rule (with \(\binom{k-1}{-1}=\binom{k-1}{k}=0\) for \(i=0\) and \(i=k\)). \(\blacksquare\)

Question 7

Q7(a) · 12 marks

Prove that P = NP ⇒ NP = co-NP.

Show answer

Recall: \(L\in\)co-NP iff its complement \(\overline L\in NP\). And P is closed under complement: swap the yes and no answers of a polynomial-time decider.

  1. Assume \(P=NP\).
  2. co-NP ⊆ NP. Let \(L\in\)co-NP. Then \(\overline L\in NP=P\). P is closed under complement, so \(L=\overline{\overline L}\in P=NP\).
  3. NP ⊆ co-NP. Let \(L\in NP=P\). Then \(\overline L\in P=NP\), so by definition \(L\in\)co-NP.
  4. Both inclusions hold, so \(NP=\)co-NP. \(\blacksquare\)

Q7(b) · 6 marks

The TAUTOLOGY problem asks if a given Boolean formula is true for all possible assignments to the Boolean variables. Prove or disprove that TAUTOLOGY is in co-NP.

Show answer

True: TAUTOLOGY is in co-NP.

  1. The complement of TAUTOLOGY is NOT-TAUTOLOGY: "some assignment makes the formula false".
  2. NOT-TAUTOLOGY is in NP. Certificate: an assignment \(a\). The verifier evaluates the formula on \(a\) in time linear in the formula and accepts iff the value is false.
  3. Since the complement is in NP, by definition TAUTOLOGY \(\in\) co-NP. \(\blacksquare\)

(TAUTOLOGY is even co-NP-complete. It is in NP only if NP = co-NP, which is believed false.)

Q7(c) · 12 marks

For a graph G = (V,E), a set S of vertices in G is a vertex cover if every edge e in G has at least one end in S. A set of vertices I in G is an independent set if for every two vertices in I, there is no edge between them. Given a graph G and a number K, the vertex cover problem asks if G contains a vertex cover of size at most K. Given a graph G and a number K, the independent set problem asks if G contains an independent set of size at least K. Prove that the vertex cover problem is at least as hard as the independent set problem.

Show answer

Show Independent Set \(\le_p\) Vertex Cover.

Reduction

  1. Input to IS: graph \(G=(V,E)\), number \(K\), \(n=|V|\).
  2. Output for VC: the same graph \(G\) and the number \(K'=n-K\). Polynomial (constant) time.

Key lemma: \(S\) is an independent set iff \(V\setminus S\) is a vertex cover.

  1. (⇒) Let \(S\) be independent. Take any edge \((u,v)\). Not both \(u,v\) are in \(S\) (no edge inside \(S\)), so at least one is in \(V\setminus S\). So \(V\setminus S\) covers every edge.
  2. (⇐) Let \(C=V\setminus S\) be a vertex cover. Take two vertices \(u,v\in S\). If \((u,v)\in E\), neither endpoint is in \(C\), so the edge is uncovered: contradiction. So \(S\) is independent.

Correctness. G has an independent set of size \(\ge K\) \(\iff\) G has a vertex cover of size \(\le n-K\) (take complements: sizes \(|S|\ge K\iff|V\setminus S|\le n-K\)). So an algorithm for VC decides IS: VC is at least as hard. \(\blacksquare\)

Q8(a) · 10 marks

Give an approximation algorithm for the vertex cover problem. Analyze the approximation ratio of your algorithm.

Show answer

2-approximation (maximal matching)

  1. \(C=\emptyset\). While some edge \((u,v)\) has neither endpoint in \(C\): add both \(u\) and \(v\) to \(C\), and remove all edges touching \(u\) or \(v\).
  2. Return \(C\).
APPROX-VC(G)
 C = empty;  E' = E
 while E' not empty
    pick any edge (u,v) in E'
    C = C union {u, v}
    delete from E' every edge incident to u or to v
 return C

Valid cover. The loop stops only when no edge remains, and every deleted edge touched a vertex we added.

Ratio \(\le2\).

  1. Let \(A\) be the set of edges picked. No two picked edges share an endpoint (we deleted all edges at both endpoints after each pick). So \(A\) is a matching.
  2. Any vertex cover, including an optimal one \(C^*\), must contain at least one endpoint of each edge in \(A\), and these endpoints are all different. So \(|C^*|\ge|A|\).
  3. \(|C|=2|A|\le2|C^*|\). \(\blacksquare\)

Time \(O(V+E)\) with adjacency lists. Ratio 2 is tight for this algorithm: on a graph that is a perfect matching (e.g. a single edge) it returns both ends of every edge, exactly \(2\cdot OPT\).

Q8(b) · 10 marks

Analyze the running time of the randomized quick sort algorithm.

Show answer

Claim: the expected running time is \(O(n\log n)\) for every input. (Worst case \(O(n^2)\), but only with tiny probability.) Pivot is chosen uniformly at random, and partition takes \(O(\text{size})\).

  1. Running time is \(O(n+X)\) where \(X\) is the total number of comparisons made in all PARTITION calls (each call does one comparison per element against the pivot, and the number of calls is \(\le n\)).
  2. Let \(z_1<z_2<\dots<z_n\) be the sorted elements. Two elements are compared at most once (one of them is then the pivot and is never used again).
  3. Let \(X_{ij}=1\) if \(z_i\) and \(z_j\) are ever compared. The elements \(z_i,\dots,z_j\) stay together in one sublist until one of them is chosen as a pivot (a pivot below \(z_i\) or above \(z_j\) sends all of them to the same side). \(z_i\) and \(z_j\) are compared iff the first pivot among \(z_i..z_j\) is \(z_i\) or \(z_j\).
  4. That first pivot is uniform among the \(j-i+1\) elements, so \(P(X_{ij}=1)=\frac2{j-i+1}\).
  5. \(E[X]=\sum_{i=1}^{n-1}\sum_{j=i+1}^{n}\frac2{j-i+1}=\sum_{i=1}^{n-1}\sum_{k=2}^{n-i+1}\frac2k<\sum_{i=1}^{n-1}2H_n=O(n\log n)\), since the harmonic number \(H_n=O(\log n)\).
  6. So expected time \(O(n)+O(n\log n)=O(n\log n)\). \(\blacksquare\)
