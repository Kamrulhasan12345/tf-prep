Q1(a) · 8 marks

Design an efficient algorithm for finding the length of the longest path in a dag (directed acyclic graph).

Show answer

Idea. In a dag, process vertices in topological order. Then when you stand at u, every path ending at u has already been counted.

LONGEST-DAG(G, w)
 topologically sort V                 // DFS, reverse finish order
 for each v in V: len[v] = 0          // best path that ENDS at v (just v alone = 0)
 for each u in topological order
   for each edge (u,v) in Adj[u]
     if len[u] + w(u,v) > len[v]
        len[v] = len[u] + w(u,v)
 return max over v of len[v]
  1. Correctness (induction on topological position). Claim: when u is processed, len[u] = weight of the longest path ending at u. A longest path ending at u is either u alone (0) or a longest path ending at some in-neighbour x plus edge \((x,u)\). Every in-neighbour \(x\) precedes \(u\) in topological order, so by induction len[x] was final when \(x\) was processed, and it then relaxed \((x,u)\). So len[u] \(=\max(0,\max_x(\texttt{len}[x]+w(x,u)))\), the true value. The answer is the maximum over all end vertices.
  2. Time: DFS \(\Theta(V+E)\), the loop \(\Theta(V+E)\). Total \(\Theta(V+E)\).
  3. Equivalent trick: negate every weight and run DAG shortest paths. This is legal because a dag has no cycles, so no negative cycle can appear.

Chapter: Relaxation, Bellman-Ford, DAG.

Q1(b) · 12 marks

Minimum-sum descent. Some positive integers are arranged in an equilateral triangle with n numbers in its base like the one in Figure for Q.1(b) for n = 4. The problem is to find the smallest sum in a descent from the triangle apex to its base through a sequence of adjacent numbers (shown in the figure by the circles). Explain how the minimum-sum descent problem can be solved by Dijkstra's algorithm.

Figure data (read from scan): row 1: 2; row 2: 5 4; row 3: 1 4 7; row 4: 8 6 9 6. The circled descent is 2, 5, 1, 6.

Show answer

Model as a graph.

  1. One vertex per number. Name them A (2), B (5), C (4), D (1), E (4), F (7), G (8), H (6), I (9), J (6), reading left to right, row by row.
  2. A number is adjacent to the two numbers just below it. Edge \(u\to v\) gets weight = the number written in v (we pay for a number when we step on it).
  3. Add a sink T with a weight-0 edge from every bottom-row vertex.
  4. All weights are positive, so Dijkstra applies. Run it from A. The answer is \(2 + d(T)\), because the apex number was never paid by an edge.
  5. The path is read back with the parent pointers \(\pi\).

Why Dijkstra and not a simple DP? A DP over rows also works in \(O(n^2)\). Dijkstra is the "graph" answer the question wants: \(V = n(n+1)/2+1\), \(E = O(V)\), so \(O(V\log V)\) with a heap.

Result: \(d(T) = 12\), so the minimum sum is \(2+12 = 14\), via A, B, D, H, which is the circled descent 2, 5, 1, 6.

On paper: draw the triangle as a layered graph with edge weights, then the table of d values after each extract (as in the trace), then circle the final path.

Chapter: Dijkstra: trace, proof, variants.

Q1(c) · 15 marks

Let T be a minimum spanning tree of graph G obtained by Prim's algorithm. Let Gnew be a graph obtained by adding to G a new vertex and some edges, with weights, connecting the new vertex to some vertices in G. Can you construct a minimum spanning tree of Gnew by adding one of the new edges to T? If your answer is yes, explain how; if your answer is no, explain why not.

Show answer

Answer: not in general. It is guaranteed only when the new vertex gets exactly one new edge (that edge must be in every spanning tree). With two or more new edges the MST may need several of them and drop an old tree edge.

Counterexample. G is the path a–b (5), b–c (5), so T = G. New vertex v with edges v–a (1) and v–c (1). Best "T plus one new edge" is T + v–a, weight 11. But the real MST of Gnew is {v–a, v–c, a–b}, weight 7. It uses two new edges and drops b–c.

What is true: the new MST uses only edges of T and the new edges.

  1. Take any edge \(e\in E(G)\setminus T\). T is an MST of G, so \(e\) is a heaviest edge on the cycle formed by \(T+e\). (If some tree edge \(f\) on that cycle had \(w(f)>w(e)\), then \(T-f+e\) would be a lighter spanning tree of G.)
  2. That cycle still exists in Gnew, and \(e\) is still a heaviest edge on it.
  3. By the cycle property, a heaviest edge of a cycle can be removed without losing an MST. So \(e\) can be discarded.
  4. Discard the non-tree edges one at a time. Each one's cycle uses only edges of \(T\), which are never discarded, so the cycle property still applies at every step. Hence an MST of Gnew lies inside \(T\cup F\), where F is the set of new edges.

Algorithm. Run Kruskal (or Prim) on the graph \((V\cup\{v\},\ T\cup F)\). It has \(|V|-1+|F|\) edges, so it takes \(O((|V|+|F|)\log |V|)\) instead of re-solving Gnew from scratch.

Chapter: Cut property, Kruskal, Prim, uniqueness.

Q2(a) · 12 marks

The shortest paths to a given vertex from each other vertex of a weighted digraph is called the single-destination shortest-paths problem. Solve the single-destination shortest-path problem in a graph with nonnegative numbers assigned to its vertices in addition to the edge weights.

Show answer

Meaning. The cost of a path = sum of its edge weights + sum of the numbers \(n(x)\) of the vertices on it. Destination is \(t\).

  1. Reverse every edge. A path \(x_k\to\dots\to x_1\to t\) in G is a path \(t\to x_1\to\dots\to x_k\) in the reversed graph \(G^R\).
  2. Move vertex costs onto edges. For each edge \((u,v)\) of G, the reversed edge \((v,u)\) gets weight \(w'(v,u)=w(u,v)+n(u)\). We charge the vertex we step into. All \(w'\ge 0\).
  3. Run Dijkstra from t on \(G^R\) with weights \(w'\). The true cost of the shortest path from \(x\) to \(t\) in G is \(d'(x)+n(t)\), because \(t\) itself was never charged.
  4. Time: \(O(E\log V)\) with a binary heap.

Why it is right. Every path from \(t\) in \(G^R\) corresponds one to one to a path into \(t\) in G. Each vertex of it except \(t\) is charged once, through the edge entering it. So path costs agree up to the constant \(n(t)\), and Dijkstra is valid because \(w'\ge0\).

Chapter: Dijkstra: trace, proof, variants.

Q2(b) · 10 marks

Explain how to implement Warshall's algorithm without using extra memory for storing elements of the algorithm's intermediate matrices.

Show answer

Keep one matrix \(R\) and update it in place:

WARSHALL(R)                 // R[i][j] = 1 if edge i->j or i = j
 for k = 1 to n
   for i = 1 to n
     for j = 1 to n
       R[i][j] = R[i][j] OR (R[i][k] AND R[k][j])
  1. The textbook version builds \(R^{(k)}\) from \(R^{(k-1)}\) in a separate matrix. The in-place version needs the old values only in row \(k\) and column \(k\).
  2. During round \(k\), row \(k\) does not change: \(R[k][j]\leftarrow R[k][j]\ \text{OR}\ (R[k][k]\ \text{AND}\ R[k][j])\). Since \(R[k][k]=1\) already, this equals \(R[k][j]\).
  3. Column \(k\) does not change either: \(R[i][k]\leftarrow R[i][k]\ \text{OR}\ (R[i][k]\ \text{AND}\ R[k][k])=R[i][k]\).
  4. So every value read in round \(k\) from row \(k\) or column \(k\) is the same as in \(R^{(k-1)}\). Overwriting other cells early is harmless: the result equals \(R^{(k)}\).
  5. Space: \(\Theta(1)\) extra. Time \(\Theta(n^3)\). The same argument works for Floyd-Warshall (\(d[k][k]=0\) when there is no negative cycle).

Chapter: Matrix squaring, Floyd-Warshall, closure.

Q2(c) · 13 marks

Rumor spreading: There are n people, each in possession of a different rumor. They want to share all the rumors with each other by sending electronic messages. Assume that a sender includes all the rumors he or she knows at the time the message is sent and that a message may only have one addressee. Design a greedy algorithm that always yields the minimum number of messages they need to send to guarantee that every one of them gets all the rumors.

Show answer

Answer: \(2n-2\) messages (for \(n\ge2\)).

Method · the hub algorithm

  1. Pick person 1 as the hub.
  2. Persons \(2,3,\dots,n\) each send one message to person 1. Now person 1 knows all \(n\) rumors. That is \(n-1\) messages.
  3. Person 1 sends one message to each of \(2,\dots,n\). Each now has everything. That is \(n-1\) more messages.

Lower bound (why you cannot do better).

  1. Look at the first moment some person \(p\) knows all \(n\) rumors. Nobody knew all rumors before this.
  2. Rumors of all \(n\) people had to flow into \(p\), so the messages sent up to that moment connect all \(n\) people. A connected graph on \(n\) vertices needs at least \(n-1\) edges. So at least \(n-1\) messages were sent.
  3. At that moment only \(p\) knows everything: nobody knew all before, and the message just sent changed only the receiver \(p\). So each of the other \(n-1\) people must still receive at least one later message, and these are \(n-1\) distinct messages (one receiver each).
  4. Total \(\ge (n-1)+(n-1)=2n-2\). The hub algorithm meets it, so it is optimal.

Check small cases. n = 2: A→B, B→A, 2 messages. n = 3: B→A, C→A, A→B, A→C is 4 messages, and 3 is impossible.

If a marker expects the "2n−4" answer: that is for phone calls (two-way). Here a message has one addressee and goes one way, so the answer is \(2n-2\).

Chapter: this is a modelling question; see Bipartite matching and modelling for how to argue lower bounds.

Question 3

Q3(a) · 10 marks

You want to increase the maximum flow of a network as much as possible, but you are only allowed to increase the capacity of one edge. How do you find such an edge? (Give pseudocode). You may assume the existence of algorithms to compute max flow min cut. What's the running time of your algorithm?

Show answer

Key fact. Raising an edge's capacity helps only if that edge crosses every minimum cut. In a residual network after max flow, edge \((u,v)\) is such an edge exactly when \(u\) is reachable from \(s\) and \(t\) is reachable from \(v\) in \(G_f\).

BEST-EDGE(G, s, t)
 f = MAX-FLOW(G, s, t)                 // any algorithm, e.g. Edmonds-Karp
 build residual network G_f
 A = vertices reachable from s in G_f          // BFS
 B = vertices that can reach t in G_f          // BFS on reversed G_f
 for each original edge (u,v)
    if u in A and v in B return (u,v)          // saturated, on every min cut
 return NONE                                    // no single edge helps
  1. Such an edge is saturated: if it had residual capacity, \(v\) would be in \(A\), and then \(s\to u\to v\to t\) would be an augmenting path, contradiction.
  2. Raise its capacity by 1: the residual edge \(u\to v\) appears and \(s\leadsto u\to v\leadsto t\) is an augmenting path, so max flow grows by at least 1. It grows by at most 1, since every cut gains at most 1. So every such edge gives the same, largest possible gain.
  3. If the edge is not of this kind, some min cut does not count it. If \(u\notin A\): \((A,V-A)\) is a min cut (the standard cut from max-flow min-cut) and \((u,v)\) does not go from \(A\) to \(V-A\). If \(v\notin B\): \((V-B,B)\) is also a min cut (no residual edge enters \(B\), so every edge into \(B\) is saturated and every edge out of \(B\) is empty), and \((u,v)\) does not enter \(B\). Raising \(c(u,v)\) leaves that cut's capacity unchanged, so max flow cannot grow.
  4. If the raise may be unlimited, gains can differ: for each candidate edge set its capacity to \(\infty\), recompute max flow and keep the best. Time \(O(E\cdot\text{maxflow})\).
  5. Time: one max-flow computation + two BFS, \(O(\text{maxflow} + V + E)\). With Edmonds-Karp, \(O(VE^2)\).

Chapter: Max-flow min-cut, Edmonds-Karp.

Q3(b) · 10 marks

In a stable matching problem (Gale-Shapley algorithm) each participant has a true preference order. Now consider a woman w. Suppose w prefers man m to m′, but both m and m′ are low on her list of preferences. Can it be the case that by switching the order of m and m′ on her list of preferences (i.e., by falsely claiming that she prefers m′ to m) and running the algorithm with this false preference list, w will end up with a man m″ that she truly prefers to both m and m′? Give proof to support your answer.

Show answer

Answer: yes, it can. Men-proposing Gale-Shapley is strategy-proof for men but not for women. A single example proves "can be the case".

Example (3 men, 3 women). Preferences, best first:

  • Men: M0: W X Y; M1: Y W X; M2: W Y X.
  • Women: W: M1, M2, M0; X: M2, M1, M0; Y: M2, M0, M1.

Here w = W, m = M2, m′ = M0, and the man she truly prefers to both is m″ = M1.

Truthful run (men propose).

  1. M0→W, M1→Y, M2→W. W holds M2 (she likes M2 more than M0) and rejects M0. Y holds M1.
  2. M0→X. X holds M0.
  3. Result: W–M2, Y–M1, X–M0. W gets her second choice.

Lying run: W reports M1, M0, M2 (swapped M2 and M0).

  1. M0→W, M1→Y, M2→W. Now W prefers M0 to M2, so she keeps M0 and rejects M2. Y holds M1.
  2. M2 proposes to Y. Y prefers M2 to M1, so Y drops M1.
  3. M1 proposes to W (his next choice). W's list has M1 first, so she takes M1 and rejects M0.
  4. M0→X. X holds M0.
  5. Result: W–M1, Y–M2, X–M0. W now has M1, her true first choice, better than both M2 and M0.

Why it works. The lie made W reject M2 early. M2 then "bumped" M1 off Y, and M1 came back to W. A woman can use her list to steer which men are free to propose to her.

Where marks go

  • Say clearly "yes" and give a concrete instance, with both runs written out.
  • Honest limit: I tested many random small instances by computer (not a proof). The swap helps only when her true partner is m or lies between m and m′. If her true partner is better than both, or is m′ or worse, swapping the two cannot help. Do not claim more than the example.
  • Contrast: for men, truth-telling is a dominant strategy (the man-optimal matching gives each man his best stable partner).

No chapter covers Gale-Shapley; the answer above is self-contained.

Q3(c) · 15 marks

Jack Straws: In the game of Jack Straws, a number of plastic or wooden "straws" are dumped on the table and players try to remove them one by one without disturbing the other straws. Here, we are only concerned with whether various pairs of straws are connected by a path of touching straws. Given a list of the endpoints for n > 1 straws (as if they were dumped on a large piece of graph paper), determine all the pairs of straws that are connected. Note that touching is connecting, but also that two straws can be connected indirectly via other connected straws.

Show answer

Model. Each straw is a vertex. Put an edge between two straws if the two line segments intersect (touching counts). Two straws are connected iff they are in the same connected component.

Method

  1. For every pair \((i,j)\), test whether segments \(i\) and \(j\) intersect (orientation test below). \(O(n^2)\) tests.
  2. Union the two straws in a union-find structure (or build adjacency lists).
  3. Label components with DFS/BFS or read union-find roots.
  4. Report every pair \((i,j)\) with the same component label.
orient(p,q,r) = sign( (q.x-p.x)*(r.y-p.y) - (q.y-p.y)*(r.x-p.x) )   // 0 = collinear

INTERSECT(p1,p2,p3,p4)
 o1 = orient(p1,p2,p3); o2 = orient(p1,p2,p4)
 o3 = orient(p3,p4,p1); o4 = orient(p3,p4,p2)
 if o1 != o2 and o3 != o4 return TRUE            // proper crossing
 if o1 == 0 and onSegment(p1,p2,p3) return TRUE  // touching / collinear overlap
 if o2 == 0 and onSegment(p1,p2,p4) return TRUE
 if o3 == 0 and onSegment(p3,p4,p1) return TRUE
 if o4 == 0 and onSegment(p3,p4,p2) return TRUE
 return FALSE

JACK-STRAWS(S[1..n])
 make-set(i) for all i
 for i = 1 to n-1: for j = i+1 to n
    if INTERSECT(S[i], S[j]) union(i, j)
 for i = 1 to n-1: for j = i+1 to n
    if find(i) == find(j) print (i, j)

Time: \(O(n^2\,\alpha(n))\) for the unions plus \(O(n^2)\) to print, so \(O(n^2)\). onSegment(p,q,r) checks that \(r\) lies within the bounding box of \(p,q\) (valid because \(r\) is already known to be collinear).

Chapter: MST chapter (union-find).

Q4(a) · 15 marks

The edge connectivity of an undirected graph is the minimum number k of edges that must be removed to disconnect the graph. For example, the edge connectivity of a tree is 1, and the edge connectivity of a cyclic chain of vertices is 2. Show how to determine the edge connectivity of an undirected graph G = (V, E) by running a maximum-flow algorithm on at most |V| flow networks, each having O(V) vertices and O(E) edges.

Show answer

Method

  1. Replace each undirected edge \(\{u,v\}\) by two directed edges \((u,v)\) and \((v,u)\), each of capacity 1. The network has \(V\) vertices and \(2E\) edges.
  2. Fix any vertex \(s\).
  3. For every other vertex \(t\), compute the max flow from \(s\) to \(t\). That is \(|V|-1\) flow networks.
  4. Edge connectivity \(k=\min_t \text{maxflow}(s,t)\).
EDGE-CONNECTIVITY(G)
 build N: each undirected edge -> two arcs of capacity 1
 s = any vertex
 k = infinity
 for each t != s
    k = min(k, MAX-FLOW(N, s, t))
 return k

Proof.

  1. Let \((S,V\setminus S)\) be a cut of N with \(s\in S\). Its capacity counts arcs from \(S\) to \(V\setminus S\), which is exactly the number of undirected edges crossing it (each crossing edge contributes one arc in that direction).
  2. Any set of edges whose removal disconnects G separates \(s\) from some vertex \(t\). So the global minimum cut separates \(s\) from some \(t\), and has size \(\ge \text{maxflow}(s,t)\) by max-flow min-cut, so \(\ge \min_t\).
  3. Conversely, for each \(t\), a minimum \(s\)–\(t\) cut is a set of edges whose removal disconnects G, so \(k\le \text{maxflow}(s,t)\) for all \(t\).
  4. Hence \(k=\min_t \text{maxflow}(s,t)\).

Each max flow is at most \(V-1\) (degree of \(s\) is at most \(V-1\)), so Ford-Fulkerson takes \(O(VE)\) per \(t\), \(O(V^2E)\) in total.

Chapter: Max-flow min-cut, Edmonds-Karp.

Q4(b) · 7 marks

What is fixed-parameter tractability? Why is it useful?

Show answer
  1. Definition. A problem with input size \(n\) and a parameter \(k\) is fixed-parameter tractable (FPT) if it can be solved in time \(f(k)\cdot n^{c}\), where \(f\) is any function of \(k\) alone and \(c\) is a constant independent of \(k\).
  2. Example. Vertex cover with parameter \(k\) (is there a cover of size \(\le k\)?) runs in \(O(2^k\cdot n)\): pick an uncovered edge, branch on which endpoint goes in the cover, depth at most \(k\). The input is huge but \(k\) is small.
  3. Why useful. An NP-hard problem is still exponential in general. FPT confines the exponential blow-up to the small parameter and keeps polynomial growth in \(n\). So it is practical when \(k\) is small, for example, a few dozen. Compare \(n^{k}\) (not FPT): the exponent itself grows with \(k\).

Chapter: Approximation algorithms (ways to cope with NP-hard problems).

Q4(c) · 13 marks

In the bottleneck traveling salesperson problem (TSP), we are given an undirected graph G with weights on its edges and asked to find a tour that visits the vertices of G exactly once and returns to the start so as to minimize the cost of the maximum-weight edge in the tour. Assuming that the weights in G satisfy the triangle inequality, design a polynomial-time 3-approximation algorithm for bottleneck TSP.

Show answer

Idea. The heaviest edge of a minimum spanning tree is at most the optimal bottleneck. Then walk the tree in a way that skips at most 2 intermediate vertices, so each tour edge costs at most 3 times that.

Algorithm

  1. Compute an MST \(T\) of G. Let \(b_T\) be its heaviest edge.
  2. Build a Hamiltonian cycle \(H\) in \(T^3\) (the graph joining vertices at tree distance \(\le 3\)), using the lemma below.
  3. Output \(H\).

Claim 1: \(b_T\le b^*\) where \(b^*\) is the optimal bottleneck value.

  1. An optimal tour minus one edge is a spanning tree whose heaviest edge is \(\le b^*\).
  2. An MST minimises the heaviest edge among all spanning trees: if a spanning tree \(T'\) had every edge lighter than \(b_T\), delete the edge \(b_T\) from \(T\); \(T'\) has an edge crossing the resulting cut, lighter than \(b_T\), and swapping it in gives a lighter spanning tree than \(T\), contradiction. So \(b_T\le b^*\).

Claim 2: if \(u,v\) are at tree distance \(\le 3\), then \(w(u,v)\le 3b_T\). The tree path has at most 3 edges, each \(\le b_T\), and the triangle inequality gives \(w(u,v)\le\) path weight \(\le 3b_T\).

So every edge of \(H\) weighs at most \(3b_T\le 3b^*\): a 3-approximation.

Lemma (the cube of a tree is Hamiltonian). For every tree with at least 2 vertices and every tree edge \((u,v)\), \(T^3\) has a Hamiltonian path from \(u\) to \(v\). Proof by induction on the number of vertices.

  1. Base: 2 vertices, the path is \(u,v\).
  2. Remove edge \((u,v)\); this splits \(T\) into \(T_u\ni u\) and \(T_v\ni v\).
  3. If \(T_u\) is a single vertex, take the path "\(u\)" and put \(u'=u\). Otherwise \(u\) has a neighbour \(u'\) in \(T_u\), and by induction \(T_u^3\) has a Hamiltonian path from \(u\) to \(u'\). Similarly get a path \(v'\ \dots\ v\) in \(T_v^3\).
  4. Join them: go \(u\leadsto u'\), jump \(u'\to v'\), go \(v'\leadsto v\). The jump is legal: \(u'-u-v-v'\) has length 3, so \(u'v'\in T^3\).
  5. This is a Hamiltonian path from \(u\) to \(v\). Because \((u,v)\) is a tree edge, \(vu\in T^3\) closes it into a Hamiltonian cycle.

Time: MST \(O(E\log V)\) plus the recursion \(O(V)\). Polynomial.

Chapter: Approximation algorithms.

Q5(a) · 10 marks

A friend of you claims that it is possible to implement Find-Min operation in a Binomial Min Heap in O(1) time using the idea of Fibonacci Min Heap. Justify his claim with proper explanation.

Show answer

The claim is true. A Fibonacci heap keeps a pointer H.min to the smallest root. Do the same in a binomial heap.

  1. The minimum key of a binomial heap is always a root (heap order in every tree). So storing min is enough.
  2. Find-min: return H.min. \(O(1)\).
  3. Insert / union: after the usual work, compare the old min(s) with each other. \(O(1)\) extra work.
  4. Decrease-key: after bubbling up, if the new key is smaller than min.key, update min. \(O(1)\) extra.
  5. Extract-min: remove min, merge its children as usual, then rescan the root list (at most \(\lfloor\log n\rfloor+1\) roots) to find the new minimum. \(O(\log n)\), the same order as extract-min already costs, so the bound is unchanged.

So find-min drops from \(O(\log n)\) (scan the root list) to \(O(1)\) with no change to the other bounds.

Chapters: Binomial heap operations, Fibonacci heap.

Q5(b) · 5 + 10 = 15 marks

Prove that the expected space usage of a skip list having n items is O(n). Perform the following operations on the given skip list sequentially: (i) Insert key = 17 where i = 2; (ii) Insert key = 25 where i = 4; (iii) Delete key = 25. Show all the steps and the resulting skip lists.

Figure data (read from scan): h = 3, n = 4. S3: −∞, +∞. S2: −∞, 15, +∞. S1: −∞, 15, 23, +∞. S0: −∞, 10, 15, 23, 36, +∞.

Show answer

Proof of \(O(n)\) expected space.

  1. When a key is inserted, it is promoted to the next level with probability \(1/2\) (coin flip). So the key appears at level \(i\) with probability \(1/2^{i}\).
  2. Let \(X_i\) be the number of keys at level \(i\). \(E[X_i]=n/2^{i}\).
  3. Expected total nodes \(=\sum_{i\ge0}E[X_i]=n\sum_{i\ge0}2^{-i}\le 2n\).
  4. The sum used linearity of expectation (\(X_i\) are dependent, that does not matter). The two sentinels per level add \(2h\). Level \(i\) is non-empty with probability \(\le\min(1,n/2^i)\), so \(E[h]\le\log_2 n+2\). So the expected space is \(\le 2n+O(\log n)=O(n)\).

Operations. Here "i" is the number of heads: the key is stored in \(S_0,\dots,S_i\). Insert: walk down from the top-left, keep the last node visited on each level (the predecessor), then splice the key in after the predecessor on levels \(0..i\).

(i) Insert 17, i = 2. Search path (predecessors): S3: −∞, S2: 15, S1: 15, S0: 15. Insert 17 after 15 in S0, S1, S2.

S3: -inf ----------------------------------------- +inf
S2: -inf ------ 15 -- 17 ------------------------- +inf
S1: -inf ------ 15 -- 17 -- 23 ------------------- +inf
S0: -inf -- 10 -- 15 -- 17 -- 23 -- 36 ------------ +inf

Q5(c) · 5 marks

Describe how Fibonacci numbers are related to Fibonacci Heaps.

Show answer
  1. Let \(x\) be a node of degree \(k\) in a Fibonacci heap. Order its children by the time they were linked to \(x\): \(y_1,\dots,y_k\).
  2. When \(y_i\) was linked, \(x\) already had \(i-1\) children, and linking only happens between roots of equal degree, so \(y_i\) had degree \(\ge i-1\) then. Since then it lost at most 1 child (a second loss would have cut it). So \(\deg y_i\ge i-2\).
  3. Let \(s_k\) be the minimum size of a subtree whose root has degree \(k\). Then \(s_k\ge 2+\sum_{i=2}^{k}s_{i-2}\), which gives \(s_k\ge F_{k+2}\) (the \((k+2)\)-th Fibonacci number: \(F_0=0,F_1=1\)).
  4. \(F_{k+2}\ge\phi^{k}\) with \(\phi=(1+\sqrt5)/2\). So \(n\ge\phi^{k}\), hence the maximum degree is \(D(n)\le\log_\phi n=O(\log n)\).
  5. This bound is why extract-min's consolidation touches only \(O(\log n)\) degrees, giving \(O(\log n)\) amortized extract-min.

Q5(d) · 5 marks

In one approach to solve the Traveling Salesman Problem using branch-and-bound technique, the lower bound of the cost of completing a partial tour has been calculated from the cost of the minimum spanning tree spanning the remaining nodes of the graph. Decide whether this bound function will give correct answer all the time, with proper explanation. If there is any better bound function for this problem, mention it.

Show answer
  1. Yes, it is a valid lower bound (it never overestimates), provided weights are non-negative. Branch and bound only needs the bound to be \(\le\) the true best completion cost, so pruning never throws away the optimum.
  2. Reason: whatever completion we choose, the remaining part of the tour visits all remaining nodes. Remove the two edges that join the remaining nodes to the end of the partial tour and to the start. What is left is a path through all remaining nodes: a spanning tree of them. Its cost is \(\ge\) MST(remaining nodes).
  3. So \(\text{bound}=\text{cost(partial tour)}+\text{MST(remaining)}\le\) true cost of every completion.
  4. It is weak, because it ignores the two connecting edges. Better bounds: add the cheapest edge from the current end to a remaining node and the cheapest edge from a remaining node back to the start; or use the 1-tree bound (MST on all but one vertex plus the two cheapest edges at that vertex), or the Held-Karp (1-tree with penalties) bound; or, for each city, half the sum of its two cheapest edges.

Q6(a) · 5 + 10 = 15 marks

Define the rank of a node of a splay tree. Prove that the change in potential of a splay tree not resulting from any splay after an insertion operation is O(log n), where the splay tree had n nodes before the insertion operation.

Show answer

Definitions (5 marks).

  • Size \(s(x)\) = number of nodes in the subtree rooted at \(x\) (including \(x\)).
  • Rank \(r(x)=\log_2 s(x)\).
  • Potential \(\Phi(T)=\sum_{x}r(x)\).

Proof (10 marks). Insert the new key \(z\) as a leaf, before splaying. Let \(y_1,y_2,\dots,y_d\) be the ancestors of \(z\) (\(y_1\) its parent, \(y_d\) the root), with sizes \(s_1,\dots,s_d\) before the insertion.

  1. Only the ancestors change size, each by +1. The new leaf has \(s(z)=1\), so \(r(z)=0\). Nothing else changes.
  2. \(\Delta\Phi=\sum_{i=1}^{d}\big[\log_2(s_i+1)-\log_2 s_i\big]=\sum_{i=1}^{d}\log_2\!\Big(1+\frac1{s_i}\Big)\).
  3. Each \(y_{i+1}\) contains \(y_i\)'s subtree plus \(y_{i+1}\) itself, so \(s_{i+1}\ge s_i+1\). Also \(s_1\ge1\). Hence \(s_i\ge i\).
  4. So \(\Delta\Phi\le\sum_{i=1}^{d}\log_2\frac{i+1}{i}=\log_2\prod_{i=1}^{d}\frac{i+1}{i}=\log_2(d+1)\). The product telescopes.
  5. \(d\le n\), so \(\Delta\Phi\le\log_2(n+1)=O(\log n)\). \(\blacksquare\)

The splay that follows is charged separately by the access lemma (amortized \(3(r(\text{root})-r(z))+1\)).

Q7(b) · 7 + 3 = 10 marks

Using an example, show that if a problem is in NP, the complement of that problems is in co-NP. Draw the general consensus regarding P, NP and co-NP in a Venn diagram.

Show answer
  1. Definition. A problem \(L\) is in co-NP iff its complement \(\overline L\) (swap yes and no) is in NP. So "the complement of an NP problem is in co-NP" is the definition applied to \(\overline{\overline L}=L\).
  2. Example. SAT is in NP: a yes-instance has a short certificate (a satisfying assignment, checked in polynomial time). Its complement UNSAT ("no assignment satisfies the formula") is therefore in co-NP. Its no-instances (satisfiable formulas) are exactly the ones with a short certificate.
  3. Similarly TAUTOLOGY (true under all assignments) is in co-NP: its complement "some assignment falsifies the formula" has a short certificate.

Venn diagram (consensus). P sits inside the overlap of NP and co-NP. NP-complete problems are in NP but believed not in co-NP. TAUTOLOGY-type problems are in co-NP but believed not in NP. It is open whether NP = co-NP and whether P = NP ∩ co-NP.

Q7(c) · 10 marks

You are given the task to implement the hash table data structure for a new programming language. You may use either separate chaining or open addressing. In open addressing, there are various options for probing. Explain your choice precisely with proper justification.

Show answer

Choice: separate chaining for a general-purpose language table; if open addressing is demanded, double hashing. State one and defend it with concrete reasons.

  1. Chaining. Never "full": the load factor \(\alpha\) may exceed 1 and expected search is \(\Theta(1+\alpha)\) under simple uniform hashing. Deletion is trivial (unlink). Degrades gracefully with a bad load estimate. Cost: pointer memory and cache misses.
  2. Open addressing. Better cache behaviour and no pointers, but needs \(\alpha<1\), resizing, and deletion needs tombstones.
  3. Probing options.
    • Linear: best cache locality, but primary clustering (long runs build up) and expected probes blow up as \(\alpha\to1\).
    • Quadratic: removes primary clustering, still has secondary clustering (keys with the same hash follow the same sequence). Visits only about half the slots unless \(m\) is prime and \(\alpha<1/2\).
    • Double hashing: \(h(k,i)=(h_1(k)+i\,h_2(k))\bmod m\). Different keys get different step sizes, so almost no clustering; it approximates uniform hashing. Needs \(h_2(k)\) coprime to \(m\) (e.g. \(m\) prime, \(h_2(k)=1+(k\bmod(m-1))\)) so the sequence covers every slot.
  4. Decision. For a language runtime: chaining for the general dictionary (robust to bad hash functions and deletions). When memory/cache matters: open addressing with double hashing, \(m\) prime, resize at \(\alpha\approx0.7\).

Q7(d) · 5 marks

Mr. X has proposed a new algorithm for insertion to a Red-Black tree, where the color of the newly inserted node is set to black by default. Discuss the advantages and disadvantages of this algorithm over the traditional algorithm followed for insertion to a Red-Black tree.

Show answer

Advantage (only one): a black node can never create a red-red violation, so the "red parent" cases (1, 2, 3) disappear.

Disadvantages (these decide it):

  1. A new black node adds 1 to the black height of every path through it. The new leaf replaces a NIL on one path, so that path now has one more black than all the others. Property 5 is always broken (unless the tree was empty), so every insertion needs a fix-up.

So: no benefit, and it makes the cheap case expensive.

Q8(c) · 5 marks

Explain how we can prove that an optimization problem is NP-complete.

Show answer
  1. NP-completeness is defined for decision problems (yes/no). So first turn the optimization problem into its decision version: "is there a solution of value \(\le k\)" (minimization) or "\(\ge k\)" (maximization). Example: TSP becomes "is there a tour of cost \(\le k\)".
  2. Show the decision version is in NP: a certificate (the solution itself) can be checked in polynomial time, including that its value meets \(k\).
  3. Show it is NP-hard: reduce a known NP-complete problem to it in polynomial time (yes-instances map to yes-instances and no-instances to no-instances).
  4. Then the decision version is NP-complete and the optimization problem is NP-hard: if we could optimize in polynomial time, we could decide by comparing the optimum with \(k\).
