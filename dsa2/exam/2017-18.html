Q1(a) · 3 + 5 + 7 = 15 marks

What is a spanning tree of a graph? Write Kruskal's algorithm for finding a minimum spanning tree of an edge-weighted graph. Analyze the time complexity of the algorithm by suggesting data structures for efficient implementation of the algorithm.

Show answer

Spanning tree (3). For a connected undirected graph \(G=(V,E)\), a spanning tree is a subgraph \(T=(V,E_T)\), \(E_T\subseteq E\), that is connected and acyclic. It has exactly \(|V|-1\) edges and reaches every vertex. A minimum spanning tree has the least total edge weight.

Kruskal (5).

KRUSKAL(G, w)
 A = empty
 for each v in V: MAKE-SET(v)
 sort E by weight w, nondecreasing
 for each edge (u,v) in sorted order
    if FIND-SET(u) != FIND-SET(v)      // different components: no cycle
        A = A union {(u,v)}
        UNION(u, v)
 return A

Complexity with data structures (7).

  1. Sorting the edges: \(O(E\log E)=O(E\log V)\) (since \(E\le V^2\), \(\log E\le2\log V\)). Use heap sort or merge sort, or a heap of edges.
  2. Disjoint-set forest with union by rank and path compression: \(V\) MAKE-SETs and up to \(2E\) FIND-SETs and \(V-1\) UNIONs cost \(O((V+E)\,\alpha(V))\), where \(\alpha\) grows slower than \(\log\).
  3. Total: \(O(E\log V)\), dominated by the sort. (With a plain array/list for components, each union costs \(O(V)\), giving \(O(E\log E+V^2)\); the DSU removes that.)
  4. If the weights are small integers, counting sort makes the sort \(O(E)\) and the total \(O(E\,\alpha(V))\).

Q1(c) · 10 marks

Let G be a weighted connected graph and let V1 and V2 be a partition of the vertices of G into two disjoint non-empty sets. Let e be an edge in G with minimum weight among those edges with one endpoint in V1 and the other in V2. Then show that there is a minimum spanning tree T of G containing e.

Show answer

Proof (cut-and-paste / exchange). Let \(T\) be any MST. If \(e\in T\) we are done. Otherwise:

  1. Write \(e=(u,v)\) with \(u\in V_1\), \(v\in V_2\). \(T\) is a spanning tree, so it has a unique path \(P\) from \(u\) to \(v\), and \(P+e\) is a cycle.
  2. \(P\) starts in \(V_1\) and ends in \(V_2\), so some edge \(f=(x,y)\) of \(P\) has \(x\in V_1\), \(y\in V_2\): \(f\) crosses the cut. \(f\in T\) (it is on \(P\)) and \(f\ne e\) (because \(e\notin T\)).
  3. \(e\) is a minimum-weight crossing edge, so \(w(e)\le w(f)\).
  4. Let \(T'=T-f+e\). Removing \(f\) splits \(T\) into two components, \(A\ni x\) and \(B\ni y\). \(P\) is the only \(u\)-\(v\) path in \(T\) and it uses \(f\), so in \(T-f\) the vertices \(u\) and \(v\) are not connected: one is in \(A\), the other in \(B\). So \(e\) joins \(A\) and \(B\), \(T'\) is connected, and it has \(|V|-1\) edges, so \(T'\) is a spanning tree.
  5. \(w(T')=w(T)-w(f)+w(e)\le w(T)\). Since \(T\) is minimum, \(w(T')=w(T)\), so \(T'\) is an MST.
  6. \(T'\) contains \(e\). \(\blacksquare\)

This is the cut property, the correctness core of both Kruskal and Prim.

Q2(a) · 3 + 3 = 6 marks

Define a flow network. What is an augmenting path in a flow network? Explain with illustrative examples.

Show answer

Flow network (3). A directed graph \(G=(V,E)\) with a non-negative capacity \(c(u,v)\ge0\) on each edge, a source \(s\) and a sink \(t\). A flow \(f\) satisfies: capacity constraint \(0\le f(u,v)\le c(u,v)\) and flow conservation at every vertex other than \(s,t\) (flow in = flow out). Its value is the net flow out of \(s\).

Augmenting path (3). A path \(s\to t\) in the residual network \(G_f\). \(G_f\) has an edge \((u,v)\) with residual capacity \(c(u,v)-f(u,v)\) when there is room to push more, and a backward edge \((v,u)\) with capacity \(f(u,v)\) when flow can be cancelled. Pushing the bottleneck (the minimum residual capacity on the path) along it increases the flow value. A flow is maximum iff there is no augmenting path.

Example. Network: s→a 3, s→b 2, a→b 1, a→t 2, b→t 3.

  1. Zero flow. Path s→a→t has residual capacities 3, 2: bottleneck 2. Push 2. Flow value 2.
  2. Residual now: s→a 1, a→t 0, backward t→a 2, a→s 2. Path s→a→b→t: capacities 1, 1, 3: bottleneck 1. Push 1. Flow value 3.
  3. Path s→b→t: capacities 2, 2 (b→t has 3−1=2 left): bottleneck 2. Push 2. Flow value 5. Out of s: 3+2 = 5 = all source edges saturated: maximum.

A path that uses a backward edge (undoing earlier flow) is also augmenting. That is why greedy path-by-path pushing does not get stuck.

Chapter: Flow networks, residuals, Ford-Fulkerson.

Q2(c) · 10 marks

Describe the minimum path length augmentation method of Edmonds and Karp and explain how this method improves the time complexity of Ford-Fulkerson algorithm.

Show answer

The method. Edmonds-Karp is Ford-Fulkerson where the augmenting path is always a shortest path (fewest edges) in the residual network, found by BFS from \(s\).

EDMONDS-KARP(G, s, t)
 f = 0 on every edge
 loop
    BFS from s in the residual network G_f      // O(E)
    if t not reached: return f
    P = the BFS path;  b = min residual capacity on P
    push b along P (update forward and backward residuals)

Why it improves the complexity.

  1. Plain Ford-Fulkerson with arbitrary paths takes \(O(E\cdot|f^*|)\) with integer capacities. This depends on the flow value, which can be huge. With irrational capacities it may never terminate.
  2. Key lemma: with shortest augmenting paths, the BFS distance \(\delta_f(s,v)\) of every vertex never decreases from one augmentation to the next.
  3. Each augmentation saturates at least one critical edge (the bottleneck). An edge \((u,v)\) can be critical again only after the distance of \(u\) has grown by at least 2 (it must be reversed first, then used again). Proof: when \((u,v)\) is critical, \(\delta(v)=\delta(u)+1\) and the edge leaves \(G_f\). It returns only when \((v,u)\) is on a later shortest path, so then \(\delta'(u)=\delta'(v)+1\ge\delta(v)+1=\delta(u)+2\) (distances never decrease). Distances are at most \(V-1\), so each edge is critical \(O(V)\) times.
  4. There are \(E\) edges (and their reverses), so the number of augmentations is \(O(VE)\).
  5. Each augmentation costs \(O(E)\) (BFS). Total \(O(VE^2)\), independent of the capacities.

Chapter: Max-flow min-cut, Edmonds-Karp.

Q2(d) · 9 marks

The strength of a path in an edge-weighted graph G is defined as the minimum weight in the edges that make up the path. The all pair strongest path problem asks to find the strongest path between every pair of vertices in the graph G. Design an algorithm to solve the all pair strongest path problem.

Show answer

Idea. This is all-pairs shortest paths with the operations changed: "+" becomes min, "min" becomes max. Floyd-Warshall works unchanged in structure.

ALL-PAIRS-STRONGEST(W)            // n x n
 S[i][j] = w(i,j) if edge exists, else -INFINITY (no path);  S[i][i] = INFINITY
 for k = 1 to n
   for i = 1 to n
     for j = 1 to n
        S[i][j] = max( S[i][j],  min(S[i][k], S[k][j]) )
 return S
  1. Let \(S^{(k)}[i][j]\) be the strength of the strongest path from \(i\) to \(j\) using only intermediate vertices from \(\{1..k\}\).
  2. A strongest path using \(\{1..k\}\) either avoids \(k\) (strength \(S^{(k-1)}[i][j]\)) or passes through \(k\) once, as an \(i\leadsto k\) part and a \(k\leadsto j\) part, each using only \(\{1..k-1\}\). Its strength is the minimum of the two parts, and to be strongest each part should itself be strongest: \(\min(S^{(k-1)}[i][k],S^{(k-1)}[k][j])\).
  3. Take the maximum of the two cases. That is the recurrence above. No cycle can improve a path (a cycle can only lower or keep the minimum), so one pass over \(k\) is enough.
  4. Time \(\Theta(n^3)\), space \(\Theta(n^2)\). To recover the path, keep a predecessor matrix as in Floyd-Warshall.

Question 3

Q3(a) · 5 marks

How do we cope with hard problems? Discuss.

Show answer

For an NP-hard problem no polynomial algorithm is known, so we give up one of: exactness, generality, or worst-case speed.

  1. Exact exponential algorithms with pruning: backtracking and branch-and-bound explore the state-space tree and cut off hopeless branches. Fast on many inputs, exponential in the worst case. (Knapsack, TSP, Hamiltonian circuit.)
  2. Approximation algorithms: polynomial time with a guaranteed ratio \(\rho\) to the optimum. (Vertex cover: 2. Metric TSP: 2 via MST. Set cover: \(\ln n\).)
  3. Randomized algorithms: good answer with high probability or expected time. (Monte Carlo, Las Vegas.)
  4. Heuristics and local search: no guarantee, often good in practice (greedy, simulated annealing, genetic algorithms).
  5. Special cases: restrict the input so it becomes easy (trees, small parameter, planar). Fixed-parameter algorithms: \(f(k)\cdot n^{c}\), exponential only in a small parameter \(k\).
  6. Dynamic programming over subsets where \(n\) is small (Held-Karp TSP in \(O(n^22^n)\)).

Chapter: P, NP, co-NP, NP-complete.

Q3(d) · 2 + 3 + 5 = 10 marks

Discuss the approximability of the general Traveling Salesperson Problem (TSP). Give an approximation algorithm for the Euclidean TSP problem and compute the approximation ratio of your algorithm.

Show answer

General TSP (2 marks): no constant-factor approximation unless P = NP.

  1. Suppose a polynomial \(\rho\)-approximation for general TSP exists (any constant \(\rho\ge1\)).
  2. Given a graph \(G\) with \(n\) vertices, build a complete graph: weight 1 on edges of \(G\) and weight \(\rho n+1\) on non-edges.
  3. If \(G\) has a Hamiltonian cycle, the optimum tour costs \(n\), and the algorithm returns a tour of cost \(\le\rho n\).
  4. If \(G\) has none, every tour uses a non-edge, costing at least \((\rho n+1)+(n-1)>\rho n\).
  5. So "answer yes iff the returned tour costs \(\le\rho n\)" decides Hamiltonian cycle; the construction is \(O(n^2)\), so this is polynomial. Hamiltonian cycle is NP-complete, so P = NP. Hence no \(\rho\)-approximation (unless P = NP).

Euclidean TSP algorithm (3 marks): MST preorder (the distances satisfy the triangle inequality).

Algorithm

  1. Compute a minimum spanning tree \(T\) of the complete graph on the points.
  2. Walk \(T\) in depth-first preorder from any root.
  3. Output the preorder list as a tour, returning to the root.

Ratio 2 (5 marks).

  1. Let \(OPT\) be the optimal tour. Removing one edge from \(OPT\) leaves a Hamiltonian path, which is a spanning tree. Weights are non-negative and \(T\) is minimum, so \(w(T)\le OPT\).
  2. The full DFS walk of \(T\) traverses every tree edge twice: cost \(2w(T)\).
  3. The preorder tour is the full walk with repeated vertices skipped. By the triangle inequality, a shortcut never costs more than the path it replaces. So the tour costs \(\le2w(T)\).
  4. Cost \(\le2w(T)\le2\cdot OPT\). The ratio is 2. \(\blacksquare\)

Better: Christofides (MST + minimum perfect matching on the odd-degree vertices + Euler tour) gives ratio 3/2 for metric TSP.

Q4(a) · 3 + 7 = 10 marks

What do you mean by X ≤P Y? Show that vertex cover problem ≤P set cover problem.

Show answer

Meaning (3). \(X\le_pY\) means there is a polynomial-time algorithm that turns any instance \(x\) of \(X\) into an instance \(f(x)\) of \(Y\) such that \(x\) is a yes-instance of \(X\) iff \(f(x)\) is a yes-instance of \(Y\). So \(Y\) is at least as hard as \(X\): a polynomial algorithm for \(Y\) gives one for \(X\), and a hardness proof for \(X\) transfers to \(Y\).

Vertex Cover \(\le_p\) Set Cover (7). Instance: graph \(G=(V,E)\), integer \(K\) (is there a vertex cover of size \(\le K\)?).

  1. Universe \(U=E\), the set of edges.
  2. For each vertex \(v\), the set \(S_v=\{e\in E: v\text{ is an endpoint of }e\}\).
  3. Set cover bound \(k=K\). Built in \(O(V+E)\) time.
  4. (⇒) If \(C\) is a vertex cover with \(|C|\le K\), the sets \(\{S_v:v\in C\}\) are at most \(K\) sets, and every edge is in some \(S_v\) because it has an endpoint in \(C\). They cover \(U\).
  5. (⇐) If at most \(K\) sets \(S_v\) (\(v\in C\)) cover \(E\), every edge has an endpoint in \(C\), so \(C\) is a vertex cover of size \(\le K\).
  6. So \(G\) has a vertex cover of size \(\le K\) iff the set cover instance is a yes-instance. \(\blacksquare\)

Q4(b) · 3 + 7 = 10 marks

Define the satisfiability problem. Show that the independent set problem in NP-hard by reducing the 3-SAT problem to the independent set problem.

Show answer

Definition (3). SAT: given a Boolean formula in conjunctive normal form (an AND of clauses, each an OR of literals), is there a truth assignment to the variables that makes the formula true? 3-SAT: every clause has exactly 3 literals. 3-SAT is NP-complete.

3-SAT \(\le_p\) Independent Set (7). Given a 3-SAT formula \(\varphi\) with \(m\) clauses.

Construction

  1. For each clause \(C_i=(l_{i1}\vee l_{i2}\vee l_{i3})\), make a triangle: three vertices (one per literal), all three joined by edges.
  2. Join every vertex labelled \(x\) with every vertex labelled \(\overline x\) (in other clauses): a conflict edge.
  3. Ask for an independent set of size \(K=m\).

Correctness.

  1. (⇒) If \(\varphi\) is satisfiable, take a satisfying assignment and pick one true literal from each clause (at least one exists). That is \(m\) vertices, one per triangle, so no triangle edge joins two of them. Two picked vertices cannot be \(x\) and \(\overline x\) (both true is impossible), so no conflict edge joins them. The set is independent, of size \(m\).
  2. (⇐) If there is an independent set \(I\) of size \(m\): each triangle contributes at most one vertex (the triangle's edges), and there are \(m\) triangles, so exactly one vertex per triangle. Set each chosen literal true. This is consistent: \(x\) and \(\overline x\) are never both chosen (conflict edge). Set remaining variables arbitrarily. Every clause has a true literal, so \(\varphi\) is satisfied.
  3. The graph has \(3m\) vertices and polynomial many edges: built in polynomial time.
  4. Independent Set is in NP (certificate: the set, check pairs). Since 3-SAT \(\le_p\) IS and 3-SAT is NP-hard, IS is NP-hard (so NP-complete). \(\blacksquare\)

Q4(c) · 3 + 7 = 10 marks

Give an approximation algorithm of the set cover problem and compute the approximation ratio of your algorithm.

Show answer

Greedy algorithm (3).

GREEDY-SET-COVER(U, S1..Sm)
 C = empty;  R = U              // R = still uncovered
 while R not empty
    pick the set S_i that covers the most elements of R
    C = C union {S_i};  R = R minus S_i
 return C

Ratio \(H_n\le1+\ln n\) (7). Let the optimum use \(k\) sets, and let \(n=|U|\).

  1. Give each element a price: when greedy picks a set that covers \(t\) new elements, each of those \(t\) elements is priced \(1/t\). The total price of all elements equals the number of sets greedy picked.
  2. Number the elements \(e_1,\dots,e_n\) in the order they get covered. When \(e_j\) is covered, at least \(n-j+1\) elements are still uncovered (counting \(e_j\)).
  3. The optimal \(k\) sets cover all those uncovered elements, so some optimal set covers at least \((n-j+1)/k\) of them.
  4. Greedy takes the set covering the most new elements, which is at least that many. So \(e_j\) is priced \(\le\frac{k}{n-j+1}\).
  5. Total \(=\sum_{j=1}^n\text{price}(e_j)\le k\sum_{j=1}^n\frac1{n-j+1}=k\,H_n\le k(1+\ln n)\).
  6. So greedy uses at most \(H_n\cdot OPT\) sets: an \(O(\log n)\)-approximation. \(\blacksquare\)

This ratio is essentially best possible unless P = NP.

Q4(d) · 5 marks

Your friend claims that he has developed a polynomial time algorithm to solve the set-packing problem. What will happen if his claim is proved to be true?

Show answer
  1. Set packing (given sets and a number \(k\), are there \(k\) pairwise disjoint sets?) is NP-complete. It is in NP (check disjointness), and independent set reduces to it (vertices become sets of their incident edges; two vertices are non-adjacent iff the sets are disjoint).
  2. If a polynomial algorithm for it exists, then every problem in NP reduces to it in polynomial time and is solved in polynomial time.
  3. So P = NP: SAT, TSP (decision), vertex cover, knapsack and thousands of others would all be polynomial. This would be among the biggest results in computer science, and would break most public-key cryptography.
  4. Almost everyone believes P ≠ NP, so the claim is almost certainly wrong or the "algorithm" has a bug.

Question 5

Q5(a) · 12 marks

Prove that a tree with n nodes and the property that the heights of the two children of any node differ by at most 1 has O(log n) height.

Show answer

Convention: height of a leaf = 0. Let \(N(h)\) be the minimum number of nodes in such a tree of height \(h\).

  1. \(N(0)=1\), \(N(1)=2\).
  2. \(N\) is increasing: a tree of height \(h\) contains, as a proper subtree, a tree of height \(h-1\) with the same property, so \(N(h)>N(h-1)\).
  3. A tree of height \(h\ge2\) has a root and one child subtree of height exactly \(h-1\); the other has height \(h-1\) or \(h-2\) (they differ by at most 1). Every subtree has the same property. To minimise, take the other subtree of height \(h-2\) (\(N\) is increasing) and make both subtrees minimal. So \(N(h)=1+N(h-1)+N(h-2)\).
  4. Since \(N(h-1)>N(h-2)\), \(N(h)>2N(h-2)\).
  5. Unrolling: \(N(h)>2N(h-2)>4N(h-4)>\dots>2^{\lfloor h/2\rfloor}N(h-2\lfloor h/2\rfloor)\ge2^{\lfloor h/2\rfloor}\).
  6. So \(n\ge N(h)>2^{h/2-1}\), hence \(h<2\log_2n+2\), i.e. \(h=O(\log n)\). \(\blacksquare\)

Sharper (optional). \(N(h)=F_{h+3}-1\) with \(F_n\) the Fibonacci numbers, and \(F_n\approx\phi^n/\sqrt5\), so \(h\le1.44\log_2n\).

Q6(d) · 5 marks

What is the main objective of splay trees? Do splay trees explicitly try to balance the height?

Show answer
  1. Main objective: make any sequence of \(m\) operations (search, insert, delete) cost \(O(m\log n)\) in total, i.e. \(O(\log n)\) amortized per operation, without storing any balance information. It is a self-adjusting BST: every access moves the accessed node to the root by splaying.
  2. Bonus: frequently accessed items stay near the root (the working-set / static-optimality behaviour), so it adapts to the access pattern.
  3. Does it balance the height? No. There is no height or colour field and no rule that restores balance. A single operation can cost \(O(n)\) (the tree can be a chain, as in the figure of Q6(a): inserting sorted keys gives a chain).
  4. Balance appears only indirectly: splaying a deep node roughly halves the depth of the nodes on its path. The amortized analysis (potential \(\sum\log\text{size}\)) pays for the occasional expensive access.

Q7(b) · 5 marks

Prove that there are kCi nodes at depth i in a binomial tree Bk.

Show answer

Let \(D(k,i)\) be the number of nodes at depth \(i\) in \(B_k\). Claim \(D(k,i)=\binom ki\).

  1. Base: \(B_0\) is one node: \(D(0,0)=1\), \(D(0,i)=0\) for \(i>0\), matching \(\binom0i\).
  2. Hypothesis: \(D(k-1,j)=\binom{k-1}j\) for all \(j\).
  3. Step: \(B_k\) is two \(B_{k-1}\)'s with one root made a child of the other. Depths in the top copy are unchanged; every node of the attached copy goes one level deeper (its root is now at depth 1). So a node at depth \(i\) is a depth-\(i\) node of the top copy or a depth-\((i-1)\) node of the attached one.
  4. \(D(k,i)=\binom{k-1}i+\binom{k-1}{i-1}=\binom ki\) by Pascal's rule, with \(\binom{k-1}{-1}=\binom{k-1}{k}=0\) covering \(i=0\) and \(i=k\). \(\blacksquare\)

Q7(c) · 10 marks

Under simple uniform hashing, what is the expected number of items that may collide with an element x in a hash table with separate chaining? Assume that there are m separate chains (lists) and n items in the hash table.

Show answer
  1. Simple uniform hashing: each item lands in each of the \(m\) chains with probability \(1/m\), independently.
  2. If \(x\) is one of the \(n\) items: every other item (there are \(n-1\)) collides with \(x\) iff it lands in \(x\)'s chain. Let \(X_y=1\) if item \(y\ne x\) hashes to the same chain as \(x\). \(E[X_y]=1/m\).
  3. By linearity of expectation, \(E[\text{collisions with }x]=\sum_{y\ne x}\frac1m=\frac{n-1}{m}<\alpha\).
  4. If \(x\) is a new key not yet stored: all \(n\) items are candidates: \(E=n/m=\alpha\).
  5. So the expected number of colliding items is \(\frac{n-1}m\) (about the load factor \(\alpha=n/m\)). Hence a search that scans \(x\)'s chain costs \(\Theta(1+\alpha)\). \(\blacksquare\)

Q7(d) · 5 + 5 = 10 marks

(i) "Quadratic probing does not necessarily probe all locations in the hash table" - prove or disprove this statement. (ii) Briefly discuss the concept of perfect hashing.

Show answer

(i) The statement is true.

  1. Probe sequence \(h(k,i)=(h(k)+i^2)\bmod m\) visits slots \(h(k)+(i^2\bmod m)\).
  2. Example: \(m=11\), \(h(k)=0\): squares of \(0..10\) mod 11 are \(0,1,4,9,5,3,3,5,9,4,1\). Only 6 distinct slots \(\{0,1,3,4,5,9\}\) are probed; slots 2, 6, 7, 8, 10 are never reached.
  3. In general, \((i+m)^2\equiv i^2\) and \((m-i)^2\equiv i^2 \pmod m\), so only \(i=0,\dots,\lfloor m/2\rfloor\) give new slots: at most \(\lfloor m/2\rfloor+1

(ii) Perfect hashing (FKS). A scheme for a static set of \(n\) keys that gives \(O(1)\) worst-case lookup with \(O(n)\) space.

  1. Level 1: hash the \(n\) keys into \(m=n\) buckets with a universal hash function. Bucket \(j\) receives \(n_j\) keys.
  2. Level 2: for each bucket give a secondary table of size \(n_j^2\) with its own universal hash function \(h_j\). With size \(n_j^2\), the probability that \(h_j\) causes no collision is at least \(1/2\), so a collision-free \(h_j\) is found after an expected 2 tries.
  3. Space: \(E\big[\sum_jn_j^2\big]<2n\) (the number of colliding pairs is small), so \(O(n)\) expected. Choose the level-1 function again if the sum is more than \(4n\).
  4. Lookup: compute \(h(k)\), then \(h_{h(k)}(k)\): two hash evaluations, no collisions, \(O(1)\) worst case. Limitation: the key set must be known in advance.

Q8(a) · 5 marks

How can BFS be adapted to solve single source shortest path problem in an edge-weighted graph with unequal weights? Explain.

Show answer
  1. BFS finds shortest paths when every edge has the same length, because it visits vertices in order of number of edges.
  2. Adaptation: replace each edge \((u,v)\) of integer weight \(w\) by a chain of \(w\) unit-length edges, adding \(w-1\) dummy vertices. Now every edge has length 1, so BFS from \(s\) gives, for every original vertex, the weighted distance.
  3. Path correctness: dummy vertices only lie on their own chain, so any path between original vertices follows whole chains, and its length equals its weight.
  4. Cost: \(O(V+\sum w)\) = \(O(V+WE)\) for maximum weight \(W\). Good when \(W\) is small (weights 1 to 5 gives linear time). If weights are large or not integers, use Dijkstra instead.
  5. Equivalent bucket form (Dial's algorithm): keep buckets indexed by distance \(0,1,2,\dots\) and scan buckets in order. This is BFS without the dummy vertices.

Q8(b) · 6 + 2 = 8 marks

Explain the intuitive idea behind Bellman-Ford algorithm. How will you detect a negative cycle using Bellman-Ford algorithm?

Show answer

Intuition (6).

  1. A shortest path (with no negative cycle) is simple, so it has at most \(V-1\) edges.
  2. Maintain an estimate \(d[v]\) (start \(d[s]=0\), others \(\infty\)). Relaxing an edge \((u,v)\) means: if \(d[u]+w(u,v)
  3. One pass that relaxes all edges finalises every vertex whose shortest path has 1 edge, because the first edge is relaxed from the correct \(d[s]\). After pass \(k\), all shortest paths with at most \(k\) edges are correct (induction: the last edge of such a path is relaxed from a vertex already correct after pass \(k-1\)).
  4. After \(V-1\) passes every shortest path is correct. It works with negative edges because it never assumes a vertex is "done" (unlike Dijkstra). Time \(O(VE)\).
BELLMAN-FORD(G, w, s)
 d[v] = INF for all v;  d[s] = 0
 repeat |V|-1 times
    for each edge (u,v) in E: if d[u] + w(u,v) < d[v]: d[v] = d[u] + w(u,v)
 for each edge (u,v) in E            // extra pass
    if d[u] + w(u,v) < d[v] return "negative cycle reachable"
 return d

Negative cycle detection (2). Run one more pass (the \(V\)-th). If any edge can still be relaxed, a negative-weight cycle is reachable from \(s\): without a negative cycle, all \(d\) values are already final after \(V-1\) passes, so no relaxation could succeed. Conversely, let \(C=v_0,v_1,\dots,v_k=v_0\) be a reachable cycle with \(w(C)<0\) (all \(d[v_i]\) finite). If no edge could be relaxed, \(d[v_i]\le d[v_{i-1}]+w(v_{i-1},v_i)\) for every \(i\); summing round the cycle, the \(d\) terms cancel and \(0\le w(C)\), a contradiction. So the extra pass reports exactly when a negative cycle is reachable.

Q8(c) · 5 + 5 + 7 + 5 = 22 marks

Write Dijkstra's algorithm for single source shortest path problem. Prove its correctness. Analyze the time complexity of the algorithm. What would be the running time of Dijkstra's algorithm if a Fibonacci heap is used instead of a binary heap.

Show answer

Algorithm (5). Edge weights must be non-negative.

DIJKSTRA(G, w, s)
 for each v: d[v] = INF, pi[v] = NIL
 d[s] = 0;  S = empty;  Q = priority queue of all vertices keyed by d
 while Q not empty
    u = EXTRACT-MIN(Q);  S = S union {u}
    for each v in Adj[u]
       if d[u] + w(u,v) < d[v]          // RELAX
          d[v] = d[u] + w(u,v);  pi[v] = u     // DECREASE-KEY in Q

Correctness (5). Claim: when \(u\) is added to \(S\), \(d[u]=\delta(s,u)\).

  1. Suppose \(u\) is the first vertex added with \(d[u]\ne\delta(s,u)\). \(u\ne s\) and \(d[u]>\delta(s,u)\) (\(d\) never goes below the true distance). A path from \(s\) to \(u\) exists (else \(d[u]=\infty=\delta(s,u)\)). \(s\) is extracted first with \(d[s]=0\), so \(s\in S\) and \(u\ne s\).
  2. Take a shortest path \(P\) from \(s\) to \(u\). It starts in \(S\) and ends outside \(S\), so let \(y\) be the first vertex of \(P\) not in \(S\), and \(x\) its predecessor, \(x\in S\).
  3. \(x\) is correct (\(u\) is the first wrong one), and \((x,y)\) was relaxed when \(x\) was added, so \(d[y]=\delta(s,y)\) (a prefix of a shortest path is shortest).
  4. Weights are non-negative, so \(\delta(s,y)\le\delta(s,u)\le d[u]\).
  5. But \(u\) was extracted before \(y\), so \(d[u]\le d[y]=\delta(s,y)\). Hence \(d[u]=\delta(s,u)\): contradiction. \(\blacksquare\)

Time complexity (7). \(V\) EXTRACT-MINs and at most \(E\) DECREASE-KEYs (one per relaxation).

  • Array: extract-min \(O(V)\), decrease-key \(O(1)\): \(O(V^2+E)=O(V^2)\).
  • Binary heap: both \(O(\log V)\): \(O((V+E)\log V)\), i.e. \(O(E\log V)\) for connected graphs.

With a Fibonacci heap (5). Extract-min is \(O(\log V)\) amortized and decrease-key is \(O(1)\) amortized, so the total is \(O(V\log V+E)\). This is better than the binary heap when the graph is dense (\(E\gg V\)); for sparse graphs they are the same order.
