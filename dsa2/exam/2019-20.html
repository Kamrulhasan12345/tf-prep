Q1(a) · 10 marks

Assuming simple uniform hashing, prove that a successful search in separate chaining requires expected O(1+α) work, where α is the load factor.

Show answer

Setup. \(n\) keys in a table of \(m\) slots, \(\alpha=n/m\). Simple uniform hashing: each key lands in each slot with probability \(1/m\), independently. New keys are inserted at the head of the chain. The searched key is equally likely to be any of the \(n\) stored keys.

  1. Let \(x_1,\dots,x_n\) be the keys in insertion order. Searching for \(x_i\) examines \(x_i\) itself, plus every key inserted after \(x_i\) into the same chain (they sit in front of it).
  2. For \(j>i\), let \(X_{ij}=1\) if \(x_j\) and \(x_i\) hash to the same slot. \(P(X_{ij}=1)=1/m\), so \(E[X_{ij}]=1/m\).
  3. Expected work for a random stored key: \[E\Big[\frac1n\sum_{i=1}^{n}\Big(1+\sum_{j=i+1}^{n}X_{ij}\Big)\Big]=\frac1n\sum_{i=1}^{n}\Big(1+\frac{n-i}{m}\Big)\]
  4. \(\sum_{i=1}^{n}(n-i)=\frac{n(n-1)}2\). So the value is \(1+\frac{n-1}{2m}=1+\frac\alpha2-\frac{\alpha}{2n}\).
  5. Add \(\Theta(1)\) for computing the hash and reaching the slot. Total \(\Theta\big(2+\frac\alpha2-\frac\alpha{2n}\big)=\Theta(1+\alpha)\). \(\blacksquare\)

Q1(b) · 10 marks

Suppose you have invited N people to a dinner, and you asked someone to enter their arrival times into a hash table. Assume that exactly one guest can enter the dinner hall at a particular time. Assuming separate chaining, briefly describe how you can achieve 1+logα expected time for an unsuccessful search, where α is the load factor.

Show answer

Idea. Arrival times are distinct numbers (one guest per time), so they can be ordered. Keep each chain as a balanced BST (or any sorted structure) instead of a linked list.

  1. The hash picks the slot in \(O(1)\).
  2. An unsuccessful search in a balanced BST holding \(L\) keys costs \(O(\log(1+L))\) comparisons (the \(+1\) handles empty chains).
  3. Under simple uniform hashing the chain length \(L\) has \(E[L]=\alpha\). The function \(\log(1+x)\) is concave, so by Jensen's inequality \(E[\log(1+L)]\le\log(1+E[L])=\log(1+\alpha)\).
  4. Expected time \(\le 1+\log(1+\alpha)=O(1+\log\alpha)\) (for \(\alpha\ge1\); for small \(\alpha\) it is \(O(1)\)).

Compare the linked list: \(\Theta(1+\alpha)\). Cost: inserts/deletes become \(O(\log)\) too and the BST needs extra pointers.

Q2(a) · 10 marks

Prove that there are kCi nodes at depth i in a binomial heap Bk of order k.

Show answer

Let \(D(k,i)\) be the number of nodes at depth \(i\) in \(B_k\). Claim: \(D(k,i)=\binom ki\). Induction on \(k\).

  1. Base. \(B_0\) is one node at depth 0: \(D(0,0)=1=\binom00\) and \(D(0,i)=0=\binom0i\) for \(i>0\).
  2. Structure. \(B_k\) is two copies of \(B_{k-1}\): the root of one becomes the (leftmost) child of the root of the other.
  3. Count. A node at depth \(i\) of \(B_k\) is either (a) a node at depth \(i\) of the first \(B_{k-1}\) (the copy that kept the root), or (b) a node at depth \(i-1\) of the copy that was attached (it sits one level lower now).
  4. So \(D(k,i)=D(k-1,i)+D(k-1,i-1)\).
  5. By the hypothesis \(D(k-1,j)=\binom{k-1}j\) for all \(j\), this is \(\binom{k-1}{i}+\binom{k-1}{i-1}=\binom ki\) (Pascal's rule; \(\binom{k-1}{-1}=\binom{k-1}{k}=0\) covers \(i=0\) and \(i=k\)). \(\blacksquare\)

Q2(c) · 8 marks

In the context of Fibonacci heaps, draw the maximally damaged tree of degree 6 (i.e., f6).

Show answer

Definition. A maximally damaged tree \(f_k\) is a tree whose root has degree \(k\) and which has the fewest nodes any such tree can have, \(F_{k+2}\). It is what you get when every child is cut as much as the rules allow.

Construction

  1. Let the root's children be \(y_1,\dots,y_k\) in the order they were linked.
  2. \(y_1\) is a single unmarked leaf (degree 0).
  3. For \(i\ge2\): \(y_i\) was linked with degree \(i-1\) and has lost exactly one child, so it has degree \(i-2\) and is marked. Below it hangs a copy of \(f_{i-2}\).
  4. So \(f_6\) has root with children: a leaf, a marked leaf (\(f_0\)), a marked root of \(f_1\), of \(f_2\), of \(f_3\), of \(f_4\). Sizes \(1,1,2,3,5,8\), total with the root \(=21=F_8\).

Marked nodes are drawn double-circled (here with *). The root is not marked.

Size check: \(|f_k|=1+\sum_{i}|f_{i-2}|+1\) gives \(1,2,3,5,8,13,21\) for \(k=0..6\): the Fibonacci numbers.

On paper: draw the root, then the six children left to right with their degrees 0, 0, 1, 2, 3, 4. Double-circle every child except the first. Write the node count 21.

Q3(a) · 8 marks

Suppose X ∈ NP-complete. Prove that X ∈ P if and only if P = NP.

Show answer
  1. (⇐) Suppose P = NP. X is NP-complete, so \(X\in NP=P\). So \(X\in P\).
  2. (⇒) Suppose \(X\in P\). Take any \(Y\in NP\).
  3. Since X is NP-complete, \(Y\le_p X\): there is a polynomial-time function \(f\) with \(y\in Y\iff f(y)\in X\).
  4. To decide \(y\): compute \(f(y)\) (polynomial time, so \(|f(y)|\) is polynomial in \(|y|\)) and run the polynomial-time algorithm for X on it. Total time polynomial.
  5. So \(Y\in P\). Hence \(NP\subseteq P\). Also \(P\subseteq NP\) always. So P = NP. \(\blacksquare\)

Q3(b) · 12 marks

For a graph G = (V, E), a set S of vertices in G is a vertex cover if every edge e in G has at least one end in S. Given a graph G and a number K, the vertex cover problem asks if G contains a vertex cover of size at most K.

Given a set U of n elements, a collection S1, ..., Sm of subsets of U, and a number k, the set cover problem asks if there exists a collection of at most k of these subsets whose union is equal to U.

Prove that the set cover problem is at least as hard as the vertex cover problem.

Show answer

Show Vertex Cover \(\le_p\) Set Cover.

Reduction (polynomial time)

  1. Input: graph \(G=(V,E)\), number \(K\).
  2. Universe \(U=E\) (the set of edges).
  3. For each vertex \(v\in V\), a subset \(S_v=\{\,e\in E: v\text{ is an endpoint of }e\,\}\).
  4. Set \(k=K\). This is built in \(O(V+E)\) time.

Correctness.

  1. (⇒) If \(C\subseteq V\) is a vertex cover with \(|C|\le K\), then \(\{S_v:v\in C\}\) is a collection of at most \(K\) subsets. Every edge has an endpoint in \(C\), so every edge lies in some chosen \(S_v\). Their union is \(U\).
  2. (⇐) If \(\le k=K\) subsets \(S_v\) (\(v\in C\)) cover \(U=E\), then every edge belongs to some \(S_v\) with \(v\in C\), i.e. has an endpoint in \(C\). So \(C\) is a vertex cover of size \(\le K\).
  3. So G has a vertex cover of size \(\le K\) iff the set cover instance is a yes-instance. Hence any algorithm for set cover solves vertex cover: set cover is at least as hard. \(\blacksquare\)

Q4(b) · 12 marks

Prove or disprove the following two statements.

(i) In an AVL tree, the difference in length between the shortest and the longest paths from the root to the leaves is at most one.

(ii) The minimum number of nodes in an AVL tree with height 5 is 20.

Show answer

(i) False. The balance rule limits the heights of the two subtrees, not the depths of every leaf. Counterexample (an AVL tree, every node has |bf| ≤ 1):

  • Right side: 30 has children 25 (leaf) and 35 (with child 40). The leaf 25 is at depth 2: 20→30→25.
  • Left side: 20→10→6→3→1, leaf 1 at depth 4.
  • Shortest root-to-leaf path = 2 edges, longest = 4 edges: difference 2. So the statement is false.
  • Check the balance: 3 has bf +1, 6 has bf +1, 14 has bf −1, 10 has bf +1, 35 has bf −1, 30 has bf −1, root 20 has bf \(3-2=+1\). All within ±1.

(ii) True (with height of a leaf = 0). Let \(N(h)\) be the minimum number of nodes of an AVL tree of height \(h\). A minimal tree has a root, one minimal subtree of height \(h-1\) and one of height \(h-2\).

  1. \(N(0)=1,\ N(1)=2\).
  2. \(N(h)=N(h-1)+N(h-2)+1\).
  3. \(N(2)=2+1+1=4,\ N(3)=4+2+1=7,\ N(4)=7+4+1=12,\ N(5)=12+7+1=\mathbf{20}\). \(\blacksquare\)

(If a leaf had height 1, the number for "height 5" would be 12. The teacher's convention gives 20, which matches the claim.)

Q5(a) · 13 marks

Given a graph with integer edge weights between 1 and 5 (inclusive), you want to find the shortest weighted path between a pair of vertices. How would you reduce this problem to the shortest unweighted path problem, which can be solved using a Breadth First Search?

Show answer

Reduction

  1. Replace every edge \((u,v)\) of weight \(w\) by a chain of \(w\) unit edges: \(u\to d_1\to d_2\to\dots\to d_{w-1}\to v\), with \(w-1\) new dummy vertices.
  2. Run BFS from \(s\) on the new unweighted graph.
  3. The BFS distance from \(s\) to \(t\) equals the weighted shortest distance in the original graph. Read the path back through parent pointers and delete the dummy vertices.

Why it is correct. A path in the new graph that goes from an original vertex to an original vertex must follow whole chains (dummy vertices have in- and out-degree 1 along their chain). Each chain of an edge of weight \(w\) has exactly \(w\) edges. So paths correspond one to one with original paths, and path length equals path weight.

Size. At most \(4E\) dummy vertices and \(5E\) edges, so \(V'\le V+4E\), \(E'\le5E\). BFS time \(O(V+E)\), which is better than Dijkstra's \(O(E\log V)\) when weights are bounded by a constant. The same idea with weights up to \(W\) gives \(O(V+WE)\).

Q5(b) · 12 marks

Prove that if all edge weights of a graph are positive, then any subset of edges that connects all vertices and has minimum total weight must be a tree. Give an example to show that the same conclusion does not follow if we allow some weights to be nonpositive.

Show answer

Proof.

  1. Let \(F\) be a subset of edges that connects all vertices and has minimum total weight. Suppose \(F\) is not a tree. It is connected, so it contains a cycle \(C\).
  2. Remove any edge \(e\) of \(C\). The rest is still connected: any path that used \(e\) can go around the rest of \(C\).
  3. The new set \(F-e\) connects all vertices and has weight \(w(F)-w(e)<w(F)\), because \(w(e)>0\).
  4. This contradicts the minimality of \(F\). So \(F\) has no cycle, and being connected it is a tree. \(\blacksquare\)

Counterexample for nonpositive weights. Take a triangle with vertices \(a,b,c\) and all three edges of weight \(-1\).

  • Any spanning tree has 2 edges: total \(-2\).
  • The whole triangle connects everything and has total \(-3<-2\). So the minimum-weight connecting subset is the triangle, which has a cycle, so it is not a tree.
  • Even weight 0 breaks "must": with weights 0 the triangle ties with the trees, so a minimum subset need not be a tree.

Q5(c) · 10 marks

The reverse of a directed graph G = (V, E) is another directed graph GR = (V, ER) on the same vertex set, but with all edges reversed; that is, ER = {(v, u) : (u, v) ∈ E}. Give a linear-time algorithm for computing the reverse of a graph in adjacency list format.

REVERSE(G)                       // G given as Adj[1..|V|]

    AdjR[u] = empty list         // O(V)
 for each u in V                 // visit every edge exactly once
    for each v in Adj[u]
       append u to AdjR[v]       // O(1): add u at the head of v's list
 return AdjR
  1. Edge \((u,v)\) is read once while scanning \(Adj[u]\), and produces \((v,u)\) by putting \(u\) into \(AdjR[v]\).
  2. Initialising the lists costs \(\Theta(V)\). Scanning all lists costs \(\Theta(V+E)\). Each insertion is \(O(1)\).
  3. Total \(\Theta(V+E)\), linear in the size of the adjacency list. \(\blacksquare\)

Q6(a) · 15 marks

A new startup FastRoute wants to route information along a path in a communication network, represented as a graph. Each node represents a router and each edge represents a wire between routers. The wires are weighted by the maximum bandwidth they can support. FastRoute comes to you and asks you to develop an algorithm to find the path with maximum bandwidth from any source s to any destination t. As you would expect, the bandwidth of a path is the minimum of the bandwidths of the edges on that path; the minimum edge is the bottleneck. Explain how to modify Dijkstra's algorithm to do this. Justify your answer.

Show answer

Modify three things. Let \(b[v]\) be the best bottleneck found from \(s\) to \(v\).

  1. Initialise \(b[s]=+\infty\) and \(b[v]=0\) (or \(-\infty\)) for all other \(v\).
  2. Extract the vertex with the maximum \(b\) (use a max-heap).
  3. Relax with \(\min\) instead of \(+\): \(b[v]\leftarrow\max\big(b[v],\ \min(b[u],\,w(u,v))\big)\).
WIDEST-PATH(G, s)
 for each v: b[v] = 0, pi[v] = NIL
 b[s] = INF
 Q = max-priority-queue over V keyed by b
 while Q not empty
   u = EXTRACT-MAX(Q)
   for each (u,v) in Adj[u]
     if min(b[u], w(u,v)) > b[v]
        b[v] = min(b[u], w(u,v)); pi[v] = u

Justification (same proof as Dijkstra).

  1. Claim: when \(u\) is extracted, \(b[u]\) is the true best bottleneck \(\beta(s,u)\). Always \(b[v]\le\beta(s,v)\), because every value written into \(b[v]\) is the bottleneck of an actual \(s\)-\(v\) path (or 0).
  2. Suppose some \(u\) is the first extracted with \(b[u]<\beta(s,u)\). Then \(\beta(s,u)>0\), so a path exists, and \(u\ne s\) (\(s\) is extracted first with \(b[s]=\infty\)). Take an optimal path \(P\) to \(u\). It starts at \(s\in S\) and ends at \(u\notin S\), so let \((x,y)\) be the first edge on \(P\) leaving the set \(S\) of extracted vertices. \(x\) is correct, so after relaxing, \(b[y]\ge\min(\beta(s,x),w(x,y))\ge\beta(s,u)\), because the bottleneck of the prefix of \(P\) is at least that of the whole path.
  3. Since \(u\) was picked before \(y\), \(b[u]\ge b[y]\ge\beta(s,u)\), contradicting \(b[u]<\beta(s,u)\).
  4. The key property that makes this work: extending a path can only lower (never raise) its bottleneck, mirroring "extending a path never lowers its length" for non-negative weights.

Time: \(O(E\log V)\) with a binary heap. Alternative: take a maximum spanning tree; the widest path between any two vertices is the path in that tree.

Q6(b) · 10 marks

Kruskal's algorithm can return different spanning trees for the same input graph G, depending on how it breaks ties when the edges are sorted. Show that for each minimum spanning tree T of G, there is a way to sort the edges of G in Kruskal's algorithm so that the algorithm returns T.

Show answer

Choice of order. Sort by weight. Among edges of equal weight, put the edges of \(T\) first. Let \(K\) be the tree Kruskal returns with this order. \(K\) is an MST (Kruskal is correct). Claim \(K=T\).

  1. Suppose \(K\neq T\). Both have \(|V|-1\) edges, so they differ. Let \(e\) be the first edge in the sorted order that is in exactly one of \(K\), \(T\). All earlier edges are in both or in neither.
  2. Case \(e\in T\setminus K\). Kruskal rejected \(e\), so \(e\)'s endpoints were already connected by edges of \(K\) that come earlier than \(e\). Those edges are in \(K\), and since they are before \(e\) they are also in \(T\) (no difference before \(e\)). So \(T\) contains a path between the endpoints of \(e\) plus \(e\) itself: a cycle in \(T\). Contradiction.
  3. Case \(e\in K\setminus T\). \(T+e\) contains a cycle \(C\). Not every edge of \(C-e\) is in \(K\) (else \(K\) has a cycle), so some \(f\in C\), \(f\in T\setminus K\) exists. \(w(f)\le w(e)\): otherwise \(T-f+e\) (a spanning tree, since \(f\) lies on the cycle that \(e\) closes) would be lighter than the MST \(T\). Also \(f\) differs between the trees and \(f\neq e\), so \(f\) comes after \(e\) in the order, hence \(w(f)\ge w(e)\). So \(w(f)=w(e)\). But among equal weights T-edges come first, and \(f\in T\), \(e\notin T\), so \(f\) is before \(e\). Contradiction.
  4. Both cases are impossible, so \(K=T\). \(\blacksquare\)

Q6(c) · 10 marks

Show how to express the single-source shortest-paths problem as a product of matrices and a vector. Describe how evaluating this product corresponds to a Bellman-Ford-like algorithm.

Show answer

Use the min-plus (tropical) product: \((A\otimes x)_i=\min_j\,(a_{ij}+x_j)\).

  1. Let \(W\) be the \(n\times n\) matrix with \(W_{ij}=w(j,i)\) if edge \(j\to i\) exists, \(W_{ii}=0\), and \(\infty\) otherwise. (So row \(i\) lists the edges into \(i\).)
  2. Let \(d^{(0)}\) be the vector with \(0\) at the source \(s\) and \(\infty\) elsewhere.
  3. Define \(d^{(k)}=W\otimes d^{(k-1)}\). Entry \(i\): \(d^{(k)}_i=\min_j\big(W_{ij}+d^{(k-1)}_j\big)=\min\big(d^{(k-1)}_i,\ \min_{(j,i)\in E}d^{(k-1)}_j+w(j,i)\big)\).
  4. By induction, \(d^{(k)}_i\) is the shortest distance from \(s\) to \(i\) using at most \(k\) edges.
  5. So \(d^{(n-1)}=W^{\otimes(n-1)}\otimes d^{(0)}\) holds the shortest-path distances (if there is no negative cycle). It is a product of \(n-1\) matrices and one vector.

Link to Bellman-Ford. One multiplication \(W\otimes d\) computes, for every vertex, the best over all its incoming edges: that is exactly one round of Bellman-Ford, which relaxes every edge once. Bellman-Ford does \(n-1\) rounds, i.e. \(n-1\) multiplications. Cost: one product is \(O(E)\) using the sparse structure (or \(O(n^2)\) dense), so \(O(VE)\) overall. A further multiplication that still changes \(d\) means a negative cycle is reachable.

Small illustration (edges A→B 4, A→C 1, C→B 2, B→D 1, source A): \(d^{(0)}=(0,\infty,\infty,\infty)\), \(d^{(1)}=(0,4,1,\infty)\), \(d^{(2)}=(0,3,1,5)\), \(d^{(3)}=(0,3,1,4)\), after which nothing changes.

Q7(a) · 13 marks

A vertex cover of a graph G = (V, E) is a subset of vertices S ⊆ V that includes at least one endpoint of every edge in E. Give a linear-time algorithm for the following task. Input: An undirected tree T = (V, E). Output: The size of the smallest vertex cover of T.

Show answer

Greedy from the leaves. The edge to a leaf must be covered. Choosing the leaf's parent is never worse than choosing the leaf, because the parent also covers its other edges.

MIN-VC-TREE(T, root r)
 DFS from r to get parent[] and a post-order (children before parents)
 inCover[v] = false for all v;  count = 0
 for v in post-order
    if v != r and not inCover[v] and not inCover[parent[v]]
       // edge (v, parent[v]) still uncovered: take the parent
       inCover[parent[v]] = true     // parent[v] joins the cover
       count = count + 1
 return count

Here inCover[x] means "x is in the cover". Step by step: process a vertex only after all its children. If edge \((v,p)\) is not yet covered (neither end chosen), choose \(p\).

Correctness (exchange argument).

  1. Take a leaf \(v\) with parent \(p\). Any cover contains \(v\) or \(p\). If it contains \(v\) and not \(p\), swap \(v\) for \(p\): all edges of \(v\) (just \((v,p)\)) are still covered, and the cover is no larger. So some minimum cover contains \(p\).
  2. Choose \(p\), delete \(p\) and all its edges, leaving a forest \(F'\). Then \(OPT(T)=OPT(F')+1\): a minimum cover \(C\ni p\) of \(T\) (step 1) gives the cover \(C-\{p\}\) of \(F'\), so \(OPT(F')\le OPT(T)-1\); and any cover of \(F'\) plus \(p\) covers \(T\), so \(OPT(T)\le OPT(F')+1\). The same lemma applies to every tree of a forest, so repeat.
  3. The post-order loop does exactly this. When \(v\) is processed and \((v,p)\) is uncovered, every child \(c\) of \(v\) is already in the cover (if \((c,v)\) had been uncovered at \(c\), \(v\) would have been chosen then). So after deleting the chosen vertices and their edges, \(v\) is a leaf of the remaining forest whose only edge is \((v,p)\), and choosing \(p\) is the step-1 choice. If \((v,p)\) is already covered, \(v\) is a leaf with no edge left and nothing is needed.

Time. DFS \(O(V+E)\) and one pass, so \(O(V)\) since \(E=V-1\). Equivalent known fact: for a tree, min vertex cover = max matching (König), and the greedy above also builds a maximal matching. (Alternative: DP with states "v in cover / v not in cover", also \(O(V)\).)

Q7(b) · 10 marks

Give an efficient algorithm to find the length (number of edges) of a minimum-length negative-weight cycle in a graph.

Show answer

Idea. Find the smallest \(k\) for which some closed walk of exactly \(k\) edges has negative weight. That \(k\) is the answer, and it is at most \(n\).

MIN-NEG-CYCLE-LENGTH(G, w)
 for k = 1 to n
    // D_k[i][j] = min weight of a walk with EXACTLY k edges from i to j
    D_k = D_(k-1) (min-plus product) W        // D_1 = W, with no zero diagonal
    if some D_k[i][i] < 0 return k
 return NONE                                      // no negative cycle
  1. Why the first such \(k\) is the cycle length. A negative simple cycle of length \(\ell\) is a closed walk of \(\ell\) edges, so the first \(k\le\ell\).
  2. Conversely, a negative closed walk of \(k\) edges splits into simple cycles, and at least one of them is negative and has length \(\le k\). So a negative simple cycle of length \(\le k\) exists. With \(k\) minimal this means the shortest negative cycle has length exactly \(k\).
  3. Time. Each min-plus product is \(O(n^3)\) and there are at most \(n\) of them: \(O(n^4)\).
  4. Cheaper: for each start vertex \(s\), run a Bellman-Ford that tracks walks with exactly \(k\) edges: \(D_0[s]=0\); \(D_k[v]=\min_{(u,v)}D_{k-1}[u]+w(u,v)\). Check \(D_k[s]<0\). Time \(O(V\cdot VE)=O(V^2E)\), better for sparse graphs.

Q7(c) · 12 marks

You are given a strongly connected directed graph G = (V, E) with positive edge weights along with a particular node v0 ∈ V. Give an efficient algorithm for finding shortest paths between all pairs of nodes, with the one restriction that these paths must all pass through v0.

Show answer

Algorithm

  1. Run Dijkstra from \(v_0\) on \(G\). This gives \(d(v_0,v)\) for every \(v\).
  2. Build the reverse graph \(G^R\) (all edges flipped) and run Dijkstra from \(v_0\) on it. This gives \(d(u,v_0)\) for every \(u\).
  3. For every pair \((u,v)\): \(\text{dist}_{v_0}(u,v)=d(u,v_0)+d(v_0,v)\).

Why. A path from \(u\) to \(v\) that passes through \(v_0\) is a path \(u\leadsto v_0\) followed by \(v_0\leadsto v\). Minimising the whole means minimising each half independently. G is strongly connected, so every distance is finite.

Time. Two Dijkstra runs, \(O(E\log V)\) each, plus \(O(V^2)\) to fill the answer table: \(O(E\log V+V^2)\). Far better than \(V\) Dijkstra runs or Floyd-Warshall (\(O(V^3)\)).

Remark. The two halves can share a vertex, in which case the combined walk visits it twice; with positive weights this is still the shortest walk that passes through \(v_0\), which is what the question wants.

Question 8

Q8(a) · 12 marks

The graph in Figure for Q8(a) is an instance of the symmetric traveling salesman problem with distances that satisfy the triangle inequality. Show how to construct a near optimal solution using a minimum spanning tree.

Graph read from scan (complete graph on a, b, c, d, e): a–b 2, a–c 2, a–d 1, a–e 6, b–c 4, b–d 3, b–e 5, c–d 3, c–e 4, d–e 6.

Show answer

2-approximation (MST preorder)

  1. Compute an MST \(T\) of the graph (Kruskal below).
  2. Pick a root (a). Walk \(T\) in depth-first order and list vertices in preorder. Visit children in any fixed order.
  3. Close the list back to the root. This is the tour. (Preorder = the full DFS walk of \(2|T|\) cost with repeated vertices shortcut. The triangle inequality says shortcuts never cost more.)

Kruskal on this graph: sorted edges ad(1), ab(2), ac(2), bd(3), cd(3), bc(4), ce(4), ...

  • Accept a–d (1), a–b (2), a–c (2). Reject b–d, c–d, b–c (cycles). Accept c–e (4). Done: four edges, total 9.
  1. Full walk of the tree from a, children in order d, b, c: a, d, a, b, a, c, e, c, a. Cost \(2\times9=18\).
  2. Preorder (skip repeated vertices): a, d, b, c, e, then back to a.
  3. Tour cost: a–d 1 + d–b 3 + b–c 4 + c–e 4 + e–a 6 = 18.

Why it is within 2 of optimal. Let \(OPT\) be the optimal tour. Delete one edge: a spanning tree, so \(w(T)\le OPT\). The preorder tour costs at most the full walk, \(2w(T)\le 2\,OPT\). Here \(18\le 2\times9\). The true optimum for this graph is 15 (tour a, b, e, c, d, a: 2+5+4+3+1), so our tour is 1.2 times the optimum.

On paper: draw the MST (4 edges, weights), draw the DFS walk with numbers 1..8 along it, then the shortcut tour as a dashed cycle on the original graph with the cost of each edge.

Q8(b) · 10 + 7 + 6 = 23 marks

Ad-hoc networks are made up of cheap, low-powered wireless devices, which can communicate within a limited range. Consider an ad-hoc wireless network where any two devices can communicate if and only if the distance between them is at most D. To improve reliability, we require each device x to have k potential backup devices, all within distance D of x; we call these k devices the backup set of x. Also, we do not want any device to be in the backup set of more than b devices, say; otherwise, a single failure might affect a large fraction of the network.

Suppose we are given the communication distance D, parameters b and k, and an array d[1...n, 1...n] of distances, where d[i, j] is the distance between device i and device j. The problem is to design and analyze an algorithm that either computes a backup set of size k for each of the n devices, such that no device appears in more than b backup sets, or correctly reports that no good collection of backup sets exists. Now answer the following questions:

(i) Reduce this problem to a max-flow problem. Describe a max-flow problem (a directed, capacitated graph G, a source and sink pair) such that a good collection of backup sets exist if and only if the max-flow in G has a certain size. What is this size? (10)

(ii) Prove the correctness of your reduction. Show that a good collection of backup sets exist if and only if the max-flow in G has a certain size. (7)

(iii) Give an algorithm to solve this max-flow problem. What is the running time of this algorithm as a function of n, k and b? (6)

Show answer

(i) The network (10 marks). This is a bipartite "degree-constrained" assignment, just like bipartite matching.

Build G

  1. Vertices: source \(s\), sink \(t\), a "left copy" \(\ell_i\) for each device \(i\), and a "right copy" \(r_j\) for each device \(j\). Total \(2n+2\) vertices.
  2. Edges \(s\to\ell_i\) with capacity \(k\) (device \(i\) needs \(k\) backups).
  3. Edges \(\ell_i\to r_j\) with capacity 1 whenever \(i\ne j\) and \(d[i,j]\le D\) (device \(j\) may back up \(i\); capacity 1 because \(j\) can be listed once in \(i\)'s set).
  4. Edges \(r_j\to t\) with capacity \(b\) (device \(j\) appears in at most \(b\) sets).
  5. Size to test: a good collection exists iff the max flow equals \(nk\) (all source edges saturated).
  6. The backup set of \(i\) is \(\{j:\text{flow on }\ell_i\to r_j=1\}\).

(ii) Correctness (7 marks).

  1. (⇒) Suppose a good collection exists. Send 1 unit along \(s\to\ell_i\to r_j\to t\) for each \(j\) in \(i\)'s backup set. Edge \(s\to\ell_i\) carries \(k\) (capacity \(k\)). Each \(\ell_i\to r_j\) carries at most 1. Each \(r_j\to t\) carries the number of sets containing \(j\), at most \(b\). Capacities hold and flow is conserved, so the flow has value \(nk\). The maximum is at most \(nk\) (the cut at the source), so max flow \(=nk\).
  2. (⇐) Suppose max flow \(=nk\). Capacities are integers, so by the integrality theorem there is an integer maximum flow. Edges out of \(s\) are all saturated, so each \(\ell_i\) receives exactly \(k\) units, which it sends along \(k\) distinct edges \(\ell_i\to r_j\) (capacity 1, integer). Define \(i\)'s backup set as those \(k\) devices \(j\): each is within distance \(D\) (only such edges exist). Edge \(r_j\to t\) has capacity \(b\), so \(j\) is chosen by at most \(b\) devices. So the collection is good. \(\blacksquare\)
  3. If max flow \(<nk\), by the equivalence no good collection exists: report that.

(iii) Algorithm and running time (6 marks).

  1. Run Ford-Fulkerson (augmenting paths) on G. The flow value is at most \(nk\) and the capacities are integers, so there are at most \(nk\) augmentations.
  2. G has \(2n+2\) vertices and \(O(n^2)\) edges (the \(\ell_i\to r_j\) edges dominate), so each augmenting path search (BFS/DFS) costs \(O(n^2)\).
  3. Total \(O(nk\cdot n^2)=O(n^3k)\). Note it does not depend on \(b\) in this bound. (With Edmonds-Karp the bound would be \(O(VE^2)=O(n^5)\), independent of \(k\) and \(b\).)
On paper: draw \(s\), the two columns \(\ell_1..\ell_n\) and \(r_1..r_n\), \(t\). Label the three kinds of edge with capacities \(k\), 1, \(b\), and write "target: max flow = nk".
