Single-Source Shortest Paths: Relaxation, Bellman-Ford, DAGs and BFS Tricks

Asked in 2023–24 (Q8, 8+7: the currency exchange anomaly), 2022–23 (Q2: equal weights 8, positive weights 12, negative weights and negative cycles 15), 2019–20 (Q5a 13: weights 1 to 5 by BFS; Q6c 10: SSSP as a matrix product; Q7b 10: shortest negative cycle; Q7c 12: paths through a given vertex), 2020–21 (Q1a 8: longest path in a DAG; Q2a 12: single destination), 2017–18 (Q8a 5, Q8b 6+2), 2024–25 (Q8b: negative cycle, done in chapter 4), and CT-1 (AMR) Q3 and Q4 (4 marks each).

Syllabus note. Bayzid sir's boxed "reduction will not come" is for the CT only. Term finals ask reductions nearly every year (negative cycle by log weights, weights 1 to 5 by BFS, vertex-cover and set-cover). Treat the reduction tricks in sections 8 and 9 as examinable.

1. The problem and the vocabulary

Directed graph \(G=(V,E)\), weight \(w(u,v)\) on each edge (may be negative). The weight of a path is the sum of its edge weights. The shortest-path weight \(\delta(s,v)\) is the minimum over all paths from \(s\) to \(v\), or \(\infty\) if there is none, or \(-\infty\) if a negative cycle can be reached on the way.

Each vertex stores v.d (current estimate, never below the truth) and v.π (predecessor). The edges \((v.\pi,v)\) form the shortest-path tree rooted at \(s\).

Optimal substructure (L5 proof)

  1. Let \(P=\langle v_0,\dots,v_k\rangle\) be a shortest path from \(v_0\) to \(v_k\). Take any sub-path \(P_{ij}\) from \(v_i\) to \(v_j\). Then \(w(P)=w(P_{0i})+w(P_{ij})+w(P_{jk})\).
  2. If some path \(P'_{ij}\) were shorter than \(P_{ij}\), replace \(P_{ij}\) by it. The new path from \(v_0\) to \(v_k\) is shorter than \(P\). Contradiction.
  3. So every sub-path of a shortest path is a shortest path. \(\blacksquare\)

Shortest paths are simple when no negative cycle is reachable. A positive-weight cycle only adds cost, a zero cycle adds nothing, and a negative cycle makes \(\delta=-\infty\) (go round again and again). So a shortest path has at most \(|V|-1\) edges.

Triangle inequality. For every edge \((u,v)\): \(\delta(s,v)\le\delta(s,u)+w(u,v)\). (Go to \(u\) the best way, then take the edge.)

2. Relaxation and its properties

INITIALIZE-SINGLE-SOURCE(G, s)            // O(V)
  for each v in V:  v.d = ∞;  v.π = NIL
  s.d = 0

RELAX(u, v, w)                            // O(1)
  if v.d > u.d + w(u,v)
      v.d = u.d + w(u,v)
      v.π = u

All algorithms in this chapter and the next differ only in which edges they relax and in what order. These are the properties they use (the teacher's list):

  1. Triangle inequality (above).
  2. Upper-bound property. \(v.d\ge\delta(s,v)\) always. Once \(v.d=\delta(s,v)\) it never changes ("most relaxed").
  3. No-path property. If no path \(s\to v\) exists, \(v.d=\infty\) always.
  4. Convergence property. If \(s\leadsto u\to v\) is a shortest path, \(u.d=\delta(s,u)\) before we relax \((u,v)\), then \(v.d=\delta(s,v)\) afterwards.
  5. Path-relaxation property. If \(p=\langle v_0=s,v_1,\dots,v_k\rangle\) is a shortest path and its edges are relaxed in the order \((v_0,v_1),(v_1,v_2),\dots\), possibly with other relaxations in between, then \(v_k.d=\delta(s,v_k)\).

Proofs of properties 2, 4 and 5 (CLRS 24.5, the slide "SSSP properties proof")

  1. Upper bound, by induction on the number of relaxations. At the start \(s.d=0\ge\delta(s,s)\) (\(\delta(s,s)\) is \(0\), or \(-\infty\) if a negative cycle passes through \(s\)) and the rest are \(\infty\). Suppose RELAX\((u,v)\) is the first step that makes some \(v.d<\delta(s,v)\). Then \(v.d=u.d+w(u,v)\ge\delta(s,u)+w(u,v)\ge\delta(s,v)\), using the hypothesis for \(u\) and then the triangle inequality. Contradiction. Estimates only decrease and never go below \(\delta\), so once equal they stay equal.
  2. Convergence. After relaxing, \(v.d\le u.d+w(u,v)=\delta(s,u)+w(u,v)=\delta(s,v)\) (the last equality because \((u,v)\) lies on a shortest path). With the upper bound, \(v.d=\delta(s,v)\).
  3. Path relaxation, by induction on \(i\). Claim: after \((v_{i-1},v_i)\) is relaxed, \(v_i.d=\delta(s,v_i)\), and it stays so. Base \(i=0\): \(s.d=0=\delta(s,s)\) from the start (\(p\) is a shortest path, so no negative cycle is on it and \(\delta(s,s)=0\)), and by the upper bound it never changes. Hypothesis: the claim holds for \(i-1\). Step: \((v_{i-2},v_{i-1})\) is relaxed before \((v_{i-1},v_i)\), so by hypothesis \(v_{i-1}.d=\delta(s,v_{i-1})\) when \((v_{i-1},v_i)\) is relaxed. The prefix \(\langle v_0,\dots,v_i\rangle\) is a shortest path (optimal substructure), so convergence gives \(v_i.d=\delta(s,v_i)\), and the upper bound keeps it there. Conclusion: with \(i=k\), \(v_k.d=\delta(s,v_k)\). \(\blacksquare\)

3. Bellman-Ford

Idea: a shortest path has at most \(V-1\) edges. So relax every edge, \(V-1\) times, in any order. Pass \(i\) fixes every vertex whose shortest path has \(i\) edges. Then do one more pass: if any edge still relaxes, a negative cycle is reachable from \(s\).

BELLMAN-FORD(G, w, s)
  INITIALIZE-SINGLE-SOURCE(G, s)
  for i = 1 to |V| - 1
      for each edge (u,v) in E
          RELAX(u, v, w)
  for each edge (u,v) in E                 // detection pass
      if v.d > u.d + w(u,v)
          return FALSE                     // negative cycle reachable from s
  return TRUE

Method · Bellman-Ford by hand

  1. Fix an edge order and write it down. Without a fixed order two students get different intermediate tables, and the marker cannot follow.
  2. Make a table with one column per vertex and one row per pass. Row 0: \(0\) for the source, \(\infty\) elsewhere.
  3. In each pass go through every edge once in the written order. Copy the table row, update the cells that change, and note \(\pi\).
  4. Stop after \(|V|-1\) passes (you may stop early if a pass changes nothing).
  5. Do the detection pass: check every edge once. Any edge that can still relax means "negative cycle".

Complexity

Initialisation \(O(V)\). The double loop does \((V-1)\cdot E\) relaxations at \(O(1)\) each: \(O(VE)\). The detection pass is \(O(E)\). Total \(O(VE)\); space \(O(V)\).

Correctness

Proof (CLRS Lemma 24.2 and Theorem 24.4)

  1. No negative cycle reachable. Every reachable vertex \(v\) has a simple shortest path \(\langle v_0=s,\dots,v_k=v\rangle\), \(k\le V-1\).
  2. Pass \(i\) relaxes every edge, so it relaxes \((v_{i-1},v_i)\). Edges of the path are therefore relaxed in order across passes 1, 2, \(\dots\), \(k\).
  3. By the path-relaxation property \(v.d=\delta(s,v)\) after \(V-1\) passes. Unreachable vertices keep \(\infty\) (no-path property).
  4. Now every edge satisfies \(v.d=\delta(s,v)\le\delta(s,u)+w(u,v)=u.d+w(u,v)\) (triangle inequality), so the detection pass finds nothing and returns TRUE.
  5. Negative cycle reachable. Let \(c=\langle v_0,\dots,v_k=v_0\rangle\) with \(\sum w(v_{i-1},v_i)<0\). Suppose the detection pass returned TRUE. Then \(v_i.d\le v_{i-1}.d+w(v_{i-1},v_i)\) for all \(i\). Add these \(k\) inequalities: \(\sum v_i.d\le\sum v_{i-1}.d+w(c)\). Both sums are the same finite number: each vertex of \(c\) appears once in each sum, and every \(d\) is finite (each \(v_i\) is reachable by a simple path of at most \(V-1\) edges, and the passes relax its edges in order, so \(v_i.d\le\) that path's weight \(<\infty\)). So \(0\le w(c)\). Contradiction. So it returns FALSE. \(\blacksquare\)

Intuitive idea in two lines (2017–18 Q8b, 6+2). "A shortest path has at most \(V-1\) edges, so relaxing all edges \(V-1\) times gives every shortest path. If after that an edge can still be relaxed, the distances are still dropping, which only a negative cycle can cause." Detection of the cycle itself: from the last relaxed vertex follow \(\pi\) back \(V\) times (you are then inside the cycle), then keep following until you return.

Edges A→B 3, B→C 2, C→D 2, D→B −8, A→D 10, B→D 5. The cycle B→C→D→B has weight \(2+2-8=-4\). Watch the values fall in every pass, and the extra pass still relaxing D→B.

4. Negative cycles: what to answer when asked to "handle" them (2022–23 Q2c, 15 marks)

"Develop an efficient algorithm when edge weights can be negative and there can be negative cycles." Answer in four steps:

Method

  1. Run Bellman-Ford from \(s\) with \(V-1\) passes.
  2. Run the detection pass. Collect every vertex \(v\) for which an edge \((u,v)\) still relaxes.
  3. Do a BFS or DFS from those vertices. Every vertex reached has \(\delta(s,v)=-\infty\).
  4. All other reachable vertices have the final \(d\) values as their distances. Unreachable ones stay \(\infty\).
  5. Why this is exactly right. (a) A vertex with finite \(\delta(s,v)\) has a simple shortest path of at most \(V-1\) edges, so by path relaxation its \(d\) is exact after \(V-1\) passes. (b) If \((u,v)\) still relaxes, \(u\) and \(v\) cannot both have finite \(\delta\) (then \(v.d=\delta(s,v)\le\delta(s,u)+w=u.d+w\) by the triangle inequality); \(u\) is reachable since \(u.d<\infty\), so \(\delta(s,u)=-\infty\) or \(\delta(s,v)=-\infty\), and either way \(\delta(s,v)=-\infty\). So every vertex the search reaches is \(-\infty\). (c) Conversely, a \(-\infty\) vertex is reachable from a negative cycle reachable from \(s\); the correctness proof shows some edge of that cycle still relaxes, so its head is collected and the search reaches the vertex.

Cost \(O(VE)+O(V+E)=O(VE)\). A complete answer also says why Dijkstra cannot be used (chapter 3) and gives the pseudocode above.

The slide example: which vertices become minus infinity (slides 06 p.63-65, CLRS Figure 24.1)

Edges: s-a 3, s-c 5, s-e 2, a-b -4, b-g 4, c-d 6, d-c -3, d-g 8, e-f 3, f-e -6, f-g 7, h-i 2, i-j 3, j-h -8. The teacher's answer: \(\delta(s,s)=0\), a 3, b -1, c 5, d 11, then e, f, g are \(-\infty\) and h, i, j are \(+\infty\). Three kinds of cycle, three different outcomes:

  • c-d: weight \(6-3=3\), positive. It is harmless, so c and d keep finite distances.
  • e-f: weight \(3-6=-3\), negative and reachable from s. So e and f are \(-\infty\), and so is g, which is reachable from f.
  • h-i-j: weight \(2+3-8=-3\), negative but not reachable from s. Those vertices are \(+\infty\) (no path), not \(-\infty\).

Bellman-Ford does not print \(-\infty\). After \(|V|-1\) passes the extra pass still relaxes an edge, so it reports a negative cycle. The trace below ends with that report.

5. The currency exchange question (2023–24 Q8, 8+7)

Rates \(r_{ij}\): one unit of \(c_i\) buys \(r_{ij}\) units of \(c_j\). (i) Best way to convert \(s\) into \(t\). (ii) Detect an anomaly: a cycle with \(r_{i_1i_2}\cdots r_{i_ki_1}>1\).

Method · turn a product into a sum

  1. Graph: one vertex per currency, an edge \(i\to j\) for every rate.
  2. Edge weight \(w(i,j)=-\ln r_{ij}\). For a path, \(\sum w=-\ln\prod r\). Maximising the product is the same as minimising the sum, because \(-\ln\) is decreasing.
  3. (i) Run Bellman-Ford from \(s\). The best sequence is the \(\pi\)-path to \(t\). Amount obtained from 1 unit is \(e^{-d[t]}\). With \(n\) currencies the graph has \(n^2\) edges, so \(O(n\cdot n^2)=O(n^3)\) (Floyd-Warshall, chapter 4, is the same cost).
  4. (ii) \(\prod r>1\iff\sum(-\ln r)<0\), so the anomaly is exactly a negative-weight cycle. Run Bellman-Ford from any currency (the graph is complete, all vertices are reachable) and look at the extra pass. If any edge relaxes, the anomaly exists. \(O(n^3)\).
  5. Check by hand: rates A→B 0.9, B→C 0.9, C→A 1.3 give product \(1.053>1\). The weights are \(0.105,\ 0.105,\ -0.262\), cycle sum \(-0.052<0\). Bellman-Ford finds it.

Where marks go

  • Student solution "Dijkstra with multiply and max" is wrong in general. It works only if every rate \(r\le1\) (then \(-\ln r\ge0\)). The question only promises \(r_{ij}r_{ji}<1\), so single rates can exceed 1 and long cycles can be profitable. Use \(-\ln r\) and Bellman-Ford. (This error is in "DSA 23-24 solve" Q8(i).)
  • If part (i) has an anomaly reachable from \(s\), "best" is unbounded; say you assume none, or run (ii) first.
  • Say what you put on the diagonal if you use Floyd-Warshall: \(d_{ii}=0\) (that is \(r_{ii}=1\)), then a negative diagonal means anomaly.

6. Shortest paths in a DAG

If the graph has no cycles you do not need Bellman-Ford. Negative edges are allowed because no cycle can be negative.

DAG-SHORTEST-PATHS(G, w, s)
  topologically sort the vertices of G          // DFS finish times, reversed
  INITIALIZE-SINGLE-SOURCE(G, s)
  for each vertex u, taken in topological order
      for each v in Adj[u]
          RELAX(u, v, w)

Correctness and complexity

  1. Every path in a DAG follows the topological order: for each edge \((v_{i-1},v_i)\), \(v_{i-1}\) comes before \(v_i\). The edge \((v_{i-1},v_i)\) is relaxed when \(v_{i-1}\) is processed. So for any shortest path \(s=v_0,\dots,v_k\) the edges are relaxed in the order \((v_0,v_1),(v_1,v_2),\dots\) (a DAG has no cycles, so every reachable \(v_k\) has such a path).
  2. By the path-relaxation property, \(v_k.d=\delta(s,v_k)\). Equivalently: when \(u\) is processed, all its predecessors are already final.
  3. Time: topological sort \(\Theta(V+E)\); initialise \(\Theta(V)\); each edge relaxed once, \(\Theta(E)\). Total \(\Theta(V+E)\).
  4. Vertices that come before \(s\) in the order cannot be reached from \(s\); they stay \(\infty\).

Longest path in a DAG (2020–21 Q1a, 8 marks)

Same algorithm, two changes: start with \(d=-\infty\) (source 0) and relax with if v.d < u.d + w. Or negate every weight, run the shortest-path version, and negate the answer. Still \(\Theta(V+E)\). This is how critical-path scheduling works. (The longest path in a graph with cycles is NP-hard, which is why the DAG matters.)

Trace

Edges A→B 5, A→C 3, B→C 2, B→D 6, C→D 7, C→E 4, C→F 2, D→E −1, D→F 1, E→F −2, source A. The engine sorts topologically (A, B, C, D, E, F) and relaxes vertex by vertex.

On paper: write the topological order as a row of boxes. Under each box write the vertex's final \(d\). Draw each relaxation as an arrow that goes left to right only, and bold the edges that end up in the shortest-path tree.

Source in the middle of the order (notes p.14, Lec 7). If \(s\) is not first in the topological order, every vertex before \(s\) is unreachable from \(s\). Their distances stay \(\infty\). Start the relaxing loop at \(s\) or let the loop pass over them, the result is the same.

7. Unit weights: BFS (2022–23 Q2a 8, 2017–18 Q8a 5)

Method · all weights equal

  1. BFS from \(s\) with a queue. \(d[s]=0\). When you dequeue \(u\) and see an unvisited \(v\): \(d[v]=d[u]+1\), \(\pi[v]=u\), enqueue.
  2. Path weight is (number of edges) \(\times\) (the common weight \(c\)), so multiply the BFS distance by \(c\).
  3. Correctness: the queue always holds vertices with \(d\) values \(k,\dots,k,k+1,\dots,k+1\) in order. So vertices leave the queue in non-decreasing order of true distance (induction on \(k\)).
  4. Time \(O(V+E)\) with adjacency lists.
BFS(G, s)
  for each v: d[v] = ∞;  d[s] = 0;  Q = [s]
  while Q not empty
      u = dequeue(Q)
      for each v in Adj[u]
          if d[v] == ∞:  d[v] = d[u] + 1;  π[v] = u;  enqueue(Q, v)

8. Reductions to BFS (2019–20 Q5a, 13 marks; 2017–18 Q8a; CT-1 Q4)

Method · integer weights between 1 and \(W\) (here \(W=5\) or \(W=3\))

  1. Replace each edge \((u,v)\) of weight \(w\) by a path of \(w\) unit edges through \(w-1\) new dummy vertices \(u\to x_1\to\cdots\to x_{w-1}\to v\).
  2. A path of weight \(L\) in the old graph becomes a path of exactly \(L\) edges in the new graph, and conversely. So shortest weighted path = shortest unweighted path.
  3. Run BFS from \(s\) in the new graph. Read the answer at \(t\); ignore dummies in the printed path.
  4. Size of the new graph: at most \(V+(W-1)E\) vertices and \(WE\) edges. BFS time \(O(V+WE)\), and since \(W\) is a constant (5 or 3), \(O(V+E)\). That beats Dijkstra's \(O(E+V\log V)\) (CT-1 Q4: "outline and give complexity").

Alternative with no dummy vertices: Dial's buckets. Keep an array of queues indexed by distance \(0,\dots,W\cdot(V-1)\). Scan the buckets in order. Same \(O(V+WE)\).

This works only for integer weights. For general positive weights the trick needs too many dummies; that is why the 2017–18 Q8a question (BFS with unequal weights) has the answer "split the edges, but the cost depends on the weights, so use Dijkstra".

9. More variants that were asked

Method · each answer in a few lines

  1. SSSP as a matrix-vector product (2019–20 Q6c, 10 marks). Let \(W\) be the weight matrix with \(w_{ii}=0\) and \(\infty\) where no edge. Let \(d^{(0)}=(0,\infty,\dots,\infty)\) (source first). Define the min-plus product \(d^{(m)}_j=\min_i\bigl(d^{(m-1)}_i+w_{ij}\bigr)\). Then \(d^{(m)}_j\) is the shortest weight of a path from \(s\) to \(j\) using at most \(m\) edges (induction: the last edge is \((i,j)\), the rest is a path with at most \(m-1\) edges; \(w_{jj}=0\) keeps "at most"). After \(V-1\) products, \(d^{(V-1)}=d^{(0)}\otimes W^{\otimes(V-1)}\) is the answer. Each product relaxes all edges once, which is exactly one Bellman-Ford pass. Cost: \(V-1\) products, each \(O(E)\) if you only use real edges, giving \(O(VE)\) (or \(O(V^3)\) dense with a full matrix). One more product that changes \(d\) means a negative cycle.
  2. Length (edge count) of a shortest negative cycle (2019–20 Q7b, 10 marks). Use the min-plus matrix powers of chapter 4: \(L^{(m)}_{ii}\) is the cheapest closed walk of at most \(m\) edges through \(i\). The answer is the smallest \(m\ge1\) with some \(L^{(m)}_{ii}<0\). Compute \(L^{(1)},L^{(2)},\dots\) one multiplication at a time, \(O(V^4)\), or square to find the range then binary search, \(O(V^3\log V)\). Since a shortest negative cycle is simple, \(m\le V\).
  3. Shortest paths that must pass through \(v_0\) (2019–20 Q7c, 12 marks). The best \(u\to v\) path through \(v_0\) costs \(\delta(u,v_0)+\delta(v_0,v)\). Run Dijkstra from \(v_0\) in \(G\) (gives \(\delta(v_0,v)\) for all \(v\)). Run Dijkstra from \(v_0\) in the reversed graph (gives \(\delta(u,v_0)\) for all \(u\)). Combine for each pair in \(O(V^2)\). Total \(O(E\log V+V^2)\). Paths need not be simple; that is allowed because the question asks only for paths through \(v_0\).
  4. Single destination with vertex weights (2020–21 Q2a, 12 marks). Reverse all edges, make the destination the source, and run Dijkstra on the reversed graph. If vertices also have costs \(c(v)\ge0\) and a path pays for the vertices it visits, charge the vertex when you arrive at it: in the reversed graph give edge \((v\to u)\) the weight \(w(u,v)+c(u)\), and start with \(d[t]=c(t)\). Non-negative, so Dijkstra is valid. (The question statement is brief; say your reading of "path cost" first.)
  5. Distributed use (CT-1 Q3, 4 marks). Bellman-Ford needs only each vertex's own estimate and its neighbours', so every router can run it on its own (distance-vector routing). Dijkstra repeatedly needs the global minimum over all unfinished vertices, which needs one machine to know everything.
  6. Which algorithm? (class test). Unweighted all pairs: BFS from every vertex, \(O(V(V+E))\). One source, negative edges, undirected graph: an undirected negative edge can be walked back and forth, so it acts as a negative cycle and shortest walks are not defined; the expected answer is Bellman-Ford, \(O(VE)\), treating each edge as two directed edges, which reports the cycle. Directed sparse all pairs: Johnson (chapter 5).
