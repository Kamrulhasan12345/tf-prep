All-Pairs Shortest Paths: Matrix Product, Floyd-Warshall, Transitive Closure

Asked in 2024–25 (Q8b, 15 marks: Floyd-Warshall on a 4-vertex graph to find a negative cycle), 2023–24 (Q9: explain Floyd-Warshall, 10 marks, plus when Johnson is better, 5), 2021–22 (Q3: the Dhaka new-road problem, 8+12+15), 2020–21 (Q2b, 10: Warshall without extra memory), 2019–20 (Q6c: SSSP as matrix product; Q7c, 12: paths through a vertex), 2017–18 (Q2d: all-pairs strongest path), and CT-1 (AMR) Q1 (6 marks: show every matrix). Floyd-Warshall by hand with the matrices of every step is the single most likely 15-mark item here.

1. The problem

Directed graph, vertices numbered \(1,\dots,n\), weight matrix \(W=(w_{ij})\): \(w_{ii}=0\), \(w_{ij}\) = edge weight, \(w_{ij}=\infty\) if there is no edge. Output: matrix \(D=(\delta_{ij})\) of all shortest distances, and a predecessor matrix \(\Pi=(\pi_{ij})\) so paths can be printed.

Running a single-source algorithm \(n\) times works: Dijkstra \(n\) times is \(O(VE+V^2\log V)\) with Fibonacci heaps, but it needs non-negative weights; Bellman-Ford \(n\) times is \(O(V^2E)\), too slow. This chapter gives the dynamic-programming methods; chapter 5 gives Johnson.

2. The matrix-multiplication approach (slide 09)

Let \(l^{(m)}_{ij}\) = the weight of the shortest path from \(i\) to \(j\) using at most \(m\) edges.

Method · recurrence and why it is right

  1. \(L^{(1)}=W\) (one edge, or none when \(i=j\)).
  2. A path of at most \(m\) edges from \(i\) to \(j\) is a path of at most \(m-1\) edges from \(i\) to some \(k\), then the edge \((k,j)\). By optimal substructure the first part is a shortest such path. So \(l^{(m)}_{ij}=\min_k\bigl(l^{(m-1)}_{ik}+w_{kj}\bigr)\). (Because \(w_{jj}=0\), the case \(k=j\) keeps the "at most".)
  3. With no negative cycle a shortest path is simple, so has at most \(n-1\) edges. Hence \(\delta_{ij}=l^{(n-1)}_{ij}=l^{(n)}_{ij}=\cdots\)
  4. This is matrix multiplication with \((+,\times)\) replaced by \((\min,+)\): \(L^{(m)}=L^{(m-1)}\otimes W\). One product costs \(\Theta(n^3)\).
  5. Slow version: \(n-2\) products one after another, \(\Theta(n^4)\).
  6. Fast version (repeated squaring): the \(\min,+\) product is associative and a path of at most \(2m\) edges splits at its middle vertex, so \(L^{(2m)}=L^{(m)}\otimes L^{(m)}\). Compute \(L^{(1)},L^{(2)},L^{(4)},\dots\) until the exponent reaches \(n-1\): \(\lceil\lg(n-1)\rceil\) products, \(\Theta(n^3\lg n)\).
EXTEND-SHORTEST-PATHS(L, W)           // one (min,+) product, Θ(n^3)
  n = rows(L);  L' = new n x n matrix of ∞
  for i = 1 to n
    for j = 1 to n
      for k = 1 to n
          L'[i][j] = min(L'[i][j], L[i][k] + W[k][j])
  return L'

FAST-ALL-PAIRS(W)                      // Θ(n^3 lg n)
  L = W;  m = 1
  while m < n - 1
      L = EXTEND-SHORTEST-PATHS(L, L);  m = 2m
  return L

Bellman-Ford link. Take one row of \(L\) (the source's) times \(W\): that is SSSP as a matrix-vector product (chapter 2, 2019–20 Q6c). The \(n\) rows together are all pairs. A negative number on the diagonal of some \(L^{(m)}\) means a negative cycle.

3. Floyd-Warshall (slide 11)

Idea: instead of limiting the number of edges, limit the set of intermediate vertices. Intermediate vertices are those on the path other than its two ends.

Method · the recurrence and its proof

  1. Let \(d^{(k)}_{ij}\) = weight of a shortest path from \(i\) to \(j\) whose intermediate vertices all lie in \(\{1,\dots,k\}\).
  2. Base: \(k=0\) means no intermediate vertex, so \(d^{(0)}_{ij}=w_{ij}\), i.e. \(D^{(0)}=W\).
  3. Take a shortest path \(P\) for \((i,j,k)\) (simple, assuming no negative cycle). Case 1: \(k\) is not on \(P\). Then all intermediates are in \(\{1,\dots,k-1\}\), so \(d^{(k)}_{ij}=d^{(k-1)}_{ij}\).
  4. Case 2: \(k\) is an intermediate vertex of \(P\), exactly once. Split \(P\) at \(k\) into \(P_1\colon i\leadsto k\) and \(P_2\colon k\leadsto j\). Neither contains \(k\) as an intermediate, so both use intermediates in \(\{1,\dots,k-1\}\). By optimal substructure both are shortest such paths: \(d^{(k)}_{ij}=d^{(k-1)}_{ik}+d^{(k-1)}_{kj}\).
  5. Take the better of the two cases: \[d^{(k)}_{ij}=\begin{cases}w_{ij}&k=0\\ \min\bigl(d^{(k-1)}_{ij},\ d^{(k-1)}_{ik}+d^{(k-1)}_{kj}\bigr)&k\ge1\end{cases}\]
  6. \(D^{(n)}\) allows every vertex as intermediate, so \(D^{(n)}=(\delta_{ij})\). \(\blacksquare\)
FLOYD-WARSHALL(W)                       // n = number of vertices
  D = W                                  // D(0); also set Π(0) below
  for k = 1 to n                         // k = the new intermediate vertex
      for i = 1 to n
          for j = 1 to n
              if D[i][k] + D[k][j] < D[i][j]
                  D[i][j] = D[i][k] + D[k][j]
                  Π[i][j] = Π[k][j]
  return D, Π

Complexity: three nested loops of \(n\) iterations, each \(O(1)\): \(\Theta(n^3)\) time, \(\Theta(n^2)\) space (the in-place version, section 5). The order of the loops matters: \(k\) must be the outermost, because \(D^{(k)}\) is built from \(D^{(k-1)}\).

The predecessor matrix \(\Pi\)

Method · build \(\Pi\) and print a path

  1. \(\pi^{(0)}_{ij}=\) NIL if \(i=j\) or \(w_{ij}=\infty\); otherwise \(\pi^{(0)}_{ij}=i\).
  2. \(\pi^{(k)}_{ij}=\pi^{(k-1)}_{ij}\) if \(d^{(k-1)}_{ij}\le d^{(k-1)}_{ik}+d^{(k-1)}_{kj}\) (no change), else \(\pi^{(k)}_{ij}=\pi^{(k-1)}_{kj}\) (the new path ends the way the path from \(k\) to \(j\) ends).
  3. Print: PRINT-PATH(i, j): if \(i=j\) print \(i\); else if \(\pi_{ij}\) is NIL print "no path"; else PRINT-PATH(i, π_ij) then print \(j\).

Example (the graph of section 2): the final \(\Pi\) row of A is (NIL, A, B, C), so the path A to D is: \(\pi_{AD}=C\), \(\pi_{AC}=B\), \(\pi_{AB}=A\). Printed: A, B, C, D, weight \(3-2+2=3\). Check with \(D\): \(d_{AD}=3\).

4. The 2024–25 question: negative cycle by Floyd-Warshall (Q8b, 15 marks)

Vertices A, B, C, D. Edges A→B 3, B→C 2, C→D 2, D→B −8, A→D 10, B→D 5. Decide whether there is a negative cycle by Floyd-Warshall and name the vertices on it.

Method · what to write

  1. Write \(D^{(0)}=W\) (rows A to D): A (0, 3, ∞, 10), B (∞, 0, 2, 5), C (∞, ∞, 0, 2), D (∞, −8, ∞, 0).
  2. Run \(k=A,B,C,D\), writing every matrix (the widget above has them). After each \(k\), look at the diagonal. A negative \(d_{ii}\) means a negative cycle through \(i\).
  3. \(k=B\): \(d[D,D]=d[D,B]+d[B,D]=-8+5=-3<0\). The cycle D→B→D has weight \(-3\). Negative cycle found already.
  4. \(k=C\): \(d[D,D]=d[D,C]+d[C,D]=-6+2=-4\). The cycle D→B→C→D has weight \(-8+2+2=-4\).
  5. \(k=D\): the diagonal becomes A 0, B −4, C −4, D −8. Final diagonal \((0,-4,-4,-8)\).
  6. Answer: yes, the graph contains a negative cycle. The vertices with a negative diagonal entry, B, C and D, lie on negative cycles (B→C→D→B of weight −4, and B→D→B of weight −3). A is not on any cycle: \(d_{AA}=0\), even though A can reach the cycle.
  7. Reading a cycle from \(\Pi\): the final \(\Pi\) row of D is (NIL, D, B, C). Start at \(j=D\): \(\pi_{DD}=C\), \(\pi_{DC}=B\), \(\pi_{DB}=D\). So the closed walk is D→B→C→D, weight −4.

Where marks go

  • Once a negative cycle exists, the other entries of \(D\) are not shortest distances. They keep falling (they are \(-\infty\) in truth). Say this, and do not report \(d_{AB}=-1\) as a distance.
  • With large negative cycles the numbers can grow exponentially, so real code stops as soon as a diagonal turns negative.
  • "Identify the vertices" means list the ones with \(d_{ii}<0\), and ideally name the cycle. Do not list A.
  • Show at least the matrices after \(k=B\) (first negative diagonal) and the final one. The widget gives all four.
On paper: draw the graph, mark the cycle B→C→D→B in red with its weight \(-4\). Then the matrices \(D^{(0)}\) to \(D^{(4)}\) with the diagonal circled whenever it is negative, and the sentence "vertices B, C, D are on a negative cycle".

5. Warshall without extra memory (2020–21 Q2b, 10 marks)

The recurrence builds \(D^{(k)}\) from \(D^{(k-1)}\), so it seems to need two matrices (or \(n\) of them). Claim: one matrix updated in place is enough.

Proof

  1. In iteration \(k\) the update reads only \(d_{ij}\), \(d_{ik}\) and \(d_{kj}\).
  2. Row \(k\) and column \(k\) do not change in iteration \(k\): \(d^{(k)}_{ik}=\min\bigl(d^{(k-1)}_{ik},\ d^{(k-1)}_{ik}+d^{(k-1)}_{kk}\bigr)=d^{(k-1)}_{ik}\) because \(d^{(k-1)}_{kk}\ge0\) when there is no negative cycle (it is 0). The same for \(d_{kj}\).
  3. So the values \(d_{ik}\) and \(d_{kj}\) read in iteration \(k\) are the \(D^{(k-1)}\) values whether or not earlier updates of this iteration were already written. Overwriting \(d_{ij}\) in place is therefore safe.
  4. Memory: one \(n\times n\) matrix, \(\Theta(n^2)\), instead of \(\Theta(n^3)\) to keep all \(D^{(k)}\). The pseudocode in section 3 is this version.
  5. For Warshall's (Boolean) algorithm the same holds because \(t_{kk}=1\), so \(t_{ik}\leftarrow t_{ik}\lor(t_{ik}\land t_{kk})=t_{ik}\). \(\blacksquare\)

6. Transitive closure (slide 12)

The transitive closure \(G^*\) has an edge \((i,j)\) whenever \(G\) has a path from \(i\) to \(j\). Two ways:

Method

  1. From Floyd-Warshall: run it with any weights (say 1). Put \(t_{ij}=1\) if \(d_{ij}<\infty\), else 0. Cost \(\Theta(n^3)\).
  2. Warshall directly: \(t^{(0)}_{ij}=1\) if \(i=j\) or \((i,j)\in E\), else 0. Then \(t^{(k)}_{ij}=t^{(k-1)}_{ij}\lor\bigl(t^{(k-1)}_{ik}\land t^{(k-1)}_{kj}\bigr)\). Same loops, \(\Theta(n^3)\), and cheaper operations (OR and AND).
  3. Meaning: there is a path \(i\leadsto j\) through intermediates \(\{1..k\}\) if there was one with \(\{1..k-1\}\), or there is a path to \(k\) and one from \(k\) to \(j\).

Trace on A→B, B→C, C→A, C→D, E→D. Vertices A, B, C reach each other and D. E reaches D only. D reaches nobody. Final matrix rows: A (1,1,1,1,0), B (1,1,1,1,0), C (1,1,1,1,0), D (0,0,0,1,0), E (0,0,0,1,1).

7. Modelling questions on this chapter

The Dhaka new road (2021–22 Q3, 8+12+15)

Undirected graph, nodes are points in the plane, road cost proportional to Euclidean distance. Build one new road \((u,v)\) so that \(C_{uv}=\sum_{i,j}(\text{PreCost}_{ij}-\text{CurCost}_{ij})\) is largest.

Method · answer in the three parts

  1. (a) Input and output (8). Input: \(n\) stations with coordinates \((x_i,y_i)\) and the list of existing roads \((a,b)\) with cost = Euclidean distance. Output: the pair \((u,v)\) (not already a road) with the largest \(C_{uv}\), and that value.
  2. (b) Pseudocode (12). Below.
  3. (c) Backbone and cost (15). The backbone is all-pairs shortest paths. Floyd-Warshall on the original graph gives PreCost in \(\Theta(n^3)\). After adding edge \((u,v)\) with cost \(c\) (the Euclid distance), a shortest path uses the new edge at most once (weights are positive), so \(\text{CurCost}_{ij}=\min(D_{ij},\ D_{iu}+c+D_{vj},\ D_{iv}+c+D_{uj})\), \(O(1)\) per pair. One candidate costs \(O(n^2)\), and there are \(O(n^2)\) candidate pairs, so the total is \(O(n^3)+O(n^4)=O(n^4)\). If the graph is sparse, replace Floyd-Warshall by Dijkstra from every vertex (\(O(n(E+n\log n))\)) or Johnson; the \(O(n^4)\) candidate loop still dominates.
BEST-NEW-ROAD(points, roads)
  D = FLOYD-WARSHALL(roads)                     // PreCost, Θ(n^3)
  best = -∞;  bestPair = NIL
  for u = 1 to n
    for v = u+1 to n
        if (u,v) is not a road
            c = euclid(points[u], points[v])
            gain = 0
            for i = 1 to n
              for j = 1 to n
                  cur = min(D[i][j], D[i][u] + c + D[v][j], D[i][v] + c + D[u][j])
                  gain += D[i][j] - cur
            if gain > best:  best = gain;  bestPair = (u,v)
  return bestPair, best

(Counting ordered pairs \((i,j)\) doubles every gain and does not change the winner; say that.)

Other items

Method · short answers

  1. All-pairs strongest path (2017–18 Q2d). Strength = minimum edge on the path. Use Floyd-Warshall with \(d_{ij}=\max\bigl(d_{ij},\min(d_{ik},d_{kj})\bigr)\), initial \(d_{ij}=w_{ij}\) (0 if no edge, \(\infty\) on the diagonal). \(\Theta(n^3)\). Proof is the same two cases.
  2. Paths forced through \(v_0\) (2019–20 Q7c, 12). Two Dijkstra runs from \(v_0\) (original and reversed graph), then \(d(u,v_0)+d(v_0,v)\). See chapter 2. Or use \(D\) from Floyd-Warshall and take \(D_{uv_0}+D_{v_0v}\) in \(\Theta(n^3)\).
  3. Explain Floyd-Warshall (2023–24 Q9, 10 marks). Write section 3: definition of \(d^{(k)}_{ij}\), the two cases, the recurrence, pseudocode, \(\Theta(n^3)\). Johnson (5 marks): see chapter 5.

8. Mandatory practice

Do these with pen and paper. The recall items are the likeliest long answers.

If you got one wrong: open the steps and find the first \(k\) where your matrix differs. Most mistakes are using the new \(d_{ik}\) of the same iteration (harmless) or forgetting to add \(\infty\) properly.
