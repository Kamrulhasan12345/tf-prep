Bipartite Matching and Modelling Problems as Flow

Asked as a modelling question in nearly every paper. 2024–25 Q8(a) (relief warehouse, 20). 2022–23 Q3(b)(c) (formulate bipartite matching, two real-life examples 6+6; solve it, 10; Edmonds-Karp 5). 2021–22 Q4(b) (car parking, 12 + 15). 2020–21 3(a) (which single edge to enlarge) and 4(a) (edge connectivity by max flow). 2019–20 Q8(b) (backup sets, 10+7+6).

Syllabus note. Bayzid sir's notes say "reduction will not come" (boxed for the class test). Term finals ask reductions nearly every year, and four of the papers above are pure modelling. Learn this chapter.

1. Maximum bipartite matching

Bipartite graph
\(G=(L\cup R,E)\): vertices split into a left set L and a right set R. Every edge joins one vertex of L to one vertex of R.
Matching
A set of edges \(M\subseteq E\) in which no two edges share a vertex. Each vertex is used at most once.
Maximum matching
A matching with the most edges.

1.1 Real-life examples (2022–23 Q3(b), two needed)

  • Jobs and applicants. L = applicants, R = jobs, an edge when the applicant is qualified for the job. A matching gives each person at most one job and each job at most one person. Maximum matching = most jobs filled.
  • Exam rooms and exams. L = exams in one time slot, R = rooms, an edge when the room is big enough. Maximum matching = most exams that can run at once.
  • Cars and parking spots (section 3.5), students and project supervisors, donors and recipients: same shape.

1.2 The reduction to max flow

Method · build the flow network G'

  1. Add a source s and a sink t.
  2. Direct every edge of G from L to R, capacity 1.
  3. Add an edge s→l with capacity 1 for every l in L.
  4. Add an edge r→t with capacity 1 for every r in R.
  5. Run Ford-Fulkerson. Max matching size = max flow value. The matching is the set of L→R edges with flow 1.

Example: left vertices x1, x2, x3; right vertices y1, y2, y3. Edges x1–y1, x1–y2, x2–y1, x3–y1. (y3 has no edges.)

Watch the second augmentation. The first path matches x1 with y1. The second path goes s, x2, y1, then backward to x1 (the residual edge y1→x1, "cancel x1–y1"), then x1 to y2. Result: x1–y2 and x2–y1. A backward edge in the residual network means "undo an earlier match". The slides call such a path an alternating path.

On paper: draw the left column, the right column, then s and t with the capacity-1 edges. Label every edge 1. After the run, circle the middle edges with flow 1 and write "matching = {x1–y2, x2–y1}, size 2". Also state: x3 stays unmatched because its only neighbour y1 is taken (the min cut shows it: S = {s, x3, x2, y1} has capacity 2).

1.3 Why it is correct (7 marks in 2019–20 had the same proof shape)

Claim: the size of a maximum matching in G equals the value of a max flow in G'.

  1. Matching ⇒ flow. Given a matching M, send one unit along s→l→r→t for each (l,r) in M. Capacities hold (every edge carries 0 or 1, and each vertex is in at most one edge of M, so s→l and r→t carry at most 1). Conservation holds on every l and r. The value is |M|.
  2. Flow ⇒ matching. Capacities are integers, so Ford-Fulkerson returns an integer max flow f (integrality, chapter 07). Every edge then carries 0 or 1.
  3. Each l receives at most 1 unit from s, so by conservation at most one edge out of l has flow 1. Each r sends at most 1 unit to t, so at most one edge into r has flow 1. So the middle edges with flow 1 form a matching M.
  4. \(|M|\) = flow across the cut \((\{s\}\cup L,\ R\cup\{t\})\) = |f|.
  5. So max matching ≥ max flow (step 4) and max flow ≥ max matching (step 1). They are equal. \(\blacksquare\)

1.4 Runtime

The flow value is at most \(\min(|L|,|R|)\le V\), so Ford-Fulkerson takes at most V augmentations, each \(O(E)\) (G' has \(E+V\) edges). Total \(O(VE)\). Edmonds-Karp would give the weaker bound \(O(VE^2)\); for 2022–23 Q3(c) say: "the Edmonds-Karp idea is to pick the shortest augmenting path by BFS, giving \(O(VE^2)\) for any capacities (chapter 07). Here the flow is at most V, so plain FF is already \(O(VE)\)."

Where marks go

  • Forgetting the direction: edges go s → L → R → t, never back.
  • Forgetting that all capacities are 1 (the middle ones too; otherwise one vertex may be matched twice).
  • Skipping the integrality argument. Without it a fractional flow does not give a matching.
  • Not saying how to read the matching: the middle edges that carry flow 1.

What the teacher's slides add (slides 18 p.3-17)

  • Which graphs are bipartite (slides p.4-6). Some graphs can be redrawn with two columns and every edge between the columns (his \(G\) and \(G_1\)); some cannot (his \(G_2\), a cycle of 5 vertices). The standard test: a graph is bipartite if and only if it can be coloured with two colours, equivalently if and only if it has no odd cycle (Dasgupta et al., exercise 3.7). The questions always hand you a bipartite graph, but you may be asked why.
  • His example (slides p.7-16). Five volunteers \(v_1,\dots,v_5\) and four flags \(F_1,\dots,F_4\). A matching such as \(\{(v_1,F_1),(v_3,F_3)\}\) leaves some volunteers unhappy; "matched" means some edge of \(M\) touches the vertex. The maximum matching on his slide is \(\{(v_2,F_1),(v_3,F_2),(v_5,F_3)\}\), of size 3, found by adding \(s\) and \(t\), directing every edge \(s\to\) volunteer \(\to\) flag \(\to t\) with capacity 1 and running any max-flow algorithm: flow value 3 (slide 16).
  • Correctness, "Self study" (slide 17). The textbook labels are Lemma 26.9 (a matching of size \(k\) gives an integer flow of value \(k\) and conversely, CLRS p.733), Theorem 26.10 (integrality: with integer capacities Ford-Fulkerson returns an integer flow on every edge, p.734) and Corollary 26.11 (the maximum matching size equals the maximum flow value, p.735). Section 1.3 above proves exactly these three.

2. How to model any word problem as flow

Method · the six steps

  1. What moves? Name one unit of flow (a package, a person, a job).
  2. Source and sink. The place the units start; the place they must reach. If there are several, add a super source and super sink (chapter 06).
  3. Intermediate nodes. One node per thing that can be used up: depots, zones, devices, rooms.
  4. Edges. One edge for every allowed move, from where it starts to where it ends.
  5. Capacities. Every limit in the text becomes a capacity. A limit on a vertex goes on the edge from s into it, on the edge from it to t, or is a split \(v_{in}\to v_{out}\). If a route has no limit, use \(\infty\) (9999).
  6. Answer. Run Ford-Fulkerson. Say what the value means in the story, and read the assignment from the edges that carry flow.

3. The exam problems

3.1 Relief warehouse (2024–25 Q8(a), 20 marks)

Problem. A warehouse (unlimited supply) feeds depots D1, D2, D3 with daily sending capacities 15, 20, 10. Zones Z1 to Z4 can receive at most 10, 15, 10, 10. Routes: D1 to {Z1, Z2}; D2 to {Z1, Z3, Z4}; D3 to {Z2, Z4}. Find the maximum packages per day.

Model.

  • Source = the warehouse W. Sink = a new vertex T (all zones deliver to T).
  • Intermediate nodes = the depots D1, D2, D3 and the zones Z1 to Z4.
  • W→Di with capacity = the depot's sending capacity: 15, 20, 10. (The warehouse itself is unlimited, so the depot limit sits on this edge.)
  • Di→Zj for each allowed route, capacity \(\infty\) (the text gives no limit on a route; use 9999 in the engine).
  • Zj→T with capacity = the zone's receiving limit: 10, 15, 10, 10.

Apply Ford-Fulkerson. The engine below explores in alphabetical order. Step through it: five augmenting paths. Paths 3 and 5 use backward edges (they re-route packages already sent, for example path 3 takes 10 units away from D1 to Z1 and sends them from D2 instead).

Result from the trace.

Augmenting pathBottleneckTotal
W D1 Z1 T1010
W D1 Z2 T515
W D2 Z1 D1 Z2 T1025
W D2 Z3 T1035
W D3 Z2 D1 Z1 D2 Z4 T1045

Final flow on the depot-to-zone edges: D1→Z1 10, D1→Z2 5, D2→Z3 10, D2→Z4 10, D3→Z2 10 (D2→Z1 and D3→Z4 carry 0). Check each depot: D1 sends 15, D2 20, D3 10. Check each zone: Z1 gets 10, Z2 15, Z3 10, Z4 10.

Answer: 45 packages per day. Check with a cut: total depot capacity is 15 + 20 + 10 = 45 and total zone limit is 10 + 15 + 10 + 10 = 45, so 45 is an upper bound, and the flow reaches it. The residual network reaches only W, so the min cut is the three edges out of W, capacity 45.

On paper: first the network with all capacities (9999 or the infinity sign on the middle edges). Then, for each augmentation, the residual network and the path. Finally the flow network with flow/capacity on every edge, the value 45 and the min cut. State in words what 45 means. A different order of paths is fine; the value must be 45.

3.2 Backup sets in an ad-hoc network (2019–20 Q8(b), 10+7+6)

Problem. n devices, distances d[i,j]. Each device i needs a backup set of exactly k devices within distance D. No device may be in more than b backup sets. Decide whether this is possible.

(i) Reduction (10). Vertices: s, t, a left vertex \(x_i\) for every device (as the one that needs backups), a right vertex \(y_j\) for every device (as a possible backup).

  • \(s\to x_i\) with capacity k (device i needs k backups).
  • \(x_i\to y_j\) with capacity 1 whenever \(i\ne j\) and \(d[i,j]\le D\) (j can back up i, at most once).
  • \(y_j\to t\) with capacity b (j may serve at most b devices).

A good collection of backup sets exists if and only if the max flow has value nk.

(ii) Correctness (7).

  1. Collection ⇒ flow. Given a good collection, send 1 unit along \(s\to x_i\to y_j\to t\) for every j in the backup set of i. Edge \(s\to x_i\) carries k (its capacity), each middle edge carries 1, edge \(y_j\to t\) carries the number of sets containing j, which is at most b. Conservation holds. The value is nk.
  2. Flow ⇒ collection. Suppose the max flow has value nk. All capacities are integers, so there is an integer max flow. The edges out of s have total capacity nk, so all are saturated: \(x_i\) receives exactly k units. Each middle edge carries 0 or 1, so \(x_i\) sends flow on exactly k distinct edges \(x_i\to y_j\). Put j in the backup set of i for each of them. Every j is within D of i (edges exist only then), the sets have size k, and j is in at most b sets because \(y_j\to t\) carries at most b.
  3. No flow can exceed nk, because the cut \(\{s\}\) has capacity nk. So if the max flow is below nk, no good collection exists (step 1 would give a flow of value nk). \(\blacksquare\)

(iii) Algorithm and time (6). Build the network in \(O(n^2)\) and run Ford-Fulkerson. The network has \(2n+2\) vertices and at most \(n^2+2n\) edges, and the flow value is at most nk. Each augmentation is \(O(E)=O(n^2)\). Total \(O(n^2\cdot nk)=O(kn^3)\). Compare the max flow with nk, and if equal read the sets from the middle edges.

3.3 Edge connectivity by max flow (2020–21 4(a), 15 marks)

Problem. The edge connectivity of an undirected graph is the smallest number of edges whose removal disconnects it. Compute it with max-flow runs on at most |V| networks of size O(V) vertices and O(E) edges.

Method

  1. Replace each undirected edge {u,v} by two directed edges u→v and v→u, each with capacity 1.
  2. Fix any vertex \(v_0\) as the source.
  3. For every other vertex t (that is \(|V|-1\) choices), compute the max flow from \(v_0\) to t.
  4. The edge connectivity is the smallest of these \(|V|-1\) values.

Why it works.

  1. For fixed \(v_0,t\): a cut \((S,T)\) of the directed network has capacity equal to the number of undirected edges with one end in S and the other in T, because each such edge contributes exactly one directed edge from S to T. Removing those edges disconnects \(v_0\) from t. So max flow \(v_0\)–t = min number of edges separating \(v_0\) from t, by max-flow min-cut. Call it \(\lambda(v_0,t)\).
  2. Every \(\lambda(v_0,t)\) is at least the edge connectivity \(\lambda\), because the separating edge set also disconnects the graph.
  3. Let C be a smallest disconnecting set, \(|C|=\lambda\). Removing C leaves two sides; \(v_0\) is on one of them, and the other side has some vertex t. Then \(\lambda(v_0,t)\le|C|\).
  4. So the smallest \(\lambda(v_0,t)\) over t equals \(\lambda\). \(\blacksquare\)

Each network has |V| vertices and 2|E| edges. Each flow value is at most |V| − 1 (the degree of \(v_0\) is at most that), so each run of Ford-Fulkerson is \(O(VE)\) and the total is \(O(V^2E)\).

3.4 Which single edge should I enlarge? (2020–21 3(a), 10 marks)

Problem. You may raise the capacity of only one edge. Which edge raises the max flow, and what is the running time?

Idea. Raising the capacity of an edge e raises the max flow only if e belongs to every min cut. (If some min cut avoids e, that cut keeps its capacity and the max flow stays. If e is in every min cut, every min cut gets bigger and the value rises, at least for a small increase.) After max flow, such edges are easy to spot in the residual network.

BEST-EDGE(G, s, t)
 compute max flow f and the residual network G_f
 A = vertices reachable from s in G_f          // BFS from s
 B = vertices that can reach t in G_f          // BFS from t on reversed G_f
 return every edge (u,v) of G with u in A and v in B
   (if there is none, no single edge helps)

Why such an edge is in every min cut. Let (S,T) be any min cut. By the proof in chapter 07 no residual edge goes from S to T. A vertex reachable from s cannot leave S, so \(u\in S\). A vertex that can reach t cannot lie in S, so \(v\in T\). So (u,v) crosses every min cut from S to T. Such an edge is saturated, since otherwise v would be reachable from s. Conversely, if u is not reachable from s, the cut S = reachable set is a min cut with u in T, so e is not in it. If v cannot reach t, use T = vertices that can reach t.

Running time: one max-flow computation plus two BFS runs, \(O(E)\) extra. So it costs the same as computing the max flow. If the question asks for the best amount of gain, run max flow again with e's capacity set to infinity for each candidate, which is one more max flow per candidate.

3.5 Car parking (2021–22 Q4(b), 12 + 15 marks)

Problem. Cars A and parking spots B lie on a road graph G. The cost for car a to use spot b is the shortest distance in G (infinity if unreachable). (i) Formulate with max-flow. (ii) Match every car so that the total cost is minimum.

(i) Formulation (12). This is bipartite matching (section 1) with cars on the left and spots on the right.

  • s→a with capacity 1 for each car a.
  • a→b with capacity 1 for every spot b the car can reach (finite cost). Unreachable pairs get no edge.
  • b→t with capacity 1 for each spot b.

The max flow equals the largest number of cars that can be parked. Every car can be parked if and only if the max flow is |A| (this needs \(|B|\ge|A|\)). By max-flow min-cut, if it is less than |A| the min cut shows the cars that cannot be placed.

(ii) Minimum total cost (15). The notes do not teach min-cost flow; the question bank expects the following. Put a cost on each edge: cost(a→b) = shortest distance from a to b in G, all other edges cost 0. Find a flow of value |A| with smallest total cost.

Method · min-cost flow by successive shortest paths

  1. Compute the costs: run Dijkstra on G from every car's location. This gives all distances d(a,b).
  2. Build the flow network above, with those costs.
  3. Check that the max flow is |A| (otherwise some car cannot be parked: report it).
  4. Start with flow 0. Repeat |A| times: in the residual network find the s→t path of smallest total cost, where a forward edge has its cost and a backward edge has the negative of its cost. Push 1 unit along it.
  5. Because backward edges have negative costs, find the path with Bellman-Ford (it also accepts negative edges).
  6. The cars matched by the final flow, a→b with flow 1, are the answer.

Why it is right. A flow has the minimum cost among all flows of its value exactly when its residual network has no negative-cost cycle (a negative cycle could be pushed around to lower the cost). Start: flow 0 has no negative cycle. Pushing along a shortest (cheapest) path keeps the property. After |A| rounds the flow has value |A| and minimum cost.

Time. Dijkstra phase: |A| runs, each \(O(E_G+V_G\log V_G)\). Flow phase: |A| rounds of Bellman-Ford on a network with \(|A|+|B|+2\) vertices and \(|A||B|+|A|+|B|\) edges: \(O(|A|\cdot VE)\) with those V, E. (The Hungarian algorithm does the same assignment in \(O(n^3)\); it is not in the notes, so only mention it.)
