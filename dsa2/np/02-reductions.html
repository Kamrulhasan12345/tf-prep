Reductions and NP-completeness Proofs

Asked almost every year. 2024–25 Q1(c): clique is as hard as independent set (15). 2023–24 Q3: set cover is NP-complete (15). 2022–23 Q5(b): the task-scheduling word problem (17, compulsory). 2021–22 Q7(a): the social platform problem, using 3-SAT (10 in the bank, 5 + 10 in the paper). 2019–20 Q3(b): set cover at least as hard as vertex cover (12). 2018–19 Q7(c): vertex cover at least as hard as independent set (12). 2017–18 Q4(a), Q4(b): VC ≤ set cover, 3-SAT → independent set (3+7 each). 2020-21 Q8(c): explain NP-completeness of an optimization problem (5).

Syllabus honesty

  • Bayzid sir's notes (p.41) have a box "CT syllabus: computational complexity: definition only. Reduction will not come." That was for the class test. Term finals ask reductions nearly every year, so learn them.
  • His notes show only 3-SAT → independent set and independent set → vertex cover. Everything else here (clique, set cover, dominating set) comes from the question bank and past papers.

1. Which way does the arrow go?

A ≤p B reads "A reduces to B": we can solve A by using a solver for B. Convert an instance of A into an instance of B (function f, polynomial time), run B's algorithm, and convert the answer back if needed (function h).

Words for A ≤p B. "B is at least as hard as A." "A is no harder than B." Bayzid sir marks "A is at least as hard as B" as wrong. The exam phrase "prove that the clique problem is as hard as independent set" means: show IS ≤p Clique. The one you know goes on the left. The question's wording "X is at least as hard as Y" means Y ≤p X.

2. The template for "prove X is NP-complete"

Method · four parts, always in this order

  1. X ∈ NP. Name the certificate and the polynomial check (chapter 1 method).
  2. Choose a known NP-complete problem Y to reduce from (3-SAT, independent set, vertex cover, ...). Write "Y ≤p X".
  3. Construction. Describe how to turn any instance of Y into an instance f(Y) of X. Say it takes polynomial time and give the sizes.
  4. Correctness, both directions. (⇒) Y is a YES instance ⇒ f(Y) is a YES instance. (⇐) f(Y) is a YES instance ⇒ Y is a YES instance.
  5. Conclude: X is in NP and NP-hard, so NP-complete.

Bayzid sir's recap box has the same three core steps: Construction, Reduction (⇒), Reduction (⇐).

Where marks go

  • Reducing the wrong way. Never start from the new problem and map to a known one. That proves the new problem is easy if the known one is.
  • Proving only one direction of the iff. Both directions are required; one direction proves nothing.
  • Forgetting "X ∈ NP". For "prove NP-hard" or "at least as hard as" you can skip it. For "prove NP-complete" you cannot.
  • Forgetting that the instance size must stay polynomial (say how many vertices and edges you create).

3. 3-SAT ≤p Independent Set (2017–18 Q4(b); Bayzid sir's example)

3-SAT: a CNF formula where every clause has exactly 3 literals. Is it satisfiable? Independent set (IS): in graph G, is there a set of at least k vertices with no edge between any two of them?

Construction

  1. Let the formula have m clauses.
  2. For each clause draw a triangle, one vertex per literal in the clause (a literal that appears in several clauses gets a separate vertex in each).
  3. Add a conflict edge between every pair of vertices that are a variable and its negation, in different triangles (x in one clause, x′ in another).
  4. Set k = m.

Size: 3m vertices, at most 3m triangle edges plus \(O(m^2)\) conflict edges. Polynomial.

Bayzid sir's example formula: \((x \vee y \vee z') \wedge (x' \vee y' \vee p) \wedge (y \vee z' \vee p')\). The graph is below. The three green vertices form an independent set of size 3 and give the assignment x = 0, y = 1, p = 0 (z is free).

Proof of correctness

  1. (⇒) Formula satisfiable ⇒ IS of size m. Take a satisfying assignment. In each clause pick one literal that is true. That gives one vertex per triangle, m in all.
  2. No two picked vertices are adjacent: two vertices in the same triangle are never both picked (only one per triangle), and a conflict edge joins x and x′, which cannot both be true. So the set is independent, size m = k.
  3. (⇐) IS of size m ⇒ formula satisfiable. A triangle can contribute at most one vertex to an independent set (any two of its vertices are adjacent). There are m triangles and m vertices, so exactly one per triangle.
  4. Set each chosen literal to true. This is consistent: x and x′ are joined by a conflict edge, so both cannot be chosen. Variables not mentioned get any value.
  5. Every clause has a chosen literal that is true, so the formula is satisfied. ∎
  6. IS ∈ NP (certificate: the vertex set; check size and that no edge has both ends in it). With 3-SAT NP-complete, IS is NP-complete.
On paper: draw the triangles in a row, label each vertex with its literal, then add the conflict edges in a different style. Write "k = number of clauses = m" next to the graph. Mark the IS vertices to show the example works. The drawing is worth most of the marks for this question.

4. Independent Set ↔ Vertex Cover, both ways (2018–19 Q7(c))

A vertex cover is a vertex set touching every edge. An independent set is a vertex set with no edges inside it.

S is an independent set of G if and only if V − S is a vertex cover of G.

Proof

  1. S is independent ⇔ no edge has both endpoints in S.
  2. ⇔ every edge has at least one endpoint outside S.
  3. ⇔ V − S contains at least one endpoint of every edge, so V − S is a vertex cover. Each step is an "iff", so it holds in both directions.
  4. Sizes: |S| ≥ k ⇔ |V − S| ≤ |V| − k. So G has an IS of size ≥ k iff G has a vertex cover of size ≤ n − k.
  • IS ≤p VC (this proves "vertex cover is at least as hard as independent set", and so VC is NP-hard): given (G, k) output (G, n − k). Same graph, linear time.
  • VC ≤p IS (the other way, so they are equally hard): given (G, k) output (G, n − k). The identical map works.
  • VC ∈ NP: certificate is the vertex set, check size ≤ k and every edge is touched, O(|E|).

5. Independent Set ≤p Clique, by complement (2024–25 Q1(c), 15 marks)

Clique: does G have a set of k vertices where every two are adjacent?

Construction and proof

  1. Given an IS instance (G, k) build the complement graph \(\bar G\): same vertices, and u–v is an edge in \(\bar G\) exactly when u–v is not an edge in G. Keep k. Time \(O(n^2)\).
  2. Claim: S is an independent set in G ⇔ S is a clique in \(\bar G\).
  3. (⇒) S independent in G: every pair in S is a non-edge in G, so an edge in \(\bar G\). So S is a clique in \(\bar G\).
  4. (⇐) S a clique in \(\bar G\): every pair in S is an edge in \(\bar G\), so a non-edge in G. So S is independent in G.
  5. Therefore G has an independent set of size ≥ k iff \(\bar G\) has a clique of size ≥ k. ∎ So clique is as hard as independent set; it is NP-hard.
  6. For NP-completeness add: clique ∈ NP (certificate: k vertices, check every pair is an edge, \(O(k^2)\)).

Where marks go

  • The question gives "IS is NP-complete" as a given. So reduce from IS to Clique, not from Clique to IS.
  • The size parameter stays k, not n − k (that is the vertex cover version).

6. Vertex Cover ≤p Set Cover, so Set Cover is NP-complete (2023–24 Q3; 2019–20 Q3(b); 2017–18 Q4(a))

Set cover: universe U, subsets S₁...Sm of U, number k. Are there at most k subsets whose union is U?

Construction

  1. Given a vertex-cover instance (G = (V, E), k).
  2. Let the universe be the edges: U = E.
  3. For every vertex v make a subset \(S_v\) = the set of edges incident to v.
  4. Keep the same k. Size: |V| subsets of E. Polynomial.

Correctness

  1. (⇒) If C ⊆ V is a vertex cover with |C| ≤ k, take the subsets \(\{S_v : v \in C\}\). Every edge has an endpoint in C, so every edge lies in some chosen \(S_v\). The union is E = U, using ≤ k subsets.
  2. (⇐) If subsets \(S_v\), v ∈ C, with |C| ≤ k, cover U = E, then each edge e lies in some \(S_v\), meaning e is incident to v ∈ C. So C is a vertex cover of size ≤ k. ∎
  3. Set cover ∈ NP: certificate is k subsets; check the count and that their union equals U, in time polynomial in the input size.
  4. VC is NP-complete, so Set Cover is NP-hard; with membership in NP, Set Cover is NP-complete.

Where marks go

  • "At least as hard as" (2019–20) needs only the reduction. "Prove NP-complete" (2023–24) also needs "∈ NP". One student solution ends with "Set Cover is an NP problem": that is not enough, say NP-complete.
  • Edges are the universe and vertices are the sets, not the other way round. If you swap them the proof breaks.
  • Both directions of the iff, again.

7. Word problems in disguise

These questions never say "independent set" or "dominating set". You must recognise the problem. Two have appeared.

7.1 Scheduling with conflicts (2022–23 Q5(b), 17 marks, compulsory)

Tasks, some pairs cannot run at the same time. Maximise the number of tasks scheduled so that no two conflicting tasks are both chosen. The friend says it maps to a popular NP-complete problem and is NP-hard by reduction.

Answer in three parts

  1. Map to Independent Set. Vertex = task. Edge between two tasks that conflict. A set of tasks with no conflicting pair = a set of vertices with no edge between them = an independent set. Maximum tasks = maximum independent set. Decision form: "can we schedule at least k tasks?" = "does G have an IS of size ≥ k?".
  2. Membership in NP. Certificate: the chosen tasks. Check |S| ≥ k and no conflict pair inside S, \(O(|E|)\).
  3. Reduce a known NP-complete problem to it. The question says "reducing it to another known NP-complete problem". Use 3-SAT ≤p IS from section 3: triangles per clause, conflict edges between x and x′, k = m. Give the proof (⇒, ⇐). Then say the step that carries hardness to scheduling: any graph G is the conflict graph of a scheduling instance (one task per vertex, one conflict per edge, same k), so IS ≤p Scheduling, and 3-SAT ≤p IS ≤p Scheduling.
  4. Conclude: scheduling is NP-hard, and in NP, so NP-complete. The optimization version (maximise tasks) is NP-hard.

Reading note: the paper's wording is loose ("same team member simultaneously"). The standard reading is a pairwise conflict relation, which is a graph. State your reading in one line at the top of the answer.

7.2 Social platform (2021–22 Q7(a), 10 marks in the bank; 5 for the mapping, 10 for the proof)

Find the smallest set of users who can reach all other users through their connections.

(i) Map to Dominating Set (5 marks)

  1. Vertex = user, edge = connection. The chosen users must reach every other user directly through their connections: every user is either chosen or adjacent to a chosen user.
  2. That is the Dominating Set problem: a vertex set D such that every vertex is in D or has a neighbour in D. Decision form: is there a dominating set of size ≤ k?
  3. Reading note: "reach" must mean one hop. If any number of hops counted, one user in any connected network would reach everyone and there would be nothing to compute.

(ii) 3-SAT ≤p Dominating Set (10 marks)

  1. In NP. Certificate D. Check |D| ≤ k and every vertex is in D or adjacent to a member, \(O(n^2)\).
  2. Construction. Formula with variables \(x_1..x_n\) and clauses \(C_1..C_m\).
  3. For each variable \(x_i\): a triangle on three vertices \(x_i\), \(\bar x_i\), \(d_i\).
  4. For each clause \(C_j\): one clause vertex \(c_j\), joined to the (three) literal vertices that appear in \(C_j\).
  5. Set k = n. Size: 3n + m vertices, \(O(n+m)\) edges. Polynomial.
  6. (⇒) Satisfying assignment. Put into D the literal vertex that is true for each variable (n vertices). In each triangle the chosen vertex dominates the other two. Each clause vertex \(c_j\) has a true literal, which is in D, so \(c_j\) is dominated. D has n vertices and dominates everything.
  7. (⇐) Dominating set D of size n. The dummy vertex \(d_i\) has neighbours only inside its triangle, so D contains at least one of \(x_i, \bar x_i, d_i\) for each i. There are n triangles and |D| = n, so exactly one vertex per triangle, and no clause vertex is in D.
  8. If a triangle's chosen vertex is \(d_i\), swap it for \(x_i\): the triangle is still dominated, and no clause vertex loses anything (they were not dominated by \(d_i\)). So every chosen vertex is a literal.
  9. Set the chosen literals to true. Each triangle gives one literal, so the assignment is consistent. Each clause vertex \(c_j\) is not in D, so some neighbour (a literal of \(C_j\)) is in D, meaning that literal is true and \(C_j\) is satisfied. ∎
On paper: draw all variable triangles in a row with the clause vertices above, dashed lines from each clause vertex to its three literals. Write k = n. State the two facts that carry the proof: "di forces one vertex per triangle" and "the clause vertex needs a true literal".

8. Optimization problems are NP-hard, not NP-complete (2020–21 Q8(c), 5 marks)

Answer

  1. NP and NP-complete contain only decision problems. An optimization problem ("find the smallest vertex cover") has no YES/NO answer, so it is not in NP and cannot be NP-complete.
  2. Make its decision version with a bound: "is there a vertex cover of size ≤ k?". Prove that NP-complete with the template of section 2.
  3. The optimization problem is then NP-hard: a polynomial algorithm for it would solve the decision version, because we compute the optimum and compare it with k. So Decision ≤p Optimization, and hardness flows to the optimization problem.

Same sentence as in Bayzid sir's notes (p.37): "If a decision problem is NP-complete, its optimization version is NP-hard."

9. One more from the bank: Subset Sum ≤p Set Partition (CT3 2022, 10 marks)

Set partition: can a multiset S be split into two parts of equal sum? Subset sum (given NP-complete): is there a subset of S with sum exactly T? Let Σ be the total of S.

Reduction

  1. Add one new number \(x = |\Sigma - 2T|\). New multiset \(S' = S \cup \{x\}\). Polynomial time.
  2. Case 2T ≤ Σ (so x = Σ − 2T; total of S′ is 2Σ − 2T; half is Σ − T). If a subset of S sums to T, add x to it: sum T + Σ − 2T = Σ − T, which is half. Conversely if S′ splits into halves of Σ − T, the half containing x minus x sums to Σ − T − (Σ − 2T) = T, a subset of S with sum T.
  3. Case 2T > Σ (x = 2T − Σ; total of S′ is 2T; half is T). A subset of S with sum T is itself a half. Conversely the half not containing x is inside S and sums to T; if x is in a half, the other half is inside S and sums to T.
  4. Set partition ∈ NP (certificate: the part A). So it is NP-complete.
