Backtracking: SAT Trees and Hamiltonian Circuit

Asked as "use backtracking to decide whether this formula is satisfiable, show the tree" in 2024–25 Q3(c) (10), 2020–21 Q8(b) (find all satisfying assignments, 10) and 2018–19 Q8(c) (10). Asked as "backtracking for a Hamiltonian circuit, show the state-space tree" in 2017–18 Q3(c) (10). Also in the 2023–24 Q4(b) list of coping approaches. This chapter is mechanical: once you know the rules, every tree is the same drill.

1. The idea

An NP-complete problem has an exponential search space. For SAT with n variables there are \(2^n\) assignments. Backtracking grows a tree of partial solutions and rejects a partial solution as soon as a small part of it is already bad, so whole subtrees are never visited. Slide example: if the formula has the clause \((x_1 \vee x_2)\), every assignment with \(x_1 = x_2 = 0\) can be thrown away at once, which prunes a quarter of the space.

At every node the algorithm classifies the sub-problem into one of three kinds:

ClassFor SAT it meansAction
Failuresome clause has all its literals false (it became the empty clause)stop here and backtrack. Do not branch on the remaining variables.
Successevery clause is already satisfiedstop. Answer is YES. (To find all solutions, record it and continue.)
Uncertainneither of the abovebranch on the next variable (0 and 1) and recurse.

The node label is the residual formula. After setting a variable, delete every clause that is now true, and delete the false literal from every other clause. What remains is written in the node. Bayzid sir's slide writes it as (y'), (y ∨ z). An empty clause is written () and means Failure. An empty formula means Success.

Backtracking is mostly for decision problems. The worst case is still exponential. It is fast on most real inputs because failures are found high up in the tree.

2. Method · backtracking for SAT

Method · draw the tree

  1. Fix a variable order (alphabetical: x, y, z) and the order of the two branches (0 first, then 1). Write them down; the examiner accepts any fixed order if the tree is consistent.
  2. Root: write the whole formula.
  3. For a node, set the next variable to 0 (left child) and to 1 (right child). Label each edge x=0 or x=1.
  4. Compute each child's residual formula: drop satisfied clauses, drop false literals from the rest.
  5. Residual contains (): write FAILURE and stop. Residual is empty: write SUCCESS and stop. Otherwise it is UNCERTAIN: branch on the next variable.
  6. If a child is a Success, the formula is satisfiable and the assignment is the edge labels on the path. If every leaf is Failure, it is unsatisfiable.
BACKTRACK-SAT(F, i)               // variables x_1 .. x_n, 0 first
  if F contains an empty clause: return FAIL
  if F has no clauses:           return SUCCESS
  for b in {0, 1}:
     F' = F with x_i = b          // delete true clauses, delete false literals
     if BACKTRACK-SAT(F', i+1) == SUCCESS: return SUCCESS
  return FAIL

3. 2024–25 Q3(c): (x′∨y′) ∧ (x′∨y) ∧ (x∨y′∨z) ∧ (x∨y∨z)

Press Next and name the class (Failure / Uncertain / Success) before reading the caption. The first run stops at the first success, which is what the question asks ("decide whether this is satisfiable").

The same formula with the whole tree drawn (both successes shown). Use this form if you want to be safe, or if the question says "find all assignments".

On paper: a binary tree three levels deep. Put the residual formula inside each node, the assignment on each edge, and write FAILURE or SUCCESS under each leaf. Note that after x = 1 the residual is (y′)(y), which fails on both branches without ever branching on z. Finish with one sentence: "Satisfiable, for example x = 0, y = 0, z = 1." The handwritten note in the paper margin (z = 1, y = 0/1, x = 0) agrees with the tree: both y values work when x = 0, z = 1.

4. Bayzid sir's slide example and the other past formulas

Slide formula: (x′∨y′) ∧ (x∨y′) ∧ (x′∨y) ∧ (x∨y∨z). The notes write the answer "satisfiable with x = 0, y = 0, z = 1".

2020–21 Q8(b): find all assignments. The formula is (x∨y′) ∧ (x′∨w) ∧ (x∨y∨z′) ∧ (x′∨w∨z). Variable order here is alphabetical in the engine: w, x, y, z. The tree ends in three Success leaves. The leaf w = 1, x = 1 stops early with y and z still free, so it stands for 4 assignments. Total: 1 + 1 + 4 = 6 satisfying assignments (checked by brute force).

2018–19 Q8(c): (x′∨y′) ∧ (x∨y′) ∧ (x′∨y) ∧ (x∨y∨z′) ∧ (x∨y∨z). Every branch fails, so the formula is unsatisfiable. Writing "UNSATISFIABLE" under the tree is part of the answer.

Where marks go

  • Branching on z under a node that already failed. Stop at the empty clause.
  • Not simplifying the clauses at each node. The examiner checks the residual formulas.
  • In "find all" questions, stopping at the first success. In "decide" questions it is fine to stop.
  • When a success leaf still has unassigned variables (like w = 1, x = 1 above), say "y, z free" instead of silently choosing values.
  • Forgetting the final one-line verdict: SAT with the assignment, or UNSAT.

5. Backtracking for a Hamiltonian circuit (2017–18 Q3(c))

A Hamiltonian circuit visits every vertex exactly once and returns to the start. The state-space tree here is a tree of partial paths.

Method · Hamiltonian circuit by backtracking

  1. Fix the start vertex (any vertex works, since a circuit passes through all of them) and an order for the neighbours (alphabetical). The root is the path a.
  2. A node is a path from a. Its children extend the path by one unvisited neighbour of the last vertex, in the chosen order.
  3. Dead end: the last vertex has no unvisited neighbour while vertices remain. Cross it out and backtrack.
  4. When the path contains all n vertices, check whether the last vertex is adjacent to the start. If yes, the path plus that edge is a Hamiltonian circuit: success. If no, it is a failure.

The 2017–18 figure is a cube-like graph with eight vertices. I read its edges from the scan as: a–b, a–d, a–f, b–c, b–g, c–d, c–h, d–e, e–f, e–h, f–g, g–h (every vertex has degree 3). If your copy differs, the method is unchanged.

Reading the tree. From abcde the first child is f (alphabetical). Then g, then h, and the path abcdefgh has all 8 vertices but h is not adjacent to a: failure, backtrack all the way to e. The next child is h, then g, then f, and f is adjacent to a: the circuit a b c d e h g f a is found. (Running the whole search without stopping, the engine finds 12 directed Hamiltonian circuits, 6 up to direction, 112 nodes visited.) Stop at the first circuit unless the question asks for all.

On paper: the graph, then the tree with the path written in each node (a, ab, abc, ...). Mark each failure with a cross and the reason ("no unvisited neighbour" or "h not adjacent to a"). Mark the circuit and write it out with the return to a. Do not draw the branches you never visited.
