P, NP, co-NP, NP-complete

Asked every year. 2024–25: Q1(a) P = NP ⇒ NP = co-NP (12), Q1(b) P = NP ∩ co-NP prove or disprove (8), Q2(c) "P ≠ NP yet NP = co-NP" (8). 2023–24 Q4(a): define P, NP, NP-complete and draw the Venn diagram (9+6). 2022–23 Q5(a): NP vs NP-hard vs NP-complete (6, compulsory). 2019–20 Q3(a): X ∈ NPC, X ∈ P iff P = NP (8). 2018–19 Q7(a) is the same proof as 2024–25 Q1(a), and Q7(b) is TAUTOLOGY. All of these are short proofs. You can learn each in ten minutes.

Start here: why complexity classes exist (Bayzid sir, Lecture 9, pp. 23-24; slides 2-4)

  • Complexity belongs to the problem, not to one algorithm. We sort problems by how hard they are.
  • Search space. The solution is hidden among a candidate set. For shortest path from vertex 1 to vertex n, his rough count gives Pn = (n−1)·Pn−1, so (n−1)! paths, which is O(nn), worse than exponential. Trying them all is hopeless.
  • Shortest path and MST are the exceptions. The relaxation property cuts the shortest-path search down, so Dijkstra runs in O(V²) (or O(E + V log V)). The cut property does the same for MST: the search space is also O(nn), yet Prim and Kruskal run in O(E log V). Slide 2 calls these "exceptions".
  • Most problems have no such property. We cannot prove "no fast algorithm exists" the way we proved the sorting lower bound. Slides 3-4 (the Garey and Johnson cartoon) say the honest alternative: show the problem is as hard as many famous problems that clever people failed to solve quickly. That is NP-completeness. It is the answer to "why study this?".

1. Decision problems, and why we only study them

A decision problem has a YES/NO answer. An optimization problem asks for the best value. Complexity classes are defined only for decision problems, so every optimization problem gets a decision twin by adding a bound.

OptimizationDecision twin
Find the shortest path from s to tIs there a path from s to t of length ≤ x?
Find the smallest vertex coverIs there a vertex cover of size ≤ k?
Find the largest independent setIs there an independent set of size ≥ k?
Find a satisfying assignment (SAT)Is the formula satisfiable? (already YES/NO)

The two twins are equally hard. Solve the optimization problem and you read off the decision answer: compute the optimum, compare it with the bound. Solve the decision problem and you get the optimum by asking "is it ≤ 1? ≤ 2? ..." (or binary search). So "decision is hard" and "optimization is hard" mean the same thing. The bound x is needed in the decision version, otherwise there is nothing to say YES or NO to.

2. P and NP

P
Decision problems solvable by an algorithm that runs in polynomial time, \(O(n^c)\) for some constant c. "Efficiently solvable."
NP
Decision problems with a polynomial-time verifier for YES answers. Given an instance I and a claimed solution S (the certificate), we can check in polynomial time that S really proves the answer is YES. Easy to check, not necessarily easy to find. (The name means non-deterministic polynomial: a machine that guesses S and then checks it.) Bayzid sir gives this as the alternate definition (p. 28): NP is the set of decision problems solvable in polynomial time on a non-deterministic Turing machine, a theoretical machine that reaches the whole search space at once.
Certificate
The short proof. It must have polynomial size and the checking must take polynomial time.

SAT is in NP, yet nobody knows a polynomial algorithm for it. Trying all \(2^n\) assignments is exponential. Checking one assignment is quick. There is no obvious short certificate for a NO answer ("unsatisfiable"): that needs a "for all assignments" statement, while YES needs only "there exists".

Method · show that a problem is in NP (use this every time)

  1. Say what the certificate is (for example "a set S of at most k vertices"). Say its size is polynomial.
  2. Write the check as a few steps and count the time (for example "for each edge test two memberships: O(|E|)").
  3. Conclude: polynomial verifier, so the problem is in NP.

P ⊆ NP

Let X ∈ P with algorithm A. The verifier ignores the certificate, runs A on the instance, and returns A's answer. That is polynomial, so X ∈ NP. Whether NP ⊆ P (that is, P = NP) is the famous open question. Most people believe P ≠ NP. To show P ≠ NP it is enough to find one problem that is in NP but not in P, and that is exactly why such a find would be important (18 CT4 6b).

3. Complements and co-NP

The complement X′ of a decision problem X answers YES exactly when X answers NO. SAT and UNSAT are complements.

co-NP
\(\text{co-NP} = \{X' : X \in NP\}\). Equivalently: decision problems with a polynomial verifier for NO answers. UNSAT, TAUTOLOGY and PRIME are in co-NP.

P is closed under complement. If X ∈ P with algorithm A, run A and flip the answer: X′ ∈ P. Nobody knows if NP is closed under complement. A certifier for X does not give a certifier for X′, because YES uses "there exists" and NO uses "for all". That open question is "NP = co-NP?".

Example for "if X is in NP then X′ is in co-NP" (20-21 7b): SAT ∈ NP, so UNSAT ∈ co-NP by definition. A NO answer to UNSAT is a satisfying assignment, which is easy to check.

Outside both (Bayzid sir, p. 32): an undecidable problem lies outside NP and outside co-NP, so these classes are not "all problems".

P ⊆ co-NP. A problem in P can verify its NO answers too, by solving the problem. So P sits in the overlap of NP and co-NP.

5. P = NP ⇒ NP = co-NP (2024–25 Q1(a), 12 marks; 2018–19 Q7(a))

Exam-ready, two inclusions. We use two facts: P is closed under complement, and "NP = co-NP" means NP ⊆ co-NP and co-NP ⊆ NP.

Proof · assume P = NP

  1. NP ⊆ co-NP. Let X ∈ NP.
  2. Since P = NP, X ∈ P.
  3. P is closed under complement (run X's algorithm and flip the answer), so X′ ∈ P.
  4. Since P = NP, X′ ∈ NP.
  5. X′ ∈ NP means X = (X′)′ ∈ co-NP by the definition of co-NP. So NP ⊆ co-NP.
  6. co-NP ⊆ NP. Let X ∈ co-NP. By definition X′ ∈ NP.
  7. Since P = NP, X′ ∈ P. By closure under complement, X ∈ P.
  8. Since P ⊆ NP, X ∈ NP. So co-NP ⊆ NP.
  9. Both inclusions hold, so NP = co-NP. ∎

The contrapositive is the form people quote: NP ≠ co-NP ⇒ P ≠ NP. It is a stronger-looking route to P ≠ NP, because if you could show NP ≠ co-NP you would get P ≠ NP for free.

6. "Prove or disprove: P = NP ∩ co-NP" (2024–25 Q1(b), 8 marks)

This is a trick question. It is an open problem, so neither a proof nor a disproof is known, and you cannot give one. The marks are for showing what is provable and why the rest is stuck.

Answer · in four steps

  1. P ⊆ NP ∩ co-NP is provable. P ⊆ NP (certifier ignores the certificate). P ⊆ co-NP (P is closed under complement, so X ∈ P gives X′ ∈ P ⊆ NP, so X ∈ co-NP).
  2. The other direction, NP ∩ co-NP ⊆ P, is not known.
  3. Why it cannot be disproved today. If P = NP then NP = co-NP (section 5), so NP ∩ co-NP = NP = P and the statement is true. Taking the contrapositive: if the statement were false, then P ≠ NP. So a disproof would also prove P ≠ NP, which nobody has done.
  4. Why it cannot be proved today. A proof would need a polynomial algorithm for every problem in NP ∩ co-NP. Nobody has one for all of them. History: PRIME sat in NP ∩ co-NP for years before the AKS algorithm put it in P, and the same status question is open for other problems in the overlap.

Where marks go

  • Writing "true" or "false" with a made-up proof. State "open" and prove the half that is provable.
  • Forgetting that P is closed under complement is what puts P inside co-NP.

7. "P ≠ NP yet NP = co-NP is possible" (2024–25 Q2(c), 8 marks)

Agree. There are four combinations of the two questions. D is impossible. A, B and C are all not ruled out:

WorldP vs NPNP vs co-NPStatus

DP = NPNP ≠ co-NPimpossible (section 5)

The only implication proved is P = NP ⇒ NP = co-NP. Its converse "NP = co-NP ⇒ P = NP" has not been proved, so world B is not contradicted by anything we know. The statement in the question is therefore consistent. It would only be false if someone proved NP = co-NP ⇒ P = NP.

8. TAUTOLOGY is in co-NP (2018–19 Q7(b))

TAUTOLOGY: is a Boolean formula true for every assignment?

Proof

  1. The complement is NON-TAUTOLOGY: is there at least one assignment that makes the formula false?
  2. NON-TAUTOLOGY ∈ NP. Certificate: a falsifying assignment. Verifier: evaluate the formula under it, in time linear in the formula size, and accept if the value is false.
  3. So the complement of TAUTOLOGY is in NP, hence TAUTOLOGY ∈ co-NP by the definition. ∎

Connection: a formula F is a tautology iff ¬F is unsatisfiable, so TAUTOLOGY is just UNSAT in disguise.

9. NP-hard, NP-complete, and the three-way comparison (2022–23 Q5(a), 6 marks)

NP-hard
X is NP-hard if every problem Y in NP reduces to it: \(Y \le_p X\). It need not be a decision problem and need not be in NP. A polynomial algorithm for X would solve all of NP in polynomial time.
NP-complete
X is in NP and NP-hard. The hardest problems inside NP. Two NP-complete problems are equally hard (each reduces to the other).
NPNP-hardNP-complete
Decision problems only?yesnoyes
Must be verifiable in poly time?yes (that is the definition)noyes
Everything in NP reduces to it?noyesyes
ExamplesSAT, Hamiltonian cycle, and every problem in PTSP optimization, optimization version of vertex cover, plus all of NPCSAT, 3-SAT, independent set, vertex cover, set cover, clique

If a decision problem is NP-complete, its optimization version is NP-hard but is not NP-complete (it is not a decision problem, so it is not in NP). The chapter on reductions shows why.

Proving a new problem NP-complete directly means reducing all of NP to it, which is impossible to do each time. Cook proved SAT NP-complete once. After that you only need one reduction from a known NPC problem. That is the whole content of the reductions chapter.

10. X ∈ NP-complete: X ∈ P ⇔ P = NP (2019–20 Q3(a), 8 marks)

Proof · both directions

  1. (⇐) Assume P = NP. X is NP-complete, so X ∈ NP = P. Hence X ∈ P.
  2. (⇒) Assume X ∈ P with a polynomial algorithm \(A\) running in time \(O(n^c)\).
  3. Take any Y ∈ NP. Because X is NP-hard, \(Y \le_p X\): there is a polynomial-time map f taking an instance I of Y to an instance f(I) of X with the same answer. Say f runs in \(O(n^d)\), so |f(I)| is \(O(n^d)\).
  4. Algorithm for Y: compute f(I), run A on it, return A's answer. Time \(O(n^d) + O((n^d)^c) = O(n^{cd})\), polynomial. So Y ∈ P.
  5. Y was arbitrary, so NP ⊆ P. Together with P ⊆ NP we get P = NP. ∎

The step that gets marks: a polynomial of a polynomial is still a polynomial, so the composed algorithm is polynomial. Same idea answers 17-18 4d ("your friend has a polynomial algorithm for set packing, what happens?"): set packing is NP-complete, so P = NP.

Quick consequences of "Y ≤p X" (use in MCQs). If X ∈ P then Y ∈ P. If Y is NP-hard then X is NP-hard. Nothing else follows: it does not say P = NP, and it does not make Y and X equally hard.

11. The fallacy question (18 CT4 6c, 4 marks)

"To see if a 3-SAT formula is satisfiable we must look at \(2^n\) assignments. That takes exponential time, so 3-SAT is not in P. But it is in NP, so P ≠ NP." Find the fallacy.

  • Looking at \(2^n\) assignments is one algorithm. P ≠ NP needs a proof that every possible algorithm is super-polynomial. A lower bound on one algorithm proves nothing. (Compare: brute-force shortest path over all paths is exponential, yet shortest path is in P.)
  • Being in NP does not separate it from P, because P ⊆ NP. You would need "in NP and not in P". The "not in P" half was never proved.
